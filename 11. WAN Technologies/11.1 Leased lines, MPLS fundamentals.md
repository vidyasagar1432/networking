# 1. Overview

Leased lines and MPLS are WAN technologies used to connect geographically separated networks. Leased lines provide dedicated point-to-point connectivity, while MPLS uses label switching inside a service provider network to efficiently forward traffic and provide scalable enterprise WAN services.

---

# 2. WAN Fundamentals

## WAN Definition

WAN:

```
Wide Area Network
```

Connects networks across large geographic distances.

Example:

```
Head Office

      |

   WAN Link

      |

Branch Office
```

---

# WAN Connection Types

| Type | Description |
|---|---|
| Internet VPN | Secure tunnel over public Internet |
| Leased Line | Dedicated private connection |
| MPLS | Provider-based label switching |
| Metro Ethernet | High-speed metropolitan connectivity |
| SD-WAN | Software-controlled WAN |

---

# 3. Leased Lines

## Definition

A leased line is a dedicated point-to-point connection rented from a telecommunications provider.

---

# Leased Line Concept

```
Customer Site A

Router

   |

Dedicated Circuit

   |

Router

Customer Site B
```

---

# Characteristics

| Feature | Description |
|---|---|
| Dedicated | Exclusive bandwidth |
| Point-to-point | Connects two locations |
| Private | Not shared with other customers |
| Predictable | Fixed performance |
| Expensive | Higher cost |

---

# Leased Line Examples

Common technologies:

- T1
- T3
- E1
- E3
- Serial circuits
- Ethernet leased circuits

---

# Leased Line Speeds

| Technology | Speed |
|---|---|
| T1 | 1.544 Mbps |
| E1 | 2.048 Mbps |
| T3 | 44.736 Mbps |
| E3 | 34.368 Mbps |

# 6. MPLS Fundamentals

## Definition

MPLS:

```
Multiprotocol Label Switching
```

A WAN technology that forwards packets using labels instead of only IP addresses.

---

# Traditional IP Routing

Router checks:

```
Destination IP

↓

Routing table lookup

↓

Forward packet
```

---

# MPLS Forwarding

Router checks:

```
Label

↓

Label table lookup

↓

Forward packet
```

---

# MPLS Concept

```
Customer Site A

      |

     PE Router

      |

 MPLS Provider Network

      |

     PE Router

      |

Customer Site B
```

---

# 7. MPLS Terminology

| Term | Meaning |
|---|---|
| CE | Customer Edge router |
| PE | Provider Edge router |
| P | Provider core router |
| LER | Label Edge Router |
| LSR | Label Switch Router |

---

# MPLS Device Roles

## CE Router

Customer device.

Responsibilities:

- Connects to provider
- Runs customer routing

Example:

```
Customer Router
```

---

## PE Router

Provider edge device.

Responsibilities:

- Adds/removes labels
- Connects customers

---

## P Router

Provider core device.

Responsibilities:

- Label switching
- No customer awareness

---

# MPLS Path

```
CE

↓

PE

↓

P

↓

P

↓

PE

↓

CE
```

---

# 8. MPLS Labels

## Definition

A label is a short identifier inserted into packets.

---

# MPLS Label Format

Size:

```
32 bits
```

Structure:

| Field | Size |
|---|---|
| Label value | 20 bits |
| Traffic Class | 3 bits |
| Bottom of Stack | 1 bit |
| TTL | 8 bits |

---

# MPLS Packet

Before MPLS:

```
IP Header

Data
```

---

After MPLS:

```
IP Header

MPLS Label

Data
```

---

# 9. MPLS Label Operations

## Push

Adding a label.

Performed by:

```
Ingress PE
```

---

## Swap

Changing label.

Performed by:

```
P routers
```

---

## Pop

Removing label.

Performed by:

```
Egress PE
```

---

# MPLS Packet Flow

```
Customer Packet

      |

PE adds label

      |

P routers swap labels

      |

PE removes label

      |

Destination
```

# 11. MPLS VPN Concept

MPLS can create private virtual networks.

Example:

```
Company A

Site 1

   |

MPLS Cloud

   |

Site 2
```

Traffic stays separated from other customers.

# 12. MPLS Layer 3 VPN

Most common enterprise MPLS VPN.

Uses:

- VRF
- MP-BGP
- MPLS labels

---

# VRF

VRF:

```
Virtual Routing and Forwarding
```

Creates separate routing tables.

Example:

```
Customer A Routing Table

Customer B Routing Table
```

# 13. MPLS vs Leased Line

| Feature | Leased Line | MPLS |
|---|---|---|
| Connection | Point-to-point | Any-to-any |
| Provider network | Dedicated circuit | Shared infrastructure |
| Scalability | Low | High |
| Cost | High | Medium |
| Multiple sites | Difficult | Easy |
| QoS | Available | Strong support |

---

# 14. MPLS vs Internet VPN

| Feature | MPLS | Internet VPN |
|---|---|---|
| Transport | Provider network | Public Internet |
| Security | Separation | Encryption |
| Cost | Higher | Lower |
| Performance | Predictable | Variable |
| Deployment | Slower | Faster |
