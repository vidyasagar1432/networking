# 1. Overview

Cisco IOS Command-Line Interface (CLI) is the primary method used to configure, manage, and troubleshoot Cisco networking devices. CCNA requires understanding IOS modes, command navigation, configuration workflows, and basic operational commands.

- Routers

# 3. Cisco IOS Command Modes

Cisco IOS uses hierarchical modes:

```
User EXEC Mode

        ↓

Privileged EXEC Mode

        ↓

Global Configuration Mode

        ↓

Specific Configuration Modes
```

---

# Mode Summary

| Mode | Prompt | Purpose |
|---|---|---|
| User EXEC | Router> | Basic monitoring |
| Privileged EXEC | Router# | Full monitoring and admin |
| Global Config | Router(config)# | Device configuration |
| Interface Config | Router(config-if)# | Interface settings |
| Line Config | Router(config-line)# | Console/SSH settings |
| Router Config | Router(config-router)# | Routing protocol settings |

# 6. Global Configuration Mode

## Enter

From privileged mode:

```bash

```

Shortcut:

```bash
conf t
```

---

Prompt:

```
Router(config)#
```

---

## Purpose

Configure device-wide settings.

Examples:

- Hostname
- Passwords
- Interfaces
- Routing
- VLANs


```

```
```
R1(config)#
```

# 16. Configuration Workflow

Typical Cisco configuration process:

```
Connect Device

↓

Enter enable mode

↓

Enter configuration mode

↓

Configure settings

↓

Verify configuration

↓

Save configuration
```

# Example Complete Workflow

## Step 1

```bash

```

---

## Step 2

Enter configuration:

```bash

```

## Step 3

Set hostname:


---

## Step 4

Configure interface:

---

## Step 5

Verify:


---

## Step 6

Save:

```bash

```

# 17. Running vs Startup Configuration

## Running Configuration

Stored in RAM.

Command:

```bash
show running-config
```

Characteristics:

- Active configuration
- Lost after reboot if not saved

---

## Startup Configuration

Stored in NVRAM.

Command:

```bash
show startup-config
```

Characteristics:

- Loaded during boot
- Persistent

---

# Save Configuration

Command:

```bash
copy running-config startup-config
```

Shortcut:

```bash
write memory
```

or:

```bash
wr
```

# 20. Common Beginner Errors

| Error | Cause | Solution |
|---|---|---|
| Invalid input detected | Wrong mode | Enter correct mode |
| Cannot configure command | In EXEC mode | Enter config mode |
| Configuration lost | Not saved | Copy run start |
| Interface down | Missing no shutdown | Enable interface |

# CCNA Exam Traps

- User EXEC prompt ends with `>`.
- Privileged EXEC prompt ends with `#`.
- Configuration mode uses `(config)#`.
- `enable` moves user → privileged mode.
- `configure terminal` enters global configuration.
- `exit` moves back one level.
- `end` immediately returns to privileged mode.
- Running-config is stored in RAM.
- Startup-config is stored in NVRAM.
- Save changes using `copy running-config startup-config`.
