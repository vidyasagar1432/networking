# 1. Overview

Packet capture and cable testing are essential troubleshooting techniques used by network engineers to identify problems at different layers of the network. Wireshark analyzes captured packets to understand protocol behavior, while cable testers verify the physical integrity of network cabling.

---

# 2. Network Troubleshooting Tools

| Tool | Layer | Purpose |
|---|---|---|
| Cable Tester | Layer 1 | Check physical cables |
| Wireshark | Layers 2-7 | Analyze packets |
| Ping | Layer 3 | Test reachability |
| Traceroute | Layer 3 | Find network path |
| SNMP | Layers 2-7 | Monitoring |
| Syslog | Layers 1-7 | Event logging |

---

# 8. Capture Filters vs Display Filters

## Capture Filter

Applied before capturing.

Reduces collected traffic.

Example:

Capture only ICMP:

```
icmp
```

---

## Display Filter

Applied after capture.

Filters displayed packets.

Example:

```
http
```

---

# Comparison

| Feature | Capture Filter | Display Filter |
|---|---|---|
| Applied | Before capture | After capture |
| Reduces file size | Yes | No |
| Syntax | BPF | Wireshark syntax |

# 16. Ethernet Cable Wiring

## T568A

Pin order:

| Pin | Color |
|---|---|
| 1 | White Green |
| 2 | Green |
| 3 | White Orange |
| 4 | Blue |
| 5 | White Blue |
| 6 | Orange |
| 7 | White Brown |
| 8 | Brown |

---

## T568B

Common in networks.

| Pin | Color |
|---|---|
| 1 | White Orange |
| 2 | Orange |
| 3 | White Green |
| 4 | Blue |
| 5 | White Blue |
| 6 | Green |
| 7 | White Brown |
| 8 | Brown |

---

# 17. Cable Types

## Straight-through Cable

Same wiring both ends:

```
T568B -------- T568B
```

Used:

- PC to Switch
- Router to Switch

---

## Crossover Cable

Different wiring:

```
T568A -------- T568B
```

Used historically:

- Switch to Switch
- Router to Router

---

# Auto-MDI/MDIX

Modern devices automatically detect cable type.

# CCNA Exam Traps

- Wireshark captures and analyzes packets.
- Capture filters reduce captured traffic.
- Display filters only filter displayed packets.
- Promiscuous mode captures more traffic.
- SPAN copies switch traffic to monitoring devices.
- Cable testers operate at Layer 1.
- T568B is commonly used for Ethernet cabling.
- Straight-through cables connect different device types.
- Crossover cables connect similar device types (legacy).
- Modern devices use Auto-MDI/MDIX.
