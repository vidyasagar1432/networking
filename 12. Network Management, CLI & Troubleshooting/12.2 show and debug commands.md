# 1. Overview

Cisco IOS provides two major troubleshooting tools: **show commands** and **debug commands**. `show` commands display the current state of a device and are safe for production use, while `debug` commands provide real-time troubleshooting information but can consume CPU resources and should be used carefully.

---

# 2. Show vs Debug

| Feature | Show Commands | Debug Commands |
|---|---|---|
| Purpose | View current status | Watch live events |
| Output | Snapshot | Real-time messages |
| Production safety | Safe | Can impact performance |
| Data | Current state | Process activity |
| Usage | Daily operations | Advanced troubleshooting |

Command:

```bash

```

Displays:

- Speed
- Input/output counters

---

# Important Output

Example:

```

```

```
+

```

---

# Show IP Interface Summary

Command:

```bash
show ip interface brief
```

Very common CCNA command.

Example:

```
Interface     IP          Status

Gi0/0       192.168.1.1   up

Gi0/1       unassigned    down
```

---

# Status Meanings

| Status | Meaning |
|---|---|
| up/up | Working |
| down/down | Physical problem |
| administratively down | Disabled |
| up/down | Layer 2 problem |

# 17. Filtering Show Output

Cisco IOS supports:

```
|
```

(pipe)

---

# Include

Example:

```bash
show running-config | include hostname
```

Shows only lines containing:

```
hostname
```

---

# Begin

Example:

```bash
show running-config | begin interface
```

Starts output at:

```
interface
```

---

# Section

Example:

```bash
show running-config | section router ospf
```

Shows OSPF configuration.

---

# 18. Troubleshooting Workflow

Use this order:

```
1. Check physical status

show interfaces


2. Check IP addressing

show ip interface brief


3. Check Layer 2

show vlan
show mac address-table


4. Check routing

show ip route


5. Test connectivity

ping
traceroute


6. Use debug if required
```

# Problem: Interface Not Working

Check:

```bash
show ip interface brief
```

If:

```

```

Fix:

```bash
interface g0/1
no shutdown
```

Check:

```bash
show ip route
```

Add:

```bash
ip route
```


# CCNA Exam Traps

- `show` commands are safe for production.
- `debug` commands can affect device performance.
- Always disable debugging after troubleshooting.
- `show ip interface brief` is one of the most important commands.
- `show running-config` displays active configuration.
- `show startup-config` displays saved configuration.
- Pipe (`|`) filters command output.
- `show ip route` verifies routing.
- `show mac address-table` verifies switch learning.
