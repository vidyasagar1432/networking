# SNMP

> **Level 26 · Monitoring & Telemetry** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SNMP** monitors and configures network devices over **UDP 161 (poll) / 162 (traps)**.
Data lives in the **MIB** and is addressed by **OIDs**; **v2c (community)** and **v3
(security)** are the versions that matter. The exam tests versions, the SNMP model, and
configuration.

---

## 2. Core Concepts

### 2.1 SNMP model

| Component | Role |
|-----------|------|
| Manager (NMS) | polls/collects |
| Agent | runs on device |
| MIB | data tree |
| OID | address of data |
| Community/security | access |

- **Manager polls the agent's MIB** via OIDs.

### 2.2 Operations

| Operation | Direction | Use |
|-----------|-----------|-----|
| GET | M→A | read one OID |
| GETNEXT | M→A | walk MIB |
| SET | M→A | change value |
| TRAP | A→M | alert |
| INFORM | A→M | acknowledged alert |

- **GET reads; SET writes; TRAP/INFORM push alerts.**

### 2.3 Versions

| Version | Security |
|---------|----------|
| v1 | community, clear |
| v2c | community, clear |
| v3 | auth + encryption |

- **v2c = community string (weak); v3 = secure (auth/priv).**

### 2.4 MIB/OID

| Item | Detail |
|------|--------|
| MIB | device database |
| OID | dotted address |
| Example | 1.3.6.1.2.1.1.1 (sysDescr) |
| Walk | GETNEXT through tree |

- The **OID** names a value in the MIB.

### 2.5 Configuration

```text
snmp-server community public RO
snmp-server community secret RW
snmp-server host 192.0.2.10 version 3 authpriv NMS
snmp-server group GRP v3 priv
snmp-server user admin GRP v3 auth sha Pass1 priv aes 128 Pass2
```

| Command | Meaning |
|---------|---------|
| `community` | v1/v2c access |
| `host` | trap destination |
| `group/user` | v3 security |

- **v3** needs user/group with auth+privacy.

### 2.6 v2c vs v3

| Aspect | v2c | v3 |
|--------|-----|----|
| Community | yes | no |
| Auth | none | SHA/MD5 |
| Encryption | none | AES/DES |
| Use | legacy/lab | production |

- **v3 for security; v2c is legacy.**

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No response | community | show snmp |
| No traps | host/port | show snmp host |
| v3 fail | auth | user/group |
| Timeout | UDP 161 | ACL |
| Wrong OID | MIB | snmpwalk |

---

## 5. Exam Traps

- SNMP = **UDP 161 poll / 162 traps**.
- **v2c = community (weak); v3 = auth+encryption**.
- GET/SET/TRAP/INFORM — know the verbs.
- Data via **MIB + OID**.
- `snmp-server community` and `host` are the config core.
