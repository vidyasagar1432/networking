# Syslog

> **Level 26 · Monitoring & Telemetry** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Syslog** sends device log messages to a central **syslog server (UDP 514)**. Entries
carry **facility + severity** (0–7) and timestamps. Only **one severity is stored on
device** (`logging buffered`); consoles can differ. The exam tests facilities, severities,
and the config commands.

---

## 2. Core Concepts

### 2.1 Syslog model

| Item | Detail |
|------|--------|
| Message | event/text |
| Facility | source of event |
| Severity | importance |
| Timestamp | time of event |
| Destinations | console/buffer/server |

- Message = **facility + severity + text**.

### 2.2 Severity levels

| Level | Keyword | Meaning |
|-------|---------|---------|
| 0 | emergencies | system down |
| 1 | alerts | immediate action |
| 2 | critical | critical cond |
| 3 | errors | error events |
| 4 | warnings | warning |
| 5 | notification | normal but notable |
| 6 | informational | normal info |
| 7 | debugging | debug output |

- **Lower number = more severe.**

### 2.3 Destinations

| Destination | Command |
|-------------|---------|
| Console | `logging console` |
| Buffer | `logging buffered` |
| Server | `logging host` |
| Trap/SNMP | via NMS |

- Configure **console, buffer, and server separately**.

### 2.4 Config examples

```text
logging host 192.0.2.10
logging trap informational
logging console errors
logging buffered 8192
logging source-interface Loopback0
logging timestamp datetime
```

| Command | Meaning |
|---------|---------|
| `logging host` | UDP server |
| `logging trap` | server level |
| `logging buffered` | on-box ring |
| `logging source-interface` | sender IP |

- **`logging trap` controls what goes to the server.**

### 2.5 Syslog vs SNMP traps

| Aspect | Syslog | SNMP trap |
|--------|--------|-----------|
| Format | text | structured |
| Port | 514 | 162 |
| Severity | numeric | OID |
| Use | logs | alerts |

- Syslog = **text logs**; SNMP = **structured alerts**.

## 3. Configuration / Commands

```text
logging host 192.0.2.10
logging trap informational
show logging
show logging | include 192
terminal monitor
```

| Command | Meaning |
|---------|---------|
| `show logging` | buffer/log |
| `terminal monitor` | see logs on session |
| `logging host` | destination |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No server logs | trap level | show logging |
| Buffer zero | buffered | config |
| Time wrong | timestamp | clock |
| No UDP | firewall | 514 |
| Console spam | level | level |

---

## 5. Exam Traps

- Severity numeric: **0 = most severe**.
- `logging trap` = **server level** (differs from console).
- Syslog default **UDP 514** (reliable option TCP 6514).
- **Buffered is on-box**, separate from server.
- Facility + severity identify the message.
