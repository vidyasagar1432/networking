# ERSPAN

> **Level 26 · Monitoring & Telemetry** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**ERSPAN** (Encapsulated Remote SPAN) mirrors traffic across a **routed/IP network** by
**encapsulating mirrored packets in IP/GRE** toward a destination on any reachable
subnet. It extends SPAN beyond a single switch. The exam stresses **GRE encapsulation**
and remote destinations.

---

## 2. Core Concepts

### 2.1 ERSPAN basics

| Item | Detail |
|------|--------|
| Source | local port/vlan |
| Destination | remote IP/GRE |
| Transport | IP + GRE |
| Scope | routed network |
| Use | remote analyzer |

- ERSPAN = **SPAN over IP/GRE**.

### 2.2 Encapsulation

| Field | Detail |
|-------|--------|
| Outer IP | router-to-router |
| GRE | tunnels to dest |
| Original | mirrored frame |
| Type | routable |

- The mirror is **tunneled to the analyzer**.

### 2.3 ERSPAN vs SPAN vs RSPAN

| Type | Scope |
|------|-------|
| SPAN | local |
| RSPAN | remote via vlan |
| ERSPAN | remote via IP/GRE |

- **ERSPAN = routed remote mirroring.**

### 2.4 Configuration

| Command | Meaning |
|---------|---------|
| `monitor session N type erspan-source` | source side |
| `... source interface Gi x/y` | what to mirror |
| `... destination` | remote config |
| `erspan id 100` | session key |
| `erspan ip-address ...` | destination IP |
| `erspan origin-ip ...` | sender IP |

- ERSPAN session = **source + GRE destination + id**.

### 2.5 Requirements

| Item | Detail |
|------|--------|
| IP route | both ends |
| GRE support | platforms |
| ACL | permit GRE |
| Overhead | +50 bytes |

- Both routers need **routes + GRE** and MTU headroom.

### 2.6 Caveats

| Caveat | Note |
|--------|------|
| MTU | raise or fragment |
| CPU | extra processing |
| Overload | plan rate |
| Only IP | no raw L2 |

- Design with **size and load** in mind.

## 3. Configuration / Commands

```text
monitor session 1 type erspan-source
 monitor session 1 source interface GigabitEthernet0/1 both
monitor session 1 destination
 erspan id 100
 erspan ip-address 192.0.2.10
 erspan origin-ip 198.51.100.1
show monitor session 1
```

| Command | Meaning |
|---------|---------|
| `type erspan-source` | kind |
| `erspan id` | session key |
| `erspan ip-address` | remote dest |
| `erspan origin-ip` | source IP |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Nothing received | route | ping dest |
| No mirror | origin IP | show monitor |
| Fragments | MTU | raise size |
| ACL drop | GRE | permit |
| Session mismatch | id | both sides |

---

## 5. Exam Traps

- ERSPAN = **mirror over IP/GRE (routed)**.
- Uses `type erspan-source/destination`.
- Needs **`erspan id` + `erspan ip-address`**.
- RSPAN = **L2 vlan remote**, ERSPAN = **L3 routed remote**.
- MTU+GRE overhead matters.
