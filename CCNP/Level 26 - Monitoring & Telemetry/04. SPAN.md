# SPAN

> **Level 26 · Monitoring & Telemetry** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SPAN (Switched Port Analyzer)** mirrors **traffic** from one or more source interfaces
to a destination port for analysis. It's local (same switch) and is **one-way**; vlan-level
mirroring is also possible. The exam tests the config and the **limits on destinations**.

---

## 2. Core Concepts

### 2.1 SPAN basics

| Item | Detail |
|------|--------|
| Source | interface/vlan |
| Destination | analyzer port |
| Direction | rx/tx/both |
| Scope | local switch |
| Use | capture/analyze |

- SPAN = **port mirroring on a single switch**.

### 2.2 Source directions

| Direction | Meaning |
|-----------|---------|
| rx | received traffic |
| tx | transmitted traffic |
| both | both directions |

- `monitor session 1 source ... rx/tx/both`.

### 2.3 Destination

| Item | Detail |
|------|--------|
| Port | analyzer/IDS |
| RSPAN | remote vlan |
| ERSPAN | routed/IP |
| Limits | one-ish per session |

- Destination is the **analyzer/IDS connection**.

### 2.4 Configuration

| Command | Meaning |
|---------|---------|
| `monitor session N source Gi x/y rx` | source |
| `monitor session N destination Gi a/b` | analyzer |
| `monitor session N vlan X` | vlan source |
| `no monitor session N` | remove |

- Build session = **source + destination**.

### 2.5 Limitations

| Limit | Detail |
|-------|--------|
| Local only | no routing |
| Resources | TCAM/session |
| Loops | danger on vlan |
| Overload | mirror all = loss |

- SPAN **does not route**; keep sources sane.

### 2.6 SPAN vs RSPAN vs ERSPAN

| Type | Scope |
|------|-------|
| SPAN | local same switch |
| RSPAN | remote via vlan |
| ERSPAN | remote via IP/GRE |

- **SPAN local; RSPAN/ERSPAN remote** (note 05).

## 3. Configuration / Commands

```text
monitor session 1 source interface GigabitEthernet0/1 both
monitor session 1 destination interface GigabitEthernet0/2
show monitor session 1
show monitor
```

| Command | Meaning |
|---------|---------|
| `source` | mirrored port |
| `destination` | analyzer port |
| `show monitor` | verify |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Empty capture | direction | rx/tx |
| Nothing at dest | session | show monitor |
| Traffic loss | overload | rate |
| Wrong vlan | scope | vlan source |
| Loop | mixing | STP watch |

---

## 5. Exam Traps

- SPAN = **local port mirroring**.
- Sessions: **source + destination**.
- Directive keywords: **rx / tx / both**.
- **SPAN ≠ RSPAN/ERSPAN** (remote needs separation).
- Destinations are **not routable** like a port.
