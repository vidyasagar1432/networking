# NetFlow

> **Level 26 · Monitoring & Telemetry** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**NetFlow** exports **flow records** (per-conversation metadata — not packets) to a
collector. Flows are **bidirectional** (forward + reverse direction) and identified by
the **7-tuple**. Versions matter: **v5 (fixed records)** and **v9 (templates)**. The exam
tests flow fields, versions, and basic config.

---

## 2. Core Concepts

### 2.1 What NetFlow exports

| Item | Detail |
|------|--------|
| Flow | conversation |
| Direction | forward + reverse |
| Fields | tuple + bytes |
| Collector | receiver |
| Export | UDP port |
| Sampling | optional |

- NetFlow = **metadata, not full packets**.

### 2.2 The 7-tuple

| Field | Meaning |
|-------|---------|
| Src IP | source |
| Dst IP | destination |
| Src port | layer 4 |
| Dst port | layer 4 |
| Protocol | IP proto |
| TOS | class |
| Interface | in/out |

- These identify and **tag a flow**.

### 2.3 Versions

| Version | Format |
|---------|--------|
| v1 | fixed fields |
| v5 | fixed, most famous |
| v9 | template-based (flexible) |
| IPFIX | template-based (standard) |

- **v5 fixed; v9/IPFIX template-based.**

### 2.4 Flow direction

| Direction | Meaning |
|-----------|---------|
| Forward | initiator → responder |
| Reverse | responder → initiator |
| Biflow | both in one record |

- The router **caches both directions**.
- Good agility: **v9 sends rich, extensible records**.

### 2.5 Export

| Item | Detail |
|------|--------|
| Port | UDP 2055 common |
| Collectors | NMS |
| Aggregation | on collector |
| Cache | on device |

- The device caches flows and **exports to a collector**.

### 2.6 The exam focus

| Topic | Know |
|-------|------|
| Fields | 7-tuple |
| Versions | v5/v9/IPFIX |
| Direction | biflow |
| Export | collector |
| Use | analysis |

- **v5 vs v9 = fixed vs templates** is the classic trap.

## 3. Configuration / Commands

```text
flow record FR1
 match ipv4 source address
 match ipv4 destination address
 match transport source-port
 match transport destination-port
 match ip protocol
 collect counter bytes
 collect counter packets
flow exporter EXP1
 destination 192.0.2.10
 transport udp 2055
flow monitor FM1
 record FR1
 exporter EXP1
 cache timeout active 300
interface GigabitEthernet0/1
 ip flow monitor FM1 input
```

| Command | Meaning |
|---------|---------|
| `flow record` | define fields |
| `flow exporter` | collector |
| `flow monitor` | bind record+exporter |
| `ip flow monitor` | apply to interface |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No flows | record | show flow monitor |
| No export | collector | show flow exporter |
| UDP blocked | ACL/firewall | port 2055 |
| Wrong fields | record | match commands |
| Direction | interface | input/output |

- Export usually **UDP 2055**.
- NetFlow = **metadata, not packets**.
