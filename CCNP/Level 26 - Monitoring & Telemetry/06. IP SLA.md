# IP SLA

> **Level 26 · Monitoring & Telemetry** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**IP SLA** generates **synthetic probes** between routers to measure **latency, jitter,
loss, and availability** along a path. Results can **react** (track) for routing or
config decisions, and are reported via **SNMP/syslog**. It's the classic **SLA testing**
tool on Cisco devices.

---

## 2. Core Concepts

### 2.1 What IP SLA measures

| Metric | Meaning |
|--------|---------|
| Latency | RTT time |
| Jitter | delay variation |
| Loss | packet loss % |
| Availability | reachability |
| MOS | voice quality |

- Probes generate **real, measurable traffic**.

### 2.2 Operation types

| Type | Use |
|------|-----|
| ICMP echo | reachability |
| UDP jitter | voice quality |
| TCP connect | app checks |
| HTTP | web availability |
| UDP echo | protocol |

- Pick the **probe type** that matches what you monitor.

### 2.3 Schedule + tracking

| Part | Detail |
|------|--------|
| Create | probe config |
| Schedule | frequency/start |
| Track | reacts to state |
| Reaction | thresholds/events |

- Schedule runs it; **track** ties it to routing/reactions.
- The router sends probes at **set intervals**.

### 2.4 Configuration

| Command | Meaning |
|---------|---------|
| `ip sla 10` | create operation |
| `icmp-echo 192.0.2.5` | type/target |
| `frequency 60` | every 60 s |
| `timeout 1000` | wait |
| `ip sla schedule 10 life forever start-time now` | run |
| `track 1 ip sla 10 reachability` | track |

- Build = create → define → schedule → track.

### 2.5 Integration

| Feature | Use |
|---------|-----|
| Route tracking | adjust routing |
| EEM | events |
| SNMP | report |
| Syslog | logs |

- IP SLA feeds **tracking and monitoring systems**.

### 2.6 ICP vs ICMP

| Aspect | IP SLA | plain ping |
|--------|--------|------------|
| Metrics | jitter/loss/MOS | reachability |
| Schedule | repeat | manual |
| Integration | track/SNMP | none |
| Use | SLA stats | quick check |

- **IP SLA beats ping** for real SLA numbers.

## 5. Exam Traps

- IP SLA = **synthetic probes** (not passive).
- Common metric focus: **latency, jitter, loss**.
- `ip sla` + `frequency` + `schedule` is the config pattern.
- **Track** links results to routing reactions.
- UDP jitter = **voice quality (MOS)**.
