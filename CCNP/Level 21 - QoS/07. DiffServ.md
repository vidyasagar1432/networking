# DiffServ (Differentiated Services)

> **Level 21 · QoS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**DiffServ** is the QoS architecture where each packet **carries its own class** in the
**DSCP field** and each router applies **per-hop behavior (PHB)**. No signaling, no
reservations — scalable, and the de-facto model for enterprise/SP QoS. The exam tests
the **PHBs** (EF, AF, CS) and how DSCP maps to them.

---

## 2. Core Concepts

### 2.1 DiffServ vs IntServ

| Aspect | DiffServ | IntServ |
|--------|----------|---------|
| Model | per-class | per-flow |
| Signaling | none | RSVP |
| Scale | excellent | poor |
| Guarantee | statistical | hard |

- DiffServ = **classification at edge, trust in core**; IntServ = RSVP reservations (note 08).

### 2.2 DSCP and PHB

| Field | Bits | Purpose |
|-------|------|---------|
| DSCP | 6 | packet class |
| ECN | 2 | congestion marks |
| PHB | — | treatment per class |

- DSCP selects the **PHB** each router applies.

### 2.3 The PHB classes

| PHB | DSCP | Use |
|-----|------|-----|
| EF | 46 | voice (low latency) |
| AF4x | 34/36/38 | video conf |
| AF3x | 26/28/30 | video stream |
| AF2x | 18/20/22 | signaling/OAM |
| AF1x | 10/12/14 | bulk |
| CSx | 0–56 | class selector / control |
| BE | 0 | default |

- **AF** classes have three drop precedences (x1 low, x2 medium, x3 high drop).

### 2.4 AF drop precedence

| Code | Drop | Example |
|------|------|---------|
| AF21 | low | signaling |
| AF22 | medium | data |
| AF23 | high | bulk |

- Within an AF class, **lower number = lower drop probability**.

### 2.5 DiffServ in the network

| Zone | Action |
|------|--------|
| Edge | classify + mark |
| Core | trust + PHB (queue/WRED) |
| Provider | honor DSCP / contract |

- Edge marks once; core **applies PHBs consistently** (CBWFQ/WRED).

### 2.6 Example policy

```text
policy-map DIFFSERV
 class VOICE      ! EF
  priority 128
 class VIDEO      ! AF41
  bandwidth 1000
  random-detect dscp-based
 class DATA
  bandwidth 2000
```

- EF → **LLQ**; AF → **bandwidth + WRED**; BE → best effort.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| PHB not applied | no service-policy | policy-map |
| Wrong class | DSCP mismatch | class-map |
| Marking lost | untrusted edge | set dscp |
| AF drops all | drop precedence | random-detect |
| Voice degraded | not EF/LLQ | priority |

---

## 5. Exam Traps

- DiffServ = **DSCP + PHB**, no signaling.
- **EF (46) = voice**, AF = assured forwarding (3 drop levels), CS = class selector.
- Core **trusts** DSCP; edge marks.
- DiffServ is **statistical**; IntServ is **per-flow guaranteed**.
- AF lower drop-number = better survival.
