# Congestion Avoidance

> **Level 21 · QoS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Congestion avoidance** drops packets **before** a queue overflows to prevent
**tail-drop** and the resulting **TCP global synchronization**. The tool is **WRED**
(Weighted Random Early Detection) — it randomly drops lower-priority traffic as the
queue fills, protecting high-priority flows and smoothing TCP behavior.

---

## 2. Core Concepts

### 2.1 Tail drop problem

| Issue | Effect |
|-------|--------|
| Tail drop | last packets dropped |
| Sync | TCP windows collapse together |
| Voice | burst loss |
| Retransmit | efficiency loss |

- Dropping at the tail hurts **voice** and causes **synchronized TCP** slow-downs.

### 2.2 RED/WRED idea

| Stage | Threshold | Action |
|-------|-----------|--------|
| Below min | normal | no drop |
| min → max | grow | random drop rate ↑ |
| Above max | full | drop all |

- WRED drops **randomly with rising probability** as depth grows.

### 2.3 Weighted = per-class

| Class | Drop profile |
|-------|--------------|
| Voice (EF) | no drop / highest min |
| Video (AF) | moderate |
| Best effort | aggressive |

- **WRED** weights each class differently — premium traffic drops last.

### 2.4 WRED config

```text
policy-map AVOID
 class AF31
  bandwidth 1000
  random-detect dscp-based
!
interface Gi0/1
 service-policy output AVOID
```

| Command | Meaning |
|---------|---------|
| `random-detect` | enable WRED |
| `random-detect dscp` | by DSCP |
| `random-detect precedence` | by precedence |
| `min/max threshold` | drop curve |

### 2.5 ECN

| Item | Detail |
|------|--------|
| What | mark instead of drop |
| Bits | ECT/CE |
| Partner | WRED + ECN |
| Result | TCP backs off |

- **ECN** marks packets (instead of dropping) when WRED would drop — TCP-friendly.

### 2.6 Where to apply

| Device | Reason |
|--------|--------|
| Egress WAN | protect voice/video |
| Core queues | avoid sync |
| Edge | drop profiles |

- Apply WRED where **congestion is real** (WAN egress).

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Tail drop still | WRED not applied | random-detect |
| Voice drops | drop profile | thresholds |
| Sync persists | all same profile | weighting |
| No random drop | queue short | thresholds |
| WRED off | not in policy | policy-map |

## 5. Exam Traps

- **Tail drop → TCP global sync** — WRED fixes both.
- WRED = **weighted random early detection** (per-class).
- Thresholds: **min → max → full**.
- **ECN marks instead of drops** (TCP friendly).
- Applies at **congested egress**.
