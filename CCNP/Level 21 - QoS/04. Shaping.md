# Shaping

> **Level 21 · QoS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Shaping** smooths traffic to a rate by **buffering excess** instead of dropping it.
It works **egress-only** and adds delay — ideal for aligning to a subscribed line rate
or a downstream policer without wasting packets. The exam contrasts it with policing
constantly.

---

## 2. Core Concepts

### 2.1 Shaping model

| Item | Meaning |
|------|---------|
| CIR | shaped rate |
| Bc | committed burst |
| Be | excess burst |
| Queue | buffers the excess |
| Delay | added latency |

- Excess waits in the **shaping queue**, then goes out.

### 2.2 Shaping vs policing

| Aspect | Shaping | Policing |
|--------|---------|----------|
| Excess | buffer | drop/re-mark |
| Delay | adds | none |
| Location | egress | in/egress |
| Rate | smooth | meter |
| Loss | low | high |

- **Shaping for the access rate; policing for enforcement.**

### 2.3 Why shape

| Reason | Detail |
|--------|--------|
| Access line | align to CIR |
| Avoid drops | don't exceed policer |
| Fairness | smooth bursts |
| Downstream | don't flood |

- Shaping protects against **bursty transmission** hitting a stricter link.

### 2.4 Shape config

```text
policy-map SHAPE-LINK
 class class-default
  shape average 10000000
!
interface Gi0/1
 service-policy output SHAPE-LINK
```

| Command | Meaning |
|---------|---------|
| `shape average` | token bucket (Bc/Be) |
| `shape peak` | allow Be use |
| `service-policy output` | egress |

- `shape average` is the standard; `shape peak` permits extra burst.

### 2.5 Hierarchical shaping

| Level | Policy |
|-------|--------|
| parent | total rate (e.g., 10 Mbps) |
| child | per-class sub-rates |
| result | class buckets within the link |

- Parent shapes the **aggregate**; children carve per-class shares.

```text
show interface Gi0/1
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Too much delay | queue buildup | queueing |
| No shaping | not attached | policy-map interface |
| Bursts leak | Bc/Be small | bc |
| Children idle | hierarchy | parent/child |
| Rate wrong | CIR | shape average |

---

## 5. Exam Traps

- Shaping = **buffer**; policing = **drop**.
- **Egress-only**, adds delay.
- `shape average` vs `shape peak`.
- **Hierarchical** shaping = parent + child policies.
- For access-rate smoothing, shape — not police.
