# Marking

> **Level 21 · QoS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Marking** writes a QoS value into the packet/frame so downstream devices can treat it
consistently. Markers exist at Layer 2 (**802.1p CoS**), Layer 3 (**IP precedence**,
**DSCP**), and even MPLS (**EXP**). Marking is **trusted across the network** — so the
core doesn't re-classify, just reads the DSCP.

---

## 2. Core Concepts

### 2.1 Marking locations

| Layer | Field | Bits |
|-------|-------|------|
| L2 | 802.1p CoS | 3 |
| L3 | IP precedence | 3 |
| L3 | DSCP | 6 |
| MPLS | EXP | 3 |

- **DSCP (6 bits)** is the modern standard; CoS is LAN-only.

### 2.2 DSCP vs precedence

| Item | IP precedence | DSCP |
|------|---------------|------|
| Bits | 3 | 6 |
| Classes | 8 | 64 |
| Default | CS0 | BE |
| Modern | legacy | preferred |

- DSCP includes the precedence as **CSx** (class selector).

### 2.3 Common DSCP values

| DSCP | Name | Use |
|------|------|-----|
| EF | Expedited Forwarding | voice |
| AF41 | 34 | video conf |
| AF31 | 26 | video stream |
| AF21 | 18 | bulk/signaling |
| CS0 | 0 | best effort |
| CS6/CS7 | 48/56 | control |

- **EF = voice**, AF4x = video conf, AF3x = video stream, AF2x = OAM/signaling, CS6 = routing.

### 2.4 Marking config

```text
policy-map MARK-VOICE
 class VOICE
  set dscp ef
!
class-map match-all VIDEO
 match dscp af41
policy-map MARK-VIDEO
 class VIDEO
  set dscp af41
```

| Command | Effect |
|---------|--------|
| `set dscp` | write DSCP |
| `set precedence` | write precedence |
| `set cos` | write CoS |

### 2.5 Trusting markings

| Device | Action |
|--------|--------|
| Edge | set/re-mark |
| Core | trust (no re-mark) |
| CoS→DSCP | LAN mapping |

- CoS and DSCP need **mapping tables** when crossing L2/L3.

### 2.6 Classification/marking pairing

- **Classify → mark** at the edge; core does **trust + queue by DSCP**.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No marking | policy not attached | service-policy |
| Wrong value | set statement | policy-map |
| Trust broken | re-mark in core | mls qos |
| CoS lost | L2/L3 boundary | mapping |
| EF dropped | over-subscribed | queue |

---

## 5. Exam Traps

- Marking **writes**; classification **reads**.
- **DSCP (6 bits)** = 64 values; precedence = 3 bits.
- **EF = voice**, AF4x/3x = video, CS6 = control.
- Set DSCP at the **edge**; trust in the core.
- `set dscp` / `set cos` / `set precedence`.
