# Private Cloud

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **private cloud** is cloud-like infrastructure (self-service, elastic, metered) that
runs on **dedicated, on-premises** resources — e.g., **VMware/OpenStack** under your
control. It keeps data and compliance in-house but adds **capex and operational cost**.
The exam contrasts private vs public and when to pick each.

---

## 2. Core Concepts

### 2.1 Definition

| Item | Detail |
|------|--------|
| Owner | your org |
| Location | on-prem / dedicated |
| Tenancy | dedicated |
| Control | full |

- Private cloud = **cloud model on your own hardware**.

### 2.2 Cloud features locally

| Feature | Local equivalent |
|---------|------------------|
| Self-service | portal |
| Elasticity | hypervisor pools |
| Metering | usage |
| Orchestration | vRealize/OpenStack |

- It's about **cloud-style operations**, not location alone.

### 2.3 Platforms

| Platform | Type |
|----------|------|
| VMware vSphere | most common |
| OpenStack | open-source |
| Nutanix | hyperconverged |
| Azure Stack | hybrid |

- **VMware + OpenStack** are the classic private-cloud stacks.

### 2.4 Private vs public

| Aspect | Private | Public |
|--------|---------|--------|
| Cost | capex | opex |
| Control | full | limited |
| Compliance | easier | shared |
| Scale | limited | elastic |

- **Private = control/compliance; public = scale/cost.**

### 2.5 When private wins

| Use | Reason |
|-----|--------|
| Regulated data | compliance |
| Latency | local |
| Legacy | integration |
| Cost control | steady load |

- Sensitive/steady workloads stay **on-prem**.

### 2.6 Networking in private cloud

| Item | Detail |
|------|--------|
| Virtual switches | vSwitch |
| VLANs | segmentation |
| NSX | SDN overlay |
| East-west | internal |

- Private cloud networks use **vSwitch + VLAN or NSX overlays**.

## 5. Exam Traps

- Private cloud = **dedicated + on-prem + full control**.
- Platforms: **VMware, OpenStack, Azure Stack**.
- Cost = **capex**; public = opex.
- Wins on **compliance/latency**; public wins on scale.
- Networking via **vSwitch/VLAN or NSX**.
