# Hypervisors

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **hypervisor** (VMM) is the software layer that creates and runs VMs by abstracting
hardware. **Type 1 (bare-metal)** runs directly on hardware — the datacenter standard
(ESXi, Hyper-V, KVM). **Type 2 (hosted)** runs on an OS (VirtualBox, Workstation). The
exam contrasts the types and their roles.

---

## 2. Core Concepts

### 2.1 Hypervisor types

| Type | Runs on | Examples |
|------|---------|----------|
| Type 1 | bare metal | ESXi, Hyper-V, KVM |
| Type 2 | host OS | VirtualBox, Workstation |

- **Type 1 = no host OS; Type 2 = on top of an OS.**

### 2.2 Type 1 (bare-metal)

| Item | Detail |
|------|--------|
| Performance | near-native |
| Overhead | minimal |
| Use | datacenter/cloud |
| Security | smaller surface |

- **ESXi/KVM power the clouds** — direct hardware access.

### 2.3 Type 2 (hosted)

| Item | Detail |
|------|--------|
| Performance | lower |
| Use | desktop/lab |
| Install | simple |
| Dependence | host OS |

- Type 2 is fine for **testing and labs**.

### 2.4 What the hypervisor does

| Task | Detail |
|------|--------|
| CPU | schedule vCPUs |
| Memory | allocate |
| I/O | emulate/passthrough |
| Isolation | between VMs |
| Management | lifecycle |

- The hypervisor **schedules and isolates** workloads.

### 2.5 Virtualization models

| Model | Detail |
|-------|--------|
| Full | emulate hardware |
| Paravirtual | guest-aware |
| Hardware-assisted | CPU VT-x |

- Modern hypervisors use **hardware-assisted** virtualization.

### 2.6 Management

| Tool | Role |
|------|------|
| vCenter | ESXi cluster mgmt |
| Libvirt | KVM |
| SCVMM | Hyper-V |
| Cloud | orchestrated |

- Hypervisors are managed by **central tools/cloud APIs**.

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| VM won't start | resources | capacity |
| Slow I/O | storage | datastore |
| No vNIC | virtual switch | network |
| Overcommit | memory | host |
| Migration fail | cluster | vCenter |

---

## 5. Exam Traps

- **Type 1 = bare-metal (ESXi/KVM); Type 2 = hosted (VirtualBox)**.
- Type 1 = **datacenter/cloud** standard.
- Hypervisor = CPU/memory/I/O **scheduling + isolation**.
- Hardware-assisted virtualization is the norm.
- Virtual switches connect **vNICs**.
