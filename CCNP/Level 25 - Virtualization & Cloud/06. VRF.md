# VRF (Virtual Routing and Forwarding)

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**VRF** creates **multiple isolated routing tables on one router** — each with its own
RIB, CEF, interfaces, and routing protocol. It's the core of **L3VPN segmentation**
(Level 20 note 07) and of **VRF-lite** for simple, MPLS-free isolation. In the cloud
context, VRFs mirror **virtual networks** per tenant.

---

## 2. Core Concepts

### 2.1 What a VRF isolates

| Table | Per-VRF |
|-------|---------|
| RIB | routes |
| CEF/FIB | forwarding |
| Interfaces | membership |
| Protocol | per-VRF process |

- **RIB + FIB + interfaces** are fully isolated.

### 2.2 Use cases

| Use | Detail |
|------|--------|
| L3VPN | MPLS + MP-BGP |
| VRF-lite | no MPLS needed |
| Multi-tenant | per customer |
| Management | OOB VRF |

- VRF powers **VPNs** (Level 20) and **VRF-lite** (note 07).

### 2.3 RD and RT

| Item | Function |
|------|----------|
| RD | uniqueness (MP-BGP) |
| RT | membership/policy |
| Lite | RTs optional |

- **RD = identity; RT = who shares** — needed for MPLS VPNs.

### 2.4 Config

```text
ip vrf CUST1
 rd 65000:100
!
interface Gi0/1
 ip vrf forwarding CUST1
 ip address 10.0.0.1 255.255.255.0
!
router bgp 65000
 address-family ipv4 vrf CUST1
```

| Command | Meaning |
|---------|---------|
| `ip vrf` | create |
| `rd` | distinguisher |
| `ip vrf forwarding` | bind interface |
| `address-family ipv4 vrf` | per-VRF BGP |

- **`ip vrf forwarding` clears the IP address** — reapply it.

### 2.5 VRF in the cloud

| Concept | Cloud equivalent |
|---------|------------------|
| VRF | VPC/tenant network |
| Isolation | per-tenant tables |
| Routing | per-network |

- Clouds use **similar isolation** — VPCs are the "VRF" of the cloud.

### 2.6 Verification

```text
show ip vrf
show ip route vrf CUST1
show ip cef vrf CUST1
ping vrf CUST1 10.0.0.2
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No routes | protocol | show ip route vrf |
| Interface missing | binding | show ip vrf |
| Overlap | RD | rd |
| Wrong sharing | RT | route-target |
| Ping fail | wrong VRF | ping vrf |

---

## 5. Exam Traps

- VRF = **separate RIB/FIB/interfaces**.
- **RD = identity; RT = membership** (for MPLS).
- `ip vrf forwarding` removes the IP.
- VRF-lite = **isolation without MPLS** (note 07).
- Cloud VPC ≈ the VRF concept.
