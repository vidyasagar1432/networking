# Virtual Machines

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **VM** is a software-emulated computer: a full guest OS running on **virtualized
hardware** (vCPU, vRAM, vNIC, vDisk) atop a **hypervisor**. VMs give **isolation** and
**workload mobility** at the cost of resource overhead. For network engineers, VMs are
the unit of **virtual appliances** (routers, WLCs, firewalls) and the cloud.

---

## 2. Core Concepts

### 2.1 What makes a VM

| Component | Detail |
|-----------|--------|
| vCPU | virtual cores |
| vRAM | allocated memory |
| vNIC | virtual NIC |
| vDisk | virtual disk |
| Guest OS | full OS |
| Hypervisor | host layer |

- A VM = **guest OS + virtualized hardware**.

### 2.2 Full isolation

| Aspect | Detail |
|--------|--------|
| Kernel | separate per VM |
| Apps | isolated |
| Crash | contained |
| Security | strong boundary |

- VMs are **hard-isolated** — a crash stays in the VM.

### 2.3 VM vs container

| Aspect | VM | Container |
|--------|----|-----------|
| Kernel | own | shared |
| Overhead | high | low |
| Isolation | strong | lighter |
| Boot | minutes | seconds |

- **VM = full kernel; container = shared kernel** (note 03).

### 2.4 Virtual appliances

| Appliance | Role |
|-----------|------|
| CSR1000v | router |
| vWLC | wireless controller |
| ASAv | firewall |
| vManage/vSmart | SD-WAN |

- Network functions ship as **VMs** — same config as hardware.

### 2.5 Migration

| Feature | Detail |
|---------|--------|
| Snapshot | save state |
| Clone | copy |
| Migrate | move live |
| Export | OVF/OVA |

- **Snapshots + migration** = agility and DR.

### 2.6 Trade-offs

| Cost | Reason |
|------|--------|
| Resource | kernel duplication |
| Boot | slower |
| Density | lower |
| Isolation | bonus |

- VMs trade **density for isolation** vs containers.

## 5. Exam Traps

- VM = **full guest OS on virtual hardware**.
- **VM = own kernel; container = shared**.
- Virtual appliances = **CSR1000v, vWLC, ASAv**.
- Strong isolation, higher overhead.
- Snapshots/migration give agility.
