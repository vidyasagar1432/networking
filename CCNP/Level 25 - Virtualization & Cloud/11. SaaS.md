# SaaS

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SaaS** delivers **complete applications over the internet** — no install, no server
management; the provider runs everything (e.g., **Office 365, Salesforce, Webex**).
The customer manages only **users and data**. The exam contrasts the three service
models (IaaS/PaaS/SaaS) and their **division of responsibility**.

---

## 2. Core Concepts

### 2.1 What SaaS is

| Item | Detail |
|------|--------|
| Deliverable | full app |
| Access | browser/client |
| Provider runs | infra + app |
| Customer | users + data |

- SaaS = **rent the application**.

### 2.2 Examples

| Service | Use |
|---------|-----|
| Office 365 | email/office |
| Salesforce | CRM |
| Webex | collaboration |
| ServiceNow | IT service mgmt |

- Enterprise SaaS = **hosted business apps**.

### 2.3 Responsibility split

| Layer | Provider | Customer |
|-------|----------|----------|
| App | yes | no |
| Middleware | yes | no |
| OS/host | yes | no |
| Data/access | no | yes |

- Customer manages **users and data**, little else.

### 2.4 SaaS vs PaaS vs IaaS

| Model | You manage |
|-------|-----------|
| IaaS | OS + app + data |
| PaaS | app + data |
| SaaS | data + users only |

- **Least control = SaaS; most = IaaS** (notes 12/13).

### 2.5 Networking angle

| Item | Detail |
|------|--------|
| Access | internet/TLS |
| Bandwidth | matters |
| QoS | priority for apps |
| Security | identity + DLP |

- Network teams **protect + prioritize** SaaS traffic.

### 2.6 Pros/cons

| Pro | Con |
|-----|-----|
| Zero maintenance | less control |
| Fast rollout | lock-in |
| Predictable | compliance |
| Mobile ready | internet-dependent |

- SaaS trades **control for convenience**.
