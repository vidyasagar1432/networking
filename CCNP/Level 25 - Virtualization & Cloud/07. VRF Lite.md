# VRF Lite

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**VRF-lite** uses **VRFs without MPLS/MP-BGP**: separate routing tables and interfaces
provide L3 segmentation on a single router — **cheap and simple**, ideal for small
multi-tenant or service-separation designs. The trade-off: **no VPN label/MP-BGP
scalability** — each hop must carry the same VRFs.

---

## 2. Core Concepts

### 2.1 VRF-lite vs L3VPN

| Aspect | VRF-lite | MPLS L3VPN |
|--------|----------|------------|
| MPLS | no | yes |
| MP-BGP | no | yes |
| Labels | none | two-label |
| Scale | small | large |
| Scope | single site | WAN-wide |

- **VRF-lite = isolation without MPLS** — point-to-point of VRFs between routers.

### 2.2 How it works

| Element | Detail |
|---------|--------|
| VRF per tenant | on each router |
| Interfaces | bound per VRF |
| Routing | per-VRF IGP/static |
| Links | same VRF both ends |

- Every router on the path needs the **same VRF mapped to the same links**.

### 2.3 Use cases

| Use | Reason |
|-----|--------|
| Small sites | cheap isolation |
| Guest/mgmt | separate tables |
| Lab | quick segmentation |
| Enterprise core | simplified |

- VRF-lite suits **single-site segmentation** without an SP.

### 2.4 Config

```text
ip vrf GUEST
 rd 65000:10
!
interface Gi0/0
 ip vrf forwarding GUEST
 ip address 10.0.0.1 255.255.255.0
!
router bgp 65000
 address-family ipv4 vrf GUEST
```

| Command | Meaning |
|---------|---------|
| `ip vrf` | create |
| `ip vrf forwarding` | bind |
| `address-family ipv4 vrf` | per-VRF BGP |
| `rd` | optional locally |

### 2.5 Limitations

| Limit | Detail |
|-------|--------|
| Scale | manual per hop |
| Overlap | RD/RT not global |
| WAN | no MPLS transit |
| Complexity | per-device |

- Beyond a few devices, **MPLS VPNs scale better**.

### 2.6 Verification

```text
show ip vrf
show ip route vrf GUEST
show ip cef vrf GUEST
ping vrf GUEST ...
```

| No routes | link not in VRF | show ip vrf |
| Overlap | both ends | mapping |
| Leak | interface | binding |
| No ping | wrong VRF | ping vrf |

---

## 5. Exam Traps

- VRF-lite = **VRFs without MPLS/MP-BGP**.
- Every hop must **map the same VRFs** to links.
- Great for **single-site isolation**; not for large WAN.
- No label stack — **scale limit**.
- L3VPN = the scalable upgrade path.
