# Public Cloud

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **public cloud** is shared, on-demand infrastructure run by a provider (**AWS, Azure,
GCP**) and delivered as **IaaS/PaaS/SaaS**. You rent capacity, get **elasticity** and
**capex-to-opex** conversion. Networking: **VPC/VNet** isolation, virtual networks,
NAT/load balancers, and **connectivity back to the campus via VPN/Direct Connect**.

---

## 2. Core Concepts

### 2.1 Definition

| Item | Detail |
|------|--------|
| Owner | provider |
| Access | internet/shared |
| Model | pay-as-you-go |
| Tenancy | multi-tenant |

- Public cloud = **shared, metered, elastic** compute.

### 2.2 Cloud services (notes 11–13)

| Service | Example |
|---------|---------|
| IaaS | EC2/VMs |
| PaaS | managed DB |
| SaaS | Office 365 |

- Public clouds offer **all three service models**.

### 2.3 Networking model

| Item | Detail |
|------|--------|
| VPC/VNet | isolated space |
| Subnets | segmentation |
| Security groups | L3/L4 rules |
| LB | load balancing |
| NAT GW | outbound |

- **VPC = the cloud's "VRF"** — isolated per tenant.

### 2.4 Connectivity options

| Method | Detail |
|--------|--------|
| Internet VPN | IPsec |
| Direct Connect | private link |
| Cloud VPN | managed |
| SD-WAN | overlay |

- Hybrid/backup connectivity uses **VPN or direct links**.

### 2.5 Public vs private

| Aspect | Public | Private |
|--------|--------|---------|
| Tenancy | shared | dedicated |
| Control | provider | you |
| Location | provider DC | on-prem |
| Cost | opex | capex |

- **Public = shared+provider-managed; private = dedicated+on-prem** (note 09).

### 2.6 Benefits/trade-offs

| Pro | Con |
|-----|-----|
| Elastic | shared |
| Global | cost mgmt |
| Fast | compliance |
| Managed | lock-in |

- Public cloud wins on **agility and scale**; watch data/compliance.

## 5. Exam Traps

- Public cloud = **shared, elastic, pay-as-you-go**.
- **VPC/VNet = isolation**; security groups = filters.
- Connectivity: **VPN/Direct Connect** back to campus.
- IaaS/PaaS/SaaS are the service models.
- vs private: **shared + provider-owned**.
