# Containers

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Containers** package an app + its dependencies to run **isolated but kernel-shared**
workloads — no guest OS, no hypervisor overhead. They boot in **seconds** and scale
easily. For network, containers run **containerized NFs** (e.g., IOS-XE on Catalyst
8000v in models), and the exam stresses VM vs container differences.

---

## 2. Core Concepts

### 2.1 How containers work

| Layer | Detail |
|-------|--------|
| Kernel | shared host |
| Namespaces | isolation |
| cgroups | resources |
| Image | app + deps |
| Runtime | Docker/containerd |

- **Namespaces isolate; cgroups limit** — no separate kernel.

### 2.2 Container vs VM

| Aspect | Container | VM |
|--------|-----------|----|
| Kernel | shared | own |
| Boot | seconds | minutes |
| Overhead | low | high |
| Isolation | lighter | strong |
| Density | high | low |

- **Containers trade isolation for density and speed.**

### 2.3 Components

| Item | Detail |
|------|--------|
| Image | read-only template |
| Container | running image |
| Registry | image store |
| Orchestrator | K8s (note 05) |

- Image → container; registry shares images.

### 2.4 Benefits

| Benefit | Detail |
|---------|--------|
| Portable | same everywhere |
| Light | fast startup |
| Scale | replicate easily |
| CI/CD | natural fit |

- Containers = **portable, repeatable packaging**.

### 2.5 Networking model

| Model | Detail |
|-------|--------|
| Bridge | NAT default |
| Host | share host net |
| Overlay | multi-node mesh |
| CNI | plugin standard |

- **CNI** (container network interface) connects containers to networks.

### 2.6 Container NFs

| NF | Detail |
|----|--------|
| IOS-XE | containerized router |
| Cloud services | microservices |
| vAppliance | many vendors |

- Network functions increasingly ship as **containers**.

## 5. Exam Traps

- Container = **shared kernel + namespaces/cgroups**.
- **vs VM: light/fast/low-isolation vs heavy/slow/strong**.
- Image + runtime + registry model.
- **CNI** = container networking standard.
- Containerized **network functions** are modern ION.
