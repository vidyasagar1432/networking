# IaaS

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**IaaS** delivers **raw compute, storage, and networking** as a service — you rent **VMs
and virtual networks** and manage the **OS, apps, and data** yourself (AWS EC2, Azure
VMs, GCP Compute). It's the **most control** of the three service models and closest to
classic infrastructure. The exam stresses the responsibility split.

---

## 2. Core Concepts

### 2.1 What IaaS is

| Item | Detail |
|------|--------|
| Deliverable | compute/storage/net |
| Provider | hosts + hypervisor |
| Customer | OS + app + data |
| Access | VMs/networks |

- IaaS = **rent raw infrastructure**.

### 2.2 Examples

| Service | Use |
|---------|-----|
| EC2 | VMs |
| Azure VM | compute |
| VPC/VNet | networks |
| S3/Blob | storage |

- **VMs + virtual networks + storage** = IaaS.

### 2.3 Responsibility split

| Layer | Provider | Customer |
|-------|----------|----------|
| Hardware | yes | no |
| Hypervisor | yes | no |
| OS | no | yes |
| App + data | no | yes |

- You manage **OS, apps, data, and networking** above the hypervisor.

### 2.4 IaaS vs PaaS vs SaaS

| Model | You manage |
|-------|-----------|
| IaaS | OS + app + data |
| PaaS | app + data |
| SaaS | data + users |

- **Most control = IaaS; least = SaaS.**

### 2.5 Networking in IaaS

| Item | Detail |
|------|--------|
| VPC/VNet | isolation |
| Subnets | segmentation |
| Security groups | filters |
| LB/NAT | services |
| VPN/Direct | connect |

- Network engineers see IaaS as **virtual networking to design**.

### 2.6 Pros/cons

| Pro | Con |
|-----|-----|
| Full control | you manage OS |
| Familiar | patching burden |
| Elastic | cost discipline |
| Migration | lift-and-shift |

- IaaS = **lift-and-shift** friendly, but **more to operate**.

- IaaS = **raw infra; you manage OS + app + data**.
- Examples: EC2, Azure VMs, VPC, S3.
- **Most control of the three models**.
- Virtual networking = **VPC/subnet/security groups**.
- Lift-and-shift targets IaaS.
