# Hybrid Cloud

> **Level 25 · Virtualization & Cloud** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **hybrid cloud** combines **on-premises (private)** and **public cloud** into one
operational model — with **shared networking, security, and management** between them.
Movement of workloads/data plus **connectivity (VPN/Direct Connect/ExpressRoute/SD-WAN)**
are the core concepts. The exam wants the split of where what runs.

---

## 2. Core Concepts

### 2.1 Definition

| Item | Detail |
|------|--------|
| Private | on-prem workloads |
| Public | elastic/overflow |
| Shared | mgmt/networking |
| Goal | best of both |

- Hybrid = **one platform spanning both worlds**.

### 2.2 Why hybrid

| Reason | Detail |
|--------|--------|
| Burst | use public for spikes |
| Compliance | sensitive stays local |
| Migration | glide path to cloud |
| DR | cloud backup |

- **Keep sensitive on-prem; burst/DR to public.**

### 2.3 Connectivity

| Method | Use |
|--------|-----|
| VPN/IPsec | internet tunnel |
| Direct Connect | private link |
| ExpressRoute | Azure |
| SD-WAN | intelligent overlay |

- A **secured, low-latency path** is the foundation of hybrid.

### 2.4 Networking consistency

| Layer | Hybrid |
|-------|--------|
| Identity | same IdP/SSO |
| Routing | extended subnets |
| Firewall | consistent policies |
| Mgmt | single control |

- Keep **policies and addressing** coherent across both.

### 2.5 Challenges

| Challenge | Detail |
|-----------|--------|
| Latency | distance |
| Data gravity | transfer cost |
| Security | consistent |
| Complexity | two platforms |

- **Data migration cost + latency** are the top concerns.

### 2.6 Verification

```text
show ip route (extended)
ping / traceroute to cloud
show crypto ipsec sa (VPN)
monitor via cloud console
```

## 5. Exam Traps

- Hybrid = **private + public in one model**.
- Connectivity: **IPsec VPN, Direct Connect/ExpressRoute, SD-WAN**.
- Sensitive data stays **on-prem**; bursts go public.
- Consistent **identity/security/routing** across both.
- Migration: **glide path**; DR: cloud.
