# LFIB (Label Forwarding Information Base)

> **Level 20 · MPLS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **LFIB** is the MPLS forwarding table on each router: it maps **incoming label →
swap/pop + outgoing interface**. LSRs forward exclusively from the LFIB; LERs also
consult CEF to **push** on ingress. It's the thing you `show` when MPLS forwarding is
broken.

---

## 2. Core Concepts

### 2.1 What the LFIB holds

| Column | Meaning |
|--------|---------|
| In label | what arrives |
| Out label | what leaves |
| Prefix | the FEC it serves |
| Interface | next hop |
| Operation | swap / pop / push |

- Each entry = one **(in-label → out-label)** forwarding decision.

### 2.2 Relationship to CEF

| Table | Purpose |
|-------|---------|
| CEF | IP prefix → next hop |
| LFIB | in-label → out-label |
| LIB (LDP) | label bindings |

- CEF feeds the **FEC**; LDP feeds the **LIB**; the LFIB is the **working table**.

### 2.3 Example entry

```text
show mpls forwarding-table

 In Label    Out Label   Prefix    Out Interface    Next Hop
 17          32          10.0.0.0  Gi0/1            192.0.2.2
 20          Pop         10.0.0.0  Gi0/0            192.0.2.1
```

- **Pop** entry = PHP toward the egress.

### 2.4 Operations per entry

| Operation | Where | Result |
|-----------|-------|--------|
| Swap | core LSR | change top label |
| Pop | penultimate | remove label |
| Pop + push | ingress | VPN service swap |
| Push | egress (PHP) | re-add for service |

- **Pop + push** is the VPN edge pattern (swap the service label).

### 2.5 Building the LFIB

| Source | Data |
|--------|------|
| CEF | FEC / next hop |
| LDP | core bindings |
| MP-BGP | VPN label |
| Interface state | adjacency |

- Failures show up as **missing or wrong LFIB entries**.

### 2.6 Verification

```text
show mpls forwarding-table
show mpls forwarding-table detail
show mpls forwarding vrf CUST1
show ip cef
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No LFIB entry | FEC/LDP missing | forwarding-table |
| Wrong out label | binding stale | ip bindings |
| Pop expected | PHP config | forwarding-table |
| VPN no swap | MP-BGP missing | vrf table |
| Interface down | adjacency | CEF |

---

## 5. Exam Traps

- LFIB = **in-label → out-label + interface**.
- Core forward = **LFIB only**; ingress push = CEF.
- **Pop + push** = VPN edge label swap.
- Missing LFIB entry = no FEC / no LDP.
- `show mpls forwarding-table` is the debug workhorse.
