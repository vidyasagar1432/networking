# VRF (Virtual Routing and Forwarding)

> **Level 20 · MPLS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **VRF** is a per-tenant **virtual routing table + forwarding instance** on a PE
router. Each VRF has its **own RIB, FIB (CEF), interfaces, and routes** — customers are
isolated even though they share the same physical router and core. VRFs + route
distinguishers (RDs) are the foundation of **MPLS L3VPN** (note 09).

---

## 2. Core Concepts

### 2.1 What a VRF contains

| Table | Per-VRF |
|-------|---------|
| RIB | routes |
| CEF/FIB | forwarding |
| Interfaces | CE-facing |
| Routing protocol | eBGP/OSPF/EIGRP/static |
| Labels | VPN service label |

- Isolation is at **both control and data plane**.

### 2.2 VRF vs global

| Aspect | Global | VRF |
|--------|--------|-----|
| RIB | main table | per-VRF table |
| Visibility | all routes | only VRF routes |
| CE sharing | none | per customer |
| Use | core/Internet | L3VPN |

- The **core/global table** stays clean of customer prefixes.

### 2.3 Configuration

```text
ip vrf CUST1
 rd 65000:100
 route-target export 65000:100
 route-target import 65000:100
!
interface Gi0/1
 ip vrf forwarding CUST1
 ip address 10.10.0.1 255.255.255.0
!
router bgp 65000
 address-family ipv4 vrf CUST1
```

| Command | Purpose |
|---------|---------|
| `ip vrf NAME` | create VRF |
| `rd` | route distinguisher |
| `route-target` | import/export policy |
| `ip vrf forwarding` | bind interface |
| `address-family ipv4 vrf` | BGP per VRF |

### 2.4 RD vs RT

| Item | Function |
|------|----------|
| RD | makes prefixes **unique** in MP-BGP |
| RT | import/export **membership** policy |

- **RD** = identity; **RT** = who shares the VRF (note 08).

### 2.5 VRF-aware features

| Feature | Use |
|---------|-----|
| Static routes | per VRF |
| eBGP/iBGP | per VRF AF |
| OSPF | per-VRF process |
| Ping/traceroute | `vrf` keyword |
| SNMP/Telnet | VRF-aware |

- Management commands often need the **`vrf` keyword** (e.g., `ping vrf CUST1`).

### 2.6 Verification

```text
show ip vrf
show ip vrf detail
show ip route vrf CUST1
show ip cef vrf CUST1
ping vrf CUST1 10.10.0.2
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Interface not in VRF | binding missing | show ip vrf |
| No CE routes | PE-CE down | show ip route vrf |
| RD collision | duplicates | rd |
| RT wrong | import/export | route-target |
| Ping fails | wrong VRF | ping vrf |

---

## 5. Exam Traps

- VRF = **per-tenant routing + forwarding** instance.
- **RD** = uniqueness; **RT** = membership.
- `ip vrf forwarding` **removes the IP** — re-apply `ip address`.
- Per-VRF BGP = `address-family ipv4 vrf`.
- Use `ping vrf X` for VRF-aware checks.
