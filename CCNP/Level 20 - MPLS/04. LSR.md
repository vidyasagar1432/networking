# LSR (Label Switch Router)

> **Level 20 · MPLS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **LSR** (also **P router** in VPN terms) lives in the **core** of the MPLS domain.
It forwards packets by **swapping the top label** based on the **LFIB** — no IP lookup,
no customer routes. The LSR runs IGP + **LDP** to build label bindings for core
reachability.

---

## 2. Core Concepts

### 2.1 Core responsibilities

| Task | Detail |
|------|--------|
| Swap labels | LFIB-driven |
| LDP | label distribution |
| IGP | core reachability |
| Transparency | no customer routes |

- The core stays **routing-free of customer prefixes** — scale win.

### 2.2 Forwarding flow

| Step | Detail |
|------|--------|
| 1 | receive labeled packet |
| 2 | LFIB lookup (in label) |
| 3 | swap label |
| 4 | forward out interface |

- Only the **top label** is examined and swapped.

### 2.3 Label bindings (LDP)

| Item | Detail |
|------|--------|
| Protocol | LDP (UDP/TCP 646) |
| Exchange | label ↔ FEC bindings |
| Trigger | IGP routes |
| Result | core LSPs |

- **LDP** distributes the labels used for core forwarding.
- Downstream routers advertise bindings; upstream installs them.

### 2.4 PHP at the penultimate LSR

| Role | Action |
|------|--------|
| Penultimate LSR | pops (implicit null) |
| Egress LER | receives naked IP |
| Unless | explicit null (QoS) |

- The last core hop usually **pops** so the egress does pure IP delivery.

### 2.5 Config sketch

```text
mpls ip
interface Gi0/0
 mpls ip
```

| Command | Purpose |
|---------|---------|
| `mpls ip` | enable globally |
| `interface ... mpls ip` | per core link |
| `mpls ldp router-id` | choose router-id |

- Every core link needs `mpls ip`.

### 2.6 Verification

```text
show mpls forwarding-table
show mpls ldp bindings
show mpls ldp neighbor
show ip cef
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No swap | LFIB missing | forwarding-table |
| No LDP | IGP down / link | show mpls ldp neighbor |
| Blackhole | binding wrong | ldp bindings |
| PHP missing | no implicit null | forwarding |
| Label leak | mismatch | interfaces |

---

## 5. Exam Traps

- LSR = **core** (P router): swaps labels only.
- Uses the **LFIB**, not the IP RIB.
- **LDP (UDP/TCP 646)** builds core labels.
- Penultimate LSR does **PHP** (pop before egress).
- Core holds **no customer routes**.
