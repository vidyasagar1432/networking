# MPLS Basics

> **Level 20 · MPLS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**MPLS** forwards packets using **short fixed-length labels** instead of IP longest-prefix
lookups. Labels sit between L2 and L3 (a **shim header**). MPLS enables **traffic
engineering**, **Layer 3 VPNs (L3VPN)** and **pseudo-wires (L2VPN)** — the carrier-grade
reason it's everywhere in SP backbones.

---

## 2. Core Concepts

### 2.1 Why MPLS

| Problem | MPLS answer |
|---------|-------------|
| Slow IP lookup | label swap (fast) |
| No TE | MPLS-TE paths |
| No VPN in core | label-stack VPN |
| Layer-2 services | pseudowire |

- Labels give the core a **simple forwarding paradigm** (swap/push/pop).

### 2.2 Position in the stack

| Layer | Example |
|-------|---------|
| L3 | IP |
| 2.5 | MPLS shim (labels) |
| L2 | Ethernet / PPP |

- The shim sits **between L2 and L3**.

### 2.3 The core idea

```
CE -- PE (LER) -- P (LSR) -- P -- PE (LER) -- CE
        push            swap/swap            pop
```

- **Edge routers** push/pop labels; **core routers** only swap.
- Forwarding decisions inside the core are **label-based**.

### 2.4 MPLS domains

| Element | Role |
|---------|------|
| LSP | label-switched path (the tunnel) |
| LER | edge: push/pop |
| LSR | core: swap |
| FEC | class of packets sharing a label |

- A path from ingress to egress LER is an **LSP**.

### 2.5 Enabling MPLS (IOS-XE)

```text
ip cef
mpls ip
interface Gi0/0
 mpls ip
```

| Command | Purpose |
|---------|---------|
| `ip cef` | CEF prerequisite |
| `mpls ip` | enable label distribution |
| `interface ... mpls ip` | per-link |

- MPLS rides on **CEF** and **LDP** (note 02/05).

### 2.6 What MPLS brings

| Benefit | Detail |
|---------|--------|
| Speed | label forwarding |
| Transparency | core needs no customer routes |
| Services | VPN/TE/pseudowire |
| Scaling | fewer core routes |

- The core stays **customer-route-free** — the key to L3VPN scale.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No labels | LDP not up | show mpls ldp |
| Traffic blackholes | CEF off | show ip cef |
| MPLS not forwarding | mpls ip missing | show mpls interfaces |
| No VPN routes | MP-BGP (note 08) | BGP |
| Broken LSP | missing swap | forwarding-table |

---

## 5. Exam Traps

- MPLS = **label switching** (2.5 shim).
- Core (LSR) **swaps**; edges (LER) **push/pop**.
- MPLS needs **CEF + LDP**.
- LSP = path; FEC = packet class.
- MPLS is the basis for **L3VPN/L2VPN/TE**.
