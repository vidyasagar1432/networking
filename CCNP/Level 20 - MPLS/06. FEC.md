# FEC (Forwarding Equivalence Class)

> **Level 20 · MPLS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **FEC** is a class of packets that **share the same forwarding treatment** — same
next hop, same path, same label. MPLS assigns **one label per FEC**, so the core only
needs to recognize the label, not reclassify every packet. Understanding FECs explains
why MPLS is fast and how VPNs carve out separate forwarding classes.

---

## 2. Core Concepts

### 2.1 What defines a FEC

| Criteria | Example |
|----------|---------|
| Prefix | /24 destination |
| Next hop | same egress |
| QoS | same class |
| VPN | same VRF |

- Packets in one FEC are **indistinguishable** for forwarding.

### 2.2 One FEC, one label

| Item | Relationship |
|------|--------------|
| FEC | packet class |
| Label | per-FEC binding |
| LSP | per-FEC path |
| Binding | label ↔ FEC |

- LDP announces **label ↔ FEC** bindings to build LSPs.

### 2.3 FEC granularity

| Granularity | Use |
|-------------|-----|
| Host (per /32) | fine, more labels |
| Aggregate | coarse, fewer labels |
| Per-VRF | VPN separation |
| Per-prefix | standard IGP |

- More granular FECs = more labels = more control (and overhead).

### 2.4 How ingress classifies

| Packet | FEC |
|--------|-----|
| to 10.0.0.0/24 | FEC A |
| to 10.1.0.0/24 | FEC B |
| VPN prefix | per-VRF FEC |

- Ingress LER maps IP → FEC → label stack.

### 2.5 FEC and LDP

| Step | Detail |
|------|--------|
| 1 | IGP installs prefix |
| 2 | FEC created |
| 3 | label bound (LIB) |
| 4 | advertised via LDP |
| 5 | LFIB entry built |

- **LDP bindings** are the FEC's label plumbing.

### 2.6 FEC in VPNs

- VPN routes are **their own FECs** per VRF + RD — the label separates customers.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No FEC label | LDP not bound | ldp bindings |
| Too many labels | granularity | prefix config |
| Wrong label | FEC mismatch | forwarding-table |
| VPN no FEC | VRF/RD | show ip cef vrf |
| Merge wrong | aggregate FEC | cef |

---

## 5. Exam Traps

- FEC = **same forwarding treatment** = same label.
- **One label per FEC**.
- Ingress classifies IP → FEC; core only sees the label.
- LDP advertises **label ↔ FEC** bindings.
- VPNs create **per-VRF FECs** (with RD).
