# MPLS Labels

> **Level 20 · MPLS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

MPLS forwarding is driven by **labels** — 20-bit values carried in a 32-bit **shim
header** between L2 and L3. Each router swaps the top label and forwards. A packet can
carry a **label stack** (multiple shims) — that's how VPNs and TE tunnels nest services.

---

## 2. Core Concepts

### 2.1 The shim header (32 bits)

| Field | Bits | Meaning |
|-------|------|---------|
| Label | 20 | forwarding value |
| Exp | 3 | QoS / class |
| S | 1 | bottom-of-stack |
| TTL | 8 | hop limit |

- **Label** drives the swap; **Exp** marks class; **S** marks the last label; **TTL** limits loops.

### 2.2 Label values

| Range | Use |
|-------|-----|
| 0–15 | reserved (special) |
| 16–1023 | explicit null / others |
| 16–1,048,575 | normal labels |

- Reserved values include **implicit null (3)** and **explicit null (0)**.

### 2.3 The label stack

| Label | Purpose |
|-------|---------|
| top | forwards in core |
| inner | service (VPN) label |
| bottom (S=1) | deepest |

- **Push** adds a label; **swap** changes the top; **pop** removes it.
- VPN uses **two labels**: transport + service (note 09).

### 2.4 Label operations

| Op | Where | Effect |
|----|-------|--------|
| Push | ingress LER | add shim |
| Swap | core LSR | replace top |
| Pop | penultimate/egress | remove |

- **PHP** (penultimate hop popping) removes the label one hop early — improves egress performance.

### 2.5 Explicit vs implicit null

| Label | Value | Use |
|-------|-------|-----|
| implicit null | 3 | PHP (pop before egress) |
| explicit null | 0 | keep QoS (Exp) at egress |
| router alert | 1 | control traffic |

- Explicit null lets the egress still read **Exp** for QoS.

### 2.6 TTL handling

| Mode | Behavior |
|------|----------|
| Pipe | TTL not decremented (hidden core) |
| Uniform | TTL decrements normally |

- **Pipe mode** hides core hops — used in SP networks.

---

## 5. Exam Traps

- Shim = **label 20 + exp 3 + S 1 + TTL 8**.
- **S bit** marks bottom of stack.
- **PHP** pops before egress; **explicit null 0** preserves QoS.
- VPN = **two-label stack** (transport + service).
- Pipe mode hides the core's TTL.
