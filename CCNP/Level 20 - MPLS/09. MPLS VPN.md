# MPLS VPN (L3VPN)

> **Level 20 · MPLS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**MPLS L3VPN** delivers private, isolated customer connectivity over a shared SP core.
Each customer has a **VRF on the PE**; the PE exchanges routes with the customer (CE),
turns them into **VPNv4 routes with a service label** via MP-BGP, and the core carries
them inside a **two-label stack**. Customers never touch the core routing.

---

## 2. Core Concepts

### 2.1 The roles

| Role | Device | Job |
|------|--------|-----|
| CE | customer router | PE-facing |
| PE | provider edge | VRF + MP-BGP |
| P | provider core | label switch |

- **PE** = the intelligence; **P** = plain label switching; **CE** = customer.

### 2.2 The two-label stack

| Label | Layer | Purpose |
|-------|-------|---------|
| top | transport | reaches egress PE (LDP) |
| inner | service (VPN) | which VRF/CE at egress |

- The core only looks at the **top label**; the egress PE uses the **inner** one.

### 2.3 End-to-end flow

```
CE1 --(IP)--> PE1: push [service|transport]
            P: swap transport label
            PE2: pop, read service label -> VRF -> CE2
```

| Step | Who | Action |
|------|-----|--------|
| 1 | CE1 | sends IP |
| 2 | PE1 | VRF lookup → push labels |
| 3 | P | swap top label |
| 4 | PE2 | pop + service label → CE2 |

### 2.4 Control plane plumbing

| Plane | Protocol | Result |
|-------|----------|--------|
| Core | IGP + LDP | transport labels |
| VPN | MP-BGP | VPNv4 + service label |
| CE-PE | eBGP/OSPF/EIGRP/static | customer routes |

- **Three routing layers** cooperate to build the L3VPN.

### 2.5 VPN models

| Model | RT policy |
|-------|-----------|
| Full mesh | all RTs shared |
| Hub-and-spoke | import/export split |
| Extranet | selective sharing |

- The **RTs** determine the VPN topology (note 08).

### 2.6 Verification

```text
show ip vrf
show ip route vrf CUST1
show bgp vpnv4 unicast vrf CUST1
show mpls forwarding-table
ping vrf CUST1 10.10.0.2
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No VPN route | MP-BGP down | show bgp vpnv4 |
| RT wrong | import/export | route-target |
| Ping fails | service label | forwarding-table |
| CE down | PE-CE protocol | show ip route vrf |
| Overlap | RD issue | rd |

---

## 5. Exam Traps

- L3VPN = **VRF + MP-BGP + two-label stack**.
- PE = edge intelligence; **P = label switch only**.
- Top label = transport (LDP); inner = **service/VPN**.
- **RTs** define VPN membership/topology.
- CE–PE can be eBGP/OSPF/EIGRP/static.
