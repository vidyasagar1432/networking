# EIGRP Successor

> **Level 11 · EIGRP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **successor** is the **best next-hop router** for a destination — the one with the
**lowest Feasible Distance (FD)**. It is what DUAL installs into the routing table (AD 90,
internal). Understanding successor selection is the heart of EIGRP: FD is our end-to-end
metric, and the successor is simply the neighbor offering the lowest one.

---

## 2. Core Concepts

### 2.1 Feasible Distance (FD) explained

- **FD** = the metric from *this router* to the destination via a given neighbor
  = **AD (neighbor's reported metric) + our link cost to that neighbor**.
- The **lowest FD** across all neighbors → that neighbor is the **successor**.

### 2.2 Successor election

```
Neighbor  FD (advertised distance + local cost)
   A       20   ← LOWEST → SUCCESSOR (installed in RIB)
   B       25
   C       35
```

- The successor's route shows in the **routing table** as `D` (internal) or `D EX`
  (external/reinstated).
- Multiple successors possible via **ECMP** when FDs tie.

### 2.3 Successor vs Feasible Successor (one-liner recap)

| | Successor | Feasible successor |
|--|-----------|--------------------|
| Best path | yes (lowest FD) | backup, loop-free |
| In routing table | **yes** | no (only topology table) |
| Condition | — | AD < successor's FD |

- See note 04 for the FS selection math.

### 2.4 Route codes for successors

| Code | Meaning |
|------|---------|
| `D` | EIGRP internal (AD 90) |
| `D EX` | EIGRP external / redistributed (AD 170) |

- A route can also show **5 tagged** as external origin.

### 2.5 Successor failure handling (DUAL)

- If the successor becomes unreachable:
  - If an **FS exists** → promote it (local recompute, fast).
  - If **no FS** → go **Active**, query, recompute (note 01).

## 3. Configuration / Commands

```text
show ip eigrp topology            ! FD, AD columns per neighbor
show ip eigrp topology 10.1.1.0 255.255.255.0
show ip route eigrp               ! installed successors (D/D EX)
show ip eigrp neighbors
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Wrong successor in RIB | metric changes / bandwidth wrong | `show ip eigrp topology` FD |
| Successor missing | neighbor not adjacent / filtered | `show ip eigrp neighbors` |
| Route flapping D↔D EX | redistribution churn | check origin source |
| Successor not failing over | FS exists but not promoted | verify FS condition |

---

## 5. Exam Traps

- **FD = AD (reported) + local link cost** — the two-part formula.
- **Lowest FD wins** → successor installed in RIB.
- Successor is **installed**; FS is only in the **topology table**.
- **Internal AD 90; external AD 170** — a re-distributed route jumps AD.
- **ECMP** when two neighbors tie on FD.
- Don't confuse **FD** (ours) with **AD** (neighbor's report).
