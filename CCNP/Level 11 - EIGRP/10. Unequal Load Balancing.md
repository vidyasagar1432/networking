# EIGRP Unequal-Cost Load Balancing

> **Level 11 · EIGRP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Unequal-cost load balancing** lets EIGRP split traffic across paths with **different
metrics** — a capability OSPF and RIP lack. It's enabled with **`variance`** (note 09),
which widens the metric window beyond the successor, while **DUAL's feasibility condition**
still guarantees every used path is **loop-free**. Traffic is then shared **in proportion
to the inverse of each path's metric**.

---

## 2. Core Concepts

### 2.1 The full eligibility test (both checks)

```
1. Metric bound:  FD(path)  <=  variance x FD(successor)
2. Loop-free:     AD(path)  <  FD(successor)     (feasibility condition)
```

- Both must hold — variance alone is not enough (the "variance doesn't bypass loop
  freedom" exam fact).

### 2.2 The distribution math (inverse weighting)

| Path | FD | Weight (1/FD) | Share |
|------|----|---------------|-------|
| A | 100 | 1/100 | 2/3 |
| B | 200 | 1/200 | 1/3 |

- Lower-metric path carries more traffic. This is CEF/interface hashing per flow on top.

### 2.3 Equal vs unequal recap

| | ECMP (variance 1) | Unequal (variance >1) |
|--|-------------------|-----------------------|
| Paths | equal metric | different metrics |
| Share | even | inverse-metric weighted |
| Config | default | `variance n` |
| Eligibility | successor/equal FD | FS within bound only |

### 2.4 Design considerations

- Use when links differ (e.g., 1 Gbps + 100 Mbps toward same destination) and you want
  both used.
- Verify **FS status first** — a path failing the feasibility condition will never load
  regardless of variance.
- Mind `maximum-paths` (cap on installed paths).
- Works per address family in named mode.

### 2.5 Verification

```text
show ip route <prefix>            ! multiple next hops listed
show ip eigrp topology            ! FS candidates with FDs
```

- Expected: several next hops in RIB; `show ip eigrp topology` shows why each qualifies.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Only one next hop | path not FS / variance=1 | FS check, variance |
| Wrong split | proportional weighting misread | compute 1/FD shares |
| Flap paths in/out | metric instability | stabilize link bandwidth |
| Max paths hit | more eligible than cap | raise maximum-paths |
| Blackhole on a path | link died but still hashed | verify both adjacencies |

---

## 5. Exam Traps

- **Feasibility condition still required** — variance is not a loop-free bypass.
- **Load split is inverse-metric**, not even.
- **variance 1 = ECMP only** (default).
- EIGRP is the **only IGP that does unequal-cost balancing** (OSPF/RIP equal only).
- Both checks: `FD <= variance x successor FD` **and** `AD < FD`.
