# EIGRP Troubleshooting

> **Level 11 · EIGRP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

EIGRP troubleshooting focuses on **neighbor formation** (hello/hold, K-values, AS, auth),
**DUAL state** (passive vs active / SIA), and **route/metric correctness** (successor, FS,
variance). A strict `show` progression isolates the layer: neighbors → topology → routes →
forwarding.

---

## 2. Core Concepts

### 2.1 The troubleshooting flow

| Step | Question | Command |
|------|----------|---------|
| 1. Interface | link up? | `show ip interface brief` |
| 2. Neighbors | adjacency formed? | `show ip eigrp neighbors` |
| 3. Topology | routes + FS present? | `show ip eigrp topology` |
| 4. Routes | installed in RIB? | `show ip route eigrp` |
| 5. Forwarding | CEF has it? | `show ip cef` / ping |

### 2.2 Neighbor-formation issues (the exam table)

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No neighbor at all | AS mismatch / multicast 224.0.0.10 blocked / auth | `show ip eigrp neighbors`, ACL |
| Hello but no adjacency | K-values mismatch | `show ip eigrp interfaces` K-values |
| Neighbor flapping | hold time too low / loss | `show ip eigrp neighbors` hold/RTO |
| Auth failure | key/algorithm mismatch | `show ip eigrp interfaces detail` |
| Passive interface | interface intentionally silent | `passive-interface` check |

### 2.3 SIA (Stuck-in-Active) — the critical failure

- **Cause**: a router sent a query but a neighbor never replied (RTP reliability broken,
  one-way link, or huge query scope).
- **Effect**: route stuck **Active** past `active-timeout` (default 3 min) → route
  declared unreachable → possible loops/outage.
- **Fixes**:
  - EIGRP **stub** on spokes (stops query propagation, note 07).
  - Verify links are bidirectional (UDLD/duplex).
  - Increase `timers active-time`.

```
show ip eigrp topology active      ! which routes are Active
show ip eigrp events               ! query/reply history
```

### 2.4 Successor / metric issues

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| Wrong successor | bandwidth/delay wrong on link | `interface ... bandwidth/delay` |
| No FS (slow failover) | AD >= FD for all backups | add links / tune metrics |
| Unequal paths unused | not FS or variance=1 | check FS + variance |
| Metric explosion | delay/bandwidth misconfig | verify `show ip eigrp topology` |

### 2.5 Common config pitfalls

- **AS mismatch** between neighbors = no adjacency.
- **K-values must match** (hello timers need not — unlike OSPF).
- **`passive-interface` on a needed segment** = silent.
- **Redistribution without `default-metric`** = rejected routes.
- Named vs classic mismatch on both ends.

---

## 5. Exam Traps

- **K-values must match; hello timers do NOT** — the EIGRP-vs-OSPF trick.
- **SIA = unanswered query** → fix with **stub** or `timers active-time`.
- **Stub stops queries** — the main SIA mitigation.
- **`passive-interface` silences** the segment (neighbors gone).
- **Redistributed routes need a default-metric** or they're rejected.
- Active state = diffusing computation in progress (note 01).
