# Local Preference (LOCAL_PREF)

> **Level 12 · BGP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Local Preference** is the **well-known discretionary** attribute that tells the whole
AS which **outbound** eBGP path is preferred. Higher is better (best-path **step 2** —
right after Weight). It is set **at the edge** (on routes received from eBGP) and
propagates **inside the AS via iBGP**, so every router in the AS makes the same choice.

---

## 2. Core Concepts

### 2.1 The one job: outbound traffic selection

- Inbound routes from **upstream A** carry a lower local-pref than **upstream B** → the
  AS exits via B.
- Because local-pref rides iBGP, one edge router's decision is shared AS-wide — consistent
  exit.

### 2.2 Default and propagation

| Fact | Value |
|------|-------|
| Default | 100 |
| Set where | inbound from eBGP (neighbor in) |
| Propagates | to iBGP peers |
| Propagates | **not** to eBGP (external routers never see it) |
| Best path | step 2, higher wins |

### 2.3 Two configuration methods

**Global default (all eBGP routes):**

```text
router bgp 65001
 bgp default local-preference 200
```

**Per-neighbor (specific routes):**

```text
route-map SETLP permit 10
 match ip address prefix-list CRITICAL
 set local-preference 300

router bgp 65001
 neighbor 192.0.2.2 route-map SETLP in
```

- Neighbor route-map wins over the global default for matching prefixes.

### 2.4 Local-pref vs Weight vs MED

| Attribute | Scope | Direction | Direction of preference |
|-----------|-------|-----------|-------------------------|
| Weight | single router | inbound | higher (local) |
| Local Pref | entire AS | inbound | higher (AS-wide) |
| MED | neighbor AS | outbound | lower |

- Weight is local-only; local-pref is AS-wide; MED is sent to upstreams.

### 2.5 Use-case: primary/backup upstreams

```text
Upstream A: local-pref 200  (primary)
Upstream B: local-pref 100  (backup)
```

- All routers exit via A; if A's session dies, B's 100 becomes the winner automatically.

### 2.6 Verification

```text
show ip bgp <prefix>           ! local pref column per path
show ip bgp neighbors <ip>     ! negotiated / applied policies
```

- `show ip bgp` shows local-pref in the table; weight is a separate column.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Wrong exit path | local-pref lower on preferred | `show ip bgp` compare |
| Decision not AS-wide | route-map applied in wrong direction | `neighbor ... in` vs `out` |
| Local-pref lost | sent to eBGP / not set at edge | attribute scope |
| Path never selected | Weight differs (step 1 first) | check weight column |
| Pref ignored | set on `out` instead of `in` | route-map direction |

---

## 5. Exam Traps

- **Higher local-pref wins** (step 2, right after Weight).
- Default = **100**.
- Set **inbound from eBGP**; never seen by external routers.
- Propagates **via iBGP only** — the AS-wide consistency trick.
- `bgp default local-preference` sets the global; a neighbor route-map overrides per prefix.
