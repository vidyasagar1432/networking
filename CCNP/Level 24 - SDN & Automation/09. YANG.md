# YANG

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**YANG** (RFC 6020/7950) is a **data modeling language** that describes network
configuration and state as a **tree of containers, lists, and leafs**. Both **NETCONF**
and **RESTCONF** operate on YANG models — it's the shared "schema" of modern network
automation. The exam tests the model structure and standard models.

---

## 2. Core Concepts

### 2.1 What YANG does

| Item | Detail |
|------|--------|
| Model | config + state |
| Tree | containers/lists |
| Reuse | modules |
| Access | NETCONF/RESTCONF |

- YANG gives devices a **structured, machine-readable interface**.

### 2.2 Key statements

| Statement | Meaning |
|-----------|---------|
| module | model namespace |
| container | group of nodes |
| list | repeated entries |
| leaf | single value |
| leaf-list | array of values |
| type | data type |

- A YANG module is the **schema** for a device's config.

### 2.3 Data types

| Type | Example |
|------|---------|
| string | "uplink" |
| int/uint | 100 |
| boolean | true/false |
| enumeration | up/down |
| ip-address | 10.0.0.1 |

- Typed leaves make validation **automatic**.

### 2.4 Standard models

| Model | For |
|-------|-----|
| ietf-interfaces | interfaces |
| ietf-ip | IP addressing |
| Cisco-IOS-XE-native | IOS-XE native |
| ietf-yang-types | common types |

- Cisco ships **Cisco-IOS-XE-*** models for its devices.

### 2.5 Example

```yaml
interface:
  - name: GigabitEthernet1
    type: ethernetCsmacd
    enabled: true
```

- This JSON/YAML maps directly to the **ietf-interfaces** YANG tree.

### 2.6 Why it matters

| Benefit | Detail |
|---------|--------|
| Standard | vendor-neutral |
| Validation | typed |
| Automation | programmatic |
| Introspection | self-describing |

- YANG = **the common language** for NETCONF/RESTCONF.

## 5. Exam Traps

- YANG = **data model (tree of containers/lists/leafs)**.
- Both NETCONF and RESTCONF use it.
- **module / container / list / leaf** are the building blocks.
- Standard models: **ietf-interfaces**, **ietf-ip**, Cisco native.
- Typed leaves = automatic validation.
