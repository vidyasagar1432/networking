# Python

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Python** is the de-facto language for network automation: scripts talk to devices via
**REST/Netmiko/NAPALM**, parse **JSON/YAML**, and drive controllers. The exam expects
basic Python literacy — variables, data types, conditionals, loops, functions, and the
`requests`/`json` modules for APIs.

---

## 2. Core Concepts

### 2.1 Core syntax

| Concept | Example |
|---------|---------|
| Variable | `host = "192.0.2.1"` |
| List | `devices = ["R1","R2"]` |
| Dict | `{"name": "R1"}` |
| Condition | `if x > 5:` |
| Loop | `for d in devices:` |
| Function | `def get(ip):` |

- **Dicts and lists** mirror JSON — the bridge to APIs.

### 2.2 Libraries for network automation

| Library | Use |
|---------|-----|
| requests | HTTP/REST |
| json | parse/serialize |
| netmiko | SSH CLI |
| napalm | multi-vendor API |
| ncclient | NETCONF |
| yaml | YAML config |

- **requests + netmiko + ncclient** cover most automation needs.

### 2.3 REST call example

```python
import requests, json
r = requests.get("https://host/api", headers={"X-Auth-Token": token}, verify=False)
data = r.json()
print(data["response"])
```

| Method | Meaning |
|--------|---------|
| requests.get/post/put/delete | verbs |
| .json() | parse response |
| verify=False | skip TLS |

### 2.4 Common patterns

| Pattern | Detail |
|---------|--------|
| Read config | GET |
| Change config | POST/PATCH |
| SSH | netmiko |
| Loop devices | for + list |
| Handle errors | try/except |

- **Try/except** keeps scripts from dying on one bad device.

### 2.5 Example device loop

```python
for host in devices:
    r = requests.get(f"https://{host}/api", ...)
    print(host, r.status_code)
```

- F-strings and loops make **multi-device** work easy.

### 2.6 Why Python in exams

| Benefit | Detail |
|---------|--------|
| Readable | easy to learn |
| Ecosystem | requests/netmiko |
| Data | JSON/YAML native |
| Controllers | DNA Center/SD-WAN APIs |

- Python = the **glue** for SDN automation.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
