# JSON

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**JSON** (JavaScript Object Notation) is the **lightweight data format** used by REST
APIs, RESTCONF, and most automation tools. It's built on **key-value pairs, arrays,
and nesting** — human-readable and machine-parseable. The exam expects you to read and
reason about JSON for API payloads.

---

## 2. Core Concepts

### 2.1 JSON structure

| Element | Syntax |
|---------|--------|
| Object | `{ }` |
| Array | `[ ]` |
| Key-value | `"key": value` |
| String | `"text"` |
| Number | `42` |
| Boolean | `true/false` |
| Null | `null` |

- Everything is **key-value pairs, nested objects, or arrays**.

### 2.2 Example

```json
{
  "device": "R1",
  "interfaces": [
    {"name": "Gi1", "enabled": true},
    {"name": "Gi2", "enabled": false}
  ],
  "asn": 65000
}
```

- `interfaces` is an **array of objects** — common for lists of devices/config.

### 2.3 Rules

| Rule | Detail |
|------|--------|
| Quotes | keys double-quoted |
| Trailing | no trailing commas |
| Nested | objects/arrays |
| Valid | must parse |

- Malformed JSON (trailing comma, unquoted key) **fails to parse**.

### 2.4 JSON in APIs

| Use | Detail |
|-----|--------|
| Request | POST/PUT body |
| Response | API data |
| Config | RESTCONF YANG+JSON |
| State | device telemetry |

- JSON is the **default payload** of REST/RESTCONF.

### 2.5 JSON vs XML

| Aspect | JSON | XML |
|--------|------|-----|
| Style | compact | verbose |
| Types | native | text |
| Popular | modern | legacy |
| Comments | no | yes |

- **JSON = lighter, modern; XML = heavier, older** (note 11).

### 2.6 Parsing (Python)

```python
import json
data = json.loads(payload)   # str -> dict
print(data["device"])
```

- `json.loads`/`json.dumps` convert between text and objects.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Parse error | trailing comma | validate |
| Key missing | wrong key | structure |
| Type mismatch | string vs int | quotes |
| Nested wrong | array | index |
| Encoding | unicode | charset |

## 5. Exam Traps

- JSON = **key-value, arrays, nesting**.
- Keys **double-quoted**; no trailing commas.
- Array `[ ]` vs object `{ }`.
- Default payload of **REST/RESTCONF**.
- `json.loads` parses text to Python objects.
