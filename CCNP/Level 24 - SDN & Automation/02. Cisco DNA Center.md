# Cisco DNA Center

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**DNA Center** is Cisco's **SDN controller + management platform** for campus networks.
It provides **intent-based networking**, automation (design, provisioning, assurance),
and the **control logic** for **SD-Access** (note 03). It exposes a **REST API** and uses
**netconf/CLI** southbound to program Catalyst switches.

---

## 2. Core Concepts

### 2.1 What DNA Center does

| Function | Detail |
|----------|--------|
| Design | sites, templates |
| Provision | device config |
| Assurance | telemetry/health |
| Automation | intent-based |
| SD-Access | fabric control |

- DNA Center = **the brain + dashboard of the campus**.

### 2.2 Intent-based networking

| Step | Meaning |
|------|---------|
| Intent | what you want |
| Translation | policies → config |
| Activation | push to devices |
| Assurance | verify intent |

- **Intent = desired state**; DNA Center makes it real and verifies it.

### 2.3 Planes/functions

| Plane | DNA Center role |
|-------|----------------|
| Management | UI/API |
| Automation | provisioning |
| Assurance | analytics |
| Control | SD-Access fabric |

- Assurance gives **telemetry-driven** troubleshooting.

### 2.4 APIs

| API | Use |
|-----|-----|
| REST API | third-party apps |
| Intent API | high-level |
| Integration | Ansible/scripts |
| Token | auth |

- DNA Center's **REST API** enables automation (note 06).

### 2.5 SD-Access tie-in

| Component | Detail |
|-----------|--------|
| Fabric controller | DNA Center |
| Control plane | LISP |
| Data plane | VXLAN |
| Policy | ISE |

- DNA Center drives **SD-Access (LISP + VXLAN + ISE)**.

### 2.6 High availability

| Item | Detail |
|------|--------|
| Cluster | multiple nodes |
| Roles | primary/secondary |
| Data | DB replication |
| Failover | automatic |

- Run DNA Center as a **cluster** for HA.
