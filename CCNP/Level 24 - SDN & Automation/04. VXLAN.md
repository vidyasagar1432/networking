# VXLAN

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**VXLAN** is an **overlay data-plane** technology: it encapsulates L2 frames in **UDP
(4789)** over the underlay, scaling VLANs to **16 million VNIs** and letting L2 domains
stretch across L3. It is the **data plane of SD-Access** and the modern DC fabric. The
exam tests the header and VNI concept.

---

## 2. Core Concepts

### 2.1 Why VXLAN

| Problem | VXLAN answer |
|---------|--------------|
| 4094 VLANs | 16M VNIs |
| L2 stretch | overlay |
| Multi-tenant | VNI = tenant |
| L3 underlay | IP transport |

- VXLAN **escapes the 12-bit VLAN limit** with a 24-bit VNI.

### 2.2 Encapsulation

| Header | Detail |
|--------|--------|
| Outer | IP/UDP (4789) |
| VXLAN | VNI (24-bit) |
| Inner | original L2 frame |
| Result | MAC-in-UDP |

- **MAC-in-UDP** over the IP underlay.

### 2.3 VNI

| Item | Detail |
|------|--------|
| VNI | 24-bit ID |
| Scope | 16,777,216 |
| Maps to | VLAN/segment |
| Tenant | isolation |

- **VNI = the overlay VLAN** — separates tenants/segments.

### 2.4 VTEP (tunnel endpoints)

| Item | Detail |
|------|--------|
| VTEP | VXLAN endpoint |
| Encapsulate | at ingress |
| Decapsulate | at egress |
| Underlay | IP address |

- **VTEPs** do the encap/decap at the edges.

### 2.5 BUM handling

| Mode | Detail |
|------|--------|
| Multicast | underlay mcast |
| Head-end replication | unicast copies |
| EVPN | BGP-based |

- BUM traffic uses **multicast, HER, or EVPN** to reach VNIs.

### 2.6 VXLAN vs VLAN

| Aspect | VLAN | VXLAN |
|--------|------|-------|
| ID | 12-bit | 24-bit |
| Count | 4094 | 16M |
| Domain | L2 | overlay L3 |
| Transport | switch | UDP/IP |

- VXLAN **decouples L2 from the physical topology**.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No VXLAN | VNI not mapped | show vxlan vni |
| No peers | underlay | show nve peers |
| BUM broken | mcast/HER | evpn |
| MAC not learned | VTEP | show mac |
| Tenant leak | VNI overlap | vn-segment |

- It's the **data plane of SD-Access**.
