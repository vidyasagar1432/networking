# Git

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Git** is a **distributed version control system** — it tracks config/scripts/playbooks,
enables **branches, commits, and rollback**. For network engineers it's the backbone of
**Infrastructure as Code** and **config-as-code** workflows. The exam tests the core
commands and concepts.

---

## 2. Core Concepts

### 2.1 Why Git

| Benefit | Detail |
|---------|--------|
| Versioning | track changes |
| Rollback | revert errors |
| Branching | parallel work |
| Collaboration | team/PR |
| Audit | history |

- Git = **the safety net for config as code**.

### 2.2 The three states

| State | Where |
|-------|-------|
| working | your files |
| staged | index |
| committed | repository |

- Files flow: **modified → staged → committed**.

### 2.3 Core commands

| Command | Meaning |
|---------|---------|
| `git init` | start repo |
| `git add` | stage |
| `git commit` | save snapshot |
| `git status` | show state |
| `git log` | history |
| `git checkout` | switch/restore |
| `git push/pull` | remote sync |

- **add → commit** records a change; **push/pull** syncs.

### 2.4 Example flow

```bash
git init
git add configs/
git commit -m "add router configs"
git log
git diff
```

| Command | Result |
|---------|--------|
| git add | stage |
| git commit | snapshot |
| git diff | see changes |
| git log | history |

### 2.5 Git for networking

| Use | Detail |
|-----|--------|
| Config files | versioned |
| Playbooks | Ansible/Terraform |
| IaC | audit + rollback |
| Collaboration | PR review |

- Store **configs/playbooks** in Git for reproducibility.

### 2.6 Remote workflows

| Item | Detail |
|------|--------|
| Remote | GitHub/GitLab |
| Clone | copy repo |
| Branch | feature work |
| Merge/PR | integrate |

- **Branch + PR** keeps changes reviewable.

## 3. Configuration / Commands

```bash
git clone <url>
git branch feature
git checkout feature
git add -A
git commit -m "msg"
git push origin main
```

---

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Nothing to commit | not staged | git add |
| Conflict | merge | git status |
| Wrong branch | checkout | git branch |
| Remote fail | auth | git remote |
| Lost change | uncommitted | git stash |

---

## 5. Exam Traps

- Git states: **working → staged → committed**.
- `add` stages; `commit` saves; `push` syncs.
- **Branch + PR** = collaboration.
- Git underpins **IaC / config-as-code**.
- `git log`/`git diff` = history + review.
