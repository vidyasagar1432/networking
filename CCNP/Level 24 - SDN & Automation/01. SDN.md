# SDN

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SDN** separates the **control plane** from the **data plane**, centralizing the brain
in a controller. Northbound **APIs** talk to apps; southbound protocols (NETCONF,
RESTCONF, OpenFlow) program devices. The result: network services become **programmable
and centrally managed** — the foundation of DNA Center, SD-Access, and VXLAN/LISP.

---

## 2. Core Concepts

### 2.1 Control vs data plane

| Plane | SDN location |
|-------|--------------|
| Control | controller (central) |
| Data | switches/routers |
| Management | orchestration |
| Service | apps/APIs |

- **Centralized control** = one brain for the whole network.

### 2.2 SDN architecture

| Layer | Role |
|-------|------|
| Application | business apps |
| Northbound API | app ↔ controller |
| Controller | control logic |
| Southbound API | controller ↔ device |
| Infrastructure | hardware |

- **Northbound** = up to apps; **southbound** = down to devices.

### 2.3 Southbound protocols

| Protocol | Style |
|----------|-------|
| NETCONF | YANG + XML |
| RESTCONF | YANG + REST |
| OpenFlow | flow table |
| CLI/SNMP | legacy |

- Modern SDN favors **NETCONF/RESTCONF over YANG** (notes 07/08).

### 2.4 Model vs controller-based

| Approach | Detail |
|----------|--------|
| Controller-based | centralized logic |
| Model-based | YANG data models |
| Overlay | VXLAN/LISP |

- Cisco's enterprise SDN = **DNA Center + SD-Access** (notes 02/03).

### 2.5 Benefits

| Benefit | Detail |
|---------|--------|
| Agility | rapid change |
| Automation | template-based |
| Consistency | single source |
| Visibility | analytics |
| Security | policy-driven |

- SDN turns the network into **an API-managed service**.

### 2.6 Trade-offs

| Concern | Detail |
|---------|--------|
| Controller | SPOF if not HA |
| Protocol | must support |
| Skill | new skills |
| Migration | hybrid path |

- Controllers need **HA**; legacy devices need gateways.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No config via API | protocol disabled | netconf-yang |
| Auth fail | credentials | API |
| Session drops | transport | netconf sessions |
| No model | YANG missing | yang |
| Controller down | HA | failover |

---

## 5. Exam Traps

- SDN = **separated control + data plane**.
- **Northbound = apps; southbound = devices**.
- NETCONF/RESTCONF + **YANG** = modern southbound.
- Controller must be **HA** (avoid SPOF).
- Cisco SDN = **DNA Center + SD-Access** (overlay + VXLAN/LISP).
