# REST API

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**REST** is an **HTTP-based** API style where resources have URLs and actions are
HTTP verbs (**GET/POST/PUT/PATCH/DELETE**). Data rides as **JSON** (or XML). Network
controllers (DNA Center, SD-WAN vManage, routers via RESTCONF) expose REST APIs —
making the network **scriptable**. The exam tests the verbs and status codes.

---

## 2. Core Concepts

### 2.1 REST principles

| Item | Detail |
|------|--------|
| Resource | URL-addressable |
| Verbs | HTTP methods |
| State | stateless |
| Data | JSON/XML |

- **Stateless** = each request is independent.

### 2.2 HTTP verbs

| Verb | Purpose |
|------|---------|
| GET | read |
| POST | create |
| PUT | replace |
| PATCH | modify |
| DELETE | remove |

- **GET=read, POST=create, PUT/PATCH=update, DELETE=remove.**

### 2.3 Status codes

| Code | Meaning |
|------|---------|
| 200 | OK |
| 201 | created |
| 401 | unauthorized |
| 404 | not found |
| 500 | server error |

- 2xx = success; **4xx = client; 5xx = server**.

### 2.4 API structure

| Part | Example |
|------|---------|
| Base URL | https://controller |
| Path | /dna/intent/api/... |
| Auth | token/headers |
| Payload | JSON body |

- Token-based auth (e.g., OAuth/bearer) is standard.

### 2.5 Example (cURL)

```bash
curl -X GET "https://10.0.0.5/dna/intent/api/v1/network-device" \
  -H "X-Auth-Token: $TOKEN" -k
```

| Method | Effect |
|--------|--------|
| -X | HTTP verb |
| -H | headers |
| -d | JSON body |
| -k | skip TLS verify |

### 2.6 Why it matters

| Benefit | Detail |
|---------|--------|
| Automation | scripts |
| Consistency | same API |
| Integration | Ansible/Python |
| Read/write | full lifecycle |

- REST is the **automation gateway** for SDN/controllers.

## 3. Configuration / Commands

```bash
curl -X GET -H "Authorization: Bearer $TOKEN" https://host/api
curl -X POST -d '{"key":"value"}' -H "Content-Type: application/json" ...
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| 401 | bad token | auth |
| 404 | wrong path | URL |
| 500 | server | logs |
| Timeout | reachability | base URL |
| 400 | bad body | JSON |

---

## 5. Exam Traps

- REST = **HTTP verbs + URLs + JSON**.
- **GET/POST/PUT/PATCH/DELETE** mapping.
- Status: 200/201 OK, 401 auth, **4xx client, 5xx server**.
- **Stateless** requests.
- Token/bearer auth is standard.
