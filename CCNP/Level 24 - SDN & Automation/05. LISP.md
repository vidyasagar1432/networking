# LISP

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**LISP** separates **identity (EID)** from **location (RLOC)**: hosts keep stable IDs
while mapping to current network locations via a **map server/control plane**. It is
the **control plane of SD-Access** — enabling host mobility and policy without changing
IPs. The exam tests the EID/RLOC split and the mapping flow.

---

## 2. Core Concepts

### 2.1 EID vs RLOC

| Term | Meaning |
|------|---------|
| EID | endpoint identity (host IP) |
| RLOC | routing locator (site IP) |
| Map | EID → RLOC |

- **EIDs travel; RLOCs are the current location.**

### 2.2 LISP roles

| Role | Device |
|------|--------|
| ITR | ingress tunnel router |
| ETR | egress tunnel router |
| MR/MS | map resolver/server |
| PxTR | proxy to non-LISP |

- **ITR/ETR = edges; MS/MR = control plane; PxTR = legacy interop.**

### 2.3 Mapping flow

| Step | Detail |
|------|--------|
| 1 | ITR needs a destination |
| 2 | map-request to MR/MS |
| 3 | MS returns EID → RLOC |
| 4 | ITR encapsulates to ETR |

- **Control plane = map lookup; data plane = encapsulation.**

### 2.4 LISP in SD-Access

| Plane | Role |
|-------|------|
| Control | LISP |
| Data | VXLAN |
| Mobility | EID persists |

- **LISP maps EIDs so hosts roam with the same IP** — the SD-Access control plane.

### 2.5 Benefits

| Benefit | Detail |
|---------|--------|
| Mobility | same IP |
| Scaling | routing table split |
| Policy | mapping control |
| Interop | PxTR |

- LISP **decouples routing scale** from endpoint movement.

## 5. Exam Traps

- LISP = **EID (identity) vs RLOC (location)**.
- Roles: **ITR/ETR (edges), MR/MS (control), PxTR (interop)**.
- Map lookup = **control plane**; encap = data plane.
- It's the **SD-Access control plane** (host mobility).
- Host keeps IP while roaming.
