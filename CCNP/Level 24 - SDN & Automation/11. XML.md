# XML

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**XML** (eXtensible Markup Language) is the **tag-based** data format used by **NETCONF**
and legacy APIs. Every value is wrapped in **opening/closing tags**; attributes add
metadata. It's verbose but strict — and it's what NETCONF RPCs are written in. The exam
contrasts XML with JSON.

---

## 2. Core Concepts

### 2.1 XML structure

| Element | Syntax |
|---------|--------|
| Element | `<tag>value</tag>` |
| Attribute | `<tag attr="v">` |
| Root | single document root |
| Nested | child elements |
| Namespace | `xmlns` |

- Everything is **nested elements with tags**.

### 2.2 Example

```xml
<device name="R1">
  <interfaces>
    <interface>
      <name>Gi1</name>
      <enabled>true</enabled>
    </interface>
  </interfaces>
</device>
```

- `device` is the root; `interfaces` contains repeated children.

### 2.3 Rules

| Rule | Detail |
|------|--------|
| Well-formed | matching tags |
| One root | single document |
| Case | tags case-sensitive |
| Escape | &amp; &lt; &gt; |
| Attribute | quoted values |

- A missing closing tag breaks **well-formedness**.

### 2.4 XML in networking

| Use | Detail |
|-----|--------|
| NETCONF | RPCs in XML |
| YANG | XML encoding |
| Legacy | SOAP/SNMP-ish |
| Config | device data |

- **NETCONF carries everything as XML RPCs** (note 08).

### 2.5 XML vs JSON

| Aspect | XML | JSON |
|--------|-----|------|
| Tags | verbose | compact |
| Types | text | native |
| Attributes | yes | no |
| Comments | yes | no |
| Popularity | legacy | modern |

- **XML = strict/verbose; JSON = light/modern.**

### 2.6 Parsing (Python)

```python
import xml.etree.ElementTree as ET
root = ET.fromstring(payload)
print(root.find("name").text)
```

- ElementTree navigates the tag tree.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Parse error | unmatched tag | well-formed |
| Wrong node | path | find/iter |
| Attribute lost | quoting | quotes |
| Namespace | missing xmlns | ns map |
| Escape | raw & | escape |
