# YAML

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**YAML** ("YAML Ain't Markup Language") is a **human-friendly data format** based on
**indentation** — used heavily by **Ansible** (playbooks/inventory) and config files.
It maps cleanly to JSON/Python structures. The exam expects you to read YAML and spot
indentation/quoting mistakes.

---

## 2. Core Concepts

### 2.1 YAML basics

| Element | Syntax |
|---------|--------|
| Mapping | `key: value` |
| List | `- item` |
| Nesting | indentation |
| Comments | `#` |
| Strings | quotes optional |

- **Indentation defines structure** — spaces, not tabs.

### 2.2 Example

```yaml
device: R1
interfaces:
  - name: Gi1
    enabled: true
  - name: Gi2
    enabled: false
asn: 65000
```

- `interfaces` is a **list of mappings** — the classic Ansible/device structure.

### 2.3 Rules to remember

| Rule | Detail |
|------|--------|
| Spaces | not tabs |
| Consistency | same indent level |
| Quote | special chars (`:`, `#`) |
| Booleans | true/false |
| Null | null/~ |

- **Tabs and mixed indent = parse errors.**

### 2.4 YAML in networking

| Use | Detail |
|-----|--------|
| Ansible | playbooks + inventory |
| Terraform | HCL is similar |
| Config | files/values |
| SDN | DNA Center exports |

- YAML is the **config/playbook language** of automation.

### 2.5 YAML vs JSON

| Aspect | YAML | JSON |
|--------|------|------|
| Readability | human | moderate |
| Braces | none | yes |
| Indent | key | braces |
| Comments | yes | no |

- **YAML = readable; JSON = compact/standard** — YAML converts to JSON.

### 2.6 Python handling

```python
import yaml
data = yaml.safe_load(text)   # YAML -> dict/list
yaml.safe_dump(data)
```

- `yaml.safe_load` converts YAML to Python objects.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Parse error | tabs/indent | spaces |
| Wrong value | quoting | quote |
| Key missing | nesting | indent level |
| Boolean issue | "yes" | true/false |
| Alias | anchors | expand |

## 5. Exam Traps

- YAML = **indentation-based**; no braces; spaces not tabs.
- **Ansible playbooks/inventory** are YAML.
- Lists `- item`, mappings `key: value`.
- Quote special characters.
- `yaml.safe_load` parses to Python.
