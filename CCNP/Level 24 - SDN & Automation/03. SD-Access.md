# SD-Access

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SD-Access** is Cisco's **intent-based campus fabric**. It builds a **VXLAN overlay**
(data plane) with a **LISP control plane** and **ISE policy**, orchestrated by **DNA
Center**. It delivers **macro/micro segmentation**, host mobility, and **policy-driven
access** across the wired+wireless campus.

---

## 2. Core Concepts

### 2.1 The three planes

| Plane | Technology |
|-------|-----------|
| Control | LISP |
| Data | VXLAN |
| Policy | ISE + SGT |

- **LISP routes; VXLAN tunnels; ISE decides access.**

### 2.2 Fabric roles

| Role | Device |
|------|--------|
| Fabric edge | access switch |
| Border | to outside/legacy |
| Control plane | LISP map server |
| Fabric WLC | wireless |

- **Edge = entry; border = exit; control = mapping.**

### 2.3 Macro vs micro segmentation

| Type | What | Tool |
|------|------|------|
| Macro | VN (VRF) | VXLAN |
| Micro | SG (trust) | ISE/SGT |

- **Macro = separate networks; micro = security groups inside them.**

### 2.4 Why it helps

| Benefit | Detail |
|---------|--------|
| Policy | group-based |
| Mobility | anywhere |
| Segmentation | simplified |
| Automation | intent-based |

- **Hosts keep IPs while roaming**; policy follows the group, not the VLAN.

### 2.5 Key components

| Component | Detail |
|-----------|--------|
| VXLAN | data plane tunnels |
| LISP | EID ↔ RLOC mapping |
| ISE | AAA + SGT |
| DNA Center | orchestration |

- **VXLAN (04) + LISP (05) + ISE + DNA Center** = the SD-Access stack.

## 5. Exam Traps

- SD-Access = **LISP (control) + VXLAN (data) + ISE (policy) + DNA Center**.
- **Macro = VN/VRF; micro = SGT**.
- Fabric roles: **edge, border, control plane**.
- Host **keeps IP** while roaming.
- Policy is **group-based**, not VLAN-based.
