# Ansible

> **Level 24 · SDN & Automation** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Ansible** is a **push-based, agentless** automation tool. Playbooks (**YAML**) run
**modules** against inventory hosts over **SSH**. For networking, modules like
`ios_command`, `ios_config`, and `restconf/ncclient` configure devices. The exam tests
the playbook structure and core concepts.

---

## 2. Core Concepts

### 2.1 Agentless push model

| Item | Detail |
|------|--------|
| Agent | none on device |
| Transport | SSH (networking) |
| Control | Ansible controller |
| Inventory | list of hosts |

- Ansible **pushes** from the controller — nothing installs on the device.

### 2.2 Key components

| Component | Detail |
|-----------|--------|
| Playbook | YAML tasks |
| Inventory | hosts/groups |
| Module | unit of work |
| Task | one module run |
| Play | tasks on hosts |

- **Playbook = the automation recipe.**

### 2.3 Playbook example

```yaml
- hosts: routers
  connection: network_cli
  tasks:
    - name: Set banner
      ios_config:
        lines:
          - banner motd ^Welcome^
```

| Keyword | Meaning |
|---------|---------|
| hosts | target group |
| connection | network_cli/ssh |
| tasks | list of modules |
| ios_config | Cisco module |

### 2.4 Network modules

| Module | Use |
|--------|-----|
| ios_command | run show |
| ios_config | push config |
| ios_facts | gather state |
| ios_l3_interface | structured |
| restconf/ncclient | YANG |

- **ios_facts** + structured modules enable **idempotent** config.

### 2.5 Idempotency

| Item | Detail |
|------|--------|
| What | same result each run |
| Benefit | safe to re-run |
| How | check desired state |
| Role | config as code |

- **Idempotent** playbooks don't duplicate config.

### 2.6 Verification

```bash
ansible-playbook playbook.yaml
ansible-inventory --list
ansible routers -m ping
```

- `ansible-playbook` runs; `-m ping` tests reachability.

## 3. Configuration / Commands

```bash
ansible-playbook -i inventory site.yaml
ansible-inventory --list
ansible routers -m ios_command -a "commands='show version'"
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Unreachable | SSH/auth | -m ping |
| Module missing | collection | install |
| Parse error | YAML | indent |
| Idempotency | state drift | ios_config |
| Privilege | enable | provider |

## 5. Exam Traps

- Ansible = **agentless, push, SSH**.
- **Playbook = YAML; modules = ios_config/ios_command**.
- Inventory lists hosts; `network_cli` for devices.
- **Idempotent** = safe to re-run.
- `ios_facts` gathers state for structured config.
