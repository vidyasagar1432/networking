# Object Tracking

> **Level 14 · First Hop Redundancy** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Object tracking** links a **condition** (interface up/down, IP SLA, route existence) to
an **action** (HSRP/VRRP/GLBP priority, static route max-metric, PBR). It's what makes
FHRP react to **upstream** failures, not just local link loss — turning a dumb redundancy
scheme into a smart one.

---

## 2. Core Concepts

### 2.1 The object → action pattern

```
track OBJECT_ID TYPE [parameter]
...
action using the object (priority decrement, route, PBR next-hop)
```

- Define the track, then reference it in the FHRP config.

### 2.2 Types of tracked objects

| Track | Watches | Example |
|-------|---------|---------|
| interface line-protocol | interface state | `track 1 interface Gi0/1 line-protocol` |
| interface ip routing | routing enabled | `track 2 interface Gi0/1 ip routing` |
| ip route | route existence | `track 3 ip route 10.0.0.0 255.0.0.0 reachability` |
| ip sla | reachability probe | `track 4 ip sla 10` |
| list | boolean combine | `track 5 list boolean and` |

- **IP SLA** tracks remote reachability beyond the local link.

### 2.3 Tracking in HSRP/VRRP/GLBP

```text
track 1 interface Gi0/1 line-protocol
track 2 ip sla 10

interface Gi0/0
 standby 10 ip 10.0.0.1
 standby 10 priority 110
 standby 10 track 1 decrement 20
 standby 10 track 2 decrement 15
```

- Both tracks fail → priority drops 35 → router likely loses Active/Master/AVG.
- VRRP: `vrrp 10 track 1 decrement 20`
- GLBP: `glbp 10 track 1 decrement 30` (affects **weighting**, not priority).

### 2.4 Track states

| State | Meaning |
|-------|---------|
| up | condition satisfied |
| down | condition failed |
| not present | object not known yet |

- `show track` reports each object's state and the subscribers.

### 2.5 Thresholds (GLBP weighting)

```text
track 1 interface Gi0/1 line-protocol
glbp 10 weighting 110 lower 80 upper 100
glbp 10 track 1 decrement 40
```

- **lower** (80): weighting below → AVF inactive.
- **upper** (100): weighting above → AVF active again.
- Weighting = initial value minus active decrements.

### 2.6 Other uses of tracking

| Use | Syntax |
|-----|--------|
| Static route | `ip route 0.0.0.0 0.0.0.0 Gi0/1 track 1` |
| PBR next-hop | `set ip next-hop verify-availability` |
| NAT / redistribution | via route benchmark |

- Object tracking extends beyond FHRP into routing and PBR.

```text
show track
show track brief

```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No priority drop | object never referenced | subscriber command |
| Track stays down | wrong interface / object | show track |
| FHRP flaps | decrement too large | tune decrement |
| Weighting 0 | track decrement > initial | keep lower threshold sane |
| No reaction to uplink loss | no track at all | add it |

---

## 5. Exam Traps

- Tracking turns **local** awareness into **upstream** awareness.
- HSRP/VRRP decrement **priority**; GLBP decrements **weighting**.
- `track 1 interface Gi0/1 line-protocol` = the classic uplink watch.
- IP SLA tracks **end-to-end** reachability.
- Object must be **referenced** (standby track / glbp track) to matter.
- `show track` verifies state + subscribers.
