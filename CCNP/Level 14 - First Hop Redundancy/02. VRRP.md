# VRRP (Virtual Router Redundancy Protocol)

> **Level 14 · First Hop Redundancy** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**VRRP** is the **open standard** (RFC 3768) FHRP — Cisco's HSRP alternative for
multi-vendor networks. It uses a **virtual router ID (VRID)** and a **virtual IP** owned
by the **master** router; the **backup** takes over on failure. Protocol = **IP protocol
112, multicast 224.0.0.18**. VRRP lets one Master and one-or-more Backups share one VIP.

---

## 2. Core Concepts

### 2.1 Roles and priorities

| Role | Priority | State |
|------|----------|-------|
| Master | highest (default 100) | forwards for VIP |
| Backup | lower | monitors, takes over |
| Init | boot or no VIP | — |

- Priority default **100**; tie-break = **highest IP** (like HSRP but IPv4 addr).
- `preempt` default **on** for master recovery (differs from HSRP).

### 2.2 Virtual MAC and addresses

| Field | Value |
|-------|-------|
| Virtual MAC | `0000.5e00.01XX` (XX = VRID) |
| VRID range | 1–255 |
| Helper addr | optional |

- The master holds the virtual IP **on a real interface** (VRRP "owns" it) or as address
  on the VRID; backups track its hellos.

### 2.3 Timers (VRRP adverts)

| Timer | Default |
|-------|---------|
| Advertisement interval | 1 s |
| Master down | 3 × interval |

- Backup declares master-down after missing 3 adverts.
- Failover usually faster/simpler than HSRP defaults (1 s vs 3 s hello).

### 2.4 Configuration

```text
interface Gi0/0
 vrrp 10 ip 10.0.0.1
 vrrp 10 priority 110
 vrrp 10 preempt
 vrrp 10 track 1 decrement 20
!
track 1 interface Gi0/1 line-protocol
```

- `track` decrements the priority when the object fails (note 04).
- `preempt` restores Master when priority recovers (default on).
- Multiple VRIDs enable load sharing.

### 2.5 VRRP vs HSRP at a glance

| Item | HSRP | VRRP |
|------|------|------|
| Standard | Cisco | RFC 3768 |
| Protocol | UDP 1985 | IP 112 |
| Multicast | 224.0.0.2 | 224.0.0.18 |
| VIP MAC | 0000.0c07.acXX | 0000.5e00.01XX |
| Preempt | off (config) | on (default) |
| Masters | 1 | 1 (with backups) |

- Exam asks the **differences** — memorize the two oscilloscope rows.

### 2.6 Master/backup behavior

- Backup only answers if master's adverts stop (3 × interval).
- With `preempt`, a recovered master reclaims immediately.
- No concept of "speaker" — VRRP is a simpler master/backup model.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Two masters | advert blocked / split VLAN | show vrrp both sides |
| No takeover | advert interval mismatch | timers equal |
| VIP not answering | VRID/IP mismatch | interface vrrp |
| Flap | preempt + priority race | preempt wording |
| Track ignore | no track configured | track 1 |

---

## 5. Exam Traps

- VRRP = **open standard** (IP protocol 112, 224.0.0.18).
- Virtual MAC `0000.5e00.01XX` (VRID).
- Default priority **100**; tie = highest IP.
- **Master-down = 3 × advert interval**.
- **Preempt default ON** (opposite of HSRP).
- VIP can be the **real address** of the master (owner) — HSRP never does this.
