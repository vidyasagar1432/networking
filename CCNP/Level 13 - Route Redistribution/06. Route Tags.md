# Route Tags

> **Level 13 · Route Redistribution** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Route tags** label routes as they enter a protocol, letting downstream routers identify
their **origin** and apply policy (filter, metric, AD) consistently. Tags survive
redistribution boundaries and are the core tool for **loop prevention** (note 08): tag
routes entering EIGRP as "from OSPF", then match that tag to keep them from being sent
back.

---

## 2. Core Concepts

### 2.1 What a tag is

| Protocol | Tag field |
|----------|-----------|
| OSPF | external route tag (LSB of route-ID-style, 32-bit) |
| EIGRP | route tag (32-bit) |
| BGP | community (tag analog) |
| RIP | route tag (16-bit) |

- One numeric value (e.g., `100`) carried inside the route's advertisement.

### 2.2 Setting tags at redistribution

```text
route-map ENABLE-TAG permit 10
 match ip address prefix-list OSPF-ONLY
 set tag 100

router eigrp CAMPUS
 address-family ipv4 unicast autonomous-system 100
  topology base
   redistribute ospf 1 route-map ENABLE-TAG
```

- Matched routes leave the boundary carrying tag `100`.

### 2.3 Matching tags downstream

```text
route-map CATCH-TAG permit 10
 match tag 100
 set metric 10000 100 255 1 1500
```

- `match tag` picks routes by number; used in `route-map`, `distribute-list`, filters.

### 2.4 Tagging for loop prevention (the classic)

| Step | Action |
|------|--------|
| 1 | Tag OSPF routes entering EIGRP as `100` |
| 2 | On EIGRP→OSPF redistribution, deny tag `100` |
| 3 | Result: OSPF routes never bounce back into EIGRP |

- This breaks the redistribution feedback loop deterministically.

### 2.5 Tagging vs communities

| Aspect | Route tag | BGP community |
|--------|-----------|---------------|
| Scope | single numeric field | 4-byte ASN:value |
| Where | IGP routes | BGP path attribute |
| Purpose | origin/policy marker | richer policy + transitive |
| Cross IGP | yes (OSPF/EIGRP) | yes (BGP) |

- Both serve the same "mark the origin" job in their own protocols.

### 2.6 Administrative uses

| Use | Tag value scheme |
|-----|------------------|
| Origin AS | tag = AS number |
| L3VPN / MPLS | VPN tag |
| Customer route | per-customer value |
| Deny lists | reserved range (e.g., 4290000000+) |

```text
show ip route <prefix>          ! shows tag if present
show ip eigrp topology          ! tag field
show ip ospf database           ! external routes carry tags
show ip protocols
show ip bgp community           ! BGP analog
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Policy not applied | tag not set / matched wrong value | match tag / set tag |
| Tag lost | not set at redistribution | route-map applied |
| Loop returns | filter missing | tag-based deny note 08 |
| Tag mismatch | different values per boundary | standardize |

---

## 5. Exam Traps

- Tags must be **set at the boundary** and **matched downstream**.
- OSPF carries tags **only on external (E1/E2)** routes.
- `match tag` requires the route-to-be to carry the tag exactly.
- Tags are the backbone of **loop prevention** designs.
- BGP's tag-analog is the **community**.
