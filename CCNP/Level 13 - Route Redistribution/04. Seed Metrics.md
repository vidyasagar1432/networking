# Seed Metrics in Redistribution

> **Level 13 · Route Redistribution** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

Every redistributed route enters the receiving protocol with a **seed metric** — the
initial metric the boundary router assigns. Each protocol requires different seed values;
giving **no seed metric** makes redistributed routes **unusable** (EIGRP/OSPF reject them
or treat them as max). The exam loves the EIGRP 5-tuple and the OSPF `subnets` + default-metric
pairing.

---

## 2. Core Concepts

### 2.1 Default seed metrics per protocol

| Protocol | Default seed metric | Effect if untouched |
|----------|---------------------|---------------------|
| EIGRP | **none** — routes not advertised | invisible |
| OSPF | `auto-cost` / 20 for external | appears as E1/E2 with default cost |
| BGP | MED default 0 | provider prefers 0 (attractive!) |
| RIP | 16 direct of 1-hop | metric 1 |
| IS-IS | 0 | metric 0 |

- **EIGRP has no default seed** — the #1 redistribution exam point.

### 2.2 The EIGRP five-part metric

```
redistribute ospf 1 metric BANDWIDTH DELAY RELIABILITY LOAD MTU
```

| Component | Unit / range | Meaning |
|-----------|--------------|---------|
| bandwidth | kbps | lowest link speed |
| delay | µs / 10 | cumulative latency |
| reliability | 0–255 | 255 = perfect |
| load | 0–255 | 1 = idle |
| MTU | bytes | max frame |

- Example: `metric 10000 100 255 1 1500` — common starting values.

### 2.3 Setting via default-metric

```text
router eigrp CAMPUS
 address-family ipv4 unicast autonomous-system 100
  topology base
   default-metric 10000 100 255 1 1500
```

- `default-metric` applies the seed to **every** redistributed source at once.

### 2.4 OSPF seed specifics

```text
router ospf 1
 default-metric 50
 redistribute eigrp 100 subnets
   metric 75
   metric-type 1
```

| Keyword | Effect |
|---------|--------|
| `metric` | cost assigned |
| `metric-type 1` | E1 (cost accumulates) |
| `metric-type 2` | E2 (cost ignored in AS, default) |
| `subnets` | redistribute **all** prefixes, not just classful |

- Without `subnets`, only **classful** routes redistribute — losing CIDR subnets.

### 2.5 BGP seed (MED)

```text
router bgp 65001
 redistribute ospf 1 metric 100     ! MED = 100
```

- MED 0 (default) is dangerously attractive; set a positive MED for external routes.

### 2.6 Matching seeds consistently at both boundaries

| Direction | Seed |
|-----------|------|
| OSPF → EIGRP | EIGRP 5-tuple on EIGRP router |
| EIGRP → OSPF | cost on OSPF router |
| Multi-homed | consistent MEDs to avoid asymmetric flows |

- **Asymmetry**: the metric chosen on one side does not retro-act on the other.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| EIGRP routes missing | no seed metric | default-metric / metric |
| OSPF only classful | no subnets | add subnets |
| E2 cost surprises | metric-type 2 | use metric-type 1 |
| MED 0 provider attract | no metric set | set metric |
| Ugly metrics | bandwidth/delay default | tune 5-tuple |

---

## 5. Exam Traps

- **EIGRP = no default seed** — must supply it.
- OSPF needs **`subnets` + `default-metric`/`metric`**.
- E2 (default) ignores cost accumulation; E1 accumulates.
- BGP MED default 0 — set a value to be “less attractive”.
- The EIGRP metric order is **BW, delay, reliability, load, MTU**.
