# OSPF to BGP Redistribution

> **Level 13 · Route Redistribution** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

Injecting **OSPF routes into BGP** is how an enterprise advertises internal networks to
service providers. It is performed with `redistribute ospf` (or the cleaner `network`
statements that match BGP-table routes). The two big BGP specifics: the **MED** is set
from the OSPF metric, and BGP **origin** becomes `?` (incomplete) when using
`redistribute` instead of `network`.

---

## 2. Core Concepts

### 2.1 The two injection methods

| Method | Origin | MED |
|--------|--------|-----|
| `network` statements | `i` (IGP) | from OSPF metric |
| `redistribute ospf` | `?` (incomplete) | from OSPF metric |

- `network` requires the route to be **present in the BGP table** (from `network` or
  another source).
- `redistribute` injects regardless — no prior BGP entry needed.

### 2.2 Configuration

```text
router bgp 65001
 redistribute ospf 1 metric 100
```

- Sets MED = 100 for redistributed OSPF routes (default MED = 0 otherwise).

### 2.3 Filtering what enters BGP

```text
route-map OSPF-TO-BGP permit 10
 match ip address prefix-list ADVERTISE
 set metric 150

router bgp 65001
 redistribute ospf 1 route-map OSPF-TO-BGP
```

- Route-maps select prefixes and set attributes (MED, communities, local-pref).

### 2.4 Origin attribute impact

| Origin | Value | Preferred |
|--------|-------|-----------|
| `i` | 0 | yes (best path step 5) |
| `e` | 1 | |
| `?` | 2 | no |

- `redistribute` makes routes origin `?` — a neighbor preferring `i` origin may rank yours
  lower.

### 2.5 Interaction with OSPF types

- Both **intra-area and inter-area** OSPF routes redistribute by default.
- **External** OSPF routes need care — filter to avoid re-advertising provider-learned
  routes back (note 08).
- `redistribute ospf match internal external 1 external 2` selects specific types.

### 2.6 Best practice: `network` + `redistribute` for connected

```text
router bgp 65001
 network 10.0.0.0 mask 255.0.0.0      ! precise, origin i
 redistribute connected route-map CONNECTED
```

- Precise advertisement + origin `i` for everything you want to announce.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No OSPF routes in BGP | no network/redistribute | show ip bgp |
| Origin `?` surprises | used redistribute | switch to network |
| MED all zero | no metric set | set metric / route-map |
| External routes leaked | no filter | route-map match |
| Wrong prefixes | route-map miss | show route-map counters |

---

## 5. Exam Traps

- `redistribute` → origin `?`; `network` → origin `i` — the classic origin trap.
- **MED inherits the OSPF metric** unless `metric` overrides.
- External OSPF routes **should be filtered** from BGP redistribution.
- BGP route must **already exist** for `network` to advertise it.
