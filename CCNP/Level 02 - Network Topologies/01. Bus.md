# Bus Topology

> **Level 02 · Network Topologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

In a **bus** topology, all devices share a single transmission medium — originally a
coaxial cable (10BASE2/10BASE5 "thicknet"/"thinnet"). Every frame travels the whole
cable and every node sees it; one shared collision domain and one broadcast domain.

---

## 2. Core Concepts

### 2.1 How it worked
- One backbone cable; taps/transceivers attach nodes (10BASE2: BNC T-connectors daisy-chained; 10BASE5: vampire taps).
- **CSMA/CD** arbitrated access — all nodes on the bus were in one **collision domain**.
- Terminators at both ends absorb signals (missing terminator → reflections, "network gone").

### 2.2 Characteristics

| Property | Value |
|----------|-------|
| Collision domain | 1 (all nodes) |
| Broadcast domain | 1 |
| Failure mode | Any break splits the bus; a short can bring the whole segment down |
| Bandwidth | Shared — all nodes divide the 10 Mbps |
| Security | Every node can see all traffic (promiscuous capture) |
| Cost | Cheap; legacy only |

### 2.3 Why it died
- Single point of failure (cable break), poor fault isolation, security exposure,
  scalability ceilings, half-duplex on shared medium.
- Replaced by **twisted-pair star wiring to switches** (physical bus gone; only
  discussion value).

### 2.4 Conceptual relevance to modern switching
The "broadcast/collision domain" concept originated here:
- A **hub** recreates a bus (all nodes same collision domain).
- A **switch** microsegments — each port a separate collision domain (Level 04).
- The exam uses "bus == one shared collision domain" as a definition of the model.

## 4. Exam Traps

- **Bus = one collision domain AND one broadcast domain** (unless many VLANs separated it).
- **A cable break kills the entire bus** — that's the classic "get rid of bus" argument.
- **Don't confuse "bus" with a logical L3 structure** — modern routers use "bus" only in old chassis backplanes.
- **CSMA/CD** is the media-arbitration protocol of bus/half-duplex; it does not exist on switched full-duplex links.
