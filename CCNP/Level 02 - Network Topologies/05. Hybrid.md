# Hybrid Topology

> **Level 02 · Network Topologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **hybrid topology** combines two or more base topologies (bus, star, ring, mesh,
tree) in one network. Real networks are almost always hybrids: the term means "this
deployment mixes topologies," not a topology in itself.

---

## 2. Core Concepts

### 2.1 Common combinations

| Hybrid | Composition | Where it appears |
|--------|-------------|------------------|
| **Star-bus / tree** | Endpoint stars to hubs, hubs daisy-chained on a backbone | Classic campus; the standard "tree" |
| **Star-ring** | Star wiring, logical ring (MAU/token) | Legacy token-ring wiring |
| **Star-mesh** | Access stars; backbone/DC in mesh | Modern enterprise (spine-leaf is star+mesh) |
| **Bus-drop** | Backbone bus with star subnets | Older thicknet campuses |
| **Wireless mesh + star** | APs in star to switch, radio mesh for ext | Mixed wireless designs |

### 2.2 Why hybrid is the norm
- **Functional blocks** use what fits: access = star (cheap/simple), core = mesh
  (redundant paths), WAN = partial mesh, wireless = mesh where needed.
- **Modularity** allows each module to choose its own topology and mate at the core/distribution.
- Fault isolation tends to improve if the hybrid is hierarchical (stars) and redundancy
  comes from mesh at the core.

### 2.3 Design guidance (exam-friendly)
- **Keep the complex part (mesh/ring) at the core/backbone only.**
- **Access stays star-hierarchical** — predictable, easy to manage.
- **Each block isolates failures** — a bus-like backbone is an anti-pattern; replace with
  redundant star/mesh.
- Always include **redundant links + STP/ECMP control** for any mesh-flavored area.

## 3. Configuration / Commands

```text
# In a hybrid campus you simply configure each interface type:
# Star access port
interface Gi0/1
 switchport access vlan 10
 spanning-tree portfast

# Mesh-ish core: physical star wide/partial; the switch sees ordinary links
interface TenGigabitEthernet1/1
 description to CORE-A
 ip address 10.0.1.1 255.255.255.252
```

---

## 4. Exam Traps

- **"Hybrid" is a description, not one fixed wiring pattern.** Look for which base
  topologies are combined in the scenario.
- **Star-mesh vs star-bus**: exam questions describe roles of each block
  (access=star, core=mesh) and ask what that is — answer "hybrid (star + mesh)".
- **Don't apply STP thinking only to pure mesh; any L2 loop needs loop control.**
- **Terminator/ring-monitor talk** only applies to the respective legacy component —
  each piece keeps its own failure properties.
