# Two-Tier (Collapsed Core)

> **Level 02 · Network Topologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Two-tier** merges the distribution and core into a single **collapsed core** layer
on top of the access layer. Fit for small/medium sites: fewer devices, lower cost,
simpler operations, while keeping routing/policy centralization. This is what most
real branch or small-campus designs use.

---

## 2. Core Concepts

### 2.1 The two tiers

| Tier | Role | Typical device |
|------|------|----------------|
| **Access** | Endpoints, VLAN ports, PoE | L2/L3 access switches |
| **Collapsed core/distribution** | Inter-VLAN routing, default gateways, WAN edge, policy | L3 switch/router pair (HA) |

In this design the "distribution+core" block does everything the 3-tier distribution
did, plus the core's fast backbone role.

### 2.2 Why choose two-tier
- **Cost & simplicity** — fewer chassis, easier licensing and ops.
- **Small site scale** — the amount of traffic doesn't justify a separate core.
- **Faster convergence** — fewer router hops to converge on failures.
- Good for: branch offices, remote sites, SMB campus, small DCs.

### 2.3 Failure/HA in the collapsed block
- The collapsed core is the **single critical point** — deploy it as an **HSRP/VRRP
  pair with dual uplinks** from every access switch (Level 14).
- Access switches **dual-home** to the two cores (EtherChannel or L2 trunk; run STP).
- Consider **routed access (L3 to the access edge)** for full convergence speed —
  then each access switch is its own L3 device with ECMP to cores.

### 2.4 When to move to three-tier
- > 5k users, multiple buildings, heavy core aggregation, strict segmentation,
  or where the campus core and the WAN/complete functions diverge
  (then a dedicated core siloizes the load). See [[08. Three-Tier]].

## 3. Configuration / Commands

```text
# Collapsed core = L3 switch pair, default gateway for VLAN 10
interface Vlan10
 ip address 10.1.10.1 255.255.255.0
 no shutdown
standby 10 ip 10.1.10.254
standby 10 priority 110

# Access switch dual-homes (two uplinks to the pair)
interface GigabitEthernet0/23
 switchport trunk encapsulation dot1q
 switchport mode trunk
 channel-group 1 mode active        # EtherChannel to core-A
```

## 4. Exam Traps

- **"Collapsed core"** is the exam term for two-tier — memorize that synonym.
- **Two-tier puts routing at the distribution/core merger** — not at access.
- **The SPOF is the collapsed core** — a single-core two-tier fails hard; HA pair required for the "best design" answer.
- **Don't describe a two-tier + WAN distribution as three-tier** — count only the
  campus L3 tiers separating hosts from the WAN edge if they're merged.
- **Access still uses VLANs + STP** unless you've gone fully routed.

## 5. Quick Review Table

| Aspect | Two-tier | Note |
|--------|----------|------|
| Layers | Access + collapsed core | Distribution merged into core |
| Cost | Low | SMB/branch |
| Convergence | Fast | Fewer hops |
| Guideline | Always HA the pair | HSRP/VRRP, dual uplinks |
| Ruling when | < campus-scale | Large → three-tier |
| Choose routed access | Optional | Fastest convergence |
