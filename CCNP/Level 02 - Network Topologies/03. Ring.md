# Ring Topology

> **Level 02 · Network Topologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

In a **ring** topology every device connects to exactly two neighbors, forming a
closed loop. Frames travel in one direction (token ring / FDDI) around the ring.
Physically, modern rings are often implemented with **ring-of-stars** wiring (each
node is a hub/switch; the hubs themselves form the logical ring).

---

## 2. Core Concepts

### 2.1 Logical vs physical
- **Logical ring** — data circulates in a defined path regardless of physical wires.
- **Physical star-ring** — token ring (IBM, 16 Mbps) wired each node to a MAU; the
  MAU closed the ring internally. Exam-relevant detail: "ring logic, star wiring."

### 2.2 Examples

| Technology | Details |
|-----------|---------|
| **Token Ring (IEEE 802.5)** | 4/16 Mbps; token passing controls access; each station has a MAC address (48-bit); deterministic access; legacy |
| **FDDI** | 100 Mbps dual counter-rotating rings; survived as campus backbone legacy |
| **Metro ring networks** (SONET/SDH / Metro Ethernet) | Resilience: traffic can redirect the other way on a fiber cut (Level 23) |

### 2.3 Controlled access (token)
- A small "token" frame circulates; a station with the token may send one frame, then
  passes the token on. In a **single-token** ring only one station transmits at a time —
  deterministic, no collisions.
- **Ring monitor / active monitor** watches for lost tokens (failures).

### 2.4 Pros / cons

| Pros | Cons |
|------|------|
| No collisions (token, up to 16 Mbps) | One break in a single ring = entire ring down (loop breaks) |
| Deterministic delay for real-time traffic | Hard to add/remove nodes |
| FDDI dual ring self-heals | Expensive, complex; not Ethernet |
| No bandwidth contention under light load | Legacy; replaced by switched Ethernet |

## 4. Exam Traps

- **Ring = token-passing media access, NOT CSMA/CD** — the shared-access question.
- **Physical layout can be star; the *logic* is a ring** — don't say "it must be wired in a circle."
- **Single ring halves on a break; dual-ring (FDDI) survives.**
- **Never mention "collisions in a token ring."**
- Ring is a topology of the **physical/distribution layer** in legacy networks; modern
  switches use STP trees, not rings (except Metro rings).
