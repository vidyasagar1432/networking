# Enterprise Campus

> **Level 02 · Network Topologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **enterprise campus** is the full in-building/between-buildings network serving
users, plus its server, WAN, and security modules. It is not one topology — it
assembles **three-tier hierarchy, star access, mesh-ish cores**, and modules
(server farm, WAN edge, wireless, DMZ) into a resilient, segmentable whole.

---

## 2. Core Concepts

### 2.1 The campus "blocks"

| Block | Purpose | Topology flavor |
|-------|---------|-----------------|
| Campus core | Backbone between buildings | Routed mesh / collapsed |
| Distribution | Per-building aggregation + policy | Dual switch pair (HSRP) |
| Access | Endpoints, VLANs, wireless APs | Star |
| Server farm / DC | Compute & storage | Spine-leaf (modern) or 3-tier |
| WAN edge | MPLS/SD-WAN/Internet | Partial mesh / hub-spoke |
| DMZ | Public-facing servers | Two-arm to firewalls |
| Management | OOB, NMS, NetOps | Dedicated VLAN/VRF |

### 2.2 Design goals (shared with Level 00)
- **HA everywhere**: dual core, dual dist, dual home access; HSRP/VRRP; port
  channeling; redundant PSUs — all about **removing single points of failure**.
- **Fast convergence**: routing protocols with summaries; RSTP on L2; first-hop
  redundancy.
- **Segmentation**: VLANs per role + VRF/ACL where security needs them; guest/voice/
  management separated.
- **Manageability**: dedicated management VLAN + OOB (out-of-band) management;
  NetFlow/telemetry feeds NMS/syslog (Level 26).
- **QoS**: trust boundaries at access, marking, priority queuing on uplinks for
  voice/video (Level 21).

### 2.3 Wired vs wireless in the campus
- Wireless today is a **first-class citizen**: APs connect to access switches, CAPWAP
  to WLCs, steering/virtuals. Mobility with the **wireless module** (Level 22).
- Design: SSIDs map to VLANs; roaming anchored at WLC; AAA via RADIUS.

### 2.4 Sample small-campus answer (the classic scenario)
```
              +-------------+  +-------------+
              | CORE A  (L3)|--| CORE B (L3) |
              +------+------+  +------+------+
                     | trunk|         |trunk
                +----+------+----+----+------+----+
                | DIST-L1 (HSRP)  |  DIST-L2        |
                +----+------+----+----+------+----+
                     |L2 trunks
              +------+------+------+
              | ACCESS-1  | ACCESS-2  |
              +------------+----------+
```
VLAN 10 users, VLAN 20 servers, VLAN 30 mgmt, VLAN 40 voice, VLAN 50 guest.

## 3. Configuration / Commands

```text
# Minimal spine of the campus: dist pair with HSRP
interface Vlan10
 ip address 10.1.10.2 255.255.255.0
standby 1 ip 10.1.10.1
standby 1 preempt

# Access: trunk to dist, portfast on hosts
interface GigabitEthernet0/1
 switchport access vlan 10
 spanning-tree portfast

# Core: just routes + fast forwarding (no policy)
ip cef
router ospf 1
 network 10.0.0.0 0.255.255.255 area 0
```

## 4. Exam Traps

- **"Enterprise campus" ≠ "single building star"** — it's the *whole* modular model.
- **Default gateway lives at distribution** (HSRP) — not at the access switch.
- **STP** is only for the L2 spans (access→dist); the core is routed.
- **Always distinguish campus versus DC spine-leaf** — the DC is often its own block
  attached to the campus core.
- **Common full-architecture answer**: "collapsed core for the branch, three-tier for
  the campus, spine-leaf DC attached to the campus core."
