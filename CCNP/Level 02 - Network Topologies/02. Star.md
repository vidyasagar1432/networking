# Star Topology

> **Level 02 · Network Topologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Star** means every device connects point-to-point to a central device (hub or,
in practice, a **switch**). It is the physical foundation of modern Ethernet wiring:
each host has its own UTP link; logical behavior depends on whether the center is a
hub (shared) or a switch (microsegmented).

---

## 2. Core Concepts

### 2.1 Center device decides everything

| Center is a... | Collision domain | Behavior |
|----------------|------------------|----------|
| **Hub** (L1) | One for all nodes | Repeats frames to every port; half-duplex CSMA/CD |
| **Switch** (L2) | One per port | Microsegmentation, full-duplex, MAC learning |
| **Router** (L3) | Isolated per port + subnet boundary | Different L3 networks per interface |

### 2.2 Advantages
- **Fault isolation**: a bad cable/port affects only that link — the rest keep working.
- **Easy adds/moves** — plug into a spare port; no bus taps.
- **Scalable**: add ports/switches; predictable for the enterprise.
- (With a switch): full duplex, per-host bandwidth, security segmentation via VLANs.

### 2.3 Disadvantages
- **Central device = single point of failure** → mitigate with **redundant switches
  + dual-homed hosts/server NICs + HSRP/VRRP gateways** (see Level 14 / Level 27).
- More cabling than bus/ring.
- Physical star, logical bus (if hub) — a trick: wiring is star, logic may be bus.

### 2.4 Where stars appear in enterprise design
- **Access layer**: every endpoint star-wires to its access switch.
- **Spine-leaf** (Level 06): each leaf connects to each spine = a **logical star/mesh hybrid**.
- Collapsed core: two distribution switches = redundant star for each access block.

## 3. Configuration / Commands

```text
# Port that makes the star unit work per-endpoint
interface GigabitEthernet0/1
 switchport access vlan 10
 spanning-tree portfast    # host -> no STP delay

# Redundancy for the central SPOF (design command example)
interface Vlan10
 standby 10 ip 10.1.10.1     # HSRP on distribution pair (Level 14)
```

---

## 4. Exam Traps

- **Star wiring, hub center = physical star but logical bus** (same collision domain).
- **Star is not "automatic full duplex"** — that depends on the center being a switch.
- **SPOF is the center switch** — "redundant switch pair + dual-homed hosts" is the fix.
- **Star ≠ single cable failure** distinguishes it from bus: in star, one cable's break
  isolates only that host.

## 5. Quick Review Table

| Center | L2 effect | Collision domains |
|--------|-----------|-------------------|
| Hub | repeats, shared | 1 (all) |
| Switch | MAC learning, separate per port | N (per port) |
| Router | L3 subnets | Isolated per interface |
| Fault impact | Only the bad link | Better isolation |
| SPOF | The center device | Mitigate: redundancy + HSRP |
| Wiring | Point-to-point to center | More cabling, easier MAC |
