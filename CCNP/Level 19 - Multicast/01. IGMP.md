# IGMP

> **Level 19 · Multicast** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**IGMP** is the **host-to-router** protocol that manages multicast group membership on a
LAN segment (Layer 2/3 boundary). Routers use it to learn **which groups hosts want to
receive**; without members, the router stops forwarding group traffic. Versions matter:
**IGMPv2 (default)** and **IGMPv3 (source filtering)**.

---

## 2. Core Concepts

### 2.1 IGMP versions

| Version | Reports | Leaves | SSM |
|---------|---------|--------|-----|
| v1 | general query | slow (2 min) | no |
| v2 | fastest-leaver | leave group (fast) | no |
| v3 | source-specific | source filtering | yes |

- **v3** supports `include/exclude` **source lists** — needed for SSM (note 03).

### 2.2 Roles on the segment

| Role | Who | Job |
|------|-----|-----|
| Querier | elected router | sends general queries |
| Member | host | sends report |
| Non-member | host | silence |

- One **querier** per LAN — lowest IP wins the election.
- Reports are **multicast to 224.0.0.22** (v2) or 224.0.0.22 group (v3).

### 2.3 Membership workflow

| Step | Packet | Destination |
|------|--------|-------------|
| 1 | query (general) | 224.0.0.1 |
| 2 | report | group address |
| 3 | leave (v2) | 224.0.0.2 |
| 4 | group-specific query | group |

- A host stays a member while it keeps reporting; **no report = timeout**.

### 2.4 How the router uses IGMP

```text
ip multicast-routing
ip pim sparse-mode
interface Gi0/1
 ip igmp version 3
```

| Command | Purpose |
|---------|---------|
| `ip pim sparse-mode` | enables PIM + IGMP on the interface |
| `ip igmp version 3` | force v3 (SSM ready) |
| `ip igmp join-group` | router joins (test) |
| `ip igmp static-group` | static membership |

- **`ip pim sparse-mode`** implicitly enables IGMP snooping behavior on the router.

### 2.5 IGMP snooping (switch layer)

| Item | Detail |
|------|--------|
| What | switch inspects IGMP reports |
| Mrouter port | port facing the router |
| Result | forwards group traffic only to members |
| Benefit | no group flooding to all ports |

- Snooping stops multicast **flooding** on access switches.

### 2.6 Verification

```text
show ip igmp groups
show ip igmp interface
show ip mroute
show ip igmp snooping groups
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No group listed | PIM not enabled | show ip igmp interface |
| Stuck member | no reports | show ip igmp groups |
| Flood to all | snooping off | show ip igmp snooping |
| v3 mismatch | hosts v2 | version config |
| No querier | election/blocked | show ip igmp interface |

---

## 5. Exam Traps

- IGMP = **host → router** membership (LAN side only).
- **IGMPv3** adds **source filtering** → enables **SSM**.
- **`ip pim sparse-mode`** enables IGMP on the interface.
- IGMP snooping is a **switch** feature to stop flooding.
- Fast leave = **IGMPv2** (leave message).
