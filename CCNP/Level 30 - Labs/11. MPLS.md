# MPLS

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **MPLS lab** configures **LDP** on the core, verifies **label bindings and FIB
entries**, and builds an **L3VPN with MP-BGP**. It ties IGP + LDP + BGP together on the
provider edge.

## 3. Configuration / Commands

```text
mpls label protocol ldp
interface Gi0/1
 mpls ip
router ospf 1
 mpls ldp autoconfig
vrf definition CUST
 rd 65000:100
 route-target both 65000:100
router bgp 65000
 address-family vpnv4
  neighbor 10.0.0.2 activate
  neighbor 10.0.0.2 send-community both
show mpls ldp bindings
show mpls forwarding
show bgp vpnv4 unicast
```

## 5. Exam Traps

- **LDP = transport labels; MP-BGP = VPN labels.**
- `mpls ip` on **interfaces** enables LDP.
- MP-BGP needs **send-community**.
- **Two labels** in L3VPN.
- Verify **LDP → FIB → VPNv4**.
