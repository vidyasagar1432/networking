# ISP

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **ISP lab** models a **service provider core** with **eBGP between providers and
customers**, **BGP attributes**, **MPLS transit**, and **traffic engineering**.
It builds the internet-facing skills needed for **SD-WAN underlay + BGP interconnect**
on ENCOR.

---

## 2. Core Concepts

### 2.1 ISP design

| Element | Detail |
|---------|--------|
| IGP | OSPF in AS |
| iBGP | internal |
| eBGP | to customers/peers |
| MPLS | label transit |
| Edge | PE routers |

- **eBGP + MPLS** form the ISP core.

### 2.2 eBGP setup

| Step | Command |
|------|---------|
| 1 | router bgp |
| 2 | neighbor remote-as |
| 3 | next-hop-self iBGP |
| 4 | advertise |
| 5 | filter |

- **eBGP peers = different AS; iBGP = same AS.**

### 2.3 Attributes lab

| Attribute | Action |
|-----------|--------|
| Weight | inbound local |
| Local-pref | outbound |
| AS-path | prepend |
| MED | inter-AS |
| Community | tagging |

- **Attributes shape best-path** toward/away.

### 2.4 MPLS transit

| Step | Command |
|------|---------|
| 1 | OSPF core |
| 2 | LDP |
| 3 | label switching |
| 4 | MP-BGP |
| 5 | L3VPN |

- **LDP + MP-BGP** deliver VPN transit.

### 2.5 Other ISP features

| Feature | Use |
|---------|-----|
| Filtering | prefix-list |
| Route reflectors | scale iBGP |
| Confederation | ASN groups |
| QoS | class transit |
| Traffic eng | tunnels |

- **RR + filters** scale the core.

### 2.6 Verification

| Check | Command |
|-------|---------|
| eBGP | show ip bgp summary |
| MPLS | show mpls ldp bindings |
| VRF | show ip vrf |
| Labels | show mpls forwarding |
| Prefixes | show ip bgp |

- **BGP + LDP** = healthy ISP transit.

## 3. Configuration / Commands

```text
router bgp 65001
 neighbor 10.0.0.2 remote-as 65002
 neighbor 10.0.0.1 remote-as 65000 next-hop-self
mpls label protocol ldp
router ospf 1
 mpls ldp autoconfig
show ip bgp summary
show mpls ldp bindings
```

## 5. Exam Traps

- **eBGP = different AS; iBGP = same AS, next-hop-self.**
- MPLS needs **LDP + MP-BGP** for VPNs.
- **Route reflectors** scale iBGP.
- Attributes direct **best-path**.
- AS-path prepend/MED/community = **traffic control**.
