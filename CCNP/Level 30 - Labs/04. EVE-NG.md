# EVE-NG

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**EVE-NG** (Emulated Virtual Environment Next Generation) is a **web-based lab
platform** that runs real images (IOS, NX-OS, ASA, and third-party VMs) — the go-to
**pro edition is free**, ideal for big multi-vendor CCNP topologies. Browser console +
API.

---

## 2. Core Concepts

### 2.1 What EVE-NG runs

| Type | Use |
|------|-----|
| IOS/IOS-XE | routers |
| NX-OS | switches |
| ASA | firewalls |
| vIOS-L2 | switching |
| Linux VMs | hosts |
| Container | Linux nodes |

- **Real multi-vendor images** on one platform.

### 2.2 Modes

| Mode | Detail |
|------|--------|
| Community | free, basic |
| Pro | free image pool |
| Pro+ | licensed |
| Import | Cisco QCOW |
| Multi-node | scale |

- Community = **free tier**; Pro unlocks image import.

### 2.3 Web UI workflow

| Step | Action |
|------|--------|
| 1 | log in web |
| 2 | add node |
| 3 | connect |
| 4 | boot |
| 5 | console |
| 6 | save topology |

- All from the **browser** — no desktop app.

### 2.4 Scale and features

| Feature | Benefit |
|---------|---------|
| Multi-user | team lab |
| API | automation |
| Snapshots | save states |
| Templates | reuse |
| External net | bridge |

- **Multi-user + API** = team + automation ready.

### 2.5 Requirements

| Item | Detail |

| RAM | many GB |
| Disk | image storage |

- Plan **hardware for node count**.
