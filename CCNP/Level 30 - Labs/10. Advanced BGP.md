# Advanced BGP

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **Advanced BGP lab** practices **iBGP full mesh vs route reflectors**, **attribute
manipulation**, **filtering**, and **advanced features** (communities, confederation).
Core to proving BGP hands-on skill. Verify sessions, paths, and best-path outcomes.

---

## 2. Core Concepts

### 2.1 iBGP scale options

| Method | Use |
|--------|-----|
| Full mesh | small |
| Route reflector | scale |
| Confederation | ASN groups |
| Multihop | non-adjacent |

- **Route reflectors** break iBGP full-mesh limits.

### 2.2 Route reflector

| Role | Detail |
|------|--------|
| RR | client reflector |
| Client | peers to RR |
| Non-client | full mesh |
| Rules | standard |

- **Clients talk to the RR only.**

### 2.3 Attributes practice

| Attribute | Action |
|-----------|--------|
| Weight | highest local |
| Local-pref | outbound |
| AS-path | length/prepend |
| MED | inter-AS |
| Origin | IGP/EGP/inc |
| Community | tagging |

- **Change attributes → change best path.**

### 2.4 Filtering

| Method | Command |
|--------|---------|
| Prefix-list | distribute-list |
| AS-path | ip as-path access-list |
| Community | route-map |
| Filter-list | neighbor filter |

- **Control what you accept/advertise.**

### 2.5 Advanced features

| Feature | Use |
|---------|-----|
| Communities | tagging |
| Confederation | scale |
| Peer groups | config reuse |
| Next-hop-self | iBGP |
| Allowas-in | similar AS |

- **Peer groups** simplify many-neighbor configs.

### 2.6 Verification

| Check | Command |
|-------|---------|
| Sessions | show ip bgp summary |
| Best path | show ip bgp |
| Reflector | show ip bgp rr |
| Routes | show ip route bgp |
| Attr | show ip bgp <net> |

- **Summary → path → installed** chain.

---

## 3. Configuration / Commands

```text
router bgp 65000
 neighbor 10.0.0.1 remote-as 65000
 neighbor 10.0.0.1 route-reflector-client
 neighbor 10.0.0.1 next-hop-self
 neighbor 10.0.0.1 send-community
 neighbor 10.0.0.2 prefix-list FILTER in
 network 10.10.0.0 mask 255.255.255.0
show ip bgp summary
show ip bgp neighbors 10.0.0.1 received-routes
```

## 5. Exam Traps

- **RR = client/non-client** rules.
- **next-hop-self** required for iBGP.
- Filters: **prefix-list, as-path, community, route-map**.
- **send-community** must be set.
- Best path: **weight → local-pref → AS path → MED**.
