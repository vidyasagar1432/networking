# Cisco Packet Tracer

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Cisco Packet Tracer (PT)** is a free, low-fidelity network simulator — great for
**topology practice and ENCOR basics** (L2/L3, routing, wireless, some automation).
It lacks full IOS features (no DMVPN/QoS depth), so treat it as a **learning sandbox,
not a CCNP-grade lab**.

---

## 2. Core Concepts

### 2.1 What PT is good for

| Area | Fit |
|------|-----|
| Campus L2/L3 | good |
| OSPF/EIGRP | good |
| Wireless | basic |
| Basic security | basic |
| Automation | limited |
| Advanced topics | no |

- **Use PT for topology + config practice.**

### 2.2 Limitations vs CCNP

| Feature | PT | CCNP needs |
|---------|-----|-----------|
| DMVPN | no | yes |
| Advanced QoS | no | yes |
| IPsec depth | limited | yes |
| MPLS | no | yes |
| SD-WAN | no | yes |

- **CML/GNS3/EVE-NG** cover the deep topics.

### 2.3 Typical lab flow

| Step | Action |
|------|--------|
| 1 | build topology |
| 2 | cable links |
| 3 | IP + VLANs |
| 4 | routing |
| 5 | verify |
| 6 | save .pkt |

- **Design → cable → configure → verify → save.**

### 2.4 Verification features

| Feature | Use |
|---------|-----|
| Simulation mode | packet animation |
| CLI | full config |
| PDU | follow packet |
| Ping/tr | verify |
| Multiuser | connect peers |

- **Simulation mode** shows packet flow visually.

### 2.5 PT vs other tools

| Tool | PT |
|------|-----|
| Fidelity | low |
| Speed | high |
| Cost | free |
| Real images | no |
| Best for | beginners/ENCOR |

- PT = **fast + free + easy** but shallow.

### 2.6 Tips

| Tip | Why |
|-----|-----|
| Save often | .pkt |
| Use physical | realism |
| Practice CLI | exam style |
| Do labs | repetition |

- Practice the **CLI, not the GUI**.

```text
(no special commands — standard IOS CLI)

```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No link | cable type | physical |
| No route | routing | show ip route |
| Simulation empty | mode | PDU list |
| Wrong IOS | version | device model |

## 5. Exam Traps

- PT **lacks advanced features** (DMVPN/MPLS/SD-WAN).
- Use **CLI**, not GUI, to build exam skills.
- Great for **ENCOR basics** only.
- Save work as **.pkt** files.
- Simulation mode = **visual verification**.
