# GNS3

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**GNS3** is a free GUI that runs **real device images** (IOS, IOS-XE, and any VM) plus
Docker containers. It's flexible and automation-friendly, popular for **CCNP lab
practice** without Cisco licensing. Runs images via QEMU/dynamips.

---

## 2. Core Concepts

### 2.1 What GNS3 runs

| Type | Use |
|------|-----|
| IOS (dynamips) | routers |
| IOS-XE (QEMU) | modern routers |
| Firewalls | ASAv |
| Linux VM | hosts/services |
| Docker | containers |
| VPCS | simple PCs |

- **Mix real images + VMs + Docker.**

### 2.2 Architecture

| Component | Role |
|-----------|------|
| GNS3 server | compute |
| GNS3 GUI | client |
| QEMU | virtualization |
| Dynamips | IOS emulation |
| Docker | containers |

- GUI → **server → emulators**.

### 2.3 Building labs

| Step | Action |
|------|--------|
| 1 | add image |
| 2 | drop nodes |
| 3 | connect |
| 4 | boot/config |
| 5 | save project |
| 6 | export/import |

- **Image first; then topology.**

### 2.4 Automation support

| Feature | Use |
|---------|-----|
| API | scripts |
| Docker | code dev |
| Cloud integration | bridge |
| Import/export | share |
| Ansible | config |

- GNS3 pairs with **Docker + Ansible** for automation.

### 2.5 Resources

| Item | Note |
|------|------|
| CPU | per node |
| RAM | images heavy |
| Disk | images big |
| Server | local/remote |

- Plan **CPU/RAM per image**.

### 2.6 GNS3 vs CML vs EVE-NG

| Tool | GNS3 |
|------|------|
| Cost | free |
| Images | real + VM |
| Docker | yes |
| API | yes |
| Fidelity | high |
| UI | desktop |

- GNS3 = **free + flexible** middle ground.
