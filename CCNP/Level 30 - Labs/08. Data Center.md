# Data Center

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **Data Center lab** uses **NX-OS** switches with **vPC, VXLAN, OTV, and
fabric interconnect** to build the spine-leaf spine. It extends ENCOR into **overlay
networks** and modern DC data plane concepts.

---

## 2. Core Concepts

### 2.1 DC design

| Tier | Device |
|------|--------|
| Spine | core NX-OS |
| Leaf | ToR switches |
| vPC | dual-homed access |
| Fabric | VXLAN overlay |

- **Spine-leaf + vPC** = resilient DC fabric.

### 2.2 NX-OS basics

| Command | Use |
|---------|-----|
| `feature <name>` | enable |
| `vlan` | L2 |
| `interface port-channel` | bundle |
| `run` vs `copy run start` | save |

- **NX-OS = feature-driven CLI.**

### 2.3 vPC

| Step | Command |
|------|---------|
| 1 | feature vpc |
| 2 | vpc domain |
| 3 | peer link |
| 4 | vpc member |
| 5 | keepalive |

- **vPC = active-active port channel across two switches.**

### 2.4 VXLAN overlay

| Step | Command |
|------|---------|
| 1 | NVE interface |
| 2 | VNIs |
| 3 | multicast/EVPN |
| 4 | VRF |

- **VXLAN = L2 over L3 fabric.**

### 2.5 OTV / redundancy

| Feature | Use |
|---------|-----|
| OTV | inter-DC overlay |
| FHRP | anycast GW |
| HSRP | legacy |
| Fabric ext | scale |

- **OTV** connects remote DCs.

### 2.6 Verification

| Check | Command |
|-------|---------|
| vPC | show vpc |
| NVE | show nve peers |
| Port channel | show port-channel |
| VRF | show ip vrf |
| MAC | show mac address-table |

- **vPC + NVE + VRF** = fabric status.

## 3. Configuration / Commands

```text
feature vpc
vpc domain 10
 peer-keepalive destination 10.0.0.2
interface port-channel 1
 vpc 1
feature vn-segment-vlan-based
interface nve1
 member vni 10010
 show vpc
 show nve peers
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| vPC down | peer link | show vpc |
| No VNI | NVE | nve peers |
| Dual flap | keepalive | config |
| No overlay | multicast | underlay |
| Save lost | no copy run start | config |

---

## 5. Exam Traps

- **NX-OS `feature` commands** must be enabled first.
- vPC = **active-active bundle** (not standby).
- **VXLAN = L2 over L3** via NVE/VNI.
- OTV connects **remote DCs**.
- Save with **`copy run start`** on NX-OS.
