# DMVPN

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **DMVPN lab** builds a **hub-and-spoke overlay** with **NHRP for dynamic spoke
discovery**, **mGRE tunnels**, and **IPsec protection** — enabling **spoke-to-spoke
direct tunnels**. Verify with NHRP, tunnel, and crypto states.

---

## 2. Core Concepts

### 2.1 Components

| Item | Role |
|------|------|
| Hub | NHRP server |
| Spoke | NHRP client |
| mGRE | dynamic tunnels |
| NHRP | address resolution |
| IPsec | encrypt overlay |

- **mGRE + NHRP** = dynamic topology.

### 2.2 NHRP

| Check | Command |
|-------|---------|
| Registration | show ip nhrp |
| Server | nhs command |
| Map | nhrp map |
| Network | nhrp network-id |
| Cache | entries |

- **Spokes register to the hub via NHRP.**

### 2.3 Spoke-to-spoke

| Flow | Detail |
|------|--------|
| First | via hub |
| Learn | NHRP resolution |
| Tunnel | direct |
| Hold | resolution timer |
| Idle | drops |

- **Spokes build direct tunnels after NHRP resolution.**

### 2.4 Phase variants

| Phase | Spoke-Spoke |
|-------|-------------|
| 1 | hub-only |
| 2 | via hub |
| 3 | direct |
| 4 | hierarchical |

- **Phase 3 = direct spoke tunnels.**

### 2.5 IPsec integration

| Step | Command |
|------|---------|
| 1 | isakmp profile |
| 2 | transform |
| 3 | ipsec profile |
| 4 | tunnel protection |

- **tunnel protection** wraps the mGRE.

### 2.6 Verification

| Check | Command |
|-------|---------|
| NHRP | show ip nhrp |
| Tunnel | show interface tunnel |
| Crypto | show crypto isakmp sa |
| Routes | show ip route |
| SA | show crypto ipsec sa |

- **NHRP → tunnel → crypto** chain.

## 3. Configuration / Commands

```text
interface Tunnel0
 ip nhrp network-id 1
 ip nhrp nhs 1.1.1.1
 tunnel mode gre multipoint
 tunnel source Gi0/1
 tunnel destination 1.1.1.1
 tunnel protection ipsec profile DMVPN
show ip nhrp short
show crypto session
```
