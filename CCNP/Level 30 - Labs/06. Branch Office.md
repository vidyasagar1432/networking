# Branch Office

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **Branch Office lab** models a small site connecting to HQ over **WAN + VPN**
(commonly **DMVPN or IPsec**). It uses a branch router, a hub router, dual WAN links,
and **automatic failover**. Core CCNP topics: tunnel, routing through overlay, NAT, QoS.

---

## 2. Core Concepts

### 2.1 Branch design

| Element | Detail |
|---------|--------|
| Router | cEdge branch |
| WAN links | 2 ISPs |
| Tunnel | DMVPN/IPsec |
| HQ | hub/datacenter |
| LAN | local users |

- **Branch = one router, multiple WAN paths, secure tunnel.**

### 2.2 Connectivity

| Link | Use |
|------|-----|
| ISP1 | primary |
| ISP2 | backup |
| Tunnel | overlay |
| Underlay | Internet |

- **Load/share + failover** across dual WAN.

### 2.3 Tunnel setup (DMVPN)

| Step | Command |
|------|---------|
| 1 | loopback + tunnel |
| 2 | NHRP map |
| 3 | IPsec profile |
| 4 | routing over tunnel |
| 5 | verify |

- DMVPN = **dynamic full-mesh** from hubs.

### 2.4 IPsec alternative

| Step | Command |
|------|---------|
| 1 | isakmp policy |
| 2 | transform |
| 3 | crypto map |
| 4 | apply interface |

- **Site-to-site IPsec** = static alternative.

### 2.5 Branch services

| Service | Use |
|---------|-----|
| NAT | Internet |
| DHCP | LAN |
| QOS | voice/video |
| Redundancy | dual WAN |

- Branch runs **local services + WAN QoS**.

### 2.6 Verification

| Check | Command |
|-------|---------|
| Tunnel | show ip nhrp |
| SA | show crypto |
| Route | show ip route |
| Failover | show track |
| QOS | show policy-map |

- **Tunnel + crypto + route** = branch health.

## 3. Configuration / Commands

```text
interface Tunnel0
 ip nhrp network-id 1
 ip nhrp nhs 1.1.1.1
 tunnel source Gi0/1
 tunnel destination 1.1.1.1
 tunnel protection ipsec profile DMVPN
track 1 ip sla 10 reachability
ip route 0.0.0.0 0.0.0.0 2.2.2.1 track 1
show ip nhrp brief
show crypto session
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Tunnel down | NHRP/reg | nhrp brief |
| No crypto | profile | crypto session |
| No route | overlay | ip route |
| No failover | track | show track |
| QOS drop | policy | policy-map |

## 5. Exam Traps

- Branch = **dual WAN + DMVPN/IPsec + failover**.
- **NHRP + IPsec profile** = DMVPN core.
- Dual WAN needed **track + route** for failover.
- Verify **tunnel → crypto → route**.
- NAT/QoS/DHCP are **local branch services**.
