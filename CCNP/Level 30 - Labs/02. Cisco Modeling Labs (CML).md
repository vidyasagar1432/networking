# Cisco Modeling Labs (CML)

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Cisco Modeling Labs (CML, ex-VIRL)** runs **real Cisco IOS/IOS-XE images** on your
server via a web UI + API. It's the **official Cisco lab environment** for CCNP/CCIE
practice, supporting automation (NETCONF/REST) and snapshots. The exam-prep gold
standard.

---

## 2. Core Concepts

### 2.1 What CML offers

| Feature | Detail |
|---------|--------|
| Real images | IOS-XE/NX-OS |
| Topologies | unlimited nodes |
| API | automation |
| Snapshots | save/restore |
| Web UI | browser control |
| Nodes | routers/switches/firewalls |

- **Real device images** make CML exam-faithful.

### 2.2 Node types

| Node | Use |
|------|-----|
| CSR1000v | router |
| IOSv | router/switch |
| NX-OS | data center |
| ASAv | firewall |
| vIOS-L2 | switching |
| External | connect real net |

- Mix **L2 + L3 + firewall** for full labs.

### 2.3 Building a lab

| Step | Action |
|------|--------|
| 1 | create nodes |
| 2 | connect links |
| 3 | boot |
| 4 | console/config |
| 5 | snapshot |
| 6 | test |

- **Boot → configure → snapshot** the working state.

### 2.4 Automation

| Interface | Use |
|-----------|-----|
| REST API | scripts |
| NETCONF | config |
| Python | pyATS/Ansible |
| Import/export | share labs |

- CML's **API + NETCONF** power automation practice.

### 2.5 Snapshots and cloning

| Feature | Benefit |
|---------|---------|
| Snapshot | rollback |
| Clone | duplicate lab |
| Export | backup |
| Timing | save states |

- **Snapshot = instant rollback** for experiments.

### 2.6 CML vs alternatives

| Tool | CML |
|------|-----|
| Images | real Cisco |
| Cost | licensed |
| UI | web |
| API | yes |
| Fidelity | high |
| Best for | serious CCNP prep |

- **CML = highest fidelity** among the GUI tools.
