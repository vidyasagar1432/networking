# IPsec

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **IPsec lab** configures **site-to-site VPN** with **IKEv1/v2**, **transform
sets**, **crypto maps**, and **interesting traffic**. It's the base VPN skill for DMVPN,
FlexVPN, and remote access. Verify the two SAs and protected traffic.

---

## 2. Core Concepts

### 2.1 Config sequence

| Step | Command |
|------|---------|
| 1 | isakmp policy |
| 2 | transform set |
| 3 | ACL interesting |
| 4 | crypto map |
| 5 | apply |

- **IKE → transform → ACL → map → interface.**

### 2.2 IKEv1 vs v2

| Aspect | IKEv1 | IKEv2 |
|--------|-------|-------|
| Phases | 2 | 1 exchange |
| Aggressive | optional | no |
| Auth | PSK/cert | PSK/cert |
| Safer | v2 | v2 |

- **IKEv2 = simpler + more secure.**

### 2.3 Transform set

| Item | Example |
|------|---------|
| Encryption | esp-aes |
| Integrity | esp-sha256 |
| DH group | 14/19 |
| Mode | tunnel |
| PFS | optional |

- **esp-aes + esp-sha = common pair.**

### 2.4 Interesting traffic

| Item | Detail |
|------|--------|
| ACL | match tunnel |
| Traffic | permitted = protected |
| Denied | clear text |
| Mirror | both sides |
| Symmetric | must match |

- **ACL defines what the tunnel carries.**

### 2.5 Crypto map

| Step | Command |
|------|---------|
| 1 | crypto map name seq |
| 2 | match address ACL |
| 3 | set peer |
| 4 | set transform |
| 5 | apply to interface |

- **map binds peer + ACL + transform.**

### 2.6 Verification

| Check | Command |
|-------|---------|
| Phase1 | show crypto isakmp sa |
| Phase2 | show crypto ipsec sa |
| Map | show crypto map |
| Traffic | ipsec sa traffic |
| Errors | show crypto errors |

- **Both SAs + packet count = working VPN.**

## 3. Configuration / Commands

```text
crypto isakmp policy 10
 encr aes
 authentication pre-share
 group 14
crypto ipsec transform-set TS esp-aes esp-sha256
access-list 100 permit ip 10.0.0.0 0.0.0.255 10.1.0.0 0.0.0.255
crypto map CM 1 ipsec-isakmp
 set peer 1.1.1.1
 transform-set TS
 match address 100
interface Gi0/1
 crypto map CM
show crypto isakmp sa
show crypto ipsec sa
```

## 5. Exam Traps

- **ACL = interesting traffic** (must mirror).
- **IKEv1 = 2 phases; IKEv2 = 1 exchange.**
- **esp-aes + esp-sha** = classic transform.
- Crypto map = **peer + ACL + transform**.
- Verify **both SAs + byte counters**.
