# Enterprise Campus

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **Enterprise Campus lab** builds a **three-tier campus** with access/distribution/
core, VLANs, EtherChannel, STP, and routing. It ties L2 + L3 together — the backbone of
ENCOR hands-on. Verify with the L2/L3 command chains.

---

## 2. Core Concepts

### 2.1 Design

| Tier | Device | Role |
|------|--------|------|
| Access | switch | hosts |
| Distribution | switch | L3 routing |
| Core | routers/switches | backbone |
| Interconnection | uplinks | EtherChannel |

- **Access → Distribution → Core** = classic campus.

### 2.2 Layer 2 setup

| Task | Command |
|------|---------|
| VLANs | vlan 10 |
| Trunks | switchport mode trunk |
| EtherChannel | channel-group |
| STP root | spanning-tree vlan X root primary |
| Access | switchport access vlan |

- **VLAN + trunk + bundle + STP** first.

### 2.3 Layer 3 setup

| Task | Command |
|------|---------|
| SVI | interface Vlan10 |
| Routing | ospf/eigrp |
| Default | ip route |
| FHRP | standby/HSRP |
| Uplink | routed ports |

- **SVI + routing + FHRP** complete the campus.

### 2.4 Verification chain

| Check | Command |
|-------|---------|
| Link | show interfaces status |
| VLAN | show vlan |
| Bundle | show etherchannel summary |
| STP | show spanning-tree |
| Routes | show ip route |
| Redundancy | show standby brief |

- Work **L1 → L2 → L3** methodically.

### 2.5 Redundancy

| Feature | Use |
|---------|-----|
| EtherChannel | uplinks |
| HSRP/VRRP | gateways |
| STP root | designed |
| Loop-free | Root Guard |

- **Design for redundancy everywhere.**

### 2.6 Common lab order

| Step | Action |
|------|--------|
| 1 | VLANs |
| 2 | trunks |
| 3 | EtherChannel |
| 4 | SVIs |
| 5 | routing |
| 6 | FHRP |
| 7 | verify |

- Build in a **repeatable sequence**.

## 3. Configuration / Commands

```text
vlan 10
interface Gi0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 channel-group 1 mode active
interface Vlan10
 ip address 10.10.10.254 255.255.255.0
 standby 1 ip 10.10.10.1
router ospf 1
 network 10.10.10.0 0.0.0.255 area 0
show spanning-tree
show etherchannel summary
show standby brief
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No VLAN | create | show vlan |
| No bundle | mode | summary |
| STP block | design | spanning-tree |
| No gateway | SVI/HSRP | standby |
| No route | ospf | route |

## 5. Exam Traps

- Three-tier: **access/distribution/core**.
- **VLANs → trunks → EtherChannel → SVIs → routing → FHRP**.
- HSRP + EtherChannel = **campus redundancy**.
- Verify **L1 → L2 → L3** order.
- Root priority controlled by **design**.
