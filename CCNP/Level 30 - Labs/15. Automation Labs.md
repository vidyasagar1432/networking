# Automation Labs

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Automation Labs** practice **Python + Ansible + APIs (NETCONF/RESTCONF)** against
labs. They build the ENCOR automation objectives: config via API, data models (YANG),
and repeatable playbooks. Core skills: interaction, parsing, and idempotent changes.

---

## 2. Core Concepts

### 2.1 Interaction methods

| Method | Detail |
|--------|--------|
| RESTCONF | HTTP + YANG |
| NETCONF | XML RPC |
| SSH | CLI |
| gNMI | streaming |
| Python | libs |

- **API-first** for modern automation.

### 2.2 Python basics

| Use | Example |
|-----|---------|
| Requests | RESTCONF |
| ncclient | NETCONF |
| json | parse |
| os | env |
| argparse | CLI |

- **requests + ncclient** cover most labs.

### 2.3 RESTCONF lab

| Step | Command |
|------|---------|
| 1 | enable RESTCONF |
| 2 | GET auth |
| 3 | parse JSON |
| 4 | PATCH config |
| 5 | verify |

- RESTCONF = **HTTP method per YANG path**.

### 2.4 NETCONF lab

| Step | Command |
|------|---------|
| 1 | enable NETCONF |
| 2 | ncclient connect |
| 3 | get config |
| 4 | edit-config |
| 5 | verify |

- NETCONF = **XML RPC** over SSH.

### 2.5 Ansible playbooks

| Element | Detail |
|---------|--------|
| ios_command | CLI |
| ios_config | config |
| netconf_config | NETCONF |
| Inventory | hosts |
| Modules | repeatable |

- **ios_config/netconf_config** = idempotent config.

### 2.6 Lab workflow

| Step | Action |
|------|--------|
| 1 | enable APIs |
| 2 | script connect |
| 3 | change config |
| 4 | verify |
| 5 | rollback |

- **Enable → connect → change → verify → rollback.**

## 5. Exam Traps

- Enable **`restconf` + `netconf-yang`** first.
- RESTCONF = **HTTP + JSON**; NETCONF = **XML**.
- Accept header = **`application/yang-data+json`**.
- Ansible = **idempotent modules**.
- Verify + **rollback** after every change.
