# Multi-Area OSPF

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **Multi-Area OSPF lab** builds **area 0 + non-backbone areas**, **ABRs**, **LSA
types**, and **summarization**. It practices the core OSPF concepts in a routed
topology. Verify adjacencies, LSDB, and inter-area routes.

---

## 2. Core Concepts

### 2.1 Topology

| Device | Role | Area |
|--------|------|------|
| Core | backbone | 0 |
| ABR | connects | 0 + X |
| Internal | non-backbone | X |
| ASBR | external | any |

- **Area 0 backbone + attached areas.**

### 2.2 Configuration

| Step | Command |
|------|---------|
| 1 | router ospf |
| 2 | network statements |
| 3 | area assignment |
| 4 | router-id |
| 5 | verify |

- `network <net> <mask> area <id>` maps **subnets to areas**.

### 2.3 LSA types

| Type | Meaning |
|------|---------|
| 1 | router |
| 2 | network |
| 3 | summary (ABR) |
| 4 | ASBR summary |
| 5 | external |
| 7 | NSSA external |

- **Type 3 = inter-area summaries**.

### 2.4 ABR roles

| Function | Detail |
|----------|--------|
| Connects | area ↔ backbone |
| Summarizes | LSA3 |
| Filters | area ranges |
| Routes | to all areas |

- ABR = **area interconnector**.

### 2.5 Areas types

| Area | Behavior |
|------|----------|
| Standard | all LSAs |
| Stub | no type 5 |
| Totally stub | no 3/5 |
| NSSA | 7 for external |

- **Stub/NSSA limit external flooding.**

### 2.6 Verification

| Check | Command |
|-------|---------|
| Neighbors | show ip ospf neighbor |
| LSDB | show ip ospf database |
| Inter-area | show ip route ospf |
| ABR | show ip ospf |
| Summaries | show ip ospf summary |

- **Neighbor + database + inter-area routes.**

---

## 3. Configuration / Commands

```text
router ospf 1
 router-id 1.1.1.1
 network 10.0.0.0 0.0.0.255 area 0
 network 10.1.0.0 0.0.0.255 area 1
 area 1 range 10.1.0.0 255.255.0.0
show ip ospf neighbor
show ip ospf database summary
```

## 5. Exam Traps

- **All areas attach to area 0** (via ABR).
- **Type 3 = inter-area summary**.
- **Stub = no type 5; NSSA uses type 7**.
- Area range = **summarization**.
- Verify **neighbor → database → route**.
