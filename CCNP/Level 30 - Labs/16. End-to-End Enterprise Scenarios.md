# End-to-End Enterprise Scenarios

> **Level 30 · Labs** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**End-to-End Enterprise Scenarios** stitch **campus + WAN + data center + security +
automation** into one integrated lab. They practice full **data-path troubleshooting**
and the ENCOR **big-picture** design. Follow a **top-down verify chain**.

---

## 2. Core Concepts

### 2.1 Scenario design

| Domain | Element |
|--------|---------|
| Campus | L2/L3 + FHRP |
| WAN | DMVPN/SD-WAN |
| DC | VXLAN/vPC |
| Security | ACL/firewall |
| Automation | APIs |

- One topology = **all domains connected**.

### 2.2 Data path

| Step | Check |
|------|-------|
| 1 | host → access |
| 2 | access → distribution |
| 3 | routing to WAN |
| 4 | tunnel/crypto |
| 5 | remote site |
| 6 | server |

- Follow **one packet end-to-end**.

### 2.3 Configuration order

| Step | Action |
|------|--------|
| 1 | L2 base |
| 2 | L3 base |
| 3 | redundancy |
| 4 | WAN/tunnels |
| 5 | security |
| 6 | automation |
| 7 | verify |

- Build in **layers, then cross-check** domains.

### 2.4 Scenario types

| Item | Feature |
|-------|---------|
| Dual-homed | failover |
| App pef | QoS |
| Cloud | extension |
| Security | segmentation |
| Monitoring | telemetry |

- Test **failure + performance + security**.

### 2.5 Verification chain

| Tool | Use |
|------|-----|
| ping/tr | reachability |
| show commands | state |
| IP SLA | SLA |
| NetFlow | flows |
| syslog | events |

- **Probe → state → flow → logs** across sites.

### 2.6 Playbook

| Step | Action |
|------|--------|
| 1 | baseline |
| 2 | failure test |
| 3 | root cause |
| 4 | fix |
| 5 | re-verify |
| 6 | automate |

- Simulate **failures and re-verify after fixes**.

## 5. Exam Traps

- **Isobar one packet end-to-end** across domains.
- Verify **each layer before cross-session**.
- Failure **simulation + rollback** practice.
- QoS/security/automation = **integrated**, not silos.
- Build a **repeatable playbook**.
