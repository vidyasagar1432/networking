# 802.11 (Wi-Fi)

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**802.11** is the IEEE standard family for WLANs. It defines the **MAC** and **PHY**
layers, the **management frames** that run association, and the **amendment generations**
(a/b/g/n/ac/ax) that add speed and bands. The exam tests frame types, the access
mechanism (CSMA/CA), and which amendment = which speed/band.

---

## 2. Core Concepts

### 2.1 Frame types

| Type | Purpose |
|------|---------|
| Management | beacon, probe, auth, assoc |
| Control | RTS/CTS, ACK |
| Data | payload |

- **Management frames** run the association lifecycle.

### 2.2 CSMA/CA (why no collisions are detectable)

| Item | Detail |
|------|--------|
| Listen | sense the channel |
| Wait | random backoff (DIFS/AIFS) |
| Send | if clear |
| ACK | receiver confirms |

- Wireless can't detect collisions → **CSMA/CA** with ACKs.

### 2.3 Management frame flow

| Frame | Direction | Step |
|-------|-----------|------|
| Beacon | AP → STA | discover |
| Probe request/response | both | search |
| Auth | both | identity |
| Association | both | join BSS |

- Beacons advertise the **BSSID/SSID** every ~100 ms.

### 2.4 Amendments

| 802.11 | Band | Max rate | Notes |
|--------|------|----------|-------|
| b | 2.4 | 11 Mbps | legacy |
| a | 5 | 54 Mbps | legacy |
| g | 2.4 | 54 Mbps | legacy |
| n (Wi-Fi 4) | 2.4/5 | 600 Mbps | MIMO |
| ac (Wi-Fi 5) | 5 | ~1.7 Gbps | wide channels |
| ax (Wi-Fi 6) | 2.4/5/6 | ~9.6 Gbps | OFDMA |

- **n** = MIMO; **ac** = 5 GHz fast; **ax** = OFDMA + 6 GHz.

### 2.5 RTS/CTS

| Control frame | Use |
|---------------|-----|
| RTS | reserve medium |
| CTS | grant |
| NAV | wait timer |

- RTS/CTS mitigates **hidden-node** problems.

### 2.6 PHY vs MAC

| Layer | 802.11 part |
|-------|-------------|
| PHY | OFDM/OFDMA, modulation |
| MAC | CSMA/CA, frames |
| L2.5 | interop (WPA) |

## 5. Exam Traps

- CSMA/CA + **ACK** — wireless can't detect collisions.
- **Management frames** = beacon/probe/auth/assoc.
- Amendments: **n = MIMO, ac = 5GHz, ax = OFDMA/6GHz**.
- RTS/CTS fights the **hidden node**.
- Beacons every ~100 ms advertise the network.
