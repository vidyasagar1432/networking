# Channels

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Channels** are the RF sub-bands APs transmit on. Non-overlapping channels let nearby
APs share spectrum without colliding; DFS adds radar-aware channels in 5 GHz. The exam
tests which channels are non-overlapping, how 20/40/80 MHz widths behave, and **RRM**
(auto channel/power) tuning.

---

## 2. Core Concepts

### 2.1 2.4 GHz channels

| Band | Channels | Non-overlap |
|------|----------|-------------|
| 2.4 GHz | 1–13 (US 1–11) | **1, 6, 11** |
| Width | 20 MHz | spacing 5 MHz |

- Only **1/6/11** are non-overlapping in the US.

### 2.2 5 GHz channels

| Band | Notes |
|------|-------|
| 5 GHz | many, wider channels |
| UNII bands | 36–165 |
| DFS | 52–144 (radar) |
| Non-DFS | 36, 40, 44, 48, 149... |

- More channels → **less interference**, but DFS needs radar detection.

### 2.3 Channel widths

| Width | 2.4 | 5 |
|-------|-----|---|
| 20 MHz | standard | standard |
| 40 MHz | bond | bond |
| 80/160 | no | high speed |

- Wider = **more throughput, less spectrum available**.

### 2.4 DFS (dynamic frequency selection)

| Item | Detail |
|------|--------|
| Purpose | avoid radar |
| Check | listen before use |
| Action | change channel |
| Downtime | brief |

- DFS channels **require radar checking** — some regions limit them.

### 2.5 RRM (radio resource management)

| Task | RRM action |
|------|------------|
| Channel | auto assign non-overlap |
| Power | auto adjust (TPC) |
| Coverage | monitor clients |
| Interference | detect |

- The WLC runs **RRM** to keep channels/power optimal.

### 2.6 Configuration

```text
ap dot11 5ghz rrm channel global
ap dot11 24ghz rrm channel global
ap dot11 5ghz rrm tx-power global
```

| Command | Meaning |
|---------|---------|
| `rrm channel global` | RRM picks channels |
| `rrm tx-power global` | auto power |
| `ch-width` | set width |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Interference | overlapping | rrm channel |
| Slow | same channel APs | radio summary |
| DFS stalls | radar | DFS status |
| Low power | TPC | tx-power |
| Busy air | noise | monitor |

---

## 5. Exam Traps

- 2.4 GHz **non-overlap = 1/6/11**.
- 5 GHz has **many channels + DFS** (52–144).
- Wider channel = faster but **fewer channels**.
- **RRM** auto-picks channels and power.
- TPC adjusts **transmit power**.
