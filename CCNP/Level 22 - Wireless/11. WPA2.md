# WPA2

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**WPA2** is the long-standing Wi-Fi security standard using **AES-CCMP** for encryption
and **802.1X (enterprise)** or **PSK (personal)** for authentication. The exam wants the
two WPA2 modes, the **4-way handshake**, and why **TKIP/PSK** are weak points.

---

## 2. Core Concepts

### 2.1 WPA2 modes

| Mode | Auth | Use |
|------|------|-----|
| Personal | PSK (passphrase) | small networks |
| Enterprise | 802.1X/RADIUS | corporate |

- **Enterprise = per-user 802.1X; Personal = shared passphrase.**

### 2.2 Encryption: AES-CCMP

| Item | Detail |
|------|--------|
| Cipher | AES |
| Protocol | CCMP |
| Key | per-session (PTK) |
| Standard | IEEE 802.11i |

- AES-CCMP replaced the weak **TKIP/RC4** (WPA1).

### 2.3 The 4-way handshake

| Step | Determinant |
|------|-------------|
| 1 | AP sends ANonce |
| 2 | client sends SNonce + MIC |
| 3 | AP confirms + installs key |
| 4 | client confirms |

- Both sides derive the **PTK (pairwise transient key)** from Anonce/Snonce + PMK.

### 2.4 PSK weakness

| Item | Detail |
|------|--------|
| PMK | from passphrase |
| Attack | off/online dictionary |
| Risk | shared, static |
| Rotation | rarely changed |

- **PSK is only as strong as the passphrase** — dictionary risk.

### 2.5 Enterprise flow (802.1X)

| Stage | Protocol |
|-------|----------|
| Auth | EAP-over-802.1X |
| Server | RADIUS |
| Key | MSK → PMK |
| Session | PTK |

- The RADIUS server hands the **MSK**, which becomes the PMK for the handshake.

### 2.6 Config (WLC)

```text
wlan CorpData 1 Corp
 security wpa akm dot1x
 security dot1x server-auth
 no security wpa akm psk
 security wpa ccmp
```

| Command | Meaning |
|---------|---------|
| `akm dot1x` | enterprise |
| `akm psk` | personal |
| `ccmp` | AES |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Auth fail | PSK typo | associations |
| Handshake loop | key mismatch | 4-way |
| RADIUS fail | server | dot1x |
| Rekey issues | PMK | security |
| Dictionary attack | weak PSK | policy |

---

## 5. Exam Traps

- WPA2 = **AES-CCMP** (not TKIP).
- Personal = PSK; **Enterprise = 802.1X/RADIUS**.
- **4-way handshake** derives the PTK.
- PSK = dictionary attack surface.
- MSK from RADIUS becomes the PMK.
