# WLC (Wireless LAN Controller)

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **WLC** is the brain of a centralized WLAN: it configures APs, runs **RRM**, handles
**client authentication/roaming**, and anchors control planes via **CAPWAP**. APs are
"lite" — the WLC pushes config, and management/control traffic flows through it. The
exam tests the WLC functions and where control/data/metastate live.

---

## 2. Core Concepts

### 2.1 What the WLC does

| Function | Detail |
|----------|--------|
| AP config | push profiles |
| RRM | channels/power |
| Auth | RADIUS/802.1X |
| Roaming | client handoff |
| Mgmt | monitoring |

- Central admin = **one go to configure the fleet**.

### 2.2 Architecture split

| Plane | Where |
|-------|-------|
| Control | WLC (CAPWAP control) |
| Management | WLC |
| Data | AP → WLC (or flexconnect) |

- **Split data/control**: AP handles RF, WLC handles policy.

### 2.3 Modes

| Mode | Data path |
|------|-----------|
| Local | client data to WLC |
| FlexConnect | data local to AP |
| Monitor | only sensing |
| Sniffer | capture |

- **Local** = traffic through the WLC; **FlexConnect** = data at the AP for remote branches.

### 2.4 AP join process

| Step | Detail |
|------|--------|
| 1 | AP discovers (DNS/L3) |
| 2 | CAPWAP discovery |
| 3 | DTLS (secure) |
| 4 | config push |

- AP joins via **CAPWAP discovery** and gets its config/software.

### 2.5 WLC management ports

| Port | Use |
|------|-----|
| Management | admin/dashboard |
| AP manager | AP traffic |
| Service | guest |

- Separate subinterfaces/VRFs keep planes isolated.

### 2.6 WLC platforms

| Type | Example |
|------|---------|
| Appliance | 9800 series |
| Embedded | Catalyst/AIRE |
| Virtual | vWLC |
| Cloud | Catalyst Center |

- 9800 is the modern **IOS-XE** controller.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| AP not joining | CAPWAP/DNS | join stats |
| No WLANs | wlan not enabled | show wlan |
| Auth fails | RADIUS | wireless stats |
| Roaming breaks | mobility | config |
| Data wrong | mode (local/flex) | ap mode |

---

## 5. Exam Traps

- WLC = **control + management plane**; data may be local (FlexConnect).
- APs join via **CAPWAP discovery → DTLS → config push**.
- **RRM** runs on the WLC.
- **FlexConnect** keeps data local for branches; Local sends it to the WLC.
- 9800 = modern IOS-XE WLC.
