# RF (Radio Frequency)

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**RF** physics decide whether Wi-Fi works: signal strength (**RSSI**), signal-to-noise
(**SNR**), attenuation, interference, and **antenna behavior**. Design for the exam
means understanding dBm, path loss, coverage, and the noisy-cell/small-cell trade-offs —
plus how to validate with a **site survey**.

---

## 2. Core Concepts

### 2.1 Key metrics

| Metric | Meaning |
|--------|---------|
| RSSI | received signal (dBm) |
| SNR | signal vs noise (dB) |
| dBm | power level |
| EIRP | total transmit (tx + ant) |

- **RSSI** how strong; **SNR** how clean — SNR ≥ ~25 dB is good.

### 2.2 Signal behavior

| Effect | Detail |
|--------|--------|
| Attenuation | distance/free-space loss |
| Absorption | walls, people |
| Reflection | multipath |
| Interference | other radios |

- RF rule of thumb: **bandwidth halves roughly every +3 dB cells** considerations.

### 2.3 RF planning trade-offs

| Factor | Small cell | Large cell |
|--------|------------|------------|
| Capacity | high (more APs) | low |
| Interference | lower | higher |
| Coverage | less per AP | more per AP |
| Cost | higher | lower |

- **Smaller cells = more capacity** — the density answer.

### 2.4 dBm and EIRP

| Item | Formula |
|------|---------|
| dBm | 10·log10(mW) |
| EIRP | tx power + antenna − cable loss |
| Example | 20 dBm + 3 dBi = 23 dBm EIRP |

- **EIRP = transmit + antenna − losses**.

### 2.5 Site survey

| Type | Purpose |
|------|---------|
| Passive | measure existing RF |
| Active | test throughput |
| Predictive | software model |

- Surveys validate **coverage, interference, and capacity**.

### 2.6 RRM tie-in

- RRM uses RF data to tune **channels/power** (note 05).

## 5. Exam Traps

- **RSSI = strength (dBm); SNR = cleanliness (dB)**.
- EIRP = **tx power + antenna − loss**.
- **Small cells = more capacity**.
- Multipath/absorption hurt performance.
- Site surveys validate the design.
