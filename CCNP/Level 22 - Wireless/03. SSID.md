# SSID (Service Set Identifier)

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **SSID** is the **human-readable name** of a wireless network, broadcast in
beacons so clients can find and join it. One WLC can run **multiple SSIDs** mapped to
different **WLAN profiles** — each with its own security, VLAN, and QoS policy. The
exam tests how SSID → WLAN profile → VLAN/security policies connect.

---

## 2. Core Concepts

### 2.1 What the SSID is

| Item | Detail |
|------|--------|
| Type | ASCII name |
| Length | up to 32 chars |
| Broadcast | in beacons |
| Case | sensitive |

- The SSID is a **label** — the real identity is the BSSID (MAC).

### 2.2 SSID vs BSSID

| Term | Type | Meaning |
|------|------|---------|
| SSID | name | network identity |
| BSSID | MAC | specific AP radio |

- One SSID can span **many BSSIDs** (many APs).

### 2.3 SSID → WLAN profile

| Layer | Definition |
|-------|-----------|
| SSID | clients see the name |
| WLAN profile | security + policy |
| VLAN | where traffic lands |
| QoS/ACL | per-WLAN rules |

- On a WLC, an SSID is the **wireless side** of a WLAN profile.

### 2.4 Multiple SSIDs

| SSID | Use |
|------|-----|
| Corp-Guest | isolation |
| Corp-Corp | 802.1X |
| Corp-IoT | PSK + VLAN |

- Each SSID → own **VLAN/security/QoS**; client isolation where needed.

### 2.5 Broadcast/hidden

| Mode | Behavior |
|------|----------|
| Broadcast | beacon carries SSID |
| Hidden | SSID withheld (not secure) |

- Hiding an SSID is **not a security measure** — clients still probe for it.

### 2.6 WLC config

```text
wlan Corp-Guest 2 Guest-Data
 security wpa psk ascii GuestPass1
 no security wpa akm dot1x
 vlan Guest
 no shutdown
```

| Command | Meaning |
|---------|---------|
| `wlan NAME id` | create |
| `security wpa psk` | pre-shared |
| `security dot1x` | enterprise auth |
| `vlan` | mapped VLAN |
| `no shutdown` | enable |

| SSID missing | wlan shutdown | show wlan summary |

| Slow | band steering | policy |

---

## 5. Exam Traps

- SSID = **name (≤32 chars)**; BSSID = MAC.
- Multiple SSIDs → **separate WLAN profiles/VLANs**.
- Hidden SSID ≠ secure.
- SSID broadcasts in **beacons**.
- WLC maps SSID → **VLAN + security + QoS**.
