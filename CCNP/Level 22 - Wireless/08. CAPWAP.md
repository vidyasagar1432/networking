# CAPWAP

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**CAPWAP** (Control And Provisioning of Wireless Access Points) is the standard tunnel
between **AP and WLC**. It carries **control** (config, stats) and, in **Local mode**,
**data** (client traffic). Control is DTLS-encrypted and rides UDP **5246**; data rides
UDP **5247**. Knowing the ports and modes is a frequent exam question.

---

## 2. Core Concepts

### 2.1 The two tunnels

| Tunnel | Protocol | Port | Content |
|--------|----------|------|---------|
| Control | CAPWAP control | UDP 5246 | config, monitor |
| Data | CAPWAP data | UDP 5247 | client traffic |

- Control = management; data = client payload.

### 2.2 Security

| Layer | Detail |
|-------|--------|
| DTLS | encrypts control |
| Optional | data DTLS |
| Join | AP authenticity |
| Result | secure WLC-AP |

- **DTLS** protects the control channel; data can also use it.

### 2.3 Discovery process

| Step | Detail |
|------|--------|
| 1 | AP looks for WLC (broadcast/multicast/DNS/hostname) |
| 2 | discovery request/response |
| 3 | join request/response |
| 4 | config push |

- AP **discovers → joins → gets config** (note 07).

### 2.4 Modes and data path

| Mode | Data over CAPWAP |
|------|------------------|
| Local | yes (to WLC) |
| FlexConnect | no (AP switches) |
| Monitor | control only |

- Only **Local mode** sends client data to the WLC over CAPWAP.

### 2.5 Overhead and design

| Point | Detail |
|-------|--------|
| WLC capacity | tunnels scale with APs |
| Path | must be reachable |
| Hairpin | data goes AP → WLC → LAN |
| Alternative | FlexConnect |

- Tunneled data means the **WLC is a chokepoint** in Local mode.

### 2.6 Verification

```text
show ap capwap ip
show ap summary
show wireless ap config

```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| AP not joining | discovery/DNS | join stats |
| Control down | UDP 5246 blocked | capwap ip |
| Data fails | 5247 | mode |
| DTLS errors | cert mismatches | security |
| Slow data | WLC overload | capacity |

---

## 5. Exam Traps

- CAPWAP control = **UDP 5246**; data = **UDP 5247**.
- Control is **DTLS-encrypted**.
- Local mode = data through WLC; **FlexConnect = data at AP**.
- AP **discovers → joins → config**.
- CAPWAP is the modern replacement for the old **LWAPP**.
