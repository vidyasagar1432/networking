# Roaming

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Roaming** is a client moving from one AP/BSS to another while keeping its session.
Types differ by scope and seamlessness: **Layer 2 vs Layer 3**, **intra- vs inter-WLC**,
and **802.11r fast roaming** for handoff speed. Roaming works because mobility (note 09)
shares the client state.

---

## 2. Core Concepts

### 2.1 Roaming types

| Type | Scope |
|------|-------|
| L2 | same subnet (switch) |
| L3 | different subnet (anchor) |
| Intra-WLC | same controller |
| Inter-WLC | across controllers |

- **L3 roams need anchor forwarding** (note 09).

### 2.2 The handoff moment

| Step | Detail |
|------|--------|
| 1 | client reassociates (new AP) |
| 2 | WLC/mobility updates |
| 3 | frames follow client |
| 4 | old AP releases |

- A **reassociation** happens at the new BSSID.

### 2.3 802.11r (fast transition)

| Item | Detail |
|------|--------|
| What | pre-auth PMK |
| FT | fast transition |
| Result | ~ms handoff |
| Use | voice/real-time |

- **802.11r** pre-distributes keys so reassociation is fast.

### 2.4 802.11k/v (agreement)

| Item | Detail |
|------|--------|
| k | neighbor reports |
| v | assist roaming |
| Result | better AP choice |

- **802.11k/v** help clients pick the right AP (network-driven).

### 2.5 Sticky clients

| Problem | Cause | Fix |
|---------|-------|-----|
| Client hangs on weak AP | RSSI threshold | 802.11v / disabling |
| Poor RF use | no steering | band steering |
| Slow roam | no FT | 802.11r |

- **Band steering + 802.11k/v/r** fix stickiness and slow handoffs.

### 2.6 Requirements for seamless roaming

| Need | Mechanism |
|------|-----------|
| Same SSID | ESS |
| Same security | PMK/802.1X |
| State sharing | mobility group |
| Fast keys | 802.11r |

- Everything must line up for a **zero-drama roam**.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Session drops | reassociation fail | client summary |
| Slow roam | no 802.11r | FT config |
| Sticky client | RSSI | band steering |
| Cross-L3 fails | anchor | mobility |
| Reauth loop | key mismatch | security |

---

## 5. Exam Traps

- L2 roam = same subnet; **L3 roam = anchor**.
- **802.11r = fast keys (FT)**; k/v = neighbor/assist.
- Intra- vs inter-WLC roaming.
- **Sticky client** fix = steering + 802.11k/v/r.
- Same SSID/security/state = seamless roam.
