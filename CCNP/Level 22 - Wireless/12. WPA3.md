# WPA3

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**WPA3** is the security upgrade over WPA2: **SAE** (Simultaneous Authentication of
Equals) replaces PSK's dictionary-prone handshake, **forward secrecy** protects past
traffic, and **enterprise 192-bit / PMF** harden enforcement. The exam contrasts SAE vs
4-way handshake and WPA3 vs WPA2 features.

---

## 2. Core Concepts

### 2.1 WPA3 Personal (SAE)

| Item | Detail |
|------|--------|
| Handshake | SAE (dragonfly) |
| PSK | swept PKBDF2 |
| Offline attack | prevented |
| Forward secrecy | yes |

- **SAE** resists offline dictionary attacks — no pre-shared passphrase guessing.

### 2.2 WPA3 Enterprise

| Aspect | Detail |
|--------|--------|
| Auth | 802.1X/RADIUS |
| Suite | 192-bit (CNSA) |
| Mutual | server + client certs |
| Result | stronger assurance |

- Enterprise mode supports **192-bit** security for high-assurance networks.

### 2.3 PMF (management frame protection)

| Item | Detail |
|------|--------|
| What | protects management frames |
| Against | deauth/forgery |
| In WPA3 | mandatory |
| Benefit | safer roaming |

- **PMF mandatory** in WPA3 stops deauth/association attacks.

### 2.4 WPA3 vs WPA2

| Feature | WPA2 | WPA3 |
|---------|------|------|
| Personal | PSK 4-way | SAE |
| Dict attack | vulnerable | resistant |
| Forward sec | no | yes |
| PMF | optional | mandatory |
| Enterprise | 802.1X | +192-bit |

- **Offline dictionary attack** is the headline WPA3 fix.

### 2.5 Wi-Fi transition

| Mode | Detail |
|------|--------|
| WPA3-only | secure but incompatible legacy |
| Transition | allows WPA2 devices |
| Risk | mixed weaker security |

- Use **transition mode** for compatibility; prefer **WPA3-only** where possible.

### 2.6 Config (WLC)

```text
wlan Secure 3 SecureData
 security wpa psk sae
 security pmf
 security wpa ccmp
```

| Command | Meaning |
|---------|---------|
| `akm sae` | WPA3 personal |
| `pmf` | management frame protection |
| `ccmp` (GCMP) | encryption |

## 5. Exam Traps

- WPA3 Personal = **SAE** (kills offline dictionary).
- **Forward secrecy + mandatory PMF**.
- Enterprise: **802.1X + optional 192-bit**.
- Transition mode keeps legacy clients working.
- SAE replaces the **4-way handshake/PSK** model.
