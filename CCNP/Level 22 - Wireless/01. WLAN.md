# WLAN (Wireless LAN)

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **WLAN** is a wireless network built on **802.11** (Wi-Fi). Clients associate to an
**AP** that broadcasts a **BSSID/SSID**; frames travel over RF in the 2.4/5/6 GHz bands.
Enterprise WLANs centralize control on a **WLC** (note 07) with **CAPWAP** tunnels, and
split into **data/control/management planes**.

---

## 2. Core Concepts

### 2.1 WLAN vs LAN

| Aspect | Wired LAN | WLAN |
|--------|-----------|------|
| Medium | cable | RF (shared) |
| Access | plug | associate |
| Error | low | interference |
| Movement | static | roaming |

- RF is a **shared, error-prone** medium — that shapes every design.

### 2.2 Components

| Component | Role |
|-----------|------|
| Client | station (STA) |
| AP | access point |
| WLC | controller |
| Backend | wired + services |

- Enterprise = **APs + WLC + wired network**.

### 2.3 Bands and data rates

| Band | Notes |
|------|-------|
| 2.4 GHz | long range, crowded |
| 5 GHz | more channels, faster |
| 6 GHz | Wi-Fi 6E (new) |

- More spectrum in 5/6 GHz → **better performance**.

### 2.4 Service sets

| Term | Meaning |
|------|---------|
| BSS | one AP + clients |
| ESS | many BSSes, one SSID |
| SSID | network name |
| BSSID | AP radio MAC |

- A **WLAN (ESS)** groups BSSes under one SSID for roaming.

### 2.5 Control vs data plane

| Plane | Device |
|-------|--------|
| Control | WLC (management) |
| Data | AP/WLC (CAPWAP) |
| Management | WLC |

- Centralized **WLC** handling = simpler operations, single admin point.

### 2.6 Deployments

| Model | Where |
|-------|-------|
| Autonomous | AP-only (standalone) |
| Centralized | WLC + CAPWAP |
| Cloud | Meraki-style |
| Mesh | wireless backhaul |

- **Centralized** is the classic enterprise model.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No SSID | WLAN disabled | show wlan summary |
| AP not joining | CAPWAP/DNS | show ap join stats |
| Weak signal | coverage/RF | show ap radio |
| Clients drop | interference | RF health |
| No roaming | same ESSID | mobility |

---

## 5. Exam Traps

- WLAN = **802.11 + AP/WLC architecture**.
- BSS/ESS/SSID/BSSID — keep the four straight (notes 03/04).
- Enterprise = **WLC + CAPWAP**, not autonomous.
- Bands: 2.4/5/6 GHz; 5/6 offer more channels.
- Data plane over **CAPWAP**.
