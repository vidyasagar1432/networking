# Mobility

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Wireless mobility** keeps a client's session alive while it moves between APs and
even **between WLCs**. WLCs join a **mobility group**; a **guest** (old) WLC anchors
the client while the foreign WLC serves it, or the anchor forwards traffic. Roaming
(notes 10) works because mobility state is shared.

---

## 2. Core Concepts

### 2.1 Mobility group

| Item | Detail |
|------|--------|
| Group | WLCs that trust each other |
| Exchange | client state (MAC/IP, security) |
| Scalability | group membership |
| Security | shared keys/certs |

- WLCs in one **mobility group** share roaming state.

### 2.2 Roles during roam

| Role | WLC | Job |
|------|-----|-----|
| Anchor | first WLC | holds session |
| Foreign | new WLC | serves client |
| Controller | group member | coordinates |

- **Anchor = where the subnet/session lives; foreign = where the client is now.**

### 2.3 Mobility vs roaming

| Term | Scope |
|------|-------|
| Roaming | client moves APs/BSSIDs |
| Mobility | WLC handoff + path |
| Fast roam | low-latency handoff |

- **Mobility is the infrastructure that makes roaming seamless.**

### 2.4 Layer 2 vs Layer 3 mobility

| Type | Subnet | Forwarding |
|------|--------|------------|
| L2 | same subnet | switch path |
| L3 | different | anchor forward |

- Cross-subnet clients need the **anchor** to forward traffic.

### 2.5 Config

```text
wireless mobility group name CORP
wireless mobility member 192.0.2.10
wireless mobility keepalive interval 30
```

| Command | Meaning |
|---------|---------|
| `mobility group name` | group id |
| `mobility member` | peer WLC IP |
| `keepalive` | health check |

### 2.6 Verification

```text
show wireless mobility summary
show wireless mobility statistics
show wireless mobility client ...
show ap summary
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Roam drops | mobility down | show wireless mobility summary |
| No handoff | not same group | config |
| Slow cross-L3 | anchor path | forwarding |
| Authen redo | fast roam off | security |
| Keepalive fails | firewall | timers |

---

## 5. Exam Traps

- **Mobility group** shares client state across WLCs.
- **Anchor = first WLC; foreign = current**.
- L2 mobility = same subnet; **L3 needs anchor forwarding**.
- Mobility enables **seamless roaming** (note 10).
- `show wireless mobility summary` is the key check.
