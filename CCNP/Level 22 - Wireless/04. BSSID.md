# BSSID (Basic Service Set Identifier)

> **Level 22 · Wireless** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **BSSID** is the **MAC address of an AP's radio** — the real, unique identity behind
every SSID. A **BSS** is one AP radio + its associated clients; a group of BSSes under
the same SSID forms an **ESS**. The exam wants you to separate SSID (name) from BSSID
(MAC) and BSS from ESS.

---

## 2. Core Concepts

### 2.1 BSSID basics

| Item | Detail |
|------|--------|
| Type | MAC (48-bit) |
| Source | AP radio |
| Unique | per radio/band |
| Frames | source of beacons |

- Each AP radio advertises its **own BSSID**, even with the same SSID.

### 2.2 BSS (Basic Service Set)

| Element | Meaning |
|---------|---------|
| BSS | one AP radio + clients |
| BSSID | its identity |
| DTPC/band | per radio |
| Independence | isolated cell |

- **BSS = the basic cell** — an AP radio and its clients.

### 2.3 ESS (Extended Service Set)

| Element | Meaning |
|---------|---------|
| ESS | many BSSes, one SSID |
| Roaming | between BSSes |
| Seamless | same SSID/auth |
| Distribution | wired backbone |

- **ESS = one logical network across many APs** — roaming within it.

### 2.4 The identity split

| Term | What | Example |
|------|------|---------|
| SSID | name clients see | CorpNet |
| BSSID | AP radio MAC | 00:1a:2b:... |
| BSS | one cell | AP1 |
| ESS | all cells | CorpNet everywhere |

- **Same SSID, different BSSIDs** is normal in an ESS.

### 2.5 Frames and BSSID

| Frame | Uses BSSID |
|-------|------------|
| Beacon | yes (source) |
| Probe response | yes |
| Data (to AP) | yes (DA) |
| Client frames | BSSID |

- Clients address frames **to the BSSID** of their AP.

### 2.6 Why it matters

- Troubleshooting: **each AP/band = own BSSID** → unique stats.
- Security: BSSID identifies a **specific AP**.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Wrong AP joined | same SSID, far BSSID | ap radio |
| Sticky client | RSSI | load |
| Duplicate MAC | misconfig | bssid |
| Coverage gap | too few APs | RF |
| Client can't roam | ESS split | mobility |

---

## 5. Exam Traps

- BSSID = **AP radio MAC**; SSID = name.
- **BSS** = one AP + clients; **ESS** = many BSSes, one SSID.
- Same SSID → many BSSIDs (roaming).
- Clients frame traffic **to the BSSID**.
- Beacons are sent from the BSSID.
