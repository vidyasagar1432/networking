# BGP

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**BGP troubleshooting** covers **session state, eBGP/iBGP rules, NLRI exchange, and
path selection**. Failures: neighbors idle, routes not advertised, or suboptimal
selection. Verify **`show ip bgp summary` → neighbors → table → bestpath** in order.

---

## 2. Core Concepts

### 2.1 Session states

| State | Meaning |
|-------|---------|
| Idle | starting |
| Connect | TCP attempt |
| Active | retrying |
| OpenSent | sent open |
| Established | up |

- **Established = healthy; anything less needs TCP check.**

### 2.2 Verify commands

| Command | Purpose |
|---------|---------|
| `show ip bgp summary` | sessions |
| `show ip bgp neighbors` | details |
| `show ip bgp` | table |
| `show ip bgp <net>` | path |
| `show ip route bgp` | installed |

- **Summary → neighbor → table → route** chain.

### 2.3 Common failures

| Symptom | Likely cause |
|---------|--------------|
| Idle | no route / ebgp-multihop |
| No route adv | network/next-hop |
| iBGP drops | no full mesh |
| Wrong path | attributes |
| No install | next-hop unreachable |

- **Next-hop reachability + network statement** dominate.

### 2.4 Advertise issues

| Item | Detail |
|------|--------|
| Network cmd | must match table |
| Redistribute | static/connected |
| Next-hop | self for eBGP |
| Filters | prefix-list |
| Sync | iBGP rules |

- **`network` matches an existing route** to advertise.

### 2.5 iBGP rules

| Rule | Impact |
|------|--------|
| Full mesh | sessions needed |
| Next-hop self | set on eBGP |
| Synchronization | (legacy) |
| AD | 200 |

- iBGP **requires full mesh** or route reflectors.

### 2.6 Best path attributes

| Attribute | Preference |
|-----------|------------|
| Weight | highest |
| Local pref | highest |
| Originate | local |
| AS path | shortest |
| Origin | IGP |
| MED | lowest |
| eBGP | over iBGP |

- Know the **order of bestpath decisions**.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Idle | route | summary |
| No adv | network | table |
| Next-hop | no route | rib-failure |
| Path wrong | attrs | show ip bgp |
| Flap | hold timer | neighbors |

---

## 5. Exam Traps

- **Established = up; Idle/Active = TCP or config.**
- `network` must **exist in the table** first.
- iBGP **full mesh** required.
- **RIB-failure** = route not installed (next-hop).
- Best path order: **weight → local pref → AS path → MED**.
