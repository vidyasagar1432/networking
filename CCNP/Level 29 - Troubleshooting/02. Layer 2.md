# Layer 2

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Layer 2** covers switching: VLANs, trunks, MAC learning, STP, and ports. Problems
appear as **no MAC learned**, **VLAN missing**, or **STP blocking**. The exam tests the
L2 verification chain after link (L1) is up.

---

## 2. Core Concepts

### 2.1 L2 verify order

| Step | Check |
|------|-------|
| 1 | link up |
| 2 | VLAN exists |
| 3 | port in VLAN |
| 4 | MAC learned |
| 5 | trunk carries VLAN |
| 6 | STP state |

- **Work up the switch database.**

### 2.2 Port state checks

| Command | Purpose |
|---------|---------|
| `show interfaces status` | vlan/type |
| `show mac address-table` | learned MACs |
| `show vlan` | VLAN list |
| `show interfaces trunk` | trunk info |
| `show spanning-tree` | STP state |

- **`show mac address-table`** proves the switch sees hosts.

### 2.3 Common issues

| Symptom | Likely cause |
|---------|--------------|
| No MAC | wrong VLAN/port |
| Down port | STP blocking |
| Trunk empty | allowed vlan |
| Unknown MAC | vlan mismatch |
| Broadcasts | loop/dup |

- **VLAN mismatch + trunk filtering** = top causes.

### 2.4 Trunk troubleshooting

| Check | Command |
|-------|---------|
| Mode | `switchport mode trunk` |
| Native | mismatch |
| Allowed | `switchport trunk allowed vlan` |
| Encapsulation | 802.1Q |
| VTP | avoid |

- **Native VLAN mismatch** causes silent loss.

### 2.5 STP interference

| Issue | Fix |
|-------|-----|
| Blocked port | expected |
| Root move | priority |
| Loop | BPDU guard |
| Storm | broadcast storm |

- STP block is **normal**; loops are not.

### 2.6 Verification loop

| Stage | Tool |
|-------|------|
| L1 | status |
| L2 | MAC table |
| VLAN | show vlan |
| Trunk | show interfaces trunk |
| STP | spanning-tree |

- **MAC table + VLAN + trunk** resolve most L2 issues.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No connectivity | VLAN | show vlan |
| Trunk drops | allowed/native | trunk |
| Flap | STP | spanning-tree |
| Unknown MAC | port | mac table |
| Broadcast storm | loop | port state |

---

## 5. Exam Traps

- **MAC table = switch proof** of L2 traffic.
- Trunk must carry the **allowed VLAN**.
- **Native VLAN** must match both ends.
- STP **blocking is normal** — look for loops instead.
- Always confirm **VLAN exists** on the switch.
