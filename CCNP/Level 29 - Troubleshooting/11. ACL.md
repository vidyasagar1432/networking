# ACL

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**ACL troubleshooting** checks **order, direction, implicit deny, wildcard masks, and
placement**. Symptoms: traffic silently dropped or wrong traffic passing. Verify with
**`show access-lists`** and **`show ip interface`** (which ACL is applied).

---

## 2. Core Concepts

### 2.1 Verify commands

| Command | Purpose |
|---------|---------|
| `show access-lists` | entries + hits |
| `show access-lists 100` | one list |
| `show ip interface Gi0/1` | applied ACLs |
| `show running-config` | config |
| `debug ip packet` | ACL drops |

- **`show access-lists` shows hit counters.**

### 2.2 Key rules

| Rule | Detail |
|------|--------|
| Order | first match wins |
| Implicit deny | at end |
| Wildcard | inverse mask |
| Direction | in/out |
| Placement | near source/dest |

- **Order matters — first match wins; implicit deny is last.**

### 2.3 Common failures

| Symptom | Likely cause |
|---------|--------------|
| Drop all | implicit deny |
| Wrong filter | mask |
| Not applied | interface |
| No hits | direction |
| Permit too broad | order |

- **Wrong wildcard or placement** is the usual trap.

### 2.4 Wildcard vs subnet mask

| Mask | Meaning |
|------|---------|
| 0.0.0.255 | match /24 |
| 0.0.0.0 | host |
| 255.255.255.0 | subnet (WRONG in ACL) |
| any | all |

- **ACLs use wildcard masks** (inverse of subnet).

### 2.5 Direction/placement

| Item | Best |
|------|------|
| Inbound ACL | closest to source |
| Outbound ACL | on egress |
| Deny | near attacker |
| Permit | near destination |

- **Standard ACLs near destination; extended near source.**

### 2.6 Interface application

| Command | Meaning |
|---------|---------|
| `ip access-group 100 in` | inbound |
| `ip access-group 100 out` | outbound |
| `show ip interface` | verify |
| `no ip access-group` | remove |

- Applied ACLs **filter per direction**.

---

## 3. Configuration / Commands

```text
show access-lists
show ip interface GigabitEthernet0/1
access-list 100 permit tcp 10.0.0.0 0.0.0.255 any eq 80
interface Gi0/1
 ip access-group 100 in
```

---

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| All denied | implicit deny | add permit |
| No effect | direction | show ip interface |
| Wrong hosts | mask | access-lists |
| Hits 0 | placement | counters |
| Too broad | order | reorder |

---

## 5. Exam Traps

- **First match wins; implicit deny at the end.**
- ACL masks are **wildcards**, not subnet masks.
- Direction: **in = as arriving; out = as leaving**.
- `show access-lists` **hit counters** prove matches.
- Standard ACLs **near destination**.
