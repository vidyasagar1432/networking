# NAT

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**NAT troubleshooting** checks **translations, inside/outside interfaces, ACLs, and
pools**. Symptoms: no translation, one-way traffic, or wrong pools. Verify with
**`show ip nat translations`** and **`debug ip nat`**. The exam tests the translation
table and config traps.

---

## 2. Core Concepts

### 2.1 Verify commands

| Command | Purpose |
|---------|---------|
| `show ip nat translations` | table |
| `show ip nat statistics` | counters |
| `show ip nat translations verbose` | detail |
| `debug ip nat detailed` | events |
| `show ip access-lists` | match |

- **Translation table = first look.**

### 2.2 Config requirements

| Item | Detail |
|------|--------|
| Inside interface | `ip nat inside` |
| Outside interface | `ip nat outside` |
| ACL | match source |
| Pool | address range |
| Overload | PAT |

- **Inside/outside assignment is essential.**

### 2.3 Common failures

| Symptom | Likely cause |
|---------|--------------|
| No translation | inside/outside |
| ACL no match | source |
| One-way | return path |
| Pool exhausted | PAT missing |
| Wrong IP | pool/overlap |

- **Wrong inside/outside = classic no-translation.**

### 2.4 Translation types

| Type | Meaning |
|------|---------|
| Static | 1:1 fixed |
| Dynamic | pool |
| Overload | PAT many:1 |
| Inside/outside | direction |
| Outside | destination |

- **Overload = many inside to one outside.**

### 2.5 Return path issues

| Issue | Check |
|-------|--------|
| No return route | route to NAT IP |
| Asymmetric | translation table |
| PAT port | full |
| Incomplete | timeouts |

- NAT is **stateful — return must match the table**.

### 2.6 Debug traps

| Trap | Meaning |
|------|---------|
| ACL miss | no match |
| No available pool | exhausted |
| Interface not inside | config |
| Port conflict | PAT |
| Timeout | aging |

- **Debug shows why translation failed.**

## 3. Configuration / Commands

```text
show ip nat translations
show ip nat statistics
debug ip nat detailed
interface Gi0/1
 ip nat inside
interface Gi0/2
 ip nat outside
access-list 1 permit 10.0.0.0 0.0.0.255
ip nat inside source list 1 interface Gi0/2 overload
```

## 5. Exam Traps

- **Inside/outside keywords** determine NAT operation.
- **Overload = PAT** (many:1).
- Translation table is **stateful**.
- ACL defines **what gets translated**.
- `debug ip nat` reveals **misses**.
