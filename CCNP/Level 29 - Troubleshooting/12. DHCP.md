# DHCP

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**DHCP troubleshooting** traces the **DORA process** and common blockers: no relay
(helper), pool exhaustion, or port conflicts. Verify with **`show ip dhcp binding`,
`debug ip dhcp server`, and pool config**. The exam tests the relay and pool checks.

---

## 2. Core Concepts

### 2.1 DORA process

| Step | Message | Direction |
|------|---------|-----------|
| D | Discover | client → server |
| O | Offer | server → client |
| R | Request | client → server |
| A | Acknowledge | server → client |

- **Discover → Offer → Request → Ack.**

### 2.2 Verify commands

| Command | Purpose |
|---------|---------|
| `show ip dhcp binding` | leases |
| `show ip dhcp pool` | ranges |
| `show ip dhcp conflict` | conflicts |
| `show ip dhcp server statistics` | counts |
| `debug ip dhcp server packets` | flow |

- **Binding table proves leases issued.**

### 2.3 Common failures

| Symptom | Likely cause |
|---------|--------------|
| No IP | pool empty |
| No reply | relay missing |
| APIPA (169.254) | no server |
| Wrong subnet | pool mismatch |
| Duplicate | conflict |

- **No helper = no cross-VLAN DHCP.**

### 2.4 Relay (helper)

| Command | Meaning |
|---------|---------|
| `ip helper-address 10.0.0.1` | forward DHCP |
| Interface | on client VLAN |
| UDP 67/68 | broadcast→unicast |
| Relay | sets giaddr |

- **`ip helper-address`** makes DHCP work across VLANs.

### 2.5 Pool issues

| Check | Command |
|-------|---------|
| Range | network |
| Mask | subnet |
| Default route | default-router |
| Exclusions | excluded-address |
| Leases | lease |

- Pool must **match the client subnet + have space**.

### 2.6 Security issues

| Issue | Fix |
|-------|-----|
| Rogue server | DHCP snooping |
| Exhaustion | rate-limit |
| Conflicts | ping/ARP |
| Authoritative | config |

- **DHCP snooping** blocks rogue servers.
