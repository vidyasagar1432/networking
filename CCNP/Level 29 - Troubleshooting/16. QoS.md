# QoS

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**QoS troubleshooting** checks **classification, marking, policy maps, and interface
counters**. Failures show as no marking, wrong queueing, or drops despite policy. Verify
with **`show policy-map interface`** and counters. The exam tests policy application
and direction.

---

## 2. Core Concepts

### 2.1 Verify commands

| Command | Purpose |
|---------|---------|
| `show policy-map interface` | applied policy |
| `show class-map` | match rules |
| `show policy-map` | config |
| `show mls qos` | trust |
| `show interface counters` | drops |

- **`show policy-map interface` = applied state + counters.**

### 2.2 QoS flow

| Step | Action |
|------|--------|
| 1 | classify |
| 2 | mark |
| 3 | police/shape |
| 4 | queue |
| 5 | monitor |

- **Class → mark → enforce → queue → observe.**

### 2.3 Common failures

| Symptom | Likely cause |
|---------|--------------|
| No marks | trust/cos |
| Drops | policer |
| Wrong class | match |
| Not applied | direction |
| Shaping lost | interface |

- **Direction (in/out) + trust** are the top traps.

### 2.4 Policy checks

| Check | Command |
|-------|---------|
| Applied | show policy-map interface |
| Matches | class-map |
| Drops | counters |
| Rate | police |
| Bytes | class stats |

- **Counters tell if the policy ever matched.**

### 2.5 Trust boundaries

| Item | Detail |
|------|--------|
| Trust COS | switch |
| Trust DSCP | router |
| Untrusted | remark |
| L3 | DSCP |
| L2 | COS |

- **Wrong trust = no preserved marking.**

### 2.6 Queueing issues

| Issue | Fix |
|-------|-----|
| Overflow | buffer |
| Wrong queue | map |
| Congestion | shape |
| Drops | WRED |
| Bandwidth | percent |

- **Drops behind policy = queueing/congestion.**

## 5. Exam Traps

- `show policy-map interface` = **applied reality**.
- Direction matters: **service-policy in/out**.
- **Trust boundary** determines marking.
- Zero counters = **class never matched**.
- Queue drops ≠ policy failure — **congestion**.
