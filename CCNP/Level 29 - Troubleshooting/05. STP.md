# STP

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**STP troubleshooting** finds **loops, root placement, and blocked-port issues**. Key
checks: **root, bridge priority, port roles/states, and topology changes**. Symptoms are
flapping ports, broadcast storms, or unexpected blocking. Verify with `show
spanning-tree`.

---

## 2. Core Concepts

### 2.1 Verify commands

| Command | Purpose |
|---------|---------|
| `show spanning-tree` | root/ports |
| `show spanning-tree vlan 10` | per vlan |
| `show spanning-tree root` | root roles |
| `show spanning-tree detail` | timers |
| `show mac address-table` | loop effect |

- **Root + port roles** are the core picture.

### 2.2 Port roles and states

| Role | State | Meaning |
|------|-------|---------|
| Root port | forwarding | toward root |
| Designated | forwarding | toward segment |
| Alternate | blocking | backup root |
| Backup | blocking | backup desig |
| Disabled | disabled | off |

- **Blocking ports are normal backups.**

### 2.3 Common issues

| Symptom | Likely cause |
|---------|--------------|
| Flapping | dup root/priority |
| Storm | loop unblocked |
| Slow convergence | timers |
| Wrong root | priority |
| MAC flip | loop |

- **Loop = the critical STP failure.**

### 2.4 Root election

| Factor | Win |
|--------|-----|
| Priority | lower |
| MAC | lower tiebreak |
| Manual | `spanning-tree vlan X root primary` |
| Guard | protect |

- Control root with **priority + root primary**.

### 2.5 Protection features

| Feature | Stops |
|---------|-------|
| PortFast | host ports |
| BPDU Guard | rogue switch |
| Root Guard | wrong root |
| Loop Guard | silent failure |
| BPDU Filter | no BPDUs |

- **BPDU Guard + PortFast** on access ports is standard.

### 2.6 Convergence factors

| Item | Detail |
|------|--------|
| Timer | 30 s blocking |
| PortFast | skip blocking |
| RSTP | fast roles |
| TC | flush MAC |
| TCN storm | flapping port |

- **PortFast + RSTP** remove most pain.

## 3. Configuration / Commands

```text
show spanning-tree
show spanning-tree vlan 10
show spanning-tree root
spanning-tree vlan 10 root primary
interface Gi0/1
 spanning-tree portfast
 spanning-tree bpduguard enable
show mac address-table count
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Loop | blocked missing | show spanning-tree |
| Flap | dup priority | root |
| 30 s wait | no portfast | interface |
| Storm | rogue | bpduguard |
| TCN flood | link flap | logs |

---

## 5. Exam Traps

- **Blocking is normal**; loops are the failure.
- Root = **lowest priority**, then lowest MAC.
- **PortFast + BPDU Guard** for access ports.
- Root Guard blocks **wrong root**; Loop Guard blocks silent failure.
- TC storm = **flapping port flushes MACs**.
