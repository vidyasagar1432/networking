# EtherChannel

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**EtherChannel troubleshooting** focuses on **why members don't bundle**. Causes:
protocol/mode mismatch, inconsistent speed/duplex/VLAN config, or STP interference.
Verify with **`show etherchannel summary`** and check member consistency.

---

## 2. Core Concepts

### 2.1 Verify commands

| Command | Purpose |
|---------|---------|
| `show etherchannel summary` | bundle state |
| `show etherchannel port-channel` | members |
| `show etherchannel load-balance` | hash |
| `show interfaces Gi0/1 etherchannel` | member |
| `show etherchannel detail` | reasons |

- **`show etherchannel summary`** = first stop.

### 2.2 Bundle states

| State | Meaning |
|-------|---------|
| P | in bundle |
| I | standalone |
| D | down |
| S | suspended |
| U | up in bundle |

- A member that won't bundle shows **I or S**.

### 2.3 Consistency rules

| Item | Must Match |
|------|------------|
| Speed | all members |
| Duplex | all members |
| VLAN config | access/trunk |
| Native/trunk | trunk ports |
| Mode | both ends |

- **Inconsistent members won't bundle.**

### 2.4 Mode issues

| Side A | Side B | Result |
|--------|--------|--------|
| active | active | bundle (LACP) |
| active | passive | bundle (LACP) |
| passive | passive | NO bundle |
| desirable | desirable | bundle (PAgP) |
| on | on | bundle (static) |

- **passive+passive or auto+auto never bundles.**

### 2.5 STP and other conflicts

| Conflict | Impact |
|----------|--------|
| STP per-member | not a LAG |
| Different allowed VLAN | mismatch |
| Misconfigured port | suspended |
| One port error | member down |

- The **bundle is one logical STP port**.

### 2.6 Load balance

| Check | Detail |
|-------|--------|
| Algorithm | `show etherchannel load-balance` |
| Hash | src/dst MAC/IP |
| In-order | per flow |
| Fix | `port-channel load-balance ...` |

- Hash **must fit the traffic type**.

## 3. Configuration / Commands

```text
show etherchannel summary
show etherchannel port-channel
show etherchannel detail
show interfaces GigabitEthernet0/1 etherchannel
interface Port-channel1
 channel-group 1 mode active (per member)
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Not bundled | mode mismatch | summary |
| Suspended | config mismatch | detail |
| One member down | cable | status |
| No load share | hash | load-balance |
| STP block | not LAG | spanning-tree |

---

## 5. Exam Traps

- **passive/passive and auto/auto won't bundle.**
- Members must match **speed, duplex, VLAN**.
- `show etherchannel summary` shows **P/I/S/U**.
- Bundle = **one STP port**.
- `mode on` = **static, no negotiation**.
