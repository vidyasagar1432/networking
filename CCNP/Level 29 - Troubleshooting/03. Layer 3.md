# Layer 3

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Layer 3** is routing: interfaces up, routes present, adjacency healthy, and packets
forwarded. Use **ping, traceroute, `show ip route`, and `show ip interface`** in that
order. The exam tests the routing-verification sequence and common L3 failures.

---

## 2. Core Concepts

### 2.1 L3 verify order

| Step | Check |
|------|-------|
| 1 | L1/L2 up |
| 2 | IP on interface |
| 3 | neighbor/adjacency |
| 4 | route in table |
| 5 | path reaches |
| 6 | policy (ACL/NAT) |

- **Interface → adjacency → route → reachability.**

### 2.2 Commands

| Command | Purpose |
|---------|---------|
| `show ip interface brief` | up + IP |
| `show ip route` | table |
| `show ip route <net>` | specific |
| `show ip protocols` | routing running |
| `ping` / `traceroute` | path |
| `show ip arp` | L3→L2 |

- **`show ip route`** proves the route exists.

### 2.3 Common issues

| Symptom | Likely cause |
|---------|--------------|
| No route | adjacency/protocol |
| Route but no ping | ACL/NAT |
| Partial path | return path |
| Default only | redistribution |
| Asymmetric | policies |

- **Check both directions** — return path often breaks.

### 2.4 Adjacency issues

| Issue | Fix |
|-------|-----|
| OSPF stuck | hello/mtu |
| BGP idle | reachability |
| EIGRP down | K-values |
| Passive | timers |

- Adjacency = **protocol health before routes**.

### 2.5 Packet flow test

| Tool | Gives |
|------|-------|
| `ping` | end-to-end L3 |
| `traceroute` | hop-by-hop |
| `show ip cef` | hardware forwarding |
| `debug ip packet` | control plane |
| `policy-map` check | QoS/NAT |

- **traceroute reveals where the path dies.**

### 2.6 Escalation

| Stage | Action |
|-------|--------|
| 1 | verify routes |
| 2 | ping/tr |
| 3 | check ACL/NAT |
| 4 | debug control plane |
| 5 | traffic capture |

- Methodical: **route → path → policy → packet.**

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No route | adjacency | show ip ospf neigh |
| No ping | ACL | access-list |
| Half path | NAT | show ip nat trans |
| No CEF | adj | show ip cef |
| Blackhole | sum/no default | route lookup |

---

## 5. Exam Traps

- **Route exists ≠ reachable** — check ACL/NAT/return path.
- `show ip route` = control plane; `show ip cef` = **hardware**.
- Check **adjacency before route**.
- Always verify **return direction**.
- traceroute pinpoints **the failing hop**.
