# OSPF

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**OSPF troubleshooting** targets **adjacencies, areas, networks, and routes**. Typical
failures: **hello mismatch, MTU, area type, passive interface, network type**. Verify
adjacency first, then route propagation. The exam tests `show ip ospf` command chains.

---

## 2. Core Concepts

### 2.1 Adjacency requirements

| Requirement | Check |
|-------------|-------|
| Hello interval | `ip ospf hello-interval` |
| Dead interval | default 4x hello |
| Network type | broadcast/ptp |
| Area | must match |
| MTU | match or negotiation |
| Authentication | must match |

- **MTU + hello + area mismatches** kill adjacencies.

### 2.2 Verify commands

| Command | Purpose |
|---------|---------|
| `show ip ospf neighbor` | adjacency |
| `show ip ospf interface` | config |
| `show ip ospf database` | LSDB |
| `show ip route ospf` | OSPF routes |
| `debug ip ospf adj` | adjacency events |

- **Neighbor table first; then LSDB and routes.**

### 2.3 Stuck states

| State | Meaning |
|-------|---------|
| 2WAY | passive/no DR |
| EXSTART | MTU |
| EXCHANGE | MTU/parse |
| LOADING | flooding |
| FULL | complete |

- **Stuck EXSTART/EXCHANGE = MTU mismatch** classic.

### 2.4 Common failures

| Symptom | Likely cause |
|---------|--------------|
| No neighbor | network type |
| No route | area/mismatch |
| DR flapping | priorities |
| Default missing | redistribution |
| Not in LSDB | filter |

- **Area + network type** cause most adjacency gaps.

### 2.5 Route issues

| Issue | Fix |
|-------|-----|
| Not advertised | network statement |
| Passive | enable |
| Wrong cost | bandwidth |
| Not redistributed | metric |
| Summarized wrong | area range |

- **`network`/`area` statements define what's advertised.**

### 2.6 Network types

| Type | Default | Notes |
|------|---------|-------|
| Broadcast | Ethernet | DR/BDR |
| Non-broadcast | NBMA | manual neigh |
| Point-to-point | links | no DR |
| Point-to-multipoint | hub | no DR |

- **P2P vs broadcast** changes DR behavior.

## 5. Exam Traps

- **MTU mismatch = stuck EXSTART**.
- Adjacency needs **matching hello/dead, area, auth, network type**.
- `show ip ospf neighbor` = **first check**.
- P2P **has no DR/BDR**.
- Passive interface = **advertise, no adjacency**.
