# VPN

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**VPN troubleshooting** checks the **tunnel, IKE phases, transforms, and interesting
traffic**. Failures show as no tunnel, crypto not established, or no traffic protected.
Verify **`show crypto`** chain and **`debug crypto`**. The exam tests IKEv1/v2 states.

---

## 2. Core Concepts

### 2.1 Verify commands

| Command | Purpose |
|---------|---------|
| `show crypto isakmp sa` | IKE phase 1 |
| `show crypto ipsec sa` | phase 2 + traffic |
| `show crypto map` | config |
| `show crypto session` | sessions |
| `show ip interface` | crypto applied |

- **IKE SA + IPSec SA** are the two checks.

### 2.2 IKE phases

| Phase | Purpose |
|-------|---------|
| Phase 1 | ISAKMP (IKE SA) |
| Phase 2 | IPSec SA (traffic) |
| IKEv1 | main/aggressive |
| IKEv2 | single exchange |

- **Phase 1 = tunnel to build tunnel; Phase 2 = data tunnel.**

### 2.3 Common failures

| Symptom | Likely cause |
|---------|--------------|
| No IKE SA | proposal/auth |
| No IPSec SA | interesting traffic |
| SA but no traffic | ACL/proxy ID |
| Flap | DPD |
| One-way | crypto map |

- **Interesting traffic (ACL) gates Phase 2.**

### 2.4 Parameter matching

| Item | Both Sides |
|------|------------|
| Proposal | encrypt/hash |
| Auth | PSK/cert |
| Lifetime | seconds |
| DH group | match |
| Proxy IDs | ACL match |

- **Mismatch in any parameter blocks the tunnel.**

### 2.5 Debug commands

| Command | Use |
|---------|-----|
| `debug crypto isakmp` | phase 1 |
| `debug crypto ipsec` | phase 2 |
| `debug crypto ikev2` | IKEv2 |
| `debug crypto session` | general |
| `clear crypto sa` | reset |

- **Debug reveals negotiation failures.**

### 2.6 Tunnel vs traffic

| Layer | Symptom |
|-------|---------|
| Tunnel up | both SAs |
| No tunnel | phase 1 |
| No data | proxy/ACL |
| Packet drop | crypto map |
| MTU | fragmentation |

- **Tunnel can be up while traffic isn't protected.**

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No phase1 | proposal | isakmp sa |

| Up no data | proxy | crypto map |
| Flap | DPD | config |
| MTU | fragmentation | packet |

---

## 5. Exam Traps

- **Phase 1 = IKE SA; Phase 2 = IPSec SA.**
- **Interesting traffic (ACL) must match for Phase 2.**
- Parameters must **match on both ends**.
- Tunnel up ≠ **traffic protected**.
- `clear crypto sa` = **reset** tunnels.
