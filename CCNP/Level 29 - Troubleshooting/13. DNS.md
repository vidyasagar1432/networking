# DNS

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**DNS troubleshooting** resolves name resolution failures: server unreachable, wrong
records, TTL/negative cache, or search-domain issues. Verify with **`nslookup`, `dig`,
`ping name`, and `show hosts`**. The exam tests the resolution chain.

---

## 2. Core Concepts

### 2.1 Resolution flow

| Step | Action |
|------|--------|
| 1 | local hosts file |
| 2 | DNS cache |
| 3 | query server |
| 4 | authoritative |
| 5 | response/cache |

- **Local cache → configured server → authoritative.**

### 2.2 Verify tools

| Tool | Purpose |
|------|---------|
| `nslookup name` | query |
| `dig name` | full detail |
| `ping name` | resolution + ICMP |
| `show hosts` | cache |
| `show ip dns` | IOS resolver |

- **nslookup/dig** isolate DNS from connectivity.

### 2.3 Common failures

| Symptom | Likely cause |
|---------|--------------|
| NXDOMAIN | wrong name |
| No answer | server |
| Timeout | firewall/UDP 53 |
| Old IP | TTL/cache |
| Wrong host | search domain |

- **Server reach + record type** dominate.

### 2.4 Record types

| Record | Maps |
|--------|------|
| A | name → IPv4 |
| AAAA | name → IPv6 |
| PTR | IP → name |
| CNAME | alias |
| MX | mail |
| NS | nameserver |

- **A/AAAA for lookup; PTR for reverse.**

### 2.5 IOS resolver

| Command | Meaning |
|---------|---------|
| `ip name-server 10.0.0.1` | server |
| `ip domain-lookup` | enable |
| `ip domain-name corp.com` | suffix |
| `show hosts` | cache |
| `no ip domain-lookup` | disable |

- Configure the **name-server + domain** on IOS.

### 2.6 Caching/timeouts

| Item | Detail |
|------|--------|
| TTL | record lifetime |
| Negative cache | NXDOMAIN cached |
| Timeout | 5 s default |
| Retry | query resend |

- **TTL + negative cache** explain stale results.

---

## 3. Configuration / Commands

```text
ip name-server 10.0.0.1
ip domain-lookup
ip domain-name corp.com
show hosts
nslookup server.corp.com
dig server.corp.com
debug ip domain
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| NXDOMAIN | typo | dig |
| No answer | type | record |
| Timeout | UDP 53 | firewall |
| Stale | TTL | cache |
| Wrong suffix | domain-name | config |

---

## 5. Exam Traps

- **UDP 53** for queries; TCP for big answers.
- `nslookup`/`dig` separate **DNS from ping**.
- NXDOMAIN ≠ **server down** — check type and name.
- TTL = **why old IP persists**.
- IOS: `ip name-server` + `ip domain-lookup`.
