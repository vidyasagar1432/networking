# Wireless

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Wireless troubleshooting** covers RF issues, client association, authentication, and
controller problems. Symptoms: weak signal, no association, slow rates, or roaming
gaps. The exam tests the RF → association → auth → DHCP chain.

---

## 2. Core Concepts

### 2.1 Troubleshoot order

| Step | Check |
|------|-------|
| 1 | RF/signal |
| 2 | association |
| 3 | authentication |
| 4 | DHCP/IP |
| 5 | roaming |

- **RF first; then association → auth → IP.**

### 2.2 RF checks

| Item | Detail |
|------|--------|
| Signal | RSSI/SNR |
| Interference | channels |
| AP coverage | floor plan |
| Client rate | lowest |
| Retries | quality |

- **Interference + weak RSSI** = top RF issues.

### 2.3 Association issues

| Issue | Cause |
|-------|-------|
| No associate | SSID hidden/ACL |
| Disconnect | client support |
| Weak | coverage |
| Roam fail | fast roam |
| Auth fail | PSK/802.1X |

- **SSID + security** gate association.

### 2.4 Controller checks

| Command | Purpose |
|---------|---------|
| `show ap summary` | AP state |
| `show ap dot11 5ghz ...` | radio |
| `show client summary` | clients |
| `show client detail` | state |
| `show wlan summary` | WLANs |

- **AP + client tables** on the controller.

### 2.5 Client issues

| State | Meaning |
|-------|---------|
| Assoc | MAC joined |
| Auth | security passed |
| IP | DHCP done |
| Run | working |
| Idle | no traffic |

- **Client can associate but fail DHCP/auth.**

### 2.6 Common failure matrix

| Symptom | Likely cause |
|---------|--------------|
| No signal | AP/radio down |
| No assoc | SSID/security |
| Slow | interference/rate |
| No IP | DHCP helper |
| Roam drop | fast roam off |

- Map **symptom → RF vs assoc vs IP**.

---

## 5. Exam Traps

- Order: **RF → association → auth → IP**.
- Client **associated ≠ authenticated**.
- `show ap summary` = **AP health**.
- Roaming issues → **fast roam + coverage**.
- 5 GHz vs 2.4 GHz — **interference differs**.
