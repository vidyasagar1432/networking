# EIGRP

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**EIGRP troubleshooting** handles **neighbor, K-value, split horizon, and route
issues**. Failures show as no neighbors, stuck-in-active (SIA), or missing routes.
Verify neighbors first, then topology and routes. The exam tests `show ip eigrp`
chains.

---

## 2. Core Concepts

### 2.1 Neighbor requirements

| Requirement | Detail |
|-------------|--------|
| AS number | must match |
| K-values | must match |
| Hello/dead | match timers |
| Network | in AS |
| Auth | match |

- **AS + K-values mismatches block neighbors.**

### 2.2 Verify commands

| Command | Purpose |
|---------|---------|
| `show ip eigrp neighbors` | adjacencies |
| `show ip eigrp topology` | routes/cost |
| `show ip eigrp interfaces` | running ifs |
| `show ip eigrp traffic` | packets |
| `debug eigrp packets` | activity |

- **Neighbor table first.**

### 2.3 Neighbor states

| State | Meaning |
|-------|---------|
| Init | hello seen |
| Pending | waiting |
| Up | established |
| Active | querying |
| Passive | converged |

- **Active = a route is in query (possible SIA).**

### 2.4 Common failures

| Symptom | Likely cause |
|---------|--------------|
| No neighbor | K-value/AS |
| SIA | slow reply |
| Missing route | summary/split-horizon |
| Suboptimal | metric |
| Flap | hello dead |

- **SIA = stuck in active** from a missing reply.

### 2.5 Route/table issues

| Issue | Fix |
|-------|-----|
| Not advertised | network/redistribute |
| Feasible successor | variance |
| Split horizon | on hub |
| Stub | no queries |
| Summary | leak-map |

- **Stub routers** stop queries on hub-and-spoke.

### 2.6 Passive vs active

| Term | Meaning |
|------|---------|
| Passive route | stable |
| Active route | computing |
| Query | asks neighbors |
| Reply | answers |
| SIA | no reply |

- **Active routes = recomputation; watch for SIA.**

## 5. Exam Traps

- **K-values + AS must match** for neighbors.
- SIA = **stuck in active** (query timeout).
- Split horizon on **hub links** can drop routes.
- **Stub = no queries** in hub-spoke.
- Neighbor table = **first verification**.
