# Layer 1

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Layer 1** is the physical layer — cable, connector, power, light. Every failure above
starts here. Troubleshoot with **`show interfaces status`**, **link light**, and loopback
tests. The exam tests interface states and the physical-to-logical chain.

---

## 2. Core Concepts

### 2.1 Interface states

| State | Meaning |
|-------|---------|
| up/up | link + line |
| up/down | admin up, no link |
| down/down | shutdown or no link |
| administratively down | `shutdown` |
| err-disabled | violation |
| SFM | no media connected |

- **First word = admin/line; second = physical link.**

### 2.2 Layer 1 checks

| Check | Tool |
|-------|------|
| Cable | physical |
| Light | optics |
| Speed/duplex | config |
| SFP | `show interface transceiver` |
| Power | PSU/PoE |

- Start with **cable and optics**.

### 2.3 Common causes

| Symptom | Likely cause |
|---------|--------------|
| No link | cable |
| up/down | wrong cable/port |
| Errors | duplex/speed |
| Flap | connector |
| Err-disabled | violation |

- **Duplex mismatch** = classic error storm.

### 2.4 Verify commands

| Command | Purpose |
|---------|---------|
| `show interfaces status` | summary |
| `show interfaces` | counters |
| `show interface transceiver` | optics |
| `show ip interface brief` | states |
| `ping` | L3 after L1 |

- Use **status + counters** to isolate.

### 2.5 Loopback test

| Test | Result |
|------|--------|
| `no shutdown` | link up? |
| Swap cable | isolates cable |
| Loopback plug | port test |
| `test cable-diagnostics` | wire pairs |

- **Cable-diag** diagnoses physical wires.

### 2.6 Escalation path

| Step | Action |
|------|--------|
| 1 | verify config |
| 2 | reseat/replace cable |
| 3 | swap SFP/port |
| 4 | loopback |
| 5 | RMA |

- Physical first; **config is step 1 only after link**.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| down/down | shutdown | no shutdown |
| up/down | cable/SFP | swap |
| Errors | duplex | speed |
| Flap | connector | reseat |
| No light | transceiver | replace |

---

## 5. Exam Traps

- **up/down** = admin up but no physical link.
- First word = **admin**, second = **protocol/physical**.
- Duplex mismatch → **errors, not no-link**.
- `show interfaces status` = quick table.
- Always rule out **L1 before routing**.
