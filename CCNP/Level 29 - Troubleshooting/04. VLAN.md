# VLAN

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**VLAN troubleshooting** covers missing VLANs, wrong port assignment, trunk filtering,
and native VLAN mismatch. Symptoms are **no reachability within a subnet** or traffic
crossing wrong VLANs. Verify with **`show vlan`, `show interfaces trunk`, and the MAC
table**.

---

## 2. Core Concepts

### 2.1 Verify chain

| Step | Command |
|------|---------|
| 1 | `show vlan` |
| 2 | `show interfaces status` |
| 3 | `show interfaces trunk` |
| 4 | `show mac address-table` |

- **VLAN must exist and carry the port.**

### 2.2 Common failures

| Symptom | Likely cause |
|---------|--------------|
| Port missing | not in VLAN |
| Trunk no pass | allowed vlan |
| Wrong broadcast | native mismatch |
| No DHCP | IP helper missing |
| Intermittent | VTP/dup |

- **Allowed list** and **native VLAN** are the usual suspects.

### 2.3 Trunk issues

| Check | Command |
|-------|---------|
| Mode | `switchport mode trunk` |
| Native | both ends equal |
| Allowed | `switchport trunk allowed vlan` |
| Encapsulation | dot1q |
| Pruning | none |

- Trunk carries **only allowed VLANs**.

### 2.4 Port-to-VLAN

| Command | Meaning |
|---------|---------|
| `switchport access vlan 10` | assign |
| `switchport mode access` | force access |
| `show interfaces Gi0/1 switchport` | detail |
| `no switchport` | L3 port |

- **Access port = one VLAN; check the assignment.**

### 2.5 Native VLAN

| Issue | Impact |
|-------|--------|
| Mismatch | control issues |
| Untagged | both must agree |
| Trunk | native 1 default |
| Security | change + prune |

- **Native VLAN must match** on both trunk ends.

### 2.6 MAC/VLAN correlation

| Check | Meaning |
|-------|---------|
| MAC learned | host seen |
| VLAN correct | shown in table |
| Wrong VLAN | duplicate/port |
| Rogue | unknown MAC |

- The MAC table proves **which VLAN a host lives in**.

## 3. Configuration / Commands

```text
show vlan brief
show vlan id 10
show interfaces trunk
show interfaces Gi0/1 switchport
show mac address-table vlan 10
show ip arp
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No VLAN | create | show vlan |
| Port dead | access vlan | switchport |
| Trunk drops | allowed | trunk |
| Cross traffic | native | both ends |
| DHCP fail | no helper | config |

---

## 5. Exam Traps

- **VLAN must exist** before assignment works.
- Trunk **allowed list** gates which VLANs cross.
- **Native VLAN mismatch** = silent breakage.
- `show vlan` ≠ what a trunk passes.
- MAC table = **ground truth of VLAN membership**.
