# SD-WAN

> **Level 29 · Troubleshooting** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SD-WAN troubleshooting** checks the **control plane (vManage/vSmart), data plane
(transport tunnels), and policy**. Failures: control connections down, TLOC issues,
or policy dropping traffic. Verify with **`show sdwan control`** and **`show sdwan
policy`**. The exam tests the vEdge/cEdge command set.

---

## 2. Core Concepts

### 2.1 Architecture check

| Component | Health |
|-----------|--------|
| vManage | admin UI |
| vSmart | control policy |
| vBond | orchestration |
| vEdge/cEdge | data plane |
| vAnalytics | reporting |

- **Control connections must be up** before data works.

### 2.2 Verify commands

| Command | Purpose |
|---------|---------|
| `show sdwan control connections` | to vSmart/vBond |
| `show sdwan tunnel` | data tunnels |
| `show sdwan interface` | transport |
| `show sdwan policy` | applied |
| `show sdwan running-config` | config |

- **Control + tunnel tables** are the core.

### 2.3 Common failures

| Symptom | Likely cause |
|---------|--------------|
| No control | DTLS/route |
| Tunnel down | TLOC |
| No policy | vSmart |
| Apps wrong | match |
| BFD down | transport |

- **Control plane first; then tunnels + policy.**

### 2.4 Control plane issues

| Issue | Check |
|-------|-------|
| vBond unreachable | DNS/IP |
| DTLS | port 12346 |
| vSmart no conn | certificates |
| BFD | transport |
| Oversubscription | links |

- **vBond + vSmart connections** gate the overlay.

### 2.5 Policy issues

| Item | Detail |
|------|--------|
| Applied | vSmart |
| Match | data-prefix/app |
| Action | drop/permit |
| Centralized | control/data |
| Localized | interface |

- **Wrong match or action** = traffic dropped.

### 2.6 Data plane

| Check | Command |
|-------|---------|
| TLOC | tunnels |
| Transport | interface |
| App awareness | match |
| SLA | BFD |
| Failover | policy |

- **BFD/SLA drives path selection + failover.**
