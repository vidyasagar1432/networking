# DHCPv6

> **Level 06 · IPv6** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**DHCPv6** (RFC 3315) is IPv6's stateful addressing/configuration protocol — the
server tracks **leases** the way DHCPv4 does, plus delivers **options (DNS, domain,
NTP)**. It complements (or fully replaces) SLAAC depending on the **M/O RA flags**.

---

## 2. Core Concepts

### 2.1 The message flow
```
client ── SOLICIT ──────────────▶ ff02::1:2 (all DHCP servers)
server ── ADVERTISE (unicast) ─▶ client
client ── REQUEST ──────────────▶ server
server ── REPLY  ───────────────▶ client (assignment + options)
```
- **Solicit** is **multicast** to `ff02::1:2` — IPv6 has no broadcast.
- Confirm/Renew/Rebind for lease maintenance (like DHCPv4).

### 2.2 Stateful vs stateless (in RA flags)

| Mode | M flag | O flag | What DHCPv6 does |
|------|--------|--------|------------------|
| **Stateful** | 1 | — | assigns **addresses** (IA_NA) |
| **Stateless** | 0 | 1 | **no address**, only **options** (IA_NASKS full: DNS via Info-Request) |
| SLAAC only | 0 | 0 | DHCPv6 not used at all |
- Stateful = "Managed M=1"; stateless = "Other-config O=1".
- Common enterprise: **SLAAC + stateless DHCPv6 for DNS** (A=1,O=1).

### 2.3 Addresses and IAs
- **IA_NA** (non-temporary address), **IA_TA** (temporary), **IA_PD** (prefix
  delegation — for CPEs delegating a /56 to downstream routers).
- Server sends **preferred/preferred lifetime + valid lifetime**.

### 2.4 Server discovery & routing
- Servers listen on UDP **546** (client) / **547** (server) — ports worth memorizing.
- If no DHCPv6 server is on the segment, use a **relay agent** (like DHCPv4 relay):
  the router forwards Solicit to a far server (with -I interface), inserts Relay-Info.

### 2.5 DHCPv6 vs SLAAC (when to pick)

| Need | Choose |
|------|--------|
| Zero-config, no server | SLAAC |
| Tracking, options, control | DHCPv6 |
| Best of both (industry norm) | SLAAC + stateless DHCPv6 for DNS |
| Prefix delegation to CPE | DHCPv6 PD |

## 3. Configuration / Commands

```text
# Server on IOS (device serving a LAN)
ipv6 dhcp pool CORP
 address prefix 2001:db8:1:10::/64 lifetime 2592000 604800
 dns-server 2001:db8:53::1
 domain-name corp.example

interface GigabitEthernet0/1
 ipv6 address 2001:db8:1:10::1/64
 ipv6 dhcp server CORP
 ipv6 nd managed-config-flag           # M=1 → clients use DHCPv6 for address
 ipv6 nd other-config-flag             # O=1 → clients use DHCPv6 for DNS

# Client/CPE side
interface GigabitEthernet0/1
 ipv6 dhcp client pd PD-CLIENT

show ipv6 dhcp binding
show ipv6 dhcp interface
```

---

## 4. Exam Traps

- **SOLICIT is multicast `ff02::1:2`** — no broadcast in IPv6 (a favorite).
- **Ports 546/547** — client 546, server 547.
- **Stateful vs stateless** is decided by **RA M/O flags**, not by DHCPv6 itself.
- **For DNS** use RDNSS (SLAAC) or DHCPv6 options (stateless) — both are exam facts.
- **RA still configures the default route** — even in DHCPv6 mode, ND/RAs give the
  default gateway (unlike v4 where DHCP gives it).
