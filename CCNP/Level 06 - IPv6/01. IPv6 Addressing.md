# IPv6 Addressing

> **Level 06 · IPv6** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

IPv6 uses **128-bit** addresses — providing roughly **3.4 × 10^38** addresses. It
solves IPv4 exhaustion and kills NAT for most designs, with **automatic link-local
addressing, SLAAC, and no broadcast**. The address is written as eight groups of four
hex digits.

---

## 2. Core Concepts

### 2.1 128-bit format
```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```
- Eight **hextets** (16-bit groups), hexadecimal `0-9 A-F`.
- Total bits = 8 groups × 16 bits = **128 bits**.
- IPv4's 32 bits ≈ 4.3e9 → IPv6 ≈ 3.4e38 addresses.

### 2.2 Shortening rules

| Rule | Example |
|------|---------|
| **Leading zeros** dropped | `0db8` → `db8`; `0000` → `0` |
| **Double colon `::`** once, for the longest run of zeros | `2001:0db8::0370:7334` |
| `::` can only appear **once** | guarantee ambiguity |
| IPv4-style last groups allowed in some forms | `::ffff:192.168.1.1` (IPv4-mapped) |

Full example:
`2001:0db8:85a3:0000:0000:8a2e:0370:7334` → `2001:db8:85a3::8a2e:370:7334`

### 2.3 Address types by prefix

| Type | Prefix | Example |
|------|--------|---------|
| **Global Unicast (GUA)** | `2000::/3` | `2001:db8:1:10::1` |
| **Link-local** | `fe80::/10` | `fe80::1` |
| **Unique local (ULA)** | `fc00::/7` (fd) | `fd12:3456:789a::1` |
| **Multicast** | `ff00::/8` | `ff02::1` (all nodes) |
| **Anycast** | same as unicast, not enunciable | any GUA address |
| **Loopback** | `::1` | `::1` |
| **Unspecified** | `::` | `::` |
| **IPv4-mapped** | `::ffff:0:0/96` | `::ffff:192.168.1.1` |

### 2.4 IPv6 has no broadcast
- Broadcast replaced by **multicast** (per-link `ff02::1`, solicited-node etc.).
- No ARP: **Neighbor Discovery (ND)** replaces ARP; no fragmentation by routers —
  PMTUD by sender (Level 03 Data Flow).

### 2.5 Subnetting units
- A **/64 = one LAN subnet** (standard; required for SLAAC).
- The **interface ID** (lower 64 bits) may be EUI-64 or random (privacy).
- Common allocations: `/48` per site, `/64` per VLAN; provider gives a `/56`–`/48`.

## 3. Configuration / Commands

```text
# Host commands
ip -6 addr show
ping6 2001:db8::1                     # ping over IPv6
ip -6 route

# Cisco IOS
interface GigabitEthernet0/1
 ipv6 address 2001:db8:1:10::1/64     # static GUA
 ipv6 address fe80::1 link-local      # optional manual LL
 ipv6 enable                          # auto link-local only

show ipv6 interface GigabitEthernet0/1
show ipv6 route
```

---

## 4. Exam Traps

- **Double colon only once** — two `::` = invalid.
- **`2001:db8::` is documentation** (RFC 3849) — not production.
- **`fe80::/10` is ALWAYS present**, not configured manually.
- **SLAAC requires /64** — a /127 or /128 breaks auto-config.
- **No broadcast address** — asking "IPv6 broadcast" is a trick.
- **32 hex digits, 8 groups, not 4.**
