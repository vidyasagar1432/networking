# Unique Local (ULA)

> **Level 06 · IPv6** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Unique Local Addresses (ULAs, RFC 4193)** are the IPv6 equivalent of **RFC 1918
private** space — not globally routable, but practically unique. Prefix **`fc00::/7`**;
the **`fd`** form is what's actually used.

---

## 2. Core Concepts

### 2.1 The /7 and two variants
- `fc00::/7` covers `fc00:...–fdff:...`.
- **`fc00::/8`** = reserved for future/defined by a centrally-assigned semantic.
- **`fd00::/8`** = the L bit set → **locally assigned**; your ULAs live here.

### 2.2 Structure
```
| 7 bits | L | 40-bit global ID | 16-bit subnet | 64-bit interface ID |
 ffdddd + 40-bit random + subnet + IID
```
- Example: `fd12:3456:789a:0001::1` (prefix `fd12:3456:789a::/48`; subnet `0001`).
- The 40-bit global ID should be **randomly generated** to minimize collisions across
  sites.

### 2.3 ULA vs Link-local (don't confuse)

| | ULA (fd) | Link-local (fe80) |
|--|----------|-------------------|
| Scope | site-wide (routable inside) | one link |
| Routed | yes, inside the org | no |
| Purpose | internal-only reachability | neighbor ops |
| Visible outside | no (filtered) | never |
| Privacy | stable internal addresses | per-interface |

### 2.4 ULA vs GUA — when to use

| Scenario | Use |
|----------|-----|
| Internal services (DNS, print, management) | **ULA** — stable, no dependence on ISP |
| Internet-facing | GUA |
| Dual-stack lab, no real ISP prefix | ULA |
| Site mergers | random-ID ULAs (low collision) |
| Migration tooling | ULA for private, GUA grows in parallel |

### 2.5 Filtering rules (router edge)
- **Don't advertise ULA to the Internet** (BGP/EGP outbound prefix filtering includes
  fd00::/8 and fe80::/10).
- Can route ULA internally; NAT not needed (unlike IPv4 private).

## 3. Configuration / Commands

```text
interface GigabitEthernet0/1
 ipv6 address fd12:3456:789a:1::1/64

# Verify
show ipv6 interface Gi0/1 | include fd
show ipv6 route fd12:3456:789a::/48
```

---

## 4. Exam Traps

- **Only `fd00::/8` is locally assigned; `fc00::/8` is for the future.** The "fc vs fd" trap.
- **ULA is site-routable** — unlike link-local; but **never leaves the enterprise**.
- **Not "IPv6 NAT private space"** — you typically don't NAT it; you just route internally.
- **Global ID should be random** — predictable 40-bit IDs cause collisions in designs.
- **`fc00::/7` question:** both fc and fd are inside it; an exam that asks "range of ULA" → fc00::/7.
