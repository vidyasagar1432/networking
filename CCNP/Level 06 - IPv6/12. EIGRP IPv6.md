# EIGRP IPv6

> **Level 06 · IPv6** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**EIGRP for IPv6** brings EIGRP's DUAL convergence to IPv6 — same metrics, timers,
authentication, and route filtering as IPv4 EIGRP, but **no network statements** (address
families instead), **link-local neighbor/next-hop**, and often deployed via **Named Mode**.

---

## 2. Core Concepts

### 2.1 Key differences from EIGRPv4

| Aspect | EIGRP IPv4 | EIGRP IPv6 |
|--------|-----------|------------|
| Neighbors | IPv4, multicast 224.0.0.10 | **ff02::A**, link-local |
| Network statement | `network x.x.x.x` | none — interfaces enable AF |
| Address | n/a | `address-family ipv6 unicast` |
| Names | classic config | classic or **named mode** |
| Metric | K-values | same (composite) |
| RID | required | required (auto 0.0.0.x) |

### 2.2 Configuration approaches
**Classic EIGRP IPv6 (rare on IOS-XE new)**
```
router eigrp NAME ?? — no; classic:
interface Gi0/1
 ipv6 eigrp 100
router eigrp 100
 address-family ipv6 unicast
  router-id 1.1.1.1
```
**Named mode (modern; THE way today)**
```
router eigrp ENCORE
 address-family ipv6 unicast
  network 2001:db8:1:10::/64      # you CAN use network in named AF
  metric weights 0 1 0 1 0 1
 interface Gi0/1
  address-family ipv6 unicast
```

### 2.3 Neighbor/hello stabilization
- **interface-level enables** start EIGRP on a link.
- Link-local next-hop (fe80-based adjacencies) — same stability rule as OSPFv3.
- **Timers**: hello 5 s (3× dead), same as IPv4.

### 2.4 Route behavior & DUAL
- Measures **composite metric** (bandwidth+delay); successor/feasible successor logic
  identical.
- **Summarization** per-interface: `ipv6 summary-address eigrp`, default-route injection.
- Redistribution points: Level 13 (OSPF↔EIGRP) — seed metrics still required.

### 2.5 Multiprotocol & the triple-stack
- Rear big picture: **OSPFv3 can carry IPv4 too; EIGRP named mode covers IPv4+IPv6 in
  one process** — an exam "simplify by one protocol" answer.

## 3. Configuration / Commands

```text
named mode (recommended)
router eigrp ENTERPRISE
 !name; IPv4 AF omitted
 address-family ipv6 unicast
  router-id 1.1.1.1
  network 2001:db8:1:10::/64

interface Gi0/1
 ipv6 address 2001:db8:1:10::1/64
 ! address-family attached automatically

show ipv6 eigrp neighbors
show ipv6 route eigrp
show ipv6 protocols
```

---

## 4. Exam Traps

- **No `network` statements in classic EIGRP IPv6** — interfaces/AF enable it (named mode may use `network`).
- **Link-local neighborhoods**: neighbors listed as fe80::… — don't try to ping them via GUA.
- **EIGRP IPv6 still needs a router-id** — auto top (1024→0.0.0.x may warn).
- **Metric weights/K-values carry over** — same composite; don't change lightly.
- **ff02::A is the EIGRP multicast in IPv6**, not 224.0.0.10.
