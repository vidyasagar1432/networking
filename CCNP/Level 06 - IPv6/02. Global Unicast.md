# Global Unicast (GUA)

> **Level 06 · IPv6** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Global Unicast Addresses (GUAs)** are the public, routable IPv6 addresses a host
usefully needs — equivalent to IPv4 public addresses, but **plentiful**, so NAT is
optional. Prefix range: **`2000::/3`** (2000:…–3FFF:…).

---

## 2. Core Concepts

### 2.1 Structure
```
|  global routing prefix  |  subnet  |  interface ID  |
|  /48 (ISP global)       |  /64     |  last 64 bits  |
```
- **Global routing prefix** — the ISP-assigned portion (e.g., `/48`).
- **Subnet ID** — site-defined (bits 49–64).
- **Interface ID** — lower 64 bits; EUI-64 (derived from MAC) or random/privacy.

### 2.2 /64 rule
- Every LAN is a **/64** — needed for **SLAAC** and ND optimizations.
- You can subdivide to /64 only; /48 site has 65,536 /64 subnets.

### 2.3 How a host gets a GUA

| Method | Source |
|--------|--------|
| **SLAAC** | router RA advertises prefix → host self-configures `prefix+interface-ID` |
| **DHCPv6** | stateful server hands address + options |
| **DHCPv6-PD** | site router delegates a prefix (e.g., /56) to a CPE |
| **Static** | manual on interfaces |

### 2.4 GUA vs Link-local (the correct reachability story)
- A host's **GUA is optional**; **link-local is mandatory** (auto). Many exam questions
  probe "can two IPv6 hosts ping without a GUA?" → yes, with link-local (same segment).
- Multi-hop routing uses GUA (link-local only on directly-connected links).
- `ping6` from a router prefers source = interface's own address.

### 2.5 Addressing best practices (Cisco)
- Use **tracked prefix from ISP** or **PD** for site.
- Keep **/64 per VLAN**, sequential subnets.
- Consider **privacy extensions** (temporary randomized interface IDs) on user hosts
  to defeat host tracking.

## 3. Configuration / Commands

```text
# Static GUA on a router interface
interface GigabitEthernet0/1
 ipv6 address 2001:db8:1:10::1/64

# Enable ND/SLAAC serving on this segment (RA is default with ipv6 enable)
interface GigabitEthernet0/1
 ipv6 nd prefix 2001:db8:1:10::/64

# Verify
show ipv6 interface GigabitEthernet0/1 | include prefix
show ipv6 route 2001:db8:1:10::/64
```

---

## 4. Exam Traps

- **`2001:db8::/32` is documentation-only** — never deployed; used in exam lab answers.
- **GUA is not automatically present** — link-local is; a host with only link-local has
  no Internet path.
- **NAT for IPv6 is unusual** (NPTv6 prefix translation exists) — don't answer "NAT is
  required" for IPv6.
- **EUI-64** alters the MAC (flips U/L bit, inserts fffe) — a favorite calculation trap.
- **Privacy (RFC 4941)** means the interface ID rotates — don't assume EUI‑64 permanently.
