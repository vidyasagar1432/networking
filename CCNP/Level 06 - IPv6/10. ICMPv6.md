# ICMPv6

> **Level 06 · IPv6** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**ICMPv6** (RFC 4443) is IPv6's control protocol — the **error reporting**, **echo**,
and **messaging foundation** that carries **ND** and **MLD** as submodules. Unlike
IPv4-only error use, ICMPv6 is *essential*: without PMTUD (Packet Too Big) IPv6
can't work across MTU limits.

---

## 2. Core Concepts

### 2.1 ICMPv6 message classes

| Class | Types | Purpose |
|-------|-------|---------|
| **Error** | 1 (Destination Unreachable) / 2 Packet Too Big / 3 Time Exceeded / 4 Parameter Problem | problem reporting |
| **Informational** | 128 Echo Request / 129 Echo Reply | ping6 |
| **ND submodule** | 133 RS, 134 RA, 135 NS, 136 NA, 137 Redirect | neighbor ops |
| **MLD submodule** | 130 MLD query, 131 report, 132 done | listener mgmt |

### 2.2 Error details you should quote

| Type | Code | Meaning |
|------|------|---------|
| 1 | 0 | no route to dest |
| 1 | 1 | administratively prohibited (firewall!) |
| 1 | 3 | address unreachable |
| 1 | 4 | port unreachable (like ICMPv4) |
| 2 | 0 | **Packet Too Big (PTB)** — *the fragmentation-replacement* |
| 3 | 0 | hop limit exceeded → traceroute (like TTL exceeded) |
| 4 | — | malformed header/option |

### 2.3 PMTUD — the "no routers fragment" story
- IPv6 routers **never fragment**. If a packet is too big for the next link, the
  router sends **ICMPv6 Type 2 (PTB)** with the **link MTU**; the sender re-sends a
  shrink packet to that MTU.
- If PTB is filtered → **big packets black-hole** (MTU black hole) — Level 01 MTU.
- **traceroute6 / ping6 size** tests diagnose.

### 2.4 ND/MLD ride on ICMPv6
- ND = Types 133–137 (see ND note).
- MLD = Types 130–132 (IPv6 IGMP analog).
- This grouping means "ICMPv6 is a suite, not just one ping function."

### 2.5 ICMPv6 vs ICMPv4 quick

| | ICMPv4 | ICMPv6 |
|--|--------|--------|
| Fragmentation | routers may fragment | only sender (PTB) |
| ARP helper | no | ND is part of it |
| Multicast listener | IGMP | MLD |
| Two-layer checksum | sometimes (checksum required) | always required |
| Security | often filtered | should be permitted for PTB/ND/MLD |
| Directions | same echo | same |

## 3. Configuration / Commands

```text
# ping6 / traceroute6 (echo is ICMPv6 128/129)
ping6 2001:db8::1
traceroute6 2001:db8:53::1

# Router-side ICMPv6 utilities
show ipv6 mtu
debug ipv6 icmp
# Ensure PTB allowed in ACLs (allow type 2)
ipv6 access-list PERMIT-ICMP6
 permit icmp any any packet-too-big
```

---

## 4. Exam Traps

- **PTB (Type 2) is how IPv6 fits MTU** — never answer "router fragments."
- **Blocked ICMPv6 breaks IPv6 even if forwarding is on** — allow ND (133-136),
  PTB (2), MLD (130-132) through firewall ACLs.
- **ND and MLD live inside ICMPv6** — the "which protocol does ND use?" → ICMPv6, not ARP.
- **Echo request/reply are 128/129** (not 8/0 like v4).
- **Type 1 code 1** = administratively prohibited → firewall drop signature.
