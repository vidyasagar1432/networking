# Static Routing

> **Level 09 · Routing Fundamentals** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Static routes** are manually configured paths with **AD 1** — the highest trust after
connected routes. They never advertise themselves (unless redistributed), never converge
on their own, and are the foundation of stub networks, hubs, and default routing. A static
route's value is **predictability and low overhead**; its cost is **no auto-failover**.

---

## 2. Core Concepts

### 2.1 The three static route forms

| Form | Syntax | Notes |
|------|--------|-------|
| **Next-hop** | `ip route PREFIX MASK <next-hop>` | may need recursive lookup (note 04) |
| **Interface (linked)** | `ip route PREFIX MASK <interface>` | installed if interface up, no next-hop check |
| **Fully specified** | `ip route PREFIX MASK <int> <next-hop>` | safest, no ambiguity, no recursion |

- **Always prefer next-hop or fully-specified** in exams/design — interface-only statics
  can forward into a void even when the remote end is unreachable.

### 2.2 AD & how statics win

- Static **default AD = 1** → beats OSPF (110), EIGRP (90), RIP (120).
- Change it with a trailing value: `ip route ... 200` (that's a **floating static**, note 09).

### 2.3 Static route metrics & tracking

| Feature | Purpose |
|---------|---------|
| AD suffix | set backup priority (floating) |
| `track` object | tie route to IP-SLA / interface up state |
| Multiple equal statics | ECMP (up to max-paths) |

```text
track 1 ip sla 100 reachability
ip route 10.1.1.0 255.255.255.0 192.0.2.1 track 1
```

- With a `track` object the static only stays in the RIB while the tracked condition holds.

### 2.4 Static + recursive next hop

- `ip route 10.1.1.0 /24 192.0.2.1` where `192.0.2.1` is **not** on a directly connected
  subnet → router resolves via RIB (note 04).
- Works, but on change the static re-resolves; fully-specified avoids surprises.

### 2.5 Null0 static (black hole / discard)

```text
ip route 10.1.1.0 255.255.255.0 Null0
```

- Send matching traffic to the **bit bucket** — used for **route summarization sink**,
  loop prevention, or filtering to the void. Shows as `S` with next hop `Null0`.

### 2.6 When to use statics (design)

| Use case | Why |
|----------|-----|
| Stub network egress | single path, no need for dynamic |
| Default routes | note 10 |
| Backup path | floating static (note 09) |
| Loop prevention | Null0 at summary points |
| Hub-and-spoke | fixed topology |

## 3. Configuration / Commands

```text
! Next-hop (typical)
ip route 10.1.1.0 255.255.255.0 192.0.2.1

! Fully specified (safe)
ip route 10.1.1.0 255.255.255.0 GigabitEthernet0/1 192.0.2.1

! Floating static (backup)
ip route 10.1.1.0 255.255.255.0 192.0.2.1 200

! Null0 blackhole
ip route 10.1.1.0 255.255.255.0 Null0

show ip route static
show ip route 10.1.1.0
show running-config | include ip route
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Static installed but traffic drops | recursive next hop unreachable | `show ip cef prefix` |
| Interface-only static forwards into void | no next-hop validation | prefer next-hop syntax |
| Route missing from RIB | wrong mask / next hop not present / AD beaten | `show ip route`, mask math |
| Silent blackhole | Null0 static too specific | verify Null0 target |
| No failover | single static, no floating/backup | add floating static (note 09) |

---

## 5. Exam Traps

- **Static AD = 1** — wins over ALL dynamic protocols for the same prefix.
- **Interface-only static is risky** — no next-hop reachability check.
- **Fully specified avoids recursion** — the "safest" answer.
- **Null0 routes drop silently** — the classic loop-prevention trick.
- **Statics don't auto-converge** — failover needs floating static or tracking.
- **Redistribution of statics is manual** — statics are not advertised by default.
