# Default Route

> **Level 09 · Routing Fundamentals** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **default route** (`0.0.0.0/0` for IPv4, `::/0` for IPv6) is the **catch-all** — traffic
matching no more specific prefix goes here. On a router it's a static or dynamic default
(`ip route 0.0.0.0 0.0.0.0 ...`); on a host it's the **default gateway**. It is the
lowest-precedence match (shortest prefix) under **longest-prefix-match** (LPM) rules.

---

## 2. Core Concepts

### 2.1 How LPM treats it

```
Packet to 203.0.113.5:
  - 203.0.113.0/24 exists  → use that (longer match wins)
  - else 0.0.0.0/0 exists  → default route (only match left)
  - else → drop ("no route")
```

- The default route is the **shortest prefix**; any more-specific route always beats it.

### 2.2 Creating default routes

| Method | Command / source | When |
|--------|------------------|------|
| Static default | `ip route 0.0.0.0 0.0.0.0 <next-hop>` | stub / edge router |
| Static default | `ip route 0.0.0.0 0.0.0.0 <int>` | interface-based |
| `ip default-network` | legacy | older designs |
| OSPF | `default-information originate` | inject default into area |
| EIGRP | `ip route ... 0.0.0.0/0` + redistribute | distribute into EIGRP |
| DHCP | client default route | hosts |

### 2.3 `default-information originate` (OSPF — exam favorite)

```text
router ospf 1
 default-information originate
```

- Advertises a default route into the OSPF domain **if the router has one** in the RIB.
- `always` keyword forces the default regardless of whether one exists.

### 2.4 Stub / edge design

- Stub routers often run **no dynamic protocol on the edge**, relying on a static default
  toward the provider.
- **Distance-vector stub** (RIP/EIGRP stub) relies on defaults to avoid advertising the
  whole world.

### 2.5 Default route & CEF

- In the FIB, `0.0.0.0/0` is an entry like any other — hardware forwards to its adjacency
  when nothing longer matches (note 05/07).

### 2.6 Default routes vs default gateways (scope)

| Item | Where | Role |
|------|-------|------|
| Default route | router | catch-all in routing table |
| Default gateway | host | single next-hop for off-subnet |
| Gateway of last resort | router (older term) | the "next hop" of the default |

## 3. Configuration / Commands

```text
! Static default
ip route 0.0.0.0 0.0.0.0 192.0.2.1

! Floating default (backup WAN)
ip route 0.0.0.0 0.0.0.0 198.51.100.1 200

! OSPF originate
router ospf 1
 default-information originate

show ip route 0.0.0.0
show ip route static
show ip cef 0.0.0.0/0
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Internet/remote unreachable | no default route | `show ip route 0.0.0.0` |
| Default present but traffic drops | default next hop unreachable | recursive resolution, `show ip cef` |
| Default not advertised to OSPF | `default-information originate` missing | check OSPF config |
| Hosts can't reach Internet | host default gateway wrong | host `ip route` / gateway |
| Blackhole to the void | Null0 default (intentional) | verify intent |

---

## 5. Exam Traps

- **Default route = shortest prefix → only used when nothing longer matches** (LPM).
- **Static default AD = 1** — beats any dynamic default for the same 0/0.
- **`default-information originate`** only works if the router **has** a default (unless `always`).
- **Default gateway (host) ≠ default route (router)** — the classic mixup.
- **Floating default** (AD 200) for WAN backup — couples with note 09.
- Interface-only default with no next-hop check = potential blackhole.
