# Routing Metrics

> **Level 09 · Routing Fundamentals** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **metric** is how a routing protocol *measures a path's cost*. After Administrative
Distance picks the **source** (note 02), the metric picks the **best path** *from that
source*. Each protocol has its own metric math and units, so you can **never compare
metrics across protocols** — that's exactly what AD is for.

---

## 2. Core Concepts

### 2.1 Metric by protocol (memorize units)

| Protocol | Metric | Meaning |
|----------|--------|---------|
| Static | n/a (AD 1 used) | configured cost — no metric math |
| Connected | n/a (AD 0) | always interface-given |
| OSPF | **cost = reference / bandwidth** | 100 Mbps (or 1 Gbps) / BW |
| EIGRP | **composite** | BW + delay (+ load/reliability) |
| RIP | **hop count** | max 15, 16 = unreachable |
| IS-IS | **cost** | fixed per-interface (default 10) |

### 2.2 OSPF cost in detail (most exam-tested)

```
cost = reference-bandwidth / interface-bandwidth
```

| Interface | Default cost (ref 100 Mbps) | Ref 1 Gbps |
|-----------|------------------------------|------------|
| 10 Mbps | 10 | 100 |
| 100 Mbps | 1 | 10 |
| 1 Gbps | 1 | 1 |
| 10 Gbps | 1 | 1 |

- Path cost = **sum of outgoing interface costs** toward the destination.
- `auto-cost reference-bandwidth 1000` keeps <1 Gbps links distinguishable.
- A **Loopback** typical cost is 1 — the classic "why all loopbacks equal-cost" nugget.

### 2.3 EIGRP composite metric

```
metric = [K1·BW + (K2·BW)/(256−load) + K3·delay] × (K5/(reliability+K4))
        (with default K values: K1=K3=1, K2=K4=K5=0)
```

- Effective default: **`BW + delay`** scaled — 10⁷/BW(min) + delay/10.
- Lower composite = better. Changing K values breaks neighbor formation (must match).

### 2.4 RIP hop count

- Metric = **hops to destination**; 16 hops = unreachable (that's RIP's real limit).
- Doesn't consider bandwidth at all — the classic "slow but few-hops path wins" gotcha.

### 2.5 Same protocol → metric compares; different protocol → AD compares

| Situation | What breaks the tie |
|-----------|---------------------|
| Two OSPF paths | lower cost wins |
| Two EIGRP paths | lower composite wins |
| OSPF path vs EIGRP path | **AD wins** (110 vs 90 → EIGRP 90 wins) regardless of metric |

### 2.6 Metric backward vs Traffic Engineering

- Changing costs per link steers traffic: raise cost to deter, lower to attract.
- OSPF is fully metric-driven; EIGRP too — these are the tools for design in Levels
  11/12 (OSPF/EIGRP notes).

## 3. Configuration / Commands

```text
! OSPF
router ospf 1
 auto-cost reference-bandwidth 1000    ! 1 Gbps reference
interface Gi0/1
 ip ospf cost 25                       ! manual per-link cost (overrides ref)

! EIGRP
interface Gi0/1
 bandwidth 1000000                     ! BW feeds composite metric (kbps)
 delay 100                             ! delay in 10-micron units

! RIP (no real tuning beyond maximum-paths)
router rip
 maximum-paths 4

show ip route                          ! [AD/metric]
show ip ospf interface brief           ! costs per interface
show ip eigrp topology
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Two disparate links ECMP | OSPF cost rounds both to 1 | raise reference-bandwidth |
| Traffic goes over slow link | RIP chose lower hop count; OSPF cost not set | use bandwidth-aware protocol or set cost |
| EIGRP, neighbors up, path weird | K values mismatch | `show ip eigrp neighbors` / `k values` |
| Loop chosen over fast path | cost misconfigured on fast interface | `show ip ospf interface` cost |

## 5. Exam Traps

- **AD decides source; metric decides path** — a metric-only question is per-protocol.
- **OSPF cost = ref/BW** — with default ref, **1 Gbps and 10 Gbps both cost 1**.
- **EIGRP default = BW + delay** (K2/K4/K5 zero) — don't compute load/reliability normally.
- **RIP 15 = reachable, 16 = infinity** — memorized hard limit.
- **You cannot compare OSPF cost with EIGRP composite** — different units entirely.
- **Static routes have no metric** — they win purely by AD 1 (unless floating, note 09).
