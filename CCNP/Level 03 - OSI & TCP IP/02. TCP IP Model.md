# TCP/IP Model

> **Level 03 · OSI & TCP/IP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **TCP/IP model** (the DoD/Internet model) describes the protocol stack actually
developed for the Internet. It has **four layers** that map onto OSI's seven and is
what Cisco/IOS speaks natively.

---

## 2. Core Concepts

### 2.1 Four layers vs OSI's seven

| TCP/IP layer | Covers OSI layers | Protocols |
|--------------|-------------------|-----------|
| **Application** | 7 + 6 + 5 | HTTP, FTP, SMTP, DNS, DHCP, Telnet, SSH, SNMP |
| **Transport** | 4 | TCP, UDP (+others) |
| **Internet (Network)** | 3 | IP, ICMP, ICMPv6, ARP placement debates |
| **Network Access (Link)** | 2 + 1 | Ethernet, 802.11, PPP, physical |

### 2.2 Layer jobs in TCP/IP terms
- **Application** — everything above ports: protocols, data formats, sessions merged
  into one (this is why "Application+Presentation","Session" are merged in real nets).
- **Transport** — **TCP** (reliable, connection-oriented, flow/congestion control) or
  **UDP** (best-effort, connectionless). Adds **ports** (source/destination).
- **Internet** — **IP** (addressing + best-effort delivery), **ICMP** (errors/diagnosis),
  **IGMP** (multicast group membership).
- **Network Access** — puts IP packets into **Ethernet frames**, resolves IP→MAC via ARP,
  actually transmits bits.

### 2.3 Correspondence rule (memorize)

| OSI | TCP/IP |
|-----|--------|
| 7,6,5 | 4. Application |
| 4 | 3. Transport |
| 3 | 2. Internet |
| 1,2 | 1. Network Access |

### 2.4 Why TCP/IP won over pure OSI
- OSI = reference-only; TCP/IP shipped working software, btw: IP is *the* internetwork
  protocol; everything was built on it.
- Practical usage: "ping works → L3 up; port 443 to host — try telnet → L4".
  The TCP/IP model is what operators actually troubleshoot.

## 4. Exam Traps

- **4 vs 5 layer TCP/IP variants** — Cisco traditionally teaches **4**; some texts
  split into 5 (link→link network separate). Answer per the question's model.
- **ARP lives at L2 "Network Access"** in TCP/IP (maps IP→MAC) — many exams place it
  at L3 or "between layers"; know both statements contextually.
- **ICMP is L3 (Internet), not "forum-less"** — it belongs to the Internet layer.
- **Only TCP and UDP are usually asked**; SCTP/DCCP are beyond scope.
- Best-effort principle: **IP, ICMP, UDP are unreliable**; reliability is added by TCP
  or applications.
