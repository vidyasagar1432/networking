# PDUs (Protocol Data Units)

> **Level 03 · OSI & TCP/IP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **Protocol Data Unit (PDU)** is the unit of data at a given layer of the stack:
the layer's header(+trailer) plus the payload it carries from the layer above.
Each layer has a specific PDU name — **data, segment, packet, frame, bits** — and a
PDU becomes the payload of the next-lower PDU.

---

## 2. Core Concepts

### 2.1 PDU names by layer

| Layer | PDU name |
|-------|----------|
| Application (7/6/5) | **Data** (some also "message") |
| Transport (4) | **Segment** (TCP) / **Datagram** (UDP) |
| Network (3) | **Packet** (IPv4/IPv6 "datagram" officially for IP) |
| Data Link (2) | **Frame** |
| Physical (1) | **Bits** (actually symbols/signals) |

### 2.2 PDU chain construction (relationship)
```
DATA →(L4 hdr)→ SEGMENT →(L3 hdr)→ PACKET →(L2 hdr+FCS)→ FRAME →(L1)→ BITS
        Segment is payload of packet   Packet is payload of frame
```
"The PDU of layer N is the **SDU (service data unit)** + header for layer N, and is
the SDU for layer N−1."

### 2.3 Official IP terminology
- RFC 791: IPv4 unit = "**datagram**". Cisco exams usually say "packet" for L3/IPv6
  and may say "datagram" for UDP/IP. Be prepared for both words.
- UDP datagram = the L4 PDU; "IP packet" = L3 PDU.

### 2.4 Size context
- Segment/packet sizes controlled by **MSS (for TCP)** and **MTU (for IP)**; the frame
  must fit the link MTU (Level 01 MTU). Over MTU → drop/fragment.
- Note: "PDU sizes include header, so **segment = TCP hdr + data** below."

## 3. Configuration / Commands

```text
# Relating PDU sizes to MTU:
ip mtu 1500            # interface L3 packet max
# Verify with:
show ip interface      # MTU reported; ping with packet-size/df
ping 10.0.0.2 size 1472 df-bit
```

## 4. Exam Traps

- **The single most-asked PDU fact**: segment = TCP, packet = IP, frame = Ethernet.
- **UDP "datagram", IP also "datagram"** — the two-datagram trap.
- **A packet that *becomes* a frame after L2 header** — don't call a frame a packet.
- **Bits at L1; symbols/codewords are the physical truth** — exam uses "bits".
- **Encapsulation math** — "what's the frame size"? = MTU + 18/22 (see MTU note).
