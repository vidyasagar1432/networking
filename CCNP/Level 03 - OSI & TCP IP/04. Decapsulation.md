# Decapsulation

> **Level 03 · OSI & TCP/IP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Decapsulation** is the reverse of encapsulation: at the receiver, each layer
**strips its own header/trailer**, validates it, and passes the payload up to the
next-higher layer until the application receives the original data.

---

## 2. Core Concepts

### 2.1 The process on receive
```
On the wire:      [Eth ][ IP ][TCP][HTTP data][FCS]
L2 remove:  →     [ IP ][TCP][HTTP data]      (check FCS → drop if bad)
L3 remove:  →        [TCP][HTTP data]         (checksum TTL ok?)
L4 remove:  →           [HTTP data]           (deliver by port)
L7:                   application data
```

### 2.2 Where decapsulation happens (hop vs endpoint)

| Device | Decapsulates | Keeps |
|--------|--------------|-------|
| Switch (L2) | Ethernet header/FCS | Re-encapsulates same frame out another port (doesn't read IP/TCP) |
| Router (L3) | Ethernet hdr, **reads IP**, rewrites L2 | Terminates/forwards IP; does not add L4 info |
| Target host | All layers | Delivers to app |
| Tunnel endpoint | Outer headers (IP+GRE/IPsec) | Inner packet is passed/decrypted |

Key rule: **intermediate routers decapsulate/ re-encapsulate L2 only**; the L3/L4
headers are untouched except TTL/hop.

### 2.3 What each layer checks during decapsulation
- **L2**: FCS (CRC) → mismatch = dropped (Counters show CRC errors; see Level 29).
- **L3**: IPv4 header checksum, TTL (if zero → ICMP TTL exceeded, drop); IPv6: hop limit.
- **L4**: TCP/UDP checksum + port matching; TCP ACK/sequence logic.
- **Application**: format, session context.

### 2.4 IPv4 checksum recalculation
- TTL decrements with every routed hop ⇒ IPv4 header checksum **recomputed each hop**
  (IPv6 removed header checksum entirely).

## 4. Exam Traps

- **Direction trap**: source *encapsulates* (down), destination *decapsulates* (up);
  don't flip.
- **Router doesn't "decapsulate for a host"** — it decapsulates L2, reads L3, *then
  re-encapsulates* a brand-new L2 header (MACs change every hop).
- **FCS check is L2** — CRC errors reported on switch interfaces.
- **Tunnels**: an intermediate tunnel endpoint decapsulates the *outer* header only.
- **IPv6**: no header checksum to check; only hop-limit check on L3.

---

## 5. Quick Review Table

| Layer | Check during decap | Result if bad |
|-------|--------------------|---------------|
| L2/FCS | CRC match | Drop (CRC counter) |
| L3 IPv4 | checksum, TTL | Drop / ICMP TTL exceded |
| L3 IPv6 | hop limit only | Drop (no checksum) |
| L4 TCP/UDP | checksum, port | Drop/reset |
| App | Format/session | App error |
| Hop devices | L2 reswap only | MAC fields change |
| Endpoints | Full chain | Data delivered |
