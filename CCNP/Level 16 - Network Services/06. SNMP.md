# SNMP

> **Level 16 · Network Services** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SNMP** (UDP 161 for queries, UDP 162 for traps/informs) monitors network devices. A
**manager** polls agents; agents send **traps** on events. The **MIB** is the tree of
object identifiers (OIDs) that represent device state. The exam tests **v1/v2c/v3
differences**, **communities**, and **`snmp-server`** configuration.

---

## 2. Core Concepts

### 2.1 Roles

| Role | Function |
|------|----------|
| Manager | polls, collects, displays |
| Agent | runs on the device, answers |
| MIB | object tree (OIDs) |
| TRAP | agent-initiated event |
| INFORM | confirmed trap |

- Traps are **unsolicited**; informs add **acknowledgment** (reliable vs UDP).

### 2.2 Versions

| Version | Security |
|---------|----------|
| v1 | plaintext community |
| v2c | plaintext community (widely used) |
| v3 | **auth + privacy** (USM) |

- **v2c** = community-based and popular; **v3** = SNMPv3 with auth (MD5/SHA) + privacy
  (DES/AES) and users.
- The exam security answer is **v3**.

### 2.3 Community strings

- RO (read-only) vs **RW (read-write)**.
- 1.3.6.1.4.1.9 is the **Cisco** enterprise branch.

| OID | Area |
|-----|------|
| 1.3.6.1.2.1.1 | system |
| 1.3.6.1.2.1.2 | interfaces |
| 1.3.6.1.2.1.4 | IP |
| 1.3.6.1.4.1.9 | Cisco |

### 2.4 Configuration (v2c)

```text
snmp-server community cisco123 RO
snmp-server community netops RW
snmp-server host 10.0.0.5 version 2c cisco123
snmp-server location R1
snmp-server contact netadmin@corp
```

### 2.5 Configuration (v3)

```text
snmp-server group ADMIN v3 priv
snmp-server user cisco-user ADMIN v3 auth sha SecretAuth priv aes SecretPriv
snmp-server host 10.0.0.5 version 3 priv cisco-user
```

- Groups define auth/priv levels; users carry the keys.

### 2.6 Operations

| Operation | Meaning |
|-----------|---------|
| GET / GETNEXT | manager reads |
| SET | manager writes (RW only) |
| GETBULK | many reads at once |
| TRAP / INFORM | agent → manager |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No response | UDP 161 blocked | ACL |
| No traps | host/community not IP'd | show snmp host |
| Wrong values | agent unresponsive / polling | OID |
| Security alerts | v1/v2c plaintext | use v3 |
| SET fails | RO community | RW community |

---

## 5. Exam Traps

- **UDP 161** queries, **UDP 162** traps.
- **v3** = the secure version (auth + privacy).
- v1/v2c use **communities**; v2c is still commonly deployed.
- TRAP unacknowledged; **INFORM acknowledged**.
- Cisco enterprise OID: **1.3.6.1.4.1.9**.
