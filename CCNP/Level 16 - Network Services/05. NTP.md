# NTP (Network Time Protocol)

> **Level 16 · Network Services** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**NTP** (UDP 123) synchronizes device clocks to a **stratum hierarchy** — servers, peers,
and clients. Accurate time underpins logs, certificates, and forensics. The exam tests
**stratum numbers**, **`ntp server` vs `ntp master`**, **source** configuration, and NTP
version/authentication.

---

## 2. Core Concepts

### 2.1 The stratum hierarchy

| Stratum | Device |
|---------|--------|
| 0 | atomic/GPS clock |
| 1 | primary server attached to stratum 0 |
| 2 | peers of stratum 1 |
| 3+ | descends further |

- **Lower stratum = more accurate**. A device syncs to a lower (better) source.
- A router at stratum 3 trusts a stratum 2 source (its own stratum = source + 1).

### 2.2 Modes

| Mode | Role |
|------|------|
| client | syncs from a server (`ntp server X`) |
| server | serves time (`ntp master`) |
| peer | mutual sync, no hierarchy |
| broadcast | passive sync, less accurate |

- `ntp master 2` makes the router a time source at stratum 2 (falls back to local clock).

### 2.3 Configuration

```text
ntp server 10.0.0.5
ntp peer 10.0.0.6
ntp source Loopback0          ! which IP to advertise
ntp authentication-key 1 md5 key123
ntp authenticate
ntp trusted-key 1
```

- `ntp source` fixes the source IP so NTP isn't dropped by ACLs/source filters.
- Authentication (MD5 key + `ntp authenticate`) prevents spoofing.

### 2.4 Client synchronization rules

| Rule | Detail |
|------|--------|
| Source | lower stratum preferred |
| Distance | stratum + sync distance within 16 |
| Select | best clock among candidates |
| Master | only if no better source |

- `ntp master` serves *if* no external source is usable — fallback.

### 2.5 Monitoring

```text
show ntp status
show ntp associations
show ntp associations detail
debug ntp
```

- `show ntp status` shows stratum, reference, and sync state (`synchronized` /
  `unsynchronized`).

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Unsynced | UDP 123 blocked | ACL |
| Wrong time | bad stratum choice | show ntp status |
| Auth fails | key mismatch | ntp authentication-key |
| No change | drift high | ntp max-associations |
| Asymmetric | source IP changed | ntp source |

---

## 5. Exam Traps

- **UDP 123**.
- **Lower stratum wins** — a router's stratum = best source + 1.
- `ntp master N` = serve local clock at stratum N.
- `ntp source` matters for ACL/peering.
- Authentication: configure **both** the key and `ntp trusted-key`.
- Clock must be **synchronized** for routing protocols like BGP/OSPF timers to be sane.
