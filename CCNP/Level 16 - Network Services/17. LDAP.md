# LDAP

> **Level 16 · Network Services** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**LDAP** (TCP 389) reads and writes a **directory** — users, groups, devices — in a
tree (DIT). It's the backbone of identity stores (Active Directory, OpenLDAP). Network
AAA (RADIUS/TACACS+ backends) often validates against an LDAP directory. Secure variant =
**LDAPS (636)**.

---

## 2. Core Concepts

### 2.1 The directory tree (DIT)

| Component | Example |
|-----------|---------|
| Root / DC | dc=corp,dc=example |
| OU | ou=Users |
| CN / DN | cn=bob,ou=Users,dc=corp,dc=example |

- Entries are addressed by **Distinguished Name (DN)** top-down from the root.

### 2.2 LDAP vs database

| Aspect | LDAP | DB |
|--------|------|----|
| Model | tree (DIT) | relational tables |
| Reads | optimized | balanced |
| Schema | extensible | fixed |
| Protocols | LDAP | SQL |

- LDAP is **read-heavy, hierarchical** — identity lookups.

### 2.3 Operations

| Operation | Meaning |
|-----------|---------|
| BIND | authenticate (simple or SASL) |
| SEARCH | lookup by filter |
| ADD / MODIFY | create/change entries |
| DELETE | remove |
| UNBIND | close session |

- **BIND** is the password validation used by AAA backends.

### 2.4 Search filters

```
(&(objectClass=user)(sAMAccountName=bob))
```

| Syntax | Meaning |
|--------|---------|
| `(&...)` | AND |
| `(\|...)` | OR |
| `(!...)` | NOT |
| `attr=val` | match |

- Filters drive identity lookups and group membership checks.

### 2.5 Ports and security

| Port | Mode |
|------|------|
| 389 | LDAP (plaintext) |
| 636 | LDAPS (TLS) |
| 3268/3269 | Global Catalog (AD) |

- Bind passwords on 389 are clear — **636/LDAPS** for auth data.

### 2.6 LDAP in the enterprise

| Use | Detail |
|-----|--------|
| User directory | identities + attributes |
| AAA backend | RADIUS/TACACS+ reference LDAP |
| Certificate revoke | CRL / OCSP data |
| Group policy | nested groups |

- Network access (802.1X) frequently resolves policy groups via LDAP.

---

## 3. Configuration / Commands

```text
ldap-server host 10.0.0.5
ldap-server base dc=corp,dc=example
show ldap server status
```

- On Cisco IOS, LDAP can be configured for AAA attribute retrieval.

---

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Auth fails | BIND denied | credentials/base DN |
| Timeout | TCP 389 blocked | ACL |
| No entries | search base wrong | base DN |
| TLS errors | cert mismatch | LDAPS |
| Group miss | nested group depth | filter scope |

---

## 5. Exam Traps

- **LDAP = 389**; **LDAPS = 636**.
- Tree = **DIT**; entry = **DN**.
- **BIND** authenticates — the AAA connection point.
- Search filters: `&` AND, `|` OR, `!` NOT.
- Read-heavy hierarchical directory vs relational DB.
