# IMAP

> **Level 16 · Network Services** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**IMAP** (TCP 143) keeps mail **on the server** and **synchronizes** it across clients —
folders, read-state, and messages stay consistent. It replaces POP3 in multi-device
environments. Secure variant = **IMAPS (993)**. IMAP also supports **server-side
search** and partial fetch.

---

## 2. Core Concepts

### 2.1 The model

| Aspect | IMAP |
|--------|------|
| Port | TCP 143 (993 SSL) |
| Storage | server-side |
| Sync | across clients |
| State | online |
| Folders | on server |

- Clients talk to the server constantly; nothing "lives only" on one device.

### 2.2 IMAP vs POP3 (the exam's core comparison)

| Aspect | IMAP | POP3 (note 15) |
|--------|------|----------------|
| Server keeps mail | yes | no (usually) |
| Multi-device | yes | no |
| Folders | server-side | single INBOX |
| Search on server | yes | no |
| Ports | 143 / 993 | 110 / 995 |

- **IMAP = synchronized online; POP3 = download offline** — the memorizable pair.

### 2.3 Basic operations

| Command | Meaning |
|---------|---------|
| LOGIN | auth |
| SELECT INBOX | open folder |
| FETCH n BODY[] | retrieve a message |
| SEARCH UNSEEN | server-side query |
| STORE +FLAGS (Seen) | mark read |
| CLOSE / LOGOUT | finish |

- Tags prefix each command (e.g., `a01 SELECT INBOX`).

### 2.4 Security ports

| Port | Mode |
|------|------|
| 143 | plaintext |
| 993 | IMAPS (TLS) |

- Use 993/STARTTLS — mail on 143 is sniffable.

### 2.5 When to choose IMAP

| Need | Choose |
|------|--------|
| Phone + laptop + webmail | IMAP |
| Offline single device | POP3 |
| Server backup | IMAP (mail retained) |
| Minimal server load | POP3 |

### 2.6 Enterprise note

- IMAP keeps mail on mail servers — **central backup/DLP** works better than POP3.
- Network visibility: allow 143/993; monitor for bulk login attempts.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Cannot connect | TCP 143 blocked | ACL |
| Bad login | credentials | LOGIN |
| Sync drift | multiple IMAP configs | client settings |
| Connection reset | TLS vs plaintext | use 993 |
| Folder missing | mailbox config | SELECT |

---

## 5. Exam Traps

- **IMAP = 143**, **IMAPS = 993**.
- **Keeps mail on the server** — the contrast with POP3.
- Online/synchronized vs POP3 offline/download.
- IMAP adds folders + server-side SEARCH.
- Multi-device sync is the IMAP use case.
