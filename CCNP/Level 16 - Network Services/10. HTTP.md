# HTTP

> **Level 16 · Network Services** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**HTTP** (TCP 80) is the request/response protocol for the web — and on Cisco gear the
default for the **embedded HTTP/HTTPS server** that powers web management (e.g.,
GUI access to the device). The exam checks the request/response model, methods, status
codes, and why **HTTPS (443)** replaces it for management.

---

## 2. Core Concepts

### 2.1 Request/response model

```
client --(GET /index.html HTTP/1.1)--> server
server --(200 OK + body)------------> client
```

| Field | Meaning |
|-------|---------|
| Method | GET, POST, PUT, DELETE |
| URI | resource path |
| Version | HTTP/1.1 (keep-alive default) |
| Headers | Host, Content-Type, etc. |
| Body | data for POST/PUT |

### 2.2 Common methods

| Method | Use |
|--------|-----|
| GET | read resource |
| HEAD | headers only |
| POST | send data / create |
| PUT | update/replace |
| DELETE | remove |

- **GET is idempotent/read-only**; POST changes state.

### 2.3 Status codes

| Class | Meaning | Examples |
|-------|---------|----------|
| 1xx | informational | 100 continue |
| 2xx | success | 200 OK |
| 3xx | redirect | 301/302 |
| 4xx | client error | 404 not found |
| 5xx | server error | 500/503 |

- 404 + 5xx are the exam-relevant failures.

### 2.4 Statelessness & sessions

- HTTP is **stateless**; sessions via cookies/tokens.
- **Keep-alive** reuses TCP connections (HTTP/1.1).

### 2.5 Cisco HTTP server

```text
ip http server
ip http port 80
ip http authentication local
```

| Command | Purpose |
|---------|---------|
| `ip http server` | enable web mgmt |
| `ip http authentication local` | auth via local DB |
| `ip http access-class` | ACL to restrict |

- The embedded server supports GUI and (some) REST/NetConf APIs.

### 2.6 HTTP vs HTTPS (management security)

| Aspect | HTTP | HTTPS |
|--------|------|-------|
| Port | 80 | 443 |
| Encryption | none | TLS |
| Management | discouraged | recommended |
| Cisco default | off (modern) | on (some) |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Page won't load | server off | ip http server |
| 404 | wrong URI | URL path |
| 401/403 | auth config | authentication |
| Blocked | ACL / TCP 80 | access-class |
| Slow | keep-alive / proxies | server stats |

---

## 5. Exam Traps

- HTTP = **TCP 80**; HTTPS = **443**.
- **Stateless** protocol; methods GET/POST matter.
- Status **2xx success / 4xx client / 5xx server**.
- Cisco device management should use **HTTPS**, not plain HTTP.
- `ip http server` + authentication + access-class = the management stack.
