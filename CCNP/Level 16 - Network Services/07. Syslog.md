# Syslog

> **Level 16 · Network Services** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Syslog** (UDP 514) centralizes device messages. Routers send **severity-tagged** logs to
a collector; the exam tests **severity levels (0–7)**, the **`logging`** commands, and the
facility/severity model. Logging feeds **SNMP traps** and is core to troubleshooting.

---

## 2. Core Concepts

### 2.1 Severity levels

| Level | Name | Meaning |
|-------|------|---------|
| 0 | emergency | system unusable |
| 1 | alert | immediate action |
| 2 | critical | severe |
| 3 | error | errors |
| 4 | warning | warnings |
| 5 | notice | normal but notable |
| 6 | informational | info |
| 7 | debug | debug (most verbose) |

- Logging at level N = messages **≤ N** are sent (0 = highest, 7 = lowest).

### 2.2 Facilities and message format

```
%FACILITY-SEVERITY-MNEMONIC: description
```

- Example: `%LINEPROTO-5-UPDOWN: Line protocol on Gi0/1 changed state to up`.

| Field | Meaning |
|-------|---------|
| Facility | subsystem (LINEPROTO, SYS, OSPF) |
| Severity | 0–7 |
| Mnemonic | message ID |
| Description | detail |

### 2.3 Configuring logging

```text
logging host 10.0.0.5
logging trap 4
logging source-interface Loopback0
logging buffered 4096
logging console
logging monitor
```

| Target | Command | Default |
|--------|---------|---------|
| Syslog server | `logging host IP` | none |
| Buffer | `logging buffered` | size |
| Console | `logging console` | on |
| Monitor (VTY) | `logging monitor` | on |
| Source | `logging source-interface` | — |

- `logging trap N` sets the severity sent to the **host**.

### 2.6 Timestamping

```text
service timestamps log datetime msec
service timestamps debug datetime msec
```

- Timestamps make logs correlatable; NTP (note 05) keeps them accurate.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No logs at server | UDP 514 blocked / host config | show logging |
| Too noisy | severity too low (7) | raise threshold |
| Nothing in buffer | buffered off | logging buffered |
| Wrong source | source IP dropped | source-interface |
| Time drift | no NTP | timestamps |

---

## 5. Exam Traps

- Syslog = **UDP 514**.
- Severity: **0 highest, 7 lowest** (debug).
- `logging trap N` = logs ≤ N go to the server.
- Format = `%FACILITY-SEVERITY-MNEMONIC`.
- `logging console` affects the console; `logging monitor` for VTY.
- Timestamps + NTP = the correlation pair.
