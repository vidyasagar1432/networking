# DHCP

> **Level 16 · Network Services** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**DHCP** (UDP 67/68) automates IP address assignment: clients broadcast **DISCOVER**,
servers answer **OFFER**, the client picks and **REQUESTs**, then the server
**ACKNOWLEDGES**. Encores check the DORA exchange, DHCP option 82 (relay), and the
config basics for **`ip dhcp pool`** and **excluded addresses**.

---

## 2. Core Concepts

### 2.1 The DORA exchange

| Sequence | Message | Direction | Port |
|----------|---------|-----------|------|
| 1 | **D**iscover | client → server | 67 (dst) |
| 2 | **O**ffer | server → client | 68 (dst) |
| 3 | **R**equest | client → server | 67 |
| 4 | **A**ck | server → client | 68 |

- Client 0.0.0.0:68 → server 255.255.255.255:67 (broadcast).
- DHCP uses **broadcast** until the client has an address (or relay converts to unicast).

### 2.2 Lease basics

| Item | Detail |
|------|--------|
| Default lease | 1 day |
| T1 (renew at 50%) | 12 h |
| T2 (rebind at 87.5%) | 21 h |

- At T1 the client renews toward its server; at T2 it rebinds to any server.

### 2.3 Server-side configuration

```text
ip dhcp excluded-address 10.0.0.1 10.0.0.99
ip dhcp pool LAN
 network 10.0.0.0 255.255.255.0
 default-router 10.0.0.1
 dns-server 10.0.0.2
 lease 1 0 0
```

- `excluded-address` removes statics from the pool.
- Pool options: router, DNS, lease, domain-name, etc.

### 2.4 DHCP options (option 82 on a switch)

| Option | Meaning |
|--------|---------|
| 53 | message type (DORA) |
| 54 | server identifier |
| 82 | relay agent info (circuit/policy) |
| 150 | TFTP server (voice) |
| 66/67 | TFTP name / bootfile |

- **Option 82** adds the switchport + VLAN info through a relay — used for security and
  policy (note 02/03).

### 2.5 Client-side and verification

```text
ip address dhcp                    ! interface as a client
show ip dhcp binding              ! server: active assignments
show ip dhcp pool
debug ip dhcp server packet
```

- Servers track **bindings**; `clear ip dhcp binding *` resets them.

### 2.6 DHCP security

| Threat | Mitigation |
|--------|-----------|
| Rogue server | DHCP snooping (note 02) |
| Spoofed REQUEST | option 82 + snooping |
| Pool exhaustion | rate-limit / snooping |

- DHCP snooping is the force multiply for these.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No address | DHCP not running / pool exhausted | show ip dhcp pool |
| Conflict | addresses not excluded | excluded-address |
| Relay needed | server in other subnet | ip helper-address (note 03) |
| Voice fails | no option 150 | pool options |
| Snooping blocks | untrusted port | snooping config (note 02) |

---

## 5. Exam Traps

- Ports: **server 67, client 68**.
- DORA order is **Discover → Offer → Request → Ack**.
- T1 renew at 50%, T2 rebind at 87.5%.
- `excluded-address` must cover statics.
- Init/rebinding = **broadcast**; that's why relays (note 03) exist.
