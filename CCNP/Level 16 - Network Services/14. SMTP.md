# SMTP

> **Level 16 · Network Services** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SMTP** (TCP 25) is the protocol that **sends and relays email** between servers.
It is a push: senders push onward; mail is stored locally and **downloaded by clients**
via POP3/IMAP (notes 15–16). The exam checks **port conventions (25/587/465)**, the
store-and-forward model, and how SMTP relates to the client mail protocols.

---

## 2. Core Concepts

### 2.1 Where SMTP fits

| Hop | Protocol |
|-----|----------|
| Client → server (submit) | SMTP (25/587) |
| Server → server (relay) | SMTP (25) |
| Server → client (download) | POP3 / IMAP |

- SMTP is **server-to-server and send-side**; clients receive via POP3/IMAP.

### 2.2 Ports and modes

| Port | Use |
|------|-----|
| 25 | legacy relay / MTA |
| 587 | **submission** (client auth) |
| 465 | SMTPS (implicit TLS) |

- Real mail relies on **587 submission** and **STARTTLS** these days.

### 2.3 Basic SMTP dialog

```
client: EHLO example.com
server: 250 mail.example.com
client: MAIL FROM:<a@ex.com>
client: RCPT TO:<b@ex.com>
client: DATA
... message ...
client: .
server: 250 queued
client: QUIT
```

- The lone `.` ends the DATA section.

### 2.4 Key reply codes

| Code | Meaning |
|------|---------|
| 220 | ready |
| 250 | OK |
| 354 | start mail input (DATA) |
| 550 | mailbox unavailable |
| 421/450/451 | temp failures |

- 5xx = permanent; 4xx = transient (retry later).

### 2.5 Security evolution

| Threat | Countermeasure |
|--------|----------------|
| Open relay abuse | reject non-local RCPT |
| Spoofing | SPF/DKIM/DMARC |
| Cleartext | STARTTLS / 587 auth |
| Password sniffing | SMTP AUTH over TLS |

- **Open relay** = relay anything → abused by spammers; must be blocked.

### 2.6 Enterprise note

- Cisco gear rarely runs SMTP itself; mail gateways/MTAs do.
- But **SNMP traps / syslog** can ride e-mail via SMTP reporting.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| 550 | invalid recipient | RCPT address |
| 421 timeout | server busy | retry window |
| Relay denied | open-relay protection | auth + permitted senders |
| Message stuck | 4xx temp | queue delay |
| TLS warning | cert mismatch | certificate |

---

## 5. Exam Traps

- **SMTP = TCP 25** (relay), **587** (submission), **465** (SMTPS).
- SMTP **pushes**; POP3/IMAP **pull**.
- The `.` terminates DATA.
- **4xx transient, 5xx permanent** — the retry rule.
- Open relays are the classic abuse/exam trap.
