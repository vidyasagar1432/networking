# Totally Stubby Area

> **Level 10 · OSPF** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **totally stubby area** (Cisco `stub no-summary`) is a **stub area that also blocks
Type 3 (inter-area summary) LSAs** — leaving only intra-area (Type 1/2) and the ABR's
injected **default route**. It's the most restrictive practical area type: the smallest
possible LSDB inside an area. It inherits all stub restrictions (no ASBR, not area 0, all
routers must match).

---

## 2. Core Concepts

### 2.1 What it blocks vs allows

| LSA | Stub area | Totally stubby |
|-----|-----------|----------------|
| Type 1 Router | allowed | allowed |
| Type 2 Network | allowed | allowed |
| Type 3 Summary | allowed | **blocked** |
| Type 4 ASBR-Summary | blocked | blocked |
| Type 5 External | blocked | blocked |
| Default (Type 3) | injected | **injected (only type 3 present)** |

- Only **intra-area routes + default** exist in the totally stubby area's table.

### 2.2 How it's configured (only on the ABR differs)

```text
! All internal routers:
router ospf 1
 area 3 stub

! ABR (the "totally" part — no-summary):
router ospf 1
 area 3 stub no-summary
```

- The **`no-summary`** keyword is what makes it totally stubby — configured **only on the
  ABR**; internal routers just use plain `stub`.

### 2.3 Advantages vs plain stub

| | Stub | Totally stubby |
|--|------|----------------|
| Type 3 into area | yes | **no** |
| LSDB size | medium | smallest |
| CPU (SPF) | lower | lowest |
| Default injected | yes | yes |
| Ideal | modest external need | maximally simplified branch |

- Best for the **most remote branches** — they only need the default to leave.

### 2.4 Route codes inside the area

- Internal routes: `O`.
- The default: `O*IA` (inter-area default, flagged `*` = default candidate).
- **No `O IA` specific inter-area routes** appear.

### 2.5 Constraints recap (inherited)

1. Cannot be **area 0**.
2. **No ASBR** inside.
3. All routers in area must run **stub** (ABR adds `no-summary`).
4. No **virtual link** traversal through the area.

---

## 3. Configuration / Commands

```text
! ABR:
router ospf 1
 area 3 stub no-summary
 area 3 default-cost 5

! Internal router:
router ospf 1
 area 3 stub

show ip ospf
show ip route ospf                  ! O intra + O*IA default only
show ip ospf database summary       ! only default Type 3
```

---

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Inter-area routes appear | `no-summary` missing on ABR | verify ABR config |
| Neighbors down | internal routers not `stub` | match `stub` all routers |
| No default | default-cost / ABR issue | `show ip ospf database` |
| Can't redistribute inside | stub restriction | use NSSA (note 11) if needed |

---

## 5. Exam Traps

- **`stub no-summary` ONLY on the ABR** — internal routers use plain `stub`.
- **Blocks Type 3, 4, 5** — only default (Type 3) + intra-area remain.
- Same **no-ASBR / no-area-0 / no-virtual-link** constraints as stub.
- Route code for the injected default: **`O*IA`**.
- The exam question "smallest LSDB area type" → **totally stubby**.
