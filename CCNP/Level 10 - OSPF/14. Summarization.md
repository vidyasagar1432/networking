# OSPF Summarization (Route Aggregation)

> **Level 10 · OSPF** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

OSPF summarizes routes **only at the Area Border Router (ABR)** using `area X range` for
**inter-area** routes, and at the **ASBR** using `summary-address` for **external**
(redistributed) routes. OSPF **cannot summarize inside an area** — LSAs are always exact
within the area. Summarization shrinks the LSDB, reduces SPF, and contains flaps.

---

## 2. Core Concepts

### 2.1 Where OSPF CAN summarize (memorize)

| Location | Command | What it aggregates |
|----------|---------|--------------------|
| **ABR** | `area X range <net> <mask>` | inter-area routes (Type 3) |
| **ASBR** | `summary-address <net> <mask>` | external redistributed routes (Type 5/7) |
| Inside an area | not possible | intra-area must be exact |

- The two commands answer the two "how do I summarize OSPF?" exam questions.

### 2.2 ABR `area X range` in detail

```text
router ospf 1
 area 1 range 10.1.0.0 255.255.0.0        ! summarizes area 1's routes
```

- Applied on the **ABR**; aggregates area-1 internal routes into a single Type 3.
- `not-advertise` option suppresses the aggregate (filtering).
- Multiple ranges allowed; the most specific covering summary wins.

### 2.3 ASBR `summary-address` in detail

```text
router ospf 1
 summary-address 10.2.0.0 255.255.0.0     ! aggregates redistributed externals
 redistribute static subnets
```

- Summarizes **Type 5** externals at the ASBR.
- Also applies to **Type 7 (NSSA)** external routes on the translating ABR.

### 2.4 Benefits (the standard answer set)

| Benefit | Why |
|---------|-----|
| Smaller LSDB | fewer Type 3/5 LSAs |
| Less SPF CPU | shorter SPF run |
| Stability | flap inside summarized range doesn't propagate |
| Determinism | one aggregate at boundary |
| Table size | fewer routes in RIB/FIB |

### 2.5 Summary + Null0 / loop concern

- A router advertising an aggregate must **discard** traffic to sub-ranges it doesn't
  have — otherwise it could re-advertise or loop. In OSPF the ABR/ASBR that generates the
  summary also needs a matching path (or a Null0) for the covered ranges.
- `discard-route` option on some platforms generates the discard for the range.

## 3. Configuration / Commands

```text
! ABR: inter-area summarization
router ospf 1
 area 1 range 10.1.0.0 255.255.0.0
 area 1 range 10.1.0.0 255.255.0.0 not-advertise   ! filter instead

! ASBR: external summarization
router ospf 1
 summary-address 10.2.0.0 255.255.0.0
 redistribute static subnets

show ip ospf database summary      ! the Type 3 summaries
show ip ospf database external     ! Type 5 view
show ip route ospf
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Summary not appearing | wrong area / wrong ABR | `show ip ospf database summary` |
| External routes not aggregated | `summary-address` missing on ASBR | verify ASBR config |
| Traffic blackholed to sub-ranges | no discard/null0 for aggregate | add Null0 for range |
| Flap still propagates | summary not covering the flap range | verify mask covers it |
| Routes duplicated | overlapping ranges | use most-specific range only |

---

## 5. Exam Traps

- **OSPF cannot summarize inside an area** — intra-area LSAs are always exact.
- **`area X range` is ABR-only** (inter-area); **`summary-address` is ASBR-only** (external).
- `not-advertise` = suppress; `discard-route` = drop covered ranges at the origin.
- Summarization also applies to **Type 7 NSSA** externals at the translating ABR.
- OSPF summarization ≠ auto-summarization (no classful auto behavior).
