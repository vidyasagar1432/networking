# OSPF Stub Area

> **Level 10 · OSPF** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **stub area** is a non-backbone area that **blocks Type 5 (AS-external) LSAs** from
entering. Routers inside see no external routes — instead the ABR injects a **default route
(Type 3)** so outbound traffic still works. Stub areas shrink the LSDB and reduce CPU, but
they **cannot contain an ASBR** (no external route injection) and **cannot be area 0**.

---

## 2. Core Concepts

### 2.1 What a stub area blocks/allows

| LSA | In a stub area |
|-----|----------------|
| Type 1 Router | allowed |
| Type 2 Network | allowed |
| Type 3 Summary | allowed |
| Type 4 ASBR-Summary | **blocked** (no ASBR here) |
| Type 5 External | **blocked** |
| Type 7 NSSA | n/a (stub ≠ NSSA) |
| Default (Type 3) | **injected by ABR** |

- Net effect: stub routers know intra-area + inter-area + a default to leave the area.

### 2.2 Rules of stub areas (exam list)

1. **No ASBR** inside the stub area (cannot inject external routes).
2. **Cannot be area 0.**
3. **All routers in the area must be configured stub** — otherwise adjacency fails.
4. No **virtual link** traversal allowed through a stub area.
5. External routes reachable only via the **ABR-injected default route**.

### 2.3 Why use a stub area

| Benefit | Reason |
|---------|--------|
| Smaller LSDB | no Type 5 flooding |
| Less CPU | SPF over fewer LSAs |
| Stability | external flaps don't reach the stub |
| Simplicity | default route out |

- Ideal for a remote office / branch area with no Internet-of-routes need.

### 2.4 Config & the default injection

```text
router ospf 1
 area 2 stub

! On the ABR (to actually inject the default):
area 2 stub
area 2 default-cost 10        ! cost of the injected default
```

- Default-cost optional; sets the metric of the injected 0.0.0.0/0 for the stub.

### 2.5 Stub vs totally stubby vs NSSA (one-line each)

| Area type | Blocks | Injects |
|-----------|--------|---------|
| **Stub** | Type 5 | default route |
| **Totally stubby** (note 10) | Type 3, 4, 5 | default route |
| **NSSA** (note 11) | Type 5, but allows Type 7 | default (optional) |

## 3. Configuration / Commands

```text
router ospf 1
 area 2 stub
 area 2 default-cost 5

! Verify
show ip ospf
show ip ospf neighbor
show ip ospf database | include "Type-3|Type-5"   ! only 3 + default present
show ip route ospf
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Neighbor stuck 2-Way/Down | one side configured stub, other not | same `stub` all routers |
| No external routes | expected — stub blocks Type 5 | use NSSA if you need external |
| No default in stub | `area N stub` missing on ABR's side | verify `show ip ospf database` default |
| Area 0 marked stub | not allowed | move config to non-backbone |

---

## 5. Exam Traps

- **Stub blocks Type 5 and Type 4; injects a default (Type 3).**
- **No ASBR permitted in a stub area** — the "can I redistribute here?" answer is NO.
- **Cannot be area 0**, cannot transit a **virtual link**.
- **All routers in the area must be stub** — half-and-half breaks adjacencies.
- External reach = **default route** — stub never sees specifics of the outside world.
