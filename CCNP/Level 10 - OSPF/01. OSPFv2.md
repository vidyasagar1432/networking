# OSPFv2

> **Level 10 · OSPF** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**OSPF (Open Shortest Path First, RFC 2328)** is an **open-standard, link-state, IGP**.
Routers exchange **LSAs (Link State Advertisements)** to build a shared **LSDB**, then each
router independently runs **Dijkstra's SPF** to compute the shortest-path tree. Because
every router has the same full map, OSPF **converges fast** and is loop-free by
construction. IPv4 OSPF is **OSPFv2**; IPv6 uses **OSPFv3** (note 02). AD = **110**.

---

## 2. Core Concepts

### 2.1 Link-state vs distance-vector (the big idea)

| | Link-state (OSPF) | Distance-vector (RIP/EIGRP-ish) |
|--|-------------------|--------------------------------|
| Knowledge | full topology map (LSDB) | only neighbor "distance vectors" |
| Loop safety | SPF computes tree | split-horizon / holddown tricks |
| Convergence | fast, deterministic | slower, can be unstable |
| Updates | LSAs on change (flooded) | periodic/triggered route updates |

- Each OSPF router holds the **complete area topology** → SPF gives a guaranteed acyclic tree.

### 2.2 The three tables

| Table | What it holds | Commands |
|-------|---------------|----------|
| **Neighbor table** | adjacent routers + state | `show ip ospf neighbor` |
| **LSDB** | all LSAs (topology map) | `show ip ospf database` |
| **Routing table** | best routes (SPF output) | `show ip route ospf` |

### 2.3 Hello protocol & protocol facts

- **Hello** every **10 s** on broadcast/P2P; **30 s** on NBMA (frame-relay style).
- **Dead interval** = **4× hello** (40 s default) — miss 4 hellos → neighbor dead.
- Multicast: **224.0.0.5 (all OSPF routers)**, **224.0.0.6 (DR/BDR)** on broadcast.
- **Port 89, protocol number 89**, unicast on NBMA.

### 2.4 LSA flooding & areas

- OSPF floods LSAs across an **area**; the **ABR** summarizes between areas with
  Type-3 LSAs (note 08).
- Area 0 (**backbone**) must be contiguous; **all areas connect to area 0** (or via a
  virtual link, note 12).

### 2.5 Metrics (cost)

```
cost = reference-bandwidth / interface-bandwidth   (default reference 100 Mbps)
```

- Default reference **100 Mbps**: 100 Mbps = 1, 1 Gbps = 1, 10 Gbps = 1 → set
  `auto-cost reference-bandwidth 1000` to keep fast links distinct (Level 09 note 03).
- Path cost = sum of outgoing interface costs.

### 2.6 Basic configuration

```text
router ospf 1
 router-id 1.1.1.1
 network 10.0.0.0 0.0.0.255 area 0

! Or interface mode (modern)
interface Gi0/1
 ip ospf 1 area 0
```

## 3. Configuration / Commands

```text
router ospf 1
 router-id 1.1.1.1
 network 10.1.0.0 0.0.255.255 area 0
 passive-interface Gi0/3             ! suppress hellos on this segment

interface Gi0/1
 ip ospf 1 area 0
 ip ospf cost 50                     ! manual cost
 ip ospf network point-to-point      ! override broadcast on P2P

show ip ospf neighbor
show ip ospf interface brief
show ip ospf database
show ip route ospf
show ip protocols | include OSPF
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Neighbor stuck in INIT/2WAY | mismatch in hello/dead/area/network-type | `show ip ospf interface` |
| DR issue on P2P links | broadcast default causes DR elections | set `network point-to-point` |
| No routes learned | LSDB mismatch / DR/DROther issue | `show ip ospf database` |
| Flapping neighbors | MTU mismatch (BIG on exam) | verify MTU equal both sides |
| Area 0 not contiguous | split backbone | virtual link (note 12) |

## 5. Exam Traps

- **Hello 10 s / dead 40 s** (broadcast/P2P) — the memorized pair; NBMA is 30/120.
- **AD 110** — vs EIGRP 90, RIP 120.
- **224.0.0.5 / 224.0.0.6** — all-routers vs DR/BDR groups.
- **MTU mismatch** = classic neighbor-stuck-in-ExStart cause.
- **Cost reference default 100 Mbps** — two fast links both cost 1 unless tuned.
- **`network` uses wildcard** (inverted mask), not subnet mask.
- OSPFv2 = IPv4; **OSPFv3 = IPv6** (note 02).
