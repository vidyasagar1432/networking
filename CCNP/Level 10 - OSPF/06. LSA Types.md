# OSPF LSA Types

> **Level 10 · OSPF** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**LSAs (Link State Advertisements)** are the building blocks of the OSPF **LSDB**. Each
type describes a different part of the topology or reachability. Knowing **who originates
which type and where it lives** (intra-area, backbone, external) is core ENCOR material —
especially Types 1–7.

---

## 2. Core Concepts

### 2.1 The LSA types (memorize the whole table)

| Type | Name | Originator | Scope / meaning |
|------|------|-----------|-----------------|
| **1** | Router LSA | every router | its links in an area (intra-area) |
| **2** | Network LSA | **DR** | broadcast/NBMA segment with attached routers |
| **3** | Summary LSA | **ABR** | routes *from other areas* into this area |
| **4** | ASBR-Summary LSA | **ABR** | how to reach an **ASBR** |
| **5** | AS-external LSA | **ASBR** | routes redistributed from outside OSPF |
| **6** | Group-membership LSA | — | MOSPF (obsolete — not on exam) |
| **7** | NSSA-external LSA | **ASBR in NSSA** | external routes in a Not-So-Stubby Area |
| **8** | — | — | OSPFv3 link-local (v2 n/a) |
| **9/10/11** | Opaque LSA | varies | TE, Graceful-restart, etc. |

### 2.2 Scope & flooding rules

| LSA | Flooded within |
|-----|----------------|
| Type 1, 2 | the area only |
| Type 3, 4 | generated by ABR, flooded between areas |
| Type 5 | **whole OSPF domain** (except stub areas — see below) |
| Type 7 | the NSSA only (converted to Type 5 by ABR at exit) |

- **Stub / totally stubby / NSSA areas** filter Type 5 (and often Type 3/4) — that's the
  whole point (notes 09/10/11).

### 2.3 The route codes that LSAs produce

| LSA | Route code in `show ip route` |
|-----|------------------------------|
| Type 1/2 | `O` (intra-area) |
| Type 3 | `O IA` (inter-area) |
| Type 5 | `O E1` / `O E2` (external) |
| Type 7 | `O N1` / `O N2` (NSSA external) |

- **E1 vs E2**: E2 = external cost added to the LSA's advertised metric (default);
  E1 = total cost includes the path cost to the ASBR. Same for N1/N2.

### 2.4 What each type is used for (quick mental map)

- **Type 1**: "my links" → SPF builds intra-area tree.
- **Type 2**: DR's view of a shared segment.
- **Type 3**: inter-area routes — an ABR's summarization of an area.
- **Type 4**: "this ASBR is over here" — needed to compute cost to external routes.
- **Type 5**: external/redistributed routes (prefix + forwarding address + cost).
- **Type 7**: external routes inside an NSSA; ABR translates to Type 5 on exit.

### 2.5 Opaque LSAs (Types 9/10/11)

- Type 9: link-local scope (e.g., LDP/segment routing).
- Type 10: area-local scope (TE, MPLS Traffic Engineering).
- Type 11: domain scope.
- Encor exam: identify opaque types are used for **MPLS-TE / extensions**, not routing basics.

## 3. Configuration / Commands

```text
show ip ospf database                       ! summary of all LSAs
show ip ospf database router                ! Type 1
show ip ospf database network               ! Type 2
show ip ospf database summary                ! Type 3
show ip ospf database asbr-summary           ! Type 4
show ip ospf database external               ! Type 5
show ip ospf database nssa-external          ! Type 7
show ip ospf database <router-id>            ! a specific LSA
show ip ospf database link-state             ! ages/sequence per LSA
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Missing external routes | Type 5 filtered by stub area | area type check |
| No NSSA routes | Type 7 not translated to 5 | ABR translation config |
| Inter-area routes absent | Type 3 not generated / area 0 broken | `show ip ospf database summary` |
| LSA flapping | interface flap / DR churn | `show ip ospf database link-state` |
| Huge LSDB | no summarization at ABR | `area X range` (note 14) |

---

## 5. Exam Traps

- **Type 2 is originated by the DR**, not by every router.
- **Type 4 tells you how to reach the ASBR** — needed only when an external route's
  forwarding address isn't directly reachable.
- **Type 5 is domain-wide but blocked in stub areas** → that's why NSSA (Type 7) exists.
- **Type 7 → Type 5 translation happens at the ABR**, not the ASBR.
- Route code mapping: `O`(1/2) `O IA`(3) `O E1/E2`(5) `O N1/N2`(7).
- **E2 default; E1 includes cost to ASBR.**
