# ARP (Address Resolution Protocol)

> **Level 04 · Ethernet & Switching** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**ARP** maps an **IPv4 address → MAC address** on a local link. It is run *per L2
segment* — before sending an IP packet to its next hop, a host must know the MAC of
that next hop (its default gateway on the same LAN, or the target host's MAC when on
the same subnet). Runs on L2/L3 boundary; data plane bootstrap for Ethernet/IPv4.

---

## 2. Core Concepts

### 2.1 When ARP is used
- Host A wants to send to Host B:
  - If same subnet → ARP for **B's IP → B's MAC**.
  - If different subnet → ARP for the **default gateway's IP** (− its MAC), then
    packet goes to the router's L2 address, L3 destination stays B.

### 2.2 Message exchange
1. **ARP Request** (broadcast): "Who has 10.1.1.2? Tell 10.1.1.1." — sender fills
   its own MAC/IP and asks for target's MAC.
2. **ARP Reply** (unicast to requester): target replies with its MAC.
3. Both sides **cache** the mapping in the ARP table (age ~parisco 4 min on hosts /
   14 min+).

### 2.3 Frame/message format highlights
- **ARP is not IP** but has a **default EtherType 0x0806**; the ARP header has
  HTYPE (1=Eth), PTYPE (0x0800), HLEN/PLEN, opcode (1 req / 2 reply), sender MAC+IP,
  target MAC+IP.
- Ethernet frame for ARP request is **broadcast** dest (`FF:FF:FF:FF:FF:FF`);
  the reply is a normal unicast frame.

### 2.4 ARP table & aging
- Cisco: `arp timeout <sec>` (default **14400 s / 4 h** on IOS for dynamic entries).
- Hosts usually 2–4 minutes (OS-dependent); switch uses the table to know hosts;
  **proxy-ARP for the router**: router answers for destinations it can route (see note below).
- `show arp` = mapping cache; `show ip arp` (optional `vrf`).

### 2.5 Security exposure → ARP poisoning
- ARP is trust-on-first-use: a rogue device can answer others' requests → impersonate
  gateway (MITM). Mitigations: **Dynamic ARP Inspection (DAI)** (Level 17),
  BPDU/PAgP protection, static ARP for critical hosts.

### 2.6 IPv6: no ARP
- Replaced by **Neighbor Discovery (ND)**: NDP with ICMPv6 (NS/NA; SLAAC etc.) — Level 06.

## 3. Configuration / Commands

```text
show arp
show ip arp
show arp | include 10.1.1.
clear ip arp 10.1.1.2        # to force re-resolution
arp 10.1.1.2 abcd.1234.5678 arpa    # static entry (rare; for security)
# Debug ARP
debug arp

# Counters/security
show ip arp inspection ?
```

---

## 4. Exam Traps

- **ARP = IPv4 only.** IPv6 uses ND/NDP (no ARP).
- **ARP Request = broadcast; Reply = unicast.**
- **ARP is competitive L2/L3: "protocol that maps IP→MAC"** — not IP itself.
- **Two environments (same-subnet vs cross-router)** — the gateway ARP trap.
- **Aging mismatch** (4h on Cisco vs host time) — stale caches cause no connectivity;
  `clear arp`.
- **Security**: ARP poisoning mitigated by **DAI** + port security.
