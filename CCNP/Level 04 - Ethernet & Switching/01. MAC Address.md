# MAC Address

> **Level 04 · Ethernet & Switching** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **MAC (Media Access Control) address** is the **Layer 2** hardware identifier,
48 bits (6 bytes) long, assigned at manufacturing to network interfaces. On Ethernet
it is used by switches to build forwarding tables and by hosts to deliver frames on
the local segment (IP→MAC resolution via ARP).

---

## 2. Core Concepts

### 2.1 Format and anatomy
- Written as 6 hex pairs: `AA:BB:CC:DD:EE:FF`, sometimes `AA-BB-CC-DD-EE-FF`
  or dotted (`AABB.CCDD.EEEE`, Cisco style).
- **OUI (Organizationally Unique Identifier)** = first 3 bytes (company),
  e.g., Cisco's 00:00:0C, 00:1B:21...
- Last 3 bytes = NIC-specific serial.

### 2.2 Bit 0 / I/G and U/L bits

| Bit | Meaning |
|-----|---------|
| **I/G (bit 0)** | 0 = **unicast** (unique to one NIC); 1 = **multicast**/broadcast group address |
| **U/L (bit 1)** | 0 = **universal** (globally unique, burned-in, OUI-managed); 1 = **locally administered** (software-set / virtual) |

**Broadcast** = all ones `FF:FF:FF:FF:FF:FF` (I/G=1, no unicast).
**Multicast** = I/G bit 1 (e.g., IPv4 multicast maps to `01:00:5E:xx:xx:xx`).

### 2.3 Unicast vs broadcast vs multicast
- **Unicast frame** — one destination NIC; frame is delivered only there.
- **Broadcast frame** — destination `FF:FF:FF:FF:FF:FF` → all hosts in the L2 broadcast domain receive it.
- **Multicast MAC** — a group; only members of that group process it.

### 2.4 Locally administered addresses (exam-visible)
- VRRP/HSRP use **virtual MACs** (e.g., `0000.0c07.ac0x` HSRP, `0000.5e00.01xx` VRRP).
- VRRP partition such addresses as "locally administered": bit1 = 1.
- Virtual machines/hypervisors assign locally administered MACs (bit U/L=1).

### 2.5 MAC vs IP

| | MAC | IP |
|--|-----|-----|
| Layer | L2 | L3 |
| Scope | Local segment | Global/internetwork |
| Format | 48-bit hex | 32-bit IPv4 / 128-bit IPv6 |
| Assignment | Burned-in / static | Manual / DHCP / SLAAC |
| Changes at hops | Yes (per link) | No (unless NAT) |
| Resolved by | ARP (IP→MAC) | Routing (prefix→next hop) |

## 3. Configuration / Commands

```text
# View MAC table on a switch (which MAC is on which port/VLAN)
show mac address-table
show mac address-table address 00:1B:21:AA:BB:CC
# Configure a static MAC entry (rarely needed; for critical servers/HAG)
mac address-table static 00:1B:21:AA:BB:CC vlan 10 interface Gi0/1

# On a router: check interface MAC
show interfaces gigabitEthernet0/1 | include Hardware|bia
```

---

## 4. Exam Traps

- **48-bit, not 24; 6 bytes, not 4.**
- **FF:FF:FF:FF:FF:FF is the broadcast address** — never "a valid unicast MAC."
- **Multicast MAC's I/G bit = 1** — a least-significant bit of first octet test.
- **Locally-administered example: virtual/hypervisor MAC (bit 1 of first byte set).**
- **MAC changes at each L2 hop** — do not say the source MAC stays the same across routers.
- OUI = first 3 bytes — "manufacturer of the NIC."
