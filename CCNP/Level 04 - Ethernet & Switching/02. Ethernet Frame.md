# Ethernet Frame

> **Level 04 · Ethernet & Switching** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **Ethernet frame** is the Layer 2 encapsulation: the bit-level unit a switch
forwards. Understanding its fields explains MAC learning, EtherTypes, VLAN tagging,
and error checking — the "what the switch actually reads" story of switching.

---

## 2. Core Concepts

### 2.1 IEEE 802.3 frame fields
```
Preamble | SFD | Dest MAC | Src MAC | (802.1Q tag) | Length/Type | Payload | FCS
   7B      1B      6B         6B         (4B)          2B        46–1500   4B
```
- **Preamble (7B)** + **SFD (1B)**: clock sync / start marker; not count toward the
  forwarded frame.
- **Dest MAC (6B)** — used by the switch for forwarding decision.
- **Src MAC (6B)** — used for learning.
- **Length/Type (2B)**:
  - **Length ≤ 1500** = legacy 802.3 payload length.
  - **Type ≥ 0x0600** = **EtherType**, e.g., `0x0800` IPv4, `0x86DD` IPv6, `0x0806` ARP,
    `0x8100` 802.1Q (VLAN), `0x88A8` QinQ.
- **Payload** 46–1500 B (min padded to 46 to satisfy the slot).
- **FCS (Frame Check Sequence, 4B)** — CRC-32 over header+payload; receivers drop
  frames when it fails (shown as CRC errors).

### 2.2 IEEE 802.3 vs Ethernet II (DIX)

| | 802.3 | Ethernet II |
|--|-------|-------------|
| Field | Length | EtherType |
| Used by | legacy | IPv4/IPv6/ARP today |
| Layer 3 | LLC+payload | direct PDU |

Real networks today run **Ethernet II**; 802.3 length frames are legacy/token.

### 2.3 802.1Q tagged frame (+4B)
```
Dest|Src|TPID(0x8100)|TCI (PCP,DEI,VID 12b)|Type|Payload|FCS
```
- Adds **VLAN tag** — the switch reads it for trunking (Level 07). Frame grows
  from 1518 → **1522** bytes with a 1500 MTU.

### 2.4 Min/Max frame sizes
- Min 64 B (incl. everything from Dest MAC to FCS) — for collision-detection/slot reasons
  (legacy CSMA/CD; **runts** are below it).
- Max 1518 B untagged; 1522 tagged; **jumbo** = 9000+ payload MTU.
- **Runts** = less than 64 B, **Giants** = above maximum — error counters (Level 29).

### 2.5 "What the switch reads"
- Dest MAC → **forward**; Src MAC → **learn**; EtherType → classification; tag → VLAN.
  That's the entire L2 forwarding job (Level 03/04 CAM notes).

## 4. Exam Traps

- **EtherType vs length** — today 0x0800/0x86DD (type), not length.
- **Frame = MTU + 18 (untrunked) / +22 (tagged)** — arithmetic trap.
- **Min 64-byte frame means "baby giants" and runts** are counter symptoms.
- **Preamble is NOT part of the frame counted by most tools** — don't add 8 extra.
- **FCS is 4 bytes at the END (trailer)**, not header.
- Broadcast dest = all FF's; multicast = `01:00:5E` mapping under IPv4.
