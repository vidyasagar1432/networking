# Filtering

> **Level 04 · Ethernet & Switching** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Filtering** at Layer 2 = the switch **dropping/not-forwarding** a frame because it
isn't *destined* to another port (dest on same port), or by **explicit policy** such
as port security, VLAN pruning, broadcast/unknown-unicast storm control, or ACLs.
It keeps a LAN segment efficient by not echoing traffic back.

---

## 2. Core Concepts

### 2.1 Implicit (automatic) filtering
- **Same-port destination**: dest MAC learned on the same ingress port ⇒ no need to
  send it anywhere → frame is not forwarded (filtered).
- **VLAN segregation**: frames from VLAN X are never carried to VLAN Y ports — L2 broadcast
  domain boundary filters by design.
- **STP-blocked ports**: forwarding is disabled (loop prevention) — see Level 08.

### 2.2 Explicit filtering mechanisms

| Feature | What it filters | Config point |
|---------|-----------------|--------------|
| **Port security** | MACs not allowed on a port | `switchport port-security` |
| **VLAN pruning** (trunk) | VLANs not allowed on trunk | `switchport trunk allowed vlan` |
| **Storm control** | broadcast/multicast/unicast rate | `storm-control broadcast level` |
| **L2 ACL (MAC ACL)** | based on source/dest MAC | `mac access-group` |
| **IP ACL / VLAN ACL (VACL)** | L3/L4 on switch | `ip access-group` / `vlan access-map` |
| **PortBlock / private VLAN** | isolates ports / promiscuous design | `switchport protected` |
| **SPAN/ERSPAN direction** | monitoring capture only | monitor session |

### 2.3 Filtering vs flooding vs forwarding (quick decision)
- **Forward** = target port known on another port.
- **Filter (drop)** = dest on the enclosing/ingress segment or policy denies.
- **Flood** = unknown dest/broadcast.

### 2.4 Storm control (spc relevance)
- Protects against broadcast/multicast/unknown-unicast storms (loops, higher flaps)
  by dropping above an *% of link rate* threshold → stops a meltdown.
- Levels: `storm-control {broadcast|multicast|unicast} level <pct>`
  - On violation: action **shutdown / trap / send** (default sends trap only).

### 2.5 Port security filtering (L2 security)
- Allows only allowed MACs; modes **protect / restrict / shutdown** on violation
  (see [[Level 17 - Security]] note on Port Security).
- Sticky MACs memorize dynamically-learned MACs to survive reboot.

## 3. Configuration / Commands

```text
# VLAN filter on trunk (prune a VLAN)
interface GigabitEthernet0/24
 switchport trunk allowed vlan remove 50

# Storm control (protect the access uplink)
interface GigabitEthernet0/1
 storm-control broadcast level 20
 storm-control action shutdown

# Port security basic (limit allowed MACs)
switchport port-security maximum 2
switchport port-security violation restrict

# Protected port (isolate within VLAN)
switchport protected
```

---

## 4. Exam Traps

- **"Filter" is defined by whether traffic *should* cross — same-port dest is filtered,
  not forwarded.**
- **Port-security violation modes**: protect (drops silently, counts) vs restrict
  (traps/SNMP) vs shutdown (port errdisable) — the seven-key distinction.
- **Trunk allowed VLAN** = pruning mechanism; forgetting `allowed vlan` blacks out VLANs.
- **Storm control threshold is a percentage of the interface line-rate**, not a packet count.
- Local bridging: even a switch filters broadcast/multicast from *specific* hosts'
  station group unless their MAC is the destination.

## 5. Quick Review Table

| Filter | Behavior |
|--------|----------|
| Same-port dest | drop (no loop-back) |
| VLAN boundary | never cross-VLAN at L2 |
| STP blocked | no forwarding |
| Port security | restrict MACs per port |
| Trunk allowed | prune VLANs |
| Storm control | cap broadcast/mcast/unknown |
| Protected port | isolate intra-VLAN neighbors |
