# CAM Table

> **Level 04 · Ethernet & Switching** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **CAM (Content-Addressable Memory) table** on a switch maps **MAC address →
VLAN → egress port**. It is the switch's forwarding database built by MAC learning.
"CAM table" and "MAC address table" are used interchangeably in the syllabus/troubleshooting.

---

## 2. Core Concepts

### 2.1 What CAM means at L2
- CAM is a hardware lookup where you query by **key (MAC+VLAN)** and instantly get the
  port — that's why switching scale is measured in **CAM table size** (entries).
- Different from memory bytes: **CAM (L2)** vs **TCAM (L3/QoS)** for prefix/ACL lookups.

### 2.2 Table structure (typical entry)
```
VLAN  MAC Address        Type      Port
----  -----------------  --------  ----
10    00:1B:21:AA:BB:CC  DYNAMIC   Gi0/1
10    00:0c:29:12:34:56  DYNAMIC   Gi0/2
30    aa:aa:aa:aa:aa:aa  STATIC    Gi0/24
```
- **DYNAMIC** — learned from source MAC of received frames.
- **STATIC** — config/admin; plugged via `mac address-table static`.
- Missing entry → frame **flooded** to all ports in that VLAN (except source/trunks blocking).

### 2.3 Aging
- Dynamic entries age out after a default **aging time (default 300 s / 5 min)**;
  configurable `mac address-table aging-time <sec>`.
- Activity (frames from that MAC) refreshes the entry.
- Aging too short → flapping/ flooding; too long → stale forwarding to moved MACs.

### 2.4 Security extension
- **Port security** ties MAC(+count/limit) to a port; **sticky** entries and violation
  modes (shutdown/restrict/protect) — see Level 17 Port Security.
- **MAC move**: same MAC seen on two ports = "mac move" events → troubleshot via CAM.

### 2.5 Troubleshooting usage
- `show mac address-table` — fast check "which port is the host on?" and for flapping.
- Compare with ARP (IP→MAC) to confirm IP-to-port association.
- Duplicate/moved MACs → check a rogue switch or virtual MAC conflicts (HSRP).

## 3. Configuration / Commands

```text
show mac address-table
show mac address-table vlan 10
show mac address-table address 00:1B:21:AA:BB:CC
show mac address-table aging-time
show mac address-table count            # utilization vs CAM size
mac address-table aging-time 300        # global aging (default 300)
mac address-table static ... vlan 10 interface Gi0/1   # static binding
```

---

## 4. Exam Traps

- **CAM = L2 (MAC→port); TCAM = L3/L4 prefix lookup** — don't swap.
- **Unknown/unicast dest → flood** (that's why CAM size matters for flood protection).
- **Aging default is 5 minutes** on Cisco (300 s).
- **CAM entry is per (VLAN, MAC)** — a MAC can appear once per VLAN.
- **Port security ties MAC to port** — clears on shutdown-violation.
- **Flapping "MAC move" logs** → duplicate/rogue device or RSTP topology shift.
