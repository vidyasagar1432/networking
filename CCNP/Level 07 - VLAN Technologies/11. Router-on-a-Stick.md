# Router-on-a-Stick

> **Level 07 · VLAN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Router-on-a-Stick (ROaS)** = inter-VLAN routing with a **single physical router link**
carrying a **trunk** to the switch; each VLAN is a **tagged subinterface** that acts as
that VLAN's gateway. It's the simplest way to route multiple VLANs when there's no
multilayer L3 switch.

---

## 2. Core Concepts

### 2.1 The concept
```
   [switch]──trunk──[router Gi0/0]
                     ├─ .10 — VLAN 10 gateway
                     ├─ .20 — VLAN 20 gateway
                     └─ .30 — VLAN 30 gateway
```
- Physical port Gi0/0, subinterfaces Gi0/0.10/.20/.30.
- **802.1Q tagging** on subinterfaces; native VLAN uses no tag (or a "native" subinterface).

### 2.2 Config essentials
```text
interface GigabitEthernet0/0
 no ip address                 # physical does not carry IP

interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 10.1.10.1 255.255.255.0

interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 10.1.20.1 255.255.255.0

interface GigabitEthernet0/0.999
 encapsulation dot1Q 999 native   # native VLAN subinterface
 ip address 10.1.999.1 255.255.255.0
```
- Hosts in VLAN 10 point default-gateway to 10.1.10.1 (the .10 subinterface).

### 2.3 Traffic flow
1. Host → gateway (subinterface .20): frame tagged 20 to router.
2. Router routes to 10.1.10.0/24: egress subinterface .10 tags 10.
3. Switch strips/re-uses tag to reach the destination VLAN.

### 2.4 Pros & cons

| Pros | Cons |
|------|------|
| cheap (1 router, no L3 switch) | **bottleneck**: one link × one router CPU |
| simple design | inter-VLAN latency via router |
| works with any router | single point of failure |
| easy to learn | tag/subinterface math per VLAN |
- Mitigations: use a **multilayer switch (SVIs)** for speed, or bundle
  multiple links/ECMP in bigger sites (Level 07 Inter-VLAN Routing).

### 2.5 Troubleshooting ROaS
- **Subinterface down**: physical up + `encapsulation dot1Q <vid>` on subint; trunk up.
- **Wrong VID/mismatch** vs switch = one VLAN dead.
- **No IP on subinterface** → gateway missing; hosts no default.
- **Native**: use `encapsulation dot1Q <n> native` or keep default — read both configs.

## 3. Configuration / Commands

```text
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 10.1.10.1 255.255.255.0
interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 10.1.20.1 255.255.255.0

show ip interface brief
show ip route
ping 10.1.20.2 source 10.1.10.1
```

---

## 4. Exam Traps

- **Subinterfaces need `encapsulation dot1Q`** — missing it = no L3 for that VLAN.
- **Physical interface `no ip address`** — put IPs on subinterfaces only.
- **Native VLAN on router**: an untagged subinterface (or `native` keyword).
- **Bottleneck** answer for "why not ROaS in a large campus?" — one link/CPU.
- **Router is NOT a switch** — it does not learn MAC-to-port; it routes (ARP per subnet).
