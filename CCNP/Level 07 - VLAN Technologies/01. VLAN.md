# VLAN

> **Level 07 · VLAN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **VLAN (Virtual Local Area Network)** splits a single physical switch into multiple
**logical broadcast domains**. Ports in the same VLAN behave as if they share one
switch/one segment; ports in different VLANs are isolated at L2 and need routing —
giving segmentación, security, and scalability without extra hardware.

---

## 2. Core Concepts

### 2.1 What a VLAN actually does

| Non-VLAN (flat) | With VLANs |
|-----------------|------------|
| one big broadcast domain | each VLAN = own broadcast domain |
| all ports one CAM/flood scope | L2 forwarding bounded per VLAN |
| no isolation (anyone sees ARP/loops) | users vs servers vs mgmt separated |
| one subnet whole switch | one IP subnet (usually) per VLAN |

- The switch marks frames with a **VLAN tag** (802.1Q) internally; a frame stays in
  its VLAN end-to-end (trunking carries multiple VLANs).

### 2.2 Identification & numbers

| Item | Range | Notes |
|------|-------|-------|
| Valid VLANs | 1–4094 | 0, 4095 reserved |
| Extended VLANs | 1006–4094 | must be configured explicitly |
| **VLAN 1** | default/native | all ports start in it; risky / often changed |
| VLAN 1002–1005 | FDDI/TokenRing legacy | exist by default |
- **VID is 12 bits** → 0–4095 (that's the 4094 usable ceiling).

### 2.3 Per-VLAN broadcast/security
- **Broadcasts/ARP/DHCP stay inside the VLAN** — that's how you contain storms
  (Level 04 Broadcast Domains).
- Rogue devices can only spam their own VLAN; inter-VLAN access is controlled by routing + ACLs.
- This is the primary segmentation tool before VRFs/SGACLs in modern fabrics.

### 2.4 Design guidelines
- One VLAN = one IP subnet (best practice).
- Allocate **dedicated VLANs**: user, server, guest, voice, management, native/traffic.
- **8091 rule**: keep user VLANs in a range, infrastructure VLANs separate.
- Summary: VLANs give L2 isolation; **routing (SVI/L3 switch) restores connectivity**
  with policy (Level 07 Inter-VLAN Routing).

### 2.5 VLANs and the fabric future (exam context)
- Classic: static access ports + SVIs.
- **SD-Access/VXLAN** (Level 24) virtualize the VLAN concept with VNI segments —
  "VLAN of the next era." Foundation to know before VXLAN.

## 3. Configuration / Commands

```text
# Create VLAN
vlan 10
 name Users
# Assign access port
interface Gi0/1
 switchport mode access
 switchport access vlan 10
# Verify
show vlan brief
show vlan id 10
show interfaces trunk
```

## 4. Exam Traps

- **Default VLAN 1** — can't be deleted; native by default; often a network-design hole.
- **VLAN 1 CAN carry all VLANs** — it's not "fine" by default; prune/change for security.
- **Extended VLANs (1006-4094) require `vlan database`-like edit or `config`; 2-1001 default.**
- **A VLAN is NOT a subnet** — it's L2; the subnet is a routing plan.
- **Trunk vs access** decide tag behavior (Level 07 notes).
- 1002–1005 legacy VLANs exist by default — commonly tested trivia.
