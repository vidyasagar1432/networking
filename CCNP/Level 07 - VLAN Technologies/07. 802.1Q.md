# 802.1Q

> **Level 07 · VLAN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**IEEE 802.1Q** is the standard for **VLAN tagging**: it inserts a 4-byte tag into the
Ethernet frame so switches/trunks can carry multiple VLANs on one link. With ISL
deprecated, 802.1Q is *the* trunking protocol on every modern switch.

---

## 2. Core Concepts

### 2.1 The tag (4 bytes inserted after Src MAC)
```
| TPID 2B | TCI 2B |
TPID = 0x8100  (tag protocol identifier)
TCI = PCP(3) | DEI(1) | VID(12)
```

| Field | Size | Meaning |
|-------|------|---------|
| **TPID** | 2 B | always 0x8100 (marks "tagged") |
| **PCP** | 3 bits | priority (CoS 0-7) — QoS src (Level 21) |
| **DEI** | 1 bit | drop eligible indicator |
| **VID** | 12 bits | VLAN identifier 0–4095 |
- With tag: frame grows from 1518 → **1522 bytes** (MTU note Level 01).

### 2.2 Effect on the frame
```
Untagged:  [DA | SA | Type | Payload | FCS]
Tagged:    [DA | SA | TPID | PCP/DEI/VID | Type | Payload | FCS]  (+4B)
```

### 2.3 802.1Q vs ISL (legacy)

| | 802.1Q | ISL |
|--|--------|-----|
| Tag | 4-byte inside frame | 30-byte external encapsulation |
| Native VLAN | untagged exists | no native (all tagged) |
| Standard | IEEE | Cisco legacy |
| Today | universal | dead (no support on new) |

### 2.4 Where the tag acts
- Inserted/removed by **egress/ingress switch** on trunks (VLAN-tag operations).
- Access ports **strip tags**; trunks preserve 802.1Q tags.
- Routers: **subinterfaces** with `encapsulation dot1Q <vid>` for inter-VLAN routing
  (Level 07 Router-on-a-Stick).
- Firewalls/LBs use tagged interfaces to segment directly.

### 2.5 QoS tie-in
- **PCP bits = 802.1p priority** — that's CoS from tag → used by switch QoS
  (maps to queue; DSCP mapping modern) — Level 21.

## 3. Configuration / Commands

```text
interface GigabitEthernet0/24
 switchport trunk encapsulation dot1q     # (older IOS) choose
 switchport mode trunk

# Router side (router-on-a-stick)
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 10.1.10.1 255.255.255.0
interface GigabitEthernet0/0.999
 encapsulation dot1Q 999 native
 ip address 10.1.999.1 255.255.255.0

show vlan
show interfaces trunk
show etherchannel 1 detail (trunk members)
```

---

## 4. Exam Traps

- **TPID is 0x8100**, not a VLAN number.
- **Tag adds 4 bytes** — frame ≤1522, MTU stays 1500.
- **9,14 4K VLANs** (VID up to 4095, usable 4094).
- **ISL is gone** — don't answer "ISL" on any modern config.
- **PCP = the QoS priority in the tag**; `priority-queue out`/queues use CoS.
- **Native stays untagged** (that's 802.1Q behavior).
