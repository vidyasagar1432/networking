# Access Port

> **Level 07 · VLAN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

An **access port** is a switch port that carries traffic for **one VLAN only** —
the "endpoint port" (PC, printer, camera, AP). Its frames are **untagged** on the
wire; the switch assigns received frames to the configured **access VLAN**.

---

## 2. Core Concepts

### 2.1 What an access port does
- Assigned a single **access VLAN** (e.g., VLAN 10).
- Sends **untagged frames** to the device; tags incoming frames internally with that VLAN.
- Ignores/does not pass other VLANs (no trunking).
- Classic example: `switchport mode access` + `switchport access vlan 10`.

### 2.2 Access vs trunk (the contrast)

| | Access | Trunk |
|--|--------|-------|
| VLANs carried | one | many (tagged) |
| Tag on wire | none (untagged) | 802.1Q tags |
| Typical peer | host/phone/AP | switch/router |
| Config | `mode access` | `mode trunk` |
| Native VLAN | N/A (untagged default) | the one untagged VLAN |
- Voice VLAN is the special case of an access port that also *accepts* tagged frames
  from a phone (cosyl) — Level 07 Voice VLAN.

### 2.3 Port behavior details
- **Spanning-tree PortFast** is typically enabled on access ports (hosts → instant
  forwarding, no listening-learning delay).
- **Security hooks** live here: port security, BPDU Guard, DHCP snooping trust,
  802.1X — all apply per access port (Level 17).
- **PoE** powers phones/APs/WAPs on access ports (Level 01).

### 2.4 Explicit vs auto mode

| Config | Effect |
|--------|--------|
| `switchport mode access` | forced access (never negotiates trunk) |
| `switchport mode dynamic desirable` | wants to trunk; may negotiate (dangerous on hosts) |
| default (auto) | negotiates via DTP; access if peer won't trunk |
- Best practice: set `mode access` explicitly on endpoint ports.

### 2.5 Gotchas / troubleshooting
- **Wrong VLAN on access** → host gets DHCP/ARP in the wrong subnet (silent).
- Port in **errdisable** (port-security/BPDUguard) → looks "down"; check `show errdisable`.
- If unsure of mode: `show interfaces Gi0/1 switchport` reveals VLAN & mode.

---

## 3. Configuration / Commands

```text
interface GigabitEthernet0/1
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
 no shutdown

show interfaces Gi0/1 switchport
show interfaces Gi0/1 status
```

---

## 4. Exam Traps

- **Access = ONE VLAN, untagged frames** — don't call it "trunk."
- **Voice VLAN is an exception** — phone's frames are tagged even on an access port.
- **`dynamic desirable` on a host port** can turn it into a trunk (trunking attack vector).
- **PortFast** on access (not trunks) is the fast-convergence answer.
- **STP beats mode** — an access port still runs spanning-tree unless PortFast.
