# Inter-VLAN Routing

> **Level 07 · VLAN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Inter-VLAN routing** lets devices in **different VLANs** communicate — since VLAN
isolation is L2, connectivity requires an **L3 device** (router or multilayer switch)
acting at Layer 3 between the VLAN subnets. Three classic designs: **router-on-a-stick,
SVI on multilayer switches, and routed/access L3**.

---

## 2. Core Concepts

### 2.1 Why routing is needed
- VLANs = separate L2 broadcast domains, usually separate **IP subnets**.
- A frame can't cross VLAN boundary by MAC; only an IP router can forward between
  the subnets.

### 2.2 The three implementation methods

| Method | Where the L3 sits | Pros |
|--------|-------------------|------|
| **Router on a stick (ROaS)** | single router + trunk subinterfaces | cheap, small sites |
| **SVI (Switch Virtual Interface)** | L3 switch (`interface Vlan10`) | fast, standard campus |
| **L3 routed access** | access switch routes per port | scale, edge performance |

### 2.3 Router on a stick (detail — Level 07 note too)
- One physical router link trunked to switch; subinterfaces per VLAN:
```
interface Gi0/0.10
 encapsulation dot1Q 10
 ip address 10.1.10.1 255.255.255.0   # VLAN 10 gateway
interface Gi0/0.20
 encapsulation dot1Q 20
 ip address 10.1.20.1 255.255.255.0   # VLAN 20 gateway
```
- Hosts: default gateway = subinterface IP (per VLAN).
- ✓ cheap ✓ simple; ✗ single-router bottleneck via one link.

### 2.4 SVI (multilayer switch) — the campus standard
```
ip routing            # enable L3 on switch
interface Vlan10
 ip address 10.1.10.1 255.255.255.0
interface Vlan20
 ip address 10.1.20.1 255.255.255.0
```
- Routing in the switch ASIC (CEF/TCAM) — near-wire performance.
- This enables VLANs → SVIs → static/OSPF/EIGRP routes → to the core.
- Router-on-a-stick has no SVI (it's a router, not a switch).

### 2.5 Policy & segmentation controls
- ACL inter-VLAN: block guest→internal, allow mgmt→all, etc. (Level 17).
- QoS marking at SVIs; routing is where you first see L3 policy applied.
- Best practice: route at **distribution** (HSRP pair) not at the access edge for
  classic 3-tier; modern campus may route at access (spine-leaf).

## 4. Exam Traps

- **VLANs don't route by themselves** — without L3, VLAN 10 can't reach VLAN 20.
- **ROaS bottleneck** — one link = bandwidth ceiling; that's its tradeoff.
- **SVI requires `ip routing`** on catalyst (default often off) — a classic miss.
- **Subinterfaces on ROaS are tagged** — don't forget `encapsulation dot1Q`.
- **Native VLAN = untagged subinterface** — a special case on the trunk to the router.
- **Modern**: routed access (L3 to the edge) is the CCNP-speed answer, not just SVI.

| Method | Device | L3 point | Best for |
|--------|--------|----------|----------|
| ROaS | router | subinterfaces | small/simpler |
