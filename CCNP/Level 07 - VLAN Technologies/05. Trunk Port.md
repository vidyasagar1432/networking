# Trunk Port

> **Level 07 · VLAN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **trunk port** carries **multiple VLANs** between switches (or switch→router) using
**802.1Q tagging**. Each frame is marked with its VLAN ID except the **native VLAN**
(which travels untagged). Trunks are the spine of multi-VLAN campuses.

---

## 2. Core Concepts

### 2.1 What a trunk does
- One physical link transports frames for many VLANs simultaneously.
- Frames are tagged with the **VID** (802.1Q tag, 12-bit).
- The **native VLAN** (often 1) goes **untagged** on the wire.

Frame on a trunk:
```
[Dest MAC | Src MAC | 0x8100 | TCI(VID) | Type | Payload | FCS]
```

### 2.2 Trunk vs access (already established)

| | Trunk | Access |
|--|-------|--------|
| VLANs | many | one |
| Tags | yes (802.1Q) | none |
| Typical peer | switch/router | host |
| Config | `switchport mode trunk` | `mode access` |

### 2.3 Configuration essentials
```text
interface GigabitEthernet0/24
 switchport mode trunk
 switchport trunk native vlan 999       # move native off VLAN 1
 switchport trunk allowed vlan 10,20,30 # prune flooded VLANs
 switchport trunk encapsulation dot1q   # (older switches)
```
- **`allowed vlan`** controls which VLANs can cross (hygiene + security).
- **EtherChannel + trunk** is the standard link group (Level 08 EtherChannel).

### 2.4 DTP & negotiation
- `switchport mode trunk` vs `dynamic desirable/auto` — DTP can autocreate trunks
  (security risk: attacker asks for trunk). Disable with `switchport nonegotiate`.
- A "dynamic" port that becomes a trunk to an untrusted device = **VLAN hopping/transex** vector.

### 2.5 Native VLAN in the frame story
- Untagged frames on a trunk are considered **native VLAN** at both ends.
- Native VLAN mismatch (different IDs per end) → **traffic quietly misconfigured**
  (CDP messages; potential VLAN hopping).
- Best practice: change native away from VLAN 1 and match at both ends.

## 3. Configuration / Commands

```text
interface GigabitEthernet0/24
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk native vlan 999
 switchport trunk allowed vlan 10,20,30,999
 switchport nonegotiate

show interfaces trunk
show interfaces Gi0/24 trunk
show vlan
```

---

## 4. Exam Traps

- **Trunk = tagged traffic**; native VLAN is the untagged exception (Level 07 Native).
- **Native VLAN mismatch is the classic silent inter-switch bug** — both ends must agree.
- **Allowing VLAN 1 default** carries it everywhere — prune for security.
- **DTP on** = trunking potential to an attacker (double-tagging/VLAN hopping).
- **Trunking protocol is 802.1Q (with ISL legacy)** — don't say "trunk uses access."
- **Allowed list does not include native unless specified** — a config nuance.
