# IP Address Classes

> **Level 05 · IPv4** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Classful addressing** divided IPv4 into **Classes A–E** based on the **first octet**.
It is largely **historical** — replaced by classless (CIDR) routing — but the class
boundaries still underpin the range checks, private ranges, loopback, and multicast.

---

## 2. Core Concepts

### 2.1 The classes

| Class | First octet | First bits | Default mask | Hosts/network | Use |
|-------|-------------|------------|--------------|---------------|-----|
| **A** | 0–127 | 0 | /8 | 2^24 − 2 | very large orgs |
| **B** | 128–191 | 10 | /16 | 2^16 − 2 | medium |
| **C** | 192–223 | 110 | /24 | 2^8 − 2 | small |
| **D** | 224–239 | 1110 | — | — | **multicast** |
| **E** | 240–255 | 1111 | — | — | **reserved/experimental** |

### 2.2 How to determine class from first octet
- A: 0–127 (special: 0 reserved, **127 = loopback**)
- B: 128–191
- C: 192–223
- D: 224–239 (multicast)
- E: 240–255 (reserved)

### 2.3 Default masks (classful)

| Class | Default mask |
|-------|--------------|
| A | 255.0.0.0 (/8) |
| B | 255.255.0.0 (/16) |
| C | 255.255.255.0 (/24) |

### 2.4 Private ranges (RFC 1918) — cause class boundary memory
- **Class A**: `10.0.0.0/8`
- **Class B**: `172.16.0.0/12` (16 /16s: 172.16–172.31)
- **Class C**: `192.168.0.0/16` (256 /24s)
Classless/private, but the mnemonic maps to class letters.

### 2.5 Classful is dead (mostly)
- Classful routing (RIP v1, IGRP) — classful boundaries assumed by first octet; no
  subnet carry.
- **CIDR/VLSM** (Level 11/12) killed class by letting masks be anything.
- Modern choices: exam range checks (which class is IP X) still tested from the table.

### 2.6 Notable class-scoped addresses

| Range | Purpose |
|-------|---------|
| 127.0.0.0/8 | loopback |
| 169.254.0.0/16 | APIPA (link-local auto) |
| 224.0.0.0/4 | multicast group |
| 0.0.0.0/8 | "this network" (0.0.0.0 = default) |
| 255.255.255.255 | limited broadcast |

## 3. Configuration / Commands

```text
# Class equality is not used today — the mask defines everything.
interface GigabitEthernet0/1
 ip address 172.16.1.1 255.255.255.0   # classful would be /16; we chose /24
```

---

## 4. Exam Traps

- **Determining class** = first-octet range, before mask discussion.
- **Class D/E have no subnet/host split** — multicast/reserved.
- **127 is class A but loopback** — "which class is 127?" is a trick (it's A-ranged but reserved).
- **Classful vs classless**: never say "class C subnetting" for a /27 — CIDR discussions
  are classless.
- **Private ranges** counted from the class table — the "172.16-31" trap (172.32 is not private).
