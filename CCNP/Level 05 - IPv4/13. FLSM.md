# FLSM (Fixed-Length Subnet Masking)

> **Level 05 · IPv4** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**FLSM (Fixed-Length Subnet Masking)** divides a network into multiple subnets where **every subnet uses the same subnet mask/prefix length**.

This makes subnetting simple and predictable, but it can **waste IP addresses** when different subnets have different host requirements.

> **FLSM = Same prefix length for every subnet.**

---

## 2. Core Concepts

### 2.1 How FLSM Works

Given:

```text
Network: 10.1.0.0/16
Chosen mask: /24
```

The `/16` network is divided into `/24` subnets.

- Borrowed bits: `24 - 16 = 8`
    
- Number of subnets: `2^8 = 256`
    
- Addresses per subnet: `2^(32-24) = 256`
    
- Usable hosts per subnet: `256 - 2 = 254`
    

Example:

|Subnet|Network|Usable Hosts|Broadcast|
|---|---|--:|---|
|1|`10.1.0.0/24`|254|`10.1.0.255`|
|2|`10.1.1.0/24`|254|`10.1.1.255`|
|3|`10.1.2.0/24`|254|`10.1.2.255`|
|...|...|...|...|
|256|`10.1.255.0/24`|254|`10.1.255.255`|

Every subnet has exactly the **same size**.

---

## 3. FLSM Address Waste

Suppose three departments need:

```text
Department A → 6 hosts
Department B → 20 hosts
Department C → 100 hosts
```

With FLSM, all subnets must use the same mask.

If `/25` is selected:

```text
/25 → 126 usable hosts per subnet
```

Then every department receives 126 usable addresses even though they do not all need that many.

This creates address waste.

**VLSM** solves this by allowing different subnet sizes:

```text
6 hosts   → /29
20 hosts  → /27
100 hosts → /25
```

---

## 4. FLSM vs VLSM

|Aspect|FLSM|VLSM|
|---|---|---|
|Subnet mask|Same for all subnets|Can differ per subnet|
|Subnet sizes|Equal|Variable|
|Address efficiency|Lower when requirements differ|Higher|
|Calculation|Simpler|More planning required|
|Best suited for|Uniform requirements|Different host requirements|
|Main idea|**Uniformity**|**Efficiency**|

### Remember

> **FLSM = Fixed/equal-sized subnets**  
> **VLSM = Variable-sized subnets**

---

## 5. FLSM Subnetting Formula

For a network with original prefix `/p` and new prefix `/n`:

### Number of Subnets

```text
2^(n - p)
```

### Total Addresses per Subnet

```text
2^(32 - n)
```

### Traditional Usable Hosts per Subnet

```text
2^(32 - n) - 2
```

Where:

- `p` = original prefix length
    
- `n` = new subnet prefix length
    

### Example

```text
10.10.0.0/16 → /20
```

Borrowed bits:

```text
20 - 16 = 4
```

Number of subnets:

```text
2^4 = 16
```

Addresses per subnet:

```text
2^(32-20) = 4096
```

Usable hosts:

```text
4096 - 2 = 4094
```

Therefore:

```text
16 subnets
4094 usable hosts per subnet
```

## 6. Common FLSM Subnetting Table

### Starting with `/24`

|Borrowed Bits|Prefix|Subnets|Usable Hosts/Subnet|
|--:|--:|--:|--:|
|0|`/24`|1|254|
|1|`/25`|2|126|
|2|`/26`|4|62|
|3|`/27`|8|30|
|4|`/28`|16|14|
|5|`/29`|32|6|
|6|`/30`|64|2|

> **Exam shortcut:** Each additional borrowed bit doubles the number of equal-sized subnets while approximately halving the addresses per subnet.

## 7. Example: `/24` into `/27`

Given:

```text
Network: 192.168.10.0/24
New mask: /27
```

Borrowed bits:

```text
27 - 24 = 3
```

Subnets:

```text
2^3 = 8
```

Addresses per subnet:

```text
2^(32-27) = 32
```

Usable hosts:

```text
32 - 2 = 30
```

The eight subnets are:

|#|Network|Usable Range|Broadcast|
|--:|---|---|---|
|1|`192.168.10.0/27`|`.1 – .30`|`.31`|
|2|`192.168.10.32/27`|`.33 – .62`|`.63`|
|3|`192.168.10.64/27`|`.65 – .94`|`.95`|
|4|`192.168.10.96/27`|`.97 – .126`|`.127`|
|5|`192.168.10.128/27`|`.129 – .158`|`.159`|
|6|`192.168.10.160/27`|`.161 – .190`|`.191`|
|7|`192.168.10.192/27`|`.193 – .222`|`.223`|
|8|`192.168.10.224/27`|`.225 – .254`|`.255`|

## 8. Cisco Configuration

FLSM does **not** have a special Cisco command.

The CLI configuration looks essentially the same as VLSM. The difference is in the **addressing plan**.

Example: three VLAN interfaces using the same `/26` mask:

```cisco
interface Vlan10
 ip address 10.1.0.1 255.255.255.192

interface Vlan11
 ip address 10.1.0.65 255.255.255.192

interface Vlan12
 ip address 10.1.0.129 255.255.255.192
```

All three subnets use:

```text
255.255.255.192 = /26
```

Therefore, this is an **FLSM design**.

---

## 9. FLSM and Routing

FLSM describes the **subnetting/addressing design**, not a particular routing protocol.

FLSM can be used with classless routing protocols such as:

- OSPF
    
- EIGRP
    
- IS-IS
    
- BGP
    

It can also exist in networks using older classful routing concepts.

> **Important:** Using the same mask does **not** automatically make a routing protocol classful.

---

## 10. FLSM vs Route Summarization

Do not confuse FLSM with route summarization.

### FLSM

Concerned with:

```text
How are a network's subnets divided?
```

Example:

```text
10.1.0.0/24
10.1.1.0/24
10.1.2.0/24
10.1.3.0/24
```

All subnets have the same prefix length.

### Route Summarization

Concerned with:

```text
How can multiple routes be represented by one summary route?
```

Example:

```text
10.1.0.0/24
10.1.1.0/24
10.1.2.0/24
10.1.3.0/24
```

may be summarized as:

```text
10.1.0.0/22
```

These are related to IP addressing but are **different concepts**.

## 11. Exam Traps

### Trap 1 — Same mask = FLSM

If every subnet uses the same prefix length:

```text
/26
/26
/26
/26
```

→ **FLSM**

If subnet sizes differ:

```text
/26
/27
/30
```

→ **VLSM**

---

### Trap 2 — `/27` subnets in `/24`

Question:

> How many `/27` subnets can be created from a `/24`?

Calculation:

```text
27 - 24 = 3 borrowed bits

2^3 = 8 subnets
```

Answer:

```text
8 subnets
```

Each has:

```text
32 total addresses
30 usable host addresses
```

---

### Trap 3 — FLSM wastes addresses

FLSM does **not always** waste addresses.

If every subnet has approximately the same host requirement, FLSM can be perfectly efficient for that design.

The waste occurs when **different subnets require significantly different numbers of hosts**.

---

### Trap 4 — FLSM is a Cisco command

There is no:

```text
ip address flsm
```

command.

FLSM is an **addressing/subnetting design method**.

---

### Trap 5 — FLSM = classful routing

Incorrect.

```text
FLSM ≠ classful routing
```

FLSM simply means the subnets use a **uniform prefix length**.

> **FLSM = Fixed-Length = Fixed/Equal subnet size = Same mask everywhere.**

```text

        │
        ├── YES → FLSM
        │
        └── NO  → VLSM
```
