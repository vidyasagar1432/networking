# FLSM (Fixed-Length Subnet Masking)

> **Level 05 · IPv4** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**FLSM** divides a network into subnets using **one single subnet mask** for all of
them. Simple and easy to calculate — but it **wastes addresses** because every subnet
gets the same (largest) size, regardless of need.

---

## 2. Core Concepts

### 2.1 How FLSM works
- Given network `10.1.0.0/16`, pick a mask, e.g., /24 → **256 subnets of 254 hosts each**.
- Every subnet identical size; you cannot size to need.

### 2.2 Example

| Subnet | Address | Usable |
|--------|---------|--------|
| 1 | 10.1.1.0/24 | 254 |
| 2 | 10.1.2.0/24 | 254 |
| 3 | 10.1.3.0/24 | 254 |
... even if each actually needs 6 hosts, all are /24s.

### 2.3 FLSM vs VLSM (exam comparison)

| Aspect | FLSM | VLSM |
|--------|------|------|
| One mask for all | yes | no |
| Address waste | high | low |
| Calculation | easy | planned-larger-first |
| Exam best-answer | when uniform/simplest | when growth/efficiency |
| Typical old exam | CID summary | addressed design problems |

### 2.4 When FLSM is "right"
- **Very simple/legacy** designs; uniform requirement; exam asks "how many subnets of
  this mask?" — that's an FLSM-style question.
- Building the "cheat sheet": `2^s` subnets where s = subnet bits borrowed.

### 2.5 Standard formula table (with mask uniform)
e.g., /24 sliced:

| Borrow | Mask | Subnets | Hosts/sub |
|--------|------|---------|-----------|
| 1 | /25 | 2 | 126 |
| 2 | /26 | 4 | 62 |
| 3 | /27 | 8 | 30 |
| 4 | /28 | 16 | 14 |
| 5 | /29 | 32 | 6 |
| 6 | /30 | 64 | 2 |

## 3. Configuration / Commands

```text
# FLSM: all subnets same mask — the config looks identical to VLSM in CLI,
# it's the PLAN that differs (here every VLAN uses /26)
interface Vlan10
 ip address 10.1.0.1 255.255.255.192
interface Vlan11
 ip address 10.1.0.65 255.255.255.192
interface Vlan12
 ip address 10.1.0.129 255.255.255.192
```

---

## 4. Exam Traps

- **FLSM = same mask everywhere** — don't design uneven sizes and call it FLSM.
- **"How many /27 subnets in a /24?"** — that's an FLSM-count computation (8).
- **It ignores actual host needs** → address waste — the reason VLSM exists.
- **Works with classful AND classless routing** (uniform masks are class-compatible).
- Don't answer "VLSM" where the plan says everything uses one mask.
