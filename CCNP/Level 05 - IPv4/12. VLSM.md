# VLSM (Variable-Length Subnet Masking)

> **Level 05 · IPv4** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**VLSM** lets a single address space use **different-length subnet masks per subnet**
— each subnet sized to its actual host count. It's the standard, exam-heavy way to
stretch IPv4, in contrast to FLSM which forces one uniform mask.

---

## 2. Core Concepts

### 2.1 VLSM vs FLSM

| | FLSM | VLSM |
|--|------|------|
| Mask | same on every subnet | per-subnet different |
| Example | 10.0.0.0/24 → all /26 | 10.0.0.0/24 → /30, /28, /26 together |
| Waste | high (big subnets unused) | minimal |
| Needs | RIPv2/OSPF (classless) | same, plus planning |

### 2.2 Example (the classic 4-subnet design)
Given `10.10.0.0/24` the request subnets: A=50 hosts, B=25 hosts, C=10 hosts, D=2 hosts.

Order by largest first:

| Subnet | Hosts needed | Mask | Block start | Usable |
|--------|--------------|------|-------------|--------|
| A | 50 | /26 (64) | .0 | .1–.62 |
| B | 25 | /27 (32) | .64 | .65–.94 |
| C | 10 | /28 (16) | .96 | .97–.110 |
| D | 2 | /30 (4) | .112 | .113–.114 |

Key: place subnets at **block-aligned boundaries**, largest → smallest saves space.

### 2.5 sizing rule of thumb
- Hosts+2 → next power of 2 → block; prefix = 32 − log2(block).
  - 50 → 64 → /26; 25 → 32 → /27; 10 → 16 → /28; 2 → 4 → /30.

### 2.4 Requirements for VLSM
- **Classless routing protocols** (RIPv2, OSPF, EIGRP, BGP, IS-IS) — they carry masks.
  RIPv1 (classful/IPv4-only) **cannot** run VLSM.
- Also: discontiguous subnets need protocol that understands; summarization when possible.

### 2.5 VLSM + summarization
- Because masks vary, **summarize carefully** — aggregates must not swallow others'
  boundaries (Level 14 Summarization).

## 3. Configuration / Commands

```text
# Configure subnets of differing mask — just use each appropriately
interface Vlan10
 ip address 10.10.0.1 255.255.255.192    # /26 (50-hosts VLAN)
interface Vlan20
 ip address 10.10.0.65 255.255.255.224   # /27
interface Serial0/0
 ip address 10.10.0.113 255.255.255.252  # /30 p2p link
```

---

## 4. Exam Traps

- **Order subnets by size (descending)** — the #1 VLSM planning step.
- **Alignment**: a /27 block must begin on a multiple of 32; /28 on 16; etc.
- **Do not overlap** — the classic VLSM mistake in a give-an-address question.
- **Classful protocols fail VLSM** — RIPv1 answer to "cannot use VLSM."
- **A /30 (4 addrs, 2 usable) is typical for serial/WAN links.**
