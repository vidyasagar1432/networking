# Binary (IPv4)

> **Level 05 · IPv4** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

IPv4 addresses and subnet masks are **binary numbers** underneath the dotted-decimal
notation. Fast binary conversion is the core skill for subnetting, summarization, and
wildcard masks.

---

## 2. Core Concepts

### 2.1 Bit weights (the table to memorize)

| Bit pos | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|---------|---|---|---|---|---|---|---|---|
| Weight | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |

An octet = sum of weights where bit=1.
```
10100000 = 128 + 32 = 160
11111111 = 255
```

### 2.2 Conversion techniques
**Binary → decimal:** add weights of `1` bits.
**Decimal → binary:** subtract largest weights, mark `1` (else `0`).

| Decimal | Binary |
|---------|--------|
| 192 | 11000000 |
| 224 | 11100000 |
| 240 | 11110000 |
| 248 | 11111000 |
| 252 | 11111100 |
| 254 | 11111110 |
| 255 | 11111111 |

### 2.3 Octet boundaries & prefix lengths

| Prefix | Mask | Binary |
|--------|------|--------|
| /24 | 255.255.255.0 | 11111111.11111111.11111111.00000000 |
| /25 | 255.255.255.128 | ...11111111.10000000 |
| /26 | 255.255.255.192 | ...11111111.11000000 |
| /27 | 255.255.255.224 | ...11111111.11100000 |
| /28 | 255.255.255.240 | ...11111111.11110000 |
| /29 | 255.255.255.248 | ...11111111.11111000 |
| /30 | 255.255.255.252 | ...11111111.11111100 |
| /31 | 255.255.255.254 | ...11111111.11111110 |

The number of `1` bits = prefix length. Host bits = 32 − prefix.

### 2.4 The magic-number approach
- The **increment** between subnet network addresses = **256 − mask octet** (in the
  octet where the mask is not 255).
  - /26 → block 64; /28 → block 16; /30 → block 4.
- Network addresses are multiples of that increment.

### 2.5 AND operation (network derivation)
- **Network address = IP AND mask** (bitwise AND). Host bits forced to 0.
```
IP    192.168.1.130 = 11000000 10101000 00000001 10000010
Mask  255.255.255.192 = 11111111 11111111 11111111 11000000
AND   network = 192.168.1.128 /26
```

## 4. Exam Traps

- **Every subnet question is binary arithmetic**; a leading-zero or off-by-one block
  bites more than any other type.
- **Bit weights reversed**: LSB (bit0) = 1, not 128 — a common mental slip.
- **/31 and /32** rules:
  - **/31 (255.255.255.254)**: allowed on **point-to-point** links (RFC 3021) — no
    network/broadcast for link ends.
  - **/32**: single host (loopback / host routes).
- **Don't forget the wildcard** = inverse mask (`255.255.255.0` → wildcard `0.0.0.255`).
- **Increment = 256 − non-255 octet**, NOT the /x number.
