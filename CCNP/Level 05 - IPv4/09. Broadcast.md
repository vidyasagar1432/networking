# Broadcast (IPv4)

> **Level 05 · IPv4** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **broadcast** targets **all hosts in a broadcast domain** (a subnet/VLAN). There are
two kinds in IPv4: the **directed (subnet) broadcast** (`network`'s last host = all 1s)
and the **limited broadcast** `255.255.255.255` (only within the local segment).

---

## 2. Core Concepts

### 2.1 The two broadcast forms

| Kind | Address | Scope | When used |
|------|---------|-------|-----------|
| **Directed broadcast** | host bits all 1 within a subnet (e.g., `10.1.1.255/24`) | that subnet only | historically DHCP to a segment; now mostly blocked |
| **Limited broadcast** | `255.255.255.255` | local segment only | neighbor discovery, emergency |

### 2.2 Frame vs broadcast domain (ties to Level 04)
- IPv4 broadcasts map to Ethernet **broadcast** dest `FF:FF:FF:FF:FF:FF` and stay
  inside the **L2 broadcast domain** (same VLAN).
- Routers do **not forward broadcasts** across subnets by default (that's what makes
  each subnet a broadcast boundary). Except: DHCP relay agents convert to unicast.

### 2.3 Which applications broadcast
- **ARP requests** ("who has 10.1.1.99?") — IPv4 only; IPv6 uses ND (Level 06).
- **DHCP Discover/Offer/Request/Ack** at boot.
- Legacy: RARP, NetBIOS name resolution, some routing (RIPv1/v2 periodic).
- **Directed broadcast abuse**: "smurf" attacks — ICMP to a directed broadcast → now
  **disabled by default** on Cisco (`no ip directed-broadcast`).

### 2.4 Address derivation
Given `A.B.C.0/24`, the **directed broadcast = A.B.C.255** (all host bits 1).
For /26 `10.1.10.64`, broadcast = `10.1.10.79` (block of 64, last host).

Usable host range = network+1 → broadcast−1.

### 2.5 Security & control
- **no ip directed-broadcast** — prevents cross-subnet broadcast injection on Cisco.
- **broadcast storms** (switch loop or excessive discoveries) — campaigning via
  storm control, VLAN segmentation (Level 04 Filtering).

## 3. Configuration / Commands

```text
# Disable directed broadcast (default on modern IOS)
interface GigabitEthernet0/1
 no ip directed-broadcast

# See broadcast-related counters
show interfaces | include broadcast

# Protect with storm control (Level 17)
interface Gi0/1
 storm-control broadcast level 20
```

---

## 4. Exam Traps

- **Directed vs limited** — the "255.255.255.255" is ONLY local limit; a subnet's own
  directed (`x.x.x.255`) means that subnet.
- **Broadcasts don't route** — "which address is forwarded by a router?" — none (except relay).
- **ARP = broadcast; 🚫 IPv6** — no ARP in IPv6.
- **Host bits all-1 = broadcast** ties into usable-host −2 math.
- **`no ip directed-broadcast`** appears in security questions.
