# IPv4 Address Structure

> **Level 05 · IPv4** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

An **IPv4 address** is a **32-bit** number that identifies a network interface in the
Internet. It is written as four **octets** in **dotted-decimal notation** (e.g.,
`192.168.1.10`). Every IPv4 address is divided into a **network portion** and a **host
portion** — the boundary is defined by the subnet mask or prefix length.

---

## 2. Core Concepts

### 2.1 32-bit structure
```
11000000 10101000 00000001 00001010   =  192.168.1.10  (32 bits, 4 octets of 8)
```
- 8 bits per octet → value range per octet **0–255**.
- Total address space: **2^32 ≈ 4.3 billion** addresses (exhausted → IPv6).

### 2.2 Dotted-decimal conversion

| Decimal | Binary (8 bits) |
|---------|-----------------|
| 0 | 00000000 |
| 128 | 10000000 |
| 255 | 11111111 |
| 192 | 11000000 |
| 168 | 10101000 |

To get from binary → decimal: 128,64,32,16,8,4,2,1 (sum where bit = 1).

### 2.3 Network vs host portion
- **Without a mask, an IP alone cannot be routed.** The mask/prefix tells which bits
  are network and which are host.
- e.g., `192.168.10.5/24` → network bits 24 (`192.168.10`), host bits 8 (`5`).

### 2.4 Key values derived from an address+mask

| Value | Definition |
|-------|-----------|
| **Network address** | all host bits = 0 (e.g., `.0`) |
| **Broadcast address** | all host bits = 1 (e.g., `.255` / `10.1.1.255`) |
| **Usable hosts** | 2^h − 2 (minus network + broadcast) |
| **First usable** | network + 1 |
| **Last usable** | broadcast − 1 |

### 2.5 Special uses of the same structure

| Address | Function |
|---------|----------|
| 0.0.0.0/0 | default route / "any" wildcard |
| 127.0.0.0/8 | loopback (see Loopback note) |
| 169.254.0.0/16 | APIPA self-config (see APIPA note) |
| 255.255.255.255 | local L2 broadcast |
| multicast 224.0.0.0/4 | group addresses |

## 3. Configuration / Commands

```text
interface GigabitEthernet0/1
 ip address 192.168.1.1 255.255.255.0   # IP + mask
# or with prefix notation:
ip address 192.168.1.1/24   (NGFW syntax)

show ip interface brief
show run interface Gi0/1
```

---

## 4. Exam Traps

- **One IP = one interface**, not one device (multihomed devices have several).
- **Dotted-decimal is 0–255 per octet** — a 256 in any octet = invalid.
- **All-zeros/all-ones host bits** are reserved (network/broadcast) — exam loves the
  "usable range" calculation.
- **The mask is required** to define network/host boundary — shown in CIDR (`/24`) or mask.
- **32-bit total**: v4 exhausted → why IPv6 (128-bit).
