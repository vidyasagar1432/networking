# Network Types (LAN, WAN, MAN, PAN, WLAN, SAN, VPN)

> **Level 00 · Level 00 - Networking Basics** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

Networks are classified by **geographic scope** (PAN → LAN → MAN → WAN), by
**transmission medium** (WLAN, SAN), or by **who controls them and how connectivity
is provided** (VPN). A single enterprise uses almost all of these at once: a WLAN for
users, a LAN in each office, a WAN linking offices, and VPNs for remote access.

---

## 2. Core Concepts

### 2.1 By geographic scope

| Type | Symbol | Scope | Example |
|------|--------|-------|---------|
| Personal Area Network | **PAN** | ~1–10 m, one person | Bluetooth, USB, IR, UWB |
| Local Area Network | **LAN** | Building/campus, high speed, low latency | Office Ethernet switches |
| Metropolitan Area Network | **MAN** | City-scale (km–tens of km) | City fiber ring, Metro Ethernet |
| Wide Area Network | **WAN** | Intercity/global (carrier-provided) | MPLS, leased line, SD-WAN, Internet backbone |

**LAN characteristics**
- Owner-operated equipment, high bandwidth (Gbps), low latency, options bounded but
  arbitrary (up to ~100 m/single link, campus scale with fiber).
- Switched Ethernet is the dominant LAN technology.

**WAN characteristics**
- Leased from service providers; lower per-unit bandwidth, higher latency, more cost.
- Technologies: MPLS, dedicated circuits (T1/E1, dark fiber), broadband (DSL/cable),
  cellular (LTE/5G), and modern SD-WAN overlay.
- SLA (availability, delay, jitter, loss) matters — see [[Level 23 - Enterprise WAN]].

### 2.2 Wireless LAN (WLAN)
- LAN that uses radio waves (RF) instead of cabling.
- IEEE **802.11** family; standard Wi-Fi: 2.4 GHz / 5 GHz / 6 GHz bands.
- Access points (APs) + Wireless LAN Controllers (WLC) centralize management.
- Compared to wired LAN: more convenience/mobility, more RF interference, shared medium,
  security exposure (see [[Level 22 - Wireless]]).

### 2.3 Storage Area Network (SAN)
- Dedicated, high-speed network connecting servers to block-level storage arrays.
- Often **Fibre Channel** (FC, dedicated fabric) or **iSCSI / FCoE** over Ethernet.
- Optimized for throughput, low latency, reliability; separate from the user/data LAN.
- Related: NAS (file-level, over regular LAN), converged (FCoE) and hyper-converged designs.

### 2.4 Virtual Private Network (VPN)
- A logical, encrypted tunnel *over* an existing network (often the Internet or MPLS).
- **Site-to-site** — connects two branch/office networks (IPsec, DMVPN).
- **Remote access** — individual user/device to the enterprise (SSL/IPsec VPN).
- Provides: confidentiality (encryption), integrity, authentication, and private
  addressing overlay without owning physical links (see [[Level 18 - VPN Technologies]]).

### 2.5 Comparison checklist
- Cost increases: PAN < LAN < MAN < WAN.
- Speed/latency degrade as geographic scope grows.
- Control decreases as scope grows (carrier owns WAN).
- WLAN trades performance/security for mobility; SAN trades generality for storage QoS.
- VPN trades some performance for privacy and lower cost vs dedicated WAN circuits.

## 3. Configuration / Commands

Conceptual topic; however, per-type lab hints:

```text
# LAN (VLAN on switch)
switch(config)# vlan 10
switch(config-vlan)# name Users

# WLAN (controller-based, conceptual)
wlan-config Users
ssid CORP
radio-type 5GHz

# Site-to-site IPsec (branch side, conceptual)
crypto isakmp policy 10
crypto ipsec transform-set TS esp-aes esp-sha-hmac
```

## 4. Exam Traps

- **Scope vs ownership:** A WAN is "across a metro/country" — but a VPN for two buildings
  in the same city is still a VPN regardless of distance; don't confuse the two axes.
- **WLAN is not a separate topology** — it is a *transmission* classification (RF).
- **SAN vs NAS:** SAN = block level over a dedicated network; NAS = file level over the
  regular LAN/IP. Frequently tested.
- **MAN** is rarely asked for configuration; know the two example technologies
  (Metro Ethernet, ring networks).
- **Don't say "the Internet is a WAN."** The Internet is a network of networks; a WAN is
  one type of network (example: an ISP's backbone is a WAN).
