# Network Components

> **Level 00 · Level 00 - Networking Basics** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

Enterprise networks are built from a small set of hardware roles. Categorizing devices
by their function — **end device / intermediary** — and by **plane** (data / control /
management) is the key mental model for the whole course.

---

## 2. Core Concepts

### 2.1 End devices (hosts)
- PCs, laptops, phones, tablets, cameras, IoT, printers, servers.
- Originate and consume traffic; have at least a MAC (L2) and typically an IP (L3) identity.

### 2.2 Intermediary devices (forwarding)

| Device | Layer | What it does |
|--------|-------|--------------|
| Hub (legacy) | L1 | Regenerates signal to all ports — one collision domain; avoid |
| Switch | L2/L3 | Forwards frames by MAC (CAM), creates VLANs, microsegmentation; L3 switches route VLANs |
| Router | L3 | Path selection by IP (routing table), interconnects networks, NAT/filtering |
| Wireless AP | L2 | Bridges 802.11 RF frames onto the wired LAN (BSSID association) |
| Firewall | L3–L7 (stateful) | Policy enforcement, tracking sessions, NAT, VPN/IPS capability |
| Load balancer | L4–L7 | Distributes flows across a server farm; health checks |
| WAN edge / CPE | L1–L3 | Terminates WAN circuits; SD-WAN edge routers • [[Level 23 - Enterprise WAN]] |
| WLC (Wireless LAN Controller) | Mgmt/Ctrl | Centralizes AP config, RF management, roaming • [[Level 22 - Wireless]] |

### 2.3 Control, data, and management planes (key ENCOR concept)
- **Data plane** — the actual forwarding path for user packets (frames/packets).
  Runs on ASICs/TCAM; performance is measured in pps/fib.
  (Switching fabric, TCAM/MAC table, FIB.)
- **Control plane** — decides *how* to forward: builds routing/forwarding tables,
  runs routing protocols (OSPF/EIGRP/BGP), ARP/ND, STP.
- **Management plane** — how we administer the box: SSH/Telnet, SNMP, syslog,
  NTP, NetFlow export, SDN controller connectivity (RESTCONF/NETCONF).

### 2.4 Physical media
- **Copper (UTP/STP)** — cheap, short (≤100 m), susceptible to EMI; PoE capable.
- **Fiber** — single-mode (long haul, laser), multimode (short, LED/VCSEL); immune to EMI.
  (**[[Level 01 - Physical Layer]]**)
- **Wireless (RF)** — mobility, but shared medium and interference.

### 2.5 Attached infrastructure services
- **Servers & storage** — data center north-south flows, server farm VLANs.
- **Security appliances** — IDS/IPS, email/web security, AAA server (RADIUS/TACACS+).
- **Monitoring** — NMS/via, NetFlow collector, syslog server; see Level 26.
- **Redundant power** — UPS, redundant PSUs (High Availability, Level 27).

## 3. Configuration / Commands

```text
# Identify a device's identity
show version              # IOS version, model, uptime
show ip interface brief   # L3 interfaces and state
show interfaces           # per-interface stats, errors, duplex

# Basic memory/conceptual commands
show ip route             # control-plane output (RIB)
show ip cef               # data-plane input (FIB/CEF)

# Management-plane access
line vty 0 4
 transport input ssh
 ssh version 2
```

## 4. Exam Traps

- **Hubs = L1, switches = L2(+L3), routers = L3, firewalls = stateful L4–L7.**
- **"Ambiguous device" questions:** L3 switch IS a router for VLANs but not a WAN router
  (no NAT/security focus); SD-WAN edge is WAN CPE, not just a LAN switch.
- **Plane classification traps:** STP and OSPF both belong to the **control plane**;
  forwarding decisions made in ASIC belong to the **data plane**; SSH/SNMP belong to the
  **management plane**.
- **PoE** devices (switches power APs/IP phones) — recall power into copper pairs — useful
  as a "which switch should I buy" scenario.
- **Firewall vs router:** a router forwards to connect networks; a firewall is a security
  policy enforcement point (stateful filter). Both can do NAT — know which is typical where.
