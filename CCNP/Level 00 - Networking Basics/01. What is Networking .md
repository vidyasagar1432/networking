# What is Networking?

> **Level 00 · Level 00 - Networking Basics** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

Networking is the practice of connecting two or more computing devices so they can
exchange data, share resources, and communicate. A network is defined not by the
number of devices but by the ability to transmit and receive information between
endpoints using agreed-upon standards and protocols.

**Key idea:** Networking enables resource sharing (files, printers, compute, storage)
and communication (email, voice, video, web) between endpoints regardless of their
physical location.

---

## 2. Core Concepts

### 2.1 What a network needs
- **Endpoints / hosts** — devices that originate or consume traffic (PCs, servers, phones, IoT).
- **Transmission media** — cables (copper, fiber) or RF (wireless) that carry signals.
- **Intermediary devices** — switches, routers, firewalls, APs that move/secure the data.
- **Protocols** — agreed rules for how data is formatted, addressed, and delivered
  (TCP/IP, Ethernet, etc.).
- **Addressing** — identifiers such as MAC and IP addresses that let data reach its destination.

### 2.2 What networking must solve
- **Connecting** heterogeneous devices that use different media and standards.
- **Addressing & naming** so packets find the right destination.
- **Path determination / routing** across possibly many intermediate networks.
- **Reliability & error recovery** (retransmission of lost or corrupted data).
- **Security** — control access and protect data in transit and at rest.
- **Management & monitoring** — visibility and operational control.

### 2.3 Data movement is layered
All of these problems are solved together by layering (see [[03. OSI Model]]).
Each layer has a specific job and hands work to the layer below/above via
encapsulation — adding headers/trailers as data travels down, removing them as it
travels up at the receiver.

### 2.4 Direction of communication
- **Simplex** — one direction only (e.g., broadcast TV, legacy one-way sensors).
- **Half-duplex** — either direction, but not simultaneously (e.g., walkie-talkies, old hubs).
- **Full-duplex** — both directions simultaneously (modern switched Ethernet, fiber).

## 3. Configuration / Commands

No direct CLI configuration — this topic is conceptual. Lab entry point:

```text
# On a host/PC
ipconfig /all            # Windows — view IP, MAC, default gateway
ip addr                 # Linux/macOS alternative
ping <destination>      # verify connectivity
traceroute <dest>       # see the path packets take

# On Cisco IOS
enable
configure terminal
hostname R1
```

## 4. Exam Traps

- **"Network" ≠ "Internet."** The Internet is a network of networks interconnected
  by routing and peering.
- **A network can be 2 devices.** Size is not part of the definition.
- **Half-duplex vs full-duplex** are frequently tested; modern Ethernet is
  full-duplex, hub-based (legacy) Ethernet is half-duplex.
- **Collision vs broadcast domain confusion** — those are covered in
  [[08. Broadcast Domains]] / [[09. Collision Domains]] later in this path.
- ENCOR focus: understanding the *architectural* purpose of networking (fast,
  predictable, secure, scalable) rather than memorizing trivia.
