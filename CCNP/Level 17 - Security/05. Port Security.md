# Port Security

> **Level 17 · Security** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Port security** limits a switchport to a fixed set of **MAC addresses**. It blocks
device spoofing and MAC-flooding attacks at the access layer. The exam checks the three
**violation modes**, **sticky learning**, and the **aging/limit** mechanics.

---

## 2. Core Concepts

### 2.1 What it guards

| Attack | Mitigation |
|--------|-----------|
| MAC flooding | max-mac limit |
| CAM table poisoning | limit + sticky |
| Device substitution | fixed allowed MACs |

- Applies on **access ports** (not trunks).

### 2.2 Configuration

```text
interface Gi0/1
 switchport mode access
 switchport port-security
 switchport port-security maximum 2
 switchport port-security mac-address sticky
 switchport port-security violation shutdown
 switchport port-security aging time 5
```

### 2.3 Key parameters

| Parameter | Meaning |
|-----------|---------|
| `maximum N` | max secure MACs (default 1) |
| `mac-address aaaa.bbbb.cccc` | static MAC |
| `mac-address sticky` | learn + save to running config |
| `aging time X` | MAC aging |
| `violation` | action on exceed |

- **Sticky** = dynamically learned MACs that persist (as if static).

### 2.4 Violation modes

| Mode | Effect on port |
|------|----------------|
| **shutdown** (default) | error-disabled, needs manual/admin recovery |
| restrict | drops offending frames, logs |
| protect | silently drops offending frames (no log) |

- **Shutdown** is default and most severe; **protect** is silent.

### 2.5 Auto-recovery

```text
errdisable recovery cause psecure-violation
errdisable recovery interval 60
```

- Error-disabled ports recover after the interval (or manually `shutdown/no shutdown`).

### 2.6 Verification

```text
show port-security
show port-security interface Gi0/1
show port-security address
show errdisable recovery
```

- `show port-security` reveals violations, mode, and secured addresses.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Port error-disabled | violation | show port-security |
| Too many MACs | maximum too low | raise max |
| Sticky not saved | no write mem | save config |
| Ports stay down | no recovery | errdisable recovery |
| Trusted device blocked | stale MAC | clear dynamic |

---

## 5. Exam Traps

- Default `maximum 1`, default violation = **shutdown**.
- **Sticky** MACs persist across reloads once saved.
- **shutdown > restrict > protect** severity order.
- Access ports only — not trunk ports.
- `errdisable recovery` + `psecure-violation` automates recovery.
