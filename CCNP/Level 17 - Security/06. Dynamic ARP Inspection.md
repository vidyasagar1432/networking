# Dynamic ARP Inspection (DAI)

> **Level 17 · Security** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**DAI** validates ARP packets against a **trusted source of truth** — the **DHCP
snooping binding table** (plus static ARP ACLs). It blocks **ARP spoofing/poisoning**
by dropping ARP replies whose IP/MAC pair is not the trusted binding. DAI needs DHCP
**snooping** enabled (note 16·02) to have a binding table.

---

## 2. Core Concepts

### 2.1 The threat: ARP poisoning

- Attacker replies to every ARP request claiming the gateway IP → traffic hijacked.
- DAI stops that by validating **IP→MAC** against the snooping table.

### 2.2 Trusted vs untrusted ports

| Port | Validates? |
|------|-----------|
| Trusted | no validation (uplink/router side) |
| Untrusted | every ARP checked |

- Default **untrusted**; trust only the link toward real gateways/routers.

### 2.3 Configuration

```text
ip dhcp snooping
ip dhcp snooping vlan 10
!
ip arp inspection vlan 10
interface Gi0/1
 ip arp inspection trust
```

- Enable **snooping first**, then DAI on the VLAN.
- Mark router/uplink ports trusted.

### 2.4 Validation checks

| Check | What it verifies |
|-------|------------------|
| src-MAC | ARP sender MAC matches binding |
| dst-MAC | destination MAC sane |
| IP address | sender IP in binding / ACL |
| ARP ACL | static entries for non-DHCP hosts |

- Both MAC and IP fields validated against the table.

### 2.5 Static entries (non-DHCP hosts)

```text
arp access-list STATIC-ARP
 permit ip host 10.0.0.10 mac host aaaa.bbbb.cccc
ip arp inspection filter STATIC-ARP vlan 10
```

- Servers with static IPs need an **ARP ACL** or they're dropped.

### 2.6 Rate limiting & verification

```text
ip arp inspection limit rate 15 burst interval 1
show ip arp inspection
show ip arp inspection statistics
debug ip arp inspection
```

- Rate-limit ARP floods; statistics show dropped packets.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Legit ARP dropped | no binding (static host) | ARP ACL |
| Gateways unreachable | uplink untrusted | ip arp inspection trust |
| Storms | limit too low | rate limit |
| No protection | snooping off | enable snooping |
| Intermittent | table aging | snooping bindings |

---

## 5. Exam Traps

- DAI **depends on DHCP snooping** for its binding table.
- Trusted ports skip validation — trust the **uplink/router**, not hosts.
- Static-IP hosts need an **ARP ACL**.
- DAI validates **both IP and MAC**.
- Rate-limit ARP to stop flooding.
