# IP Source Guard (IPSG)

> **Level 17 · Security** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**IP Source Guard** prevents a host from **spoofing its source IP**. It builds a
**per-port allowlist** of source IPs (and MACs) from the **DHCP snooping binding table**
and filters every frame against it — any packet with a source IP not on the list is
dropped on the spot.

---

## 2. Core Concepts

### 2.1 How it works

- Requires **DHCP snooping** (note 16·02) to populate the binding table.
- Each untrusted port gets a **port ACL (PACL)** with allowed source IPs.
- Non-matching source IPs → dropped.

### 2.2 Trusted vs untrusted

| Port | IPSG? |
|------|-------|
| Trusted | bypassed (router/uplink) |
| Untrusted | source-filtered |

- Trust the switch/router links; hosts stay untrusted.

### 2.3 Configuration

```text
ip dhcp snooping
ip dhcp snooping vlan 10
!
interface Gi0/1
 switchport mode access
 ip verify source port-security     ! bind IP (and MAC) via snooping
```

- `ip verify source` = IP check; `port-security` keyword also validates **MAC**.
- Without `port-security`, only the source **IP** is checked.

### 2.4 Static entries (non-DHCP hosts)

```text
ip source binding aaaa.bbbb.cccc vlan 10 10.0.0.10 interface Gi0/1
```

- Add manual bindings for servers/devices that don't use DHCP.

### 2.5 IPSG vs DAI vs Port Security

| Feature | IPSG | DAI (06) | Port Sec (05) |
|---------|------|----------|---------------|
| Stops | IP spoofing | ARP spoofing | MAC flooding |
| Checks | src IP/MAC | ARP IP↔MAC | MAC count |
| Uses | snooping table | snooping table | own table |

- They stack on the same access port — defense in depth.

### 2.6 Verification

```text
show ip verify source
show ip source binding
show ip dhcp snooping binding
debug ip verify source
```

- `show ip verify source` shows the per-port allowed sources.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Host dropped | not in binding (static IP) | ip source binding |
| No filter | snooping off | enable snooping |
| Uplink breaks | uplink untrusted | trust the uplink |
| Port flap | verify source + dynamic | binding expiry |
| Dual stack | IPv6 source guard | ipv6 verify source |

---

## 5. Exam Traps

- IPSG **needs DHCP snooping** for bindings.
- `ip verify source` = IP only; **add `port-security`** for MAC check.
- Trusted ports skip filtering.
- Static-IP hosts need **manual `ip source binding`**.
- Blocks **spoofed source IPs** — the layer-3 analog of DAI.
