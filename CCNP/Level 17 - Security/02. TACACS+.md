# TACACS+

> **Level 17 · Security** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**TACACS+** is the **Cisco-proprietary** AAA protocol (TCP 49) for **device
administration**. Its strengths: **full encryption** (entire packet), **per-command
authorization**, and separation of the three A's. When the exam asks "device admin AAA",
the answer is TACACS+.

---

## 2. Core Concepts

### 2.1 Transport and encryption

| Item | TACACS+ |
|------|---------|
| Port | TCP 49 |
| Encryption | whole packet (payload + header) |
| Auth separate | yes |
| Authz per-command | yes |

- Shared secret encrypts everything — no packet content leaks.

### 2.2 TACACS+ vs RADIUS (the exam table)

| Aspect | TACACS+ | RADIUS |
|--------|---------|--------|
| Vendor | Cisco | open standard |
| Port | TCP 49 | UDP 1812/1813 |
| Encryption | full packet | password only |
| Authz | per-command | coarse |
| Protocol support | device admin | network access |
| Transport | TCP (reliable) | UDP |

- **Device admin → TACACS+**; **network access (wireless/VPN) → RADIUS**.

### 2.3 Server + AAA config

```text
tacacs server T1
 address ipv4 10.0.0.5
 key SharedSecret
!
aaa new-model
aaa authentication login DEFAULT group tacacs+ local
aaa authorization exec DEFAULT group tacacs+ local
aaa authorization commands 15 DEFAULT group tacacs+ local
aaa accounting exec DEFAULT start-stop group tacacs+
```

- The **key** must match on server and device.

### 2.4 Authorization granularity

| Level | What's authorized |
|-------|-------------------|
| exec | entering shell / enable |
| commands N | specific commands at privilege N |
| network | line/network access (rare for device mgmt) |

- Per-command authorization is TACACS+'s killer feature.

### 2.5 Accounting records

| Type | Records |
|------|---------|
| exec | start/stop of sessions |
| commands N | every command typed |
| connection | outbound connections |

- Command accounting = full audit trail for security ops.

### 2.6 When to use local fallback

```text
aaa authentication login DEFAULT group tacacs+ local
```

- `local` (or `none`) is the fallback when the TACACS+ server is unreachable —
  otherwise lockouts happen.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Auth fail | shared secret mismatch | show tacacs / key |
| Timeout | TCP 49 blocked | reachability |
| Commands denied | authorization missing on line | line aaa config |
| No accounting | list not applied | accounting command |
| Login lockout | no fallback | add local to list |

---

## 5. Exam Traps

- **TACACS+ = TCP 49**, **Cisco-proprietary**, **device admin**.
- **Encrypts the entire packet** — unlike RADIUS (password only).
- **Per-command authorization** — the differentiator.
- RADIUS = UDP, network access; TACACS+ = TCP, device mgmt.
- Secret key must match both ends.
