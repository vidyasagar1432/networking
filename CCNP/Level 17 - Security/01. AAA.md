# AAA

> **Level 17 · Security** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**AAA** = **Authentication** (who), **Authorization** (what can they do), **Accounting**
(what did they do). Centralizing AAA on a server (TACACS+ / RADIUS) beats local configs
for scale, auditing, and policy. Cisco IOS combines three blocks: `aaa new-model`,
**method lists**, and **AAA commands** per service.

---

## 2. Core Concepts

### 2.1 The three A's

| A | Meaning | Example |
|---|---------|---------|
| Authentication | prove identity | login via TACACS+ |
| Authorization | grant/limit commands | privilege 15 only |
| Accounting | log the action | start/stop records |

- Accounting is **audit + billing**; it doesn't gate anything.

### 2.2 `aaa new-model` — the gateway

```text
aaa new-model
```

- Enabling it activates AAA and **changes login behavior**: local fallback must be
  re-declared or all VTY logins are denied.

### 2.3 Method lists

```text
aaa authentication login DEFAULT group tacacs+ local
aaa authorization commands 15 DEFAULT group tacacs+ local
aaa accounting exec DEFAULT start-stop group tacacs+
```

| Element | Meaning |
|---------|---------|
| Service | authentication / authorization / accounting |
| Type | login, exec, commands N, network |
| List name | DEFAULT or named |
| Methods | group server / local / none / line |

- **First method wins**; later ones are fallbacks on failure.
- `group tacacs+` / `group radius` reference the server group.

### 2.4 Applying lists

```text
line vty 0 15
 login authentication DEFAULT
 authorization commands 15 DEFAULT
 accounting exec DEFAULT
```

- Lists are **referenced on lines or services**; DEFAULT applies when none is named.

### 2.5 Server groups

```text
aaa group server tacacs+ TGROUP
 server 10.0.0.5
aaa authentication login TACACS-ONLY group TGROUP
```

- Named groups allow distinct servers per service.

### 2.6 AAA vs local-only

| Aspect | Local | AAA |
|--------|-------|-----|
| Users | on-device | central server |
| Audit | none | accounting |
| Scale | poor | good |
| Change mgmt | per-device | one place |

- Exam: AAA for enterprise; local as fallback (`local` in the list).

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Login refused | no local fallback after new-model | method list |
| Auth timeout | server unreachable | reachability |
| Commands denied | authorization missing | commands N list |
| No logs | accounting not applied | exec/commands list |
| Wrong server | group misconfigured | aaa group server |

---

## 5. Exam Traps

- **`aaa new-model` turns off implicit local login** — the classic lockout trap.
- Method lists: first match wins, rest are fallback.
- `commands N` authorizes per **privilege level**.
- Accounting uses **start/stop** records.
- AAA supersedes line `password`/`login local` only after new-model + list.
