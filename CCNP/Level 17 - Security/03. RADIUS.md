# RADIUS

> **Level 17 · Security** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**RADIUS** is the **open-standard** AAA protocol used for **network access** — wireless,
VPN, 802.1X, and dial-up. It runs over **UDP (1812 auth, 1813 accounting)**, encrypts
**only the password**, and does **coarse authorization** (attribute-based). When the exam
asks "wireless/VPN/802.1X authentication", the answer is RADIUS.

---

## 2. Core Concepts

### 2.1 Transport and encryption

| Item | RADIUS |
|------|--------|
| Ports | UDP 1812 (auth), 1813 (acct) |
| Encryption | password only (plus shared secret) |
| Authz | attributes / coarse |
| Reliable? | no (UDP) — client retransmits |

- Attribute-value pairs (AVPs) carry user policy.

### 2.2 RADIUS vs TACACS+

| Aspect | RADIUS | TACACS+ (note 02) |
|--------|--------|-------------------|
| Standard | open | Cisco |
| Port | UDP 1812/1813 | TCP 49 |
| Encryption | password only | full packet |
| Authz | attributes | per-command |
| Use | network access | device admin |
| Transport | UDP | TCP |

- The division: **RADIUS = access**, **TACACS+ = admin**.

### 2.3 RADIUS roles

| Role | Function |
|------|----------|
| Client (NAS) | network device requesting auth |
| Server | validates, returns accept/reject |
| Proxy | forwards between realms |

- The NAS (AP/switch/firewall) is the RADIUS **client**.

### 2.4 Configuration

```text
radius server R1
 address ipv4 10.0.0.5 auth-port 1812 acct-port 1813
 key SharedSecret
!
aaa new-model
aaa authentication login DEFAULT group radius local
aaa accounting network DEFAULT start-stop group radius
```

- Match `auth-port`/`acct-port` and the shared **key** on both ends.

### 2.5 Key protocol use cases

| Use case | Why RADIUS |
|----------|------------|
| 802.1X port auth | EAP exchange via RADIUS |
| WPA2-Enterprise | 802.1X/EAP-TLS |
| VPN (IPsec) auth | user auth via RADIUS |
| Posture/policy | AVPs return VLAN/ACL |

- RADIUS carries **EAP** transparently between supplicant and server.

### 2.6 Failover and fallback

```text
aaa authentication login DEFAULT group radius local
```

- Multiple RADIUS servers = failover order.
- `local`/`none` fallback prevents lockout when RADIUS is down.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Auth fails | secret mismatch | show radius / key |
| Timeout | UDP 1812 blocked | reachability |
| Wireless reject | EAP/AVP misconfig | debug radius |
| No accounting | acct-port / list | accounting config |
| Wrong attribute | vendor-attr | server policy |

---

## 5. Exam Traps

- **RADIUS = UDP 1812/1813**; encrypts **password only**.
- **Network access** AAA (not device admin).
- RADIUS is the **NAS → server** model; devices are the clients.
- EAP rides RADIUS for 802.1X/WPA2-Enterprise.
- TACACS+ is the admin-side Cisco alternative.
