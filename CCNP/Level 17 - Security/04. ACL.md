# ACLs (Access Control Lists)

> **Level 17 · Security** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**ACLs** filter packets by matching **source/dest IP, protocol, and ports** in a
**first-match-wins, implicit-deny** list. They gate traffic **in/out on interfaces** and
also drive NAT, route-maps, QoS, and management access. The exam stresses **wildcard
masks**, **standard vs extended**, and the implicit deny.

---

## 2. Core Concepts

### 2.1 Standard vs extended

| Type | Matches | Range |
|------|---------|-------|
| Standard | **source IP only** | 1–99, 1300–1999 |
| Extended | src+dst+proto+port | 100–199, 2000–2699 |

- Extended ACLs are applied **closest to the source** (they specify everything).
- Standard ACLs applied **closest to the destination**.

### 2.2 Wildcard masks

| ACL notation | Equivalent |
|--------------|------------|
| `0.0.0.255` | /24 host range |
| `0.0.255.255` | /16 |
| `0.0.0.0` | exact host |
| `255.255.255.255` | any |

- **1 = ignore that bit, 0 = must match** — the wildcard logic.

### 2.3 Entry evaluation

| Rule | Detail |
|------|--------|
| First match wins | stop at first permit/deny |
| Implicit deny | nothing matches at the end |
| Order matters | best-specific first |

- Put **specifics first**, general last.

### 2.4 Extended ACL example

```text
access-list 101 permit tcp any host 10.0.0.5 eq 443
access-list 101 deny ip any any

interface Gi0/0
 ip access-group 101 in
```

| Command | Effect |
|---------|--------|
| `ip access-group X in` | filter inbound |
| `ip access-group X out` | filter outbound |
| `eq/gt/lt/range` | port operators |

### 2.5 Named ACLs (recommended)

```text
ip access-list extended MGMT-IN
 permit tcp 10.0.0.0 0.0.0.255 host 192.0.2.1 eq 22
 deny ip any any
```

- Named ACLs allow **editing/resequencing** and clear self-documentation.

### 2.6 Common uses beyond filtering

| Use | Command |
|-----|---------|
| NAT matching | `ip nat inside source list 10` |
| Route-map match | `match ip address ACL` |
| VTY restriction | `access-class ACL in` |
| QoS classification | `match access-group` |
| CoPP (note 09) | control-plane ACL |

- An ACL is the reusable **match primitive** across IOS features.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Traffic blocked | implicit deny / wrong order | show access-lists counters |
| Too permissive | broad permit first | order |
| Wrong direction | in vs out | access-group |
| NAT no match | ACL too narrow | counters |
| Unreachable mgmt | standard ACL far from src | placement |

---

## 5. Exam Traps

- **Implicit deny** at the end — the #1 surprise.
- Wildcard: **0 = match, 1 = ignore**.
- Standard = source only, applied near destination; extended applied near source.
- `eq`/`range` operators only in **extended** ACLs.
- ACLs are also the match engine for NAT/QoS/route-maps.
