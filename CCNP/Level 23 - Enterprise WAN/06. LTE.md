# LTE (Cellular)

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**LTE/5G cellular** is a wireless WAN transport — perfect for **primary in rural areas,
backup, or roaming/merchant sites**. It uses **SIM + APN** on a cellular interface, is
**routed via DHCP/static**, and shines as an **SD-WAN transport** (note 07) for
automatic failover. The exam focuses on use cases and the interface model.

---

## 2. Core Concepts

### 2.1 Why LTE

| Benefit | Detail |
|---------|--------|
| Coverage | anywhere with signal |
| Speed | LTE/5G |
| Setup | SIM + APN |
| Mobility | works on the move |
| Cost | per data |

- LTE needs **no fixed wiring** — instant, location-independent.

### 2.2 Use cases

| Use | Detail |
|-----|--------|
| Primary | remote/rural |
| Backup | failover |
| Roaming | moving vehicles |
| SD-WAN | transport |

- The classic role is **backup / SD-WAN transport**.

### 2.3 Interface model

| Item | Detail |
|------|--------|
| Interface | Cellular0/0/0 |
| SIM | subscriber identity |
| APN | provider access point |
| Profile | cellular profile |

- The cellular interface needs an **APN profile** for the carrier.

### 2.4 Config sketch

```text
interface Cellular0/0/0
 ip address negotiated
 cellular profile 1
 no shutdown
!
dialer-list 1 protocol ip permit
```

| Command | Meaning |
|---------|---------|
| `cellular profile` | APN/profile |
| `ip address negotiated` | carrier DHCP |
| `dialer-list` | trigger data |

### 2.5 Characteristics

| Characteristic | LTE |
|----------------|-----|
| Latency | moderate |
| Bandwidth | variable |
| Data caps | yes |
| Predictability | variable |
| Cost | per usage |

- **Metered + variable** — treat as best-effort.

### 2.6 SD-WAN pairing

| Use | Benefit |
|-----|---------|
| SD-WAN | multi-transport |
| Failover | automatic |
| Policy | route by app |

- SD-WAN makes LTE a **seamless automatic fallback**.
