# Broadband

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Broadband** WANs ride **DSL, cable, or fiber** over a shared access network, almost
always with **PPPoE** (note 02) as the session/auth layer. Broadband is cheap and
everywhere, but **asymmetric, shared, and less predictable** than MPLS — so it's the
classic **secondary/DIA link** or SD-WAN transport.

---

## 2. Core Concepts

### 2.1 Broadband types

| Type | Medium | Notes |
|------|--------|-------|
| DSL | phone lines | ADSL/VDSL |
| Cable | coax | shared |
| Fiber | GPON/EPON | high speed |
| Fixed wireless | RF | rural |

- **Fiber = fastest/most symmetric; DSL/cable = asymmetric.**

### 2.2 Characteristics

| Characteristic | Broadband |
|----------------|-----------|
| Asymmetry | down > up |
| Sharing | neighborhood |
| Latency | variable |
| Predictability | low |
| Cost | low |

- Broadband is a **best-effort, shared** service.

### 2.3 Session model

| Layer | Protocol |
|-------|----------|
| Access | DSL/cable/fiber |
| Session | PPPoE |
| Auth | CHAP/RADIUS |
| IP | IPCP/DHCP |

- **PPPoE** provides the per-subscriber session + auth.

### 2.4 Enterprise use

| Role | Detail |
|------|--------|
| Primary | small sites |
| Secondary | backup / DIA |
| SD-WAN | cheap transport |
| QoS | limited |

- Enterprises treat broadband as **secondary or SD-WAN** transport.

### 2.5 Design notes

| Point | Detail |
|-------|--------|
| NAT | CPE often NATs |
| MTU | 1492 PPPoE |
| DIA | local breakout |
| Redundancy | pair with MPLS |

- **MTU 1492 + NAT + backup role** = the broadband playbook.

### 2.6 Verification

```text
show pppoe session
show interface Dialer1
show ip interface brief
ping / traceroute
show nbar ...
```

|---------|--------------|-------|
| No session | PPPoE down | pppoe session |
| Slow | shared/asym | bandwidth |
| MTU issues | 1492 | adjust |
| Drops | contention | latency |
| Failover | secondary | redundancy |

---

## 5. Exam Traps

- Broadband = **DSL/cable/fiber + PPPoE**.
- **Asymmetric, shared, best-effort** — not an SLA link.
- PPPoE → **MTU 1492**.
- Typical role: **backup / DIA / SD-WAN transport**.
- Pair with MPLS for redundancy.
