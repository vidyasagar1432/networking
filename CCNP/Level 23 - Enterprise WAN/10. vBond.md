# vBond

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**vBond** is the **orchestration plane** of Cisco SD-WAN — the first contact point for
new devices. It **authenticates and onboards** edges and controllers, assigns them to
vSmart/vManage, and establishes a **public DTLS/TLS identity** in the network. The exam
tests vBond vs vSmart (control) and vManage (management).

---

## 2. Core Concepts

### 2.1 vBond's role

| Function | Detail |
|----------|--------|
| Orchestration | first contact |
| Authentication | device identity |
| Discovery | hand to vSmart/manage |
| NTP/keys | bootstrap |

- vBond = **the network's front door / authentication broker**.

### 2.2 Onboarding flow

| Step | Detail |
|------|--------|
| 1 | new edge contacts vBond |
| 2 | vBond verifies identity |
| 3 | assigns controllers |
| 4 | edge builds secure sessions |

- Edges **start at vBond**, then talk to vSmart/vManage.

### 2.3 Why reachability matters

| Item | Detail |
|------|--------|
| Public IP | vBond reachable |
| DTLS | secure onboarding |
| DNS | vbond discovery |
| Firewall | 12346 or 443 |

- vBond must be **publicly reachable** (or DNS-reachable) for onboarding.

### 2.4 Identity and security

| Item | Detail |
|------|--------|
| Serial/chassis | device ID |
| Certificates | mutual auth |
| Keys | bootstrap |
| Result | trusted fabric |

- Device **serial + certificate** prove identity to vBond.

### 2.5 The three controllers

| Controller | Plane |
|-----------|-------|
| vBond | orchestration |
| vSmart | control |
| vManage | management |

- **vBond lets devices in; vSmart controls; vManage manages.**

### 2.6 Scale/HA

| Item | Detail |
|------|--------|
| Multiple vBond | redundancy |
| DNS round-robin | load |
| Out-of-band | separate network |

- Run vBond in **HA + reachable DNS** for reliability.

## 5. Exam Traps

- vBond = **orchestration plane + onboarding/auth**.
- Edges **first contact vBond**, then assigned to vSmart/vManage.
- vBond must be **publicly reachable**.
- Identity via **serial + certificates**.
- vBond ≠ vSmart (control) ≠ vManage (management).
