# PPPoE (PPP over Ethernet)

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**PPPoE** carries PPP sessions over Ethernet — the standard for **DSL/broadband**
(note 05). Discovery (PADI/PADO/PADR/PADS) sets up the session, then **LCP/CHAP/IPCP**
run as usual (note 01). The exam tests the discovery messages and the PPPoE config.

---

## 2. Core Concepts

### 2.1 Why PPPoE

| Item | Detail |
|------|--------|
| Medium | Ethernet/DSL |
| Sessions | per-subscriber |
| Auth | PPP CHAP/PAP |
| Addressing | IPCP |

- PPPoE gives broadband the **authentication/addressing** of PPP.

### 2.2 Discovery (PADx)

| Message | Meaning |
|---------|---------|
| PADI | client broadcast |
| PADO | server offer |
| PADR | client requests |
| PADS | session established |

- **PADI → PADO → PADR → PADS** = session creation.
- Session ID issued by the **access concentrator**.

### 2.3 After discovery

| Phase | Protocol |
|-------|----------|
| LCP | link config |
| Auth | CHAP/PAP |
| IPCP | IP addressing |
| Data | PPP frames |

- Once up, it behaves like classic **PPP over a session**.

### 2.4 Config (client side, IOS-XE)

```text
interface Dialer1
 ip address negotiated
 encapsulation ppp
 dialer pool 1
 ppp authentication chap callin
 ppp chap password Secret
!
interface GigabitEthernet0/0
 pppoe enable
 pppoe-client dial-pool-number 1
```

| Command | Meaning |
|---------|---------|
| `Dialer1` | virtual PPPoE session |
| `pppoe-client dial-pool-number` | bind to pool |
| `dialer pool` | link physical |

### 2.5 Access concentrator

| Role | Server |
|------|--------|
| Terminates | PPPoE sessions |
| Authenticates | RADIUS/CHAP |
| Routes | to Internet |

- The **AC** (e.g., BNG) ends the sessions.

### 2.6 Verification

```text
show ip interface dialer
show pppoe session
show interface Dialer1
debug pppoe events
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No session | discovery blocked | show pppoe session |
| Auth fail | secret | debug ppp |
| No IP | IPCP | ip address negotiated |
| Dialer down | pool | dialer pool |
| Slow PPPoE | MTU | mtu 1492 |

- **MTU note**: PPPoE overhead → use **MTU 1492** on the link.

---

## 5. Exam Traps

- Discovery = **PADI → PADO → PADR → PADS**.
- PPPoE = PPP over **Ethernet/DSL**.
- Dialer interface + `pppoe-client dial-pool-number`.
- **MTU 1492** because of the 8-byte PPPoE header.
- Auth rides PPP (CHAP/PAP).
