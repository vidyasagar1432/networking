# WAN Edge

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**WAN Edge** is the SD-WAN term for the routers at each site — **vEdge** (Viptela OS)
or **cEdge** (IOS-XE). They terminate overlay tunnels, run **OMP** with vSmart, forward
data via secure DTLS/IPsec, and enforce app-aware policies. This is where the **data
plane** actually lives.

---

## 2. Core Concepts

### 2.1 WAN edge roles

| Function | Detail |
|----------|--------|
| Tunnel termination | DTLS/IPsec |
| OMP | vSmart control |
| Data forwarding | overlay |
| Local policy | templates |
| Transport | multi-WAN |

- The edge is the **site's SD-WAN gateway**.

### 2.2 vEdge vs cEdge

| Item | vEdge | cEdge |
|------|-------|-------|
| OS | Viptela OS | IOS-XE |
| Platform | vEdge hardware/virtual | Catalyst/ISR |
| Config | SD-WAN CLI | IOS-XE SD-WAN |
| Interop | native | native |

- **cEdge = IOS-XE routers running SD-WAN**; vEdge = Viptela-native.

### 2.3 Transport connections

| Item | Detail |
|------|--------|
| TLOC | transport locator |
| Colors | labels (MPLS/broadband) |
| Multiple | per-site links |
| SLA | path health |

- Each **transport (TLOC + color)** is a potential path.

### 2.4 Control connections

| Session | To |
|---------|----|
| vBond | onboarding |
| vSmart | OMP |
| vManage | management |
| Peers | edge-to-edge tunnels |

- The edge keeps **four session types** with the controllers/peers.

### 2.5 Data plane

| Layer | Detail |
|-------|--------|
| Tunnel | DTLS/IPsec |
| Overlay | OMP routing |
| Policy | app-aware |
| NAT | on/off per transport |

- Data is **encrypted and SLA-routed** between edges.

### 2.6 Config/verification

```text
show sdwan control connections
show sdwan omp peers
show omp routes
show sdwan interface
show sdwan running-config
```

|---------|--------------|-------|

| No OMP | vSmart | omp peers |

| Path fails SLA | transport | omp routes |
| Edge lost | onboarding | history |

## 5. Exam Traps

- WAN Edge = **data plane** (vEdge/cEdge).
- **cEdge = IOS-XE; vEdge = Viptela OS**.
- TLOC + **color** identify transports.
- Sessions: **vBond, vSmart (OMP), vManage, peers**.
- Data tunnels are **DTLS/IPsec**; policy is app-aware.
