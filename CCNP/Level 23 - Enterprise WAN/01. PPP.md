# PPP (Point-to-Point Protocol)

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**PPP** is the classic point-to-point WAN protocol that succeeded HDLC thanks to
**authentication (PAP/CHAP)**, **multilink**, and **negotiation via LCP/NCP**. It is
also the framing PPPoE rides on (note 02). The exam tests the PPP stack and PAP vs CHAP.

---

## 2. Core Concepts

### 2.1 The PPP stack

| Layer | Protocol | Job |
|-------|----------|-----|
| Link control | LCP | setup, options |
| Network control | NCP | IP etc. |
| Authentication | PAP/CHAP | verify peers |
| Data | PPP framing | encapsulated |

- **LCP** opens the link; **NCP** negotiates network layer; auth sits on top.

### 2.2 LCP phases

| Phase | Action |
|-------|--------|
| 1 | link established (LCP) |
| 2 | authentication (PAP/CHAP) |
| 3 | NCP (IPCP) |
| 4 | data phase |

- Link is up only if all phases pass.

### 2.3 PAP vs CHAP

| Aspect | PAP | CHAP |
|--------|-----|------|
| Password | sent clear | hashed challenge |
| Direction | one-way | challenge/response |
| Security | weak | stronger |
| Re-auth | no | periodic |

- **CHAP** challenges and hashes; **PAP** transmits the password in the clear.

### 2.4 PAP/CHAP config

```text
interface Serial0/0/0
 encapsulation ppp
 ppp authentication chap
 ppp chap hostname R1
 ppp chap password Secret
```

| Command | Meaning |
|---------|---------|
| `encapsulation ppp` | enable PPP |
| `ppp authentication chap` | force CHAP |
| `ppp chap password` | shared secret |

### 2.5 Multilink PPP (MLPPP)

| Item | Detail |
|------|--------|
| What | bond multiple links |
| Result | higher bandwidth |
| Control | LCP fragmentation |
| Use | QoS on bundles |

- **MLPPP** combines serial/T1 links into one logical pipe.

### 2.6 Verification

```text
show interface Serial0/0/0
show ppp multilink
debug ppp authentication
debug ppp negotiation
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Link down | LCP fails / no clock | show interface |
| Auth fail | secret mismatch | debug ppp authentication |
| No IPCP | NCP blocked | debug ppp negotiation |
| Wrong LCP | encapsulation | encapsulation ppp |
| PAP mismatch | method | ppp authentication |

---

## 5. Exam Traps

- PPP = **LCP + NCP + PAP/CHAP**.
- **CHAP uses challenge/response** — never sends clear passwords.
- PAP is clear-text → weak.
- `encapsulation ppp` on serial interfaces.
- **MLPPP** bonds links for bandwidth.
