# SD-WAN

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Cisco SD-WAN (Viptela)** builds an **overlay network** over any transport (MPLS,
broadband, LTE) with **secure tunnels (DTLS/IPsec)** between vEdge/cEdge routers. A
**controller cluster** (vManage, vSmart, vBond — notes 08–10) manages policies and
routing centrally. The exam wants the planes and the role of each controller.

---

## 2. Core Concepts

### 2.1 Overlay over any transport

| Layer | Component |
|-------|-----------|
| Underlay | MPLS/broadband/LTE |
| Overlay | secure tunnels |
| Control | OMP (overlay mgmt protocol) |
| Policy | centralized |

- SD-WAN decouples **services from the physical WAN**.

### 2.2 The four components

| Component | Role |
|-----------|------|
| vEdge/cEdge | WAN edge routers |
| vSmart | control + policy |
| vManage | management |
| vBond | orchestration |

- **vBond authenticates/onboards; vSmart controls; vManage manages; edges carry traffic.**

### 2.3 The planes

| Plane | Runs on |
|-------|---------|
| Data | WAN edge |
| Control | vSmart (OMP) |
| Management | vManage |
| Orchestration | vBond |

- **Orchestration (vBond) → control (vSmart) → management (vManage)** = the model.

### 2.4 OMP (overlay management protocol)

| Item | Detail |
|------|--------|
| What | control protocol |
| Runs | edge ↔ vSmart |
| Carries | routes, TLOCs, policies |
| Result | overlay routing |

- **OMP** replaces BGP/IGP in the overlay.

### 2.5 Key features

| Feature | Detail |
|---------|--------|
| Transport independence | any link |
| App-aware routing | SLA-based |
| Security | DTLS/IPsec tunnels |
| Centralized policy | vSmart |
| Analytics | vManage |

- **App-aware routing + SLA** is the SD-WAN killer feature.

### 2.6 Benefits

| Benefit | Detail |
|---------|--------|
| Cost | use cheap broadband |
| Agility | fast site adds |
| Reliability | multi-link failover |
| Visibility | vManage dashboards |

- SD-WAN = **cheaper, more reliable, centrally managed WAN**.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Edge offline | no vBond/vSmart | control connections |
| No routes | OMP down | show omp peers |
| Tunnel issues | DTLS/IPsec | show sdwan control |
| Policy not applied | vSmart | omp routes |
| Slow | underlay | SLA |

---

## 5. Exam Traps

- SD-WAN = **overlay + OMP + centralized controllers**.
- **vBond=orchestrates, vSmart=control/policy, vManage=management**.
- Data plane on **WAN edges** (vEdge/cEdge).
- OMP replaces **BGP/IGP in the overlay**.
- App-aware routing chooses paths by **SLA**.
