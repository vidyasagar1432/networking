# Metro Ethernet

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Metro Ethernet** uses Ethernet services across a metro/SP network as the WAN. It
brings **cost, speed, and simple L2/L3 models** with service types like **E-LINE, E-LAN,
E-TREE** and delivery via **EoMPLS/pseudowire** or **VPLS/EVPN**. The exam contrasts the
EVC service types and connectivity models.

---

## 2. Core Concepts

### 2.1 Why Metro Ethernet

| Benefit | Detail |
|---------|--------|
| Familiar | Ethernet skills |
| Speed | 1/10/100 G |
| Cost | cheaper than TDM |
| Scale | EVPN at scale |

- Ethernet is **everywhere** — cheap, fast, familiar.

### 2.2 EVC service types

| Type | Model | Use |
|------|-------|-----|
| E-LINE | point-to-point | site links |
| E-LAN | multipoint | any-to-any |
| E-TREE | hub-spoke | root/leaf |

- **E-LINE = P2P; E-LAN = any-to-any; E-TREE = hub-spoke**.

### 2.3 Delivery techs

| Technology | Type |
|------------|------|
| EoMPLS | L2VPN pseudowire |
| VPLS | multipoint L2VPN |
| EVPN | modern (BGP) |
| QinQ | VLAN stacking |

- Pseudowires (EoMPLS) for P2P; **VPLS/EVPN** for multipoint.

### 2.4 Provider bridging

| Mode | Tag |
|------|-----|
| 802.1ad (QinQ) | S-tag + C-tag |
| Q-in-Q | stacked VLANs |
| Service | carrier Ethernet |

- Customer tags ride inside **service tags** at the edge.

### 2.5 Connectivity vs L3 WAN

| Aspect | Metro Ethernet | MPLS L3VPN |
|--------|----------------|-------------|
| Layer | L2 or L3 | L3 |
| Routing | customer's | provider's |
| Control | EVPN/VPLS | MP-BGP |
| Typical | data center | enterprise |

- **L2 keeps customer routing; L3 hands it to the provider** (note 04).

### 2.6 EVPN in a line

- EVPN = **BGP + VXLAN** modern L2/L3 — scales beyond VPLS.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| P2P down | pseudowire | l2vpn forwarding |
| Multipoint broken | VPLS/EVPN | evpn evi |
| Tag mismatch | QinQ | service |
| MAC learning | bridge-domain | mac table |
| No BGP EVPN | MP-BGP | evpn |

---

## 5. Exam Traps

- **E-LINE / E-LAN / E-TREE** = P2P / any-to-any / hub-spoke.
- Delivery: EoMPLS (P2P), **VPLS/EVPN (multipoint)**.
- QinQ = customer + service tags.
- L2 keeps customer routing; **L3 hands it to the SP**.
- EVPN = BGP-based modern alternative.
