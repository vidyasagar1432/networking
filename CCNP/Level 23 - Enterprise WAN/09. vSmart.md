# vSmart

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**vSmart** is the **control plane** of Cisco SD-WAN. It runs **OMP** (Overlay Management
Protocol) with all WAN edges, computes the overlay topology, and distributes **centralized
policy** (routing, data, cflowd). No vSmart = no control or policy. The exam wants
vSmart vs vBond/vManage clarity.

---

## 2. Core Concepts

### 2.1 vSmart's role

| Function | Detail |
|----------|--------|
| OMP | control protocol |
| Route distribution | edge routes |
| Policy | centralized |
| Topology | compute |
| SLA | app-aware paths |

- vSmart = **the brain of the overlay control plane**.

### 2.2 OMP (overlay management protocol)

| Item | Detail |
|------|--------|
| Peers | vSmart ↔ edges |
| Routes | OMP routes |
| TLOC | transport locator |
| Policy | attached |

- **OMP** carries routes + TLOCs between vSmart and edges.

### 2.3 Route types

| Type | Meaning |
|------|---------|
| OMP route | prefix (origin) |
| TLOC | transport location |
| Service | VPN/ETR |
| Policy | match/action |

- Routes are advertised **as OMP routes with TLOCs**.

### 2.4 Policy model

| Policy | Effect |
|--------|--------|
| Centralized | vSmart-based |
| Local | edge-based |
| App-route | SLA path |
| Control | route filtering |

- **Centralized policy lives on vSmart** and pushes to edges.

### 2.5 Why centralized control

| Benefit | Detail |
|---------|--------|
| Consistent | one policy source |
| Agility | change centrally |
| Scale | edges stay light |
| App-aware | global SLA |

- Edges stay simple; **vSmart does the thinking**.

### 2.6 vSmart vs others

| Controller | Plane |
|-----------|-------|
| vBond | orchestration |
| vSmart | **control** |
| vManage | management |

- Remember: **vBond opens the door, vSmart steers, vManage runs the GUI**.

|---------|--------------|-------|

| Missing routes | policy filter | show omp routes |

| Policy not applied | not attached | policy |
| Edge offline | control conn | sdwan control |

## 5. Exam Traps

- vSmart = **control plane + OMP + centralized policy**.
- OMP carries **routes + TLOCs**.
- Centralized policy is **pushed from vSmart**.
- vBond = orchestration; vManage = management; **vSmart = control**.
- No vSmart → no overlay control.
