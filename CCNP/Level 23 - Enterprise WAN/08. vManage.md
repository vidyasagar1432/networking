# vManage

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**vManage** is the **management plane** of Cisco SD-WAN — the web UI/API dashboard that
onboards devices, pushes templates, monitors health, and gathers analytics. It connects
to edges and controllers over the **management plane**; config flows through it. The exam
wants its role versus vSmart (control) and vBond (orchestration).

---

## 2. Core Concepts

### 2.1 vManage's role

| Function | Detail |
|----------|--------|
| Dashboard | single UI |
| Templates | device config |
| Onboarding | zero-touch |
| Monitoring | health/analytics |
| APIs | automation |

- vManage = **where you configure and watch the fabric**.

### 2.2 Plane placement

| Plane | Component |
|-------|-----------|
| Management | vManage |
| Control | vSmart |
| Orchestration | vBond |
| Data | WAN edges |

- vManage sits in the **management plane** only.

### 2.3 How config flows

| Step | Detail |
|------|--------|
| 1 | build template in vManage |
| 2 | push to device |
| 3 | device validates |
| 4 | monitor via vManage |

- Config is **template-driven**, pushed centrally.

### 2.4 Features

| Feature | Detail |
|---------|--------|
| Templates | feature/device |
| CLI mode | direct config |
| Monitoring | real-time |
| Alerts | health |
| REST API | automation |

- Template + API = **programmable, consistent WAN**.

### 2.5 Monitoring/analytics

| View | Content |
|------|---------|
| Device list | status |
| Links | SLA/usage |
| Events | alerts |
| Logs | troubleshooting |

- vManage collects **telemetry from every edge**.

### 2.6 High availability

| Item | Detail |
|------|--------|
| Cluster | multiple vManage |
| Replication | DB sync |
| Failover | transparent |

- Run vManage in a **cluster** for resilience.

## 5. Exam Traps

- vManage = **management plane** (dashboard/templates/monitoring).
- Config is **template-driven and pushed**.
- vSmart = control; **vBond = orchestration**; vManage = management.
- REST API enables **automation**.
- Run in a **cluster** for HA.
