# MPLS WAN

> **Level 23 · Enterprise WAN** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

An **MPLS WAN** connects enterprise sites over a provider's **L3VPN** (Level 20/21
notes 09). The SP provides **PE routers** that carry customer routes (CE–PE via eBGP/
static/OSPF); the customer gets a **private, any-to-any VPN** and the SP handles routing
between sites. Key contrast: **L2 (customer routes) vs L3 (SP routes)** WAN models.

---

## 2. Core Concepts

### 2.1 The L3VPN model

| Role | Device | Job |
|------|--------|-----|
| CE | customer | to PE |
| PE | SP edge | VRF + MP-BGP |
| P | SP core | labels |

- Customer hands routes to the **PE**; SP routes between sites.

### 2.2 CE–PE options

| Protocol | Note |
|----------|------|
| eBGP | most common |
| OSPF | mutual redistribution |
| EIGRP | legacy |
| Static | simplest |

- The **CE–PE routing** choice shapes the L3VPN design.

### 2.3 MPLS WAN vs Metro Ethernet

| Aspect | MPLS L3VPN | Metro Ethernet |
|--------|------------|----------------|
| Layer | L3 | L2 |
| Routing | provider | customer |
| Any-to-any | yes | via VPLS/EVPN |
| Redundancy | SP handles | customer |

- **MPLS L3 hands routing to the SP; L2 keeps it with the customer.**

### 2.4 Benefits

| Benefit | Detail |
|---------|--------|
| Private | VRF isolation |
| Any-to-any | full mesh no cost |
| Managed | SP does routing |
| SLA | provider guarantees |

- Enterprises buy **routing + transport** from the SP.

### 2.5 Dual-homing

| Model | Detail |
|-------|--------|
| Single PE | simpler |
| Dual PE | resilience |
| Dual sites | MPLS link |
| BGP | handles path |

- Dual PE/CE gives **fast failover** via routing.

### 2.6 Design considerations

| Point | Detail |
|-------|--------|
| IP plan | per-site uniqueness |
| CE redundancy | dual CE |
| QoS | per-class over VPN |
| DIA | separate Internet |

- Internet often goes **direct/DIA**, keeping MPLS for private traffic.

---

## 5. Exam Traps

- MPLS WAN = **SP-provided L3VPN** (VRF + MP-BGP).
- CE–PE: eBGP/static/OSPF/EIGRP.
- L3 = SP routes; **L2 (Metro E) = customer routes**.
- Dual PE/CE = resilience via routing.
- DIA keeps Internet off the private VPN.
