# Speed

> **Level 01 · 02. Ethernet** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Speed** is the line rate of an Ethernet port. It is negotiated (copper), fixed
(fiber), and constrained by the cable category/optics installed. Understanding speed
mechanics prevents wrong diagnosis: a "slow port" is usually a **mismatch, cabling,
or bottleneck**, not the nominal rate.

---

## 2. Core Concepts

### 2.1 Standard speed ladder
| Speed | Name | Typical medium | Notes |
|-------|------|----------------|-------|
| 10 Mbps | 10BASE-T | Cat3 | Legacy |
| 100 Mbps | 100BASE-TX | Cat5 (2 pair) | Fast Ethernet |
| 1 Gbps | 1000BASE-T / -SX/-LX | Cat5e / MM/SM | Gigabit — FDX only |
| 2.5 Gbps | 2.5GBASE-T | Cat5e/Cat6 | NBASE-T on existing cabling |
| 5 Gbps | 5GBASE-T | Cat6 (100 m) | NBASE-T |
| 10 Gbps | 10GBASE-T / -SR/-LR/-ER | Cat6a / optics | 100 m Copper cats; 300 m–40 km optics |
| 25 Gbps | 25GBASE-* | SFP28 / SM-MM | DC high-density |
| 40 Gbps | 40GBASE-* | QSFP+ (SR4/LR4/CR4) | DC spine-leaf |
| 100 Gbps | 100GBASE-* | QSFP28 (LR4/SR4/CR4) | Modern DC |
| 400 Gbps | 400GBASE-* | OSFP / QSFP-DD | Very latest DC |

### 2.2 Negotiation behaviors
- **Copper ports**: advertise capability; highest common = negotiated speed.
  Forced settings override (see [[02. Duplex]] for the half-duplex fallback trap).
- **Fiber ports**: no speed negotiation (1G SFP fixed; 10G SFP+ fixed; some QSFPs
  auto-negotiate via AN 802.3 for Ethernet rates between 1G–40/100G on breakout).
- **Breakout (40G→4×10G / 100G→4×25G)** via DAC and splitter — a DC staple.

### 2.3 Where "speed" becomes a bottleneck
- Link speed (line rate) ≠ throughput: TCP window, latency, MSS, drops cap real
  performance (see Level 26 Performance).
- Pragmatism: the weakest link in a path sets end-to-end rate (a 100M uplink kills a
  gigabit campus flow).
- **Auto-neg off on a broken cable** → port falls to lowest common speed (10M) —
  a red flag. Commonly seen in the "suddenly slow" question pattern.

## 3. Configuration / Commands

```text
interface GigabitEthernet0/1
 speed 1000            # fixed or "auto"
 duplex full

show interfaces gig0/1 | include "(Gb/s|Mb/s|Duplex|Speed)"   # negotiated reality
show interfaces status        # speed/duplex of all ports
show interfaces counters rate # current utilization
```

---

## 4. Exam Traps

- **Never assume the CLI "speed 1000" is running** — verify with `show interfaces`.
- **NBASE-T (2.5/5G) on Cat5e/6** extends life of copper without re-cabling;
  count it as a modern twist.
- **Fiber speed is set by module** — a 1G SFP in a 10G port stays 1G; wrong module
  (SX vs LX SMA) is a common silent failure.
- **Breakout cables** split one high-speed port into several lower-rate links — if you
  see 40G in a design question, expect QSFP/MPO terms.
- **Speed mismatch override**: when one side forced, verify the sibling `duplex` —
  a forced speed may still work yet be half-duplex (slow but "up").
