# Fiber

> **Level 01 · 01. Cables** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

Fiber-optic cabling carries **light** (photons) through a glass or plastic core
using total internal reflection. It offers far longer reach, higher bandwidth, and
immunity to EMI compared with copper. Two varieties dominate: **single-mode (SMF)**
and **multimode (MMF)**.

---

## 2. Core Concepts

### 2.1 Physics in one line
Light injected at an angle into the core bounces down the fiber via total internal
reflection at the core–cladding boundary (cladding has a lower refractive index).

### 2.2 Single-mode vs Multimode
| Property | Multimode (MMF) | Single-mode (SMF) |
|----------|-----------------|-------------------|
| Core diameter | 50 or 62.5 µm | ~9 µm |
| Light source | LED / VCSEL | Laser (longer coherence) |
| Modal dispersion | Present (limits distance) | Minimal |
| Typical reach | 100 m – 550 m | 10 km – 120 km+ |
| Distance limit reason | Modal dispersion + attenuation | Attenuation (and power budget) |
| Cost | Cheaper modules | More expensive modules, better reach |
| Color coding | **Aqua** (OM3/OM4), Grey (OM1/OM2) | **Yellow** (OS1/OS2) |
| Typical use | Campus / intra-DC (ToR–ToR) | WAN, metro, DC interconnects (long haul) |

### 2.3 Multi-mode classes (OM)
- OM1 62.5 µm · OM2 50 µm (legacy, LED)
- OM3 / OM4 50 µm laser-optimized → 10G (OM3: 300 m, OM4: 550 m).
- OM5 50 µm wideband — supports 4-WDM for 100G+ at 150 m+.

### 2.4 Single-mode classes (OS)
- OS1 — indoor; OS2 — outdoor/wider reach.
- Usually 10G and above; 40/100/400G use multiple wavelengths (WDM) over SMF.

### 2.5 Duplex connectors and polarity
- Fiber links are **duplex**: one fiber TX, one fiber RX (LC duplex pair).
- Polarity = the connector/link that ensures TX(A)→RX(B) alignment through panels
  (A↔B flip) — important when using patch panels to avoid light back to the same port.

### 2.6 Power budget basics (for design)
- Optical loss = each connector (~0.5 dB) + splice (~0.1–0.3 dB) + attenuation
  (MMF ≤3.5 dB/km @850 nm, SMF ≤0.4 dB/km @1310 nm, ≤0.25 dB/km @1550 nm).
- Systems have a receiver sensitivity; if budget is exceeded, link fails/high BER.

## 4. Exam Traps

- **Multimode distance limits** are dispersion-based; single-mode reach is loss-based.
- **Don't claim "fiber is always faster"** — speed is protocol/module-dependent;
  fiber's real strengths are distance and immunity to noise.
- **Color code questions:** aqua = OM3/OM4, yellow = single-mode — easy marks.
- **40GBASE-SR4 / 100GBASE-SR4 MPO** use parallel fibers; LC duplex is the legacy
  small-run pattern — QSFP uses MPO-12/24.
- **OM5 is 50 µm laser-optimized WDM, not "newer single-mode."**
