# UTP

> **Level 01 · 01. Cables** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Unshielded Twisted Pair (UTP)** is the most common copper cabling for LANs. Four
twisted pairs of copper wire carry signals differentially: twisting and the balanced
differential signal cancel electromagnetic interference (EMI) and crosstalk. It is
cheap, familiar, and standardized in the TIA/EIA-568 series.

---

## 2. Core Concepts

### 2.1 Why twist?
- Adjacent pairs are twisted at different rates (lay/length varies) so that unwanted
  coupling (crosstalk, EMI) induced on one pair is out of phase with the other and
  cancels at the differential receiver.
- Balanced transmission: both conductors carry the same signal in opposite polarity
  (+V and −V); receiver reads the difference.

### 2.2 Pairs and the color code
- Pairs: orange (1-2), green (3-6), blue (4-5), brown (7-8).
- The pairs are **not** contiguous pins — 3-6 splits around 4-5 (legacy of the
  telephone-based 10BASE-T design which used pins 1,2,3,6).

### 2.3 Categories (Ethernet relevance)
| Cat | Rating | Purpose |
|-----|--------|---------|
| Cat 5 | 100 MHz | 100BASE-TX (Fast Ethernet) |
| Cat 5e | 100 MHz | Up to 1000BASE-T (Gigabit, 4-pair 1000BASE-T) |
| Cat 6 | 250 MHz | 1000BASE-T, 10GBASE-T up to 55 m |
| Cat 6a | 500 MHz | 10GBASE-T up to 100 m |
| Cat 7 | 600 MHz | Shielded; limited use |
| Cat 8 | 2000 MHz | 25/40GBASE-T, short (<30 m) data-center runs |

### 2.4 Cabling rules
- Pairs are used by the Ethernet PMD as follows: 100BASE-TX uses 1-2 (TX) and 3-6 (RX);
  1000BASE-T uses all four pairs bidirectionally.
- **Segment length ≤ 100 m** (90 m horizontal + 10 m patch/user cables) for twisted-pair
  Ethernet — "100-meter rule."
- 2.5GBASE-T and 5GBASE-T (NBASE-T) reuse Cat 5e/6 at higher speeds over same 100 m.

### 2.5 Straight-through vs crossover — the AUTO-MDIX game
- Straight-through — same pinout both ends (device↔switch). Crossover — TX/RX swapped
  (switch↔switch, host↔host, or legacy host↔host).
- **auto-MDIX** (automatic medium-dependent interface crossover) makes the distinction
  irrelevant on modern equipment — the PHY detects the peer and swaps internally.
  On Cisco IOS disable/enable with:
  `switchport nonegotiate` is unrelated — use the PHY-level:
  `speed auto` / `duplex auto` plus global auto-mdix (default on for 10/100/1000M).

## 3. Configuration / Commands

```text
# Interface physical gigabit negotiation (typically auto)
interface GigabitEthernet0/1
 speed auto
 duplex auto
 mdix auto            # auto-MDIX (default enabled in most IOS images)

show interfaces GigabitEthernet0/1
show interfaces status       # quick media/duplex/speed view
```

## 4. Exam Traps

- **UTP vs STP cabling names:** "STP" is a *cable* (shielded twisted pair), NOT just the
  spanning-tree protocol — the exam uses the same initials; disambiguate by context.
- **100-meter rule** includes patch cables within the 100 m budget.
- **Modern auto-MDIX** means a straight cable works switch-to-switch — an older question
  pattern (crossover required) is tiny on newer exams; still know the pinout concept.
- **Different pairs used by speed:** 100BASE-TX = 2 pairs, 1000BASE-T = 4 pairs
  using all with echo cancellation.
- **Cat 5 and 5e both 100 MHz** — 5e adds stricter specs for gigabit; don't claim
  a higher MHz rating for 5e.
