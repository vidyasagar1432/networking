# Transceivers

> **Level 01 · Physical Layer** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **transceiver** converts the electrical signal of the switch's PHY into the
optical/ electrical form of the media (typically fiber optics). It plugs into a
fixed bay or a carrier (SFP, SFP+, QSFP) and contains the laser, optics, and PMD logic.

---

## 2. Core Concepts

### 2.1 Form factors (the more common names on exams)

| Factor | Speed range | Typical use |
|--------|-------------|-------------|
| **SFP** | 100M–1G | 1G fiber, also 100M/1000BASE copper SFPs |
| **SFP+** | 10G | 10G fiber/cable; same footprint as SFP |
| **SFP28** | 25G | 25G laterals / dense DC |
| **XFP** | 10G | Legacy device-to-device (aging) |
| **QSFP+** | 4×10G (40G) | 40G spine-leaf |
| **QSFP28** | 4×25G (100G) | 100G DC |
| **QSFP-DD / OSFP** | 100G–400G+ | Latest generations, 8 lanes |
| **GBIC** | 1G | Legacy rj45/lc carrier (superseded by SFP) |

### 2.2 What's inside / control
- **DOM (Digital Optical Monitoring)**: reads laser power TX/RX, temperature, voltage —
  a fast link-health diagnostic (`show interface transceiver detail`).
- **Optical TX/RX power**: check RX near expected receive sensitivity when below
  threshold for high error rate.
- **DDM/CMIS** data accessed via I2C — covered by the transceiver MIB.

### 2.3 Common failure modes (exam favorites)
- **Unsupported / counterfeit module** → Cisco "invalid transceiver" messages and
  port disabled (`errdisable`) — require genuine/certified modules.
- **Wrong wavelength**: 850 nm (SR) vs 1310 nm (LR/LX) on opposite ends → no link.
- **Wrong fiber type**: Multi-mode media + single-mode module laser behavior → SX module
  needs MM fiber; LX with SM pigtails is common.
- **Dirty connectors** → low RX power, CRC errors.
- **Missing/DAC (Direct Attach Cable)** — copper twinax SFP+ with no optics — saves cost for ≤7 m.

### 2.4 Transceiver ↔ link mapping (repeat of connectors but now devices)

| Media | Module | Fiber/connector |
|-------|--------|-----------------|
| 1G MM | SFP 1000BASE-SX | MMF, LC, 850 nm |
| 1G SM | SFP 1000BASE-LX | SMF (or MM+LXC), LC, 1310 nm |
| 10G MM | SFP+ 10GBASE-SR | MMF, LC, 850 nm (~300 m) |
| 10G SM | SFP+ 10GBASE-LR | SMF, LC, 1310 nm (10 km) |
| 40G MM | QSFP+ SR4 | MPO-12, 850 nm, 100 m |
| 40G SM | QSFP+ LR4 | LC duplex, 1310 nm CWDM, 10 km |
| 100G | QSFP28 SR4/LR4 | MPO / LC duplex |

## 3. Configuration / Commands

```text
# See all optical interface DOM values
show int tend1/1 transceiver | include (Wavelength|Temperature|Tx Power|Rx Power)

# Verify which module a port has
show interfaces transceiver | include "(SFP|QSFP|XFP|PORT)"

# Rule: if DOM RX too low => clean, check fiber/connector, reseat module.
```

Troubleshoot "link down on fiber":
1. `show interface <if> transceiver` — module present? TX/RX power sane?
2. Confirm both ends **same wavelength** and **correct fiber type**.
3. Clean and reseat; swap known-good module.

---

## 4. Exam Traps

- **SFP/SFP+ same mechanics** — a 1G SFP works at 1G in a 10G slot (no 10G!).
- **SR=850 nm MM, LR/LX=1310 nm SM** — a wavelength mismatch = no link even with light.
- **40G SR4=MPO vs LR4=LC** — modules differ, connector differs; test knows.
- **"Invalid transceiver"** = compatibility/compliance block — port disabled.
- **DAC vs fiber** — DAC = copper twinax, shortest reach, no optics/DOM.
- **DOM data** is read from the module, not the fiber — know the diagnostic value.
