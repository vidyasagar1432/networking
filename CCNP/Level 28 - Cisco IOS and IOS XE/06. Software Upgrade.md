# Software Upgrade

> **Level 28 · Cisco IOS and IOS XE** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Upgrading IOS XE** = copy the new image to flash, **set it as boot**, reload, and
verify. Since the image isn't run in-place, you must **point `boot system` at it**.
Rollback uses the old image. The exam tests the sequence and verification.

---

## 2. Core Concepts

### 2.1 Upgrade flow

| Step | Action |
|------|--------|
| 1 | check space |
| 2 | copy image |
| 3 | verify checksum |
| 4 | `boot system flash:` |
| 5 | save config |
| 6 | reload |
| 7 | verify version |

- Follow the **order: space → copy → boot → reload → verify.**

### 2.2 Getting the image

| Source | Command |
|--------|---------|
| TFTP | `copy tftp: flash:` |
| FTP | `copy ftp: flash:` |
| SCP | `copy scp: flash:` |
| USB | `copy usb0: flash:` |

- Network copy is the **common path**.

### 2.3 Boot statements

| Command | Meaning |
|---------|---------|
| `boot system flash:ios-xe.bin` | boot file |
| `no boot system` | clear |
| `show boot` | verify |
| `show version` | running image |

- **`boot system` tells the device which image to load.**

### 2.4 Verifying integrity

| Command | Purpose |
|---------|---------|
| `verify /md5 flash:img.bin` | checksum |
| `dir flash:` | size |
| `show flash:` | usage |
| `show version` | loaded |

- Compare **MD5** before you trust the copy.

### 2.5 Reload and rollback

| Action | Command |
|--------|---------|
| Save | `copy run start` |
| Reload | `reload` |
| Rollback | old boot statement + reload |
| Validate | `show version` |

- Keep the **previous image** for rollback.

### 2.6 Upgrade vs SMU

| Term | Meaning |
|------|---------|
| Full image | full upgrade |
| SMU | patch on running image |
| Patch | no full reload |
| Major | version jump |

- **SMU = targeted patch**, not a full image.

---

## 3. Configuration / Commands

```text
copy tftp://10.0.0.5/ios-xe-new.bin bootflash:
verify /md5 bootflash:ios-xe-new.bin
boot system bootflash:ios-xe-new.bin
copy running-config startup-config
reload
show version
show boot
```

---

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Booted old | boot statement | show boot |
| Space | flash full | dir |
| Corrupt | checksum | verify |
| No console | reload | watchdog |
| Wrong image | version | show version |

---

## 5. Exam Traps

- **`boot system flash:` is required** — image won't auto-boot.
- **`verify /md5`** before install.
- **`show boot` / `show version`** confirm load.
- Copy needs **space + checksum**.
- Rollback = revert **boot statement + reload**.
