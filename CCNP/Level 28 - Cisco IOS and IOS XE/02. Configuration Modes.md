# Configuration Modes

> **Level 28 · Cisco IOS and IOS XE** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

IOS organizes configuration into **hierarchical modes**: **global → interface/line/router
→ submode (e.g. under an interface)**. Each mode's prompt reflects the context, and
commands apply to that scope only. The exam tests entering, exiting, and nesting modes.

---

## 2. Core Concepts

### 2.1 Mode hierarchy

| Mode | Prompt | Scope |
|------|--------|-------|
| Privileged EXEC | `#` | all EXEC |
| Global config | `(config)#` | device-wide |
| Interface | `(config-if)#` | one interface |
| Line | `(config-line)#` | console/vty |
| Router | `(config-router)#` | routing protocol |

- **Prompt tells you where you are.**

### 2.2 Entering modes

| Command | From | To |
|---------|------|----|
| `configure terminal` | exec | global |
| `interface Gi0/1` | global | interface |
| `line console 0` | global | line |
| `router ospf 1` | global | router |
| `access-list 100` | global | still global |

- Submodes are entered from **global config**.

### 2.3 Exiting modes

| Command | Action |
|---------|--------|
| `exit` | up one level |
| `end` | back to EXEC |
| Ctrl+Z | same as end |
| `interface Gi0/2` | switch context |

- **`exit` = one level; `end` = all the way out.**

### 2.4 Common global commands

| Command | Scope |
|---------|-------|
| `hostname` | device |
| `ip route` | routing |
| `access-list` | ACLs |
| `snmp-server` | NMS |
| `logging` | syslog |

- Global config = **device-wide settings**.

### 2.5 Interface submode commands

| Command | Scope |
|---------|-------|
| `ip address` | that interface |
| `no shutdown` | admin up |
| `description` | label |
| `speed`/`duplex` | L1 |
| `channel-group` | bundle |

- Interface commands affect **only that interface**.

### 2.6 `do` inside config

| Feature | Use |
|---------|-----|
| `do show` | EXEC from config |
| `do ping` | test from config |
| Saves exit | quick verify |

- **`do` runs EXEC without leaving config mode.**

---

## 3. Configuration / Commands

```text
configure terminal
 hostname R1
 interface GigabitEthernet0/1
  ip address 10.0.0.1 255.255.255.0
  no shutdown
  exit
 line vty 0 4
  password cisco
  exit
 end
show running-config
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Wrong prompt | mode | type `exit` |
| Command rejected | wrong mode | prompt |
| No `do` | IOS | version |
| Nested deep | stuck | `end` |
| Duplicate | scope | config context |

---

## 5. Exam Traps

- **Prompt reveals the mode** — read it.
- `exit` = one level; **`end`/Ctrl+Z = to EXEC**.
- Interface commands are **interface-scoped**.
- `do` runs EXEC **inside config**.
- Global config first; **submodes nest under it**.
