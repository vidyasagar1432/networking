# Smart Licensing

> **Level 28 · Cisco IOS and IOS XE** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Smart Licensing** replaces PAK files with a **central portal (CSSM)** that manages
entitlements across devices. Devices **report usage**; **Smart Licensing Using Policy
(SLUP)** is the latest model with evaluation/callback behavior. The exam tests
registration, call-home, and the policy model.

---

## 2. Core Concepts

### 2.1 How it works

| Component | Role |
|-----------|------|
| CSSM | portal entitlement |
| Registration | token from portal |
| Report | usage to portal |
| Call-home | transport |
| Enforcement | policy |

- Devices register to **CSSM via a token**.

### 2.2 Communication

| Channel | Purpose |
|---------|---------|
| Call-home | device → Cisco |
| Smart transport | HTTPS |
| Offline | via file |
| Proxy | HTTPS proxy |
| Direct | internet |

- **HTTPS call-home** is the normal path.

### 2.3 Smart Licensing Using Policy (SLUP)

| Item | Detail |
|------|--------|
| Default | policy-based |
| Evaluation | 90 days |
| Tags | license types |
| Enrollment | via CSSM |
| Enforcement | after eval |

- SLUP gives **evaluation + flexible enforcement**.

### 2.4 License tiers (network)

| Tier | Features |
|------|----------|
| network-essentials | base |
| network-advantage | full |
| dna-essentials/advantage | DNA |

- **Tier = capability level** bought per device.

### 2.5 Registration flow

| Step | Action |
|------|--------|
| 1 | get token |
| 2 | `license smart register idtoken <t>` |
| 3 | device registers |
| 4 | entitlements match |
| 5 | usage reported |

- Token → register → **entitlements appear**.

### 2.6 Troubleshooting

| Item | Detail |
|------|--------|
| Auth fail | token |
| No report | call-home |
| Eval expiry | period |
| Offline | manual file |

- **`show license status`** diagnoses registration.
