# Recovery

> **Level 28 · Cisco IOS and IOS XE** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Recovery** covers regaining access after **lost passwords, corrupt images, or failed
boots**. Methods: **password recovery** (config register trick), **ROMMON** for image
recovery, and **emergency-access** on modern IOS XE. The exam tests the recovery steps
and the **config-register**.

---

## 2. Core Concepts

### 2.1 Config-register

| Register | Meaning |
|----------|---------|
| 0x2102 | normal boot + ROM monitor |
| 0x2142 | ignore startup-config |
| 0x2100 | boot to ROMMON |

- **0x2142 ignores the startup config** for recovery.

### 2.2 Password recovery steps

| Step | Action |
|------|--------|
| 1 | power cycle / break |
| 2 | set register 0x2142 |
| 3 | boot |
| 4 | copy start run |
| 5 | change password |
| 6 | reset register 0x2102 |
| 7 | save + reload |

- **Break sequence** drops to ROMMON to change the register.

### 2.3 ROMMON / ROM monitor

| Item | Detail |
|------|--------|
| Access | break / register 0 |
| Purpose | boot without image |
| Commands | `boot`, `dir`, `set` |
| Image boot | `boot flash:...` |
| XE | `rommon` with xmodem/usb |

- ROMMON = **minimal bootloader environment**.

### 2.4 Image recovery

| Method | Use |
|--------|-----|
| ROMMON `boot` | load from flash |
| USB | boot device image |
| Xmodem | console slow load |
| TFTP in ROMMON | network |
| Emergency access | XE modern |

- Recover a **corrupt image from ROMMON**.

### 2.5 Emergency access (IOS XE)

| Command | Meaning |
|---------|---------|
| `platform console virtual` | virtual console |
| `enable` recovery | via emergency |
| `security password` | set |
| `exit` | back |

- **`platform console virtual`** unlocks modern recovery.

### 2.6 Recovery flow table

| Problem | Fix |
|---------|-----|
| Lost enable | 0x2142 + reset |
| No image | ROMMON boot/TFTP |
| Corrupt image | verify + recopy |
| Locked out | console break |
| XE password | emergency access |

- Match **problem to the right recovery path**.

## 3. Configuration / Commands

```text
confreg 0x2142
boot
copy startup-config running-config
enable secret NewPass
config-register 0x2102
copy running-config startup-config
reload
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No ROMMON | no break | timing |
| Register lost | boot | config-register |
| No image | flash | dir |
| Xmodem slow | console | rate |
| XE lock | emergency | platform console |

---

## 5. Exam Traps

- **0x2142 = skip startup config**; 0x2102 = normal.
- Break = **ROMMON**.
- Password recovery: **register → boot → copy start run**.
- **Emergency access** on IOS XE (`platform console virtual`).
- Restore **0x2102** before reload.
