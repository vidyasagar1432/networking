# File Systems

> **Level 28 · Cisco IOS and IOS XE** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

IOS uses a **virtual file system** with prefixes like **flash:, bootflash:, system:,
nvram:**, and network prefixes (**tftp:, ftp:, scp:**). `dir`, `copy`, and `show flash`
navigate it. The exam tests prefixes, copy syntax, and where configs live.

---

## 2. Core Concepts

### 2.1 File system prefixes

| Prefix | Location |
|--------|----------|
| `flash:` | flash device |
| `bootflash:` | boot flash (XE) |
| `nvram:` | startup config |
| `system:` | running config |
| `disk0:` | removable |
| `tftp:` | network |
| `ftp:` / `scp:` | network |

- **Prefix = which storage the command touches.**

### 2.2 Where things live

| Data | Location |
|------|----------|
| IOS image | flash/bootflash |
| Running config | system: running-config |
| Startup config | nvram:startup-config |
| Config files | flash |
| Crash info | flash |

- **running-config in RAM; startup-config in NVRAM.**

### 2.3 Directory commands

| Command | Purpose |
|---------|---------|
| `dir` | list |
| `dir flash:` | flash |
| `show flash:` | usage |
| `cd` / `pwd` | navigate |
| `show file systems` | all |

- **`show file systems`** lists available prefixes.

### 2.4 Copy operations

```text
copy flash: flash:
copy running-config startup-config
copy tftp: flash:
copy startup-config running-config
```

| Copy | Meaning |
|------|---------|
| `copy run start` | save |
| `copy start run` | restore |
| `copy tftp: flash:` | get image |
| `copy flash: tftp:` | back up |

- Copy = **from to**, ask for names interactively.

### 2.5 File details

| Item | Command |
|------|---------|
| Size | `dir` |
| Free space | `dir flash:` |
| CRC | `verify` |
| Show all | `show file systems` |

- Verify image integrity with **`verify /md5 flash:image.bin`**.

### 2.6 NVRAM vs Flash

| Aspect | NVRAM | Flash |
|--------|-------|-------|
| Content | startup-config | image + files |
| Volatile? | no | no |
| Size | small | large |
| Uses | boot config | image/backup |

- **NVRAM = config; Flash = files/image.**

## 3. Configuration / Commands

```text
show file systems
dir bootflash:
copy running-config startup-config
copy tftp://10.0.0.5/ios.bin bootflash:
show flash:
verify /md5 bootflash:ios.bin
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No space | flash full | dir |
| Copy fail | permissions | path |
| Wrong file | prefix | fs list |
| Image corrupt | CRC | verify |
| Config lost | never saved | copy run start |

---

## 5. Exam Traps

- **running-config = system:; startup-config = nvram:**.
- Prefixes: **flash:, bootflash:, tftp:**.
- `copy run start` = save to **NVRAM**.
- `dir` lists; `show file systems` shows **all prefixes**.
- Image integrity via **`verify /md5`**.
