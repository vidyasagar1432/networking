# CLI

> **Level 28 · Cisco IOS and IOS XE** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **Cisco CLI** is the primary configuration interface: **exec commands** run in
privileged mode, **configure commands** in config mode. Built-in help, **tab
completion**, and `do` let you verify from anywhere. The exam tests mode navigation,
shortcuts, and help features.

---

## 2. Core Concepts

### 2.1 Two command classes

| Class | Mode | Examples |
|-------|------|----------|
| EXEC | user/privileged | show, ping |
| Configure | config mode | interface, router |

- **`show` runs in EXEC; `interface` in config.**

### 2.2 Help features

| Feature | Command | Result |
|---------|---------|--------|
| `?` | `?` | all commands |
| `show ?` | partial | subcommands |
| `show x?` | no space | completions |
| `show co?` | word | candidates |
| Error | `% Invalid input` | wrong syntax |

- `?` = **context help**; `?` after word = **next keyword**.

### 2.3 Shortcuts

| Shortcut | Action |
|----------|--------|
| Tab | complete word |
| Up arrow | history |
| Ctrl+Z | exit config |
| Ctrl+C | abort |
| Ctrl+Shift+6 | interrupt |
| `do` | run EXEC in config |

- **Tab + Ctrl+Z** are the daily lifesavers.

### 2.4 Privilege levels

| Level | Meaning |
|-------|---------|
| 0 | minimal |
| 1 | user mode |
| 15 | privileged |
| custom | via `privilege` |

- **Level 15 = enable (full).**

### 2.5 Verification style

| Command | Purpose |
|---------|---------|
| `show running-config` | live |
| `show startup-config` | saved |
| `show version` | image/uptime |
| `show interfaces` | status |
| `terminal length 0` | no paging |

- **`show` family** drives troubleshooting.

### 2.6 Output modifiers

| Modifier | Use |
|----------|-----|
| `| include X` | filter |
| `| exclude X` | hide |
| `| section X` | block |
| `| begin X` | start at |
| `| redirect tftp:` | save |

- Pipes **filter and save** long output.

## 3. Configuration / Commands

```text
enable
configure terminal
interface GigabitEthernet0/1
 ip address 10.0.0.1 255.255.255.0
 no shutdown
end
show running-config | include ip address
```

| Command | Meaning |
|---------|---------|
| `enable` | level 15 |
| `configure terminal` | config mode |
| `no ...` | remove |
| `end` / Ctrl+Z | exit config |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Bad command | wrong mode | mode prompt |
| `% Ambiguous` | abbreviation | type more |
| No permission | privilege | level |
| Can't configure | no `configure` | privilege 15 |
| Output too long | paging | length 0 |

---

## 5. Exam Traps

- **Config mode vs EXEC mode** — where each command lives.
- `?` vs `?` after word — **no-space = completion**.
- `do` allows **EXEC inside config**.
- Ctrl+Z / `end` = **exit config mode**.
- Abbreviation ok but must be **unambiguous**.
