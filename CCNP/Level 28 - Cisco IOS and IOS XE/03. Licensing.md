# Licensing

> **Level 28 · Cisco IOS and IOS XE** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Licensing** controls feature entitlements on IOS XE. Legacy **EULA** models (classic
LICENSE) are being replaced by **Smart Licensing**. Packages like **network-advantage**
bundle features; images carry a `universalk9` and licenses gate functions. The exam
tests package tiers and how licenses are evaluated.

---

## 2. Core Concepts

### 2.1 License packages (classic)

| Package | Features |
|---------|----------|
| ipbase | base routing |
| ipservices | advanced |
| Security (in newer) | security |
| network-advantage | full (modern) |

- **Advantage tiers bundle more features.**

### 2.2 How licenses gate features

| Item | Detail |
|------|--------|
| Entitlement | feature flag |
| Evaluation | 60-day eval |
| Permanent | installed |
| Enforcement | config denied |
| Product | per PID |

- Without a license, the feature **won't enable**.

### 2.3 License types

| Type | Meaning |
|------|---------|
| Eval | temporary (60 d) |
| Evaluation period | grace |
| Permanent | owned |
| Subscription | time-based |
| RTU | right-to-use |

- **Eval licenses let you try features.**

### 2.4 Image packages

| Image | Purpose |
|-------|---------|
| universalK9 | all features licensed |
| Feature-based | smaller footprint |
| Universal | future-proof |

- **universalK9 = single image, feature gated by license.**

### 2.5 Checking licenses

| Command | Purpose |
|---------|---------|
| `show license` | installed |
| `show license summary` | status |
| `show license feature` | available |
| `license install` | activate |
| `license boot level` | set tier |

- **`show license summary`** is the day-1 check.

### 2.6 Classic vs Smart

| Aspect | Classic | Smart |
|--------|---------|-------|
| Activation | PAK/license file | portal |
| Reporting | manual | automatic |
| Enforcement | local | CSSM |
| Model | perpetual | subscription |

- Smart Licensing is the **modern default**.

## 3. Configuration / Commands

```text
show license
show license summary
show license feature
license install bootflash:license.lic
license boot level network-advantage
reload
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Feature denied | no license | show license feature |
| Eval near end | period | summary |
| Wrong tier | boot level | config |
| Install fail | file | path |
| No entitlement | PID | correct license |
