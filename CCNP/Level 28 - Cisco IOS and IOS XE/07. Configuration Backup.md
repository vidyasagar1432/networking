# Configuration Backup

> **Level 28 · Cisco IOS and IOS XE** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Configuration backup** protects the running/startup config by copying it to external
storage (**TFTP/SCP/FTP/USB**) or the **archive** feature. `show archive` tracks
versions. The exam tests copy targets, `archive` config, and restore paths.

---

## 2. Core Concepts

### 2.1 What to back up

| Data | Source |
|------|--------|
| Running config | system:running-config |
| Startup config | nvram:startup-config |
| Image | flash (separate) |
| Archive | auto snapshots |

- Back up **running/startup config + image** (note 06).

### 2.2 Copy targets

| Target | Command |
|--------|---------|
| TFTP | `copy running-config tftp:` |
| SCP | `copy running-config scp:` |
| FTP | `copy running-config ftp:` |
| USB | `copy running-config usb0:` |
| Flash | `copy run flash:config.bak` |

- External storage = **off-box protection**.

### 2.3 The archive feature

| Command | Meaning |
|---------|---------|
| `archive` | enter archive mode |
| `path tftp://...` | destination |
| `write-memory` | auto-save |
| `maximum 14` | versions kept |
| `show archive` | list |

- Archive = **versioned, automatic snapshots**.

### 2.4 Restore paths

| From | Command |
|------|---------|
| TFTP | `copy tftp: running-config` |
| Startup | `copy start run` |
| Archive | `configure replace file:` |
| Flash | `copy flash: running-config` |

- Restore by **copying the file back into place**.

### 2.5 Version management

| Item | Detail |
|------|--------|
| Archive max | keep N |
| Increment | numbered |
| Diff | `show archive config differences` |
| Timestamp | in name |

- **`show archive`** lists every saved generation.

### 2.6 Best practice

| Step | Why |
|------|-----|
| Schedule | automation |
| Off-box | survive device loss |
| Verify | compare hashes |
| Document | restore steps |

- Backup is **only useful if you can restore**.

---

## 3. Configuration / Commands

```text
archive
 path tftp://10.0.0.5/archive
 write-memory
 maximum 14
show archive
copy running-config tftp://10.0.0.5/r1-run.cfg
copy tftp://10.0.0.5/r1-run.cfg running-config
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Copy fail | reachability | ping target |
| No archive | path | show archive |
| Old versions | maximum | config |
| Restore bad | file | diff |
| Disk full | target | free space |

---

## 5. Exam Traps

- **`archive` + `path` + `write-memory`** = auto backup.
- `show archive` = **version list**.
- `copy run start` ≠ off-box backup (NVRAM only).
- **`configure replace`** applies archived config.
- Always **off-box** for real DR.
