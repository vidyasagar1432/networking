# PAT (Port Address Translation / NAT Overload)

> **Level 15 · NAT** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**PAT** (overload) lets **thousands of inside hosts share one (or a few) public
addresses** by translating the **source port** in addition to the IP. The router keeps a
socket-level table (src IP:port → global IP:port). It's the standard internet-sharing NAT
in homes and enterprises.

---

## 2. Core Concepts

### 2.1 Packet transformation

```
Inside: 10.0.0.5:12345  -> 203.0.113.1:23456 (outbound)
Return: 203.0.113.1:23456 -> 10.0.0.5:12345   (inbound)
```

- Translation = **IP + TCP/UDP port** mapping; ICMP uses ID.

### 2.2 Configuration (on a pool or on address overload)

```text
access-list 1 permit 10.0.0.0 0.0.255.255
ip nat pool PUBLIC 203.0.113.1 203.0.113.1 netmask 255.255.255.0
ip nat inside source list 1 pool PUBLIC overload
```

or **(overload on the outside interface)**:

```text
ip nat inside source list 1 interface Gi0/1 overload
```

- `overload` turns pool/dynamic NAT into PAT.
- Using the **interface address** is the most common (reference) deployment.

### 2.3 Port allocation

| Protocol | Mapping key | Limit |
|----------|-------------|-------|
| TCP | src IP+port | many per public IP |
| UDP | src IP+port | many per public IP |
| ICMP | ICMP identifier | many per public IP |

- The router assigns **unique source ports** to disambiguate sessions.

### 2.4 PAT vs dynamic NAT

| Aspect | Dynamic NAT | PAT |
|--------|-------------|-----|
| Public addresses | many | one (or few) |
| Port translation | no | yes |
| Scalability | pool-limited | thousands |
| Inbound | no | only via explicit port maps |
| Exhaustion | drops | port-space limit |

### 2.5 Inbound with PAT

```text
ip nat inside source static tcp 10.0.0.10 8080 interface Gi0/1 80
```

- Public-facing servers need **explicit port statics** — PAT alone can't reach them.
- One public IP + many port-statics = the common DMZ pattern.

### 2.6 Considerations

| Concern | Note |
|---------|------|
| Ports per public IP | ~64k TCP per IP theoretical |
| Overlapping sessions | refcounted ports |
| ALG / FTP | requires inspection or multi-port maps |
| Traceability | add `show ip nat translations` logging |

---

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Port exhaustion (rare) | too many concurrent | show translations count |
| FTP fails | ALG / active mode | statics for data ports |
| VPN breaks | ESP not translatable | NAT transparency |
| Inbound fails | no port static | add ip nat inside source static |
| Wrong interface overload | ACL matches wrong source | access-list |

---

## 5. Exam Traps

- PAT = **`overload`**; it does **port translation**, unlike dynamic NAT.
- `interface ... overload` maps the **outside interface address**.
- Inbound still requires **explicit port statics**.
- ICMP is disambiguated by **identifier**, not port.
- PAT supports **thousands** of flows per public address.
