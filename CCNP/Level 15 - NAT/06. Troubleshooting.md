# NAT Troubleshooting

> **Level 15 · NAT** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

NAT failures usually split into four buckets: **interface marking**, **translation rule**
(ACL/pool/static), **table state**, and **return-path / ALG issues**. A strict flow —
ping inside→outside, check translations, then check return — isolates the broken step.
`show ip nat statistics` is the single fastest diagnosis.

---

## 2. Core Concepts

### 2.1 The flow

| Step | Check | Command |
|------|-------|---------|
| 1 | interfaces in/out | `show ip nat statistics` |
| 2 | rule matches traffic | `debug ip nat` |
| 3 | translation created | `show ip nat translations` |
| 4 | return path reaches | ping outside→inside |
| 5 | ALG / port handling | application level |

### 2.2 Interface marking failures

| Symptom | Cause |
|---------|-------|
| No translation at all | interface not `ip nat inside/outside` |
| Partial NAT | some interfaces marked, others not |
| Reverse direction dead | `inside`/`outside` swapped |

- Both interfaces must be marked correctly; NAT is **direction-aware**.

### 2.3 Translation-rule failures

| Symptom | Cause |
|---------|-------|
| Outbound works, some hosts fail | ACL too narrow |
| All fail | ACL permits nothing |
| Pool exhausted | dynamic NAT without overload |
| Wrong global address | pool/wrong binding |

- Check ACL hits with `show access-lists` counters.

### 2.4 Table and state issues

| Symptom | Cause |
|---------|-------|
| Entry missing | timeout / clear |
| Stale entry | long TCP timeout |
| No entry for ICMP | ICMP ID not translated (ALG) |
| Port conflicts | PAT exhaustion |

- `clear ip nat translation *` resets; stale entries drop sessions.

### 2.5 Return-path and ALG problems

| Symptom | Cause |
|---------|-------|
| Inbound to server fails | missing static / port map |
| FTP data fails | active FTP needs ALG or passive |
| SIP/RTP fails | inspection not enabled |
| Asymmetric routing | return doesn't hit same NAT box |

- ALGs are the classic "ping works, app fails" culprit.

### 2.6 Commands for diagnosis

```text
show ip nat translations
show ip nat translations verbose
show ip nat statistics
show ip nat statistics clear       ! fresh counters
show access-lists
clear ip nat translation *
debug ip nat
debug ip nat detailed
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Nothing translated | interface marking | statistics |
| Partial hosts fail | ACL scope | access-lists counters |
| Exhaustion | dynamic no-overload | pool / overload |
| Inbound dead | no static/port map | translations |
| FTP broken | ALG | inspection / passive |
| Flap | stale entries | clear + timeout |

---

## 5. Exam Traps

- **Interface marking is step zero** — no inside/outside = no NAT.
- Direction: translation depends on `inside`/`outside` labels.
- Dynamic NAT without overload = pool exhaustion risk.
- Inbound always needs a **static or port static** (except static-only designs).
- ALG issues: "ping works, app doesn't".
- `debug ip nat` shows live translations; `statistics` shows counters.
