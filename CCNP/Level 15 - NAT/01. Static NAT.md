# Static NAT

> **Level 15 · NAT** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Static NAT** binds a **fixed private (inside local) IP to a fixed public (inside
global) IP** — a permanent 1:1 mapping. It's how servers behind a NAT router get a stable
address reachable from the outside. Because it's always on, **inbound traffic works
unprompted** (no session to create), and it does **not** consume dynamic pool addresses.

---

## 2. Core Concepts

### 2.1 Terminology (the NAT vocabulary)

| Term | Meaning |
|------|---------|
| Inside local | private IP as seen from inside |
| Inside global | public IP as seen from outside |
| Outside local | peer address as seen from inside |
| Outside global | peer address as seen from outside |

- Static NAT maps **inside local ↔ inside global** permanently.

### 2.2 One-to-one behavior

| Direction | Translation |
|-----------|-------------|
| Outbound (inside→outside) | inside local → inside global |
| Inbound (outside→inside) | inside global → inside local |

- The mapping is **bidirectional** and always active.

### 2.3 Configuration

```text
ip nat inside source static 10.0.0.10 203.0.113.10

interface Gi0/0
 ip nat inside
interface Gi0/1
 ip nat outside
```

- `ip nat inside/outside` on the interfaces **defines the NAT boundary**.
- The static entry is the mapping; inbound connections arrive on the outside interface.

### 2.4 Port-level static NAT (PAT-style publish)

```text
ip nat inside source static tcp 10.0.0.10 80 203.0.113.10 8080
```

- Maps a specific **TCP/UDP port** of one inside host to a port on the public address —
  lets one public IP host many internal servers on different ports.

### 2.5 Static NAT vs others

| Type | Mapping | Inbound |
|------|---------|---------|
| Static | fixed 1:1 | yes, always |
| Dynamic | pool + release | no (from outside) |
| PAT | one public, many lets | only via ports |
| Policy | conditional rules | depends |

- Static is the **only** flavor that guarantees inbound reachability by default.

### 2.6 Verification

```text
show ip nat translations
show ip nat statistics
clear ip nat translation *
```

- Static entries always appear in the translations table.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No translation | interfaces not marked in/out | ip nat inside/outside |
| Inbound fails | wrong direction static | map inside==local |
| Port conflict | same port two servers | vary port mapping |
| Ping works, app fails | application ports not statically mapped | add port entries |
| Address reused | overlapping statics | unique goals |

---

## 5. Exam Traps

- Static NAT = **always-on 1:1**; inbound works with **no session setup**.
- Must mark interfaces `ip nat inside` / `ip nat outside`.
- Port static NAT maps specific ports — enables inbound to several servers.
- Static entries **never time out** (unlike dynamic).
- Order matters: inside source static vs outside source static.
