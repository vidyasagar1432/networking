# Dynamic NAT

> **Level 15 · NAT** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Dynamic NAT** assigns a public address **from a pool** to inside hosts **on demand**,
releasing it when the session ends. It provides many-to-many sharing without permanent
mappings. Unlike static NAT, **inbound initiation fails** — no host owns a fixed public
address. It does **not** do port translation; each active flow consumes one pool address.

---

## 2. Core Concepts

### 2.1 How it works

1. Inside host starts traffic → NAT router picks a free pool address.
2. Translation entry created (inside local ↔ inside global).
3. On timeout/idle the entry expires → pool address freed.

- **Pool exhaustion** = no free addresses → outbound traffic dropped (no overflow to
  PAT).

### 2.2 Configuration

```text
access-list 10 permit 10.0.0.0 0.0.0.255

ip nat pool PUBLIC 203.0.113.10 203.0.113.20 netmask 255.255.255.0
ip nat inside source list 10 pool PUBLIC

interface Gi0/0
 ip nat inside
interface Gi0/1
 ip nat outside
```

- ACL selects **which inside addresses** are eligible.
- Pool defines the public range.
- ACL + pool = the translation rule.

### 2.3 Pool keywords

| Keyword | Meaning |
|---------|---------|
| `netmask` | subnet mask of pool |
| `type rotary` | load-balance across pool (servers) |
| `add-route` | install routes for pool (IOS-XR) |
| overload | not used here — that's PAT (note 03) |

- Without `overload`, each host = one pool address at a time.

### 2.4 Behavior differences

| Aspect | Static | Dynamic |
|--------|--------|---------|
| Mapping | fixed | temporary |
| Inbound | yes | no |
| Pool | none | used |
| Timeout | never | yes (idle) |
| Port translation | optional | none |

### 2.5 Timing and timeouts

| Timer | Default |
|-------|---------|
| `ip nat translation timeout` | 24 h |
| udp | 5 min |
| tcp | 24 h |

- Idle flows time out, freeing pool addresses.

### 2.6 Verification

```text
show ip nat translations
show ip nat statistics          ! total translations, pool hits/misses
clear ip nat translation *
```

- Pool exhaustion shows in `statistics` as misses; hosts time out waiting.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Outbound fails | pool exhausted | show ip nat statistics |
| No translation | ACL doesn't match | ACL permit |
| Hosts share wrongly | overload accidentally | remove overload |
| Inbound dead | dynamic design | use static/PAT |
| Entry never expires | long timeout | translation timeout |

---

## 5. Exam Traps

- Dynamic NAT = **pool-based, on-demand, released on timeout**.
- **No inbound initiation** — it's outbound-only reachability.
- ACL defines inside sources; pool defines public addresses.
- **`overload` converts to PAT** (note 03).
- Exhaustion drops outbound traffic — unlike PAT which folds to ports.
