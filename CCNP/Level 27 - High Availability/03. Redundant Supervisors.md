# Redundant Supervisors

> **Level 27 · High Availability** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Redundant supervisors** protect a chassis switch by running a **standby supervisor**
in the same or second slot. Modes define how much state is kept: **RPR (no state)**,
**RPR+ (startup config shared)**, and **SSO (full sync)**. The exam tests redundancy
modes and how a switchover behaves.

---

## 2. Core Concepts

### 2.1 Why redundant supervisors

| Benefit | Detail |
|---------|--------|
| Chassis HA | second supervisor |
| Fast failover | hot standby |
| Shared config | sync configs |
| Control continuity | SSO |

- A second supervisor = **brain redundancy**.

### 2.2 Redundancy modes

| Mode | State on standby | Failover |
|------|------------------|----------|
| RPR | none / cold | slow, reload |
| RPR+ | shared config | medium |
| SSO | full sync | fast, zero drop |

- **SSO = highest availability.**

### 2.3 RPR explained

| Item | Detail |
|------|--------|
| Standby | boots for failover |
| Config | reloaded from NVRAM/Flash |
| State | NO sync |
| Switchover | forwarding drop |
| Use | basic HA |

- RPR = **swap the brain, reload the box**.

### 2.4 RPR+ explained

| Item | Detail |
|------|--------|
| Config | shared |
| Startup | same image |
| State | minimal |
| Switchover | faster than RPR |
| Use | mid-tier |

- RPR+ shares **startup config + image**.

### 2.5 SSO recap

| Item | Detail |
|------|--------|
| State | control-plane sync |
| Forwarding | unaffected |
| Failover | seamless |
| Mode | `mode sso` |
| Use | enterprise spine |

- **SSO is the production choice.**

### 2.6 Choosing the mode

| Requirement | Mode |
|-------------|------|
| Minimal HA | RPR |
| Config share | RPR+ |
| Zero-loss | SSO |
| Legacy | RPR |

- Match **mode to the HA budget**.

## 5. Exam Traps

- Modes ordered: **RPR < RPR+ < SSO** (capability).
- RPR = **no state + reload**; RPR+ = shared config.
- **SSO = full sync, zero-loss failover**.
- `mode <name>` under `redundancy`.
- Dual supervisor needed for all.
