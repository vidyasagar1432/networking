# Gateway Redundancy

> **Level 27 · High Availability** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Gateway redundancy** keeps the **default gateway (FHRP)** available by sharing a
**virtual IP** among routers. Protocols: **HSRP (Cisco-proprietary)**, **VRRP
(standard)**, and **GLBP (load-balancing)**. The exam tests protocol differences,
preemption, and the virtual MAC.

---

## 2. Core Concepts

### 2.1 The FHRP role

| Component | Role |
|-----------|------|
| Virtual IP | shared gateway |
| Active | forwards |
| Standby | watches |
| Virtual MAC | used by hosts |
| Failover | automatic |

- Hosts point at a **virtual IP**, not a single router.

### 2.2 Protocols compared

| Protocol | Vendor | Default | Priority |
|----------|--------|---------|----------|
| HSRP | Cisco | 100 | larger |
| VRRP | IETF | 100 | larger |
| GLBP | Cisco | 100 | AVG/AVF |

- **HSRP/VRRP active-passive; GLBP = load-balanced.**

### 2.3 HSRP details

| Item | Detail |
|------|--------|
| Group | 0–4095 |
| Virtual MAC | 0000.0c07.acXX |
| Hello | UDP 1985 |
| Preempt | `preempt` |
| Priority | higher wins |

- HSRPv2 uses **UDP 1985**, group field wider.

### 2.4 VRRP vs HSRP

| Aspect | HSRP | VRRP |
|--------|------|------|
| Standard | Cisco | IETF |
| Group IP | not required | own IP |
| State names | Active/Standby | Master/Backup |
| Hello | UDP 1985 | 112 |
| Virtual MAC | 0c07.acxx | 0000.5e0001XX |

- **VRRP states = Master/Backup; HSRP = Active/Standby.**

### 2.5 GLBP

| Item | Detail |
|------|--------|
| AVG | virtual gateway |
| AVF | virtual forwarders |
| Load | per-host |
| MACs | unique per AVF |
| Use | both members active |

- GLBP = **active-active load sharing**.

### 2.6 Configuration knob

| Command | Meaning |
|---------|---------|
| `standby <g> ip <VIP>` | HSRP VIP |
| `standby <g> priority <n>` | election |
| `standby <g> preempt` | take over |
| `vrrp <g> ip <VIP>` | VRRP |
| `glbp <g> ip <VIP>` | GLBP |

- Election = **priority, then higher IP wins**.

## 3. Configuration / Commands

```text
interface Vlan10
 standby 1 ip 192.168.1.254
 standby 1 priority 110
 standby 1 preempt
show standby brief
show standby
show vrrp brief
show glbp
```

|---------|---------|

## 5. Exam Traps

- **HSRP/VRRP = active-passive; GLBP = load-sharing.**
- States: **HSRP Active/Standby; VRRP Master/Backup.**
- Virtual MAC: **HSRP 0c07.acXX; VRRP 0000.5e0001XX.**
- Prio: **higher wins; tie → higher IP.**
- UDP 1985 (HSRP) vs 112 (VRRP).
