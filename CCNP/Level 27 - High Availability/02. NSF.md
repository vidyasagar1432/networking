# NSF

> **Level 27 · High Availability** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**NSF (Nonstop Forwarding)** lets a router continue forwarding traffic while its
**control plane recovers** during a supervisor/route-processor switchover. It works with
**SSO**, and peers see it via **NSF capabilities** — forwarding continues while routing
state is rebuilt. **NSF/SSO** is the unified HA story.

---

## 2. Core Concepts

### 2.1 What NSF does

| Item | Detail |
|------|--------|
| Forwarding | continues |
| Control plane | rebooting/rebuilding |
| Peer awareness | NSF capability |
| Partner cooperation | graceful restart |
| Goal | zero traffic loss |

- NSF keeps **packets flowing** during the rebuild.

### 2.2 NSF + SSO

| Component | Role |
|-----------|------|
| SSO | keeps control state |
| NSF | continues forwarding |
| Routing | rebuilds gracefully |
| Result | seamless failover |

- **SSO preserves state; NSF preserves forwarding.**

### 2.3 Graceful restart

| Step | Detail |
|------|--------|
| Capability | announcements |
| Restart | peer unaware of drop |
| Reconstruct | re-learn routes |
| FIB/CEF | maintained independent |
| Convergence | no full flap |

- **CEF keeps forwarding** from the FIB during restart.

### 2.4 NSF awareness (helping router)

| Aspect | Detail |
|--------|--------|
| Detects NSF-capable | hello/graceful |
| Continues forwarding | to disabled peer |
| Bridges restart | avoids flap |
| Final convergence | after rebuild |

- Neighbors **hold state** instead of flapping routes.

### 2.5 Configuration

| Command | Meaning |
|---------|---------|
| `mode sso` | prerequisite |
| `router ospf 1` | routing instance |
| `nsf` | enable OSPF NSF |
| `nsf cisco` | Cisco-specific |
| `nsf ietf` | IETF standard |
| `router bgp` → `bgp graceful-restart` | BGP variant |

- **`nsf` under the routing protocol** enables it.

### 2.6 NSF vs GR (BGP)

| Aspect | NSF | BGP GR |
|--------|-----|--------|
| Protocol | OSPF/EIGRP | BGP |
| Curator | local | peer |
| Standard | Cisco/IETF | RFC 4724 |
| Goal | same | same |

- Different implementations, **same zero-loss goal**.

## 5. Exam Traps

- **NSF = forwarding continues** during control rebuild.
- Requires **SSO** as foundation.
- **CEF/FIB independent** of control plane.
- Config: **`nsf` under routing** + `bgp graceful-restart`.
- Peers must be **NSF-aware** to cooperate.
