# SSO

> **Level 27 · High Availability** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SSO (Stateful Switchover)** keeps **control-plane state** synchronized between
active and standby supervisors so a **supervisor switchover causes no forwarding
interruption**. Cisco IOS-XE uses `mode sso`; the two RPs stay synchronized via
**bulk sync** + **incremental SYNC**. **NSF/SSO** is the classic HA pairing.

---

## 2. Core Concepts

### 2.1 What SSO does

| Item | Detail |
|------|--------|
| State | control-plane |
| Sync | active → standby |
| Switchover | zero control loss |
| Forwarding | unaffected |
| Pairs | dual supervisors |

- SSO = **seamless control-plane failover**.

### 2.2 The two supervisors

| Role | Duty |
|------|------|
| Active | runs tasks |
| Standby | hot synced |
| Sync type | bulk + incremental |
| Failover | promoted |

- Standby holds a **hot copy** of the active's state.

### 2.3 Sync phases

| Phase | Detail |
|-------|--------|
| Bulk sync | full state at start |
| Incremental | ongoing updates |
| SYNC | periodic refresh |
| Switchover | takeover on fault |

- State stays **current between the pair**.

### 2.4 Configuration

| Command | Meaning |
|---------|---------|
| `redundancy` | enter redundancy mode |
| `mode sso` | enable SSO |
| `main-cpu` | processor config |
| `state ... standby` | sync commands |

- Enable SSO with **`mode sso`** under redundancy.

### 2.5 Monitoring

| Command | Use |
|---------|-----|
| `show redundancy states` | active/standby |
| `show redundancy sso` | SSO mode |
| `show redundancy switchover` | history |
| `redundancy force-switchover` | manual test |

- Verify with **`show redundancy`**.

### 2.6 SSO vs RPR

| Aspect | RPR | SSO |
|--------|-----|-----|
| Standby initializes | yes | no |
| Sync state | no | yes |
| Switchover speed | slow | fast |
| Forwarding impact | drop | none |

- **SSO = true stateful; RPR = cold standby.**

## 5. Exam Traps

- **SSO = control-plane state sync**; forwarding unaffected.
- Requires **dual supervisors** with `mode sso`.
- Two sync types: **bulk + incremental**.
- **NSF + SSO** = zero-loss routing continuity (note 02).
- `show redundancy states` = validation command.
