# BPDU

> **Level 08 · STP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

A **Bridge Protocol Data Unit (BPDU)** is the control message switches exchange to run
Spanning Tree — carrying root identity, path costs, sender identity, and timers. STP
decisions (root election, root/designated port choice) and most troubleshooting all reduce
to reading BPDU fields. BPDUs live in the **control plane** — they are *slow* protocol
traffic, not user data.

---

## 2. Core Concepts

### 2.1 BPDU types

| Type | Used by | Purpose |
|------|---------|---------|
| **Configuration BPDU (CBPDU)** | STP/RSTP | elect root & build tree (standard) |
| **TCN (Topology Change Notification)** | classic STP | notify root of topology change |
| **RSTP BPDU (version 2)** | RSTP/Rapid-PVST+ | flag bits encode roles/agreement |

- RSTP BPDU is essentially the classic one **plus a flag byte** carrying the
  proposal/agreement bits and the sender's current role/state.

### 2.2 Key fields in a Configuration BPDU

| Field | Meaning |
|-------|---------|
| Protocol ID + Version + Type | identifies 802.1D / RSTP |
| Flags (RSTP) | TC, TCA, proposal, agreement, role, learning, forwarding |
| **Root Bridge ID** | priority + sys ID + MAC |
| **Root Path Cost** | cost to reach root |
| **Sender Bridge ID** | who's sending |
| **Sender Port ID** | originating port |
| Max Age / Hello / Forward Delay | timer values |
| Message Age | how old the BPDU is since root originated it |

### 2.3 BPDU timing & forwarding

- **Hello timer 2 s** — root sends; non-roots relay toward leaves (they don't originate).
- BPDUs flow from the root outward; every switch relays.
- Classic 802.1D: BPDUs are sent on **non-blocking** ports; blocking ports **receive but
  do not send** (they still monitor).
- **On 802.1Q trunks with PVST+**: native-VLAN BPDUs ride **untagged**, non-native-VLAN
  BPDUs ride **tagged** (this distinguishes per-VLAN instances on the trunk).

### 2.4 Reading BPDUs for root election / decision

The comparison applied to every received BPDU, in order:

1. **Root Bridge ID** — lowest wins (root election).
2. **Root Path Cost** — lower is better (root-port selection).
3. **Sender Bridge ID** — lower wins (designated-port selection).
4. **Sender Port ID** — lower wins (final tie-break).

### 2.5 TCN & topology-change window

- Classic 802.1D: a switch detecting a topology change sends **TCN** toward the root;
  the root sets **TC** in its BPDUs; all switches shorten MAC aging to **~15 s** while a
  "topology change window" is active.
- RSTP folds this into its **flag bits** — no separate TCN BPDU needed.

### 2.6 BPDU & security / protection

| Feature | Trigger | Outcome |
|---------|---------|---------|
| **BPDU Guard** | ANY BPDU on a PortFast/edge port | errdisable (note 11) |
| **BPDU Filter** | configured | ignore/suppress BPDUs entirely (risky) |
| **Root Guard** | superior root BPDU | root-inconsistent (note 12) |
| **Loop Guard** | BPDU loss on blocked port | loop-inconsistent (note 13) |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Root always unexpected switch | a lower-ID BPDU arriving from it | inspect Root ID in BPDUs |
| Port errdisabled after plug-in | BPDU Guard hit a rogue BPDU | `show interfaces status` |
| Root-inconsistent port | Root Guard blocked superior BPDU | `show spanning-tree inconsistentports` |
| Loop after silent link loss | BPDUs stopped but port went forwarding | Loop Guard / UDLD (note 13) |
| Per-VLAN STP broken on trunk | native VLAN mismatch | `show interfaces trunk`, native match |

## 5. Exam Traps

- **Blocking ports still RECEIVE BPDUs** — they monitor for better paths.
- **BPDU is control traffic**, not user data.
- **Timers: Hello 2 s, Max Age 20 s, Forward Delay 15 s.**
- **Root originates; non-roots relay** — tracing question staple.
- **TCN is classic-STP; RSTP folds topology change into flags.**
- **PVST+ trunking**: native VLAN BPDUs untagged; non-native tagged.
- **BPDU Guard vs Filter** — guard ERRDisables on receipt; filter ignores BPDUs (both
  usually paired with PortFast).
