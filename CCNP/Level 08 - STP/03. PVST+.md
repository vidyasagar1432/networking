# PVST+ (Per-VLAN Spanning Tree +)

> **Level 08 · STP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**PVST+** runs **one Spanning Tree instance per VLAN** over 802.1Q trunks (Cisco).
Each VLAN elects its own root and can use different paths — enabling **load-balancing
per VLAN** and per-VLAN tuning. It's classic STP logic × N VLANs.

---

## 2. Core Concepts

### 2.1 One tree per VLAN
- Switches run a separate STP instance for **each VLAN** (Hello, root, cost all per VLAN).
- A port can be **Forwarding in VLAN 10 and Blocking in VLAN 20** — path diversity.
- BPDUs are tagged per VLAN (they ride the trunk with the VLAN ID).

### 2.2 How it differs from classic STP
| | Classic 802.1D | PVST+ |
|--|----------------|-------|
| Instances | 1 (all VLANs) | **1 per VLAN** |
| Failed loads | all VLANs same path | per-VLAN choices |
| Root | global | per-VLAN |
| Trunk BPDUs | untagged/native | tagged by VLAN |
| Cisco | supports | default (older maps) |

### 2.3 Extended System ID (the detail)
- The **12-bit system ID (VLAN number)** is folded into the bridge-priority field →
  each VLAN's Bridge ID is unique (`priority< 4096*vlan` + MAC).
- Effective: you can't have a priority lower than VLAN number (÷4096 boundary).

### 2.4 Load-balancing example
- Switch A: **root for VLAN 10,20**; Switch B: **root for VLAN 30,40**.
- Uplinks: Gi0/23 forwards 10/20, hai blocks 30/40 → uses both trunks.

### 2.5 PVST+ vs Rapid PVST+ (next note)
- PVST+ = **802.1D logic**, one instance per VLAN — **slow** (50 s).
- **Rapid PVST+** = RSTP per VLAN — **fast** (1-3 s). Modern IOS default is rapid-pvst.

## 3. Configuration / Commands

```text
spanning-tree mode pvst              # (or pvst; default older)
! per-VLAN root control:
spanning-tree vlan 10 priority 4096
spanning-tree vlan 20 priority 8192

show spanning-tree summary
show spanning-tree vlan 10
show spanning-tree vlan 20 bridge
```

---

## 4. Exam Traps

- **PVST+ ≠ Rapid PVST+** — one is 802.1D (slow), the other RSTP (fast). Classic trap.
- **PVST+ lets VLANs load-balance** by alternate roots — that's its headline.
- **BPDUs are VLAN-tagged** in PVST+.
- **System-ID consumes 12 bits of priority** — affects the "priority must be multiple
  of 4096" rule.
- **More instances = more CPU/BPDU** — that's why huge VLAN fleets may prefer MST
  (Level 08 note 05).
