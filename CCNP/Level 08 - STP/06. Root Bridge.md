# Root Bridge

> **Level 08 · STP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

The **root bridge** is the switch that serves as the **center of the spanning tree** —
every other switch computes its path to the root, and loops are blocked accordingly.
Elected by **lowest Bridge ID**, it anchors the whole topology (per VLAN in PVST+).

---

## 2. Core Concepts

### 2.1 Election rule — lowest bridge ID
```
Bridge ID = Bridge Priority (2B) + Extended System ID/VLAN + Switch/Sys MAC (6B)
Winner = lowest priority first; tie = lowest MAC
```
- Default priority **32768**.
- Intended root: set priority low (`priority 4096` or `root primary`).

### 2.2 How the election spreads (BPDU flood)
- Every switch sends BPDUs claiming its Bridge ID as root; switches adopt the lowest.
- Eventually all converge to the **one root**; others see root in their BPDU.
- Root sends BPDUs; non-roots forward/relay (they don't originate root claims).

### 2.3 What being root means
| Attribute | Root | Non-root |
|-----------|------|----------|
| Root port | none (it IS root) | one toward root |
| Autos | all ports designated (usually Forwarding) | may have blocking |
| BPDU source | originates | relays |
| Priority | lowest in domain | higher |
| Placement | should be the **fastest/central** switch | rest |
- Best practice: place root at **core/distribution**, not access edge.

### 2.4 Root in per-VLAN (PVST+/Rapid PVST+)
- Root is elected **per VLAN** → you can make different switches root for different
  VLANs to distribute load (Level 08 note 03/04).

### 2.5 Root misplacement problems
| Symptom | Cause |
|---------|-------|
| High links blocked oddly | another switch elected root |
| Slow traffic (all via one cheap switch) | root where it should not be |
| Flapping | portable root (MAC moves) |
| Unexpected | no root priority set, MAC decided |
- Proactive fixes: set priority low on core, `root primary/secondary`, verify with
  `show spanning-tree`.

## 3. Configuration / Commands

```text
spanning-tree vlan 10 priority 4096        # hard-set
spanning-tree vlan 10 root primary         # helper (sets 24576/4096-ish)
spanning-tree vlan 10 root secondary       # backup (28672)

show spanning-tree                         # "Root ID ... Root: This bridge"
show spanning-tree vlan 10 bridge
show spanning-tree root
```

---

## 4. Exam Traps

- **Root = LOWEST bridge ID**, not highest, not MAC alone.
- **Tie = lowest MAC**, after priority.
- **Root has no root port** — all its ports are designated (usually forwarding).
- **Per VLAN = per-VLAN root** in PVST flavors.
- **Root BPDUs originate from root**; non-roots relay — a tracing question staple.
- **`root primary/secondary` is a macro**, not a reserved config.
