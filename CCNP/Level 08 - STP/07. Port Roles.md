# STP Port Roles

> **Level 08 · STP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Port roles** define *what a port does* in the spanning tree: **Root**, **Designated**,
**Alternate** (RSTP), **Backup** (RSTP), or **Disabled**. They are separate from **port
states** (Blocking/Listening/Learning/Forwarding) — state says what the port is *doing*,
role says what the port *is for*. Getting roles right is essential to read any
`show spanning-tree` output (the **Role** and **State** columns).

---

## 2. Core Concepts

### 2.1 The roles (who elects / how computed)

| Role | Meaning | Who has it |
|------|---------|-----------|
| **Root port** | best path to root bridge | every **non-root** switch (one) |
| **Designated port** | the segment's serving port | one per segment (root or best switch) |
| **Alternate port** (RSTP) | backup for the root port (blocked) | non-root switch, ready |
| **Backup port** (RSTP) | redundant path to the **same segment** | rare |
| **Disabled** | admin-shutdown / down | any |

- **Root bridge**: all ports are Designated (auto); it has **no root port**.

### 2.2 How a switch picks its Root Port

For each non-root switch, choose the port that minimizes, **in order**:

1. **Root Bridge ID** (which root is being claimed)
2. **Root Path Cost** (cost to reach that root)
3. **Sender Bridge ID** (neighbor's bridge ID)
4. **Sender Port ID** (neighbor's port)

The winning port = **Root Port**; the next-best port = **Alternate** (RSTP) — ready to
take over instantly.

### 2.3 How each segment picks a Designated Port

Per segment, the switch with the **best (lowest) bridge-ID/path-cost claim** supplies the
Designated Port. That port is Forwarding; the peer's port on that segment becomes the
**non-designated** side (blocking in 802.1D; Alternate/Backup in RSTP).

### 2.4 Role vs State (the constant exam trap)

| | Role | State |
|--|------|-------|
| What | *purpose* of port in tree | *operational* phase |
| Examples | Root, Designated, Alternate, Backup | Blocking, Listening, Learning, Forwarding |
| Persistence | stable after convergence | changes during convergence |
| Shown as | `Role` column | `State` column |

- A Forwarding port is *usually* Root/Designated; a Discarding port is *usually*
  Alternate/Backup. Read **both** columns in `show spanning-tree`.

### 2.5 Role changes & convergence (failure cases)

| Event | What happens |
|-------|--------------|
| **Root port fails** | **Alternate port promotes** to Root Port (RSTP: instant/near-instant) |
| **Designated port fails** | segment waits for new designated election |
| Link up with new path | proposal/agreement (RSTP) or timer (802.1D) |
| Root bridge changes | all non-root switches recompute roles |

- UplinkFast-style failover is **built into RSTP** via Alternate/Backup (no extra config).

## 3. Configuration / Commands

```text
show spanning-tree                       # Role/State columns per port
show spanning-tree interface Gi0/1
show spanning-tree vlan 10
show spanning-tree active
```

You usually do **not** configure roles directly — you influence them:

```text
spanning-tree vlan 10 root primary       # make dist switch root → its ports designated
interface Gi0/1
 spanning-tree cost 4                    # lower cost → this port becomes root port
 spanning-tree port-priority 32          # lower port id wins tie-breaks
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Two ports both forwarding on a segment | designated election misread / duplex issue | `show spanning-tree interface` |
| Root port not on the cheap link | sender cost/port-priority values | compare BPDU fields |
| Alternate never promotes | root port failure but guard/react issues | verify link + `spanning-tree guard` |
| Wrong port chosen as root port | per-VLAN cost differences | `spanning-tree vlan N cost` |

---

## 5. Exam Traps

- **Roles are purpose, states are phases** — never label a Blocking port "root."
- **Root bridge has no Root Port** — all Designated.
- **Root Port exists only on non-root switches.**
- **Each segment has exactly one Designated port.**
- **Alternate port = the standing backup** that converges fastest (RSTP).
- **Backup port** duplicates the *same segment*; **Alternate** backs the *root path*.
- **Selection order: root ID → path cost → sender bridge ID → sender port ID.**

## 6. Quick Review Table

| Role | Applies to | State usually |
|------|-----------|---------------|
| Root | every non-root switch (one) | Forwarding |
| Designated | one per segment | Forwarding |
| Alternate | non-root backup (RSTP) | Discarding |
| Backup | same-segment secondary (RSTP) | Discarding |
| Disabled | admin down | — |
| Root bridge | none (all designated) | Forwarding |
| Trap | role ≠ state | read both columns |
