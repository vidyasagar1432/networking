# RSTP (Rapid Spanning Tree Protocol)

> **Level 08 · STP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**RSTP (IEEE 802.1w)** is the fast-evolution of STP: **sub-second convergence** (≈1–3 s
instead of 30–50 s) using **explicit port roles/agreement (handshake)** instead of
timers. It's backward-compatible with classic STP and is the default today on most
platforms (rapid-pvst on Cisco).

---

## 2. Core Concepts

### 2.1 The three big changes
| Change | Classic STP | RSTP |
|--------|-------------|------|
| Notification | rely on MaxAge/ForwardDelay | **explicit RSTP BPDU** (Type 2, flags) |
| Port states | 5 | **3** (Discarding/Learning/Forwarding) |
| Roles | Root/Designated/none | Root/Designated/**Alternate/Backup** |

### 2.2 Port states simplified
| State | Forwards data | Learns MAC | RSTP |
|-------|---------------|------------|------|
| **Discarding** | no | no | blocking+listening merged |
| Learning | no | yes | — |
| Forwarding | yes | yes | — |
- No separate "listening" state.

### 2.3 Port roles (RSTP adds blockage intelligence)
| Role | Purpose |
|------|---------|
| **Root port** | best path to root (each non-root switch) |
| **Designated port** | best port of the segment's designated switch |
| **Alternate port** | backup to root path (discarding, ready) |
| **Backup port** | redundant path to the same segment (rare) |
- Alternate/backup are ready instantly → fast failover.

### 2.4 How RSTP converges fast (agreement/proposal)
- A designated port sends a **Proposal**, neighbor replies **Agreement**; the links
  go straight to Forwarding — no ForwardDelay wait.
- **Edge ports** (hosts) go to Forwarding immediately (PortFast baked in for edge).
- RSTP BPDU is sent every **hello 2 s** (like STP) but carries fresh flags; expired
  3× hello → immediate link-down detection (no MaxAge liturgy).

### 2.5 RSTP timers vs STP
| Timer | Classic | RSTP note |
|-------|---------|-----------|
| Hello | 2 s | 2 s (kept) |
| MaxAge | 20 s | mostly irrelevant; link-down detected fast |
| ForwardDelay | 15 s | only used (rarely) for transitions to legacy |
- Backward compatible: RSTP port talking to classic STP downgrades behavior to STP rules.

### 2.6 RSTP vs Rapid PVST+
- **RSTP** — single spanning tree instance for ALL VLANs (like STP).
- **Rapid PVST+** — Cisco: RSTP per VLAN (Level 08 note 04). Cisco default on IOS switches.

## 3. Configuration / Commands

```text
# Enable RSTP globally (single instance) or per-VLAN flavor
spanning-tree mode rapid-pvst         # Cisco per-VLAN RSTP (typical)
# or spanning-tree mode rstp          # single-instance RSTP

# Edge ports fast (RSTP native)
interface Gi0/1
 spanning-tree portfast

show spanning-tree
show spanning-tree vlan 10 | include "Role | State"
```

---

## 4. Exam Traps

- **RSTP forward delay exists in the config but is not the driver** — agreement/proposal
  replaces it in RSTP-to-RSTP links.
- **Alternate port** is the "ready backup" — has the fastest failover.
- **3 states, not 5** — "listening" state is gone (merged into discard).
- **BPDU version** — RSTP sends version-2 BPDU with flag bits; classic STP ignores.
- **PortFast/edge ports go Forwarding instantly** — that's why host ports converge immediately.
- **Don't say "RSTP is per-VLAN"** — that's Rapid PVST+ (Cisco). RSTP itself is one instance.
