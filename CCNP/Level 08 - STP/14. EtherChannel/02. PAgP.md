# EtherChannel — PAgP

> **Level 08 · STP / EtherChannel** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**PAgP (Port Aggregation Protocol)** is Cisco's **proprietary** EtherChannel
negotiation — for **Cisco-to-Cisco** links only. Modes `desirable` / `auto` are the
PAgP lexicon. It is **legacy**: LACP (IEEE 802.3ad) is the modern, multi-vendor
default — but the PAgP **mode matrix** still appears on the exam.

---

## 2. Why PAgP (and when it's a trap)

| Why you'd see it | Why it's legacy |
|------------------|-----------------|
| older Cisco field gear / exams still test it | proprietary → **no interop** with non-Cisco |
| existing install base configured 2000s-era | LACP is standard + supported everywhere |

The exam truth: **PAgP is Cisco-only** — for a non-Cisco peer the answer is LACP (or
`on` static).

---

## 3. Core Concepts

### 3.1 PAgP modes (negotiation matrix)

| Mode | Talks | Forms bundle with |
|------|-------|-------------------|
| **desirable** | actively solicits | desirable / auto |
| **auto** | passive, responds | desirable |
| **on** | no negotiation | on (both ends, static) |
- `desirable ↔ desirable` = YES; `desirable ↔ auto` = YES; `auto ↔ auto` = NO.
- **`on` is not PAgP** — it's forced/static (requires `on` on both sides).

### 3.2 PAgP vs LACP (must-memorize)

| Aspect | PAgP | LACP |
|--------|------|------|
| Vendor | **Cisco proprietary** | IEEE 802.3ad / 802.1AX |
| Modes | desirable / auto | active / passive |
| Interop | Cisco-only | multi-vendor |
| PDU | PAgP | LACP (Slow Protocol) |
| Modern answer | legacy | default |
| `show` flag | `S` (PAgP) | `P` (LACP) |

### 3.3 Member requirements (same as LACP)
- Identical **speed + duplex**, same **VLAN/trunk config**, same physical type.
- Config applied on `Port-channelN` (VLANs/trunk); speed/duplex on the members.
- If a member mismatches → **not bundled** (SA/individually-discarding).

## 4. Configuration / Commands

```text
! Cisco-to-Cisco
interface GigabitEthernet0/1
 channel-group 1 mode desirable
interface GigabitEthernet0/2
 channel-group 1 mode desirable

interface Port-channel1
 description PAgP bundle to SW-CORE
 switchport mode trunk
 switchport trunk allowed vlan 10,20

! Verify
show etherchannel summary             # SU (in use), S = PAgP negotiated
show etherchannel 1 detail
show pagp neighbor
show pagp counters
```

---

## 5. Exam Traps

- **PAgP = Cisco-only** — non-Cisco peer → LACP (or `on`).
- **`auto` needs the other side `desirable`** — auto+auto never forms.
- **`on` is static, not PAgP** — it needs `on` on both ends and no PDU exchange.
- **Don't mix PAgP with LACP modes** on the same bundle (both ends must agree on
  protocol family).
- **`S` flag = PAgP, `P` = LACP**, `-` = static `on`, `D` = down.
- The 30 s / 1 s **LACP timing does not apply to PAgP** — PAgP hello is ~1 s.
