# PortFast

> **Level 08 · STP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**PortFast** makes an **edge port** (one connecting to a host/endpoint, not another
switch) go **straight to Forwarding** — skipping the 30–50 s Blocking→Listening→Learning
delay. Hosts get instant network access after reboot/plug-in. In RSTP terms, PortFast =
**edge port** (the "E" in show output). PortFast **does not disable STP** — the port still
has STP roles; it just enters Forwarding immediately.

---

## 2. Core Concepts

### 2.1 What PortFast is for (and NOT for)

| Use | Do NOT |
|-----|--------|
| Hosts/PCs, printers, servers | switch-to-switch links (loop risk!) |
| IP phones, cameras, APs (if single uplink) | any port where another switch could attach |
| Access endpoints | trunk to another switch **unless** guarded |

- Because PortFast assumes "no switch there," a loop could slip through if one appears —
  always pair with **BPDU Guard** (Level 08 note 11).

### 2.2 What it actually changes

| Without PortFast | With PortFast |
|------------------|---------------|
| 30+ s listening/learning | instant forwarding |
| Port starts in Blocking | goes Forwarding immediately |
| — | skips STP timers on this port |

- It does **not** turn off STP — roles are still computed; the transition delay is skipped.

### 2.3 Config & the edge-port concept

```text
interface Gi0/1
 switchport mode access
 spanning-tree portfast
```

- In RSTP/Rapid-PVST+: PortFast = **edge port**; the RSTP handshake is skipped on it.
- Global default: `spanning-tree portfast default` (applies to all access ports — but
  NOT trunks). `spanning-tree portfast` can also be applied on a trunk (`portfast trunk`)
  — only with explicit intent and protection.

### 2.4 PortFast + BPDU Guard (the standard pair)

| Scenario | Result with PortFast only | Result with PortFast + BPDU Guard |
|----------|---------------------------|-----------------------------------|
| Rogue switch plugged in | possible brief loop | port **errdisabled instantly** |
| Normal host | instant forwarding | instant forwarding, unaffected |

- BPDU Guard (note 11): any BPDU received on the edge port → errdisable, no loop.
- Many Cisco defaults auto-pair them (`spanning-tree portfast bpduguard default`).

### 2.5 PortFast + BPDU Filter (don't confuse)

| | PortFast | BPDU Filter |
|--|----------|-------------|
| Function | skip transition delay | **ignore all BPDUs** (send and receive) |
| Pairing | safe with BPDU Guard | risky — can hide a loop |
| STP still runs | yes | effectively bypassed on the port |

### 2.6 PortFast vs legacy UplinkFast

| | PortFast | UplinkFast (legacy) |
|--|----------|---------------------|
| Whom | edge (endpoint) ports | uplink ports for fast failover |
| Effect | instant forwarding on link-up | fast root-port failover on link-down |

- In RSTP/Rapid PVST+, both behaviors are native (edge + alternate) — no legacy config.

## 3. Configuration / Commands

```text
interface GigabitEthernet0/1
 switchport mode access
 spanning-tree portfast
 spanning-tree bpduguard enable      # safer edge

! Global default (all access ports)
spanning-tree portfast default
spanning-tree portfast bpduguard default

show spanning-tree interface Gi0/1
show running-config interface gi0/1 | include portfast
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| Host still waits 30 s | PortFast missing / mode not applied | `spanning-tree portfast` |
| Port flapping on/off | PortFast on a link that receives BPDUs without guard | add BPDU Guard |
| Loop despite PortFast | edge port connected to a switch | remove PortFast or guard it |
| Access port shows "edge" never | global default skips trunks | explicit per-port config |

---

## 5. Exam Traps

- **PortFast ≠ STP off** — STP still runs; only the transition delay is skipped.
- **Never PortFast a populated trunk to another switch** (loop risk) unless BPDU Guard.
- **PortFast + BPDU Guard = the correct edge-port answer** for host ports.
- **In RSTP, edge ports are effectively PortFast** (native fast transition).
- **Don't confuse with BPDU Filter** (ignores BPDUs entirely — riskier).
- **`spanning-tree portfast default`** skips trunks — safest global option.
