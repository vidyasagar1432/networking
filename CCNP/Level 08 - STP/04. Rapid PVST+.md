# Rapid PVST+

> **Level 08 · STP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Rapid PVST+** = **RSTP running per VLAN** (Cisco). It combines RSTP's **fast
convergence** with PVST+'s **per-VLAN instances** — the default STP mode on modern
Catalyst switches and the exam's usual expectation.

---

## 2. Core Concepts

### 2.1 Composition
```
Rapid PVST+ = RSTP (802.1w) mechanics + PVST+ per-VLAN instances
```
- Separate RSTP tree per VLAN, with fast proposal/agreement per instance.
- Default `spanning-tree mode rapid-pvst` on IOS/Catalyst.

### 2.2 Why it wins
| Need | Rapid PVST+ |
|------|-------------|
| Fast convergence to edge | yes (agreement) |
| Per-VLAN control | yes (instances) |
| Load-balance across uplinks | yes (root per VLAN) |
| Backward to classic neighbor | degrades to STP per VLAN |
- One trade-off: **instance count** grows with VLAN count (CPU/BPDU cost); huge scale
  → consider **MST** (note 05).

### 2.3 Operational benefits day-to-day
- Edge ports (hosts/trunks with portfast) transition **instantly**.
- Link loss detected in **3× hello (6 s)** rather than MaxAge 20 s.
- New links with proposal/agreement go Forwarding immediately — no ForwardDelay.

### 2.4 Tuning per VLAN (same as PVST+)
- Root per VLAN: `spanning-tree vlan 10 priority 4096` (or `root primary`).
- Path cost per VLAN: set on interface for specific VLANs.
- Load balance: roots differ per VLAN across two distribution switches.

### 2.5 Rapid PVST+ vs MST (when to switch)
| | Rapid PVST+ | MST (802.1s) |
|--|-------------|--------------|
| Instances | per VLAN | mapped groups (few) |
| Scale | many instances cost | best for huge VLAN fleets |
| Config complexity | simple | instance mapping |
| Interop Cisco | native | standard-friendly |
- Exam choice: campus = Rapid PVST+; large provider/kube = MST.

## 3. Configuration / Commands

```text
spanning-tree mode rapid-pvst
spanning-tree vlan 10 root primary      # fast election
spanning-tree vlan 20 root secondary
interface Gi0/1
 spanning-tree portfast                 # edge host instant

show spanning-tree vlan 10
show spanning-tree summary
show switch? no — show spanning-tree active
```

---

## 4. Exam Traps

- **Rapid PVST+ is RSTP per VLAN** — don't call it "PVST+."
- **Default on modern Cisco** — questions assume it's already running.
- **Edge/PortFast ports skip the proposal process** — instant forwarding.
- **It still needs BPDU guard on edge** (note 11) for safety.
- **Many VLANs → instance scale issue** → MST answer.
