# Rapid PVST+

> **Level 08 · STP** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Rapid PVST+** = **RSTP running per VLAN** (Cisco). It combines RSTP's **fast
convergence** with PVST+'s **per-VLAN instances** — the default STP mode on modern
Catalyst switches and the usual exam expectation. Each VLAN gets its own RSTP tree,
own root, own blocking decisions, and own fast proposal/agreement handshake.

---

## 2. Core Concepts

### 2.1 Composition

```
Rapid PVST+ = RSTP (802.1w) mechanics + PVST+ per-VLAN instances
```

- Separate RSTP tree per VLAN, each with its own root election and role computation.
- Default `spanning-tree mode rapid-pvst` on IOS/Catalyst.
- **Extended System ID** still applies: the VLAN ID lives in the low 12 bits of the
  16-bit bridge-priority field, so per-VLAN Bridge IDs are unique and configurable
  priorities stay in **multiples of 4096**.

### 2.2 Why it wins

| Need | Rapid PVST+ |
|------|-------------|
| Fast convergence to edge | yes (agreement) |
| Per-VLAN control | yes (instances) |
| Load-balance across uplinks | yes (root per VLAN) |
| Backward to classic neighbor | degrades to STP **per VLAN** |

- Trade-off: **instance count grows with VLAN count** (CPU/BPDU cost). Huge VLAN fleets
  → consider **MST** (Level 08 note 05).

### 2.3 Operational benefits day-to-day

- Edge ports (hosts/trunks with PortFast) transition **instantly**.
- Link loss detected in **3 × hello (6 s)**, not MaxAge 20 s.
- New links with proposal/agreement go Forwarding immediately — no ForwardDelay.
- Per-VLAN root placement means **both uplinks carry traffic** (VLAN 10 up link A,
  VLAN 20 up link B) instead of one idle uplink.

### 2.4 Tuning per VLAN (same as PVST+)

- Root per VLAN: `spanning-tree vlan 10 priority 4096` (or `root primary`).
- Path cost per VLAN: set on interface for specific VLANs (`spanning-tree vlan 10 cost`).
- Load balance: roots differ per VLAN across two distribution switches.
- Protection per VLAN: `portfast`, `bpduguard`, `guard root/loop` all apply per instance.

### 2.5 Rapid PVST+ vs MST (when to switch)

| | Rapid PVST+ | MST (802.1s) |
|--|-------------|--------------|
| Instances | per VLAN | mapped groups (few) |
| Scale | many instances = cost | best for huge VLAN fleets |
| Config complexity | simple | instance mapping |
| Interop | Cisco | standard-friendly (802.1s) |

- Exam choice: campus = Rapid PVST+; large-scale / many VLANs = MST.

### 2.6 Interoperability

- Talking to **PVST+** (classic per-VLAN) neighbors: RSTP features degrade to 802.1D
  behavior on those per-VLAN portlets (per-port migration as in RSTP, applied per VLAN).
- Talking to **MST**: at the region boundary Cisco maps per-VLAN PVST+ BPDUs to/from the
  CIST — the PVST+/Rapid-PVST+ neighbor sees the MST region as a single spanning-tree
  bridge per recognized VLAN. See Level 08 note 05.

## 3. Configuration / Commands

```text
spanning-tree mode rapid-pvst
spanning-tree vlan 10 root primary      # fast per-VLAN root election
spanning-tree vlan 20 root secondary
spanning-tree vlan 10 priority 4096     # explicit alternative (effective 4106)

interface Gi0/1
 spanning-tree portfast                 # edge host instant

show spanning-tree
show spanning-tree vlan 10
show spanning-tree summary              # mode + instance count
show spanning-tree active
show spanning-tree inconsistentports
```

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Still slow convergence | mode still `pvst` (802.1D) not `rapid-pvst` | `show spanning-tree summary` |
| No load balance | same switch root for all VLANs | `show spanning-tree root` per VLAN |
| Edge host waits 30 s | PortFast missing on access port | `spanning-tree portfast` |
| BPDU guard errdisable | rogue switch on edge port | `show interfaces status \| include err-disab` |
| One VLAN dark | that VLAN's instance blocked / native mismatch | `show spanning-tree vlan X` |
| Root not expected switch | no priority set; MAC decided | `root primary` / explicit priority |

## 5. Exam Traps

- **Rapid PVST+ is RSTP per VLAN** — don't call it plain "PVST+" (which is 802.1D).
- **Default on modern Cisco** — questions assume it's already running.
- **Edge/PortFast ports skip the proposal process** — instant forwarding.
- **Extended System ID**: per-VLAN priority is `configured + VLAN`, gaps of 4096.
- **3 × missed hello (6 s)** detects link loss — quicker than classic MaxAge.
- **It still needs BPDU Guard on edge** (Level 08 note 11) for safety.
- **Many VLANs → instance scale issue** → choose MST in the exam.
