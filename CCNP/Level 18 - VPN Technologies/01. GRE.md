# GRE

> **Level 18 · VPN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**GRE** (IP protocol 47) encapsulates arbitrary payloads (IPv4/IPv6/multicast) inside an
**IP tunnel** between routers — the classic way to run routing protocols over an
untrusted or disjoint underlay. GRE provides **no encryption** (often wrapped with IPsec,
note 02), **no reliability**, and adds a **4-byte header** + 20-byte outer IP.

---

## 2. Core Concepts

### 2.1 The tunnel concept

| Element | Detail |
|---------|--------|
| Tunnel interface | virtual L3 interface |
| Outer IP | physical (transport) |
| Inner IP | original packet |
| GRE header | protocol 47 |

- The router treats the tunnel as a normal interface — **routing/multicast work** over it.

### 2.2 GRE vs IPsec (the pairing)

| Aspect | GRE | IPsec |
|--------|-----|-------|
| Encryption | none | yes |
| Payload | any L3 (+mcast) | typically unicast |
| Routing over it | yes (OSPF/EIGRP/BGP) | not directly |
| Header | 4+20 B | ESP (varies) |
| Use | transport + dynamic routing | confidentiality |

- **GRE + IPsec** = the standard site-to-site recipe (note 06).

### 2.3 Configuration

```text
interface Tunnel0
 ip address 10.10.0.1 255.255.255.252
 tunnel source Gi0/0
 tunnel destination 203.0.113.1
 ip mtu 1400
 ip tcp adjust-mss 1360
```

| Command | Purpose |
|---------|---------|
| `tunnel source` | physical interface/loopback |
| `tunnel destination` | far tunnel endpoint |
| `ip mtu` / `tcp adjust-mss` | fix MTU overhead |

### 2.4 MTU / fragmentation (exam focus)

- Overhead = GRE 4 B + outer IP 20 B (+ IPsec ESP later) = **24 B+**.
- Reduce tunnel `ip mtu` and shrink **TCP MSS** so packets fit without fragmentation.
- PMTUD + TCP adjust-mss keep the tunnel clean.

### 2.5 GRE keepalives

```text
interface Tunnel0
 keepalive 10 3
```

- Tunnel endpoints can send keepalives to detect **one-way / black-hole** tunnels.
- Caveat: keepalives only make sense between direct GRE peers.

### 2.6 Multi-protocol tunnels

| Payload | Use |
|---------|-----|
| IPv4 | branch routing over Internet |
| IPv6 | IPv6-over-IPv4 transit |
| multicast | DMVPN / dynamic routing |

- GRE is the **carrier** that makes multicast-capable VPN overlays (DMVPN) possible.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Tunnel up, ping fails | routing/firewall on path | underlay reachability |
| Fragmentation | MTU too high | ip mtu / tcp adjust-mss |
| Keepalive down | no return path | keepalive/one-way |
| GRE protocol 47 blocked | firewall | ACL 47 |
| Blackhole | no routing in tunnel | both ends tunnel IP |

---

## 5. Exam Traps

- GRE = **IP protocol 47** — not TCP/UDP.
- **No encryption** by itself; pair with IPsec.
- Supports **multicast + any L3 payload** — the DMVPN enabler.
- **MTU/MSS** must be tuned for the added header.
- `tunnel source/destination` define the underlay endpoints.
