# IPsec

> **Level 18 · VPN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**IPsec** provides **confidentiality, integrity, and authentication** for IP traffic at
the packet level. Two phases: **IKE** (key management, UDP 500/4500) and **ESP/AH**
(data plane). The exam tests **AH vs ESP**, **transport vs tunnel mode**, and the **IKE
phase 1/2** flow.

---

## 2. Core Concepts

### 2.1 The two protocols

| Protocol | Job | Notes |
|----------|-----|-------|
| **AH** (51) | integrity + auth | does **not** encrypt; no NAT traversal |
| **ESP** (50) | confidentiality + integrity + auth | the standard choice |

- **ESP** is the answer for real encryption; AH is legacy.

### 2.2 Modes

| Mode | Protects | Use |
|------|----------|-----|
| Transport | only payload (headers visible) | host-to-host / GRE |
| Tunnel | entire IP packet (new outer header) | site-to-site VPN |

- **Tunnel mode** wraps the whole packet; **transport** keeps the original IP header.

### 2.3 IKE phases

| Phase | Purpose | Result |
|-------|---------|--------|
| 1 | authenticate + build secure channel | ISAKMP SA (main/aggressive) |
| 2 | negotiate data-plane keys | IPsec SA (quick mode) |

| Port | IKE |
|------|-----|
| 500 | ISAKMP (UDP) |
| 4500 | NAT-T (ESP in UDP) |

- **Main mode** = 6 messages (secure); **aggressive** = 3 (fast but weaker).
- NAT-T wraps ESP in UDP 4500 when NAT is between peers.

### 2.4 IKEv1 vs IKEv2

| Aspect | IKEv1 | IKEv2 |
|--------|-------|-------|
| Phases | 1 + 2 | one exchange |
| SA negotiation | complex | simpler |
| NAT-T | built-in | native |
| Modern | legacy | preferred |

- IKEv2 is the current standard.

### 2.5 Cisco configuration (crypto map legacy)

```text
crypto isakmp policy 10
 encryption aes
 authentication pre-share
 group 14
!
crypto isakmp key Secret123 address 203.0.113.1
!
crypto ipsec transform-set TS esp-aes esp-sha-hmac
!
crypto map CM 10 ipsec-isakmp
 set peer 203.0.113.1
 set transform-set TS
 match address VPN-TRAFFIC
!
interface Gi0/0
 crypto map CM
```

- **Transform set**: `esp-aes` (encryption) + `esp-sha-hmac` (integrity).
- `crypto map` attaches to the physical interface.

### 2.6 Modern approach: IPsec profile / IKEv2

- IKEv2 profile + IPsec profile simplify config (used by DMVPN/FlexVPN).

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No SA | IKE blocked (500/4500) | show crypto isakmp sa |
| Tunnel up, no traffic | ACL mismatch | match address |
| NAT breaks ESP | no NAT-T | NAT-T / 4500 |
| Transform mismatch | algos differ | transform-set |
| Peer key mismatch | pre-shared key | isakmp key |

---

## 5. Exam Traps

- **ESP (50)** encrypts; **AH (51)** doesn't.
- **Tunnel mode** for site-to-site; transport for host/host.
- IKE: **UDP 500**, NAT-T **UDP 4500**.
- Transform-set pairs **encryption + integrity** (aes + sha).
- IKEv2 is modern; IKEv1 is legacy.
