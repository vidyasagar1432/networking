# FlexVPN

> **Level 18 · VPN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**FlexVPN** is Cisco's **IKEv2-based** VPN framework — one unified design that does
**site-to-site, remote access, hub-and-spoke, and spoke-to-spoke** using the same
**IKEv2 profile** building blocks. It modernizes IPsec (note 02) by replacing the legacy
`crypto map`/ISAKMP config with **profiles** and simplifies DMVPN-style deployments.

---

## 2. Core Concepts

### 2.1 The IKEv2 profile model

| Block | Role |
|-------|------|
| crypto ikev2 proposal | encryption + integrity + DH |
| crypto ikev2 policy | proposal + lifetime |
| crypto ikev2 keyring | pre-shared keys |
| crypto ikev2 profile | match + auth + keyring |
| crypto ipsec profile | transform + ikev2 profile |

- One consistent config language across every VPN type.

### 2.2 FlexVPN modes

| Mode | Use |
|------|-----|
| Site-to-site | static tunnel between sites |
| Remote access | client → server (IKEv2) |
| Hub-and-spoke | DMVPN-style with IKEv2 |
| Spoke-to-spoke | dynamic shortcuts |

- Same building blocks, different **match/authentication** setup.

### 2.3 Example config (site-to-site, hub side)

```text
crypto ikev2 proposal PROP
 encryption aes-gcm-256
 integrity sha256
 group 14
!
crypto ikev2 policy POL
 proposal PROP
!
crypto ikev2 keyring KR
 peer SPOKE
  address 203.0.113.10
  pre-shared-key local Secret123
!
crypto ikev2 profile IKEV2-PROF
 match identity remote address 203.0.113.10
 authentication remote pre-share
 authentication local pre-share
 keyring local KR
!
crypto ipsec profile IPSEC-PROF
 set transform-set TS
 set ikev2-profile IKEV2-PROF
!
interface Tunnel0
 tunnel protection ipsec profile IPSEC-PROF
```

### 2.4 FlexVPN vs DMVPN

| Aspect | DMVPN | FlexVPN |
|--------|-------|---------|
| IKE | IKEv1 or v2 | IKEv2 native |
| Config | NHRP + mGRE | profiles |
| Modes | hub-spoke | + remote access |
| Crypto | crypto map/profiles | profile-based |
| Complexity | higher | unified |

- FlexVPN = **IKEv2 profiles**; DMVPN = **NHRP + mGRE** model.
- FlexVPN can also run hub-spoke using NHRP.

### 2.5 Remote access with FlexVPN

- IKEv2 client (AnyConnect) uses the same **IKEv2 profile** server-side.
- Certificates or pre-shared keys authenticate.
- Dynamic virtual tunnel interfaces (VTIs) scale client tunnels.

### 2.6 Benefits

| Benefit | Detail |
|---------|--------|
| Unified | one framework, many topologies |
| Modern | IKEv2 + AES-GCM |
| Simpler | profiles over crypto maps |
| Scale | dynamic VTIs / hubs |

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| No IKE SA | proposal/policy mismatch | show crypto ikev2 sa |
| Auth fail | keyring/match | ikev2 profile |
| Peer mismatch | match identity | profile |
| No IPsec SA | transform set | crypto ipsec profile |
| NAT issue | NAT-T | 4500 |

## 5. Exam Traps

- FlexVPN = **IKEv2 profile** model (not crypto map / ISAKMP).
- One framework: **site-to-site, RA, hub-spoke, spoke-spoke**.
- AES-GCM + SHA-256 common proposals.
- Uses **IPsec profiles** attached via `tunnel protection`.
- Compare vs DMVPN: FlexVPN is profile/IKEv2-first.
