# SSL VPN (Remote Access)

> **Level 18 · VPN Technologies** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**SSL VPN** gives remote users secure access **through a web browser or AnyConnect
client** using **TLS/HTTPS (443)** — no pre-installed IPsec client, works through most
firewalls. Two flavors: **clientless** (portal to internal apps) and **AnyConnect
full-tunnel**. The exam compares it with IPsec remote access.

---

## 2. Core Concepts

### 2.1 Two access modes

| Mode | Description |
|------|-------------|
| Clientless (portal) | browser-based access to apps |
| AnyConnect (full) | installs a full VPN tunnel |

- **Clientless** = zero install; **AnyConnect** = complete network access.

### 2.2 Transport

| Item | Detail |
|------|--------|
| Port | TCP 443 (TLS) |
| Uses | HTTPS session |
| NAT friendly | yes (443 passes anywhere) |
| Client | browser or AnyConnect |

- Riding TLS makes it **firewall-friendly** — the main advantage over IPsec.

### 2.3 How AnyConnect full-tunnel works

- AnyConnect client → ASDM/ASA → **TLS/DTLS tunnel**.
- Virtual interface on the client routes the user's traffic inside.
- **DTLS** (UDP 443) reduces latency for real-time apps.

| Transport | Protocol |
|-----------|----------|
| Primary | TLS (TCP 443) |
| Optimized | DTLS (UDP 443) |

### 2.4 Authentication & posture

| Layer | Mechanism |
|-------|-----------|
| User auth | LDAP/RADIUS/AAA |
| MFA | token / cert |
| Posture | endpoint check (AnyConnect) |
| Group policy | split-tunnel / full-tunnel |

- Security answers: **MFA + certificates + posture**.

### 2.5 SSL VPN vs IPsec remote access

| Aspect | SSL VPN | IPsec RA |
|--------|---------|----------|
| Client | browser/AnyConnect | IPsec client |
| Port | 443 (anywhere) | 500/4500 (often blocked) |
| App access | fine-grained | full tunnel |
| Corporate control | moderate | strong |
| Setup friction | low | higher |

- **SSL VPN wins on reachability**; IPsec wins on raw control.

### 2.6 Typical headend

- Cisco **ASA / ASAv / ISR** hosting the SSL VPN service.
- **AnyConnect** licensed per user; group-policies define access.

## 4. Troubleshooting & common failures

| Symptom | Likely cause | Check |
|---------|--------------|-------|
| Portal unreachable | 443 blocked | ACL |
| Auth loop | AAA/LDAP | vpn-sessiondb |
| No full tunnel | split-tunnel policy | group-policy |
| Slow | TCP 443 | use DTLS |
| Cert warnings | self-signed | proper cert |

---

## 5. Exam Traps

- SSL VPN = **TLS 443**, firewall-friendly.
- **Clientless vs AnyConnect** — the two modes.
- DTLS (UDP 443) = performance for real-time.
- MFA/cert/posture are the security enhancements.
- SSL VPN > IPsec for **per-user reachability** through NAT/firewalls.
