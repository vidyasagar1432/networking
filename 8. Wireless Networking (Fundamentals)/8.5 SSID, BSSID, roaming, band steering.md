# 1. Overview

SSID, BSSID, roaming, and band steering are fundamental WLAN concepts that describe wireless network identification and client movement. CCNA tests the difference between SSID and BSSID, how wireless clients roam between access points, and how band steering improves wireless performance.

---

# 2. Core Concepts

# SSID (Service Set Identifier)

SSID:

```
The name of a wireless network.
```

It is the name users see when selecting Wi-Fi.

Example:

```
Available Networks:

Office-WiFi
Guest-WiFi
IoT-WiFi
```

---

# SSID Characteristics

| Feature | Description |
|---|---|
| Full Name | Service Set Identifier |
| Purpose | Identifies WLAN |
| Length | Up to 32 characters |
| Broadcast | Can be visible or hidden |
| Security | Associated with authentication policies |

---

# SSID Example

```
Wireless Network:

SSID = COMPANY_WIFI
```

Client connects:

```
Laptop
   |
   |
COMPANY_WIFI
   |
   |
Access Point
```

---

# SSID and WLAN Relationship

In Cisco WLAN:

```
SSID

  |

WLAN Configuration

  |

Wireless Service
```

A WLC can provide multiple SSIDs.

Example:

| SSID | Purpose |
|---|---|
| Corp-WiFi | Employees |
| Guest-WiFi | Visitors |
| IoT-WiFi | Devices |

---

# Hidden SSID

A hidden SSID:

```
Does not advertise its network name.
```

Normal:

```
Beacon Frame:

SSID = OfficeWiFi
```

Hidden:

```
Beacon Frame:

SSID = Not Broadcast
```

---

# Hidden SSID Security

Important:

```
Hidden SSID is NOT a security feature.
```

Reasons:

- Clients reveal SSID during connection
- Attackers can discover it

---

# BSSID (Basic Service Set Identifier)

BSSID:

```
The MAC address of an access point radio.
```

It uniquely identifies a wireless cell.

---

# BSSID Example

Access Point:

```
MAC Address:

00:11:22:33:44:55
```

BSSID:

```
00:11:22:33:44:55
```

---

# SSID vs BSSID

| Feature | SSID | BSSID |
|---|---|---|
| Meaning | Network name | AP radio identifier |
| Format | Text | MAC address |
| Example | Corp-WiFi | 00:11:22:33:44:55 |
| Visible to user | Yes | Usually hidden |
| Identifies | WLAN | Individual AP/radio |

---

# Basic Service Set (BSS)

A BSS is:

```
One AP + connected wireless clients
```

Example:

```
        AP

       /|\

      / | \

 Client Client Client
```

---

# Extended Service Set (ESS)

ESS:

```
Multiple APs using the same SSID.
```

Example:

```
              SSID: Office-WiFi


        AP1              AP2

         |                |

     Clients          Clients
```

Allows roaming.

---

# Roaming

Roaming:

```
A wireless client moving from one AP to another while maintaining connectivity.
```

Example:

```
Client

AP1  --------->  AP2
```

---

# Why Roaming Is Needed

Users move while connected:

Examples:

- Office buildings
- Hospitals
- Campuses
- Warehouses

---

# Roaming Process

```
Client connected to AP1

        |

Signal becomes weak

        |

Client searches for better AP

        |

Authentication

        |

Client connects to AP2
```

---

# Roaming Types

## Layer 2 Roaming

Client moves between APs in:

```
Same VLAN
```

Example:

```
AP1 VLAN 10

      |

AP2 VLAN 10
```

---

## Layer 3 Roaming

Client moves between:

```
Different IP subnets
```

Example:

```
AP1 VLAN 10

      |

AP2 VLAN 20
```

Requires additional mobility functions.

---

# Roaming Decision

The client usually decides when to roam.

Factors:

| Factor | Effect |
|---|---|
| Signal strength | Weak signal triggers search |
| Noise | Poor quality |
| Data rate | Lower speed |
| AP load | Congestion |

---

# Fast Roaming

Used for applications requiring low delay:

- Voice over Wi-Fi
- Video calls

Technologies:

| Technology | Purpose |
|---|---|
| 802.11r | Fast BSS transition |
| 802.11k | Neighbor reports |
| 802.11v | Client management |

---

# Band Steering

Band steering:

```
Technology that encourages dual-band clients to use 5 GHz instead of 2.4 GHz.
```

---

# Why Band Steering Is Needed

Without band steering:

```
Many devices choose 2.4 GHz
```

Problems:

- More interference
- Less bandwidth
- Congestion

---

# Band Steering Operation

Before:

```
Client

   |

2.4 GHz AP
```

After:

```
Client

   |

5 GHz AP
```

---

# Band Steering Benefits

| Benefit | Explanation |
|---|---|
| Less congestion | Moves clients away from 2.4 GHz |
| Higher speed | 5 GHz supports faster rates |
| Better performance | More available channels |

---

# Band Steering Requirements

Client must support:

```
Both 2.4 GHz and 5 GHz
```

Known as:

```
Dual-band client
```

---

# Band Steering Limitations

- Cannot force unsupported devices
- Depends on client behavior
- Poor signal may still prefer 2.4 GHz

---

# 5. Exam Traps

- SSID is the wireless network name.
- BSSID is the AP radio MAC address.
- Multiple BSSIDs can advertise the same SSID.
- ESS uses multiple APs with the same SSID.
- Roaming changes BSSID, not necessarily SSID.
- Hidden SSID does not provide real security.
- Clients usually make roaming decisions.
- Band steering moves capable clients from 2.4 GHz to 5 GHz.
- 5 GHz generally provides higher speed but shorter range.
- Fast roaming is important for voice applications.
- 802.11r improves roaming speed.
- 802.11k provides neighbor information.
- 802.11v helps client steering.

# 7. Practice Questions

## Question 1

What identifies a wireless network name?

A. BSSID  
B. SSID  
C. MAC table  
D. VLAN ID  

### Answer: B

Explanation:

SSID is the WLAN name.

---

## Question 2

What identifies a specific AP radio?

A. SSID  
B. IP address  
C. BSSID  
D. Channel  

### Answer: C

Explanation:

BSSID is based on the AP radio MAC address.

---

## Question 3

What technology encourages clients to use 5 GHz?

A. Roaming  
B. Band steering  
C. CAPWAP  
D. NAT  

### Answer: B

Explanation:

Band steering moves capable devices toward 5 GHz.

---

## Question 4

A client moves from AP1 to AP2 but keeps the same Wi-Fi name. What happened?

A. NAT  
B. Roaming  
C. VLAN trunking  
D. Routing  

### Answer: B

Explanation:

The client roamed between access points.

---

## Question 5

Which standard improves fast wireless roaming?

A. 802.11r  
B. 802.11b  
C. 802.11g  
D. 802.11a  

### Answer: A

Explanation:

802.11r provides Fast BSS Transition.
