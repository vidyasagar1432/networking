# 1. Overview

IEEE 802.11 standards define how wireless LAN devices communicate, including frequency bands, modulation methods, channel widths, and performance capabilities. CCNA tests the differences between Wi-Fi generations, supported frequencies, maximum speeds, and range/performance tradeoffs.

---

# 2. Core Concepts

# IEEE 802.11 Definition

802.11:

```
IEEE Wireless LAN Standard Family
```

Used for:

- Wi-Fi communication
- Wireless client connectivity
- WLAN deployment

# MIMO

MIMO:

```
Multiple Input Multiple Output
```

Uses multiple antennas.

Example:

```
2x2 MIMO

2 transmit antennas
2 receive antennas
```

Benefits:

- Higher throughput
- Better reliability

---

# 802.11ac (Wi-Fi 5)

Designed for:

```
High-speed 5 GHz wireless
```

---

# 802.11ac Features

| Feature | Description |
|---|---|
| Frequency | 5 GHz only |
| Channel width | Up to 160 MHz |
| MIMO | Improved |
| MU-MIMO | Supported |
| Speed | Multi-Gbps |

# MU-MIMO

Multi-User MIMO:

Allows:

```
One AP communicating with multiple clients simultaneously
```

# 802.11ax (Wi-Fi 6)

Focus:

```

```

# 802.11ax Improvements

| Feature | Benefit |
|---|---|

| BSS Coloring | Reduces interference |

# OFDMA

Orthogonal Frequency Division Multiple Access:

```
Splits channel into smaller resource units.
```

Allows:

```
Multiple clients transmit together.
```

---

# BSS Coloring

Purpose:

Reduce:

```
Co-channel interference
```

by identifying nearby networks.

---

# Target Wake Time (TWT)

Allows devices to:

- Sleep longer
- Save battery
- Reduce congestion

# 5. Exam Traps

- 802.11ac operates only on 5 GHz.
- 802.11ax operates on 2.4 GHz and 5 GHz.
- Wi-Fi 6E uses 6 GHz.
- 802.11be is Wi-Fi 7.
- 2.4 GHz provides longer range than 5 GHz.
- Higher frequency does not mean longer distance.
- 802.11n introduced MIMO.
- 802.11ac introduced MU-MIMO.
- 802.11ax introduced OFDMA and BSS Coloring.
- Channel width affects throughput.
- Actual wireless speed is lower than theoretical speed.
- More clients sharing an AP reduces available bandwidth.
- Wi-Fi generations are marketing names; IEEE numbers are standards.

# 7. Practice Questions

## Question 1

Which standard introduced MIMO?

A. 802.11a  
B. 802.11g  
C. 802.11n  
D. 802.11b  

### Answer: C

Explanation:

802.11n introduced MIMO technology.

---

## Question 2

Which Wi-Fi standard operates only on 5 GHz?

A. 802.11ac  
B. 802.11n  
C. 802.11ax  
D. 802.11g  

### Answer: A

Explanation:

802.11ac uses the 5 GHz band.

---

## Question 3

Which technology improves Wi-Fi 6 efficiency in crowded networks?

A. DSSS  
B. OFDMA  
C. CSMA/CD  
D. Token Ring  

### Answer: B

Explanation:

OFDMA allows multiple users to share channel resources.

---

## Question 4

Which provides the longest wireless range?

A. 6 GHz  
B. 5 GHz  
C. 2.4 GHz  
D. 60 GHz  

### Answer: C

Explanation:

Lower frequency signals travel farther.

---

## Question 5

What is Wi-Fi 7 based on?

A. 802.11n  
B. 802.11ac  
C. 802.11ax  
D. 802.11be  

### Answer: D

Explanation:

802.11be is Wi-Fi 7.
