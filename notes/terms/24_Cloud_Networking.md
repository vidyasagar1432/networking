# Cloud Networking

| Term | Definition |
|---|---|
| **VPC** | Virtual Private Cloud — isolated virtual network in AWS |
| **VNet** | Virtual Network — isolated virtual network in Azure |
| **Subnet** | IP range within a VPC/VNet |
| **Internet Gateway** | AWS gateway connecting VPC to the Internet |
| **NAT Gateway** | AWS managed service for outbound Internet from private subnets |
| **Route Table** | Defines traffic routing rules within a VPC/VNet |
| **Security Group** | Stateful firewall at instance level (AWS) |
| **Network ACL** | Stateless firewall at subnet level (AWS) |
| **Elastic IP** | Static public IP assigned to an AWS resource |
| **Load Balancer** | Distributes traffic across targets (ALB, NLB, ELB) |
| **Transit Gateway** | Hub connecting multiple VPCs and on-premises networks |
