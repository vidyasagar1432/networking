# Network Monitoring

| Term | Definition |
|---|---|
| **SNMP Manager** | Central system that polls and receives traps from agents |
| **SNMP Agent** | Software on a device that exposes management data via SNMP |
| **MIB** | Management Information Base — hierarchical database of OIDs |
| **Syslog** | Standard for log message generation and transmission (UDP 514) |
| **NetFlow** | Cisco flow monitoring — captures flow metadata |
| **sFlow** | Packet sampling monitoring (statistical) |
| **IPFIX** | NetFlow v10 standard — template-based flow export |
| **Telemetry** | Streaming, push-based device data (not polled) |
