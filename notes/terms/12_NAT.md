# NAT

| Term | Definition |
|---|---|
| **NAT** | Network Address Translation — maps private IPs to public IPs |
| **Static NAT** | 1:1 mapping between private and public IP (permanent) |
| **Dynamic NAT** | 1:1 mapping from a pool of public IPs (on-demand) |
| **PAT** | Port Address Translation / NAT Overload — many:1 (different ports) |
| **Inside Local** | Private IP of internal host as seen from inside the network |
| **Inside Global** | Public IP of internal host as seen from outside the network |
| **Outside Local** | IP of external host as seen from inside the network |
| **Outside Global** | Public IP of external host as seen from outside the network |
