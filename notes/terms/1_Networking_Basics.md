# Networking Basics

| Term | Definition |
|---|---|
| **Network** | A group of interconnected devices that can communicate with each other |
| **Node** | Any device connected to a network (computer, printer, switch, router) |
| **Host** | Any device that sends or receives traffic (has an IP address) |
| **Client** | A device or application that requests services from a server |
| **Server** | A device or application that provides services to clients |
| **Peer** | Devices that share resources equally in a peer-to-peer network |
| **Topology** | The arrangement of elements in a network |
| **Physical Topology** | The physical layout of cables, devices, and connections |
| **Logical Topology** | The logical path data takes regardless of physical layout |
| **LAN** | Local Area Network — limited geographic area (building, office) |
| **WLAN** | Wireless Local Area Network — LAN using wireless technology |
| **MAN** | Metropolitan Area Network — city-wide network |
| **WAN** | Wide Area Network — large geographic area (country, world) |
| **PAN** | Personal Area Network — around a person (Bluetooth) |
| **SAN** | Storage Area Network — dedicated storage network |
| **CAN** | Campus Area Network — university/corporate campus |
| **VPN** | Virtual Private Network — secure tunnel over public network |
| **Intranet** | Private network accessible only within an organization |
| **Extranet** | Intranet partially accessible to authorized outsiders |
| **Internet** | Global network of interconnected networks |
