# QoS

| Term | Definition |
|---|---|
| **QoS** | Quality of Service — managing bandwidth, latency, jitter, and loss |
| **CoS** | Class of Service — 3-bit 802.1p priority in VLAN tag (0–7) |
| **DSCP** | Differentiated Services Code Point — 6 bits in IP header (0–63) |
| **Traffic Shaping** | Buffering excess traffic to meet a configured rate (smooths bursts) |
| **Traffic Policing** | Dropping or re-marking traffic exceeding a configured rate |
| **Queue** | Buffer holding packets waiting for transmission |
| **Priority Queue** | Strict-priority queue emptied before other queues |
| **Bandwidth** | Data capacity of a link (bits per second) |
| **Latency** | Time for data to travel from source to destination |
| **Delay** | Same as latency — end-to-end transmission time |
| **Jitter** | Variation in packet delay (variance of latency) |
| **Packet Loss** | Percentage of packets dropped in transit |
