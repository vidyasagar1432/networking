# Security

| Term | Definition |
|---|---|
| **ACL** | Access Control List — rules permitting or denying traffic |
| **Standard ACL** | Filters based on source IP only (numbered 1–99, 1300–1999) |
| **Extended ACL** | Filters based on source/dest IP, port, protocol (numbered 100–199, 2000–2699) |
| **Stateful Firewall** | Tracks connection state — allows return traffic automatically |
| **Stateless Firewall** | Filters each packet independently (no connection tracking) |
| **DMZ** | Demilitarized Zone — isolated network for public-facing servers |
| **AAA** | Authentication, Authorization, Accounting |
| **Authentication** | Verifying identity (who are you?) |
| **Authorization** | Determining permitted actions (what can you do?) |
| **Accounting** | Logging user activity (what did you do?) |
| **Certificate** | Digital document binding a public key to an identity (X.509) |
| **PKI** | Public Key Infrastructure — system managing certificates and keys |
| **Encryption** | Transforming data to be unreadable without a key |
| **Hashing** | One-way cryptographic function (fixed output, irreversible) |
| **Digital Signature** | Signed hash of data verifying authenticity and integrity |
| **VPN Tunnel** | Encrypted connection between two endpoints over an untrusted network |
| **Zero Trust** | Security model: never trust, always verify (no implicit trust) |
