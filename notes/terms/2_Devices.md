# Devices

| Term | Definition |
|---|---|
| **Router** | Forwards packets between networks based on IP addresses |
| **Switch** | Forwards frames within a network based on MAC addresses |
| **Hub** | Repeats signals to all ports (no intelligence, shared bandwidth) |
| **Bridge** | Connects two network segments, forwards based on MAC |
| **Repeater** | Amplifies/regenerates signals to extend cable distance |
| **Gateway** | Connects networks using different protocols (translates) |
| **Firewall** | Filters traffic based on security rules |
| **IDS** | Intrusion Detection System — monitors and alerts on threats |
| **IPS** | Intrusion Prevention System — monitors and blocks threats inline |
| **Load Balancer** | Distributes traffic across multiple servers |
| **Wireless Access Point (AP)** | Bridges wireless clients to wired network |
| **Wireless LAN Controller (WLC)** | Centralized management of multiple APs |
| **Modem** | Modulates/demodulates signals (digital ↔ analog) |
| **CSU/DSU** | Channel Service Unit / Data Service Unit — serial interface to T1/E1 |
| **Proxy Server** | Intermediary for client requests (caching, filtering, anonymity) |
| **Reverse Proxy** | Intermediary for incoming requests (load balancing, caching, SSL termination) |
| **Bastion Host** | Hardened server exposed to the Internet (jump box) |
| **DNS Server** | Resolves hostnames to IP addresses |
| **DHCP Server** | Automatically assigns IP addresses to clients |
| **AAA Server** | Authentication, Authorization, Accounting server (RADIUS, TACACS+) |
