# Ethernet

| Term | Definition |
|---|---|
| **Ethernet Frame** | Layer 2 PDU — contains MAC addresses, payload, and FCS |
| **Frame** | Layer 2 data unit (encapsulated packet) |
| **MTU** | Maximum Transmission Unit — largest L3 packet a link can carry (default 1500 bytes) |
| **Jumbo Frame** | MTU > 1500 (typically 9000 bytes) — reduces overhead on fast links |
| **CRC** | Cyclic Redundancy Check — error-detecting code in FCS |
| **FCS** | Frame Check Sequence — 4-byte CRC trailer on Ethernet frame |
| **Duplex** | Communication mode for data transmission |
| **Half Duplex** | One direction at a time (like a walkie-talkie) |
| **Full Duplex** | Both directions simultaneously (like a phone call) |
| **Auto Negotiation** | Advertises speed/duplex capabilities to negotiate best common settings |
