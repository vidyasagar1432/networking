# TCP/IP Model

| Term | Definition |
|---|---|
| **Network Access** | Combines OSI L1 + L2 — hardware, framing, MAC (Ethernet, Wi-Fi) |
| **Internet Layer** | OSI L3 equivalent — packet forwarding, IP addressing (IPv4, IPv6) |
| **Transport Layer** | OSI L4 equivalent — end-to-end reliability (TCP, UDP) |
| **Application Layer** | Combines OSI L5–L7 — HTTP, FTP, SMTP, DNS, SSH |
