# Subnetting

| Term | Definition |
|---|---|
| **Subnet** | Logical subdivision of an IP network |
| **Supernet** | Aggregation of multiple subnets into a larger network |
| **VLSM** | Variable Length Subnet Mask — different masks within same network |
| **CIDR** | Classless Inter-Domain Routing — prefix notation (e.g., /24) |
| **Prefix Length** | Number of bits in the network portion (e.g., /24 = 255.255.255.0) |
| **Network ID** | First address in subnet (host bits all 0) |
| **Host ID** | The host portion of an IP address |
| **Wildcard Mask** | Inverted subnet mask (e.g., 0.0.0.255 for /24) — used in ACLs/OSPF |
| **Default Route** | 0.0.0.0/0 — matches all destinations, used as catch-all gateway |
