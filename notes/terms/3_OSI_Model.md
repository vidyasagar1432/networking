# OSI Model

| Term | Definition |
|---|---|
| **Layer 1 – Physical** | Transmits raw bits over physical medium (cables, connectors, voltage) |
| **Layer 2 – Data Link** | Frames, MAC addressing, error detection (Ethernet, PPP, Frame Relay) |
| **Layer 3 – Network** | Packet forwarding, IP addressing, routing (IPv4, IPv6, OSPF, BGP) |
| **Layer 4 – Transport** | End-to-end communication, reliability, flow control (TCP, UDP) |
| **Layer 5 – Session** | Manages sessions between applications (establish, maintain, terminate) |
| **Layer 6 – Presentation** | Data translation, encryption, compression (TLS, SSL) |
| **Layer 7 – Application** | Interface for applications (HTTP, FTP, SMTP, DNS) |

**Mnemonic**: Please Do Not Throw Sausage Pizza Away (Physical → Application)
