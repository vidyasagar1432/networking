# DNS

| Term | Definition |
|---|---|
| **Domain Name** | Human-readable name for a website (e.g., example.com) |
| **FQDN** | Fully Qualified Domain Name — complete domain name with all labels (host.example.com.) |
| **Root Server** | Top-level DNS server — directs queries to appropriate TLD servers |
| **Recursive Resolver** | DNS server that performs full resolution on behalf of clients |
| **Authoritative Server** | DNS server that has the definitive answer for a domain |
| **Zone** | A portion of the DNS namespace delegated to an authoritative server |
| **Zone Transfer** | Replication of DNS zone data between primary and secondary servers |
| **DNS Cache** | Temporary storage of DNS query results to speed up future lookups |
