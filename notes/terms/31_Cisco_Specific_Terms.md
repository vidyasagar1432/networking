# Cisco-Specific Terms

| Term | Definition |
|---|---|
| **IOS** | Internetwork Operating System — Cisco's legacy OS (routers/switches) |
| **IOS XE** | Linux-based IOS — modern, modular (Catalyst 9000, ISR 4000) |
| **NX-OS** | Data center OS — Nexus switches (feature-rich, modular) |
| **ROMMON** | ROM Monitor — low-level bootloader / recovery mode |
| **Startup Configuration** | Saved config loaded on boot (stored in NVRAM) |
| **Running Configuration** | Active config in RAM (changes take effect immediately) |
| **NVRAM** | Non-Volatile RAM — stores startup config (persists across reboots) |
| **Flash Memory** | Stores IOS images and files (persists across reboots) |
| **Bootloader** | Initial program that loads the OS (ROMMON on Cisco) |
| **License** | Software license enabling feature sets (e.g., IP Base, Security) |
| **Feature Set** | Collection of licensed features (LAN Base, IP Services, Advanced IP Services) |
