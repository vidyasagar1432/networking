# Troubleshooting

| Term | Definition |
|---|---|
| **Ping** | ICMP Echo Request/Reply — tests reachability and RTT |
| **Traceroute** | Traces path packets take to destination (ICMP Time Exceeded) |
| **Packet Capture** | Capturing network traffic for analysis (tcpdump, Wireshark) |
| **Mirror Port** | Switch port configured to copy traffic for monitoring (SPAN) |
| **Debug** | Verbose logging of events (use with caution — CPU intensive) |
| **Log** | Recorded events from network devices |
| **Baseline** | Normal performance metrics used as reference for comparison |
| **Root Cause Analysis (RCA)** | Process of identifying the underlying cause of an incident |
