# Wireless

| Term | Definition |
|---|---|
| **SSID** | Service Set Identifier — network name visible to clients |
| **BSSID** | Basic Service Set Identifier — MAC address of the AP's radio |
| **ESS** | Extended Service Set — multiple APs sharing the same SSID |
| **BSS** | Basic Service Set — a single AP and its associated clients |
| **Channel** | A frequency range used for wireless transmission |
| **Channel Width** | Bandwidth of a channel (20, 40, 80, 160 MHz) |
| **Roaming** | Client moves from one AP to another without losing connectivity |
| **RSSI** | Received Signal Strength Indicator — signal power level |
| **SNR** | Signal-to-Noise Ratio — signal strength relative to noise |
| **MIMO** | Multiple Input Multiple Output — multiple antennas for performance |
| **OFDM** | Orthogonal Frequency Division Multiplexing — subdivides spectrum into subcarriers |
| **Beamforming** | Focuses wireless signal toward a specific client |
| **Captive Portal** | Web page presented to users before granting network access |
