# Routing Tables

| Term | Definition |
|---|---|
| **Routing Table** | Database of known networks and next-hop information |
| **RIB** | Routing Information Base — all routes known to the router |
| **FIB** | Forwarding Information Base — optimized lookup table for packet forwarding |
| **Next Hop** | The next router IP to forward a packet toward its destination |
| **Exit Interface** | The outbound interface used to reach a destination |
| **Recursive Lookup** | Router looks up next-hop IP in routing table to find exit interface |
