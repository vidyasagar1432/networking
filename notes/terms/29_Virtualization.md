# Virtualization

| Term | Definition |
|---|---|
| **Hypervisor** | Software that creates and runs VMs (Type 1: bare-metal, Type 2: hosted) |
| **Virtual Machine** | Software emulation of a physical computer running an OS |
| **Container** | Lightweight, isolated environment sharing host OS kernel (Docker) |
| **Overlay** | Virtual network built on top of physical infrastructure |
| **Bridge Network** | Virtual switch connecting VMs/containers to each other and host |
| **Host-only Network** | Private virtual network isolated to the host machine |
