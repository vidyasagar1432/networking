# DHCP

| Term | Definition |
|---|---|
| **Lease** | The period an IP address is assigned to a client (must renew) |
| **Scope** | Range of IP addresses a DHCP server can assign |
| **Reservation** | Permanent IP assignment tied to a specific MAC address (static DHCP) |
| **Exclusion Range** | IP addresses excluded from DHCP assignment (used by static devices) |
| **Relay Agent** | Router that forwards DHCP broadcasts across subnets (ip helper-address) |
| **DHCP Pool** | Configuration container defining scope, gateway, DNS, lease time, etc. |
