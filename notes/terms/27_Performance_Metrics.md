# Performance Metrics

| Term | Definition |
|---|---|
| **Throughput** | Actual data transfer rate (bits per second) |
| **Bandwidth** | Maximum possible data transfer rate |
| **Goodput** | Useful application data rate (excludes headers/retransmissions) |
| **Utilization** | Percentage of bandwidth currently in use |
| **RTT** | Round Trip Time — time for packet to travel to destination and back |
| **One-Way Delay** | Time for packet to travel one direction |
| **Availability** | Percentage of time a system is operational |
| **Uptime** | Time since last reboot/outage |
| **MTBF** | Mean Time Between Failures — average time between failures |
| **MTTR** | Mean Time To Repair — average time to restore after failure |
