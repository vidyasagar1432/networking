# High Availability

| Term | Definition |
|---|---|
| **Redundancy** | Duplicate components to eliminate single points of failure |
| **Failover** | Automatic switch to standby component when primary fails |
| **Active/Standby** | One active, one standby (fails over if active fails) |
| **Active/Active** | Both components active simultaneously (load sharing + failover) |
| **First Hop Redundancy** | Protocols providing default gateway redundancy (HSRP, VRRP, GLBP) |
| **Load Sharing** | Distributing traffic across multiple active components |
