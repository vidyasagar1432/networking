# MPLS

| Term | Definition |
|---|---|
| **Label** | 20-bit identifier used for MPLS forwarding decisions |
| **LSP** | Label Switched Path — path through MPLS network |
| **LER** | Label Edge Router — ingress/egress (pushes/pops labels) |
| **LSR** | Label Switch Router — transit (swaps labels) |
| **VRF** | Virtual Routing and Forwarding — separate routing table per VPN |
| **PE Router** | Provider Edge — connects customer to MPLS network |
| **CE Router** | Customer Edge — customer router connected to PE |
