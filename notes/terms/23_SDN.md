# SDN

| Term | Definition |
|---|---|
| **Control Plane** | Makes forwarding decisions (routing protocols, logic) |
| **Data Plane** | Forwards packets based on control plane decisions |
| **Management Plane** | Configuration, monitoring, and administration |
| **Overlay Network** | Virtual network built on top of physical underlay |
| **Underlay Network** | Physical infrastructure supporting the overlay |
| **Fabric** | Flat, scalable network architecture (Spine/Leaf, VXLAN EVPN) |
| **Intent-Based Networking** | Declarative network management (specify intent, system configures) |
