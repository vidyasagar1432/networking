# Automation

| Term | Definition |
|---|---|
| **API** | Application Programming Interface — programmatic interface to a system |
| **REST API** | Representational State Transfer — HTTP-based API (GET, POST, PUT, DELETE) |
| **JSON** | JavaScript Object Notation — lightweight data format |
| **YAML** | YAML Ain't Markup Language — human-readable data serialization |
| **XML** | Extensible Markup Language — structured data format |
| **Ansible** | Automation tool — agentless, YAML playbooks |
| **NETCONF** | Network Configuration Protocol — XML over SSH (RFC 6241) |
| **RESTCONF** | RESTful NETCONF — JSON/XML over HTTP (RFC 8040) |
| **YANG** | Yet Another Next Generation — data modeling language |
| **gNMI** | gRPC Network Management Interface — streaming telemetry + config |
| **Infrastructure as Code (IaC)** | Managing infrastructure through declarative configuration files |
