# 802.1X (Port-Based Network Access Control)

## Overview
- **IEEE 802.1X** — port-based authentication for wired/wireless
- Prevents unauthorized devices from accessing the network
- Uses **EAP** (Extensible Authentication Protocol) over **RADIUS**

## Architecture
```
Supplicant ──EAP over LAN (EAPoL)──→ Authenticator ──RADIUS──→ Authentication Server (RADIUS)
   (Client)                    (Switch/AP)                  (FreeRADIUS, Cisco ISE, Aruba ClearPass)
```

| Role | Description |
|---|---|
| **Supplicant** | End device requesting access (laptop, phone) |
| **Authenticator** | NAS (switch/AP) — controls port access |
| **Authentication Server (AS)** | RADIUS server — validates credentials |

## EAP (Extensible Authentication Protocol)
- Framework, not a single method
- Carried inside EAPoL (LAN) or EAP over RADIUS

### Common EAP Methods
| Method | Description | Security |
|---|---|---|
| **EAP-MD5** | Password hash (no mutual auth) | Weak |
| **EAP-TLS** | Mutual certificate-based | Strong |
| **EAP-TTLS** | Tunneled TLS (server cert + inner PAP/CHAP/MSCHAP) | Strong |
| **PEAP** | Protected EAP (server cert + inner MSCHAPv2/GTC) | Strong |
| **EAP-FAST** | Flexible Auth via Secure Tunneling (Cisco, PAC-based) | Strong |
| **LEAP** | Legacy Cisco (MSCHAPv2, crackable) | Weak |

## EAPoL (EAP over LAN)
- **EtherType**: 0x888E
- **EAPoL-Start** — Supplicant initiates (or authenticator sends Identity Request)
- **EAPoL-Logoff** — Supplicant deauthenticates
- **EAPoL-Key** — Key exchange (WPA/WPA2)

## 802.1X Port States
| State | Description |
|---|---|
| **Unauthorized** | Port blocked — only EAPoL traffic allowed |
| **Authorized** | Port open — all traffic allowed |

## Authentication Flow
```
1. Supplicant connects
2. Authenticator sends EAP-Request/Identity
3. Supplicant responds EAP-Response/Identity
4. Authenticator forwards to RADIUS (Access-Request)
5. RADIUS ↔ Supplicant EAP exchange (credentials, certs)
6. RADIUS sends Access-Accept/Reject
7. Authenticator sets port to Authorized/Unauthorized
```

## MAB (MAC Authentication Bypass)
- Fallback for devices that don't support 802.1X (printers, IoT)
- Authenticator sends device MAC as username/password to RADIUS
- RADIUS checks MAC against allowed list

## Config Example (Cisco Switch)
```cisco
aaa new-model
aaa authentication dot1x default group radius
aaa authorization network default group radius

dot1x system-auth-control

interface GigabitEthernet0/1
 switchport mode access
 authentication port-control auto        # Enable 802.1X
 dot1x pae authenticator
 dot1x timeout tx-period 30              # Wait for supplicant
 dot1x max-req 3
 spanning-tree portfast
```

## Config Example (WLC)
```bash
config wlan security 802.1x enable 1
config wlan radius server add 1 192.168.1.100 1812 sharedsecret
config wlan radius accounting add 1 192.168.1.100 1813 sharedsecret
```
