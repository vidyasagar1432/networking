# 1. Overview

A socket is a Layer 4 communication endpoint that identifies a specific application running on a device. CCNA tests the relationship between IP addresses, port numbers, TCP/UDP protocols, and how applications establish network connections.

---

# 2. Core Concepts

# Socket Definition

A socket is:

```
IP Address + Port Number
```

It identifies:

```
A specific application on a specific device
```

Example:

```
192.168.1.10:443
```

Means:

```
Device:
192.168.1.10

Application:
HTTPS service

Port:
443
```

---

# Socket Components

| Component | Function |
|---|---|
| IP Address | Identifies the host/device |
| Port Number | Identifies the application/service |
| Protocol | Defines communication method (TCP/UDP) |

---

# IP Address vs Port Number

| Item | Identifies |
|---|---|
| MAC Address | Network interface on local LAN |
| IP Address | Device on network |
| Port Number | Application on device |
| Socket | Application endpoint |

# Client and Server Socket

A TCP connection requires two sockets:

```
Client Socket
+
Server Socket
```

Example:

```
Client                         Server

192.168.1.50:50000  ----->  192.168.1.10:443
```

---

# Socket Pair

A complete TCP session is identified by:

```
Source Socket
+
Destination Socket
```

Example:

```
192.168.1.50:50000
          |
          |
          v
192.168.1.10:443
```

---

# 5-Tuple Connection Identification

TCP uniquely identifies connections using:

```
5-Tuple
```

| Component | Example |
|---|---|
| Source IP | 192.168.1.50 |
| Destination IP | 192.168.1.10 |
| Source Port | 50000 |
| Destination Port | 443 |
| Protocol | TCP |

---

# Why 5-Tuple Is Needed

Example:

One server:

```
192.168.1.10
```

Multiple clients:

```
Client 1:
192.168.1.20:50000

Client 2:
192.168.1.30:50001
```

Both connect:

```
192.168.1.10:443
```

The server distinguishes sessions using:

```
5-Tuple
```

# 5. Exam Traps

- A socket is IP address + port number.
- IP identifies the device; port identifies the application.
- MAC addresses do not identify applications.
- TCP connections use a 5-tuple.
- Server ports are usually well-known ports.
- Client ports are usually ephemeral ports.
- Port 443 identifies HTTPS, not the device.
- Multiple applications can share one IP address using different ports.
- TCP uses sockets to maintain individual sessions.
- UDP also uses ports but does not establish sessions.
- NAT modifies IP addresses and port numbers.
- Port numbers operate at Layer 4.

# 7. Practice Questions

## Question 1

What identifies a specific application on a device?

A. MAC address  
B. Port number  
C. VLAN ID  
D. Subnet mask  

### Answer: B

Explanation:

Port numbers identify applications.

---

## Question 2

What is a socket?

A. MAC + VLAN  
B. IP + Port  
C. Router + Switch  
D. IP + MAC  

### Answer: B

Explanation:

A socket is an IP address combined with a port number.

---

## Question 3

Which port is normally used by a client?

A. TCP 443  
B. TCP 22  
C. Dynamic port  
D. TCP 53  

### Answer: C

Explanation:

Clients normally use ephemeral ports.

---

## Question 4

Which information identifies a TCP connection?

A. MAC address only  
B. IP address only  
C. 5-tuple  
D. VLAN number  

### Answer: C

Explanation:

TCP uses source/destination IP, ports, and protocol.

---

## Question 5

A server hosts HTTPS and SSH on the same IP address. How are they separated?

A. MAC address  
B. Port numbers  
C. Subnet masks  
D. ARP  

### Answer: B

Explanation:

HTTPS uses port 443 and SSH uses port 22.
