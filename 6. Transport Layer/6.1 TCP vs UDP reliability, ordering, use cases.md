# 1. Overview

TCP (Transmission Control Protocol) and UDP (User Datagram Protocol) are Layer 4 transport protocols used for end-to-end communication between applications. CCNA tests their differences, reliability mechanisms, connection behavior, port numbers, and common application use cases.

---

# 2. Core Concepts

# Transport Layer Role

OSI Layer:

```
Layer 4 - Transport Layer
```

Main functions:

| Function | Purpose |
|---|---|
| Segmentation | Break data into smaller units |
| Reassembly | Rebuild original data |
| Port numbers | Identify applications |
| Flow control | Prevent receiver overload |
| Error recovery | Detect/recover lost data |

---

# TCP (Transmission Control Protocol)

## Definition

TCP is a:

```
Connection-oriented, reliable transport protocol
```

Provides:

- Guaranteed delivery
- Ordered data transfer
- Error recovery
- Flow control

---

# UDP (User Datagram Protocol)

## Definition

UDP is a:

```
Connectionless, best-effort transport protocol
```

Provides:

- Faster transmission
- Lower overhead
- No delivery guarantee
- No ordering

---

# TCP vs UDP Comparison

| Feature | TCP | UDP |
|---|---|---|
| Connection | Connection-oriented | Connectionless |
| Reliability | Yes | No |
| Ordering | Yes | No |
| Acknowledgments | Yes | No |
| Retransmission | Yes | No |
| Flow control | Yes | No |
| Error recovery | Yes | No |
| Header size | 20-60 bytes | 8 bytes |
| Speed | Slower | Faster |
| Overhead | Higher | Lower |
| Communication | Stream-based | Datagram-based |

Purpose:

```

       <------------- SYN ACK

 ACK  ------------->

```

# TCP Reliability Mechanisms

| Mechanism | Function |
|---|---|
| Sequence numbers | Track data order |
| Acknowledgments | Confirm delivery |
| Retransmission | Resend lost segments |
| Checksum | Detect corruption |
| Sliding window | Flow control |

---

# Sequence Numbers

Purpose:

```
Maintain correct order of segments
```

Example:

Sender:

```
Segment 1
Segment 2
Segment 3
```

Receiver:

```
Segment 1
Segment 2
Segment 3
```

Even if packets arrive:

```
3,1,2
```

TCP reorders them.

---

# TCP Acknowledgment (ACK)

Receiver confirms received data.

Example:

Sender:

```
Send sequence 100
```

Receiver:

```
ACK 101
```

Meaning:

```
Received up to 100.
Send next byte 101.
```

---

# TCP Retransmission

If ACK is not received:

```
Sender waits
       |
       v
Timeout
       |
       v
Resend data
```

---

# TCP Flow Control

Uses:

```
Sliding Window
```

Purpose:

Prevent sender from overwhelming receiver.

---

# UDP Operation

UDP sends data immediately.

Process:

```
Application
     |
     v
UDP Segment
     |
     v
Network
```

No:

- Handshake
- ACK
- Retransmission

---

# UDP Advantages

| Advantage | Reason |
|---|---|
| Faster | No connection setup |
| Low overhead | Small header |
| Efficient | Good for real-time traffic |

# 5. Exam Traps

- TCP is connection-oriented.
- UDP is connectionless.
- TCP guarantees delivery; UDP does not.
- TCP uses sequence numbers and acknowledgments.
- UDP has lower overhead.
- UDP does not reorder packets.
- TCP header is larger than UDP header.
- DNS commonly uses UDP port 53.
- BGP uses TCP port 179.
- DHCP uses UDP ports 67 and 68.
- HTTPS uses TCP port 443.
- TCP is not always faster; UDP is preferred for latency-sensitive traffic.
- UDP can still use checksums for error detection.
- Reliable delivery happens at Layer 4, not Layer 3.

# 7. Practice Questions

## Question 1

Which protocol provides reliable, ordered delivery?

A. UDP  
B. TCP  
C. ICMP  
D. ARP  

### Answer: B

Explanation:

TCP uses acknowledgments, sequence numbers, and retransmissions.

---

## Question 2

Which transport protocol is used by BGP?

A. UDP 179  
B. TCP 179  
C. TCP 53  
D. UDP 161  

### Answer: B

Explanation:

BGP uses TCP port 179.

---

## Question 3

Which protocol is preferred for VoIP traffic?

A. TCP  
B. UDP  
C. FTP  
D. SMTP  

### Answer: B

Explanation:

VoIP prioritizes low latency.

---

## Question 4

What is the size of a UDP header?

A. 8 bytes  
B. 20 bytes  
C. 32 bytes  
D. 64 bytes  

### Answer: A

Explanation:

UDP has a fixed 8-byte header.

---

## Question 5

Which TCP feature ensures segments arrive in order?

A. VLAN tagging  
B. Sequence numbers  
C. MAC learning  
D. ARP cache  

### Answer: B

Explanation:

TCP uses sequence numbers to reorder segments.
