# 1. Overview

FTP, TFTP, and SFTP are file transfer protocols used to move files between network devices and servers. CCNA tests their transport protocols, port numbers, security differences, and common Cisco IOS uses such as transferring configurations and software images.

---

# 2. Core Concepts

# File Transfer Protocol Definition

| Protocol | Full Name | Purpose |
|---|---|---|
| FTP | File Transfer Protocol | Transfer files between client and server |
| TFTP | Trivial File Transfer Protocol | Simple file transfer with minimal features |
| SFTP | SSH File Transfer Protocol | Secure file transfer over SSH |

---

# Protocol Comparison

| Feature | FTP | TFTP | SFTP |
|---|---|---|---|
| Security | Low | None | High |
| Encryption | No | No | Yes |
| Authentication | Username/password | None | SSH authentication |
| Transport | TCP | UDP | TCP |
| Port | 20/21 | 69 | 22 |
| Reliability | High | Low | High |
| Complexity | High | Low | High |

---

# FTP (File Transfer Protocol)

## Purpose

FTP transfers files using:

```
Client ↔ FTP Server
```

Examples:

- Upload files
- Download files
- Manage directories

---

# FTP Characteristics

| Feature | Value |
|---|---|
| Layer | Application Layer |
| Transport | TCP |
| Control Port | TCP 21 |
| Data Port | TCP 20 |
| Authentication | Username/password |
| Encryption | No |

---

# FTP Ports

FTP uses two connections:

## Control Connection

```
TCP Port 21
```

Used for:

- Login
- Commands
- Session control

Example commands:

```
USER
PASS
LIST
GET
PUT
```

---

## Data Connection

```
TCP Port 20
```

Used for:

- File transfer

---

# FTP Modes

| Mode | Description |
|---|---|
| Active FTP | Server opens data connection to client |
| Passive FTP | Client opens data connection to server |

---

# FTP Active Mode

```
Client                  Server

TCP 21  ------------->

TCP 20  <-------------
```

Server initiates data connection.

---

# FTP Passive Mode

```
Client                  Server

TCP 21  ------------->

Client opens data connection
```

Common with firewalls/NAT.

---

# TFTP (Trivial File Transfer Protocol)

## Purpose

TFTP is a simple file transfer protocol mainly used for:

- Router configuration backup
- IOS image transfer
- Network booting

---

# TFTP Characteristics

| Feature | Value |
|---|---|
| Transport | UDP |
| Port | 69 |
| Authentication | None |
| Encryption | None |
| Directory support | No |
| Complexity | Simple |

---

# TFTP Operation

```
Client

  |
  | UDP 69
  |
  v

TFTP Server
```

---

# TFTP Limitations

| Limitation | Explanation |
|---|---|
| No authentication | Anyone can access if allowed |
| No encryption | Data visible |
| No directory browsing | Simple file access |
| UDP based | No guaranteed delivery |

---

# SFTP (SSH File Transfer Protocol)

## Purpose

Secure file transfer using SSH.

---

# SFTP Characteristics

| Feature | Value |
|---|---|
| Transport | TCP |
| Port | 22 |
| Security | SSH encryption |
| Authentication | Username/password or keys |
| Encryption | Yes |

---

# SFTP vs FTP

| Feature | FTP | SFTP |
|---|---|---|
| Encryption | No | Yes |
| Port | 20/21 | 22 |
| Protocol | FTP | SSH |
| Security | Weak | Strong |

---

# FTP vs TFTP vs SFTP Summary

| Feature | FTP | TFTP | SFTP |
|---|---|---|---|
| TCP/UDP | TCP | UDP | TCP |
| Port | 20/21 | 69 | 22 |
| Secure | No | No | Yes |
| Login | Yes | No | Yes |
| Encryption | No | No | Yes |
| Common Cisco use | File transfer | IOS/config backup | Secure transfer |

# 5. Exam Traps

- FTP uses TCP ports 20 and 21.
- FTP port 21 is for control, not data.
- FTP port 20 transfers data.
- TFTP uses UDP port 69.
- SFTP uses TCP port 22.
- SFTP is not the same as FTPS.
- TFTP has no authentication.
- TFTP has no encryption.
- Cisco commonly uses TFTP for configuration backup in CCNA labs.
- SFTP uses SSH security.
- FTP is reliable because it uses TCP.
- TFTP is simple because it uses UDP.
- FTP and SFTP support authentication; TFTP does not.
