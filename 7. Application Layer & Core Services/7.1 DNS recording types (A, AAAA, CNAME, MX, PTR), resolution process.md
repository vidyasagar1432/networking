# 1. Overview

Domain Name System (DNS) translates human-readable domain names into IP addresses used for network communication. CCNA tests DNS purpose, common record types, DNS hierarchy, client resolution process, and protocol/port usage.

---

# 2. Core Concepts

# DNS Definition

DNS:

```
A distributed database system that maps domain names
to IP addresses and other service information.
```

Example:

```
www.cisco.com
        |
        v
72.163.4.185
```

---

# DNS Purpose

| Function | Description |
|---|---|
| Name resolution | Converts names to IP addresses |
| Service discovery | Finds services like mail servers |
| Reverse lookup | Converts IP to name |
| Load distribution | Maps names to multiple IPs |

---

# DNS Layer and Protocol

| Item | Value |
|---|---|
| OSI Layer | Application Layer (Layer 7) |
| Protocol | DNS |
| Transport | UDP/TCP |
| Port | 53 |

---

# DNS Transport Usage

| Transport | Usage |
|---|---|
| UDP 53 | Normal DNS queries |
| TCP 53 | Zone transfers, large responses |

---

# DNS Components

| Component | Function |
|---|---|
| DNS Client (Resolver) | Requests name resolution |
| Recursive Resolver | Finds answers for clients |
| Root Server | Directs queries to TLD servers |
| TLD Server | Handles .com, .org, etc. |
| Authoritative Server | Provides final DNS records |

---


Levels:

| Level | Example |
|---|---|

# DNS Record Types

DNS records store information about domains.

---

# A Record

## Address Record

Maps:

```
Hostname → IPv4 Address
```

Example:

```
www.example.com

A

192.168.1.10
```

Format:

```
Name → IPv4
```

---

# AAAA Record

## IPv6 Address Record

Maps:

```
Hostname → IPv6 Address
```

Example:

```
www.example.com

AAAA

2001:db8::10
```

---

# CNAME Record

## Canonical Name Record

Creates:

```
Alias → Real hostname
```

Example:

```
shop.example.com

CNAME

www.example.com
```

Meaning:

```
shop.example.com
points to
www.example.com
```

---

# MX Record

## Mail Exchange Record

Defines:

```
Mail server for a domain
```

Example:

```
example.com

MX

mail.example.com
```

Used by:

```
Email delivery
```

---

# PTR Record

## Pointer Record

Used for:

```
Reverse DNS lookup
```

Maps:

```
IP Address → Hostname
```

Example:

```
192.168.1.10

PTR

server.example.com
```

---

# DNS Record Comparison

| Record | Full Name | Maps |
|---|---|---|
| A | Address | Name → IPv4 |
| AAAA | IPv6 Address | Name → IPv6 |
| CNAME | Canonical Name | Alias → Name |
| MX | Mail Exchange | Domain → Mail Server |
| PTR | Pointer | IP → Name |

---

# Forward vs Reverse Lookup

## Forward Lookup

Question:

```
What is the IP address of www.example.com?
```

Process:

```
Name → IP
```

Uses:

```
A / AAAA records
```

---

## Reverse Lookup

Question:

```
Who owns 192.168.1.10?
```

Process:

```
IP → Name
```

Uses:

```
PTR record
```

---

# DNS Resolution Process

## Example:

User enters:

```
www.example.com
```

---

# Step 1: Check Local Cache

Resolver checks:

```
Browser cache
OS cache
DNS cache
```

If found:

```
Return IP address
```

---

# Step 2: Query Recursive Resolver

Client sends:

```
DNS Query
```

to configured DNS server.

Example:

```
8.8.8.8
```

---

# Step 3: Recursive Resolver Queries Root Server

Root server responds:

```
Ask .com TLD server
```

---

# Step 4: Query TLD Server

.com server responds:

```
Ask authoritative server
```

---

# Step 5: Query Authoritative DNS Server

Authoritative server returns:

```
A Record:

www.example.com = 192.168.1.10
```

---

# Step 6: Response to Client

Resolver returns:

```
192.168.1.10
```

Client connects to:

```
192.168.1.10
```

---

# Recursive vs Iterative Queries

## Recursive Query

Client asks:

```
Give me the final answer.
```

Example:

```
PC → DNS Resolver
```

Resolver does all searching.

---

## Iterative Query

Server responds:

```
I don't know the answer,
but ask this server.
```

Example:

```
Root → TLD
```

---

# Recursive vs Iterative Comparison

| Feature | Recursive | Iterative |
|---|---|---|
| Client responsibility | Low | Higher |
| Server finds answer | Yes | No |
| Example | PC to resolver | DNS server hierarchy |

Purpose:


DNS responses include:

```
TTL (Time To Live)
```

Example:

```
TTL = 3600 seconds
```

Meaning:

Cache for:

```
1 hour
```

```bash
ip domain lookup
```

## Disable DNS Lookup

```bash
no ip domain lookup
```

```bash
nslookup www.example.com
```

Checks DNS response.

---

## Cisco IOS Ping by Name

```bash
ping www.example.com
```

IOS performs DNS lookup.

---

## View DNS Cache

```bash
show hosts
```

Displays cached hostname information.

# 5. Exam Traps

- DNS translates names to IP addresses.
- DNS operates at Layer 7.
- DNS normally uses UDP port 53.
- DNS uses TCP 53 for zone transfers and large responses.
- A record = IPv4 address.
- AAAA record = IPv6 address.
- CNAME = alias, not IP address.
- MX = mail server.
- PTR = reverse lookup.
- Forward lookup uses A/AAAA records.
- Reverse lookup uses PTR records.
- DNS does not assign IP addresses; DHCP does.
- Recursive resolver performs queries on behalf of clients.
- Root servers do not store all domain records.

# 7. Practice Questions

## Question 1

Which DNS record maps a hostname to an IPv4 address?

A. PTR  
B. MX  
C. A  
D. CNAME  

### Answer: C

Explanation:

A records store IPv4 address mappings.

---

## Question 2

Which DNS record is used for mail servers?

A. MX  
B. AAAA  
C. PTR  
D. A  

### Answer: A

Explanation:

MX identifies mail exchange servers.

---

## Question 3

Which DNS record performs reverse lookup?

A. CNAME  
B. PTR  
C. A  
D. MX  

### Answer: B

Explanation:

PTR maps IP addresses to hostnames.

---

## Question 4

What port does DNS normally use?

A. 22  
B. 80  
C. 53  
D. 443  

### Answer: C

Explanation:

DNS uses port 53.

---

## Question 5

A user types a website name. Which device normally performs recursive DNS lookup?

A. Switch  
B. DNS resolver  
C. Access point  
D. Firewall  

### Answer: B

Explanation:

The recursive resolver finds the final DNS answer for the client.
