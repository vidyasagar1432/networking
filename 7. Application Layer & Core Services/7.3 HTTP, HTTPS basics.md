# 1. Overview

HTTP and HTTPS are application-layer protocols used for communication between web clients and servers. CCNA tests HTTP/HTTPS ports, request-response operation, basic methods, status codes, and HTTPS security differences.

---

# 2. Core Concepts

# HTTP Definition

HTTP:

```
Hypertext Transfer Protocol
```

A protocol used to transfer:

- Web pages
- Images
- API data
- Application content

between:

```
Client (browser)
        |
        |
        v
Server (web server)
```

---

# HTTPS Definition

HTTPS:

```
HTTP Secure
```

HTTP combined with:

```
TLS (Transport Layer Security)
```

Provides:

| Feature | Purpose |
|---|---|
| Encryption | Protect data confidentiality |
| Authentication | Verify server identity |
| Integrity | Prevent data modification |

---

# HTTP/HTTPS Protocol Details

| Feature         | HTTP          | HTTPS                       |
| --------------- | ------------- | --------------------------- |
| OSI Layer       | Layer 7       | Layer 7                     |
| Transport       | TCP           | TCP                         |
| Port            | 80            | 443                         |
| Security        | No encryption | TLS encryption              |
| Data protection | None          | Confidentiality + integrity |

---

# HTTP Communication Model

HTTP uses:

```
Client-Server Model
```

Example:

```

      |
      | HTTP Request
      v

      | HTTP Response
```

# HTTP Request-Response Process


# 5. Exam Traps

- HTTP operates at Layer 7.
- HTTP uses TCP port 80.
- HTTPS uses TCP port 443.
- HTTPS is HTTP + TLS, not a different application protocol.
- TLS provides encryption, authentication, and integrity.
- DNS happens before HTTP communication.
- HTTP itself does not encrypt data.
- HTTP/3 uses QUIC over UDP 443.
- GET retrieves information.
- POST sends information.
- 404 means resource not found.
- 403 means access forbidden.
- 500 indicates server-side error.
- HTTPS requires certificates.
- TCP handshake occurs before HTTP communication.

# 7. Practice Questions

## Question 1

Which port is used by HTTPS?

A. 21  
B. 53  
C. 80  
D. 443  

### Answer: D

Explanation:

HTTPS uses TCP port 443.

---

## Question 2

What provides encryption for HTTPS?

A. DNS  
B. TLS  
C. DHCP  
D. ARP  

### Answer: B

Explanation:

HTTPS uses TLS for secure communication.

---

## Question 3

A browser requests a web page. Which HTTP method is normally used?

A. GET  
B. DELETE  
C. PATCH  
D. TRACE  

### Answer: A

Explanation:

GET retrieves resources from servers.

---

## Question 4

Which HTTP status code means "Not Found"?

A. 200  
B. 301  
C. 404  
D. 500  

### Answer: C

Explanation:

404 indicates requested resource does not exist.

---

## Question 5

Before HTTPS data exchange, what occurs first?

A. DHCP  
B. TLS handshake  
C. DNS zone transfer  
D. ARP reply  

### Answer: B

Explanation:

HTTPS establishes TCP, then performs TLS handshake before encrypted HTTP communication.
