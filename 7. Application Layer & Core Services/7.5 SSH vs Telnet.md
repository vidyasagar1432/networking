# 1. Overview

SSH and Telnet are remote-access protocols used to manage network devices through a command-line interface (CLI). CCNA tests the difference between secure and insecure remote access, port numbers, encryption methods, and Cisco IOS configuration for SSH.

---

# 2. Core Concepts

# Remote Access Protocol Definition

Remote access allows an administrator to:

```
Access and configure a device from another location
```

Example:

```
Administrator PC

       |
       |
       v

Cisco Router/Switch CLI
```

---

# SSH (Secure Shell)

SSH:

```
Secure Shell
```

A secure remote-access protocol that provides encrypted CLI access to network devices.

---

# Telnet

Telnet:

```
Telecommunication Network
```

An older remote-access protocol that provides unencrypted CLI access.

---

# SSH vs Telnet Comparison

| Feature | SSH | Telnet |
|---|---|---|
| Security | Secure | Insecure |
| Encryption | Yes | No |
| Authentication | Yes | Yes (but credentials exposed) |
| Transport | TCP | TCP |
| Port | 22 | 23 |
| Data protection | Encrypted | Plain text |
| Recommended use | Yes | No |
| OSI Layer | Layer 7 | Layer 7 |

---

# Protocol Details

| Protocol | Port | Transport |
|---|---:|---|
| SSH | TCP 22 | TCP |
| Telnet | TCP 23 | TCP |

---

# Telnet Operation

Telnet sends all information as plain text.

Example:

```
Username:
admin

Password:
cisco123
```

Network capture:

```
admin
cisco123
```

can be viewed by attackers.

---

# SSH Operation

SSH creates an encrypted session.

Example:

```
Username:
admin

Password:
********
```

Captured traffic:

```
Encrypted Data
```

---

| Feature | Purpose |
|---|---|

# Cisco SSH Configuration

## Step 1: Configure Hostname

```bash
hostname R1
```

Sets device name.

---

## Step 2: Configure Domain Name

```bash
ip domain-name example.com
```

Required for RSA key generation.

---

## Step 3: Create Local User

```bash
username admin privilege 15 secret Cisco123
```

Creates local administrator account.

---

## Step 4: Generate RSA Keys

```bash
crypto key generate rsa
```

Creates encryption keys for SSH.

Example:

```
How many bits in modulus [512]:
2048
```

---

## Step 5: Enable SSH Version 2

```bash
ip ssh version 2
```

Uses secure SSHv2.

---

## Step 6: Configure VTY Lines

```bash
line vty 0 4
```

Selects remote access lines.

---

Enable SSH only:

```bash
transport input ssh
```

Allows SSH connections.

---

Use local authentication:

```bash
login local
```

Uses configured username/password.

---

# Complete SSH Configuration Example

```bash
hostname R1

ip domain-name cisco.com

username admin privilege 15 secret Cisco123

crypto key generate rsa

ip ssh version 2

line vty 0 4
 login local
 transport input ssh
```

# 5. Exam Traps

- SSH uses TCP port 22.
- Telnet uses TCP port 23.
- SSH encrypts traffic.
- Telnet sends traffic in plain text.
- SSH is preferred for device management.
- SSH requires RSA keys on Cisco IOS.
- `transport input ssh` allows only SSH.
- `transport input telnet` allows only Telnet.
- `transport input ssh telnet` allows both.
- SSH operates at the application layer.
- SSH and Telnet both provide CLI remote access.
- Telnet authentication does not make the session secure.
- SSHv2 is preferred over SSHv1.
- HTTPS is not a replacement for SSH; HTTPS is web-based management.

Which protocol provides encrypted remote CLI access?

A. FTP  
B. Telnet  
C. SSH  
D. HTTP  

### Answer: C

Explanation:

SSH encrypts remote CLI communication.

## Question 2

Which TCP port is used by SSH?

A. 21  
B. 22  
C. 23  
D. 80  

### Answer: B

Explanation:

SSH uses TCP port 22.

## Question 3

Why is Telnet considered insecure?

A. Uses UDP  
B. Does not support passwords  
C. Sends data in plain text  
D. Cannot connect remotely  

### Answer: C

Explanation:

Telnet does not encrypt usernames, passwords, or commands.

---

## Question 4

Which Cisco command restricts VTY access to SSH only?

A. login ssh  
B. transport input ssh  
C. ssh enable  
D. ip ssh enable  

### Answer: B

Explanation:

`transport input ssh` allows SSH connections only.
