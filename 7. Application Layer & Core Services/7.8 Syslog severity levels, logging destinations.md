# 1. Overview

Syslog is a standard protocol used to collect, store, and analyze system messages generated by network devices. CCNA tests Syslog message format, severity levels (0–7), logging destinations, and Cisco IOS logging configuration.

---

# 2. Core Concepts

# Syslog Definition

Syslog:

```
System Logging Protocol
```

Purpose:

- Collect device events
- Troubleshoot network issues
- Monitor security events
- Maintain audit records

# Syslog Message Format

Cisco Syslog message:

```
%FACILITY-SEVERITY-MNEMONIC: Message
```

Example:

```
%LINK-3-UPDOWN: Interface GigabitEthernet0/1 changed state to down
```

---

# Syslog Message Components

| Field | Meaning |
|---|---|
| Facility | Source of message |
| Severity | Importance level |
| Mnemonic | Short message identifier |
| Description | Detailed event |

---

# Facility Codes

Facility identifies the source of the message.

Common Cisco facilities:

| Facility | Source |
|---|---|
| LINK | Interface changes |
| LINEPROTO | Line protocol events |
| SYS | System messages |
| CONFIG | Configuration changes |
| OSPF | OSPF events |

---

# Syslog Severity Levels

Syslog uses:

```
0–7 scale
```

Lower number:

```
Higher severity
```

---

# Severity Level Table

| Level | Name | Keyword | Meaning |
|---|---|---|---|
| 0 | Emergencies | emergency | System unusable |
| 1 | Alerts | alert | Immediate action required |
| 2 | Critical | critical | Critical conditions |
| 3 | Errors | error | Error conditions |
| 4 | Warnings | warning | Warning conditions |
| 5 | Notifications | notification | Normal but significant |
| 6 | Informational | informational | Informational messages |
| 7 | Debugging | debugging | Debug messages |

---

# Severity Mnemonic

Remember:

```
0 = Emergency
1 = Alert
2 = Critical
3 = Error
4 = Warning
5 = Notification
6 = Informational
7 = Debug
```

# Severity Filtering

Example:

Configuration:

```

```

Means:

Display:

```
0 through 4
```

Because severity includes all higher-priority messages.

# Syslog Logging Destinations

Cisco IOS supports multiple logging destinations.

| Destination | Description |
|---|---|
| Console | Messages displayed on console |
| VTY terminal | Messages displayed on remote sessions |
| Buffer | Stored in device memory |
| Syslog server | Sent to external server |
| SNMP trap | Forwarded as SNMP notifications |

---

# Console Logging

Default destination:

```
Console
```

Used during:

- Local troubleshooting
- Initial configuration

---

# Buffered Logging

Stores messages in RAM.

Example:

```
Router memory
```

View:

```bash
show logging
```

---

# Terminal Logging

Displays messages on active VTY sessions.

Example:

```
SSH session
```

Enable:

```bash

```

---

# Syslog Server Logging

Sends messages to external server.

Benefits:

- Centralized storage
- Long-term history
- Multiple device monitoring

# Syslog vs SNMP Trap

| Feature | Syslog | SNMP Trap |
|---|---|---|
| Purpose | Event logging | Event notification |
| Transport | UDP/TCP | UDP |
| Port | 514 | 162 |
| Storage | Logs | NMS event |
| Example | Interface down message | Alert notification |

# Syslog and NTP Relationship

Syslog requires accurate timestamps.

Without NTP:

```
Router A:
10:01

Router B:
10:15
```

Difficult troubleshooting.

With NTP:

```
All devices:
10:05
```

# 5. Exam Traps

- Syslog severity numbers are reversed:
  - 0 = highest severity
  - 7 = lowest severity
- Lower number means more important.
- Syslog default port is UDP 514.
- SNMP traps use UDP 162, not Syslog.
- `logging trap` controls messages sent to Syslog server.
- `logging buffered` stores messages locally.
- `terminal monitor` displays logs in VTY sessions.
- Syslog does not synchronize time; NTP does.
- Syslog is for event messages, not configuration backup.
- A severity setting includes all levels above it.

# 7. Practice Questions

## Question 1

Which Syslog severity level is the most critical?

A. 7  
B. 5  
C. 3  
D. 0  

### Answer: D

Explanation:

Severity 0 (Emergency) is the highest priority.

---

## Question 2

Which port does Syslog commonly use?

A. UDP 53  
B. UDP 161  
C. UDP 162  
D. UDP 514  

### Answer: D

Explanation:

Syslog commonly uses UDP port 514.

---

## Question 3

Which command displays stored Syslog messages?

A. show logs  
B. show logging  
C. show syslog  
D. show events  

### Answer: B

Explanation:

`show logging` displays Syslog configuration and messages.

## Question 4

A router must send only warning and higher messages to a Syslog server. Which command is correct?

A. logging trap warnings  
B. logging buffered warnings  
C. logging console warnings  
D. trap warnings enable  

### Answer: A

Explanation:

`logging trap warnings` controls messages sent to Syslog servers.

Which Syslog destination stores messages in router memory?
