# 1. Overview

Network Time Protocol (NTP) synchronizes clocks between network devices using a hierarchical time system. CCNA tests NTP purpose, stratum levels, client/server operation, and Cisco IOS NTP configuration.

---

# 2. Core Concepts

# NTP Definition

NTP:

```
Network Time Protocol
```

Purpose:

```
Synchronize time across network devices.
```

---

# Why NTP Is Important

Accurate time is required for:

| Function | Reason |
|---|---|
| Logs | Match events across devices |
| Troubleshooting | Analyze incidents |
| Security | Validate authentication events |
| Certificates | Check validity periods |
| Monitoring | Accurate timestamps |

---

# NTP Protocol Details

|---|---|

| Protocol | NTP |

# NTP Components

| Component | Function |
|---|---|
| Reference Clock | Provides accurate time source |
| NTP Server | Provides time to clients |
| NTP Client | Synchronizes its clock |
| NTP Peer | Exchanges time with another NTP device |

---

# NTP Stratum

Stratum indicates:

```
Distance from the reference clock.
```

Lower number:

```
More accurate source
```

---

# Stratum Levels

| Stratum | Description |
|---|---|
| Stratum 0 | Reference clocks |
| Stratum 1 | Directly connected to reference clock |
| Stratum 2 | Synchronizes from Stratum 1 |
| Stratum 3 | Synchronizes from Stratum 2 |
| Higher stratum | Less accurate |

---

# Stratum Hierarchy

```

        |
        v

        |
        v

        |
        v

```

---

# Stratum Rules

| Rule | Meaning |
|---|---|
| Lower stratum | Better accuracy |
| Stratum 0 | Not a network server |
| Stratum 16 | Unsynchronized |

---

# NTP Synchronization Process

Example:

```
Router
   |
   |
   v
NTP Server
```

Steps:

1. Client sends NTP request.
2. Server responds with current time.
3. Client calculates delay.
4. Client adjusts clock.
5. Time becomes synchronized.

---

# NTP Modes

| Mode | Description |
|---|---|
| Client | Gets time from server |
| Server | Provides time |
| Peer | Both devices synchronize |
| Broadcast | Server sends time without request |

# Cisco NTP Configuration

## Configure NTP Client

Example:

NTP server:

```
192.168.1.100
```

Command:

```bash
ntp server 192.168.1.100
```

Device synchronizes with NTP server.

---

# Configure NTP Master

Example:

```bash
ntp master 5
```

Makes router an NTP server.

Number:

```
5
```

represents stratum.

---

# Configure NTP Authentication

Enable authentication:

```bash
ntp authenticate
```

---

Create key:

```bash
ntp authentication-key 1 md5 NTPpass
```

---

Use key:

```bash
ntp trusted-key 1
```

---

Apply key:

```bash
ntp server 192.168.1.100 key 1
```

---

# Configure Timezone

Example:

```bash
clock timezone IST 5 30
```

Sets timezone.

---

# Manually Set Clock

```bash
clock set 12:00:00 11 JUL 2026
```

Sets device clock manually.

# NTP Troubleshooting

| Problem | Possible Cause |
|---|---|
| Not synchronized | Wrong server IP |
| Stratum 16 | No valid source |
| Wrong time | Timezone issue |
| Authentication failure | Key mismatch |
| No response | UDP 123 blocked |

---

# NTP Security

Threats:

| Threat | Description |
|---|---|
| Fake time source | Attacker provides incorrect time |
| Replay attacks | Old timestamps reused |
| DoS | NTP service overload |

Protection:

- Use NTP authentication
- Restrict NTP sources
- Use trusted servers

Without NTP:

```

10:01:05

```

Logs are difficult to compare.

With NTP:

```

```

Troubleshooting becomes easier.

# 5. Exam Traps

- NTP uses UDP port 123.
- NTP operates at Layer 7.
- Lower stratum means better accuracy.
- Stratum 0 devices are reference clocks.
- Stratum 1 servers connect directly to reference clocks.
- Stratum 16 means unsynchronized.
- NTP does not provide IP addressing.
- NTP is used for time synchronization, not clock speed adjustment.
- `ntp master` makes a Cisco device an NTP server.
- NTP authentication prevents fake time sources.
- Syslog accuracy depends on synchronized clocks.
- NTP client requests time; server provides time.

Which protocol synchronizes time between network devices?

A. DNS  
B. DHCP  
C. NTP  
D. SNMP  

### Answer: C

Explanation:

NTP provides network time synchronization.

## Question 2

Which NTP stratum is the most accurate?

A. Stratum 1  
B. Stratum 5  
C. Stratum 10  
D. Stratum 16  

### Answer: A

Explanation:

Lower stratum values indicate closer reference clocks.

## Question 3

Which UDP port does NTP use?

A. 53  
B. 67  
C. 123  
D. 161  

### Answer: C

Explanation:

NTP uses UDP port 123.

## Question 4

A router shows Stratum 16. What does this mean?

A. Excellent accuracy  
B. It is a reference clock  
C. It is not synchronized  
D. It is an NTP master  

### Answer: C

Explanation:

Stratum 16 indicates no valid NTP synchronization.
