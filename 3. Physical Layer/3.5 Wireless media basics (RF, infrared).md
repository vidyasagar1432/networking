# 1. Overview

Wireless media transmits data without physical cables by using electromagnetic waves. CCNA tests wireless fundamentals such as radio frequency (RF), infrared transmission, frequency bands, interference, and basic wireless characteristics.

---

# 2. Core Concepts

# Wireless Communication

## Definition

Wireless networking uses electromagnetic signals to transmit data through air instead of copper or fiber.

Transmission methods:

| Medium | Signal Type |
|---|---|
| Copper | Electrical signals |
| Fiber | Light pulses |
| Wireless RF | Radio waves |
| Infrared | Infrared light |

---

# Electromagnetic Spectrum

Wireless technologies operate within the electromagnetic spectrum.

```
Low Frequency
        |
        v
Radio → Microwave → Infrared → Visible Light → X-Ray
```

# Wireless Media Types

|---|---|---|---|

# Radio Frequency (RF)

## Definition

RF uses radio waves to transmit data through the air.

Common wireless technologies:

| Technology | Usage |
|---|---|
| Wi-Fi | WLAN |
| Bluetooth | Personal devices |
| Cellular | Mobile networks |
| Zigbee | IoT devices |

---

# RF Characteristics

| Feature | Description |
|---|---|
| Signal type | Electromagnetic wave |
| Medium | Air |
| Direction | Omnidirectional or directional |
| Range | Medium to long |
| Interference | Possible |
| Security | Requires encryption |

---

# RF Frequency Measurements

## Hertz (Hz)

Frequency represents the number of cycles per second.

| Unit | Value |
|---|---:|
| Hz | 1 cycle/sec |
| kHz | 1,000 cycles/sec |
| MHz | 1,000,000 cycles/sec |
| GHz | 1,000,000,000 cycles/sec |

---

# Wi-Fi Frequency Bands

| Band | Frequency | Characteristics |
|---|---|---|
| 2.4 GHz | 2.400-2.483 GHz | Longer range, more interference |
| 5 GHz | 5.150-5.850 GHz | Higher speed, shorter range |
| 6 GHz | 5.925-7.125 GHz | Newer Wi-Fi 6E/7 band |

# Antenna Types

## Omnidirectional Antenna

Signal spreads in all directions.

```
      ↑
   ↖  |  ↗
←----AP----→
   ↙  |  ↘
      ↓
```

Usage:

- Office WLAN
- Indoor environments

---

## Directional Antenna

Signal focuses in one direction.

```
AP  -------------->
```

Usage:

- Point-to-point links
- Long-distance connections

# Infrared (IR)

## Definition

Infrared uses light waves just below visible light frequencies.

---

# Infrared Characteristics

| Feature | Description |
|---|---|
| Signal type | Light |
| Range | Very short |
| Direction | Usually line-of-sight |
| Wall penetration | Cannot pass through walls |
| Interference | Less RF interference |

---

# Infrared Applications

| Usage | Example |
|---|---|
| Remote controls | TV remotes |
| Short-range communication | Older devices |
| Sensors | Motion detection |

---

# RF vs Infrared Comparison

| Feature | RF | Infrared |
|---|---|---|
| Signal | Radio waves | Light waves |
| Range | Longer | Short |
| Wall penetration | Possible | No |
| Direction | Omni/directional | Mostly line-of-sight |
| Common networking use | Wi-Fi | Rare |

# 5. Exam Traps

- RF uses radio waves, not light.
- Infrared requires line-of-sight.
- Infrared cannot pass through walls.
- 2.4 GHz has better range but more interference.
- 5 GHz provides higher speed but shorter range.
- 6 GHz is used by newer Wi-Fi technologies.
- dBm values are negative; closer to zero means stronger signal.
- Microwave ovens commonly interfere with 2.4 GHz.
- Omnidirectional antennas send signals in all directions.
- Directional antennas focus signals in one direction.
- Wireless communication is half-duplex in many WLAN scenarios.

# 7. Practice Questions

## Question 1

Which wireless medium is used by Wi-Fi?

A. Infrared  
B. RF  
C. Fiber  
D. Copper  

### Answer: B. RF

Explanation:

Wi-Fi operates using radio frequency signals.

---

## Question 2

Which frequency band typically has better range?

A. 5 GHz  
B. 6 GHz  
C. 2.4 GHz  
D. Infrared  

### Answer: C. 2.4 GHz

Explanation:

Lower frequency signals generally travel farther.

---

## Question 3

Which antenna type is best for a point-to-point wireless bridge?

A. Omnidirectional  
B. Directional  
C. Internal antenna  
D. Patch cable  

### Answer: B. Directional

Explanation:

Directional antennas focus RF energy between two locations.

---

## Question 4

What unit measures wireless signal strength?

A. Mbps  
B. dBm  
C. GHz  
D. Volt  

### Answer: B. dBm

Explanation:

dBm measures received signal power.

---

## Question 5

Which device commonly causes interference on 2.4 GHz Wi-Fi?

A. Fiber cable  
B. Microwave oven  
C. Router CPU  
D. Ethernet switch  

### Answer: B. Microwave oven

Explanation:

Microwave ovens operate near the 2.4 GHz frequency range.
