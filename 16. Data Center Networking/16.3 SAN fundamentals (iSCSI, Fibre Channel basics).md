# SAN Fundamentals: iSCSI and Fibre Channel Basics

## CCNP Enterprise (ENCOR 350-401) & CCNP Data Center (DCCOR) Level

**CCNA Relevance: Basic awareness of storage networking.**  
**CCNP ENCOR Relevance: Medium — Understanding enterprise storage connectivity and protocols is beneficial.**  
**CCNP Data Center Relevance: High — SANs, Fibre Channel, FCoE, and iSCSI are core storage networking technologies.**

---

# 1. Overview

A **Storage Area Network (SAN)** is a **high-speed, dedicated network** that provides block-level storage access to servers.

Instead of storing data locally inside each server, storage devices are centralized in a SAN and shared among multiple servers.

This architecture improves:

- Availability
- Scalability
- Performance
- Backup and recovery
- Disaster recovery

---

# 2. Storage Types

Enterprise storage is commonly divided into three categories:

| Storage Type | Access Method | Typical Protocols |
|--------------|--------------|-------------------|
| DAS (Direct Attached Storage) | Directly connected | SATA, SAS, NVMe |
| NAS (Network Attached Storage) | File-level | NFS, SMB/CIFS |
| SAN (Storage Area Network) | Block-level | Fibre Channel, iSCSI, FCoE |

---

# 3. Direct Attached Storage (DAS)

```
+---------+     SATA/SAS/NVMe     +---------+
| Server  | --------------------> |  Disk   |
+---------+                       +---------+
```

### Characteristics

- Simple
- Low cost
- Limited scalability
- Storage dedicated to one server

---

# 4. Network Attached Storage (NAS)

```
              Ethernet LAN

+---------+        |        +-----------+
| Server  |--------|--------|    NAS    |
+---------+        |        +-----------+
                   |
              Other Clients
```

### Characteristics

- File-level access
- Uses standard Ethernet
- Shared folders
- Easy deployment

Examples:

- Windows File Server
- Synology NAS
- QNAP
- NetApp NAS

---

# 5. Storage Area Network (SAN)

```
          SAN Switch

      +---------------+

      | Fibre Channel |

      +---------------+

       /             \

+---------+      +-----------+

| Server  |      | Storage   |

+---------+      +-----------+
```

Servers view remote storage as if it were a locally attached disk.

---

↓

# 10. Logical Unit Number (LUN)

A **LUN (Logical Unit Number)** represents a logical block storage device presented by the storage array.

```
Storage Array

↓

LUN 1

↓

Database

LUN 2

↓

VMware

LUN 3

↓

Backup
```

Each LUN appears as a separate disk to the server.

# 11. What is Fibre Channel (FC)?

**Fibre Channel (FC)** is a high-speed networking technology specifically designed for SANs.

Unlike Ethernet, Fibre Channel is optimized for:

- Low latency
- High throughput
- Lossless transport
- Reliable block storage

# 15. Fibre Channel Addressing

Each Fibre Channel device has a unique **World Wide Name (WWN)**.

Similar to:

```
MAC Address

↓

Ethernet
```

Equivalent in Fibre Channel:

```
WWN
```

Example:

```
50:06:01:60:3B:A0:12:34
```

---

# 16. World Wide Names (WWNs)

Types:

| Type | Description |
|------|-------------|
| WWNN | Node Name |
| WWPN | Port Name |

WWPN uniquely identifies an FC port.

---

# 17. Host Bus Adapter (HBA)

An HBA is a specialized network adapter used to connect servers to a Fibre Channel SAN.

```
Server

↓

HBA

↓

FC Switch
```

Functions:

- FC communication
- WWN identification
- Storage connectivity

---

# 18. Fibre Channel Switch

Dedicated switch for storage traffic.

Responsibilities:

- Forward FC frames
- Zoning
- Fabric services
- Name services

Unlike Ethernet switches, FC switches operate within a Fibre Channel fabric.

---

# 19. Fibre Channel Fabric

```
Server

↓

FC Switch

↓

Storage
```

Multiple FC switches create a **fabric**, allowing scalable and redundant storage connectivity.

---

# 20. Zoning

Zoning controls which devices may communicate within an FC fabric.

Example:

```
Zone A

Server1

↓

Storage1

Zone B

Server2

↓

Storage2
```

Benefits:

- Security
- Isolation
- Reduced unnecessary traffic

---

# 21. LUN Masking

LUN masking controls **which servers can see specific LUNs**.

Example:

```
Storage Array

↓

LUN1

↓

Server A

LUN2

↓

Server B
```

Even if connected to the same SAN, servers only access authorized storage.

# 22. What is iSCSI?

**iSCSI (Internet Small Computer Systems Interface)** transports SCSI block storage commands over **TCP/IP and Ethernet**.

Instead of a dedicated FC network, it uses standard IP infrastructure.

---

# 29. Fibre Channel vs iSCSI

| Feature | Fibre Channel | iSCSI |
|----------|---------------|--------|
| Transport | Fibre Channel | TCP/IP |
| Network | Dedicated SAN | Ethernet |
| Performance | Very High | High |
| Cost | Higher | Lower |
| Management | Specialized | Familiar IP networking |
| Latency | Lower | Slightly Higher |

---

# 30. Fibre Channel over Ethernet (FCoE)

**FCoE** encapsulates Fibre Channel frames over **lossless Ethernet**.

Benefits:

- Converged network
- Fewer cables
- Single adapter (CNA)

Requirements:

- Data Center Bridging (DCB)
- Lossless Ethernet

---

# 31. FC vs FCoE vs iSCSI

| Feature | FC | FCoE | iSCSI |
|----------|----|-------|--------|
| Uses Ethernet | No | Yes | Yes |
| Uses TCP/IP | No | No | Yes |
| Dedicated SAN | Yes | Shared Ethernet | Shared Ethernet |
| Cost | Highest | Medium | Lowest |

---

# 32. Multipathing

Multipathing provides multiple storage paths.

```
Server

 |     |

Path1 Path2

 |     |

Storage
```

Benefits:

- Redundancy
- Load balancing
- High availability

If one path fails, another path continues carrying traffic.

# 34. SAN Best Practices

- Use redundant SAN fabrics (Fabric A and Fabric B).
- Enable multipathing on hosts.
- Separate storage traffic from user traffic.
- Implement zoning and LUN masking.
- Monitor latency and storage performance.
- Use jumbo frames for iSCSI where appropriate (end-to-end support required).
- Keep firmware and HBA drivers up to date.

# 36. Troubleshooting

## Server Cannot See Storage

Check:

- HBA status
- WWPN registration
- Zoning
- LUN masking
- Multipathing
- FC cable/SFP

---

## iSCSI Connection Fails

Verify:

- IP connectivity
- TCP port **3260**
- Target configuration
- Initiator authentication (CHAP if used)
- Jumbo frame consistency

---

## High Storage Latency

Check:

- SAN congestion
- Link utilization
- Storage controller health
- Disk performance
- Multipath status

# CCNP Exam Traps

- **SAN provides block-level storage**, while **NAS provides file-level storage**.
- **iSCSI uses TCP/IP over Ethernet** (default **TCP port 3260**).
- **Fibre Channel uses a dedicated storage network**, not Ethernet.
- **WWPN** identifies an individual Fibre Channel port.
- **HBA** connects servers to Fibre Channel SANs.
- **LUNs** are logical block storage devices presented by a storage array.
- **Zoning** controls communication in the FC fabric; **LUN masking** controls which hosts can access specific LUNs.
- **Multipathing** provides redundancy and load balancing for storage access.
- **FCoE** carries Fibre Channel frames over **lossless Ethernet**, but it does **not** use TCP/IP.
