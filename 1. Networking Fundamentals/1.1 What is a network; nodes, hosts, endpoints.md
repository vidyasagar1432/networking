# 1. Overview

A **network** is a collection of interconnected devices that communicate and exchange data using defined protocols and communication links. CCNA tests this topic because understanding what participates in a network (nodes, hosts, endpoints, infrastructure devices) is required before learning switching, routing, IP addressing, and troubleshooting.

---

# 2. Core Concepts

## Network Definition

| Term | Definition | Example |
|---|---|---|
| Network | Collection of connected devices that exchange data | LAN, WAN, Internet |
| Communication link | Physical or wireless path between devices | Ethernet cable, Wi-Fi |
| Protocol | Rules defining communication | TCP/IP, HTTP, OSPF |
| Data transfer | Movement of information between devices | File transfer, web browsing |
| Network device | Hardware/software that forwards, processes, or generates traffic | Router, switch, firewall |

# Network Components

| Component | Role | Examples |
|---|---|---|

| Intermediate Device | Connects networks and forwards traffic | Switch, router, firewall |
| Network Media | Carries signals | Fiber, copper, radio |
| Network Protocol | Defines communication rules | IPv4, IPv6, TCP, UDP |

# Nodes, Hosts, and Endpoints

## Node

| Term | Definition | Examples |
|---|---|---|
| Node | Any device connected to a network that can send, receive, or process data | Router, switch, PC, printer |
| Network node | General term for any connected device | All devices in topology |

**Key point:**

Every host is a node, but not every node is a host.

---

## Host

| Term | Definition | Examples |
|---|---|---|
| Host | Device assigned an IP address that participates in network communication | PC, server, smartphone |
| Network host | Endpoint that runs applications or services | Web server, workstation |

### Host Characteristics

| Feature | Host |
|---|---|
| Has IP address | Usually yes |
| Runs applications | Yes |
| Generates user traffic | Yes |
| Destination/source of communication | Yes |

---

## Endpoint

| Term | Definition | Examples |
|---|---|---|
| Endpoint | Device at the edge of a network where communication begins or ends | Laptop, phone, IoT device |
| Endpoint device | User-facing network participant | PC, printer, camera |

---

## Node vs Host vs Endpoint

| Feature | Node | Host | Endpoint |
|---|---|---|---|
| Broadest term | Yes | No | No |
| Requires IP address | No | Usually yes | Usually yes |
| Sends/receives data | Yes | Yes | Yes |
| Runs applications | Not always | Usually | Usually |
| Example | Switch | Server | Laptop |

# 3. Worked Examples

## Example 1: Identify Nodes, Hosts, and Endpoints

Topology:

```
Laptop ---- Switch ---- Router ---- Internet
               |
             Server
```

| Device | Node? | Host? | Endpoint? |
|---|---|---|---|
| Laptop | Yes | Yes | Yes |
| Switch | Yes | No | No |
| Router | Yes | No | No |
| Server | Yes | Yes | Yes |

### Reasoning

1. All connected devices are nodes.
2. Devices running applications are hosts.
3. Edge communication devices are endpoints.

---

## Example 2: Identify Source and Destination

Scenario:

User opens:

```
https://www.cisco.com
```

Path:

```
PC → Switch → Router → ISP → Web Server
```

| Role | Device |
|---|---|
| Source | User PC |
| Destination | Web server |
| Intermediate devices | Switch, router, ISP routers |
| Application protocol | HTTPS |
| Transport protocol | TCP |
| Destination port | 443 |

# 4. Configuration/Commands

## View Device Information

```bash
Router# show version
```

Displays:

- Hostname
- IOS version
- Hardware details

---

## Display Interfaces

```bash
Router# show ip interface brief
```

Shows:

- Interfaces
- IP addresses
- Interface status

---

## View Connected Hosts on Switch

```bash
Switch# show mac address-table
```

Displays learned MAC addresses and connected ports.

---

## Test Host Connectivity

```bash
ping 192.168.1.10
```

Uses ICMP to test reachability.

# 5. Exam Traps

- Every host is a node, but every node is not a host.
- A switch with a management IP is still not considered a host.
- Servers are hosts.
- Endpoints include IoT devices, printers, cameras, and phones.
- Routers and switches are nodes but normally not endpoints.
- MAC address identifies Layer 2 devices.
- IP address identifies Layer 3 hosts.

# 7. Practice Questions

## Question 1

Which device is a node but normally not a host?

A. Laptop  
B. Web server  
C. Switch  
D. Smartphone  

**Answer: C. Switch**

Explanation:  
A switch is a network node but does not normally run user applications.

---

## Question 2

Which statement is correct?

A. Every host is a node  
B. Every node is a host  
C. Every endpoint is a router  
D. Hosts cannot have IP addresses  

**Answer: A. Every host is a node**

Explanation:  
Hosts are a subset of nodes.

---

## Question 3

A user accesses a website. The destination device is:

A. Switch  
B. Router  
C. Web server  
D. Laptop  

**Answer: C. Web server**

Explanation:  
The web server receives the request.

---

## Question 4

Which address operates at Layer 2?

A. IP address  
B. Port number  
C. MAC address  
D. URL  

**Answer: C. MAC address**

Explanation:  
MAC addresses provide Layer 2 addressing.

---

## Question 5

An endpoint is:

A. A device that only forwards packets  
B. A device where communication starts or ends  
C. A device without an address  
D. A routing-only device  

**Answer: B. A device where communication starts or ends**

Explanation:  
Endpoints include PCs, phones, printers, and IoT devices.
