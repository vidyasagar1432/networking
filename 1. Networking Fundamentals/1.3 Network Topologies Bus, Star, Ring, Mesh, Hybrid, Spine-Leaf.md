# 1. Overview

A network topology describes how devices and communication links are arranged in a network, either physically or logically. CCNA tests topologies because they affect scalability, performance, fault tolerance, and network design decisions.

---

# 2. Core Concepts

## Physical vs Logical Topology

| Type | Definition | Example |
|---|---|---|
| Physical Topology | Actual physical arrangement of devices and cables | Star Ethernet cabling |
| Logical Topology | How data flows through the network | Ethernet switching behavior |

---

# Bus Topology

## Definition

A bus topology connects all devices to a single shared communication cable called a backbone.

Diagram:

```
PC1     PC2     PC3     PC4
 |       |       |       |
================================
        Backbone Cable
```

---

## Bus Characteristics

| Feature | Details |
|---|---|
| Main Component | Single backbone cable |
| Communication | Shared medium |
| Cost | Low |
| Scalability | Poor |
| Fault Tolerance | Low |
| Collision Domain | Large |
| Historical Technology | Ethernet coaxial networks |

---

## Advantages and Disadvantages

| Advantages | Disadvantages |
|---|---|
| Simple design | Backbone failure affects entire network |
| Low cost | Difficult troubleshooting |
| Requires less cable | Collisions increase with size |
| Easy initial setup | Limited scalability |

---

## CCNA Relevance

- Mostly historical.
- Not used in modern switched Ethernet networks.

---

# Star Topology

## Definition

A star topology connects all devices to a central device, usually a switch or access point.

Diagram:

```
          PC1
           |
PC2 ---- Switch ---- PC3
           |
          PC4
```

---

## Star Characteristics

| Feature | Details |
|---|---|
| Central Device | Switch/Hub/AP |
| Common Technology | Ethernet |
| Scalability | High |
| Fault Isolation | Good |
| Current Usage | Very common |

---

## Advantages and Disadvantages

| Advantages | Disadvantages |
|---|---|
| Easy management | Central device failure affects all devices |
| Easy troubleshooting | Requires more cable |
| Simple expansion | Higher cost than bus |

---

## CCNA Relevance

Modern LANs commonly use star topology:

```
PC → Switch → Router
```

---

# Ring Topology

## Definition

A ring topology connects devices in a circular path where each device connects to two neighbors.

Diagram:

```
PC1 ---- PC2
 |        |
PC4 ---- PC3
```

---

## Ring Characteristics

| Feature | Details |
|---|---|
| Data Flow | One direction or both directions |
| Access Method | Token passing (traditional) |
| Fault Impact | Link/device failure can interrupt communication |
| Historical Technology | Token Ring, FDDI |

---

## Advantages and Disadvantages

| Advantages | Disadvantages |
|---|---|
| Predictable access | Failure can affect entire ring |
| No collisions in token systems | Difficult expansion |
| Equal access for devices | Less common today |

---

# Mesh Topology

## Definition

A mesh topology connects devices with multiple redundant links.

Types:

1. Full Mesh
2. Partial Mesh

---

# Full Mesh

Every device connects directly to every other device.

Formula:

```
Number of links = n(n-1)/2
```

Where:

```
n = number of devices
```

Example:

For 5 routers:

```
5(5-1)/2

= 5×4/2

= 10 links
```

---

## Mesh Characteristics

| Feature | Details |
|---|---|
| Redundancy | Very high |
| Reliability | Excellent |
| Cost | High |
| Complexity | High |
| Common Use | WAN, service provider networks |

---

## Advantages and Disadvantages

| Advantages | Disadvantages |
|---|---|
| Excellent fault tolerance | Expensive |
| Multiple paths available | Complex configuration |
| High availability | More cables/interfaces required |

---

# Hybrid Topology

## Definition

A hybrid topology combines two or more topology types.

Examples:

```
Star + Mesh
Star + Ring
```

---

## Hybrid Characteristics

| Feature | Details |
|---|---|
| Design | Combination of topologies |
| Scalability | High |
| Flexibility | High |
| Cost | Depends on design |
| Usage | Enterprise networks |

---

## Example

Enterprise network:

```
Branch LAN (Star)
        |
       WAN
        |
Data Center (Spine-Leaf)
```

# Spine-Leaf Topology

## Definition

Spine-leaf is a modern data center topology designed for predictable, high-speed east-west traffic.

Architecture:

```
          Spine1     Spine2
            |          |
--------------------------------
 |          |          |        |
Leaf1     Leaf2      Leaf3    Leaf4
 |          |          |        |
Servers   Servers   Servers  Servers
```

---

# Spine-Leaf Components

| Component | Function |
|---|---|
| Spine Switch | Backbone layer |
| Leaf Switch | Connects servers/end devices |
| Leaf-Spine Link | High-speed connection |
| Server Connection | Usually connected to leaf switches |

---

# Spine-Leaf Characteristics

| Feature | Details |
|---|---|
| Used In | Data centers |
| Traffic Pattern | East-West traffic |
| Design | Two-tier architecture |
| Redundancy | High |
| Path Length | Predictable |
| Protocols | ECMP, VXLAN |

---

# Spine-Leaf vs Traditional Three-Tier Design

| Feature | Three-Tier | Spine-Leaf |
|---|---|---|
| Layers | Core, Distribution, Access | Spine, Leaf |
| Main Traffic | North-South | East-West |
| Data Center Use | Older design | Modern design |
| Scalability | Limited | High |
| Path Selection | Variable | Predictable |

---

# Topology Comparison

| Topology | Cost | Reliability | Scalability | Common Use |
|---|---|---|---|---|
| Bus | Low | Low | Poor | Legacy networks |
| Star | Medium | Medium/High | High | LANs |
| Ring | Medium | Medium | Medium | Legacy WANs |
| Mesh | High | Very High | Medium | WAN redundancy |
| Hybrid | Variable | High | High | Enterprise networks |
| Spine-Leaf | High | Very High | Very High | Data centers |

---

# Topology and Failure Impact

| Topology | Single Device/Link Failure Result |
|---|---|
| Bus | Entire network affected if backbone fails |
| Star | Only connected device affected if endpoint link fails |
| Ring | Ring interruption possible |
| Mesh | Traffic reroutes through alternate paths |
| Hybrid | Depends on design |
| Spine-Leaf | Leaf/spine redundancy maintains connectivity |

# 3. Worked Examples

## Example 1: Calculate Full Mesh Links

### Scenario

A WAN has 6 routers connected using full mesh topology.

Find required links.

Formula:

```
Links = n(n-1)/2
```

Given:

```
n = 6
```

Calculation:

```
6(6-1)/2

= 6×5/2

= 15 links
```

Answer:

```
15 physical connections required
```

---

## Example 2: Identify Spine-Leaf Design

### Scenario

A data center has:

- 4 leaf switches
- 2 spine switches
- Servers connected only to leaf switches

Question:

Which topology is used?

Solution:

Step 1:
- Servers connect to leaf switches.

Step 2:
- Leaf switches connect upward to spine switches.

Step 3:
- Two-layer data center design.

Answer:

```
Spine-Leaf topology
```

# 4. Configuration/Commands (if applicable)

Topology itself is not configured directly, but Cisco IOS commands verify topology connections.

---

## View Neighbor Devices

```bash
Switch# show cdp neighbors
```

Purpose:

- Displays directly connected Cisco devices.
- Helps identify physical topology.

---

## View Interfaces

```bash
Switch# show interfaces status
```

Purpose:

- Shows connected ports.
- Identifies active links.

---

## View MAC Address Learning

```bash
Switch# show mac address-table
```

Purpose:

- Shows devices learned on switch ports.

---

## Check Routing Paths

```bash
Router# show ip route
```

Purpose:

- Displays available paths between networks.

# 5. Exam Traps

- Star topology is the most common modern LAN topology.
- Bus topology uses a shared backbone cable.
- A switch-based Ethernet LAN is usually a physical star topology.
- Full mesh links formula:

```
n(n-1)/2
```

- Spine-leaf is mainly used in data centers, not typical small LANs.
- Spine switches do not connect directly to servers.
- Leaf switches connect to servers and endpoints.
- Mesh provides redundancy but increases cost.
- Ring topology is not the default Ethernet LAN design.
- Physical topology and logical topology are different concepts.

# 7. Practice Questions

## Question 1

Which topology provides the highest redundancy?

A. Bus  
B. Star  
C. Mesh  
D. Ring  

### Answer: C. Mesh

Explanation:

Mesh provides multiple paths between devices.

---

## Question 2

A modern Ethernet LAN with switches usually uses which physical topology?

A. Bus  
B. Star  
C. Ring  
D. Mesh  

### Answer: B. Star

Explanation:

Endpoints connect to a central switch.

---

## Question 3

How many links are required for a full mesh of 8 routers?

A. 16  
B. 24  
C. 28  
D. 32  

### Answer: C. 28

Explanation:

Formula:

```
n(n-1)/2

8(7)/2 = 28
```

---

## Question 4

Which topology is commonly used in modern data centers?

A. Bus  
B. Ring  
C. Spine-Leaf  
D. Token Ring  

### Answer: C. Spine-Leaf

Explanation:

Spine-leaf provides scalable east-west traffic handling.

---

## Question 5

Which device connects servers in a spine-leaf architecture?

A. Spine switch  
B. Leaf switch  
C. Router  
D. Firewall  

### Answer: B. Leaf switch

Explanation:

Servers connect to leaf switches; leaf switches connect to spine switches.
