# 1. Overview

Client-server and peer-to-peer (P2P) are two common network communication models that define how devices share resources and services. CCNA tests these models because they explain how hosts communicate, how services are delivered, and how networks are designed.

---

# 2. Core Concepts

# Client-Server Model

## Definition

The client-server model uses dedicated servers that provide services or resources to client devices that request them.

Example:

```
Client PC
    |
    | Request
    |
    v
 Server
    |
    | Response
    |
    v
Client PC
```

---

## Client-Server Components

| Component | Function                    | Example                   |
| --------- | --------------------------- | ------------------------- |
| Client    | Requests services           | Web browser, email client |
| Server    | Provides services           | Web server, DNS server    |
| Network   | Provides communication path | LAN/WAN/Internet          |

---

## Common Client-Server Examples

| Service | Client | Server |
|---|---|---|
| Web browsing | Browser | Web server |
| Email | Outlook/Gmail app | Mail server |
| File sharing | User PC | File server |
| Database access | Application | Database server |
| DNS lookup | Host | DNS server |
| DHCP | Client device | DHCP server |

| Server Type | Function | Common Protocol |
|---|---|---|
| Web Server | Hosts websites | HTTP/HTTPS |

| DHCP Server | Assigns IP addresses | DHCP |

---

# Client-Server Characteristics

| Feature | Description |
|---|---|
| Architecture | Centralized |
| Management | Easier |
| Security | Centralized control |
| Scalability | High with server upgrades |
| Cost | Higher |
| Reliability | Depends on server availability |

---

# Advantages of Client-Server

| Advantage | Explanation |
|---|---|
| Centralized management | Users and resources managed from servers |
| Better security | Authentication and access control |
| Easier backup | Data stored centrally |
| Better performance | Dedicated server resources |
| Easier monitoring | Network administrators can manage services |

---

# Disadvantages of Client-Server

| Disadvantage | Explanation |
|---|---|
| Server failure impact | Service may become unavailable |
| Higher cost | Requires server hardware/software |
| Administration required | Needs management |

# Peer-to-Peer (P2P) Model

## Definition

A peer-to-peer network allows devices to communicate directly and share resources without a dedicated central server.

Example:

```
PC1 <--------> PC2
 |              |
 |              |
 v              v
PC3 <--------> PC4
```

Each device can act as both:

- Client
- Server

---

# Peer-to-Peer Characteristics

| Feature | Description |
|---|---|
| Architecture | Decentralized |
| Management | Distributed |
| Server requirement | No dedicated server |
| Cost | Low |
| Security | More difficult |
| Scalability | Limited |

---

# Peer-to-Peer Examples

| Example | Description |
|---|---|
| BitTorrent | Users share files directly |
| Small home network | PCs share files/printers |
| Blockchain networks | Distributed communication |
| Cryptocurrency networks | Peer nodes exchange data |

---

# Client-Server vs Peer-to-Peer Comparison

| Feature | Client-Server | Peer-to-Peer |
|---|---|---|
| Architecture | Centralized | Decentralized |
| Dedicated server | Required | Not required |
| Management | Centralized | Distributed |
| Cost | Higher | Lower |
| Security | Stronger | Weaker |
| Scalability | High | Limited |
| Performance | Predictable | Depends on peers |
| Failure impact | Server failure affects service | Individual peer failure usually limited |
| Example | Web services | File sharing |

---

# Network Roles

| Device Role | Client-Server | Peer-to-Peer |
|---|---|---|
| Client | Requests resources | Can request and provide |
| Server | Provides resources | No dedicated server |
| Host | Usually client/server role | Acts as both |

---

# Hybrid Model

## Definition

Many modern networks combine both models.

Example:

```
User PC
   |
   |
Cloud Application Server
   |
   |
Other Users
```

Examples:

| Service | Model |
|---|---|
| Google Drive | Client-server |
| BitTorrent | Peer-to-peer |
| Online games | Hybrid |
| Cloud applications | Client-server with distributed systems |

# 3. Worked Examples

## Example 1: Identify Communication Model

### Scenario

A user opens a website:

```
Laptop → Web Server
```

The laptop requests a webpage, and the server sends the webpage back.

### Solution

Step 1:
- Laptop requests a service.

Step 2:
- Web server provides the service.

Step 3:
- A dedicated server exists.

Answer:

```
Client-Server Model
```

Reason:

The client requests resources from a centralized server.

---

## Example 2: Identify Peer-to-Peer Model

### Scenario

Four computers in a home network share files directly.

```
PC1 <----> PC2
PC1 <----> PC3
PC2 <----> PC4
```

No dedicated server exists.

### Solution

Step 1:
- All computers communicate directly.

Step 2:
- Each computer can provide and request files.

Step 3:
- No central server exists.

Answer:

```
Peer-to-Peer Model
```

Reason:

Every device acts as both client and server.

- Tests name resolution.

```bash

```

Purpose:

# 5. Exam Traps

- A server is still a host.
- A client does not always mean a physical computer.
  - A smartphone browser is also a client.

- Peer-to-peer does not mean there are no servers anywhere.
  - It means no dedicated central server is required.

- Client-server is not limited to LANs.
  - Internet services commonly use this model.

- DNS, DHCP, HTTP, and email commonly use client-server architecture.

- P2P networks distribute responsibility among devices.

- Centralized management = client-server.
- Decentralized management = peer-to-peer.

# 7. Practice Questions

## Question 1

A web browser accessing a website uses which model?

A. Peer-to-peer  
B. Client-server  
C. Ring topology  
D. Mesh topology  

### Answer: B. Client-server

Explanation:

The browser is the client and the web server provides the service.

---

## Question 2

Which model does not require a dedicated server?

A. Client-server  
B. Peer-to-peer  
C. Mainframe  
D. Three-tier  

### Answer: B. Peer-to-peer

Explanation:

P2P devices can act as both clients and servers.

---

## Question 3

Which provides centralized management?

A. Peer-to-peer  
B. Client-server  
C. Bus network  
D. Ring network  

### Answer: B. Client-server

Explanation:

Servers centrally manage resources and security.

---

## Question 4

A computer sharing files directly with another computer is using:

A. Client-server  
B. Peer-to-peer  
C. WAN  
D. SAN  

### Answer: B. Peer-to-peer

Explanation:

Devices communicate directly without a dedicated server.

---

## Question 5

Which statement is correct?

A. Servers cannot act as hosts  
B. Clients always provide services  
C. Peer devices can act as client and server  
D. Client-server networks cannot use the Internet  

### Answer: C. Peer devices can act as client and server

Explanation:

In P2P networks, each device can request and provide resources.
