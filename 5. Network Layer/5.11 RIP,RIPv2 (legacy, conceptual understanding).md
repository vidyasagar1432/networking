**CCNP ENCOR Relevance: Limited — RIP is not used in modern enterprise networks and is not a focus of CCNP ENCOR. However, understanding distance-vector concepts, metrics, and routing fundamentals is useful.**

---

# 1. Overview

Routing Information Protocol (RIP) is a legacy distance-vector routing protocol that uses hop count as its routing metric. CCNA tests RIP mainly to understand routing protocol concepts, distance-vector behavior, RIPv1 vs RIPv2 differences, and why modern networks use protocols like OSPF and EIGRP instead.

---

# 2. Core Concepts

# RIP Definition

RIP:

```
Routing Information Protocol
```

Type:

```
Distance Vector Routing Protocol
```

Purpose:

Automatically exchange routes between routers.

---

# RIP Characteristics

| Feature | Value |
|---|---|
| Protocol type | Distance Vector |
| Transport protocol | UDP |
| UDP port | 520 |
| Algorithm | Bellman-Ford |
| Metric | Hop count |
| Maximum hops | 15 |
| 16 hops | Unreachable |
| Administrative Distance | 120 |

---

# RIP Versions

| Feature | RIPv1 | RIPv2 |
|---|---|---|
| Classful/Classless | Classful | Classless |
| VLSM support | No | Yes |
| CIDR support | No | Yes |
| Authentication | No | Yes |
| Multicast updates | No | Yes |
| Update address | Broadcast | 224.0.0.9 |
| Auto-summary | Yes | Yes (default) |

---

# RIPv1

## Characteristics

RIPv1 is classful.

It does not send subnet mask information in routing updates.

Example:

```
Network:
192.168.1.0/24
```

RIPv1 advertises only:

```
192.168.1.0
```

---

# Problems with RIPv1

| Limitation | Result |
|---|---|
| No subnet mask | No VLSM support |
| Broadcast updates | More traffic |
| No authentication | Less secure |

---

# RIPv2

## Characteristics

RIPv2 is classless.

It includes subnet mask information.

Example:

Advertisement:

```
192.168.1.0/24
```

---

# RIPv2 Improvements

| Feature | Benefit |
|---|---|
| Subnet mask included | Supports VLSM |
| Authentication | More secure |
| Multicast updates | Reduces unnecessary traffic |
| Route tagging | Supports redistribution |

---

# RIP Operation

RIP routers exchange their routing tables periodically.

Process:

```
Router A
   |
   | Routing Update
   |
Router B
```

Each router learns:

- Destination network
- Hop count
- Next hop

---

# RIP Update Timer

| Timer | Value |
|---|---:|
| Update timer | 30 seconds |
| Invalid timer | 180 seconds |
| Hold-down timer | 180 seconds |
| Flush timer | 240 seconds |

---

# RIP Metric

RIP uses:

```
Hop Count
```

Example:

```
Router A
 |
R1
 |
R2
 |
Network
```

Hop count:

```
2
```

---

# RIP Hop Count Rules

| Hops | Status |
|---|---|
| 0 | Direct network |
| 1-15 | Reachable |
| 16 | Unreachable |

---

# Distance Vector Concept

Routers know:

```
Distance
+
Direction
```

Example:

Router A learns:

```
Network X
Distance = 3 hops
Direction = Router B
```

---

# Bellman-Ford Algorithm

Distance-vector routing uses:

```
Best path =
Lowest metric
```

Formula:

```
New Distance =
Neighbor Distance + Cost to Neighbor
```

---

# RIP Route Selection

Example:

Routes:

```
Network A via R1 = 5 hops
Network A via R2 = 3 hops
```

Selected:

```
3 hop route
```

---

# Split Horizon

## Purpose

Prevents routing loops.

Rule:

```
Do not advertise a route back through the interface it was learned from.
```

Example:

```
R1 ---- R2
```

R2 learns route from R1.

R2 does not advertise that route back to R1.

---

# Route Poisoning

## Purpose

Marks failed routes as unreachable.

Metric:

```
16 hops
```

Example:

Before failure:

```
Network A = 2 hops
```

After failure:

```
Network A = 16 hops
```

---

# Hold-Down Timer

Purpose:

Prevents accepting incorrect routing information immediately after failure.

---

# Triggered Updates

Instead of waiting 30 seconds:

Router immediately sends update after topology change.

---

| Subnet Mask | No | Yes |

# RIP Multicast

RIPv2 uses:

```
224.0.0.9
```

IPv6 RIP version:

```
RIPng
```

Uses:

```
FF02::9
```

---

# Administrative Distance

RIP:

```
AD = 120
```

Comparison:

| Protocol | AD |
|---|---:|
| Connected | 0 |
| Static | 1 |
| EIGRP Internal | 90 |
| OSPF | 110 |
| RIP | 120 |

---

# RIP Limitations

| Limitation | Explanation |
|---|---|
| Slow convergence | Takes time after failures |
| Hop limit | Maximum 15 hops |
| Periodic updates | Uses bandwidth |
| Poor scalability | Not suitable for large networks |

---

# Why RIP Is Rarely Used

Modern networks prefer:

| Protocol | Advantage |
|---|---|
| OSPF | Fast convergence, scalable |
| EIGRP | Efficient metric calculation |
| IS-IS | Large provider networks |
| BGP | Internet routing |


## Example 2: RIP Maximum Hop Calculation

Network path:

```
R1
 |
R2
 |
R3
 |
R4
 |
Destination
```

Count hops:

```
R1 → R2 = 1
R2 → R3 = 2
R3 → R4 = 3
R4 → Destination = 4
```

Metric:

```
4 hops
```

Reachable because:

```
< 16
```

# 5. Exam Traps

- RIP uses hop count, not bandwidth.
- Maximum usable hop count is 15.
- 16 hops means unreachable.
- RIP administrative distance is 120.
- RIPv1 is classful.
- RIPv2 supports VLSM and CIDR.
- RIPv2 uses multicast address 224.0.0.9.
- RIPv1 uses broadcast 255.255.255.255.
- RIP uses UDP port 520.
- RIP is a distance-vector protocol.
- Split horizon prevents routing loops.
- RIP is not a preferred modern enterprise protocol.
- Lower hop count wins.

# 7. Practice Questions

## Question 1

What metric does RIP use?

A. Bandwidth  
B. Delay  
C. Hop count  
D. Cost  

### Answer: C. Hop count

Explanation:

RIP selects routes using hop count.

---

## Question 2

What is the maximum valid RIP hop count?

A. 10  
B. 15  
C. 16  
D. 255  

### Answer: B. 15

Explanation:

16 hops represents an unreachable network.

Which RIP version supports VLSM?

A. RIPv1  
B. RIPv2

D. Neither  

### Answer: B. RIPv2

Explanation:

RIPv2 includes subnet mask information.
