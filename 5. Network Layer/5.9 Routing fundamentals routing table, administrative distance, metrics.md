# 1. Overview

Routing is the process of selecting the best path for forwarding packets between different networks. CCNA tests routing table interpretation, route selection logic, administrative distance, metrics, and how routers choose the best route.

---

# 2. Core Concepts

# Routing Definition

A router forwards packets between networks using:

```
Destination IP Address
+
Routing Table
```

Basic process:

```
Packet arrives
        |
        v
Check destination IP
        |
        v
Search routing table
        |
        v
Select best route
        |
        v
Forward packet
```

---

# Routing Table

## Definition

A routing table is a database stored on a router containing paths to destination networks.

Example:

```
Router# show ip route
```

Output:

```
C 192.168.1.0/24 is directly connected, GigabitEthernet0/0
S 10.10.0.0/16 via 192.168.1.2
O 172.16.0.0/16 via 10.1.1.2
```

---

# Routing Table Components

| Field | Purpose |
|---|---|
| Route source | How route was learned |
| Destination network | Target network |
| Prefix length | Network size |
| Next hop | Router to forward packet |
| Outgoing interface | Exit interface |
| Metric | Path cost |

---

# Routing Table Entry Format

```
[Source Code] Destination/Prefix [AD/Metric] via Next Hop
```

Example:

```
O 10.1.1.0/24 [110/20] via 192.168.1.2
```

Meaning:

| Field | Value |
|---|---|
| Source | OSPF |
| Network | 10.1.1.0/24 |
| AD | 110 |
| Metric | 20 |
| Next hop | 192.168.1.2 |

---

# Route Sources

| Code | Route Source |
|---|---|
| C | Connected |
| L | Local |
| S | Static |
| R | RIP |
| O | OSPF |
| D | EIGRP |
| B | BGP |
| * | Candidate default |

---

# Types of Routes

| Route Type | Description |
|---|---|
| Connected route | Automatically created from interface IP |
| Local route | Router interface IP address |
| Static route | Manually configured |
| Dynamic route | Learned through routing protocols |
| Default route | Used when no specific route exists |

---

# Connected Route

Example:

Interface:

```
192.168.1.1/24
```

Routing table:

```
C 192.168.1.0/24 is directly connected
```

Created automatically.

---

# Local Route

Example:

Interface IP:

```
192.168.1.1
```

Routing table:

```
L 192.168.1.1/32
```

Purpose:

Identifies the router's own interface address.

---

# Static Route

Manually configured by administrator.

Example:

```
ip route 10.1.0.0 255.255.0.0 192.168.1.2
```

Advantages:

- Simple
- Predictable
- Low resource usage

---

# Dynamic Routing

Routes learned automatically using protocols.

Examples:

| Protocol | Type |
|---|---|
| RIP | Distance Vector |
| OSPF | Link State |
| EIGRP | Advanced Distance Vector |
| BGP | Path Vector |

---

# Default Route

Used when no specific route exists.

IPv4:

```
0.0.0.0/0
```

IPv6:

```
::/0
```

Example:

```
S* 0.0.0.0/0 via 192.168.1.1
```

---

# Route Selection Process

Router selects routes using this order:

```
1. Longest Prefix Match
2. Lowest Administrative Distance
3. Lowest Metric
```

---

# 1. Longest Prefix Match

Most specific route wins.

Example:

Routing table:

```
192.168.0.0/16
192.168.1.0/24
```

Destination:

```
192.168.1.50
```

Selected:

```
192.168.1.0/24
```

Reason:

```
/24 > /16
```

---

# 2. Administrative Distance (AD)

## Definition

Administrative Distance measures the trustworthiness of a route source.
   
Lower AD is preferred.

Example:

```
Static route AD = 1
OSPF AD = 110
```

Static route wins.

---

# Default Administrative Distance Values

| Route Source | AD |
|---|---:|
| Connected | 0 |
| Local | 0 |
| Static | 1 |
| EIGRP Summary | 5 |
| External BGP | 20 |
| Internal EIGRP | 90 |
| OSPF | 110 |
| IS-IS | 115 |
| RIP | 120 |
| External EIGRP | 170 |
| Internal BGP | 200 |
| Unknown | 255 |

---

# AD Rules

| Value | Meaning |
|---|---|
| Lower AD | More trusted |
| Higher AD | Less trusted |
| AD 255 | Never used |

---

# 3. Metrics

## Definition

A metric is a value used by a routing protocol to choose the best path among routes from the same protocol.

Lower metric usually wins.

---

# Metric Examples

| Protocol | Metric |
|---|---|
| RIP | Hop count |
| OSPF | Cost (bandwidth) |
| EIGRP | Bandwidth + Delay |
| BGP | Path attributes |

---

# RIP Metric

Uses:

```
Hop Count
```

Example:

```
Route A = 3 hops
Route B = 5 hops
```

Best:

```
3 hops
```

Maximum:

```
15 hops
```

16 = unreachable.

---

# OSPF Metric

Uses:

```
Cost
```

Formula:

```
Cost = Reference Bandwidth / Interface Bandwidth
```

Default reference:

```
100 Mbps
```

Example:

100 Mbps link:

```
100/100 = 1
```

---

# EIGRP Metric

Uses:

Main values:

- Bandwidth
- Delay

Formula:

```
Composite Metric
```

Default:

```
Bandwidth + Delay
```

---

# BGP Metric

Uses attributes:

| Attribute | Purpose |
|---|---|
| Weight | Cisco-specific preference |
| Local Preference | Outbound path selection |
| AS Path | Shortest AS path |
| MED | External path preference |

---

# Administrative Distance vs Metric

| Feature | Administrative Distance | Metric |
|---|---|---|
| Purpose | Choose between protocols | Choose within same protocol |
| Example | OSPF vs RIP | OSPF path A vs B |
| Scope | Route source | Path quality |
| Lower value | Better | Usually better |

---

# 3. Worked Examples

## Example 1: Choose Best Route Using AD

Routing table contains:

```
Static route:
10.10.0.0/16 AD 1

OSPF route:
10.10.0.0/16 AD 110
```

Question:

Which route is installed?

---

Solution:

Step 1:

Compare prefix lengths.

Both:

```
/16
```

Equal.

Step 2:

Compare AD.

```
Static = 1
OSPF = 110
```

Step 3:

Lower AD wins.

Answer:

```
Static route
```

---

## Example 2: Longest Prefix Match

Routing table:

```
10.0.0.0/8
10.1.0.0/16
10.1.1.0/24
```

Destination:

```
10.1.1.50
```

---

Solution:

Matches:

```
10.0.0.0/8 ✓
10.1.0.0/16 ✓
10.1.1.0/24 ✓
```

Longest prefix:

```
/24
```

Answer:

```
10.1.1.0/24
```

# 5. Exam Traps

- Longest prefix match happens before AD comparison.
- Lower AD is preferred.
- Lower metric is usually preferred.
- AD compares different routing sources.
- Metric compares routes inside the same protocol.
- Connected routes have AD 0.
- Static routes have AD 1.
- RIP has AD 120.
- OSPF has AD 110.
- EIGRP internal has AD 90.
- Routing table does not contain every possible route.
- Routers forward based on destination IP, not source IP.
- Default route is 0.0.0.0/0.
- A route with AD 255 is considered unusable.

# 7. Practice Questions

## Question 1

Which route is preferred?

```
OSPF AD 110
RIP AD 120
```

A. RIP  
B. OSPF  
C. Both equal  
D. Neither  

### Answer: B. OSPF

Explanation:

Lower AD is preferred.

---

## Question 2

What is checked first during route selection?

A. Metric  
B. Administrative distance  
C. Longest prefix match  
D. Interface speed  

### Answer: C. Longest prefix match

Explanation:

The most specific route wins first.

---

## Question 3

What is the administrative distance of a static route?

A. 0  
B. 1  
C. 90  
D. 110  

### Answer: B. 1

Explanation:

Static routes have AD 1 by default.

---

## Question 4

Which routing protocol uses hop count as metric?

A. OSPF  
B. EIGRP  
C. RIP  
D. BGP  

### Answer: C. RIP

Explanation:

RIP uses hop count.

---

## Question 5

Which command displays the routing table?

A. show arp  
B. show ip route  
C. show mac address-table  
D. show vlan  

### Answer: B. show ip route

Explanation:

Cisco IOS uses show ip route to view IPv4 routes.
