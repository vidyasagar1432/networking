# 1. Overview

IPv4 addressing provides unique logical addresses used for communication between devices on IP networks. CCNA tests IPv4 address structure, address classes, public/private ranges, reserved addresses, and identifying valid host addresses.

---

# 2. Core Concepts

# IPv4 Address Basics

IPv4 uses:

```
32 bits
```

Format:

```
Dotted decimal notation
```

Example:

```
192.168.1.10
```

Binary format:

```
11000000.10101000.00000001.00001010
```

---

# IPv4 Address Structure

An IPv4 address contains:

| Part | Purpose |
|---|---|
| Network portion | Identifies the network |
| Host portion | Identifies the device |

Example:

```
192.168.10.25/24
```

Network:

```
192.168.10.0
```

Host:

```
25
```

---

# IPv4 Address Components

| Component | Size |
|---|---:|
| Total address size | 32 bits |
| Octets | 4 |
| Bits per octet | 8 |
| Maximum value per octet | 255 |

---

# IPv4 Address Range

Minimum:

```
0.0.0.0
```

Maximum:

```
255.255.255.255
```

Total addresses:

```
2^32 = 4,294,967,296
```

# IPv4 Address Classes (Classful Addressing)

Original IPv4 used classes:

| Class | First Octet Range | Default Mask | Purpose |
|---|---|---|---|
| A | 1-126 | /8 | Large networks |
| B | 128-191 | /16 | Medium networks |
| C | 192-223 | /24 | Small networks |
| D | 224-239 | N/A | Multicast |
| E | 240-255 | N/A | Experimental |

---

# Class A

Range:

```
1.0.0.0 - 126.255.255.255
```

Default mask:

```
255.0.0.0
```

CIDR:

```
/8
```

Structure:

```
Network.Host.Host.Host
```

Example:

```
10.1.1.5
```

---

# Class B

Range:

```
128.0.0.0 - 191.255.255.255
```

Default mask:

```
255.255.0.0
```

CIDR:

```
/16
```

Structure:

```
Network.Network.Host.Host
```

Example:

```
172.16.10.5
```

---

# Class C

Range:

```
192.0.0.0 - 223.255.255.255
```

Default mask:

```
255.255.255.0
```

CIDR:

```
/24
```

Structure:

```
Network.Network.Network.Host
```

Example:

```
192.168.1.10
```

---

# Class D

Range:

```
224.0.0.0 - 239.255.255.255
```

Purpose:

```
Multicast
```

Example:

```

```

- OSPF
- Multicast applications

---

# Class E

Range:

```
240.0.0.0 - 255.255.255.255
```

Purpose:

```
Experimental / reserved
```

# Classful vs Classless Addressing

Modern networks use:

```
CIDR
(Classless Inter-Domain Routing)
```

Not fixed classes.

---

# CIDR Example

Class C:

```
192.168.1.0/24
```

Can be divided:

```
192.168.1.0/26
192.168.1.64/26
192.168.1.128/26
192.168.1.192/26
```

# Public IPv4 Addresses

## Definition

Public addresses are globally unique addresses routable on the Internet.

Example:

```
8.8.8.8
```

---

# Public Address Characteristics

| Feature | Value |
|---|---|
| Internet routable | Yes |
| Globally unique | Yes |
| Assigned by | ISP/RIR |
| Used internally | No |

---

# Private IPv4 Addresses (RFC 1918)

## Definition

Private addresses are reserved for internal networks and are not directly routed on the Internet.

---

# Private Address Ranges

| Class | Private Range | CIDR |
|---|---|---|
| A | 10.0.0.0 - 10.255.255.255 | 10.0.0.0/8 |
| B | 172.16.0.0 - 172.31.255.255 | 172.16.0.0/12 |
| C | 192.168.0.0 - 192.168.255.255 | 192.168.0.0/16 |

---

# Private vs Public Comparison

| Feature | Private IP | Public IP |
|---|---|---|
| Internet reachable | No | Yes |
| Globally unique | No | Yes |
| Assigned by ISP | No | Yes |
| Used in LAN | Yes | Sometimes |
| Requires NAT | Usually | No |

---

# NAT and Private Addresses

Private addresses require translation before Internet communication.

Example:

```
Private IP

       |
       v

NAT Router

       |
       v

Public IP

```

# Reserved IPv4 Ranges

## Special IPv4 Addresses

| Range | Purpose |
|---|---|
| 0.0.0.0 | Unspecified/default route |
| 127.0.0.0/8 | Loopback |
| 169.254.0.0/16 | APIPA/link-local |
| 224.0.0.0/4 | Multicast |
| 240.0.0.0/4 | Reserved |

---

# 0.0.0.0

Uses:

| Use | Meaning |
|---|---|
| Host source | Unknown address |
| Routing | Default route |

Default route:

```
0.0.0.0/0
```

Means:

```
Any destination
```

---

# Loopback Range

Range:

```
127.0.0.0/8
```

Common address:

```
127.0.0.1
```

Purpose:

Testing local TCP/IP stack.

Example:

```
ping 127.0.0.1
```

---

# APIPA / Link-Local

Range:

```
169.254.0.0/16
```

Purpose:

Automatic address assignment when DHCP fails.

Example:

```
169.254.10.20
```

---

# Network Address

First address in a subnet.

Example:

Network:

```
192.168.1.0/24
```

Network address:

```
192.168.1.0
```

Cannot assign to hosts.

---

# Broadcast Address

Last address in a subnet.

Example:

Network:

```
192.168.1.0/24
```

Broadcast:

```
192.168.1.255
```

Used to send traffic to all hosts.

---

Network:


| First host | 192.168.1.1 |
| Last host | 192.168.1.254 |

```

```

# 5. Exam Traps

- Classful addressing is legacy; modern networks use CIDR.
- Private addresses are not Internet routable.
- 172.16.0.0/12 is private, but 172.32.0.0 is public.
- 127.0.0.0/8 is reserved for loopback.
- 169.254.x.x indicates DHCP failure.
- 224.0.0.0/4 is multicast, not normal host addressing.
- Network address cannot be assigned to a host.
- Broadcast address cannot be assigned to a host.
- 0.0.0.0/0 represents the default route.
- Public IP addresses must be globally unique.

# 7. Practice Questions

## Question 1

Which IPv4 range is private?

A. 11.0.0.0/8  
B. 172.16.0.0/12  
C. 192.0.2.0/24  
D. 224.0.0.0/4  

### Answer: B. 172.16.0.0/12

Explanation:

RFC 1918 defines 172.16.0.0-172.31.255.255 as private.

---

## Question 2

Which address is used for loopback testing?

A. 0.0.0.0  
B. 127.0.0.1  
C. 169.254.1.1  
D. 255.255.255.255  

### Answer: B. 127.0.0.1

Explanation:

127.0.0.0/8 is reserved for loopback.

---

## Question 3

Which IPv4 class is used for multicast?

A. Class A  
B. Class B  
C. Class C  
D. Class D  

### Answer: D. Class D

Explanation:

224.0.0.0-239.255.255.255 is multicast.

---

## Question 4

What is the broadcast address for:

```
192.168.5.0/24
```

A. 192.168.5.0  
B. 192.168.5.1  
C. 192.168.5.254  
D. 192.168.5.255  

### Answer: D. 192.168.5.255

Explanation:

The last address in a subnet is the broadcast address.

---

## Question 5

A device receives:

```
169.254.20.15
```

What does this indicate?

A. Public address  
B. DHCP failure  
C. Loopback address  
D. Multicast address  

### Answer: B. DHCP failure

Explanation:

169.254.0.0/16 is APIPA/link-local addressing.
