# 1. Overview

Route summarization (route aggregation) combines multiple smaller network prefixes into a single larger prefix. CCNA tests CIDR-based summarization, finding summary routes, reducing routing table size, and understanding how summarization improves routing efficiency.

---

# 2. Core Concepts

# Route Summarization Definition

Route summarization:

```
Combining multiple contiguous networks into one summarized route
```

Example:

Before:

```
192.168.0.0/24
192.168.1.0/24
192.168.2.0/24
192.168.3.0/24
```

After:

```
192.168.0.0/22
```

---

# Purpose of Route Summarization

| Benefit | Explanation |
|---|---|
| Smaller routing tables | Fewer entries |
| Less routing traffic | Fewer advertisements |
| Faster lookups | Less searching |
| Improved scalability | Supports large networks |
| Hides topology changes | Limits updates |

---

# Route Aggregation Terms

| Term | Meaning |
|---|---|
| Summary route | Combined network prefix |
| Supernet | Larger network containing smaller networks |
| CIDR | Classless prefix notation |
| Prefix length | Number of network bits |
| Block size | Number of addresses grouped |

---

# CIDR Review

Format:

```
Network/Prefix Length
```

Example:

```
192.168.0.0/24
```

Meaning:

```
24 network bits
8 host bits
```

---

# Binary Concept

IPv4 address:

```
32 bits
```

Example:

```
192.168.0.0
```

Binary:

```
11000000.10101000.00000000.00000000
```

---

# Summarization Rules

To create a summary:

1. Arrange networks in binary.
2. Find common left-most bits.
3. Count matching bits.
4. Create new prefix.

---

# Example Network Range

Networks:

```
192.168.0.0/24
192.168.1.0/24
192.168.2.0/24
192.168.3.0/24
```

Binary third octet:

| Network | Third Octet |
|---|---|
| 0 | 00000000 |
| 1 | 00000001 |
| 2 | 00000010 |
| 3 | 00000011 |

Common bits:

```
000000
```

Prefix:

```
/22
```

Summary:

```
192.168.0.0/22
```

---

# Block Size Method

Formula:

```
Block Size = 256 - Interesting Octet Mask
```

Example:

Prefix:

```
/22
```

Subnet mask:

```
255.255.252.0
```

Interesting octet:

```
252
```

Block size:

```
256 - 252 = 4
```

Networks:

```
0-3
```

Summary:

```
192.168.0.0/22
```

---

# Summary Route Requirements

Networks should be:

| Requirement | Description |
|---|---|
| Contiguous | Continuous address range |
| Same prefix boundary | Proper binary alignment |
| Same parent network | Belong to same block |

# 3. Worked Examples

## Example 1: Summarize Four /24 Networks

Given:

```
192.168.8.0/24
192.168.9.0/24
192.168.10.0/24
192.168.11.0/24
```

---

Step 1:

Convert third octet:

```
8  = 00001000
9  = 00001001
10 = 00001010
11 = 00001011
```

---

Step 2:

Common bits:

```
000010
```

Number of common bits:

```
6 bits
```

---

Step 3:

Original prefix:

```
/24
```

Add common third-octet bits:

```
16 + 6 = 22
```

Answer:

```
192.168.8.0/22
```

---

## Example 2: Find Summary Route Using Block Size

Given:

```
10.20.32.0/24
10.20.33.0/24
10.20.34.0/24
10.20.35.0/24
```

---

Step 1:

Need four /24 networks.

Four networks:

```
2² = 4
```

Borrow:

```
2 bits
```

---

Step 2:

Prefix:

```
/24 - 2 = /22
```

---

Step 3:

Mask:

```
255.255.252.0
```

Block size:

```
256 - 252 = 4
```

Range:

```
32-35
```

Answer:

```
10.20.32.0/22
```

# 5. Exam Traps

- Summarization reduces routing table size.
- Summary routes must align with binary boundaries.
- Do not summarize non-contiguous networks.
- /22 contains four /24 networks.
- Longer prefix = more specific route.
- Route summarization does not change host addresses.
- Automatic summarization is a legacy classful concept.
- Modern networks use manual CIDR summarization.
- Incorrect summarization can create black holes.
- OSPF summarizes at ABR/ASBR.
- EIGRP summarization is configured on interfaces.
- BGP heavily uses route aggregation.

What is the summary route for:

```
192.168.0.0/24
192.168.1.0/24
192.168.2.0/24
192.168.3.0/24
```

A. 192.168.0.0/24  
B. 192.168.0.0/22  
C. 192.168.0.0/16

### Answer: B

Explanation:

Four /24 networks combine into one /22.
