# 1. Overview

Route redistribution allows one routing protocol to advertise routes learned from another routing source. CCNA tests the concept of connecting different routing domains, while CCNP ENCOR goes deeper into redistribution design, metrics, filtering, and preventing routing loops.

---

# 2. Core Concepts

# Route Redistribution Definition

Route redistribution:

```
The process of taking routes learned by one routing source
and injecting them into another routing protocol.
```

Example:

```
OSPF Domain
     |
     |
Redistribution Router
     |
     |
EIGRP Domain
```

OSPF routes can be advertised into EIGRP.

---

# Why Redistribution Is Needed

Common scenarios:

| Scenario | Example |
|---|---|
| Network migration | RIP → OSPF migration |
| Multiple departments | Different routing protocols |
| Company merger | Separate networks combined |
| Enterprise + ISP | Internal routing + BGP |

---

# Routing Domains

A routing domain is a network using the same routing protocol.

Example:

```
OSPF Domain

R1 ---- R2 ---- R3
```

All routers share:

```
OSPF
```

---

# Redistribution Router

The router performing redistribution is called:

```
Boundary Router
```

or:

```
ASBR (Autonomous System Boundary Router)
```

Example:

```
          OSPF
           |
           |
          ASBR
           |
           |
          EIGRP
```

---

# Redistribution Direction

Redistribution is directional.

Example:

OSPF into EIGRP:

```
OSPF → EIGRP
```

Command concept:

```
redistribute ospf
```

Only OSPF routes enter EIGRP.

Reverse requires:

```
EIGRP → OSPF
```

---

# One-Way Redistribution

Example:

```
OSPF
 |
 v
EIGRP
```

Routes:

```
OSPF routes appear in EIGRP
```

But:

```
EIGRP routes do not appear in OSPF
```

---

# Two-Way Redistribution

Example:

```
OSPF <----> EIGRP
```

Both protocols exchange routes.

Risk:

```
Routing loops
```

---

# Redistribution Problems

| Problem | Description |
|---|---|
| Routing loops | Routes return to original protocol |
| Suboptimal routing | Wrong path selected |
| Metric mismatch | Different protocols use different metrics |
| Route feedback | Redistributed routes re-enter source protocol |

---

# Metric Differences

Different routing protocols measure paths differently.

| Protocol | Metric |
|---|---|
| RIP | Hop count |
| OSPF | Cost |
| EIGRP | Bandwidth + Delay |
| BGP | Path attributes |

A router cannot automatically translate metrics.

---

# Seed Metric

## Definition

The initial metric assigned to redistributed routes.

Some protocols require a seed metric.

---

# Default Seed Metrics

| Protocol | Default Redistribution Metric |
|---|---|
| RIP | Infinity (unreachable) |
| OSPF | Cost 20 |
| EIGRP | Infinity (requires metric) |
| BGP | Depends on attributes |

---

# Example Problem

Redistribute OSPF into EIGRP:

```
OSPF route:
10.1.0.0/16
```

EIGRP receives:

```
No metric
```

Result:

```
Route not installed
```

Solution:

Set EIGRP metric.

---

# Administrative Distance During Redistribution

Redistributed routes receive the AD of the destination protocol.

Example:

```
OSPF → EIGRP
```

EIGRP receives:

```
External EIGRP route
AD = 170
```

---

# Route Codes After Redistribution

Example:

OSPF route redistributed into EIGRP:

Original:

```
O 10.1.0.0/16
```

After redistribution:

```
D EX 10.1.0.0/16
```

Meaning:

```
EIGRP External
```

---

# Internal vs External Routes

## EIGRP

| Type | Code | AD |
|---|---|---:|
| Internal | D | 90 |
| External | D EX | 170 |

---

## OSPF

| Type | Code | AD |
|---|---|---:|
| Internal | O | 110 |
| External Type 5 | O E2 | 110 |
| NSSA External | O N1/N2 | 110 |

---

# Redistribution Points

Best practice:

```
Redistribute at minimum locations
```

Why?

Reduces:

- Complexity
- Loops
- Unpredictable paths

---

# Route Filtering

Redistribution should not advertise everything.

Methods:

| Method | Purpose |
|---|---|
| ACL | Match routes |
| Prefix-list | Match prefixes |
| Route-map | Apply policies |
| Distribute-list | Control updates |

---

# Route Map

Used for:

- Filtering
- Changing metrics
- Setting attributes

Example:

```
Match route
      |
Apply policy
      |
Redistribute
```

---

# Redistribution Loop Example

Network:

```
OSPF
 |
R1
 |
EIGRP
```

Redistribution:

```
OSPF → EIGRP
EIGRP → OSPF
```

Problem:

OSPF route enters EIGRP.

Then:

EIGRP advertises it back into OSPF.

Result:

```
Routing loop risk
```

---

# Loop Prevention Methods

| Method | Purpose |
|---|---|
| Route tagging | Mark redistributed routes |
| Filtering | Block routes |
| Single redistribution point | Reduce complexity |
| Administrative distance tuning | Control preference |

---

# Route Tagging

## Concept

Attach a value to redistributed routes.

Example:

```
Tag = 100
```

Router checks:

```
If tag exists:
Do not redistribute
```

---

# Default Route Redistribution

Default routes can also be redistributed.

Example:

```
0.0.0.0/0
```

into another protocol.

---

# Redistribution vs Route Summarization

| Feature | Redistribution | Summarization |
|---|---|---|
| Purpose | Exchange protocols | Combine networks |
| Changes protocol | Yes | No |
| Metric conversion | Yes | No |
| Risk | Loops | Black holes |

---

# Redistribution vs Static Routes

| Feature | Redistribution | Static Route |
|---|---|---|
| Automatic | Yes | No |
| Protocol aware | Yes | No |
| Scalable | More | Less |

# 5. Exam Traps

- Redistribution is not route summarization.
- Redistribution is directional.
- Two-way redistribution can create loops.
- Different protocols use different metrics.
- EIGRP requires a seed metric when redistributing.
- Redistributed EIGRP routes become external routes.
- Redistribution occurs at boundary routers.
- Route tagging helps prevent loops.
- OSPF external routes are usually generated by ASBR.
- More than one redistribution point increases complexity.
- Static routes are not automatically redistributed.
- Administrative distance does not fix metric differences.

# 7. Practice Questions

## Question 1

What is route redistribution?

A. Combining subnets  
B. Exchanging routes between routing protocols  
C. Encrypting routing updates  
D. Creating static routes  

### Answer: B

Explanation:

Redistribution allows different routing protocols to exchange routes.

---

## Question 2

Which device normally performs redistribution?

A. Access switch  
B. Host computer  
C. Boundary router  
D. DHCP server  

### Answer: C

Explanation:

Boundary routers connect routing domains.

---

## Question 3

What is a major risk of two-way redistribution?

A. Faster convergence  
B. Routing loops  
C. Smaller packets  
D. Lower latency  

### Answer: B

Explanation:

Routes can be learned and advertised back into their original protocol.

---

## Question 4

Which method helps prevent redistribution loops?

A. VLAN tagging  
B. Route tagging  
C. NAT  
D. STP  

### Answer: B

Explanation:

Tags identify redistributed routes.

---

## Question 5

Which routing protocol requires a metric when redistributing routes?

A. EIGRP  
B. ARP  
C. ICMP  
D. Ethernet  

### Answer: A

Explanation:

EIGRP needs a seed metric to install redistributed routes.
