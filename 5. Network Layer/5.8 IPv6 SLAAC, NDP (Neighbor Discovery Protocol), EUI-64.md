# 1. Overview

IPv6 uses Neighbor Discovery Protocol (NDP) instead of ARP to discover neighbors, routers, and network parameters. SLAAC allows IPv6 hosts to automatically configure addresses using Router Advertisements, while EUI-64 can generate the interface ID from a MAC address.

---

# 2. Core Concepts

# IPv6 Address Configuration Methods

IPv6 hosts can obtain addresses using:

| Method | Description |
|---|---|
| Manual configuration | Administrator assigns address |
| SLAAC | Host automatically creates address |
| Stateful DHCPv6 | DHCPv6 server assigns address |
| Stateless DHCPv6 | SLAAC address + DHCPv6 options |

---

# SLAAC (Stateless Address Autoconfiguration)

## Definition

SLAAC allows a host to automatically configure its IPv6 address without a DHCPv6 server.

Requirements:

- IPv6-enabled interface
- Router Advertisement (RA)

---

# SLAAC Process

Uses:

```
NDP + ICMPv6
```

Process:

```
Host
 |
 | Router Solicitation (RS)
 |
 v
Router
 |
 | Router Advertisement (RA)
 |
 v
Host creates IPv6 address
```

---

# SLAAC Steps

## Step 1: Host Starts

Host has:

```
No global IPv6 address
```

Creates:

```
Link-local address
```

Example:

```
FE80::AABB:CCFF:FE11:2233
```

---

## Step 2: Router Solicitation (RS)

Host sends:

```
ICMPv6 Type 133
```

Message:

```
Are there any IPv6 routers?
```

Destination:

```
FF02::2
```

(All routers multicast)

---

## Step 3: Router Advertisement (RA)

Router responds:

```
ICMPv6 Type 134
```

Contains:

- Network prefix
- Prefix length
- Default gateway information
- SLAAC information

---

## Step 4: Host Builds Address

Host combines:

```
Network Prefix
+
Interface ID
```

Example:

Router provides:

```
2001:db8:10:1::/64
```

Host creates:

```
2001:db8:10:1::abcd/64
```

---

# SLAAC Address Creation

Formula:

```
IPv6 Address =
Router Prefix + Interface ID
```

Example:

Prefix:

```
2001:db8:1:1::/64
```

Interface ID:

```
0000:0000:0000:1234
```

Result:

```
2001:db8:1:1::1234/64
```

---

# NDP (Neighbor Discovery Protocol)

## Definition

NDP is an IPv6 protocol used for:

- Neighbor discovery
- Router discovery
- Address resolution
- Duplicate address detection

NDP replaces:

```
ARP
```

in IPv6.

---

# NDP Characteristics

| Feature | Value |
|---|---|
| Protocol | ICMPv6 |
| IPv6 protocol number | 58 |
| Replacement for | ARP |
| Uses | Multicast |
| Layer | Layer 3 |

---

# NDP Message Types

| ICMPv6 Type | Message | Purpose |
|---|---|---|
| 133 | Router Solicitation | Find routers |
| 134 | Router Advertisement | Router information |
| 135 | Neighbor Solicitation | Resolve neighbors |
| 136 | Neighbor Advertisement | Neighbor response |
| 137 | Redirect | Better route information |

---

# NDP Functions

| Function | Description |
|---|---|
| Router discovery | Find IPv6 routers |
| Address resolution | IPv6 address → MAC address |
| Duplicate Address Detection | Check address uniqueness |
| Neighbor reachability | Verify neighbor status |
| Redirect | Inform better next hop |

---

# Neighbor Solicitation (NS)

Replaces:

```
ARP Request
```

Purpose:

Find MAC address of IPv6 neighbor.

Example:

Host wants:

```
2001:db8::20
```

Sends:

```
Neighbor Solicitation
```

Destination:

```
Solicited-node multicast address
```

---

# Neighbor Advertisement (NA)

Replaces:

```
ARP Reply
```

Purpose:

Provides:

```
IPv6 address → MAC address
```

mapping.

---

# NDP Address Resolution Process

Example:

Host A:

```
IPv6:
2001:db8::10
MAC:
AAAA
```

Host B:

```
IPv6:
2001:db8::20
MAC:
BBBB
```

---

Step 1:

Host A sends:

```
Neighbor Solicitation
```

---

Step 2:

Host B replies:

```
Neighbor Advertisement
```

---

Step 3:

Host A stores:

```
2001:db8::20 → BBBB
```

---

# Duplicate Address Detection (DAD)

Purpose:

Check if an IPv6 address is already in use.

Process:

1. Host creates tentative address.
2. Sends Neighbor Solicitation.
3. If no reply:

```
Address is unique
```

---

# EUI-64 (Extended Unique Identifier)

## Definition

EUI-64 creates a 64-bit interface ID from a 48-bit MAC address.

Used with:

```
SLAAC
```

---

# EUI-64 Conversion Steps

MAC Address:

```
AA:BB:CC:DD:EE:FF
```

---

## Step 1: Split MAC

Before:

```
AA:BB:CC
DD:EE:FF
```

---

## Step 2: Insert FFFE

Insert:

```
FFFE
```

Middle:

```
AA:BB:CC:FF:FE:DD:EE:FF
```

---

## Step 3: Flip U/L Bit

The 7th bit of first octet is inverted.

Example:

```
AA → A8
```

Final Interface ID:

```
A8BB:CCFF:FEDD:EEFF
```

---

# EUI-64 Address Example

MAC:

```
00:25:96:12:34:56
```

---

Insert FFFE:

```
00:25:96:FF:FE:12:34:56
```

---

Flip U/L bit:

```
02:25:96:FF:FE:12:34:56
```

Interface ID:

```
0225:96FF:FE12:3456
```

---

IPv6 Address:

Prefix:

```
2001:db8:1:1::/64
```

Result:

```
2001:db8:1:1:225:96ff:fe12:3456/64
```

---

# SLAAC vs DHCPv6

| Feature | SLAAC | DHCPv6 |
|---|---|---|
| Address assignment | Automatic | Automatic |
| Uses router | Yes | Not required |
| Uses DHCP server | No | Yes |
| Uses RA | Yes | Yes |
| DNS information | Limited | Available |

---

# Stateless vs Stateful DHCPv6

| Feature | Stateless DHCPv6 | Stateful DHCPv6 |
|---|---|---|
| Address | SLAAC | DHCPv6 server |
| Other information | DHCPv6 | DHCPv6 |
| MAC tracking | No | Yes |

---

# SLAAC Router Advertisement Flags

RA contains:

| Flag | Meaning |
|---|---|
| A flag | SLAAC allowed |
| M flag | Managed DHCPv6 |
| O flag | Other DHCPv6 information |

---

# Common RA Flag Combinations

| M Flag | O Flag | Method |
|---|---|---|
| 0 | 0 | SLAAC only |
| 0 | 1 | SLAAC + Stateless DHCPv6 |
| 1 | 1 | Stateful DHCPv6 |

# 5. Exam Traps

- IPv6 does not use ARP.
- NDP replaces ARP using ICMPv6.
- SLAAC requires Router Advertisements.
- Router Solicitation is ICMPv6 Type 133.
- Router Advertisement is ICMPv6 Type 134.
- Neighbor Solicitation is ICMPv6 Type 135.
- Neighbor Advertisement is ICMPv6 Type 136.
- EUI-64 inserts FFFE in the MAC address.
- EUI-64 flips the U/L bit.
- Link-local addresses are required for IPv6 interfaces.
- IPv6 uses multicast instead of broadcast.
- DHCPv6 is optional; SLAAC can work without DHCPv6.
- NDP uses multicast, not broadcast.

# 7. Practice Questions

## Question 1

Which protocol replaces ARP in IPv6?

A. DHCPv6  
B. ICMPv6 NDP  
C. DNS  
D. TCP  

### Answer: B. ICMPv6 NDP

Explanation:

IPv6 uses Neighbor Discovery Protocol instead of ARP.

---

## Question 2

Which ICMPv6 message discovers routers?

A. Neighbor Advertisement  
B. Router Advertisement  
C. Router Solicitation  
D. Redirect  

### Answer: C. Router Solicitation

Explanation:

Hosts send RS messages to find IPv6 routers.

---

## Question 3

What value is inserted into a MAC address during EUI-64?

A. FFFF  
B. FFFE  
C. AAAA  
D. 0000  

### Answer: B. FFFE

Explanation:

EUI-64 inserts FFFE in the middle of the MAC address.

---

## Question 4

Which command displays IPv6 neighbor entries?

A. show arp  
B. show mac address-table  
C. show ipv6 neighbors  
D. show ip route  

### Answer: C. show ipv6 neighbors

Explanation:

NDP neighbor information is displayed using this command.

---

## Question 5

Which IPv6 mechanism checks for duplicate addresses?

A. DHCPv6  
B. SLAAC  
C. DAD  
D. NAT  

### Answer: C. DAD

Explanation:

Duplicate Address Detection verifies IPv6 address uniqueness.
