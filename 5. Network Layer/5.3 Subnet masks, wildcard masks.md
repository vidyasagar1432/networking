# 1. Overview

Subnet masks identify the network and host portions of an IPv4 address, while wildcard masks provide a reverse matching mechanism used mainly in Cisco ACLs and routing protocols. CCNA tests subnet mask calculation, CIDR conversion, wildcard mask conversion, and their use in OSPF and ACL configuration.

---

# 2. Core Concepts

# Subnet Mask Definition

A subnet mask is a 32-bit value used to separate:

```
Network portion
+
Host portion
```

Example:

IP:

```
192.168.1.50
```

Mask:

```
255.255.255.0
```

Binary:

```
IP:
11000000.10101000.00000001.00110010

Mask:
11111111.11111111.11111111.00000000
```

Result:

```
Network bits = 24
Host bits = 8
```

---

# Subnet Mask Characteristics

| Feature | Value |
|---|---|
| Size | 32 bits |
| Network bits | Continuous 1s |
| Host bits | Continuous 0s |
| Used by | Routers and hosts |
| Written as | Decimal or CIDR |

---

# CIDR and Subnet Mask Mapping

| CIDR | Subnet Mask | Wildcard Mask |
|---|---|---|
| /8 | 255.0.0.0 | 0.255.255.255 |
| /16 | 255.255.0.0 | 0.0.255.255 |
| /24 | 255.255.255.0 | 0.0.0.255 |
| /25 | 255.255.255.128 | 0.0.0.127 |
| /26 | 255.255.255.192 | 0.0.0.63 |
| /27 | 255.255.255.224 | 0.0.0.31 |
| /28 | 255.255.255.240 | 0.0.0.15 |
| /29 | 255.255.255.248 | 0.0.0.7 |
| /30 | 255.255.255.252 | 0.0.0.3 |
| /31 | 255.255.255.254 | 0.0.0.1 |
| /32 | 255.255.255.255 | 0.0.0.0 |

---

# Network and Host Identification

Example:

```
192.168.10.25/24
```

Subnet mask:

```
255.255.255.0
```

Network:

```
192.168.10.0
```

Host:

```
25
```

---

# Valid Subnet Mask Rules

A valid subnet mask must have:

```
Continuous 1s followed by continuous 0s
```

Valid:

```
11111111.11111111.11111111.00000000
```

Invalid:

```
11111111.11110111.00000000.00000000
```

---

# Default Subnet Masks

| Class | Default Mask | CIDR |
|---|---|---|
| Class A | 255.0.0.0 | /8 |
| Class B | 255.255.0.0 | /16 |
| Class C | 255.255.255.0 | /24 |

---

# Wildcard Mask Definition

A wildcard mask is the inverse of a subnet mask.

Formula:

```
Wildcard Mask = 255.255.255.255 - Subnet Mask
```

Example:

Subnet mask:

```
255.255.255.0
```

Wildcard:

```
0.0.0.255
```

---

# Wildcard Mask Bit Meaning

Subnet Mask:

```
1 = Must match
0 = Ignore
```

Wildcard Mask:

```
0 = Must match
1 = Ignore
```

---

# Subnet Mask vs Wildcard Mask

| Feature | Subnet Mask | Wildcard Mask |
|---|---|---|
| Purpose | Identify network/host | Match addresses |
| Used by | IP routing | ACLs, OSPF |
| Exact matching | Network bits | Zero bits |
| Binary meaning | 1 = network | 0 = match |

---

# Wildcard Mask Usage

Common Cisco uses:

| Technology | Usage |
|---|---|
| Standard ACL | Match networks |
| Extended ACL | Match source/destination |
| OSPF | Network statements |
| EIGRP | Network statements |

---

# Wildcard Mask Examples

## Example 1: /24 Network

Network:

```
192.168.1.0/24
```

Subnet mask:

```
255.255.255.0
```

Wildcard:

```
0.0.0.255
```

Meaning:

```
First 3 octets must match
Last octet can change
```

Matches:

```
192.168.1.1
192.168.1.50
192.168.1.200
```

Does not match:

```
192.168.2.10
```

---

## Example 2: /26 Network

Network:

```
192.168.10.0/26
```

Subnet mask:

```
255.255.255.192
```

Wildcard:

```
0.0.0.63
```

Meaning:

```
First 26 bits must match
Last 6 bits ignored
```

---

# Wildcard Mask Calculation

Example:

Subnet mask:

```
255.255.255.192
```

Subtract from 255:

```
255-255 = 0
255-255 = 0
255-255 = 0
255-192 = 63
```

Wildcard:

```
0.0.0.63
```

# Wildcard Masks in ACLs

Example:

Allow network:

```
192.168.10.0/24
```

ACL:

```bash
access-list 10 permit 192.168.10.0 0.0.0.255
```

Meaning:

```
192.168.10.X
```

is permitted.

---

# Wildcard Masks in OSPF

Example:

Network:

```
192.168.1.0/24
```

OSPF command:

```bash
router ospf 1
network 192.168.1.0 0.0.0.255 area 0
```

Meaning:

Enable OSPF on interfaces in:

```
192.168.1.0/24
```

---

# Host Wildcard Mask

Single host:

Subnet mask:

```
255.255.255.255
```

Wildcard:

```
0.0.0.0
```

Example:

```bash
access-list 10 permit host 192.168.1.10
```

Equivalent:

```bash
access-list 10 permit 192.168.1.10 0.0.0.0
```

# 3. Worked Examples

## Example 1: Convert Subnet Mask to Wildcard Mask

Given:

```
255.255.255.224
```

Find wildcard mask.

---

Solution:

Step 1:

Subtract each octet:

```
255-255 = 0
255-255 = 0
255-255 = 0
255-224 = 31
```

Step 2:

Answer:

```
0.0.0.31
```

---

## Example 2: Determine Matching Addresses

ACL:

```bash
access-list 10 permit 192.168.5.0 0.0.0.255
```

Question:

Which addresses match?

---

Solution:

Wildcard:

```
0.0.0.255
```

Meaning:

First 3 octets fixed.

Matches:

```
192.168.5.1
192.168.5.100
192.168.5.254
```

Does not match:

```
192.168.6.10
```

# 5. Exam Traps

- Wildcard mask is NOT the subnet mask.
- Wildcard mask is the inverse of subnet mask.
- In wildcard masks:
  - 0 = must match
  - 1 = ignore
- Subnet masks:
  - 1 = network bits
  - 0 = host bits
- /32 wildcard is 0.0.0.0.
- ACLs use wildcard masks, not subnet masks.
- OSPF network statements use wildcard masks.
- A wildcard of 0.0.0.255 matches only one /24 network.
- Invalid subnet masks cannot have 1s after 0s.

# 7. Practice Questions

## Question 1

What is the wildcard mask for:

```
255.255.255.0
```

A. 0.0.0.0  
B. 0.0.0.255  
C. 255.255.255.0  
D. 0.0.255.255  

### Answer: B. 0.0.0.255

Explanation:

Wildcard is the inverse of subnet mask.

---

## Question 2

Which value in a wildcard mask means "must match"?

A. 0  
B. 1  
C. 255  
D. 254  

### Answer: A. 0

Explanation:

Wildcard 0 requires an exact match.

---

## Question 3

Which technology commonly uses wildcard masks?

A. DHCP  
B. ACL  
C. NAT  
D. STP  

### Answer: B. ACL

Explanation:

Cisco ACLs use wildcard masks for address matching.

---

## Question 4

What wildcard mask matches a single host?

A. 0.0.0.255  
B. 255.255.255.255  
C. 0.0.0.0  
D. 255.0.0.0  

### Answer: C. 0.0.0.0

Explanation:

A single host requires all bits to match.

---

## Question 5

What is the wildcard mask for /26?

A. 0.0.0.31  
B. 0.0.0.63  
C. 0.0.0.127  
D. 0.0.0.255  

### Answer: B. 0.0.0.63

Explanation:

/26 subnet mask:

```
255.255.255.192
```

Wildcard:

```
255-192 = 63
```
