# 1. Overview

First Hop Redundancy Protocols (FHRPs) provide default gateway redundancy for end devices by allowing multiple Layer 3 devices to share a virtual gateway address. CCNA tests HSRP, VRRP, GLBP concepts, virtual IP operation, active/standby roles, and basic configuration.

---

# 2. Core Concepts

# First Hop Redundancy Protocol (FHRP)

Definition:

```
A protocol that provides a redundant default gateway
for hosts in a LAN.
```

Problem without FHRP:

```
Host
 |
Default Gateway
 |
Router Failure
 |
Network unreachable
```

With FHRP:

```
          Virtual Gateway
              |
       ----------------
       |              |
      R1             R2
   Active          Standby
```

---

# FHRP Purpose

| Purpose | Description |
|---|---|
| Gateway redundancy | Backup default gateway |
| High availability | Reduces downtime |
| Automatic failover | Moves gateway role |
| Transparent to hosts | Hosts use virtual IP |

---

# FHRP Components

| Component | Meaning |
|---|---|
| Physical IP | Real router interface address |
| Virtual IP | Shared gateway address |
| Virtual MAC | Shared MAC address |
| Active router | Currently forwarding |
| Standby router | Backup router |

---

# FHRP Operation

Example:

Hosts configure:

```
Default Gateway:
192.168.1.1
```

This is:

```
Virtual IP
```

Not a physical router IP.

---

Normal operation:

```
Client
 |
Virtual Gateway
 |
Active Router
 |
Network
```

Failure:

```
Active Router fails

Standby becomes Active
```

---

# FHRP Protocol Comparison

| Feature | HSRP | VRRP | GLBP |
|---|---|---|---|
| Vendor | Cisco | Open Standard | Cisco |
| Standard | Cisco proprietary | RFC 5798 | Cisco proprietary |
| Purpose | Redundancy | Redundancy | Redundancy + Load balancing |
| Active role | Yes | Master | AVG/AVF |
| Standby role | Yes | Backup | No |
| Load balancing | No (traditional) | Limited | Yes |

---

# HSRP (Hot Standby Router Protocol)

## Definition

HSRP is Cisco's FHRP that creates a virtual router using active and standby roles.

---

# HSRP Roles

| Role | Function |
|---|---|
| Active | Forwards packets |
| Standby | Backup router |
| Listen | Other HSRP routers |

---

# HSRP Virtual Router

Contains:

```
Virtual IP
+
Virtual MAC
```

Hosts communicate with:

```
Virtual router
```

---

# HSRP Versions

| Version | Support |
|---|---|
| HSRPv1 | IPv4 |
| HSRPv2 | IPv4 + larger group range |

---

# HSRP Virtual MAC

HSRPv1:

```
0000.0c07.acXX
```

Example:

Group 10:

```
0000.0c07.ac0a
```

---

HSRPv2:

```
0000.0c9f.fXXX
```

---

# HSRP States

| State | Meaning |
|---|---|
| Initial | Starting |
| Learn | Learning virtual IP |
| Listen | Monitoring |
| Speak | Participating in election |
| Standby | Backup router |
| Active | Forwarding traffic |

---

# HSRP Election

Decision:

1. Highest priority
2. Highest IP address if priority equal

Default priority:

```
100
```

Range:

```
0-255
```

---

# HSRP Preemption

Problem:

Router with higher priority returns but does not automatically become active.

Solution:

Enable:

```
preempt
```

---

# VRRP (Virtual Router Redundancy Protocol)

## Definition

VRRP is an open-standard FHRP defined by IETF.

RFC:

```
5798
```

---

# VRRP Roles

| Role | Function |
|---|---|
| Master | Active router |
| Backup | Standby router |

---

# VRRP Election

Uses:

1. Highest priority
2. Highest IP address

Default priority:

```
100
```

Master priority range:

```
1-254
```

Priority:

```
255 = owner of virtual IP
```

---

# VRRP Virtual MAC

Format:

```
0000.5e00.01XX
```

---

# GLBP (Gateway Load Balancing Protocol)

## Definition

GLBP is Cisco proprietary FHRP that provides:

- Gateway redundancy
- Load balancing

---

# GLBP Roles

| Role | Function |
|---|---|
| AVG | Active Virtual Gateway |
| AVF | Active Virtual Forwarder |

---

# AVG (Active Virtual Gateway)

Responsible for:

- Virtual IP
- Assigning virtual MAC addresses
- Selecting AVFs

---

# AVF (Active Virtual Forwarder)

Responsible for:

- Forwarding client traffic

Multiple routers can forward traffic.

---

# GLBP Load Balancing Methods

| Method | Description |
|---|---|
| Round-robin | Each client gets next MAC |
| Weighted | Based on router capacity |
| Host-dependent | Same client uses same router |

---

# HSRP vs VRRP vs GLBP

| Feature | HSRP | VRRP | GLBP |
|---|---|---|---|
| Vendor | Cisco | Open | Cisco |
| Active device | Active | Master | Multiple AVF |
| Backup | Standby | Backup | AVF |
| Load balancing | No | Limited | Yes |
| Default priority | 100 | 100 | 100 |
| Virtual IP | Yes | Yes | Yes |

# Cisco Commands

# HSRP Configuration

Example:

Router 1:

```bash
interface gigabitEthernet 0/1
```

Select interface.

---

```bash
ip address 192.168.1.2 255.255.255.0
```

Assign physical IP.

---

```bash
standby 10 ip 192.168.1.1
```

Creates HSRP group 10.

Virtual IP:

```
192.168.1.1
```

---

```bash
standby 10 priority 110
```

Makes router preferred.

---

```bash
standby 10 preempt
```

Allows router to regain active role.

# 3. Worked Examples

## Example 1: HSRP Active Router Election

Given:

| Router | Priority | IP |
|---|---:|---|
| R1 | 100 | 192.168.1.2 |
| R2 | 110 | 192.168.1.3 |

---

Step 1:

Compare priority:

```
R1 = 100
R2 = 110
```

Highest priority wins.

---

Result:

```
Active Router = R2
Standby Router = R1
```

---

## Example 2: HSRP Failover

Normal:

```
R1 = Active
R2 = Standby

Virtual IP:
192.168.1.1
```

---

Failure:

```
R1 goes down
```

---

Process:

1. R2 detects missing hellos.
2. R2 changes state:

```
Standby → Active
```

3. Hosts continue using:

```
192.168.1.1
```

---

Result:

```
Network continues working.
```

# 4. Configuration/Commands (if applicable)

## Complete HSRP Example

Router R1:

```bash
interface gigabitEthernet 0/0
ip address 10.1.1.2 255.255.255.0
standby 1 ip 10.1.1.1
standby 1 priority 110
standby 1 preempt
```

Explanation:

| Command | Function |
|---|---|
| interface | Selects interface |
| ip address | Physical IP |
| standby ip | Virtual gateway |
| priority | Election preference |
| preempt | Restore active role |

# 5. Exam Traps

- FHRP provides default gateway redundancy.
- Hosts use the virtual IP, not router IP.
- HSRP is Cisco proprietary.
- VRRP is an open standard.
- GLBP provides load balancing.
- HSRP active router forwards traffic.
- HSRP standby router does not normally forward traffic.
- Highest priority wins elections.
- If priority ties, highest IP wins.
- Default HSRP priority is 100.
- Preemption is disabled by default.
- GLBP uses AVG and AVF roles.
- Virtual MAC is different from physical MAC.
- FHRP does not replace routing protocols.

Which FHRP supports gateway load balancing?

A. HSRP  
B. VRRP

Which HSRP router forwards traffic?

A. Standby  
B. Active  
C. Listen

### Answer: B

Explanation:

The active router forwards packets.
