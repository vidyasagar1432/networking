# 1. Overview

Open Shortest Path First (OSPF) is a link-state routing protocol that uses the SPF (Shortest Path First) algorithm to calculate the best path. CCNA tests OSPF operation, area concepts, LSA types, DR/BDR elections, OSPFv2 for IPv4, and OSPFv3 for IPv6.

---

# 2. Core Concepts

# OSPF Definition

OSPF:

```
Open Shortest Path First
```

Protocol type:

```
Link-State Routing Protocol
```

Algorithm:

```
Dijkstra SPF Algorithm
```

---

# OSPF Characteristics

| Feature | Value |
|---|---|
| Protocol type | Link-state |
| Algorithm | SPF (Dijkstra) |
| IP protocol number | 89 |
| Transport protocol | None |
| Administrative Distance | 110 |
| Metric | Cost |
| Multicast addresses | 224.0.0.5 / 224.0.0.6 |
| IPv6 multicast | FF02::5 / FF02::6 |

---

# OSPF Metric

OSPF uses:

```
Cost
```

Formula:

```
Cost = Reference Bandwidth / Interface Bandwidth
```

Default reference bandwidth:

```
100 Mbps
```

Example:

100 Mbps link:

```
100/100 = Cost 1
```

---

# Link-State Concept

Each OSPF router builds:

```
Link-State Database (LSDB)
```

Contains:

- Network topology
- Router information
- Link information

All routers in the same area have the same LSDB.

---

# OSPF Operation

Process:

```
Discover neighbors
        |
        v
Exchange LSAs
        |
        v
Build LSDB
        |
        v
Run SPF algorithm
        |
        v
Install routes
```

---

# OSPF Tables

| Table | Purpose |
|---|---|
| Neighbor table | Stores OSPF neighbors |
| LSDB | Stores topology information |
| Routing table | Stores best routes |

Commands:

```
show ip ospf neighbor
show ip ospf database
show ip route ospf
```

---

# OSPF Areas

## Definition

An OSPF area is a logical grouping of routers that share the same LSDB.

Purpose:

- Reduce LSDB size
- Improve scalability
- Reduce SPF calculations

---

# Area Types

| Area                | Purpose                        |
| ------------------- | ------------------------------ |
| Area 0              | Backbone area                  |
| Normal area         | Standard OSPF area             |
| Stub area           | Blocks external LSAs           |
| Totally Stubby area | Blocks most LSAs               |
| NSSA                | Allows limited external routes |

---

# Backbone Area

Area:

```
Area 0
```

Rules:

- All OSPF areas must connect to Area 0.
- Provides inter-area communication.

---

# OSPF Router Types

| Router Type | Function |
|---|---|
| Internal Router | All interfaces in same area |
| Backbone Router | Connected to Area 0 |
| ABR | Connects multiple areas |
| ASBR | Connects OSPF to external networks |

---

# ABR (Area Border Router)

Connects:

```
Area 0
+
Other OSPF areas
```

Functions:

- Maintains multiple LSDBs
- Summarizes routes between areas

---

# ASBR (Autonomous System Boundary Router)

Connects OSPF to:

- RIP
- EIGRP
- Static routes
- BGP

---

# OSPF Neighbor Formation

Routers become neighbors using:

```
Hello packets
```

---

# OSPF Hello Packet Contains

| Field | Purpose |
|---|---|
| Router ID | Identifies router |
| Area ID | Must match |
| Hello timer | Must match |
| Dead timer | Must match |
| Network type | Must match |
| Authentication | Must match |

---

# OSPF Neighbor States

| State | Meaning |
|---|---|
| Down | No hello received |
| Init | Hello received |
| 2-Way | Bidirectional communication |
| ExStart | Master/slave negotiation |
| Exchange | Database description exchange |
| Loading | Requesting LSAs |
| Full | LSDB synchronized |

---

# OSPF Router ID

A 32-bit value used to identify OSPF routers.

Format:

```
IPv4 address format
```

Example:

```
1.1.1.1
```

---

# Router ID Selection

Order:

1. Manually configured router-id
2. Highest loopback IP address
3. Highest active interface IP address

# LSA (Link-State Advertisement)

## Definition

LSAs are messages used by OSPF routers to share topology information.

Stored in:

```
LSDB
```

---

# Common OSPF LSA Types

| Type | Name | Generated By | Purpose |
|---|---|---|---|
| 1 | Router LSA | Every OSPF router | Router links |
| 2 | Network LSA | DR | Multi-access networks |
| 3 | Summary LSA | ABR | Inter-area routes |
| 4 | ASBR Summary LSA | ABR | ASBR location |
| 5 | External LSA | ASBR | External routes |
| 7 | NSSA External LSA | NSSA ASBR | NSSA external routes |

---

# LSA Type Details

## Type 1: Router LSA

Generated by:

```
Every OSPF router
```

Contains:

- Router links
- Interface information
- Area information

---

## Type 2: Network LSA

Generated by:

```
DR only
```

Used on:

```
Broadcast networks
```

Contains:

- Connected routers
- Network information

---

## Type 3: Summary LSA

Generated by:

```
ABR
```

Advertises:

```
Inter-area routes
```

---

## Type 4: ASBR Summary LSA

Provides:

```
Path to ASBR
```

Generated by:

```
ABR
```

---

## Type 5: External LSA

Generated by:

```
ASBR
```

Contains:

- External routes
- Redistributed networks

---

## Type 7: NSSA External LSA

Used in:

```
NSSA areas
```

Generated by:

```
NSSA ASBR
```

# DR/BDR Election

## Purpose

On multi-access networks (Ethernet), OSPF elects:

- DR (Designated Router)
- BDR (Backup Designated Router)

Purpose:

Reduce OSPF adjacency overhead.

---

# Without DR/BDR

Example:

5 routers:

Full mesh:

```
n(n-1)/2
```

Adjacencies:

```
5×4/2 = 10
```

---

# With DR/BDR

Routers form adjacency with:

```
DR + BDR
```

Reduces overhead.

---

# DR/BDR Election Criteria

Highest:

1. OSPF priority
2. Router ID

wins.

---

# OSPF Priority

Default:

```
1
```

Range:

```
0-255
```

Priority:

```
0 = never becomes DR/BDR
```

---

# DR/BDR Election Example

Routers:

| Router | Priority | Router ID |
|---|---:|---|
| R1 | 1 | 1.1.1.1 |
| R2 | 10 | 2.2.2.2 |
| R3 | 5 | 3.3.3.3 |

Winner:

DR:

```
R2
```

Reason:

Highest priority.

---

# DR/BDR Multicast Addresses

| Address | Purpose |
|---|---|
| 224.0.0.5 | All OSPF routers |
| 224.0.0.6 | DR/BDR only |

IPv6:

| Address | Purpose |
|---|---|
| FF02::5 | All OSPFv3 routers |
| FF02::6 | DR/BDR |

---

# OSPF Network Types

| Type | DR/BDR |
|---|---|
| Broadcast Ethernet | Yes |
| Point-to-point | No |
| NBMA | Yes |
| Point-to-multipoint | No |

---

# OSPFv2 vs OSPFv3

| Feature | OSPFv2 | OSPFv3 |
|---|---|---|
| Address family | IPv4 | IPv6 |
| Protocol number | 89 | 89 |
| Algorithm | SPF | SPF |
| LSA concept | Yes | Yes |
| Multicast | 224.0.0.5/6 | FF02::5/6 |
| Router ID | IPv4 format | IPv4 format |
| Security | Authentication in header | IPv6 security methods |

---

# OSPFv3 Characteristics

OSPFv3:

- Supports IPv6 routing
- Uses link-local addresses
- Separates routing protocol from address family

Example:

```
IPv6 address:
2001:db8::1

OSPFv3 neighbor:
Uses FE80:: address
```

# 3. Worked Examples

## Example 1: DR Election

Network:

| Router | Priority | Router ID |
|---|---:|---|
| R1 | 1 | 10.10.10.10 |
| R2 | 5 | 2.2.2.2 |
| R3 | 5 | 3.3.3.3 |

---

Step 1:

Compare priority:

```
R2 = 5
R3 = 5
R1 = 1
```

R2/R3 continue.

---

Step 2:

Compare Router ID:

```
R3 = 3.3.3.3
R2 = 2.2.2.2
```

Highest wins.

Answer:

```
DR = R3
BDR = R2
```

---

## Example 2: Identify LSA Type

Scenario:

An ABR advertises routes from Area 1 into Area 0.

Question:

Which LSA type is used?

---

Solution:

ABR advertises:

```
Inter-area routes
```

LSA:

```
Type 3 Summary LSA
```

Answer:

```
LSA Type 3
```

# 5. Exam Traps

- OSPF is link-state, not distance-vector.
- OSPF uses Dijkstra SPF algorithm.
- OSPF AD is 110.
- OSPF protocol number is 89.
- Area 0 is the backbone area.
- All areas should connect to Area 0.
- DR/BDR elections happen on multi-access networks.
- Highest priority wins DR election.
- If priority ties, highest Router ID wins.
- Priority 0 cannot become DR/BDR.
- DR/BDR election is not preemptive by default.
- Type 1 LSA is generated by every router.
- Type 2 LSA is generated by DR.
- Type 3 LSA is generated by ABR.
- Type 5 LSA is generated by ASBR.
- OSPFv3 is used for IPv6.
- OSPFv3 still uses IPv4-style Router IDs.

# 7. Practice Questions

## Question 1

Which algorithm does OSPF use?

A. DUAL  
B. Bellman-Ford  
C. Dijkstra SPF  
D. Path Vector  

### Answer: C. Dijkstra SPF

Explanation:

OSPF is a link-state protocol using SPF.

---

## Question 2

Which area is the OSPF backbone?

A. Area 1  
B. Area 10  
C. Area 0  
D. NSSA  

### Answer: C. Area 0

Explanation:

All OSPF areas connect through Area 0.

---

## Question 3

Which LSA type is generated by an ABR?

A. Type 1  
B. Type 2  
C. Type 3  
D. Type 5  

### Answer: C. Type 3

Explanation:

ABRs generate summary LSAs.

---

## Question 4

Which router becomes DR?

A. Lowest priority  
B. Highest priority  
C. Lowest router ID  
D. First powered-on router  

### Answer: B. Highest priority

Explanation:

OSPF elects DR using priority first.

---

## Question 5

What is the OSPF administrative distance?

A. 90  
B. 100  
C. 110  
D. 120  

### Answer: C. 110

Explanation:

OSPF default AD is 110.
