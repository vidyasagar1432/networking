# 1. Overview

Ansible is an open-source automation platform used to automate network configuration, device management, software deployment, and operational tasks. Network engineers use Ansible to configure hundreds of routers, switches, firewalls, and servers consistently without manually connecting to each device.

Ansible uses **YAML-based playbooks** to describe the desired network state and communicates with devices using protocols such as SSH, NETCONF, and APIs.

# 10. Ansible Playbooks

## Definition

A playbook is a YAML file containing automation instructions.

File:

```
playbook.yml
```

---

Example:

```yaml
---
- name: Show router information
  hosts: routers

  tasks:

    - name: Get interface status
      cisco.ios.ios_command:
        commands:
          - show ip interface brief
```

---

# 11. YAML Structure in Ansible

Basic hierarchy:

```
Playbook

 └── Play

      └── Tasks

            └── Modules
```

---

Example:

```yaml
- hosts: routers

  tasks:

    - name: Configure interface
      ios_config:
        lines:
          - description LAN
```

---

# 12. Tasks

## Definition

A task is one action performed by Ansible.

Example:

```yaml
tasks:

- name: Check version
  ios_command:
    commands:
      - show version
```

---

# 13. Play

A play defines:

- Target devices
- Tasks to execute

Example:

```yaml
- hosts: switches
```

Means:

```
Run tasks on switches group
```

# 15. Cisco IOS Example

## Show Command Automation

Playbook:

```yaml
---
- name: Check interfaces
  hosts: routers

  tasks:

  - name: Show interfaces
    cisco.ios.ios_command:
      commands:
        - show ip interface brief
```

---

Result:

```
GigabitEthernet0/0 up up

GigabitEthernet0/1 down down
```

# 16. Configuration Automation

Example:

Configure hostname:

```yaml
---
- name: Configure hostname

  hosts: routers

  tasks:

  - name: Set hostname
    cisco.ios.ios_config:
      lines:
        - hostname Router-A
```

---

Equivalent CLI:

```bash
hostname Router-A
```

---

# 17. VLAN Configuration Example

Playbook:

```yaml
- name: Create VLAN

  hosts: switches

  tasks:

  - name: Add VLAN

    cisco.ios.ios_vlans:

      config:

      - vlan_id: 10
        name: USERS
```

---

Equivalent CLI:

```bash
vlan 10

name USERS
```

# 18. Idempotency

## Definition

Ansible only makes required changes.

Example:

First run:

```
Create VLAN 10
```

Second run:

```
Already exists

No change
```

---

Benefits:

- Safe automation
- Prevents unnecessary changes
- Predictable results
