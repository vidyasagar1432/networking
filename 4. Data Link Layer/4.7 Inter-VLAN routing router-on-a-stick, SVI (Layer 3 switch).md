# 1. Overview

Inter-VLAN routing enables communication between devices located in different VLANs by using a Layer 3 device. CCNA tests two main methods: router-on-a-stick using subinterfaces and Layer 3 switching using Switched Virtual Interfaces (SVIs).

---

# 2. Core Concepts

# Why Inter-VLAN Routing is Required

## VLANs Create Separate Broadcast Domains

Example:

```
VLAN 10                 VLAN 20

PC-A                    PC-B
192.168.10.10           192.168.20.10

        X
   Cannot communicate
```

Reason:

- Different VLANs
- Different broadcast domains

Solution:

```
Layer 3 routing required
```

---

# Inter-VLAN Routing Methods

| Method | Device Used | Interface Type |
|---|---|---|
| Router-on-a-stick | Router | Subinterfaces |
| SVI routing | Layer 3 switch | VLAN interfaces |
| Legacy inter-VLAN | Router | Multiple physical interfaces |

---

# Method 1: Router-on-a-Stick

## Definition

Router-on-a-stick uses one physical router interface configured with multiple logical subinterfaces to route between VLANs.

---

# Router-on-a-Stick Topology

```
             Trunk Link
               
Switch ================= Router

VLAN 10 ------------- G0/0.10
VLAN 20 ------------- G0/0.20
```

---

# Router-on-a-Stick Components

| Component | Purpose |
|---|---|
| Router interface | Physical connection |
| Subinterface | Logical VLAN interface |
| 802.1Q encapsulation | VLAN tagging |
| Default gateway | Router subinterface IP |

---

# Router Subinterface

Example:

```
G0/0.10
```

Meaning:

| Part | Meaning |
|---|---|
| G0/0 | Physical interface |
| .10 | Subinterface number |

---

# Router-on-a-Stick Operation

Example:

PC in VLAN 10:

```
192.168.10.10
Gateway:
192.168.10.1
```

Process:

```
PC
 |
VLAN 10
 |
Switch
 |
802.1Q trunk
 |
Router G0/0.10
 |
Routing
 |
Router G0/0.20
 |
VLAN 20
 |
PC
```

---

# Router-on-a-Stick Limitations

| Limitation | Explanation |
|---|---|
| Single physical link | Traffic bottleneck |
| Router CPU processing | Less scalable |
| More latency | Compared with Layer 3 switch |

---

# Method 2: SVI (Switched Virtual Interface)

## Definition

An SVI is a virtual Layer 3 interface on a multilayer switch used as a VLAN gateway.

Example:

```
interface vlan 10
IP address 192.168.10.1
```

---

# SVI Topology

```
             Layer 3 Switch

          VLAN 10 SVI
              |
              |
PC-A -------- VLAN 10


          VLAN 20 SVI
              |
              |
PC-B -------- VLAN 20
```

---

# SVI Characteristics

| Feature | Value |
|---|---|
| Interface type | Virtual |
| Created with | interface vlan command |
| Provides | Default gateway |
| Device | Layer 3 switch |
| Routing required | Enabled |

---

# SVI Example

VLAN 10:

```
Network:
192.168.10.0/24

Gateway:
192.168.10.1
```

SVI:

```
interface vlan 10
ip address 192.168.10.1 255.255.255.0
```

---

# Router-on-a-Stick vs SVI

| Feature | Router-on-a-Stick | SVI |
|---|---|---|
| Device | Router | Layer 3 switch |
| Interface | Subinterface | VLAN interface |
| Routing location | Router | Switch |
| Performance | Lower | Higher |
| Scalability | Limited | Better |
| Common enterprise use | Less common | Common |

---

# Layer 2 Switch vs Layer 3 Switch

| Feature | Layer 2 Switch | Layer 3 Switch |
|---|---|---|
| Switching | Yes | Yes |
| Routing | No | Yes |
| VLAN support | Yes | Yes |
| SVI routing | Limited | Yes |
| IP forwarding | No | Yes |

---

# Default Gateway Role

Every VLAN needs a gateway for external communication.

Example:

VLAN 10:

```
PC:
192.168.10.50

Gateway:
192.168.10.1
```

Traffic leaving VLAN 10:

```
PC
 |
Default Gateway
 |
Router/L3 Switch
 |
Destination VLAN
```

---

# Routing Table on Layer 3 Switch

Example:

```
C 192.168.10.0/24 is directly connected, VLAN10

C 192.168.20.0/24 is directly connected, VLAN20
```

The switch routes between connected VLANs.

---

# Enabling Layer 3 Routing

Layer 3 switches require:

```
ip routing
```

Without it:

- SVIs exist
- Routing does not occur

---

# VLAN Interface Status

For an SVI to become active:

Requirements:

| Requirement | Needed |
|---|---|
| VLAN exists | Yes |
| SVI configured | Yes |
| VLAN has active port | Yes |
| Interface not shutdown | Yes |

---

# Inter-VLAN Traffic Flow

Example:

```
PC-A VLAN 10
        |
        |
Gateway VLAN 10 SVI
        |
        |
Layer 3 Routing
        |
        |
Gateway VLAN 20 SVI
        |
        |
PC-B VLAN 20
```

---

# ARP in Inter-VLAN Routing

Process:

1. PC checks destination IP.
2. Determines destination is another network.
3. Sends frame to default gateway MAC.
4. Router/L3 switch routes packet.
5. New Layer 2 frame created.

---

# Ethernet Frame Changes During Routing

Before routing:

```
Source MAC:
PC-A

Destination MAC:
Gateway
```

After routing:

```
Source MAC:
Gateway

Destination MAC:
PC-B
```

IP addresses remain:

```
Source IP: PC-A
Destination IP: PC-B
```

# 3. Worked Examples

## Example 1: Router-on-a-Stick Design

### Scenario

Requirements:

- VLAN 10: 192.168.10.0/24
- VLAN 20: 192.168.20.0/24
- Router interface: G0/0

Configure gateways.

---

### Solution

Step 1:

Create VLAN 10 subinterface:

```
G0/0.10
```

Step 2:

Add VLAN tag:

```
encapsulation dot1Q 10
```

Step 3:

Assign gateway:

```
192.168.10.1/24
```

---

Step 4:

Create VLAN 20 subinterface:

```
G0/0.20
```

Step 5:

Configure:

```
encapsulation dot1Q 20
```

Step 6:

Assign:

```
192.168.20.1/24
```

Result:

```
VLAN 10 gateway = 192.168.10.1
VLAN 20 gateway = 192.168.20.1
```

---

## Example 2: SVI Troubleshooting

### Scenario

SVI configuration:

```
interface vlan 10
ip address 192.168.10.1 255.255.255.0
no shutdown
```

But:

```
show ip interface brief
```

shows:

```
Vlan10 down
```

---

### Solution

Step 1:

Check if VLAN exists.

```
show vlan brief
```

Step 2:

Check active ports.

An SVI requires at least one active port in that VLAN.

Step 3:

Assign an active access port:

```
interface gi0/1
switchport access vlan 10
```

Result:

```
Vlan10 becomes up
```

# 5. Exam Traps

- VLANs cannot communicate without Layer 3 routing.
- Router-on-a-stick uses subinterfaces.
- SVI is used on Layer 3 switches.
- 802.1Q tagging is required on router-on-a-stick trunks.
- A Layer 3 switch requires `ip routing` for inter-VLAN routing.
- An SVI may stay down if the VLAN has no active ports.
- Access ports connect end devices; trunk ports connect network devices.
- MAC addresses change at every routed hop.
- IP addresses remain end-to-end during routing.
- Router-on-a-stick uses one physical interface for multiple VLANs.
- SVI routing is usually faster than router-on-a-stick.

# 7. Practice Questions

## Question 1

Which technology allows communication between different VLANs?

A. STP  
B. Inter-VLAN routing  
C. EtherChannel  
D. VTP  

### Answer: B. Inter-VLAN routing

Explanation:

Different VLANs are separate broadcast domains and require Layer 3 routing.

---

## Question 2

Router-on-a-stick uses:

A. Multiple physical router ports  
B. Router subinterfaces  
C. Only Layer 2 switching  
D. Static MAC addresses  

### Answer: B. Router subinterfaces

Explanation:

One router interface is divided into multiple logical subinterfaces.

---

## Question 3

Which command enables routing on a Layer 3 switch?

A. router ospf  
B. ip routing  
C. switchport routing  
D. route enable  

### Answer: B. ip routing

Explanation:

Layer 3 switches require IP routing enabled.

---

## Question 4

What is an SVI?

A. A physical cable  
B. A VLAN trunk  
C. A virtual Layer 3 interface  
D. A MAC address table  

### Answer: C. A virtual Layer 3 interface

Explanation:

SVIs provide IP gateways for VLANs.

---

## Question 5

A VLAN 10 SVI is down/down. What is a possible cause?

A. Wrong MAC address  
B. No active port in VLAN 10  
C. Incorrect DNS  
D. Bad routing protocol  

### Answer: B. No active port in VLAN 10

Explanation:

An SVI requires an active VLAN port to become operational.
