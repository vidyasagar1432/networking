# 1. Overview

The Spanning Tree Protocol (STP) elects a root bridge and assigns port roles to create a loop-free Layer 2 topology. CCNA tests how switches exchange BPDUs, how the root bridge is selected, and how ports transition between forwarding and blocking states.

---

# 2. Core Concepts

# STP Operation Overview

STP follows this process:

```
1. Exchange BPDUs
        |
        v
2. Elect Root Bridge
        |
        v
3. Select Root Ports
        |
        v
4. Select Designated Ports
        |
        v
5. Block redundant paths
```

---

# Root Bridge

## Definition

The root bridge is the central reference point of the STP topology.

Characteristics:

| Feature | Description |
|---|---|
| Has lowest Bridge ID | Yes |
| Root port | None |
| All ports | Usually designated ports |
| Sends BPDUs | Yes |

---

# Bridge ID (BID)

STP uses Bridge ID to elect the root bridge.

Format:

```
Bridge ID =
Bridge Priority + Extended System ID + MAC Address
```

---

# Bridge ID Components

| Component | Description |
|---|---|
| Priority | Determines preference |
| Extended System ID | Contains VLAN ID |
| MAC Address | Tie breaker |

---

# Default Cisco STP Priority

| Value | Meaning |
|---|---|
| 32768 | Default priority |
| 0 | Highest preference |
| 61440 | Lowest preference |

Priority changes:

```
4096 increments
```

---

# Root Bridge Election Rules

Lowest Bridge ID wins.

Comparison order:

```
1. Lowest priority
2. Lowest VLAN ID (extended system ID)
3. Lowest MAC address
```

---

# Root Bridge Election Example

Switch A:

```
Priority: 32768
MAC: 00:00:00:00:00:01
```

Switch B:

```
Priority: 24576
MAC: FF:FF:FF:FF:FF:FF
```

Winner:

```
Switch B
```

Reason:

```
24576 < 32768
```

---

# Bridge ID Tie Example

Switch A:

```
Priority: 32768
MAC:
00:11:22:33:44:55
```

Switch B:

```
Priority: 32768
MAC:
00:11:22:33:44:66
```

Winner:

```
Switch A
```

Reason:

Lower MAC address wins.

---

# BPDUs (Bridge Protocol Data Units)

## Definition

BPDUs are STP control frames exchanged between switches to calculate the spanning-tree topology.

---

# BPDU Purpose

| Purpose | Description |
|---|---|
| Elect root bridge | Determines best switch |
| Exchange topology information | Shares STP data |
| Detect topology changes | Maintains stability |

---

# BPDU Destination MAC

STP BPDU multicast address:

```
01:80:C2:00:00:00
```

---

# BPDU Information Fields

| Field | Purpose |
|---|---|
| Root Bridge ID | Current root information |
| Sender Bridge ID | Sending switch |
| Root Path Cost | Distance to root |
| Sender Port ID | Sending interface |
| Timer values | STP timing information |

---

# BPDU Types

| BPDU Type | Purpose |
|---|---|
| Configuration BPDU | Normal STP operation |
| Topology Change Notification (TCN) | Announces topology changes |

---

# BPDU Exchange Example

```
Switch A                 Switch B

   BPDU  ---------------->

"Who is root?"
```

Switches compare:

- Root ID
- Cost
- Bridge ID

and select best paths.

---

# Port Roles

STP assigns every switch port a role.

Main roles:

| Role | Purpose |
|---|---|
| Root Port | Best path toward root bridge |
| Designated Port | Forwarding port for a segment |
| Non-designated Port | Blocking backup path |

---

# Root Port (RP)

## Definition

The root port is the best path from a non-root switch toward the root bridge.

Rules:

- Every non-root switch has exactly one root port.
- Root bridge has no root port.

---

# Root Port Selection Criteria

Lowest value wins:

1. Lowest root path cost
2. Lowest sender Bridge ID
3. Lowest sender Port ID

---

# Root Port Example

```
          Root Bridge

              |
          Cost 4
              |
          Switch A

          /      \
      Cost 19   Cost 4
```

Switch A selects:

```
Cost 4 path
```

as root port.

---

# Designated Port (DP)

## Definition

The designated port is the forwarding port selected for each network segment.

Characteristics:

| Feature | Value |
|---|---|
| State | Forwarding |
| Sends BPDUs | Yes |
| One per segment | Yes |

---

# Non-Designated Port

## Definition

A port that is blocked to prevent loops.

Characteristics:

| Feature | Value |
|---|---|
| State | Blocking/discarding |
| Forwards frames | No |
| Receives BPDUs | Yes |

---

# Port Role Summary

| Port Role | Function | State |
|---|---|---|
| Root Port | Best path to root | Forwarding |
| Designated Port | Best path on segment | Forwarding |
| Alternate Port | Backup path (RSTP) | Blocking |
| Backup Port | Backup designated port | Blocking |

---

# STP Port States (802.1D)

Traditional STP has five states:

| State | Function |
|---|---|
| Disabled | Port inactive |
| Blocking | Receives BPDUs only |
| Listening | Builds topology |
| Learning | Learns MAC addresses |
| Forwarding | Sends and receives traffic |

---

# STP State Transition

```
Blocking
   |
   v
Listening
   |
   v
Learning
   |
   v
Forwarding
```

---

# Port State Details

## Blocking

| Feature | Status |
|---|---|
| Receive BPDUs | Yes |
| Learn MAC addresses | No |
| Forward frames | No |

---

## Listening

| Feature | Status |
|---|---|
| Learn MAC | No |
| Forward frames | No |
| Build topology | Yes |

---

## Learning

| Feature | Status |
|---|---|
| Learn MAC | Yes |
| Forward frames | No |

---

## Forwarding

| Feature | Status |
|---|---|
| Learn MAC | Yes |
| Forward frames | Yes |

---

# RSTP Port Roles

RSTP simplifies roles:

| RSTP Role | Equivalent |
|---|---|
| Root | Root Port |
| Designated | Designated Port |
| Alternate | Backup root path |
| Backup | Backup designated port |

---

# STP Timers

| Timer | Default |
|---|---:|
| Hello Time | 2 seconds |
| Forward Delay | 15 seconds |
| Max Age | 20 seconds |

---

# BPDU Guard

## Purpose

Protects PortFast-enabled ports from unauthorized switches.

Example:

```
PC Port
 |
Switch added accidentally
 |
BPDU received
 |
Port shutdown
```

---

# BPDU Filter

## Purpose

Suppresses BPDU transmission/reception.

Warning:

Can create loops if incorrectly used.

# 3. Worked Examples

## Example 1: Root Bridge Election

### Scenario

Three switches:

Switch A:

```
Priority: 32768
MAC: 00:00:00:00:00:01
```

Switch B:

```
Priority: 28672
MAC: 00:00:00:00:00:02
```

Switch C:

```
Priority: 32768
MAC: 00:00:00:00:00:03
```

Which becomes root?

---

### Solution

Step 1:

Compare priorities.

```
A = 32768
B = 28672
C = 32768
```

Step 2:

Lowest priority:

```
Switch B
```

Answer:

```
Switch B becomes root bridge
```

---

## Example 2: Root Port Selection

### Scenario

Switch A has two paths to root.

Path 1:

```
Cost = 4
Sender BID = 32768
```

Path 2:

```
Cost = 19
Sender BID = 24576
```

Which becomes root port?

---

### Solution

Step 1:

Compare path cost.

```
4 < 19
```

Step 2:

Lower cost wins.

Answer:

```
Path 1 becomes root port
```

Sender BID is not considered because cost already decides.

# 5. Exam Traps

- Root bridge is selected by lowest Bridge ID, not highest.
- Lower priority is better.
- Root bridge does not have a root port.
- Every non-root switch has exactly one root port.
- Every segment has one designated port.
- Blocking ports still receive BPDUs.
- STP BPDUs are multicast frames.
- STP operates at Layer 2.
- STP prevents loops but does not provide redundancy by itself.
- PortFast is for end devices, not switch-to-switch links.
- MAC address is only considered after priority comparison.
- Root ports are selected on non-root switches only.

# 7. Practice Questions

## Question 1

How does STP select the root bridge?

A. Highest MAC address  
B. Lowest Bridge ID  
C. Highest priority  
D. Lowest port number  

### Answer: B. Lowest Bridge ID

Explanation:

STP elects the switch with the lowest BID.

---

## Question 2

Which port exists on every non-root switch?

A. Designated port  
B. Root port  
C. Disabled port  
D. Backup port  

### Answer: B. Root port

Explanation:

Each non-root switch selects its best path toward the root.

---

## Question 3

What message do switches exchange for STP calculations?

A. ARP  
B. BPDU  
C. DHCP  
D. ICMP  

### Answer: B. BPDU

Explanation:

BPDUs contain STP topology information.

---

## Question 4

Which STP state learns MAC addresses but does not forward frames?

A. Blocking  
B. Listening  
C. Learning  
D. Forwarding  

### Answer: C. Learning

Explanation:

Learning state builds the MAC table before forwarding begins.

---

## Question 5

Which command displays STP information?

A. show vlan  
B. show spanning-tree  
C. show interfaces  
D. show ip route  

### Answer: B. show spanning-tree

Explanation:

This command shows root bridge, roles, states, and costs.
