# 1. Overview

Spanning Tree Protocol (STP) prevents Layer 2 switching loops by creating a loop-free logical topology while maintaining redundant links. CCNA tests STP operation, root bridge election, port roles/states, RSTP improvements, and MSTP concepts.

---

# 2. Core Concepts

# Why STP is Required

## Problem: Layer 2 Loops

Ethernet frames do not have a TTL field.

Example:

```
        Switch A
       /        \
      /          \
Switch B ------- Switch C
```

A broadcast frame can circulate forever:

```
Broadcast
    |
    v
Loop
    |
    v
Broadcast storm
```

Problems:

| Issue | Result |
|---|---|
| Broadcast storm | Network overload |
| MAC table instability | MAC flapping |
| Duplicate frames | Application problems |

---

# STP Purpose

| Purpose | Description |
|---|---|
| Prevent loops | Blocks redundant paths |
| Maintain redundancy | Keeps backup links |
| Create loop-free topology | Selects best paths |

---

# STP Characteristics

| Feature | Value |
|---|---|
| Protocol | IEEE 802.1D |
| Layer | Layer 2 |
| Used by | Switches |
| Prevents | Switching loops |
| Uses | BPDU messages |

---

# STP Terminology

| Term | Meaning |
|---|---|
| Root Bridge | Central reference switch |
| BPDU | STP control message |
| Root Port | Best path toward root |
| Designated Port | Forwarding port for segment |
| Alternate Port | Backup path |
| Blocked Port | Prevents loops |

---

# Bridge ID (BID)

STP elects the root bridge using Bridge ID.

Format:

```
Bridge ID =
Priority + MAC Address
```

---

# Bridge ID Components

| Component | Description |
|---|---|
| Priority | Lower value wins |
| MAC Address | Tie breaker |

---

# Default STP Priority

Cisco default:

```
32768
```

Range:

```
0 - 61440
```

Increment:

```
4096
```

---

# Root Bridge Election

The switch with the lowest Bridge ID becomes root bridge.

Election order:

1. Lowest priority
2. Lowest MAC address

---

# Example

Switch A:

```
Priority: 32768
MAC: 00:11:22:33:44:55
```

Switch B:

```
Priority: 24576
MAC: AA:BB:CC:DD:EE:FF
```

Winner:

```
Switch B
```

Reason:

Lower priority.

---

# BPDU (Bridge Protocol Data Unit)

## Definition

BPDU messages are exchanged between switches to calculate the STP topology.

---

# BPDU Information

| Field | Purpose |
|---|---|
| Root Bridge ID | Identifies root |
| Sender Bridge ID | Sending switch |
| Root Path Cost | Distance to root |
| Port ID | Identifies port |

---

# STP Port Roles

| Role | Function |
|---|---|
| Root Port | Best path toward root bridge |
| Designated Port | Forwarding port on segment |
| Non-designated Port | Blocking backup port |

---

# Root Port Selection

Each non-root switch selects one root port.

Selection order:

1. Lowest root path cost
2. Lowest sender Bridge ID
3. Lowest sender port ID

---

# Designated Port

Rules:

- One designated port per network segment
- Always forwarding
- Best path toward root for that segment

---

# STP Port States (802.1D)

| State | Function |
|---|---|
| Blocking | Receives BPDUs only |
| Listening | Builds topology |
| Learning | Learns MAC addresses |
| Forwarding | Sends traffic |
| Disabled | Shut down |

---

# STP Convergence Time

Traditional STP:

```
30-50 seconds
```

Reason:

Transition through states:

```
Blocking
   |
Listening
   |
Learning
   |
Forwarding
```

---

# RSTP (Rapid Spanning Tree Protocol)

## Definition

RSTP improves STP convergence speed by reducing port transition delays.

Standard:

```
IEEE 802.1w
```

---

# RSTP Improvements

| Feature | STP | RSTP |
|---|---|---|
| Standard | 802.1D | 802.1w |
| Convergence | Slow | Fast |
| Port states | 5 | 3 |
| Backup roles | Limited | Improved |

---

# RSTP Port Roles

| Role | Function |
|---|---|
| Root | Best path to root |
| Designated | Forwarding port |
| Alternate | Backup root path |
| Backup | Backup designated port |

---

# RSTP Port States

| RSTP State | Equivalent STP State |
|---|---|
| Discarding | Blocking + Listening |
| Learning | Learning |
| Forwarding | Forwarding |

---

# RSTP Edge Port

## Definition

A port connected directly to an end device.

Example:

```
Switch
 |
 |
PC
```

RSTP can immediately move it to forwarding.

Cisco feature:

```
PortFast
```

---

# MSTP (Multiple Spanning Tree Protocol)

## Definition

MSTP allows multiple VLANs to share spanning tree instances to reduce STP overhead.

Standard:

```
IEEE 802.1s
```

---

# Problem with PVST+

Cisco PVST+:

```
VLAN 10 → STP instance
VLAN 20 → STP instance
VLAN 30 → STP instance
```

Large networks:

- More CPU usage
- More BPDU processing

---

# MSTP Solution

Groups VLANs into instances.

Example:

```
Instance 1:
VLAN 10,20,30

Instance 2:
VLAN 40,50
```

---

# STP Variants Comparison

| Feature | STP | RSTP | MSTP |
|---|---|---|---|
| Standard | 802.1D | 802.1w | 802.1s |
| Speed | Slow | Fast | Fast |
| VLAN support | Single tree | Single tree | Multiple instances |
| Port states | 5 | 3 | 3 |
| Enterprise use | Legacy | Common | Large networks |

---

# Cisco STP Modes

| Mode | Description |
|---|---|
| PVST+ | Cisco per-VLAN STP |
| Rapid PVST+ | Cisco RSTP per VLAN |
| MST | IEEE multiple instance |

Better path

# 3. Worked Examples

## Example 1: Root Bridge Election

### Scenario

Two switches:

Switch A:

```
Priority: 32768
MAC: 00:00:00:00:00:01
```

Switch B:

```
Priority: 28672
MAC: FF:FF:FF:FF:FF:FF
```

Which becomes root?

---

### Solution

Step 1:

Compare priority.

```
A = 32768
B = 28672
```

Lower wins.

Step 2:

Winner:

```
Switch B
```

MAC address is not checked because priority already decided.

---

## Example 2: Root Port Selection

### Scenario

A switch has two paths:

Path A:

```
Cost = 4
```

Path B:

```
Cost = 19
```

Which becomes root port?

---

### Solution

Step 1:

Compare path costs.

```
4 < 19
```

Step 2:

Lower cost wins.

Answer:

```
Path A becomes root port
```

# 5. Exam Traps

- STP prevents Layer 2 loops.
- STP does not prevent routing loops.
- Lowest Bridge ID becomes root bridge.
- Lower priority wins.
- Root bridge has no root port.
- Every non-root switch has exactly one root port.
- Designated ports forward traffic.
- Blocking ports prevent loops.
- RSTP uses three states, not five.
- PortFast should only be used on end-device ports.
- BPDU Guard protects PortFast ports.
- MSTP groups VLANs into instances.
- STP uses MAC addresses only after priority comparison.

# 7. Practice Questions

## Question 1

What is the main purpose of STP?

A. Increase bandwidth  
B. Prevent Layer 2 loops  
C. Provide IP routing  
D. Encrypt frames  

### Answer: B. Prevent Layer 2 loops

Explanation:

STP creates a loop-free Layer 2 topology.

---

## Question 2

Which switch becomes the STP root bridge?

A. Highest MAC address  
B. Highest priority  
C. Lowest Bridge ID  
D. Lowest port number  

### Answer: C. Lowest Bridge ID

Explanation:

STP elects the switch with the lowest BID.

---

## Question 3

Which protocol provides faster convergence than traditional STP?

A. VTP  
B. RSTP  
C. DHCP  
D. ARP  

### Answer: B. RSTP

Explanation:

RSTP reduces convergence time compared with 802.1D STP.

---

## Question 4

Which command displays spanning-tree information?

A. show vlan  
B. show spanning-tree  
C. show mac address-table  
D. show ip route  

### Answer: B. show spanning-tree

Explanation:

It displays root bridge, roles, and states.

---

## Question 5

Which STP feature allows immediate forwarding on end-device ports?

A. EtherChannel  
B. PortFast  
C. VTP pruning  
D. DTP  

### Answer: B. PortFast

Explanation:

PortFast skips normal STP transition delays on access ports.
