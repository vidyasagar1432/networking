# 1. Overview

The OSI (Open Systems Interconnection) model is a 7-layer reference framework that explains how data moves between applications and network devices. CCNA tests the OSI model because it provides the foundation for understanding protocols, troubleshooting, encapsulation, and device operation.

---

# 2. Core Concepts

# OSI Model Overview

| Layer Number | Layer Name | Main Function | PDU |
|---|---|---|---|
| 7 | Application | Provides network services to user applications | Data |
| 6 | Presentation | Data formatting, encryption, compression | Data |
| 5 | Session | Establishes and manages sessions | Data |
| 4 | Transport | End-to-end delivery, reliability, flow control | Segment/Datagram |
| 3 | Network | Logical addressing and routing | Packet |
| 2 | Data Link | Framing, MAC addressing, error detection | Frame |
| 1 | Physical | Transmission of bits over media | Bits |

# Layer 7 — Application Layer

## Function

Provides network services directly to end-user applications.

The application layer does not mean the application itself; it provides services applications use to communicate.

---

## Application Layer Functions

| Function | Description |
|---|---|
| User interface services | Allows applications to access network resources |
| Resource sharing | File and printer access |
| Network services | Web, email, DNS services |

# TCP vs UDP

| Feature | TCP | UDP |
|---|---|---|
| Connection | Connection-oriented | Connectionless |
| Reliability | Reliable | Best effort |
| Acknowledgments | Yes | No |
| Ordering | Maintains order | No guarantee |
| Speed | Slower | Faster |
| Example | HTTPS | Video streaming |

# 3. Worked Examples

## Example 1: Identify Layer from Function

### Scenario

A router receives a packet and decides the best path to reach another network.

### Solution

Step 1:

Routing requires logical addressing.

Step 2:

Logical addressing happens at Layer 3.

Answer:

```
Layer 3 — Network Layer
```

---

## Example 2: Identify PDU

### Scenario

A TCP application sends data before reaching the IP layer.

### Solution

Step 1:

TCP operates at Layer 4.

Step 2:

Layer 4 PDU for TCP is:

```
Segment
```

Answer:

```
TCP Segment
```

# 5. Exam Traps

- Layer 4 uses port numbers, not MAC addresses.
- MAC addresses operate at Layer 2.
- IP addresses operate at Layer 3.
- Switches operate mainly at Layer 2.
- Routers operate at Layer 3.
- Data is the PDU for Layers 5, 6, and 7.
- TCP uses segments.
- UDP uses datagrams.
- Network layer PDU is packet.
- Data Link layer PDU is frame.
- Physical layer PDU is bits.
- Encapsulation adds headers as data moves down the OSI model.
- De-encapsulation removes headers as data moves upward.

# 7. Practice Questions

## Question 1

Which OSI layer uses IP addresses?

A. Layer 1  
B. Layer 2  
C. Layer 3  
D. Layer 4  

### Answer: C. Layer 3

Explanation:

IP addressing and routing occur at the Network layer.

---

## Question 2

What is the PDU of the Data Link layer?

A. Packet  
B. Frame  
C. Segment  
D. Bits  

### Answer: B. Frame

Explanation:

Layer 2 creates frames using MAC addresses.

---

## Question 3

Which layer uses port numbers?

A. Physical  
B. Data Link  
C. Network  
D. Transport  

### Answer: D. Transport

Explanation:

TCP and UDP use port numbers to identify applications.

---

## Question 4

A switch operates primarily at which OSI layer?

A. Layer 1  
B. Layer 2  
C. Layer 3  
D. Layer 7  

### Answer: B. Layer 2

Explanation:

Switches forward frames using MAC addresses.

---

## Question 5

Which protocol uses segments as its PDU?

A. IP  
B. Ethernet  
C. TCP  
D. UDP  

### Answer: C. TCP

Explanation:

TCP Layer 4 PDU is called a segment.
