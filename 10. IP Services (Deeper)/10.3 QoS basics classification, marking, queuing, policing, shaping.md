# 1. Overview

Quality of Service (QoS) is a set of techniques used to manage network traffic and provide better performance for important applications. QoS is required because network bandwidth is limited, and different applications have different delay, jitter, and reliability requirements.

---

# 2. Core Concepts

# QoS Definition

QoS:

```
Quality of Service
```

A technology that prioritizes and manages network traffic based on application requirements.

---

# Why QoS Is Needed

Without QoS:

```
All traffic treated equally
```

During congestion:

- Voice suffers
- Video freezes
- Critical applications slow down

---

# QoS Goals

| Goal | Purpose |
|---|---|
| Reduce delay | Faster delivery |
| Reduce jitter | Stable packet timing |
| Reduce packet loss | Maintain quality |
| Prioritize traffic | Protect important applications |
| Control bandwidth | Manage usage |

---

# QoS Important Terms

| Term | Meaning |
|---|---|
| Bandwidth | Data capacity |
| Delay | Time taken to deliver packets |
| Jitter | Variation in delay |
| Packet loss | Dropped packets |
| Congestion | More traffic than capacity |

---

# 1. QoS Traffic Types

Different applications have different requirements.

| Application | Requirement |
|---|---|
| Voice | Low delay, low jitter |
| Video | Low delay, high bandwidth |
| Web browsing | Normal priority |
| Email | Less sensitive |
| File transfer | High reliability |

---

# Voice Traffic Example

Voice packets:

```
Small

+

Frequent

+

Delay sensitive
```

A 200 ms delay may affect call quality.

# 2. QoS Trust Boundary

## Definition

The trust boundary defines where QoS markings are trusted.

---

# Example

```
IP Phone

   |

Switch

   |

Router
```

The switch may trust:

```
Phone markings
```

but not:

```
Unknown computers
```

---

# Why Trust Boundary Matters

Attackers could mark:

```
All traffic as high priority
```

and steal bandwidth.

# 2. Marking

## Definition

Marking adds a value to packets so network devices know how to treat them.

---

# Common Marking Fields

| Field | Location |
|---|---|
| DSCP | IP header |
| IP Precedence | IP header |
| CoS | Ethernet frame |

---

# DSCP

DSCP:

```
Differentiated Services Code Point
```

Located in:

```
IP header
```

Uses:

```
6 bits
```

Values:

```
0-63
```

---

# Common DSCP Values

| Traffic | DSCP | Decimal |
|---|---|---|
| Best Effort | BE | 0 |
| Voice | EF | 46 |
| Critical data | AF | Various |

---

# Voice Marking

Voice packets commonly marked:

```
DSCP EF

Value:
46
```

---

# CoS

CoS:

```
Class of Service
```

Located in:

```
802.1Q VLAN tag
```

Uses:

```
3 bits
```

Values:

```
0-7
```

---

# DSCP vs CoS

| Feature | DSCP | CoS |
|---|---|---|
| Layer | Layer 3 | Layer 2 |
| Location | IP header | Ethernet frame |
| Bits | 6 | 3 |
| Range | 0-63 | 0-7 |

---

# 3. Queuing

## Definition

Queuing manages packets when congestion occurs.

---

# Problem

Interface speed:

```
100 Mbps
```

Traffic:

```
150 Mbps
```

Result:

```
Congestion
```

---

# Without Queuing

Packets are dropped randomly.

---

# With Queuing

Important traffic goes first.

---

# Queuing Types

| Type | Description |
|---|---|
| FIFO | First packet first out |
| Priority Queuing | High priority first |
| CBWFQ | Class-based queues |
| LLQ | Low latency priority queue |

---

# FIFO

FIFO:

```
First In First Out
```

No prioritization.

---

Example:

```
Packet 1

Packet 2

Packet 3
```

Sent:

```
1 → 2 → 3
```

---

# Priority Queuing

High-priority traffic:

```
Voice
```

gets sent first.

---

# LLQ (Low Latency Queuing)

Used for:

```
Real-time traffic
```

Example:

- Voice
- Video

---

# 4. Scheduling

## Definition

Scheduling decides which queue gets service.

---

# Scheduling Algorithms

| Algorithm | Purpose |
|---|---|
| FIFO | Simple delivery |
| WFQ | Fair sharing |
| CBWFQ | Class-based bandwidth |
| LLQ | Priority traffic |

# 5. Policing

## Definition

Policing limits traffic by enforcing a maximum rate.

---

# Policing Action

When traffic exceeds limit:

```
Drop

or

Remark
```

---

# Example

Policy:

```
Maximum:
10 Mbps
```

Traffic:

```
15 Mbps
```

Excess:

```
Dropped
```

---

# Policing Characteristics

| Feature | Description |
|---|---|
| Location | Usually ingress |
| Excess traffic | Dropped/marked |
| Buffering | No |
| Goal | Enforce limit |

---

# Policing Example

Customer bandwidth:

```
100 Mbps
```

ISP policy:

```
50 Mbps
```

Extra:

```
Dropped
```

---

# 6. Shaping

## Definition

Shaping controls traffic rate by buffering excess packets.

---

# Shaping Action

Traffic exceeds limit:

```
Buffer packets

↓

Send later
```

---

# Shaping Characteristics

| Feature | Description |
|---|---|
| Location | Usually egress |
| Excess traffic | Buffered |
| Packet loss | Reduced |
| Goal | Smooth traffic |

---

# Policing vs Shaping

| Feature | Policing | Shaping |
|---|---|---|
| Action | Drop/remark | Buffer |
| Direction | Usually inbound | Usually outbound |
| Delay | No added delay | Adds delay |
| Packet loss | Possible | Less |
| Uses buffer | No | Yes |

---

# Example Comparison

Traffic:

```
20 Mbps
```

Allowed:

```
10 Mbps
```

---

## Policing

Result:

```
10 Mbps sent

10 Mbps dropped
```

---

## Shaping

Result:

```
10 Mbps sent now

Remaining buffered
```

# 9. QoS Configuration Concepts

## Class Map

Defines:

```
Traffic to match
```

Example:

```bash
class-map VOICE
 match dscp ef
```

---

## Policy Map

Defines:

```
Action
```

Example:

```bash
policy-map QOS_POLICY
 class VOICE
 priority 1000
```

---

## Service Policy

Applies policy:

```bash
interface g0/0
 service-policy output QOS_POLICY
```

|---|---|

# CCNA Exam Traps

- Classification identifies traffic.
- Marking labels traffic.
- Queuing handles congestion.
- Policing drops or remarks excess traffic.
- Shaping buffers excess traffic.
- DSCP is Layer 3 marking.
- CoS is Layer 2 marking.
- Voice commonly uses DSCP EF (46).
- QoS does not increase bandwidth.
- QoS manages available bandwidth.
- LLQ is designed for delay-sensitive traffic.
- Shaping delays traffic; policing drops traffic.
