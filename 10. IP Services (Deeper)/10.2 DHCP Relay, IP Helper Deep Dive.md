# 1. Overview

DHCP Relay allows clients on one network segment to obtain IP configuration from a DHCP server located on another network segment. Since DHCP uses broadcast messages that routers normally block, a router or Layer 3 switch forwards DHCP requests as unicast messages using the `ip helper-address` feature.

---

# 2. DHCP Review

# DHCP Definition

DHCP:

```
Dynamic Host Configuration Protocol
```

A protocol that automatically provides:

- IP address
- Subnet mask
- Default gateway
- DNS server
- Other network parameters

---

# DHCP Ports

| Device | Protocol | Port |
|---|---|---|
| Client → Server | UDP | 68 → 67 |
| Server → Client | UDP | 67 → 68 |

---

# DHCP DORA Process

DORA:

```
Discover

Offer

Request

Acknowledgment
```

---

# Normal DHCP Process (Same VLAN)

Example:

```
Client

192.168.1.0/24

      |

Broadcast

      |

DHCP Server

192.168.1.5
```

---

## Step 1: DHCP Discover

Client has no IP address.

Source:

```
0.0.0.0
```

Destination:

```
255.255.255.255
```

Broadcast:

```
DHCPDISCOVER
```

---

## Step 2: DHCP Offer

Server replies:

```
DHCPOFFER
```

Example:

```
192.168.1.100
```

---

## Step 3: DHCP Request

Client accepts offer:

```
DHCPREQUEST
```

---

## Step 4: DHCP ACK

Server confirms:

```
DHCPACK
```

Client receives:

- IP address
- Gateway
- DNS

# 3. Why DHCP Relay Is Needed

## Problem

Broadcasts do not cross routers.

Example:

```
VLAN 10

Client

192.168.10.20

    |

    |

Router

    |

    |

VLAN 100

DHCP Server
192.168.100.10
```

Client sends:

```
DHCPDISCOVER Broadcast
```

Router:

```
Drops broadcast
```

Result:

```
No IP address
```

---

# Solution

Use:

```
DHCP Relay Agent
```

---

# 4. DHCP Relay Agent

## Definition

A DHCP relay agent forwards DHCP messages between clients and DHCP servers across Layer 3 boundaries.

---

# DHCP Relay Operation

```
Client

DHCPDISCOVER
(Broadcast)

      |

      |

Layer 3 Switch

(ip helper-address)

      |

      |

DHCP Server

192.168.100.10

```

---

# Relay Process

## Step 1

Client broadcasts:

```
DHCPDISCOVER
```

---

## Step 2

Router receives broadcast.

Instead of dropping:

```
Convert broadcast to unicast
```

---

## Step 3

Router sends:

```
Unicast DHCP request
```

to:

```
DHCP Server IP
```

---

## Step 4

Server replies.

Router forwards response to client.

---

# 5. IP Helper Address

## Definition

`ip helper-address` tells a Cisco router where to forward UDP broadcasts.

---

# Configuration Example

Topology:

```
Client VLAN 10

192.168.10.0/24


Router


DHCP Server

192.168.100.10
```

---

Configure interface:

```bash
interface g0/1
 ip address 192.168.10.1 255.255.255.0
 ip helper-address 192.168.100.10
```

---

# Verify Configuration

```bash
show running-config interface g0/1
```

Output:

```
ip helper-address 192.168.100.10
```

---

# 6. DHCP Relay on Layer 3 Switch

Example:

```
             DHCP Server
             10.1.1.10

                 |

             L3 Switch

        -----------------

        VLAN 10 SVI

        VLAN 20 SVI

        VLAN 30 SVI
```

---

Configure SVI:

```bash
interface vlan 10

```

---

Repeat for each VLAN:

```bash
interface vlan 20
 ip helper-address 10.1.1.10
```

 |

# 8. What Does IP Helper Forward?

By default, Cisco routers forward these UDP broadcasts:

| Service | Port |
|---|---|
| DHCP/BOOTP Server | UDP 67 |
| DHCP/BOOTP Client | UDP 68 |
| TFTP | UDP 69 |
| DNS | UDP 53 |
| TACACS | UDP 49 |
| Time service | UDP 37 |

---

# Important:

`ip helper-address` is not only DHCP.

It forwards multiple UDP broadcasts.

---

# 9. Disable Unwanted Helper Forwarding

Example:

Disable TFTP forwarding:

```bash
no ip forward-protocol udp 69
```

---

Disable DNS forwarding:

```bash
no ip forward-protocol udp 53
```

# 10. DHCP Relay and GIADDR

## Gateway IP Address (GIADDR)

When a relay agent forwards DHCP messages, it inserts:

```
giaddr field
```

---

Purpose:

The DHCP server knows:

```
Which subnet requested the address
```

---

Example:

Client:

```
VLAN 10

192.168.10.0/24
```

Relay adds:

```
GIADDR:
192.168.10.1
```

DHCP server selects:

```
VLAN 10 DHCP pool
```

# 12. DHCP Relay Troubleshooting

## Problem 1: Client Gets APIPA Address

Example:

```
169.254.x.x
```

Meaning:

```
DHCP failed
```

---

Check:

## Step 1

Verify helper address:

```bash
show running-config
```

---

## Step 2

Check interface:

```bash
show ip interface brief
```

---

## Step 3

Check DHCP server reachability:

```bash
ping DHCP_SERVER_IP
```

---

# Problem 2: Wrong DHCP Address Pool

Client receives:

```
192.168.20.x
```

but should receive:

```
192.168.10.x
```

---

Cause:

Wrong GIADDR/subnet mapping.

---

Check:

- VLAN interface IP
- DHCP scopes

---

# Problem 3: One VLAN Works, Another Fails

Example:

```
VLAN 10 ✓

VLAN 20 ✗
```

---

Cause:

Missing helper address.

---

Solution:

```bash
interface vlan 20
 ip helper-address 10.1.1.10
```

---

# Problem 4: DHCP Server Cannot Reply

Check routing:

```
Client VLAN

↓

Relay Router

↓

DHCP Server
```

Both directions need routing.

---

# Problem 5: Helper Address Configured on Wrong Interface

Incorrect:

```
DHCP Server Interface
```

Correct:

```
Client-facing Interface
```

# 13. DHCP Relay vs DHCP Server

| Feature | DHCP Server | DHCP Relay |
|---|---|---|
| Assigns IP addresses | Yes | No |
| Stores DHCP pools | Yes | No |
| Forwards requests | No | Yes |
| Requires DHCP database | Yes | No |
| Runs on router | Sometimes | Yes |

---

# 14. DHCP Relay vs DHCP Snooping

| Feature | DHCP Relay | DHCP Snooping |
|---|---|---|
| Purpose | Forward DHCP messages | Security protection |
| Function | Routing | Filtering |
| Location | Router/L3 switch | Switch |
| Blocks attacks | No | Yes |

# 17. Exam Traps

- DHCP Discover is a broadcast.
- Routers do not forward broadcasts by default.
- DHCP relay uses `ip helper-address`.
- Helper address is configured on the client-facing interface.
- DHCP relay does not assign IP addresses.
- DHCP server uses GIADDR to choose the correct scope.
- IP helper forwards more than DHCP traffic.
- DHCP uses UDP ports 67 and 68.
- APIPA address (169.254.x.x) usually indicates DHCP failure.
- Each VLAN requires its own relay configuration.
