# 1. Overview

Network Address Translation (NAT) allows private IP addresses to communicate with public networks by translating addresses between private and public spaces. Port Address Translation (PAT), also called NAT overload, allows many private devices to share a single public IP address.

---

# 2. Core Concepts

# NAT Definition

NAT:

```
Network Address Translation
```

A process that modifies IP address information in packet headers.

---

# Why NAT Is Used

Before NAT:

```
Every device needs a public IP address
```

Problem:

- IPv4 address shortage
- Security concerns

---

After NAT:

```
Many private IPs

        |

       NAT

        |

One/few public IPs
```

---

# Private IPv4 Address Ranges

Defined in RFC 1918:

| Class | Private Range |
|---|---|
| A | 10.0.0.0/8 |
| B | 172.16.0.0/12 |
| C | 192.168.0.0/16 |

---

# NAT Terminology

| Term | Meaning |
|---|---|
| Inside Local | Private address of internal host |
| Inside Global | Public address representing internal host |
| Outside Local | Address of external host as seen internally |
| Outside Global | Real public address of external host |

---

# NAT Architecture

```
Inside Network

Private IPs

     |

Inside Interface

     |

   NAT Router

     |

Outside Interface

     |

Internet
```

---

# NAT Types Overview

| Type | Description |
|---|---|
| Static NAT | One-to-one permanent mapping |
| Dynamic NAT | Pool-based temporary mapping |
| PAT/NAT Overload | Many-to-one using ports |

---

# 1. Static NAT

## Definition

Static NAT creates a permanent one-to-one mapping between private and public IP addresses.

---

# Static NAT Mapping

Example:

```
Private Server

192.168.1.10

       |

      NAT

       |

Public IP

203.0.113.10
```

---

# Static NAT Characteristics

| Feature | Value |
|---|---|
| Mapping | 1:1 |
| Address usage | Permanent |
| Public IP required | Yes |
| Common use | Servers |

---

# Static NAT Example

Web server:

```
Inside:
192.168.1.100

Public:
203.0.113.100
```

Configuration:

```bash
ip nat inside source static 192.168.1.100 203.0.113.100
```

---

# Static NAT Use Cases

Used for:

- Web servers
- Mail servers
- FTP servers
- Public services

---

# Advantages

- Simple
- Predictable
- Allows inbound connections

---

# Disadvantages

- Requires many public IP addresses
- Poor IPv4 conservation

---

# 2. Dynamic NAT

## Definition

Dynamic NAT maps private addresses to public addresses from a pool.

---

# Dynamic NAT Operation

Example:

Private pool:

```
192.168.1.0/24
```

Public pool:

```
203.0.113.10-20
```

Mapping:

```
192.168.1.10

      ↓

203.0.113.10
```

---

# Dynamic NAT Characteristics

| Feature | Value |
|---|---|
| Mapping | Many possible 1:1 mappings |
| Allocation | Temporary |
| Uses pool | Yes |
| Public IP required | Multiple |

---

# Dynamic NAT Process

1. Internal host sends traffic.
2. NAT checks available public addresses.
3. NAT assigns an address.
4. Translation is created.
5. Address released after timeout.

---

# Dynamic NAT Configuration

Create pool:

```bash
ip nat pool PUBLIC_POOL 203.0.113.10 203.0.113.20 netmask 255.255.255.0
```

Create ACL:

```bash
access-list 1 permit 192.168.1.0 0.0.0.255
```

Bind:

```bash
ip nat inside source list 1 pool PUBLIC_POOL
```

---

# 3. PAT (NAT Overload)

## Definition

PAT allows multiple private devices to share one public IP address by using different port numbers.

---

# PAT Operation

Example:

```
PC1
192.168.1.10:5000

        |

       NAT

        |

203.0.113.5:10001


PC2
192.168.1.20:5000

        |

       NAT

        |

203.0.113.5:10002
```

---

# PAT Uses

Translation based on:

```
IP Address + Port Number
```

---

# PAT Characteristics

| Feature | Value |
|---|---|
| Mapping | Many-to-one |
| Uses ports | Yes |
| Public IP required | One |
| Common use | Home networks |

---

# PAT Example

Home network:

```
Laptop
192.168.1.10

Phone
192.168.1.20

TV
192.168.1.30
```

All share:

```
Public IP:
203.0.113.5
```

---

# PAT Configuration

Using interface IP:

```bash
ip nat inside source list 1 interface g0/0 overload
```

---

# NAT/PAT Comparison

| Feature | Static NAT | Dynamic NAT | PAT |
|---|---|---|---|
| Mapping | 1:1 | 1:1 temporary | Many:1 |
| Uses ports | No | No | Yes |
| Public IPs required | Many | Multiple | One |
| Direction | Both | Mostly outbound | Mostly outbound |
| Common use | Servers | Enterprise users | Internet access |

---

# Static NAT vs PAT

Example:

## Static NAT

```
Server

192.168.1.10

↓

203.0.113.10
```

One device, one public IP.

---

## PAT

```
Many devices

192.168.1.x

↓

203.0.113.10
```

Many devices, one public IP.

---

# NAT and Port Numbers

PAT uses TCP/UDP ports:

Example:

Before:

```
192.168.1.10:5000
```

After:

```
203.0.113.5:30001
```

# NAT Troubleshooting

| Problem | Possible Cause |
|---|---|
| No Internet access | Missing NAT rule |
| Translation missing | Wrong ACL |
| Wrong interface | Inside/outside error |
| Server unreachable | Static NAT missing |
| Limited connections | PAT port exhaustion |

---

# NAT with ACL

ACL identifies traffic to translate.

Example:

```bash
access-list 1 permit 192.168.1.0 0.0.0.255
```

Meaning:

```
Translate this network
```

---

# NAT Security Consideration

NAT can hide:

```
Internal IP addresses
```

But:

```
NAT is not a firewall
```

# 3. Worked Examples

## Example 1: Identify NAT Type

Scenario:

```
A company maps:

192.168.1.10

to

203.0.113.10
```

Permanent mapping.

Answer:

```
Static NAT
```

Reason:

One private address permanently maps to one public address.

---

# Example 2: Identify PAT

Scenario:

```
50 home devices use one ISP public IP.
```

Requirement:

Need port translation.

Answer:

```
PAT (NAT overload)
```

Reason:

Multiple devices share one public IP using ports.

# 4. Exam Traps

- NAT translates IP addresses.
- PAT translates IP addresses and port numbers.
- PAT is also called NAT overload.
- Static NAT is one-to-one.
- Dynamic NAT uses a public IP pool.
- PAT is the most common home NAT type.
- NAT does not replace a firewall.
- Private IP addresses are not routable on the Internet.
- Inside local = private address.
- Inside global = public translated address.
- `overload` keyword indicates PAT.
- NAT requires inside and outside interfaces.
