# VSS, StackWise, and Chassis Virtualization

## CCNP Enterprise (ENCOR 350-401) Level

**CCNA Relevance: Basic awareness of switch stacking is beneficial.**  
**CCNP ENCOR Relevance: Very High — StackWise, Virtual Switching System (VSS), StackWise Virtual, and chassis virtualization are key campus enterprise design technologies.**

---

# 1. Overview

Enterprise networks require **high availability**, **redundancy**, **simplified management**, and **scalability**. Managing multiple independent switches can introduce complexity and create Layer 2 loops.

Cisco provides several technologies to simplify network design:

- **StackWise**
- **Virtual Switching System (VSS)**
- **StackWise Virtual**
- **Chassis Virtualization**

These technologies allow multiple physical switches to operate as a **single logical switch**, improving resiliency and simplifying administration.

---

# 2. Why Chassis Virtualization?

Without virtualization:

```
         Core

      +--------+

      |Switch1 |

      +--------+

         ||

         ||

      +--------+

      |Switch2 |

      +--------+

```

Problems:

- Separate management
- STP blocking links
- Multiple control planes
- More complex redundancy

---

With virtualization:

```
     +----------------------+

     |   Logical Switch     |

     |   (Two Chassis)      |

     +----------------------+

```

Benefits:

- Single control plane
- Single management IP
- Active-active forwarding
- Better bandwidth utilization

# 4. Switch Stacking

## Definition

Switch stacking connects multiple physical switches using dedicated stack cables so they operate as one logical switch.

Example:

```
+--------+

|Switch1 |

+--------+

     ||

=====Stack Cable=====

     ||

+--------+

|Switch2 |

+--------+

     ||

=====Stack Cable=====

     ||

+--------+

|Switch3 |

+--------+
```

---

Characteristics:

- One configuration
- One management IP
- One control plane
- Multiple forwarding planes

---

# 5. Cisco StackWise

## Definition

StackWise is Cisco's switch stacking technology used primarily on Catalyst access switches.

Examples:

- Catalyst 9200
- Catalyst 9300
- Catalyst 3750
- Catalyst 3850

---

Stack members communicate using a high-speed stack ring.

---

# 6. StackWise Architecture

```
      Stack Ring

+------+   +------+   +------+

| SW1 |---| SW2 |---| SW3 |

+------+   +------+   +------+

      |__________________|

```

The ring provides:

- Redundancy
- High bandwidth
- Fast convergence

---

# 7. Stack Roles

Each stack has:

| Role | Function |
|------|----------|
| Active Switch | Controls entire stack |
| Standby Switch | Backup control plane |
| Member Switch | Forwards traffic |

---

Example:

```
SW1 → Active

SW2 → Standby

SW3 → Member

SW4 → Member
```

---

# 8. Active Switch Responsibilities

The active switch manages:

- Configuration
- Routing
- STP
- VLAN database
- Stack management
- Software upgrades

---

# 9. Standby Switch

Maintains a synchronized copy of:

- Configuration
- Routing table
- Control-plane state

If Active fails:

```
Standby

↓

Becomes Active
```

Failover is typically very fast.

---

# 10. Stack Master Election

Election priority:

1. Highest priority
2. Existing active switch
3. Highest hardware/software capability
4. Lowest MAC address (last tiebreaker)

---

Configuration:

```bash
switch 1 priority 15
```

Priority range:

```
1–15

15 = Highest
```

# 11. StackWise Advantages

| Advantage | Description |
|-----------|-------------|
| Single configuration | One CLI |
| Single IP | Easier management |
| Redundancy | Active/standby |
| Increased ports | Combined switch ports |
| Simplified upgrades | Stack-wide software updates |

# 12. StackWise Limitations

- Limited stack size (platform dependent)
- Requires compatible hardware/software
- Dedicated stack cables
- Usually limited to switches in the same rack or nearby

# 13. Virtual Switching System (VSS)

## Definition

VSS combines **two Catalyst chassis switches** into one logical switch.

Originally supported on:

- Catalyst 4500
- Catalyst 6500

---

Before VSS:

```
        Core

     +--------+

     |SW1     |

     +--------+

      ||    ||

     STP Blocking

      ||    ||

     +--------+

     |SW2     |

     +--------+
```

---

After VSS:

```
     +------------------+

     |   Logical Switch |

     +------------------+

      Chassis1 + Chassis2
```

---

# 14. VSS Components

Two chassis:

```
Active Supervisor

↓

Standby Supervisor

↓

Virtual Switch
```

Connected using:

```
VSL

(Virtual Switch Link)
```

---

# 15. Virtual Switch Link (VSL)

The VSL carries:

- Control traffic
- Configuration synchronization
- Data forwarding
- State information

---

Example:

```
+------------+

| Chassis A  |

+------------+

      ||

======VSL======

      ||

+------------+

| Chassis B  |

+------------+
```

---

# 16. VSS Benefits

| Benefit | Description |
|----------|-------------|
| Eliminates STP blocking | Active-active links |
| MEC support | Multi-Chassis EtherChannel |
| Single management | One device |
| Better bandwidth | Uses all uplinks |
| Fast failover | Supervisor redundancy |

---

# 17. Multi-Chassis EtherChannel (MEC)

Normally:

```
Switch A

↓

EtherChannel

↓

Switch B
```

With VSS:

```
Server

 ||

EtherChannel

 ||

Chassis A + Chassis B

(Logical Switch)
```

Benefits:

- No STP blocking
- Active-active forwarding
- Higher throughput
- Link redundancy

---

# 18. StackWise Virtual

## Definition

StackWise Virtual extends the VSS concept to modern Catalyst 9000 switches.

Supported on:

- Catalyst 9500
- Catalyst 9600
- Selected Catalyst 9300 models

---

Architecture:

```
+------------+

| Switch A   |

+------------+

      ||

Virtual Link

      ||

+------------+

| Switch B   |

+------------+
```

Appears as:

```
One Logical Switch
```

---

# 19. StackWise vs StackWise Virtual

| Feature | StackWise | StackWise Virtual |
|----------|-----------|------------------|
| Stack Cable | Yes | No |
| Distance | Short | Longer (fiber capable) |
| Devices | Multiple | Two |
| Physical Stack | Yes | No |
| Logical Switch | Yes | Yes |

---

# 20. Chassis Virtualization

## Definition

Chassis virtualization allows multiple physical switches or chassis to operate as a single logical device.

Technologies include:

- StackWise
- VSS
- StackWise Virtual
- vPC (Nexus)

---

Benefits:

- Single control plane
- High availability
- Simplified management
- Active-active forwarding

---

# 21. High Availability

Failure scenario:

```
Active Switch

↓

Fails

↓

Standby Switch

↓

Becomes Active
```

Traffic disruption is minimized.

---

# 22. Comparison

| Feature | Independent Switches | StackWise | VSS |
|----------|----------------------|-----------|-----|
| Management IP | Multiple | One | One |
| Control Plane | Multiple | One | One |
| STP | Required | Simplified | Reduced/optimized |
| EtherChannel Across Devices | No | Yes | Yes (MEC) |
| Hardware | Fixed | Fixed | Modular |

# 24. Troubleshooting

## Stack Member Not Joining

Check:

- Software version
- License compatibility
- Stack cable
- Switch priority
- Hardware model compatibility

---

## Split-Brain Condition

Occurs when:

```
Virtual link fails

↓

Both switches think they are Active
```

Prevention:

- Dual-active detection
- Redundant virtual links
- Proper design

---

## Active Switch Failure

Verify:

```bash
show redundancy
```

Ensure standby is synchronized.

---

# 25. Design Best Practices

- Use redundant stack or virtual links.
- Configure switch priorities to control master election.
- Keep all members on the same software version.
- Use Multi-Chassis EtherChannel where supported.
- Deploy StackWise in the access layer.
- Deploy VSS or StackWise Virtual in the distribution/core layer.
- Monitor stack health and redundancy regularly.

# CCNP Exam Traps

- StackWise uses dedicated stack cables.
- VSS virtualizes **two chassis** into one logical switch.
- VSL stands for **Virtual Switch Link**.
- StackWise Virtual is the successor to VSS on many Catalyst 9000 platforms.
- Active and standby switches maintain synchronized control-plane information.
- Multi-Chassis EtherChannel (MEC) allows EtherChannel across two physical chassis.
- Chassis virtualization reduces STP blocking by enabling active-active forwarding.
- Stack master election considers priority before MAC address.
