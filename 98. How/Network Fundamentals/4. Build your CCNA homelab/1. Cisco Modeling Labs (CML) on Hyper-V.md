[Cisco Modeling Labs (CML) on Hyper-V](https://www.networkacademy.io/ccna/network-fundamentals/cml-on-hyperv)
==========

In this lesson, we'll show you how to set up a CCNA/CCNP homelab for practicing networking using the free version of Cisco Modeling Labs running on Hyper-V. 

Why run CML on Hyper-V and not VMware?
--------------------------------------

- Hyper-V comes built into Windows, so you don't need to purchase or install third-party software.
- Hyper-V on Windows is considered a Type 1 (bare-metal) hypervisor, which runs directly on the hardware. This gives better performance and more stability.
- Many people report problems running CML on VMware because of Intel VT-x/EPT issues on newer Windows versions.

What is Cisco Modeling Labs (CML)?
-----------------------------------

CML is a software tool that lets you build real networks **in a virtual environment using virtual devices**. It is a must-have tool for students and network engineers who prepare for certifications like the CCNA and CCNP.

![Cisco CML](../../images/cdn.networkacademy.io/sites/default/files/2025-08/cisco-cml.jpg)

Figure 1. Cisco CML.

### CML vs the other alternatives

| Feature | CML | Packet Tracer | EVE-NG | GNS3 |
|---|---|---|---|---|
| Cisco official images | Yes | Yes | No (user provided) | No (user provided) |
| Free version | Yes (5 nodes) | Yes | Yes (limited) | Yes |
| Container support | Yes | No | Yes | Yes |
| GUI quality | Excellent | Good | Good | Good |

Table 1. Comparison between CML, Packet Tracer, EVE-NG and GNS3.

For CCNA, CML is currently the best tool for practicing Cisco networking. It is developed by Cisco itself and includes official Cisco images, which other emulators do not provide.

Set up CML on Hyper-V
---------------------

### Enable Hyper-V on Windows

Go to the Start menu and type "Windows Features". The Turn Windows Features on or off window will appear.

![Enable Hyper-V on Windows 11 Pro](../../images/cdn.networkacademy.io/sites/default/files/2025-09/enable-hyperv.jpg)

Figure 2. Enable Hyper-V on Windows 11 Pro.

Enable **Hyper-V**, **Virtual Machine Platform**, and **Windows Hypervisor Platform**. Restart your computer.

### Downloading CML files

Go to the Cisco Software download page and download the **bare metal** deployment file and the **refplat ISO** file.

![Downloading CML files](../../images/cdn.networkacademy.io/sites/default/files/2025-09/downloading-cml-free.jpg)

Figure 3. Downloading CML files.

You need a free Cisco account. The files are ZIP archives — extract the ISO files.

### Create a new Hyper-V virtual machine

In Hyper-V Manager, click **New > Virtual Machine**.

1. Specify a name and location for the VM.
2. Select **Generation 2**.
3. Assign as much memory as you can. Disable Dynamic Memory.
4. Configure Networking — select **Default Switch**.
5. Connect Virtual Hard Disk — give at least 100 GB.

![Specify Name and Location](../../images/cdn.networkacademy.io/sites/default/files/2025-09/sepcify-vm-name.png)

Figure 4. Specify Name and Location.

![Specify Generation](../../images/cdn.networkacademy.io/sites/default/files/2025-09/sepcify-generation2.png)

Figure 5. Specify Generation.

![Configure Networking](../../images/cdn.networkacademy.io/sites/default/files/2025-09/configure-network.png)

Figure 6. Configure Networking.

![Configure Virtual Hard Disk](../../images/cdn.networkacademy.io/sites/default/files/2025-09/configure-virtual-disk.png)

Figure 7. Configure Virtual Hard Disk.

### VM Settings

Right-click on the VM and go to Settings:

1. Change **Secure Boot** to use **Microsoft UEFI Certificate Authority** or disable it.

![Configure Secure Boot](../../images/cdn.networkacademy.io/sites/default/files/2025-09/configure-secure-boot.png)

Figure 8. Configure Secure Boot.

2. Add two additional DVD drives under the **SCSI Controller** tab.

![Add the first DVD Drive](../../images/cdn.networkacademy.io/sites/default/files/2025-09/add-dvd-drives.png)

Figure 9. Add the first DVD Drive.

3. Mount the CML ISO file on the first DVD drive.

![Add the bootable CML ISO file](../../images/cdn.networkacademy.io/sites/default/files/2025-09/add-boot-iso-file.png)

Figure 10. Add the bootable CML ISO file.

4. Add another DVD drive and mount the **RefPlat** image.

![Add a second DVD drive](../../images/cdn.networkacademy.io/sites/default/files/2025-09/add-second-dvd-drive.png)

Figure 11. Add a second DVD drive.

5. Set the boot order so the CML ISO is topmost.

![Set boot order](../../images/cdn.networkacademy.io/sites/default/files/2025-09/set-boot-order.png)

Figure 12. Set boot order.

#### Enable Nested Virtualization and MAC spoofing

Open PowerShell as an administrator and run:

```
Set-VMProcessor -VMName CML-FREE -ExposeVirtualizationExtensions $true
Get-VMNetworkAdapter -VMName CML-FREE | Set-VMNetworkAdapter -MacAddressSpoofing On
```

### Power up the CML VM

Start the virtual machine. It will begin the initial installation process.

![Start the CML VM](../../images/cdn.networkacademy.io/sites/default/files/2025-09/start-virtual-machine.png)

Figure 13. Start the CML VM.

After the initial installation, the VM may get stuck at the initial screen. Turn off the VM manually and power it on again.

![CML stuck at boot screen](../../images/cdn.networkacademy.io/sites/default/files/2025-09/vm-stuck-at-initial-screen.png)

Figure 14. CML stuck at boot screen.

After reboot, enter **"Advanced options for CML2 -- GNU/Linux"**.

![Advanced options for CML](../../images/cdn.networkacademy.io/sites/default/files/2025-09/advanced-cml-options.png)

Figure 15. Advanced options for CML.

Select one of the recovery mode options.

![Boot in Recovery Mode](../../images/cdn.networkacademy.io/sites/default/files/2025-09/boot-in-recovery-mode.png)

Figure 16. Boot in Recovery Mode.

The VM should now boot correctly and enter the CML initial configuration wizard.

![Enter CML initial configuration wizard](../../images/cdn.networkacademy.io/sites/default/files/2025-09/enter-initial-configuration-wizard.png)

Figure 17. Enter CML initial configuration wizard.

After completing the wizard, the VM will show the IP address acquired via DHCP. Use this IP to access CML via your browser.

![CML installed successfully](../../images/cdn.networkacademy.io/sites/default/files/2025-09/cml-installed-successfully.png)

Figure 18. CML installed successfully.

Log in with the username and password you specified during the wizard.

![Login to CML via browser](../../images/cdn.networkacademy.io/sites/default/files/2025-09/login-to-cml-via-browser.png)

Figure 19. Login to CML via browser.

Key Takeaways
-------------

![CML on Hyper-V Overview](../../images/cdn.networkacademy.io/sites/default/files/2025-09/cml-on-hyperv-overview.svg)

Figure 20. CML on Hyper-V Overview.

- Cisco Modeling Labs lets you build real virtual Cisco networks for CCNA and CCNP practice.
- Running it on Hyper-V avoids VMware VT-x/EPT issues on newer Windows versions.
