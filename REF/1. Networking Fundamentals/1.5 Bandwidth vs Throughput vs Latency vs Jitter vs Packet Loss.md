# 1. Overview

Network performance is measured using bandwidth, throughput, latency, jitter, and packet loss. CCNA tests these concepts because they directly affect application performance, QoS decisions, troubleshooting, and user experience.

---

# 2. Core Concepts

# Bandwidth

## Definition

Bandwidth is the maximum capacity of a network link to transmit data over a specific period.

It represents the theoretical maximum data rate of a connection.

---

## Bandwidth Characteristics

| Feature | Description |
|---|---|
| Meaning | Maximum possible data transfer capacity |
| Measurement | bits per second (bps) |
| Units | Kbps, Mbps, Gbps |
| Affected by | Cable type, interface speed, technology |
| Example | 1 Gbps Ethernet link |

---

## Bandwidth Examples

| Technology | Typical Bandwidth |
|---|---|
| Fast Ethernet | 100 Mbps |
| Gigabit Ethernet | 1 Gbps |
| 10 Gigabit Ethernet | 10 Gbps |
| Wi-Fi 6 | Multiple Gbps theoretical |

---

# Throughput

## Definition

Throughput is the actual amount of data successfully transmitted across a network.

Throughput is usually lower than bandwidth.

Formula:

```
Throughput ≤ Bandwidth
```

---

## Throughput Characteristics

| Feature | Description |
|---|---|
| Meaning | Actual data transfer rate |
| Measurement | bits per second |
| Depends on | Congestion, protocols, errors, traffic |
| Example | 700 Mbps achieved on a 1 Gbps link |

---

## Bandwidth vs Throughput

| Feature | Bandwidth | Throughput |
|---|---|---|
| Meaning | Maximum capacity | Actual performance |
| Value | Theoretical | Real-world |
| Affected by congestion | No | Yes |
| Example | 1 Gbps link | 850 Mbps actual speed |

---

# Latency

## Definition

Latency is the time required for data to travel from source to destination.

Also called delay.

Measurement:

```
Milliseconds (ms)
```

---

## Types of Latency

| Type | Description |
|---|---|
| Propagation Delay | Time for signal to travel through medium |
| Transmission Delay | Time to place bits onto the link |
| Processing Delay | Time devices take to process packets |
| Queuing Delay | Time packets wait in buffers |

---

## Latency Example

```
PC -------- Router -------- Server

Packet leaves PC:
10:00:00.000

Packet reaches Server:
10:00:00.050

Latency:
50 ms
```

---

## Latency Impact

| Application | Latency Requirement |
|---|---|
| Voice calls | Very low |
| Video conferencing | Low |
| Online gaming | Low |
| Email | Less sensitive |
| File transfer | Less sensitive |

---

# Jitter

## Definition

Jitter is the variation in packet arrival times.

It occurs when packets do not arrive at consistent intervals.

---

## Example

Normal packet arrival:

```
Packet 1 → 10 ms
Packet 2 → 10 ms
Packet 3 → 10 ms
```

Low jitter.

---

High jitter:

```
Packet 1 → 10 ms
Packet 2 → 50 ms
Packet 3 → 15 ms
```

---

## Jitter Characteristics

| Feature | Description |
|---|---|
| Meaning | Delay variation |
| Measurement | Milliseconds |
| Major Impact | Voice/video quality |
| Solution | Buffering, QoS |

---

# Packet Loss

## Definition

Packet loss occurs when packets fail to reach the destination.

Measurement:

```
Percentage (%)
```

---

## Causes of Packet Loss

| Cause | Example |
|---|---|
| Congestion | Router queue overflow |
| Interface errors | Bad cable |
| Wireless interference | Weak Wi-Fi signal |
| Hardware failure | Faulty interface |
| Incorrect configuration | Routing issues |

---

## Packet Loss Impact

| Application | Effect |
|---|---|
| Voice | Audio gaps |
| Video | Freezing/artifacts |
| Gaming | Lag |
| File transfer | Retransmissions |

---

# Performance Metrics Comparison

| Metric | Meaning | Unit | Lower/Better? |
|---|---|---|---|
| Bandwidth | Maximum capacity | bps | Higher is better |
| Throughput | Actual transfer rate | bps | Higher is better |
| Latency | Packet travel delay | ms | Lower is better |
| Jitter | Delay variation | ms | Lower is better |

# 3. Worked Examples

## Example 1: Bandwidth vs Throughput

### Scenario

A network link has:

```
Bandwidth = 1 Gbps
```

A file transfer achieves:

```
Throughput = 650 Mbps
```

### Solution

Step 1:

Bandwidth is the maximum capacity.

```
Bandwidth = 1 Gbps
```

Step 2:

Throughput is actual performance.

```
Throughput = 650 Mbps
```

Step 3:

Difference:

```
1 Gbps - 650 Mbps = 350 Mbps unused capacity
```

Answer:

```
Bandwidth = 1 Gbps
Throughput = 650 Mbps
```

---

## Example 2: Calculate Packet Loss

### Scenario

A ping sends:

```
100 packets
```

Received:

```
97 packets
```

Find packet loss.

Formula:

```
Packet Loss =
(Lost Packets / Sent Packets) × 100
```

Calculation:

```
Lost packets = 100 - 97

= 3 packets

Packet Loss =
(3/100) × 100

= 3%
```

Answer:

```
Packet Loss = 3%
```

# 5. Exam Traps

- Bandwidth is not the same as speed experienced by users.
  - Throughput represents actual performance.

- A high-bandwidth link can still have high latency.

- Latency is measured in milliseconds, not Mbps.

- Jitter is not the same as latency.
  - Latency = delay
  - Jitter = variation in delay

- Packet loss is measured as a percentage.

- Increasing bandwidth does not always reduce latency.

- Voice traffic is sensitive to:
  - Latency
  - Jitter
  - Packet loss

- Throughput is always less than or equal to bandwidth.

# 7. Practice Questions

## Question 1

A 1 Gbps link transfers data at 700 Mbps. What is 700 Mbps?

A. Bandwidth  
B. Throughput  
C. Latency  
D. Jitter  

### Answer: B. Throughput

Explanation:

Throughput is the actual achieved transfer rate.

---

## Question 2

Which metric measures packet delay?

A. Bandwidth  
B. Throughput  
C. Latency  
D. Packet loss  

### Answer: C. Latency

Explanation:

Latency measures the time taken for packets to travel.

---

## Question 3

Voice calls are most affected by:

A. High bandwidth only  
B. Jitter and latency  
C. MAC addresses  
D. VLAN numbers  

### Answer: B. Jitter and latency

Explanation:

Voice requires consistent packet delivery with low delay.

---

## Question 4

A network sends 1000 packets and loses 20 packets. What is packet loss?

A. 2%  
B. 5%  
C. 20%  
D. 50%  

### Answer: A. 2%

Explanation:

```
20 / 1000 × 100 = 2%
```

---

## Question 5

Which statement is correct?

A. Bandwidth is always equal to throughput  
B. Jitter measures delay variation  
C. Latency is measured in Mbps  
D. Packet loss improves performance  

### Answer: B. Jitter measures delay variation

Explanation:

Jitter represents variation in packet arrival time.
