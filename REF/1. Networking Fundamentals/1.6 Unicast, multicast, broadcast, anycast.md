# 1. Overview

Network communication types describe how data is delivered from a source device to destination devices. CCNA tests unicast, multicast, broadcast, and anycast because they determine packet delivery behavior, address usage, bandwidth consumption, and routing decisions.

---

# 2. Core Concepts

# Communication Types Overview

| Type | Communication Pattern | Source | Destination |
|---|---|---|---|
| Unicast | One-to-one | One sender | One receiver |
| Broadcast | One-to-all | One sender | All devices in broadcast domain |
| Multicast | One-to-many | One sender | Selected group members |
| Anycast | One-to-nearest | One sender | Closest member of a group |

---

# Unicast

## Definition

Unicast is communication where one sender sends data to one specific destination.

Example:

```
PC1  -------->  Server
```

---

## Unicast Characteristics

| Feature | Details |
|---|---|
| Communication | One-to-one |
| Destination | Single device |
| Addressing | Individual IP/MAC address |
| Common Usage | Web browsing, SSH, email |
| Routing | Normal IP routing |

---

## Unicast Examples

| Application | Example |
|---|---|
| Web browsing | PC → Web server |
| SSH | Admin PC → Router |
| File download | Client → File server |
| Email | Mail client → Mail server |

---

## Unicast IPv4 Example

```
Source:
192.168.1.10

Destination:
192.168.1.50
```

Only the destination host processes the packet.

---

# Multicast

## Definition

Multicast sends traffic from one source to multiple selected receivers that have joined a multicast group.

Example:

```
             PC1
              ^
              |
Source ------ Multicast Group
              |
             PC2
              |
             PC3
```

---

## Multicast Characteristics

| Feature | Details |
|---|---|
| Communication | One-to-many |
| Destination | Group of receivers |
| Efficiency | Saves bandwidth |
| Addressing | Multicast addresses |
| Common Usage | Video streaming, routing protocols |

---

# IPv4 Multicast Address Range

| Range | Purpose |
|---|---|
| 224.0.0.0 - 239.255.255.255 | IPv4 multicast |

---

## Common IPv4 Multicast Addresses

| Address | Purpose |
|---|---|
| 224.0.0.1 | All hosts on subnet |
| 224.0.0.2 | All routers on subnet |
| 224.0.0.5 | OSPF routers |
| 224.0.0.6 | OSPF DR/BDR |
| 224.0.0.9 | RIPv2 routers |
| 224.0.0.10 | EIGRP routers |

---

## Multicast Examples

| Protocol/Application | Multicast Usage |
|---|---|
| OSPF | Router communication |
| EIGRP | Neighbor updates |
| Video conferencing | Multiple viewers |
| IPTV | Video distribution |

---

# Broadcast

## Definition

Broadcast sends traffic from one sender to all devices within the same broadcast domain.

Example:

```
          PC1
           |
           |
       Broadcast
      /    |    \
    PC2   PC3   PC4
```

---

## Broadcast Characteristics

| Feature | Details |
|---|---|
| Communication | One-to-all |
| Scope | Broadcast domain |
| Router Behavior | Routers do not forward broadcasts by default |
| Common Usage | ARP, DHCP |

---

# IPv4 Broadcast Types

## Limited Broadcast

Address:

```
255.255.255.255
```

Characteristics:

| Feature | Description |
|---|---|
| Scope | Local subnet only |
| Routed | No |
| Example | DHCP discovery |

---

## Directed Broadcast

Example:

Network:

```
192.168.1.0/24
```

Broadcast address:

```
192.168.1.255
```

Characteristics:

| Feature | Description |
|---|---|
| Scope | Specific network |
| Routed | Normally disabled |
| Example | Remote subnet broadcast |

---

# Broadcast Examples

| Protocol | Broadcast Usage |
|---|---|
| ARP | Find MAC address of IP |
| DHCP Discover | Find DHCP server |
| NetBIOS | Legacy Windows discovery |

---

# Anycast

## Definition

Anycast sends traffic to the nearest or best destination among multiple devices sharing the same address.

Example:

```
              DNS Server A
                   |
Client ---------- Anycast Address
                   |
              DNS Server B
```

The network chooses the closest server.

---

## Anycast Characteristics

| Feature | Details |
|---|---|
| Communication | One-to-nearest |
| Destination | Closest device in group |
| Routing Method | Uses normal routing protocols |
| Common Usage | DNS, CDN, IPv6 services |

---

## Anycast Examples

| Service | Usage |
|---|---|
| DNS root servers | Distributed DNS availability |
| Cloudflare DNS | 1.1.1.1 service |
| Content Delivery Networks | Closest content server |

---

# Unicast vs Multicast vs Broadcast vs Anycast

| Feature | Unicast | Multicast | Broadcast | Anycast |
|---|---|---|---|---|
| Communication | One-to-one | One-to-many | One-to-all | One-to-nearest |
| Receivers | One | Group | All hosts | One selected host |
| Bandwidth Usage | Higher for many receivers | Efficient | High usage | Efficient |
| Address Type | Individual address | Group address | Broadcast address | Shared address |
| IPv4 Support | Yes | Yes | Yes | Limited |
| IPv6 Support | Yes | Yes | No broadcast | Yes |

---

# IPv4 vs IPv6 Communication Types

| Type | IPv4 | IPv6 |
|---|---|---|
| Unicast | Supported | Supported |
| Multicast | Supported | Supported |
| Broadcast | Supported | Not supported |
| Anycast | Limited | Supported |

---

# IPv6 Multicast Examples

| Address | Purpose |
|---|---|
| FF02::1 | All IPv6 nodes |
| FF02::2 | All IPv6 routers |
| FF02::5 | OSPFv3 routers |
| FF02::6 | OSPFv3 DR/BDR |

# Broadcast Domain

## Definition

A broadcast domain is the group of devices that receive broadcast traffic from each other.

---

## Broadcast Domain Devices

| Device | Broadcast Behavior |
|---|---|
| Hub | Forwards broadcasts everywhere |
| Switch | Forwards broadcasts within VLAN |
| Router | Stops broadcasts between networks |

# 3. Worked Examples

## Example 1: Identify Communication Type

### Scenario

A user opens a website:

```
Laptop --------> Web Server
```

Only one server receives the request.

### Solution

Step 1:
- One sender.

Step 2:
- One destination.

Answer:

```
Unicast
```

Reason:

One device communicates with one specific device.

---

## Example 2: Identify Broadcast Address

### Scenario

Network:

```
192.168.10.0/24
```

Find broadcast address.

### Solution

Subnet mask:

```
/24 = 255.255.255.0
```

Host portion:

```
Last octet
```

Maximum host value:

```
255
```

Answer:

```
Broadcast Address:
192.168.10.255
```

# 5. Exam Traps

- Broadcast is only within a broadcast domain.
- Routers do not forward IPv4 broadcasts by default.
- IPv6 does not use broadcast.
- IPv6 replaces broadcast with multicast.
- Multicast is not the same as broadcast.
  - Multicast = selected group.
  - Broadcast = everyone.

- Unicast is the most common traffic type.
- Anycast uses the same address on multiple devices.
- Anycast routing chooses the closest/best destination.
- OSPF uses multicast, not broadcast, for neighbor communication.
- ARP uses broadcast request and unicast reply.

# 7. Practice Questions

## Question 1

A PC accessing a web server uses which communication type?

A. Broadcast  
B. Multicast  
C. Unicast  
D. Anycast  

### Answer: C. Unicast

Explanation:

One client communicates with one server.

---

## Question 2

Which IPv4 range is used for multicast?

A. 10.0.0.0/8  
B. 172.16.0.0/12  
C. 224.0.0.0/4  
D. 192.168.0.0/16  

### Answer: C. 224.0.0.0/4

Explanation:

IPv4 multicast uses addresses from 224.0.0.0 to 239.255.255.255.

---

## Question 3

Which communication method does IPv6 use instead of broadcast?

A. Unicast  
B. Multicast  
C. Anycast only  
D. None  

### Answer: B. Multicast

Explanation:

IPv6 removed broadcast and uses multicast.

---

## Question 4

ARP request traffic is normally:

A. Unicast  
B. Multicast  
C. Broadcast  
D. Anycast  

### Answer: C. Broadcast

Explanation:

ARP request is sent to all devices in the local broadcast domain.

---

## Question 5

A DNS client reaches the nearest DNS server using the same IP address shared by multiple servers. This is:

A. Broadcast  
B. Multicast  
C. Anycast  
D. Unicast  

### Answer: C. Anycast

Explanation:

Anycast selects the closest available destination.
