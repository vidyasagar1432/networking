# 1. Overview

Network types classify networks based on geographic coverage, communication technology, and purpose. CCNA tests LAN, WAN, WLAN, and related concepts because they form the foundation for switching, routing, wireless networking, and enterprise architecture.

---

# 2. Core Concepts

## Network Type Classification

| Network Type | Full Form | Coverage Area | Primary Purpose |
|---|---|---|---|
| PAN | Personal Area Network | Few meters | Connect personal devices |
| LAN | Local Area Network | Building or campus | Connect local devices |
| WLAN | Wireless Local Area Network | Wireless LAN area | Connect devices using Wi-Fi |
| MAN | Metropolitan Area Network | City or metropolitan area | Connect multiple LANs |
| WAN | Wide Area Network | Countries/continents | Connect remote networks |
| SAN | Storage Area Network | Data center environment | Provide storage connectivity |

---

# PAN (Personal Area Network)

## Definition

A PAN connects personal devices over a very short distance, usually around an individual user.

| Feature | Details |
|---|---|
| Coverage | Few meters |
| Ownership | Personal |
| Technologies | Bluetooth, NFC, USB |
| Speed | Low to medium |
| Example | Smartphone connected to smartwatch |

Example:

```
Smartwatch
     |
 Bluetooth
     |
Smartphone
     |
 Bluetooth
     |
Wireless Earbuds
```

---

# LAN (Local Area Network)

## Definition

A LAN connects devices within a limited geographic area such as a home, office, school, or building.

| Feature | Details |
|---|---|
| Coverage | Building, office, campus |
| Ownership | Private organization |
| Technology | Ethernet |
| Main Device | Switch |
| Speed | High |
| Example | Office network |

Example:

```
PC
 |
Switch
 |
Server
 |
Router
```

---

## LAN Characteristics

| Feature | Description |
|---|---|
| Latency | Low |
| Speed | High |
| Administration | Local organization |
| Communication | Internal network communication |
| Common Protocols | Ethernet, TCP/IP |

---

# WLAN (Wireless Local Area Network)

## Definition

A WLAN is a LAN that uses wireless communication instead of physical Ethernet cables.

| Feature | Details |
|---|---|
| Standard | IEEE 802.11 |
| Medium | Radio frequency |
| Main Device | Wireless Access Point |
| Security | WPA2/WPA3 |
| Example | Home Wi-Fi |

---

## WLAN Components

| Component | Function |
|---|---|
| Wireless Client | Connects to Wi-Fi |
| Access Point (AP) | Provides wireless connectivity |
| Wireless LAN Controller (WLC) | Central AP management |
| SSID | Wireless network name |

Example:

```
Laptop
    \
     \
   Access Point ---- Switch ---- Router
     /
    /
 Phone
```

---

# MAN (Metropolitan Area Network)

## Definition

A MAN connects multiple LANs across a city or metropolitan region.

| Feature | Details |
|---|---|
| Coverage | City-level |
| Size | Larger than LAN, smaller than WAN |
| Technology | Fiber, Metro Ethernet |
| Ownership | ISP or large organization |
| Example | University buildings across a city |

Example:

```
Building A LAN
       |
       |
 Metro Network
       |
       |
Building B LAN
```

---

# WAN (Wide Area Network)

## Definition

A WAN connects networks over large geographic distances such as countries and continents.

| Feature | Details |
|---|---|
| Coverage | Large geographic areas |
| Devices | Routers |
| Technologies | MPLS, VPN, SD-WAN, leased lines |
| Ownership | Enterprise or service provider |
| Example | Global company network |

Example:

```
Office A
   |
Router
   |
 ISP WAN
   |
Router
   |
Office B
```

---

## WAN Technologies

| Technology | Purpose |
|---|---|
| MPLS | Private enterprise WAN |
| SD-WAN | Software-controlled WAN |
| VPN | Secure connection over Internet |
| Leased Line | Dedicated connection |
| Broadband | Internet connectivity |

---

# SAN (Storage Area Network)

## Definition

A SAN is a dedicated network that provides high-speed access between servers and storage devices.

| Feature | Details |
|---|---|
| Purpose | Storage communication |
| Used In | Data centers |
| Devices | Servers, storage arrays |
| Technologies | Fibre Channel, iSCSI |
| Traffic Type | Storage traffic |

---

## SAN vs LAN

| Feature | LAN | SAN |
|---|---|---|
| Purpose | User/application communication | Storage access |
| Traffic | Data packets | Storage blocks |
| Devices | PCs, printers, servers | Servers and storage systems |
| Protocols | Ethernet/IP | Fibre Channel, iSCSI |

---

# Network Type Comparison

| Feature | PAN | LAN | WLAN | MAN | WAN | SAN |
|---|---|---|---|---|---|---|
| Coverage | Few meters | Building | Building wireless | City | Global | Data center |
| Main Technology | Bluetooth | Ethernet | Wi-Fi | Metro Ethernet | MPLS/VPN | FC/iSCSI |
| Main Device | Personal devices | Switch | Access Point | Provider equipment | Router | Storage switch |
| Purpose | Personal connectivity | Local communication | Wireless access | Connect LANs | Connect remote networks | Storage connectivity |

---

# Internet vs WAN

| Internet | WAN |
|---|---|
| Public global network | Category of large networks |
| Largest public network | Can be private or public |
| Uses many interconnected WAN links | Connects geographically separated networks |

**Important:**  
The Internet is the world's largest WAN.

---

# Broadcast Domain Relationship

| Network Type | Broadcast Behavior |
|---|---|
| PAN | Very small network |
| LAN | Single broadcast domain unless VLANs are used |
| WLAN | Similar to LAN |
| MAN | Connects multiple LANs |
| WAN | Routers separate broadcast domains |
| SAN | Usually isolated from normal LAN traffic |

# 3. Worked Examples

## Example 1: Identify Network Type

### Scenario

A company has offices in:

- Chennai
- Mumbai
- Delhi

All offices are connected using ISP-provided links.

### Solution

Step 1:
- Multiple cities are involved.

Step 2:
- Networks are geographically separated.

Step 3:
- Routers connect different locations.

Answer:

```
WAN
```

Reason:

WAN connects LANs over large geographic distances.

## Example 2: Identify LAN vs WLAN

### Scenario

```
Laptop
   |
 Wi-Fi
   |
Access Point
   |
 Switch
   |
Server
```

### Solution

Step 1:
The laptop uses wireless communication.

Step 2:
Wireless LAN uses IEEE 802.11.

Answer:

```
WLAN
```

Reason:

WLAN is the wireless version of LAN.

# 4. Configuration/Commands (if applicable)

## Display Interfaces

```bash
Router# show ip interface brief
```

Purpose:

- Shows router interfaces
- Displays IP addresses
- Shows interface status

---

## View Interface Details

```bash
Router# show interfaces
```

Purpose:

- Displays interface statistics
- Shows errors and traffic information

---

## Configure a LAN Interface

```bash
Router(config)# interface gigabitEthernet 0/0
Router(config-if)# ip address 192.168.1.1 255.255.255.0
Router(config-if)# no shutdown
```

| Command | Purpose |
|---|---|
| interface gigabitEthernet 0/0 | Select interface |
| ip address | Assign Layer 3 address |
| no shutdown | Enable interface |

---

## Configure WAN Interface Example

```bash
Router(config)# interface serial 0/0/0
Router(config-if)# ip address 10.1.1.1 255.255.255.252
Router(config-if)# no shutdown
```

Purpose:

- Configure router-to-router WAN connection.

# 5. Exam Traps

- LAN does not mean only wired networks.
  - WLAN is a type of LAN.

- WAN does not always mean Internet.
  - Enterprises can have private WANs.

- MAN is smaller than WAN.

Order:

```
PAN < LAN < MAN < WAN
```

- SAN is not used for normal user traffic.

- Access Point provides WLAN access, not WAN connectivity.

- Router commonly connects LAN networks to WAN networks.

- Internet is the largest example of a WAN.

# 7. Practice Questions

## Question 1

A company connects offices located in different countries. Which network type is used?

A. PAN  
B. LAN  
C. WAN  
D. SAN  

### Answer: C. WAN

Explanation:

WAN connects networks over large geographic distances.

---

## Question 2

Which technology is used by WLAN?

A. MPLS  
B. IEEE 802.11  
C. Fibre Channel  
D. Serial link  

### Answer: B. IEEE 802.11

Explanation:

IEEE 802.11 defines Wi-Fi communication.

---

## Question 3

Which network is designed for storage communication?

A. LAN  
B. WAN  
C. SAN  
D. MAN  

### Answer: C. SAN

Explanation:

SAN provides dedicated storage connectivity.

---

## Question 4

Which order represents increasing network size?

A. WAN → MAN → LAN → PAN  
B. PAN → LAN → MAN → WAN  
C. LAN → PAN → WAN → MAN  
D. MAN → WAN → LAN → PAN  

### Answer: B. PAN → LAN → MAN → WAN

Explanation:

PAN is smallest and WAN is largest.

---

## Question 5

A company uses Wi-Fi inside an office. This network is called:

A. MAN  
B. WLAN  
C. SAN  
D. WAN  

### Answer: B. WLAN

Explanation:

A WLAN provides wireless LAN connectivity using Wi-Fi.
