# 1. Overview

Port numbers operate at the OSI Layer 4 (Transport Layer) to identify specific applications or services running on a device. CCNA tests port number ranges, TCP/UDP usage, and common application ports used for troubleshooting and configuration.

---

# 2. Core Concepts

# Port Number Definition

A port number is a:

```
16-bit logical identifier used by TCP and UDP
to identify applications.
```

Range:

```
0 - 65535
```

---

# Port Number Purpose

Without ports:

```
IP Address identifies the device
```

With ports:

```
IP Address + Port identifies the application
```

Example:

```
192.168.1.10:443
```

Means:

```
HTTPS service on device 192.168.1.10
```

---

# Socket Concept

Socket:

```
IP Address + Port Number
```

Example:

```
Client Socket:
192.168.1.50:50000

Server Socket:
192.168.1.10:443
```

---

# TCP/UDP Port Ranges

| Range | Name | Usage |
|---|---|---|
| 0-1023 | Well-known ports | Common system services |
| 1024-49151 | Registered ports | Applications and vendors |
| 49152-65535 | Dynamic/private ports | Temporary client ports |

---

Range:

```
0 - 1023
```

Used by:

- Core network services
- Standard protocols
- Common applications

| 21 | FTP Control | TCP | FTP commands |

| 25 | SMTP | TCP | Email sending |
| 53 | DNS | TCP/UDP | Name resolution |
| 67 | DHCP Server | UDP | IP assignment |
| 68 | DHCP Client | UDP | IP assignment |
| 69 | TFTP | UDP | File transfer |
| 80 | HTTP | TCP | Web |
| 110 | POP3 | TCP | Email retrieval |
| 123 | NTP | UDP | Time synchronization |
| 143 | IMAP | TCP | Email access |
| 161 | SNMP | UDP | Network monitoring |
| 162 | SNMP Trap | UDP | Notifications |
| 179 | BGP | TCP | Routing |

# 2. Registered Ports

Range:

```
1024 - 49151
```

Used by:

- Vendor applications
- User applications
- Database services

Examples:

| Port | Protocol | Purpose |
|---|---|---|
| 1433 | Microsoft SQL Server | Database |
| 1521 | Oracle Database | Database |
| 3306 | MySQL | Database |
| 3389 | RDP | Remote desktop |
| 5060 | SIP | VoIP signaling |
| 8080 | HTTP Alternate | Web services |

---

# 3. Dynamic / Private Ports

Range:

```
49152 - 65535
```

Also called:

```
Ephemeral ports
```

Used by:

```
Temporary client-side connections
```

Example:

Client:

```
192.168.1.10:52000
```

Server:

```
192.168.1.20:443
```

The client port:

```
52000
```

is dynamically assigned.

# Port Numbers in Cisco ACLs

Ports are used in extended ACLs.

Example:

Allow HTTPS:

```bash
access-list 100 permit tcp any any eq 443
```

Meaning:

```
Allow TCP traffic to port 443
```

---

# Port Numbers and Firewalls

Firewalls filter traffic using:

```
IP + Port + Protocol
```

Example:

Allow web traffic:

```
TCP 80
TCP 443
```

Block:

```
TCP 23
```

---

# Port Scanning Concept

Tools identify open services by checking ports.

Example:

```
Port 443 OPEN
```

Means:

```
HTTPS service available
```

# 4. Configuration/Commands (if applicable)

## Extended ACL Using Ports

Allow SSH:

```bash
access-list 101 permit tcp any any eq 22
```

Explanation:

| Command | Function |
|---|---|
| access-list 101 | Creates ACL |
| permit | Allows traffic |
| tcp | Uses TCP |
| eq 22 | Matches SSH |

---

Allow DNS:

```bash
access-list 101 permit udp any any eq 53
```

Allows UDP DNS queries.

---

Verify ACL:

```bash
show access-lists
```

# 5. Exam Traps

- Port numbers operate at Layer 4.
- IP addresses identify devices; ports identify applications.
- Port 443 is HTTPS, not HTTP.
- Port 22 is SSH, not Telnet.
- Port 23 is Telnet.
- DNS can use TCP and UDP port 53.
- DHCP uses UDP 67 and 68.
- BGP uses TCP port 179.
- Dynamic ports are normally used by clients.
- Well-known ports are 0-1023.
- Registered ports are 1024-49151.
- Dynamic/private ports are 49152-65535.
- Ports are used by TCP and UDP, not IP.

# 7. Practice Questions

## Question 1

Which port range contains well-known ports?

A. 0-1023  
B. 1024-49151  
C. 49152-65535  
D. 65536+

### Answer: A

Explanation:

Well-known ports are assigned to common services.

---

## Question 2

A client connects to an HTTPS server. Which port does the server use?

A. 22  
B. 53  
C. 443  
D. 50000  

### Answer: C

Explanation:

HTTPS uses TCP port 443.

---

## Question 3

Which ports are normally assigned dynamically to clients?

A. Well-known ports  
B. Registered ports  
C. Ephemeral ports  
D. Static ports  

### Answer: C

Explanation:

Clients use dynamic/private ports for temporary sessions.

---

## Question 4

Which protocol uses TCP port 179?

A. DNS  
B. BGP  
C. DHCP  
D. SSH  

### Answer: B

Explanation:

BGP uses TCP 179.

---

## Question 5

Which Layer 4 information identifies an application?

A. MAC address  
B. IP address  
C. Port number  
D. VLAN ID  

### Answer: C

Explanation:

Port numbers identify applications and services.
