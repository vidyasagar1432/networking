# 1. Overview

WLAN architecture defines how wireless access points are deployed, managed, and controlled in a network. CCNA tests the differences between autonomous access points and controller-based WLANs, including WLC functions, CAPWAP communication, and centralized wireless management.

---

# 2. Core Concepts

# WLAN Architecture Definition

WLAN:

```
Wireless Local Area Network
```

A network that provides connectivity using wireless radio communication.

Basic components:

```
Wireless Client

      |

      |

Access Point

      |

      |

Network Infrastructure
```

---

# WLAN Components

| Component | Function |
|---|---|
| Wireless Client | Device connecting to Wi-Fi |
| Access Point (AP) | Provides wireless connectivity |
| WLC | Centralized AP management |
| Authentication Server | User authentication |
| LAN Switch | Connects APs/WLC to network |

---

# Access Point (AP)

An AP provides:

- Wireless coverage
- Client connectivity
- Radio transmission
- WLAN services

Example:

```
Laptop
   |
 Wi-Fi
   |
 AP
   |
 Switch
```

---

# WLAN Deployment Models

Two main architectures:

| Architecture | Description |
|---|---|
| Autonomous AP | Each AP operates independently |
| Controller-Based WLAN | Multiple APs managed by WLC |

---

# Autonomous Access Point Architecture

An autonomous AP is:

```
A standalone AP with all intelligence locally.
```

Each AP manages:

- Configuration
- Security
- Radio settings
- Client connections

---

# Autonomous AP Design

```
                 LAN

                  |

        +---------+---------+

        |         |         |

       AP1       AP2       AP3

        |         |         |

     Clients  Clients  Clients
```

---

# Autonomous AP Characteristics

| Feature | Description |
|---|---|
| Management | Individual AP |
| Configuration | Manual |
| Scaling | Difficult |
| Cost | Lower |
| Best for | Small networks |

---

# Autonomous AP Advantages

| Advantage | Explanation |
|---|---|
| Simple | No controller required |
| Low cost | Less equipment |
| Independent | Each AP works alone |
| Good for small sites | Few APs needed |

---

# Autonomous AP Disadvantages

| Disadvantage | Explanation |
|---|---|
| Manual configuration | Configure every AP separately |
| Difficult troubleshooting | No centralized view |
| Poor scalability | Hard with many APs |
| No centralized RF control | Manual channel planning |

---

# Controller-Based WLAN Architecture

A controller-based WLAN uses:

```
Wireless LAN Controller (WLC)
```

to manage multiple APs.

---

# Controller-Based Design

```
              WLC

               |

        +------+------+

        |      |      |

       AP1    AP2    AP3

        |      |      |

     Clients Clients Clients
```

---

# WLC Functions

The WLC provides centralized control of:

| Function | Purpose |
|---|---|
| AP Management | Configure many APs |
| Authentication | Control user access |
| Security | Apply policies |
| RF Management | Channel/power optimization |
| Roaming | Client movement support |
| Monitoring | Wireless visibility |

---

| Feature | Autonomous AP | Lightweight AP |

# WLC (Wireless LAN Controller)

WLC:

```
Central device managing multiple APs.
```

---

# WLC Responsibilities

## AP Management

Controls:

- AP configuration
- Firmware
- Policies

---

## RF Management

Automatically manages:

- Channel assignment
- Transmit power
- Interference

---

## Security Management

Controls:

- Authentication
- Encryption
- Access policies

---

## Roaming Support

Allows users to move:

```
AP1 → AP2
```

without losing connection.

---

# CAPWAP Protocol

CAPWAP:

```
Control And Provisioning of Wireless Access Points
```

Used between:

```
Lightweight AP ↔ WLC
```

---

# CAPWAP Characteristics

| Feature | Value |
|---|---|
| Purpose | AP management |
| Transport | UDP |
| Control Channel | UDP 5246 |
| Data Channel | UDP 5247 |
| Encryption | Control channel encrypted |

---

# CAPWAP Communication

```
Wireless Client

      |

      |

Lightweight AP

      |

      |

      |

WLC
```

---

# CAPWAP Tunnels

## Control Tunnel

Used for:

- AP management
- Configuration

Port:

```

```

---

## Data Tunnel

Used for:

- Client traffic

Port:

```
UDP 5247
```

# 5. Exam Traps

- Autonomous AP does not require a WLC.
- Lightweight AP requires a WLC.
- CAPWAP connects AP to WLC.
- CAPWAP control uses UDP 5246.
- CAPWAP data uses UDP 5247.
- WLC provides centralized management.
- WLC manages RF channels and transmit power.
- Autonomous APs are suitable for small networks.
- Controller-based WLANs are preferred for enterprise networks.
- AP provides wireless access; WLC provides centralized control.
- Roaming is easier with controller-based WLANs.

Which device centrally manages lightweight APs?

A. Router  
B. Switch  
C. WLC  
D. Firewall  

### Answer: C

Explanation:

Wireless LAN Controller manages lightweight APs.

## Question 2

Which protocol connects lightweight APs to a WLC?

A. STP  
B. CAPWAP

D. SNMP  

### Answer: B

Explanation:

CAPWAP provides AP-WLC communication.

A. Autonomous AP

Small deployments can use standalone APs.
