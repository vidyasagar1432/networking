# 1. Overview

Wireless security protects WLAN communication by providing authentication, encryption, and access control. CCNA tests the evolution of wireless security standards (WEP → WPA → WPA2 → WPA3), encryption methods, and enterprise authentication using 802.1X/EAP.

---

# 2. Core Concepts

# Wireless Security Goals

Wireless security provides:

| Goal | Purpose |
|---|---|
| Authentication | Verify user/device identity |
| Confidentiality | Encrypt wireless traffic |
| Integrity | Prevent data modification |
| Access Control | Allow authorized users only |

---

# Wireless Security Evolution

```
WEP

 |

WPA

 |

WPA2

 |

WPA3
```

Each generation improves:

- Encryption strength
- Authentication
- Protection against attacks

---

# WEP (Wired Equivalent Privacy)

## Definition

WEP:

```
Original IEEE 802.11 security mechanism
```

Designed to provide wired-like security.

---

# WEP Characteristics

| Feature | Value |
|---|---|
| Standard | 802.11 legacy |
| Encryption | RC4 |
| Key Size | 64-bit / 128-bit |
| Authentication | Shared key |
| Security | Weak |

---

# WEP Operation

```
Client

 |

Shared Secret Key

 |

Access Point
```

Both sides use the same key.

---

# WEP Problems

| Issue | Description |
|---|---|
| Weak encryption | RC4 vulnerabilities |
| Static keys | Difficult management |
| Small IV space | Easy key recovery |
| No strong authentication | Easy attacks |

---

# WEP Status

```
Deprecated
```

Should not be used.

---

# WPA (Wi-Fi Protected Access)

## Definition

WPA was introduced as a temporary improvement over WEP.

---

# WPA Characteristics

| Feature | Value |
|---|---|
| Encryption | TKIP |
| Based on | RC4 |
| Security | Better than WEP |
| Authentication | PSK / 802.1X |

---

# WPA Improvements

Compared with WEP:

- Dynamic keys
- Better integrity checking
- Improved authentication

---

# WPA Limitations

- Uses TKIP
- Still based on RC4
- Replaced by WPA2

---

# WPA2

## Definition

WPA2 is based on:

```
IEEE 802.11i security standard
```

---

# WPA2 Characteristics

| Feature | Value |
|---|---|
| Encryption | AES |
| Cipher | CCMP |
| Security | Strong |
| Authentication | PSK / 802.1X |

---

# WPA2 Encryption

WPA2 uses:

```
AES-CCMP
```

AES:

```
Advanced Encryption Standard
```

CCMP:

```
Counter Mode CBC-MAC Protocol
```

---

# WPA2 Modes

Two main modes:

| Mode | Use |
|---|---|
| WPA2-Personal | Home/small networks |
| WPA2-Enterprise | Business networks |

---

# WPA2-Personal

Also called:

```
Pre-Shared Key (PSK)
```

---

# WPA2-PSK Operation

```
Client

 |

Shared Password

 |

Access Point
```

Example:

```
WiFiPassword123
```

---

# WPA2-PSK Advantages

- Simple setup
- Low cost
- No authentication server

---

# WPA2-PSK Disadvantages

- Shared password
- Hard to manage many users
- Password compromise affects everyone

---

# WPA2-Enterprise

Uses:

```
802.1X authentication
```

Components:

```
Client

 |

Authenticator (AP/WLC)

 |

Authentication Server (RADIUS)
```

---

# WPA3

## Definition

Latest Wi-Fi security standard.

Provides:

- Stronger encryption
- Better password protection
- Improved enterprise security

---

# WPA3 Features

| Feature | Purpose |
|---|---|
| SAE | Stronger password authentication |
| Forward secrecy | Protect past sessions |
| Improved encryption | Better security |
| 192-bit security mode | Enterprise protection |

---

# WPA3 Personal

Uses:

```
SAE
```

SAE:

```
Simultaneous Authentication of Equals
```

Replaces:

```
WPA2 PSK
```

---

# WPA3 Enterprise

Provides:

```
192-bit cryptographic security
```

Used for:

- Government
- High-security organizations

---

# WPA Security Comparison

| Feature | WEP | WPA | WPA2 | WPA3 |
|---|---|---|---|---|
| Encryption | RC4 | TKIP | AES-CCMP | AES + SAE |
| Security | Weak | Better | Strong | Strongest |
| Key Management | Static | Dynamic | Dynamic | Advanced |
| Recommended | No | No | Yes | Yes |

---

# 802.1X Authentication

## Definition

802.1X provides:

```
Port-based network access control
```

Used for:

- Wired networks
- Wireless networks

---

# 802.1X Components

Three main components:

```
Supplicant

      |

Authenticator

      |
```

# 802.1X Roles

| Component | Function |
|---|---|
| Supplicant | Client requesting access |
| Authenticator | AP/WLC or switch |

```
      |
```

# RADIUS

RADIUS:

```
Remote Authentication Dial-In User Service
```

Provides:

- Authentication
- Authorization
- Accounting

Known as:

```
AAA
```

---

# AAA Concept

AAA:

| Component | Meaning |
|---|---|
| Authentication | Who are you? |
| Authorization | What can you access? |
| Accounting | What did you do? |

---

# EAP (Extensible Authentication Protocol)

EAP:

```
Framework for authentication methods.
```

Used with:

```
802.1X
```

---

# Common EAP Methods

| EAP Method | Description |
|---|---|
| EAP-TLS | Certificate-based authentication |
| PEAP | Protected EAP |
| EAP-TTLS | Tunnel-based authentication |
| EAP-FAST | Cisco-developed method |

---

# EAP-TLS

Uses:

```
Digital certificates
```

Provides:

- Strong security
- Mutual authentication

---

# PEAP

Uses:

```
Server certificate + user credentials
```

Common in enterprises.

---

# Wireless Authentication Comparison

| Method | Authentication | Use Case |
|---|---|---|
| WPA2-PSK | Shared password | Home |
| WPA3-Personal | SAE password | Home/new devices |
| WPA2-Enterprise | 802.1X + RADIUS | Business |
| WPA3-Enterprise | 802.1X + advanced encryption | High security |

---

# Personal vs Enterprise Security

| Feature | Personal | Enterprise |
|---|---|---|
| Authentication | Shared key | User identity |
| Server required | No | Yes |
| Management | Simple | Centralized |
| Scalability | Low | High |

---

# Wireless Encryption vs Authentication

| Function | Example |
|---|---|
| Authentication | 802.1X, PSK |
| Encryption | AES, CCMP |
| Identity verification | RADIUS |
| Key exchange | SAE |

---

# Cisco WLAN Security Flow

Example:

```
Client

 |

SSID Selection

 |

Authentication

 |

802.1X/EAP

 |

RADIUS

 |

Access Granted

 |

Encrypted Session
```

---

# WPA2-Enterprise Flow

Steps:

1. Client connects to SSID.
2. AP/WLC requests authentication.
3. Client provides EAP credentials.
4. WLC forwards request to RADIUS.
5. RADIUS validates user.
6. Encryption keys are generated.
7. Client connects.

# 5. Exam Traps

- WEP is insecure and deprecated.
- WEP uses RC4.
- WPA uses TKIP.
- WPA2 uses AES-CCMP.
- WPA3 Personal uses SAE.
- WPA2/WPA3 Enterprise use 802.1X.
- 802.1X requires a RADIUS server.
- AP/WLC acts as the authenticator.
- Client device is the supplicant.
- RADIUS provides AAA services.
- PSK means one shared password.
- Enterprise authentication provides individual user identity.
- Encryption protects data; authentication verifies identity.
