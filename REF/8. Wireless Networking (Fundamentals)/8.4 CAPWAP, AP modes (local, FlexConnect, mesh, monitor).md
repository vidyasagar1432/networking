# 1. Overview

CAPWAP is a protocol used by Cisco lightweight access points to communicate with a Wireless LAN Controller (WLC). Cisco AP modes define how an access point operates, including providing client access, monitoring RF conditions, extending wireless coverage, or operating remotely.

---

# 2. Core Concepts

# CAPWAP Definition

CAPWAP:

```
Control And Provisioning of Wireless Access Points
```

Purpose:

- Connect lightweight APs to WLC
- Transport AP management information
- Carry wireless client traffic
- Provide centralized WLAN control

---

# CAPWAP Architecture

```
Wireless Client

      |

      |

 Lightweight AP

      |

      |

 CAPWAP Tunnel

      |

      |

      WLC
```

---

# CAPWAP Components

| Component | Function |
|---|---|
| AP | Wireless radio device |
| WLC | Central controller |
| CAPWAP Tunnel | Communication path |
| WLAN | Wireless network service |

---

# CAPWAP Protocol Details

| Feature | Value |
|---|---|
| Protocol | CAPWAP |
| Transport | UDP |
| Control Channel | UDP 5246 |
| Data Channel | UDP 5247 |
| Encryption | Control messages encrypted |

---

# CAPWAP Channels

CAPWAP uses two tunnels:

```
          AP

          |

 +----------------+

 | CAPWAP Tunnel |

 +----------------+

          |

          |

          WLC
```

---

# 1. CAPWAP Control Channel

Port:

```
UDP 5246
```

Used for:

- AP configuration
- WLC discovery
- Keepalive messages
- Firmware management
- Control messages

---

# 2. CAPWAP Data Channel

Port:

```
UDP 5247
```

Used for:

- Client data traffic
- Wireless user packets

---

# CAPWAP Discovery Process

When a lightweight AP starts:

```
AP Boot

 |

 v

Find WLC

 |

 v

Join WLC

 |

 v

Download Configuration

 |

 v

Provide Wireless Service
```

---

# AP Discovery Methods

An AP can discover a WLC using:

| Method | Description |
|---|---|
| DHCP Option 43 | DHCP provides WLC address |
| DNS | Resolves CISCO-CAPWAP-CONTROLLER |
| Broadcast | Local network discovery |
| Static configuration | Manually configured WLC address |

---

# Lightweight AP Registration Process

Steps:

1. AP obtains IP address.
2. AP discovers WLC.
3. AP creates CAPWAP tunnel.
4. WLC authenticates AP.
5. AP downloads configuration.
6. AP begins operation.

Client

 |

# Local Mode Features

| Feature | Support |
|---|---|
| Client access | Yes |

---

# Local Mode Advantages

- Centralized management
- Centralized security
- Easy roaming
- Full WLC features

---

# Local Mode Disadvantages

- Requires WLC connectivity
- WAN dependency for remote sites

---

# 2. FlexConnect Mode

FlexConnect is designed for:

```
Remote branch offices
```

where WAN bandwidth is limited.

---

# FlexConnect Architecture

```
             Headquarters

                 |

                WLC

                 |

              WAN Link

                 |

              Branch

                 |

             FlexConnect AP
```

---

# FlexConnect Features

| Feature | Description |
|---|---|
| Local switching | Client traffic stays local |
| Central management | WLC controls AP |
| WAN failure support | Can continue working |
| Remote offices | Main use |

---

# FlexConnect Operation

Normal:

```
Client

 |

 AP

 |

 Local Switch

 |

 LAN
```

Management:

```
AP

 |

CAPWAP

 |

WLC
```

---

# FlexConnect Advantages

- Saves WAN bandwidth
- Supports remote locations
- Continues operation during WLC loss
- Centralized configuration

---

# FlexConnect Limitations

- Some WLC features unavailable
- Requires proper design

---

# 3. Mesh Mode

Mesh APs use:

```
Wireless connection between APs
```

instead of wired Ethernet.

---

# Mesh Architecture

```
Root AP

 |

Wireless Link

 |

Mesh AP

 |

Clients
```

---

# Mesh Terms

| Term | Meaning |
|---|---|
| Root AP | Connected to wired network |
| Mesh AP | Uses wireless backhaul |

---

# Mesh Uses

- Outdoor wireless coverage
- Areas without cabling
- Temporary networks

Examples:

- Warehouses
- Campuses
- Public areas

---

# Mesh Advantages

- No Ethernet required for every AP
- Flexible deployment
- Extended coverage

---

# Mesh Disadvantages

- Lower throughput
- Wireless backhaul consumes bandwidth
- More interference risk

---

| Feature | Local Mode | FlexConnect |

| Feature | CAPWAP | FlexConnect |

# 6. Exam Traps

- CAPWAP control uses UDP 5246.
- CAPWAP data uses UDP 5247.
- Local mode tunnels client traffic to WLC.
- FlexConnect allows local client switching.
- FlexConnect is designed for branch offices.
- Mesh APs use wireless backhaul.
- Monitor mode does not provide client access.
- Lightweight APs require a WLC.
- CAPWAP is not a routing protocol.
- Autonomous APs do not use CAPWAP.
- WLC provides centralized AP management.
- DHCP Option 43 can help AP discover WLC.

Which CAPWAP port carries control messages?

A. UDP 53  
B. UDP 161

D. UDP 5247  

### Answer: C

Explanation:

CAPWAP control traffic uses UDP 5246.
