# 1. Overview

Radio Frequency (RF) fundamentals describe how wireless devices transmit data using electromagnetic waves. CCNA tests frequency bands, channels, channel overlap, interference, and differences between 2.4 GHz, 5 GHz, and 6 GHz Wi-Fi bands.

---

# 2. Core Concepts

# RF Definition

RF:

```
Radio Frequency
```

A type of electromagnetic energy used for wireless communication.

Examples:

- Wi-Fi
- Bluetooth
- Cellular networks
- RFID

# Frequency

Frequency is:

```
Number of wave cycles per second
```

Measured in:

```
Hertz (Hz)
```

---

# Frequency Units

| Unit | Value |
|---|---:|
| Hz | 1 cycle/second |
| kHz | 1,000 Hz |
| MHz | 1,000,000 Hz |
| GHz | 1,000,000,000 Hz |

---

# Frequency Relationship

Higher frequency:

| Advantage | Disadvantage |
|---|---|
| Higher data rates | Shorter range |
| More channels | Less wall penetration |

Lower frequency:

| Advantage | Disadvantage |
|---|---|
| Longer range | Fewer channels |
| Better penetration | More interference |

---

# Wavelength

Frequency and wavelength are related:

```
Higher frequency = shorter wavelength

Lower frequency = longer wavelength
```

---

# Wi-Fi Frequency Bands

| Band | Frequency Range | IEEE Usage |
|---|---|---|
| 2.4 GHz | 2.400–2.483 GHz | 802.11 b/g/n/ax |
| 5 GHz | 5.150–5.850 GHz | 802.11 a/n/ac/ax |
| 6 GHz | 5.925–7.125 GHz | Wi-Fi 6E / Wi-Fi 7 |

---

# Channel Concept

A channel is:

```
A specific frequency range used for wireless communication.
```

Example:

```
2.4 GHz Channel 6
```

---

# Channel Width

Channel width:

```
Amount of frequency spectrum used by a channel.
```

Common widths:

| Width | Usage |
|---|---|
| 20 MHz | Standard Wi-Fi |
| 40 MHz | Higher speed |
| 80 MHz | 5 GHz high throughput |
| 160 MHz | Maximum throughput |

---

# Channel Overlap

When channels interfere:

```
Adjacent channels overlap
```

Causes:

- Reduced speed
- Retransmissions
- Packet loss

| Feature | 2.4 GHz | 5 GHz | 6 GHz |
|---|---|---|---|

# RF Power Concepts

## Transmit Power

Amount of RF energy sent by transmitter.

Measured in:

```
dBm
```

Higher power:

- Longer range
- More interference risk

---

# Signal Strength

Measured as:

```
RSSI
```

Received Signal Strength Indicator.

Typical values:

| RSSI | Quality |
|---|---|
| -30 dBm | Excellent |
| -50 dBm | Good |
| -67 dBm | Minimum recommended |
| -80 dBm | Poor |

---

# Signal-to-Noise Ratio (SNR)

SNR:

```
Signal strength compared to noise
```

Formula:

```
SNR = Signal - Noise
```

Higher SNR:

```
Better wireless performance
```

---

# Noise

Unwanted RF energy.

Sources:

- Microwave ovens
- Bluetooth devices
- Other APs
- Electrical equipment

# 5. Exam Traps

- Higher frequency does not mean longer range.
- 2.4 GHz has better coverage but more interference.
- 5 GHz provides higher speed but shorter range.
- 6 GHz is used by Wi-Fi 6E and Wi-Fi 7.
- Channels are frequency ranges, not separate networks.
- 2.4 GHz commonly uses channels 1, 6, and 11.
- Adjacent channel interference occurs when channels overlap.
- Co-channel interference occurs when devices share the same channel.
- GHz is a frequency measurement, not speed.
- RSSI measures signal strength.
- SNR measures signal quality.
- DFS channels are used in 5 GHz to avoid radar interference.

# 7. Practice Questions

## Question 1

Which frequency band provides the longest range?

A. 6 GHz  
B. 5 GHz  
C. 2.4 GHz  
D. 60 GHz  

### Answer: C

Explanation:

Lower frequencies travel farther and penetrate obstacles better.

---

## Question 2

Which 2.4 GHz channels are commonly non-overlapping?

A. 1, 5, 9  
B. 1, 6, 11  
C. 2, 7, 12  
D. 3, 8, 13  

### Answer: B

Explanation:

Channels 1, 6, and 11 do not overlap in most regions.

---

## Question 3

What does RSSI measure?

A. Channel width  
B. Signal strength  
C. Encryption type  
D. Data rate  

### Answer: B

Explanation:

RSSI indicates received signal strength.

---

## Question 4

Which band provides the highest number of available channels?

A. 2.4 GHz  
B. 5 GHz  
C. 6 GHz  
D. AM radio  

### Answer: C

Explanation:

6 GHz provides a large amount of new spectrum.

---

## Question 5

What causes adjacent-channel interference?

A. Same channel usage  
B. Overlapping channels  
C. Weak passwords  
D. Low transmit power  

### Answer: B

Explanation:

Adjacent-channel interference occurs when channels overlap.
