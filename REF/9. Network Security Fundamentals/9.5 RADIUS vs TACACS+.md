# 1. Overview

RADIUS and TACACS+ are AAA (Authentication, Authorization, Accounting) protocols used to centrally control access to network resources. CCNA tests their differences, transport protocols, ports, encryption methods, and common use cases.

---

# 2. Core Concepts

# AAA Reminder

AAA:

| Component | Question Answered |
|---|---|
| Authentication | Who are you? |
| Authorization | What can you do? |
| Accounting | What did you do? |

---

```
              User

```

---

# RADIUS

## Definition

RADIUS:

```
Remote Authentication Dial-In User Service
```

An open-standard AAA protocol commonly used for:

- Network access
- Wireless authentication
- VPN users

---

# RADIUS Characteristics

| Feature | Value |
|---|---|
| Protocol | RADIUS |
| Transport | UDP |
| Authentication Port | 1812 |
| Accounting Port | 1813 |
| Encryption | Password only |
| AAA Support | Yes |
| Standard | Open standard |

---

# RADIUS Operation

Example:

```
Wireless Client

      |

     AP/WLC

      |

   RADIUS Server
```

---

Steps:

1. User connects to network.
2. AP/WLC sends authentication request.
3. RADIUS checks credentials.
4. RADIUS sends accept/reject response.
5. User receives network access.

---

# RADIUS Security

RADIUS encrypts:

```
User password
```

The rest of the packet is not fully encrypted.

---

# RADIUS Uses

Common environments:

| Use Case | Example |
|---|---|
| Wireless | Enterprise Wi-Fi |
| VPN | Remote users |
| 802.1X | Network access |
| ISP authentication | Subscriber access |

---

# TACACS+

## Definition

TACACS+:

```
Terminal Access Controller Access-Control System Plus
```

A Cisco-developed AAA protocol mainly used for network device administration.

---

# TACACS+ Characteristics

| Feature | Value |
|---|---|
| Protocol | TACACS+ |
| Transport | TCP |
| Port | 49 |
| Encryption | Entire packet body |
| AAA Support | Yes |
| Vendor | Cisco |

---

# TACACS+ Operation

Example:

```
Administrator

      |

 Router/Switch

      |

 TACACS+ Server
```

---

Steps:

1. Admin connects through SSH.
2. Device sends request to TACACS+ server.
3. Server authenticates user.
4. Server checks command permissions.
5. Commands are logged.

---

# TACACS+ Security

TACACS+ encrypts:

```
Entire AAA packet body
```

Provides better confidentiality for administrative access.

---

# RADIUS vs TACACS+

| Feature | RADIUS | TACACS+ |
|---|---|---|
| Full Name | Remote Authentication Dial-In User Service | Terminal Access Controller Access-Control System Plus |
| Standard | Open standard | Cisco-developed |
| Transport | UDP | TCP |
| Port | 1812/1813 | 49 |
| Encryption | Password only | Entire packet body |
| AAA Separation | Limited | Complete |
| Authentication | Yes | Yes |
| Authorization | Yes | Yes |
| Accounting | Yes | Yes |

---

# AAA Separation Difference

## RADIUS

Combines:

```
Authentication + Authorization
```

More tightly integrated.

---

## TACACS+

Separates:

```
Authentication

Authorization

Accounting
```

Independently.

# Advantages and Disadvantages

## RADIUS

Advantages:

| Advantage | Description |
|---|---|
| Open standard | Multi-vendor support |
| Lightweight | Efficient |
| Widely supported | Wireless/VPN |

Disadvantages:

| Disadvantage | Description |
|---|---|
| Limited command authorization | Less control |
| UDP based | Less reliable than TCP |

---

## TACACS+

Advantages:

| Advantage | Description |
|---|---|
| Full AAA separation | Better control |
| Command authorization | Strong admin security |
| TCP reliability | Reliable communication |

Disadvantages:

| Disadvantage | Description |
|---|---|
| Cisco focused | Less universal |
| Mostly device administration | Not common for Wi-Fi |

# Cisco AAA Example

Enable AAA:

```bash
aaa new-model
```

---

Configure TACACS+:

```bash
tacacs server TAC1
 address ipv4 192.168.1.10
 key Cisco123
```

---

Configure RADIUS:

```bash
radius server RAD1
 address ipv4 192.168.1.20 auth-port 1812
 key Cisco123
```

# 3. Worked Examples

## Example 1: Choose Protocol

Scenario:

```
Company wants employees to authenticate to corporate Wi-Fi.
```

Need:

- 802.1X
- User authentication

Answer:

```
RADIUS
```

Reason:

RADIUS is commonly used with 802.1X.

---

# Example 2: Administrator Access Control

Scenario:

```
Network team needs different CLI permissions.
```

Need:

- Command authorization
- Command logging

Answer:

```
TACACS+
```

Reason:

TACACS+ provides granular command authorization.

---

# 4. Exam Traps

- RADIUS uses UDP.
- TACACS+ uses TCP.
- RADIUS ports are 1812 and 1813.
- TACACS+ port is 49.
- RADIUS is common for wireless and VPN authentication.
- TACACS+ is common for Cisco device administration.
- TACACS+ encrypts the entire packet body.
- RADIUS encrypts mainly the password.
- Both support AAA.
- TACACS+ provides better command-level authorization.
- 802.1X commonly uses RADIUS.
