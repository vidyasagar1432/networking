**CCNP ENCOR Relevance: Yes — AAA architecture, RADIUS/TACACS+, centralized authentication, and network device access control are important CCNP Enterprise security concepts.**

# 1. Overview

AAA (Authentication, Authorization, and Accounting) is a security framework used to control and monitor user access to network devices and services. CCNA tests the three AAA components, local vs centralized authentication, and the differences between RADIUS and TACACS+.

---

# 2. Core Concepts

# AAA Definition

AAA:

```
Authentication
Authorization
Accounting
```

A framework that provides:

- Identity verification
- Access control
- Activity tracking

---

# AAA Purpose

AAA helps organizations:

| Function | Purpose |
|---|---|
| Authentication | Verify who the user is |
| Authorization | Determine what user can do |
| Accounting | Record user activity |

# AAA Components

## Definition

Authentication answers:

```

```

It verifies user identity.

| Method | Example |
|---|---|

# 2. Authorization

## Definition

Authorization answers:

```
What are you allowed to do?
```

It determines permissions after authentication.

---

# Authorization Examples

User roles:

| User | Permission |
|---|---|
| Network Admin | Full configuration |
| Engineer | Limited commands |
| Guest | Read-only access |

---

# Authorization Example

```

```

```

```

Denied:

```

```

# 3. Accounting

## Definition

Accounting answers:

```

```

It records activities.

- Network usage

# Local AAA Advantages

|---|---|

# Local AAA Disadvantages

# RADIUS

## Definition

RADIUS:

```
Remote Authentication Dial-In User Service
```

A centralized AAA protocol.

---

# RADIUS Characteristics

| Feature | Value |
|---|---|
| Standard | Open standard |
| Transport | UDP |
| Authentication Port | 1812 |
| Accounting Port | 1813 |
| Encryption | Password encrypted |

---

# RADIUS Operation

```
Client

 |

Network Device

 |

RADIUS Server

```

Example:

```
Administrator

     |

   Router

     |

  RADIUS
```

---

# RADIUS Security

RADIUS encrypts:

```
User password
```

but not the entire communication.

---

# RADIUS Uses

Commonly used for:

- Wireless authentication
- VPN authentication
- Network access control

---

# TACACS+

## Definition

TACACS+:

```
Terminal Access Controller Access-Control System Plus
```

Cisco-developed AAA protocol.

---

# TACACS+ Characteristics

| Feature | Value |
|---|---|
| Transport | TCP |
| Port | 49 |
| Encryption | Entire packet body |
| Common use | Device administration |

---

# TACACS+ Advantages

Provides separate control of:

```
Authentication

Authorization

Accounting
```

---

# RADIUS vs TACACS+

| Feature | RADIUS | TACACS+ |
|---|---|---|
| Vendor | Open standard | Cisco |
| Transport | UDP | TCP |
| Port | 1812/1813 | 49 |
| Encryption | Password only | Packet body |
| AAA separation | Limited | Complete |
| Common use | User/network access | Device administration |

# 4. Configuration/Commands (Cisco IOS)

# Enable AAA

```bash
aaa new-model
```

---

# Create Local User

```bash
username admin privilege 15 secret Cisco123
```

---

# Configure AAA Authentication

```bash
aaa authentication login default local
```

---

# Configure RADIUS Server

```bash
radius server RADIUS1
 address ipv4 192.168.1.10 auth-port 1812
 key Cisco123
```

---

# Configure TACACS+ Server

```bash
tacacs server TACACS1
 address ipv4 192.168.1.20
 key Cisco123
```

---

# Enable AAA Authorization

```bash
aaa authorization exec default local
```

---

# Enable AAA Accounting

```bash
aaa accounting commands 15 default start-stop group tacacs+
```

---

# Verify AAA

Show AAA configuration:

```bash
show aaa servers
```

---

View users:

```bash
show users
```

# 5. Exam Traps

- Authentication = Who are you?
- Authorization = What can you do?
- Accounting = What did you do?
- RADIUS uses UDP ports 1812/1813.
- TACACS+ uses TCP port 49.
- TACACS+ encrypts the entire packet body.
- RADIUS mainly encrypts the password.
- AAA server centralizes user management.
- 802.1X commonly uses RADIUS.
- Local AAA is suitable for small networks.
- Enterprise networks usually use centralized AAA.
- AAA is not the same as ACL filtering.
