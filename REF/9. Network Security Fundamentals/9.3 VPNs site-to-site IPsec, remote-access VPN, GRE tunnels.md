# 1. Overview

A Virtual Private Network (VPN) creates a secure connection over an untrusted network such as the Internet. CCNA tests VPN types, IPsec site-to-site tunnels, remote-access VPNs, and GRE tunneling concepts.

---

# 2. Core Concepts

# VPN Definition

VPN:

```
Virtual Private Network
```

A technology that creates a private communication channel over a public network.

---

# VPN Purpose

VPNs provide:

| Function | Purpose |
|---|---|
| Confidentiality | Encrypt data |
| Integrity | Detect modification |
| Authentication | Verify endpoints |
| Secure tunneling | Carry private traffic |

---

# VPN Basic Architecture

Without VPN:

```
Site A

     Internet

Site B
```

Traffic is exposed.

---

With VPN:

```
Site A

   |

Encrypted Tunnel

   |

Internet

   |

Encrypted Tunnel

   |

Site B
```

---

# VPN Components

| Component | Function |
|---|---|
| VPN Gateway | Creates tunnel |
| Encryption | Protects data |
| Authentication | Verifies identity |
| Tunnel | Encapsulates traffic |

---

# VPN Types Overview

| Type | Purpose |
|---|---|
| Site-to-Site VPN | Connect networks |
| Remote-Access VPN | Connect users |
| GRE Tunnel | Encapsulate traffic |
| IPsec VPN | Secure encryption |

---

# 1. Site-to-Site IPsec VPN

## Definition

A site-to-site VPN connects two or more networks securely through an encrypted tunnel.

---

# Site-to-Site Architecture

```
Branch Office

LAN A

  |

VPN Router

  |

==== IPsec Tunnel ====

  |

VPN Router

  |

LAN B

Head Office
```

---

# Site-to-Site Characteristics

| Feature | Description |
|---|---|
| Connects | Network to network |
| Users | Multiple devices |
| Encryption | IPsec |
| Endpoint | VPN routers/firewalls |
| Common use | Branch connectivity |

---

# Site-to-Site Example

Company:

```
Headquarters
+
Branch Office
```

Need:

```
Secure communication
```

Solution:

```
IPsec Site-to-Site VPN
```

---

# IPsec (Internet Protocol Security)

IPsec provides:

- Authentication
- Integrity
- Encryption

Works at:

```
Layer 3 (Network Layer)
```

---

# IPsec Security Services

| Service | Purpose |
|---|---|
| Authentication | Verify sender |
| Integrity | Detect changes |
| Confidentiality | Encrypt data |
| Anti-replay | Prevent duplicate packets |

---

# IPsec Protocols

## AH (Authentication Header)

Provides:

- Authentication
- Integrity

Does NOT provide:

```
Encryption
```

Protocol number:

```
51
```

---

## ESP (Encapsulating Security Payload)

Provides:

- Encryption
- Authentication
- Integrity

Protocol number:

```
50
```

Most commonly used.

---

# IPsec Modes

## Transport Mode

Protects:

```
Payload only
```

Used mainly:

```
Host-to-host
```

---

## Tunnel Mode

Protects:

```
Entire original IP packet
```

Used for:

```
Site-to-site VPN
```

---

# Transport vs Tunnel Mode

| Feature | Transport | Tunnel |
|---|---|---|
| Encryption | Payload | Entire packet |
| Header | Original IP header remains | New IP header added |
| Use | Host communication | VPN gateways |
| Common use | Less common | Site-to-site VPN |

---

# IPsec Tunnel Example

Original packet:

```
Private IP Packet
```

After encryption:

```
New IP Header

+

Encrypted Original Packet
```

---

# IPsec Components

## IKE

IKE:

```
Internet Key Exchange
```

Purpose:

- Authenticate peers
- Negotiate security parameters
- Create keys

---

# IKE Versions

| Version | Description |
|---|---|
| IKEv1 | Older |
| IKEv2 | Modern |

---

# Security Association (SA)

SA:

```
Agreement between VPN peers.
```

Contains:

- Encryption algorithm
- Authentication method
- Keys
- Lifetime

---

# IPsec Encryption Algorithms

| Algorithm | Security |
|---|---|
| DES | Weak |
| 3DES | Older |
| AES | Recommended |

---

# IPsec Authentication

Methods:

| Method | Description |
|---|---|
| Pre-shared key | Shared secret |
| Digital certificate | PKI-based |

# 3. GRE Tunnel

## Definition

GRE:

```
Generic Routing Encapsulation
```

A tunneling protocol used to encapsulate one protocol inside another.

---

# GRE Operation

Original packet:

```
IP Packet
```

GRE adds:

```
GRE Header

+

New IP Header
```

---

# GRE Architecture

```
Router A

   |

 GRE Tunnel

   |

Router B
```

---

# GRE Characteristics

| Feature | Description |
|---|---|
| Encryption | No |
| Authentication | No |
| Multicast support | Yes |
| Protocol | IP protocol 47 |
| Layer | Layer 3 tunnel |

---

# GRE Advantages

- Supports multicast
- Supports routing protocols
- Simple configuration
- Works across different networks

---

# GRE Disadvantages

- No encryption
- Adds overhead
- Requires IPsec for security

---

# GRE + IPsec

Common enterprise design:

```
GRE

+

IPsec
```

---

# Why Combine GRE and IPsec?

GRE provides:

- Tunneling
- Multicast support

IPsec provides:

- Encryption
- Security

---

# GRE over IPsec Architecture

```
Routing Protocol

      |

     GRE

      |

    IPsec

      |

 Internet
```

---

# VPN Technology Comparison

| Feature | IPsec VPN | GRE | Remote VPN |
|---|---|---|---|
| Encryption | Yes | No | Usually yes |
| Authentication | Yes | No | Yes |
| Tunnel | Yes | Yes | Yes |
| Multicast | Limited | Yes | Depends |
| Main use | Secure WAN | Routing tunnels | Users |

---

# VPN Security Comparison

| Technology | Security |
|---|---|
| GRE | No encryption |
| IPsec | Strong encryption |
| GRE + IPsec | Secure + routing support |
| SSL VPN | Secure remote access |

Router A:

```bash
interface tunnel 0
 ip address 10.10.10.1 255.255.255.252
 tunnel source g0/0
 tunnel destination 203.0.113.2
```

```bash
interface tunnel 0

 tunnel source g0/0
 tunnel destination 203.0.113.1
```

```bash
show interface tunnel 0
```

```bash
show ip interface brief
```

```bash
show crypto isakmp sa
```


# 5. Exam Traps

- IPsec provides encryption; GRE does not.
- GRE protocol number is 47.
- ESP protocol number is 50.
- AH protocol number is 51.
- Site-to-site VPN connects networks.
- Remote-access VPN connects individual users.
- IPsec works at Layer 3.
- GRE supports multicast and routing protocols.
- GRE is often combined with IPsec.
- Tunnel mode is commonly used for site-to-site VPNs.
- Transport mode protects only the payload.
- IKE negotiates IPsec security parameters.
- VPN gateways terminate tunnels.
