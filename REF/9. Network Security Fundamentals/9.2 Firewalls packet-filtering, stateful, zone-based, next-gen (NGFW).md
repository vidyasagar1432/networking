# 1. Overview

A firewall is a network security device that controls traffic flow between networks based on security rules. CCNA tests different firewall types, traffic inspection methods, security zones, and the differences between traditional firewalls and next-generation firewalls.

---

# 2. Core Concepts

# Firewall Definition

Firewall:

```
A security device that monitors and controls network traffic based on defined security policies.
```

---

# Firewall Purpose

Firewalls provide:

| Function | Purpose |
|---|---|
| Traffic filtering | Allow or block packets |
| Access control | Restrict communication |
| Threat prevention | Detect malicious traffic |
| Network segmentation | Separate security zones |
| Logging | Record network activity |

---

# Firewall Placement

Typical location:

```
Internet

   |

 Firewall

   |

Internal Network
```

---

# Firewall Traffic Decision

A firewall checks:

- Source address
- Destination address
- Protocol
- Port number
- Connection state
- Application data

Decision:

```
Permit

or

Deny
```

# Firewall Evolution

```

        |
```

# 1. Packet-Filtering Firewall

## Definition

A packet-filtering firewall examines individual packets using Layer 3 and Layer 4 information.

---

# Packet Filtering Checks

| Field | Example |
|---|---|
| Source IP | 192.168.1.10 |
| Destination IP | 8.8.8.8 |
| Protocol | TCP/UDP/ICMP |
| Source Port | 50000 |
| Destination Port | 443 |

---

# Packet Filtering Operation

Example:

```
Packet:

Source:
192.168.1.10

Destination:
8.8.8.8

Port:
443
```

Firewall rule:

```
Allow HTTPS
```

Result:

```
Permit
```

---

# Packet Filtering Characteristics

| Feature | Description |
|---|---|
| OSI Layers | Layer 3/4 |
| Inspection | Individual packets |
| Connection awareness | No |
| Speed | Fast |
| Security | Basic |

---

# Packet Filtering Advantages

- Simple
- Fast
- Low resource usage
- Easy implementation

---

# Packet Filtering Disadvantages

- No session awareness
- Cannot inspect applications
- Limited security

---

# 2. Stateful Firewall

## Definition

A stateful firewall tracks active network connections.

---

# Stateful Inspection

Unlike packet filtering:

```
Packet-by-packet decision
```

Stateful firewall:

```
Understands the conversation
```

---

# Connection Table

A stateful firewall maintains:

```
State Table
```

Example:

| Source | Destination | State |
|---|---|---|
| 10.1.1.10 | 8.8.8.8 | ESTABLISHED |

---

# TCP Stateful Example

Client sends:

```
SYN
```

Firewall records:

```
New connection
```

Server replies:

```
SYN-ACK
```

Firewall allows because:

```
Existing session
```

---

# Stateful Firewall Characteristics

| Feature | Description |
|---|---|
| OSI Layers | 3/4 mainly |
| Connection tracking | Yes |
| Session table | Yes |
| Security | Higher |
| Performance | Good |

---

# Stateful vs Packet Filtering

| Feature | Packet Filtering | Stateful |
|---|---|---|
| Packet inspection | Yes | Yes |
| Session tracking | No | Yes |
| Dynamic decisions | No | Yes |
| Security | Lower | Higher |

---

# 3. Zone-Based Firewall (ZBF)

## Definition

Zone-Based Firewall is a Cisco IOS firewall feature that controls traffic between security zones.

---

# Security Zones

A zone is:

```
A logical grouping of interfaces with similar security requirements.
```

---

# Example Zones

```
Internet Zone

      |

 Firewall

      |

Inside Zone
```

---

# Common Zones

| Zone | Purpose |
|---|---|
| Inside | Trusted network |
| Outside | Internet/untrusted |
| DMZ | Public servers |

---

# Zone-Based Firewall Architecture

Example:

```
          Outside

             |

          Firewall

             |

          Inside

             |

          Users
```

---

# Zone Pair

Traffic policy is applied between:

```
Source Zone → Destination Zone
```

Example:

```
Inside → Outside
```

---

# Zone-Based Firewall Rules

Example:

Allow:

```
Inside users → Internet
```

Block:

```
Internet → Inside
```

---

# ZBF Characteristics

| Feature | Description |
|---|---|
| Security model | Zone-based |
| Policy control | Zone pairs |
| Cisco IOS feature | Yes |
| Inspection | Stateful |

---

# 4. Next-Generation Firewall (NGFW)

## Definition

NGFW is an advanced firewall that combines traditional firewall functions with application and threat inspection.

---

# NGFW Capabilities

| Feature | Purpose |
|---|---|
| Stateful inspection | Track connections |
| Application awareness | Identify applications |
| Deep Packet Inspection | Inspect packet content |
| IPS | Detect attacks |
| URL filtering | Control websites |
| Malware detection | Block threats |
| SSL inspection | Inspect encrypted traffic |

---

# Traditional Firewall vs NGFW

| Feature | Traditional Firewall | NGFW |
|---|---|---|
| IP filtering | Yes | Yes |
| Port filtering | Yes | Yes |
| Stateful inspection | Yes | Yes |
| Application control | Limited | Yes |
| IPS | No/Limited | Yes |
| Malware detection | No | Yes |
| Deep inspection | No | Yes |

---

# Application Awareness

Traditional firewall:

```
Allow TCP 443
```

Problem:

Any HTTPS application allowed.

---

NGFW:

Can identify:

```
YouTube
Facebook
Malware traffic
Cloud applications
```

---

# Deep Packet Inspection (DPI)

DPI examines:

```
Packet headers

+

Packet content
```

Allows advanced threat detection.

---

# Intrusion Prevention System (IPS)

IPS:

```
Detects and blocks malicious activity.
```

Examples:

- Exploit attempts
- Malware communication
- Attacks

---

# Firewall Type Comparison

| Feature | Packet Filtering | Stateful | ZBF | NGFW |
|---|---|---|---|---|
| IP filtering | Yes | Yes | Yes | Yes |
| Port filtering | Yes | Yes | Yes | Yes |
| Session tracking | No | Yes | Yes | Yes |
| Zones | No | No | Yes | Yes |
| Application control | No | Limited | Limited | Yes |
| IPS | No | No | No | Yes |
| DPI | No | No | No | Yes |

# 4. Configuration/Commands (Cisco ZBF)

## Create Zone

```bash
zone security INSIDE
```

---

## Assign Interface to Zone

```bash
interface g0/0
 zone-member security INSIDE
```

---

## Create Class Map

```bash
class-map type inspect HTTP_TRAFFIC
 match protocol http
```

---

## Create Policy Map

```bash
policy-map type inspect INSPECT_POLICY
 class type inspect HTTP_TRAFFIC
  inspect
```

---

## Create Zone Pair

```bash
zone-pair security INSIDE-OUTSIDE source INSIDE destination OUTSIDE
```

---

## Apply Policy

```bash
service-policy type inspect INSPECT_POLICY
```

---

# Verify Firewall

```bash
show policy-map control-plane
```

# 5. Exam Traps

- Packet filtering does not track sessions.
- Stateful firewalls maintain connection tables.
- Zone-based firewalls apply policies between zones.
- NGFW provides application awareness.
- NGFW can perform deep packet inspection.
- IPS is commonly integrated into NGFW.
- A DMZ is a separate security zone for public services.
- Firewalls usually block traffic by default unless permitted.
- Stateful firewalls understand TCP sessions.
- ACLs filter traffic but do not provide full firewall capabilities.
- NGFW can identify applications, not just ports.
- HTTPS port 443 alone does not identify the application.
