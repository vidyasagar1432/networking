# 1. Overview

Peer-to-peer communication in networking describes how the same layers of two different systems communicate logically with each other. CCNA tests this concept because protocols operate between corresponding layers while actual data travels down and up the network stack through encapsulation and de-encapsulation.

---

# 2. Core Concepts

# What is Peer-to-Peer Communication?

## Definition

Peer-to-peer communication means that each layer on one device communicates with the same layer on another device using agreed protocols and rules.

Example:

```
Host A                         Host B

Application  <-------------->  Application

Transport    <-------------->  Transport

Network      <-------------->  Network

Data Link    <-------------->  Data Link

Physical     <-------------->  Physical
```

---

# Important Concept

The communication is:

```
Logical between same layers
```

but:

```
Physical transmission occurs through lower layers
```

---

# Real Data Flow

Two computers communicating:

```
Sender                          Receiver

Application                     Application
      |                              ^
      |                              |
Transport                       Transport
      |                              ^
      |                              |

      |                              ^
      |                              |

      |                              ^
      |                              |

```

# Peer-to-Peer vs Actual Transmission

| Concept | Meaning |
|---|---|
| Peer communication | Logical layer-to-layer communication |
| Actual transmission | Data moves through physical media |
| Encapsulation | Adds information while sending |
| De-encapsulation | Removes information while receiving |

# 3. Worked Examples

## Example 1: Identify Peer Layer

### Scenario

A browser sends an HTTPS request to a web server.

Question:

Which layers communicate as peers?

### Solution

Step 1:

Browser and web server use HTTP/HTTPS.

```
Application ↔ Application
```

Step 2:

The connection uses TCP.

```
Transport ↔ Transport
```

Step 3:

Data uses IP.

```
Network ↔ Network
```

Answer:

```
Each layer communicates with its matching layer.
```

---

## Example 2: Identify Address Changes

### Scenario

A packet crosses three routers.

Question:

Which information changes?

### Solution

Step 1:

IP identifies end devices.

```
Source IP → Destination IP
```

Usually unchanged.

Step 2:

MAC identifies local delivery.

Each hop creates a new frame.

Answer:

```
MAC addresses change.
IP addresses remain end-to-end.
```

# 5. Exam Traps

- Peer-to-peer communication does not mean every device is a P2P network.
- It means same OSI layers communicate logically.
- Application does not directly send bits to another application.
- Data must travel through lower layers first.
- Routers communicate at Layer 3 using IP.
- Switches communicate at Layer 2 using frames.
- MAC addresses are hop-by-hop.
- IP addresses are end-to-end.
- Encapsulation happens at the sender.
- De-encapsulation happens at the receiver.

# 7. Practice Questions

## Question 1

In the OSI model, which layers communicate logically with their equivalent layers on another device?

A. Only Physical layer  
B. Only Network layer  
C. All layers  
D. Only Application layer  

### Answer: C. All layers

Explanation:

Each OSI layer communicates with its peer layer using defined protocols.

---

## Question 2

Which address changes at every router hop?

A. IP address  
B. MAC address  
C. Port number  
D. URL  

### Answer: B. MAC address

Explanation:

Each hop creates a new Layer 2 frame.

---

## Question 3

A TCP connection is an example of peer communication at which layer?

A. Layer 1  
B. Layer 2  
C. Layer 3  
D. Layer 4  

### Answer: D. Layer 4

Explanation:

TCP operates at the Transport layer.

---

## Question 4

What happens during encapsulation?

A. Headers are removed  
B. Data is encrypted only  
C. Headers and trailers are added  
D. Packets are deleted  

### Answer: C. Headers and trailers are added

Explanation:

Encapsulation prepares data for transmission.

---

## Question 5

Which statement is correct?

A. Applications communicate directly using electrical signals  
B. Peer communication is physical only  
C. Layers communicate logically while data travels physically  
D. Routers use MAC addresses for end-to-end communication  

### Answer: C. Layers communicate logically while data travels physically

Explanation:

Peer communication is logical; actual transmission uses the network stack.
