# 1. Overview

Encapsulation and de-encapsulation describe how data is prepared for transmission and processed when received across a network. CCNA tests these concepts because they explain PDU changes, headers/trailers, protocol operation, and troubleshooting with tools like Wireshark.

---

# 2. Core Concepts

# Encapsulation

## Definition

Encapsulation is the process of adding protocol information (headers and trailers) to data as it moves down the OSI or TCP/IP layers before transmission.

Sender process:

```
Application
      |
      v
Data
      |
Transport
      |
Segment
      |
Network
      |
Packet
      |
Data Link
      |
Frame
      |
Physical
      |
Bits
```

---

# De-Encapsulation

## Definition

De-encapsulation is the reverse process where receiving devices remove headers and trailers as data moves upward through the OSI/TCP/IP layers.

Receiver process:

```
Bits
 |
Frame
 |
Packet
 |
Segment
 |
Data
```

---

# Encapsulation vs De-Encapsulation

| Feature | Encapsulation | De-Encapsulation |
|---|---|---|
| Direction | Upper layers → Lower layers | Lower layers → Upper layers |
| Location | Sending device | Receiving device |
| Action | Adds headers/trailers | Removes headers/trailers |
| Purpose | Prepare data for transmission | Deliver data to application |

---

# PDU Changes During Encapsulation

| OSI Layer | Action | PDU |
|---|---|---|
| Layer 7 Application | Creates user data | Data |
| Layer 6 Presentation | Formats/encrypts data | Data |
| Layer 5 Session | Creates session information | Data |
| Layer 4 Transport | Adds TCP/UDP header | Segment/Datagram |
| Layer 3 Network | Adds IP header | Packet |
| Layer 2 Data Link | Adds MAC header + FCS trailer | Frame |
| Layer 1 Physical | Converts frame into signals | Bits |

# Header and Trailer Addition

## Transport Layer

Adds:

```
TCP/UDP Header
```

Contains:

| Field | Purpose |
|---|---|
| Source Port | Sending application |
| Destination Port | Receiving application |
| Sequence Number (TCP) | Ordering data |
| Acknowledgment Number (TCP) | Reliability |

Example:

```
Application Data
        +
 TCP Header
        =
 TCP Segment
```

---

# Network Layer

Adds:

```
IP Header
```

Contains:

| Field | Purpose |
|---|---|
| Source IP Address | Sender identity |
| Destination IP Address | Receiver identity |
| TTL | Prevents routing loops |
| Protocol | Identifies upper-layer protocol |

Example:

```
TCP Segment
      +
 IP Header
      =
 IP Packet
```

---

# Data Link Layer

Adds:

```
Ethernet Header + FCS Trailer
```

Contains:

| Field | Purpose |
|---|---|
| Source MAC | Sending device |
| Destination MAC | Next-hop device |
| FCS | Error detection |

Example:

```
IP Packet
     +
Ethernet Header
     +
FCS
     =
Ethernet Frame
```

---

# Physical Layer

Converts:

```
Frame → Bits
```

Transmission media:

| Medium | Signal |
|---|---|
| Copper | Electrical signals |
| Fiber | Light pulses |
| Wireless | Radio waves |

# End-to-End vs Hop-by-Hop Communication

## Layer 3 IP Address

End-to-end:

```
Source IP
        ↓
Destination IP
```

Usually remains unchanged across routers.

---

## Layer 2 MAC Address

Hop-by-hop:

```
PC
 ↓
Router
 ↓
Router
 ↓
Server
```

MAC addresses change at every hop.

---

# Example Across a Router

Before Router:

```
Source MAC:
PC MAC

Destination MAC:
Router MAC

Source IP:
PC IP

Destination IP:
Server IP
```

After Router:

```
Source MAC:
Router MAC

Destination MAC:
Next Hop MAC

Source IP:
PC IP

Destination IP:
Server IP
```

# 3. Worked Examples

## Example 1: Identify PDU at Each Layer

### Scenario

A computer sends an HTTPS request.

Find the PDU at each layer.

### Solution

Application:

```
HTTPS Data
```

Transport:

```
TCP Segment
```

Network:

```
IP Packet
```

Data Link:

```
Ethernet Frame
```

Physical:

```
Bits
```

Answer:

```
Data → Segment → Packet → Frame → Bits
```

---

## Example 2: MAC Address Change Through Router

### Scenario

PC-A sends traffic to Server-B through Router-R.

Question:

Which addresses change at the router?

### Solution

Step 1:

IP addresses identify the final source and destination.

```
Source IP → Destination IP
```

Remain unchanged.

Step 2:

MAC addresses identify local delivery.

Router creates a new Layer 2 frame.

Answer:

```
MAC addresses change
IP addresses remain the same
```

# 5. Exam Traps

- Encapsulation adds information; de-encapsulation removes information.
- Headers are added at Layers 4, 3, and 2.
- Trailer (FCS) is added only at Layer 2.
- Layer 4 adds port numbers.
- Layer 3 adds IP addresses.
- Layer 2 adds MAC addresses.
- MAC addresses change at every router hop.
- IP addresses normally remain end-to-end.
- Physical layer does not create headers.
- TCP PDU is a segment.
- UDP PDU is a datagram.
- Network layer PDU is a packet.
- Data Link layer PDU is a frame.

# 7. Practice Questions

## Question 1

Which layer adds port numbers?

A. Layer 1  
B. Layer 2  
C. Layer 3  
D. Layer 4  

### Answer: D. Layer 4

Explanation:

Transport layer uses TCP/UDP ports.

---

## Question 2

Which layer adds the FCS trailer?

A. Physical  
B. Data Link  
C. Network  
D. Transport  

### Answer: B. Data Link

Explanation:

Ethernet frames include an FCS field for error detection.

---

## Question 3

What is the correct encapsulation order?

A. Data → Packet → Segment → Frame → Bits  
B. Data → Segment → Packet → Frame → Bits  
C. Frame → Packet → Segment → Data → Bits  
D. Bits → Frame → Packet → Data → Segment  

### Answer: B. Data → Segment → Packet → Frame → Bits

Explanation:

Data moves downward through layers during transmission.

---

## Question 4

Which address changes at every router hop?

A. IP address  
B. MAC address  
C. Port number  
D. Application address  

### Answer: B. MAC address

Explanation:

Each local network uses different Layer 2 addressing.

---

## Question 5

A router operates mainly at which encapsulation layer?

A. Layer 1  
B. Layer 2  
C. Layer 3  
D. Layer 7  

### Answer: C. Layer 3

Explanation:

Routers forward packets using IP addresses.
