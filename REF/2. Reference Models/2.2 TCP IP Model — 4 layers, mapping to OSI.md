# 1. Overview

The TCP/IP (Transmission Control Protocol/Internet Protocol) model is the protocol suite used by the Internet and modern IP networks. CCNA tests the TCP/IP model because it explains how real-world protocols communicate, how data is encapsulated, and how it maps to the OSI reference model.

---

# 2. Core Concepts

# TCP/IP Model Overview

| TCP/IP Layer | Primary Function | OSI Mapping | PDU |
|---|---|---|---|
| Application | Network services for applications | OSI Layers 7, 6, 5 | Data |
| Transport | End-to-end communication | OSI Layer 4 | Segment (TCP) / Datagram (UDP) |
| Internet | Logical addressing and routing | OSI Layer 3 | Packet |
| Network Access | Physical transmission and framing | OSI Layers 2, 1 | Frame / Bits |

---

# TCP/IP Layer 4 — Application

## Function

Provides network services directly to user applications.

Unlike the OSI model, the TCP/IP Application layer combines the functions of:

- Application Layer
- Presentation Layer
- Session Layer

|---|---|

| Data formatting | Character encoding |
| Encryption | SSL/TLS |

# 3. Worked Examples

## Example 1: Identify the TCP/IP Layer

### Scenario

A router receives an IPv4 packet and determines the best path to the destination network.

### Solution

Step 1:
- The router examines the destination IP address.

Step 2:
- Routing decisions use logical addressing.

Step 3:
- Logical addressing belongs to the Internet layer.

**Answer:**

```
Internet Layer
```

---

## Example 2: Map OSI Layers to TCP/IP

### Scenario

Identify which TCP/IP layer corresponds to the following OSI layers:

- Application
- Presentation
- Session

### Solution

Step 1:
- OSI Layers 7, 6, and 5 provide application-related services.

Step 2:
- TCP/IP combines these functions into one layer.

**Answer:**

```
TCP/IP Application Layer
```

# 5. Exam Traps

- TCP/IP has **4 layers**, not 5 or 7.
- OSI Layers **5, 6, and 7** are combined into the TCP/IP **Application** layer.
- OSI Layers **1 and 2** are combined into the TCP/IP **Network Access** layer.
- TCP and UDP belong to the **Transport** layer.
- IPv4 and IPv6 belong to the **Internet** layer.
- Ethernet and Wi-Fi belong to the **Network Access** layer.
- Routers operate primarily at the **Internet** layer.
- Switches primarily operate at the **Network Access** layer.
- The TCP/IP model is the **real-world implementation model**; the OSI model is a **reference model**.

# 7. Practice Questions

## Question 1

Which TCP/IP layer is responsible for routing packets?

A. Application  
B. Transport  
C. Internet  
D. Network Access

### Answer: C. Internet

**Explanation:**

The Internet layer provides logical addressing and routing using IP.

---

## Question 2

Which OSI layers map to the TCP/IP Application layer?

A. Layers 1–3

B. Layers 2–4

C. Layers 5–7

D. Layers 3–5

### Answer: C. Layers 5–7

**Explanation:**

The TCP/IP Application layer combines the OSI Application, Presentation, and Session layers.

---

## Question 3

Which protocol belongs to the TCP/IP Transport layer?

A. IPv4

B. Ethernet

C. TCP

D. ARP

### Answer: C. TCP

**Explanation:**

TCP provides reliable end-to-end communication at the Transport layer.

---

## Question 4

Which TCP/IP layer uses MAC addresses?

A. Application

B. Transport

C. Internet

D. Network Access

### Answer: D. Network Access

**Explanation:**

The Network Access layer handles framing and hardware (MAC) addressing.

---

## Question 5

What is the PDU of the Internet layer?

A. Frame

B. Segment

C. Packet

D. Data

### Answer: C. Packet

**Explanation:**

The Internet layer encapsulates data into IP packets before forwarding.
