# 1. Overview

Duplex defines how devices send and receive data over a network link. CCNA tests half/full duplex operation, auto-negotiation, and speed/duplex mismatches because incorrect settings can cause collisions, errors, and poor network performance.

---

# 2. Core Concepts

# What is Duplex?

## Definition

Duplex describes the direction of data transmission between two devices.

Types:

| Type | Communication |
|---|---|
| Half-duplex | One direction at a time |
| Full-duplex | Both directions simultaneously |

---

# Half-Duplex

## Operation

Only one device can transmit at a time.

```
Device A  -------->  Device B

Device B  -------->  Device A
```

Not simultaneous.

---

## Characteristics

| Feature | Half-Duplex |
|---|---|
| Transmission | One direction at a time |
| Collisions | Possible |
| Collision detection | Required |
| CSMA/CD | Used |
| Performance | Lower |
| Example | Hub networks |

---

# Full-Duplex

## Operation

Both devices transmit and receive at the same time.

```
Device A  <========>  Device B
```

---

## Characteristics

| Feature | Full-Duplex |
|---|---|
| Transmission | Both directions simultaneously |
| Collisions | None |
| CSMA/CD | Not required |
| Performance | Higher |
| Example | Modern switches |

---

# Half vs Full Duplex Comparison

| Feature | Half-Duplex | Full-Duplex |
|---|---|---|
| Data direction | One at a time | Both directions |
| Collision possibility | Yes | No |
| Media usage | Shared | Dedicated |
| CSMA/CD | Required | Disabled |
| Speed | Lower | Higher |
| Common device | Hub | Switch |

---

# Collision Domain Relationship

## Hub Network

```
PC1
 |
Hub
 |
PC2
 |
PC3
```

Characteristics:

- One collision domain
- Half-duplex
- All devices share bandwidth

---

## Switch Network

```
PC1
 |
Switch
 |
PC2
```

Characteristics:

- Each port is a separate collision domain
- Full-duplex
- Dedicated bandwidth

# Ethernet Duplex Modes

| Ethernet Type | Duplex |
|---|---|
| 10BASE-T | Half/Full |
| 100BASE-TX | Half/Full |
| 1000BASE-T | Full only (normally) |
| 10GBASE-T | Full only |

---

# Auto-Negotiation

## Definition

Auto-negotiation allows two Ethernet devices to automatically agree on:

- Speed
- Duplex mode

---

# Auto-Negotiation Process

Example:

```
Switch
Speed: 1 Gbps
Duplex: Full

        Negotiation

PC
Speed: 1 Gbps
Duplex: Full
```

Both devices select the highest common capability.

---

# Negotiation Rules

| Device A | Device B | Result |
|---|---|---|
| Auto | Auto | Best match selected |
| Full | Auto | Usually full |
| Half | Auto | Half |
| Full | Full | Full |
| Different forced settings | Mismatch |

---

# Speed Settings

Common Ethernet speeds:

| Speed | Name |
|---|---|
| 10 Mbps | Ethernet |
| 100 Mbps | Fast Ethernet |
| 1000 Mbps | Gigabit Ethernet |
| 10 Gbps | 10 Gigabit Ethernet |

---

# Duplex Mismatch

## Definition

A duplex mismatch occurs when two connected devices have different duplex settings.

Example:

```
Switch:
100 Mbps Full

PC:
100 Mbps Half
```

---

# Causes of Duplex Mismatch

| Cause | Example |
|---|---|
| Manual configuration | One side forced full |
| Auto-negotiation failure | Different settings |
| Old equipment | Legacy devices |
| Incorrect troubleshooting | Changing only one side |

---

# Duplex Mismatch Symptoms

| Symptom | Cause |
|---|---|
| Slow network | Retransmissions |
| CRC errors | Frame corruption |
| Late collisions | Duplex mismatch |
| Interface errors | Incorrect settings |
| Poor throughput | Collision problems |

---

# Common Error Counters

| Error | Meaning |
|---|---|
| CRC errors | Damaged frames |
| Input errors | Receive problems |
| Late collisions | Duplex mismatch indicator |
| Runts | Small corrupted frames |
| Giants | Oversized frames |

---

# Speed Mismatch

## Definition

Speed mismatch occurs when connected devices operate at different speeds.

Example:

```
Switch:
1000 Mbps

PC:
100 Mbps
```

---

# Speed Mismatch Examples

| Device A | Device B | Result |
|---|---|---|
| 1 Gbps | 1 Gbps | Normal |
| 100 Mbps | 1 Gbps | Negotiates 100 Mbps |
| Forced 1 Gbps | Auto 100 Mbps | Possible failure |

---

# Best Practice Configuration

Recommended:

```
Both sides:
Auto speed
Auto duplex
```

or:

```
Both sides:
Same manual speed
Same duplex
```

# Configure Speed

```bash
interface gigabitEthernet 0/1
 speed 100
```

Explanation:

```bash
interface gigabitEthernet 0/1
```

Enters interface configuration.

```bash
speed 100
```

Sets interface speed to 100 Mbps.

---

# Configure Duplex

```bash
interface gigabitEthernet 0/1
 duplex full
```

Explanation:

```bash
duplex full
```

Forces full-duplex operation.

---

# Enable Auto Negotiation

```bash
interface gigabitEthernet 0/1
 speed auto
 duplex auto
```

Explanation:

```bash
speed auto
```

Allows automatic speed selection.

```bash
duplex auto
```

Allows automatic duplex selection.

# 3. Worked Examples

## Example 1: Identify Duplex Mismatch

### Scenario

A switch port shows:

```
Speed: 100 Mbps
Duplex: Full
```

PC NIC shows:

```
Speed: 100 Mbps
Duplex: Half
```

What problem exists?

---

### Solution

Step 1:

Compare speed:

```
100 Mbps = 100 Mbps
```

Speed matches.

Step 2:

Compare duplex:

```
Full ≠ Half
```

Step 3:

Result:

```
Duplex mismatch
```

Symptoms:

- Slow performance
- Late collisions
- Errors

# 5. Exam Traps

- Full-duplex does not use CSMA/CD.
- Half-duplex can have collisions.
- Modern switched Ethernet normally uses full-duplex.
- Hubs operate half-duplex.
- Switch ports normally operate full-duplex.
- A duplex mismatch is more common than a speed mismatch.
- Auto-negotiation works only when both sides participate correctly.
- Forcing one side to full and leaving the other side auto can cause issues.
- Gigabit Ethernet normally requires full-duplex.
- CRC errors and late collisions can indicate duplex problems.

# 7. Practice Questions

## Question 1

Which duplex mode allows simultaneous transmission and reception?

A. Half-duplex  
B. Full-duplex  
C. Simplex  
D. Broadcast  

### Answer: B. Full-duplex

Explanation:

Full-duplex supports two-way communication at the same time.

---

## Question 2

Which device traditionally uses half-duplex?

A. Switch  
B. Router interface  
C. Hub  
D. Fiber switch  

### Answer: C. Hub

Explanation:

Hubs create shared collision domains.

---

## Question 3

What is a common symptom of duplex mismatch?

A. Faster speed  
B. Late collisions  
C. More bandwidth  
D. Lower latency only  

### Answer: B. Late collisions

Explanation:

Late collisions are a common indicator of duplex problems.

---

## Question 4

Which command displays interface speed and duplex information?

A. show vlan  
B. show interfaces status  
C. show ip route  
D. show arp  

### Answer: B. show interfaces status

Explanation:

It displays port speed and duplex state.

---

## Question 5

What is the recommended Ethernet configuration today?

A. Half duplex everywhere  
B. Manual mismatch settings  
C. Auto speed and auto duplex  
D. Disable negotiation  

### Answer: C. Auto speed and auto duplex

Explanation:

Modern devices use auto-negotiation for reliable operation.
