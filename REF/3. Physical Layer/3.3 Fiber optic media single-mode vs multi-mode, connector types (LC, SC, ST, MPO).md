# 1. Overview

Fiber optic media uses pulses of light to transmit data through glass or plastic fibers, providing high bandwidth and long-distance communication. CCNA tests fiber types, connector identification, wavelength usage, and when to choose single-mode versus multi-mode fiber.

---

# 2. Core Concepts

# Fiber Optic Cable Overview

| Feature | Description |
|---|---|
| Transmission method | Light pulses |
| Medium | Glass or plastic fiber |
| Signal type | Optical |
| Interference | Immune to EMI/RFI |
| Distance | Longer than copper |
| Bandwidth | Higher than copper |
| Common use | Backbone, WAN, data centers |

# Fiber Types

Two major categories:

| Type | Abbreviation |
|---|---|
| Single-Mode Fiber | SMF |
| Multi-Mode Fiber | MMF |

---

# Single-Mode Fiber (SMF)

## Characteristics

Single-mode fiber carries one light path through a very small core.

```
One light ray
================>
```

---

## SMF Specifications

| Feature | Value |
|---|---|
| Core size | ~9 microns |
| Light source | Laser |
| Wavelength | 1310 nm / 1550 nm |
| Distance | Long distance |
| Bandwidth | Very high |
| Cost | Higher |
| Common use | WAN, ISP, backbone |

---

# SMF Advantages

| Advantage | Explanation |
|---|---|
| Long distance | Low signal loss |
| High bandwidth | Supports high speeds |
| Low dispersion | Less signal spreading |
| Future-ready | Supports upgrades |

---

# SMF Disadvantages

| Disadvantage | Explanation |
|---|---|
| Higher cost | More expensive optics |
| Precise installation | Small core alignment required |

---

# Multi-Mode Fiber (MMF)

## Characteristics

Multi-mode fiber allows multiple light paths.

```
Multiple light rays
===================>
```

---

## MMF Specifications

| Feature | Value |
|---|---|
| Core size | 50 or 62.5 microns |
| Light source | LED or VCSEL |
| Wavelength | 850 nm / 1300 nm |
| Distance | Shorter distance |
| Bandwidth | High |
| Cost | Lower |
| Common use | LAN, data centers |

---

# MMF Types

| Type | Core Size | Common Use |

# SMF vs MMF Comparison

| Feature | Single-Mode (SMF) | Multi-Mode (MMF) |
|---|---|---|
| Core size | ~9 µm | 50/62.5 µm |

| Light source | Laser | LED/VCSEL |
| Distance | Long | Short |
| Bandwidth | Higher | Lower |
| Cost | Higher | Lower |
| Installation | More difficult | Easier |
| Common use | WAN/backbone | LAN/data center |

# 4. Configuration/Commands (if applicable)

Fiber itself has no IOS configuration, but these commands verify fiber interfaces.

---

## Check Interface Status

```bash
show interfaces status
```

Purpose:

- Shows connected ports.
- Displays speed and status.

---

## Check Transceiver Information

```bash
show interfaces transceiver
```

Purpose:

Displays:

- SFP information
- Optical power levels
- Module details

---

## View Interface Details

```bash
show interfaces gigabitEthernet 0/1
```

Purpose:

Checks:

- Errors
- Speed
- Duplex
- Link status

---

## Enable Interface

```bash
interface gigabitEthernet 0/1
no shutdown
```

Purpose:

Activates the fiber interface.

# 5. Exam Traps

- Fiber uses light, not electrical signals.
- Single-mode has a smaller core than multi-mode.
- SMF uses lasers and supports longer distances.
- MMF commonly uses 850 nm wavelength.
- LC is the most common modern fiber connector.
- SC and ST are older/larger connectors.
- MPO is used for high-density multi-fiber connections.
- Fiber is immune to EMI.
- Do not look directly into fiber connectors.
- 1000BASE-SX uses multi-mode fiber.
- 1000BASE-LX commonly uses single-mode fiber.
- 10GBASE-SR uses multi-mode fiber.
- 10GBASE-LR uses single-mode fiber.

# 7. Practice Questions

## Question 1

Which fiber type is best for long-distance WAN links?

A. Cat6  
B. MMF  
C. SMF  
D. UTP  

### Answer: C. SMF

Explanation:

Single-mode fiber supports long distances and high bandwidth.

---

## Question 2

Which connector is commonly used with SFP modules?

A. ST  
B. LC  
C. SC  
D. MPO  

### Answer: B. LC

Explanation:

LC is a small form-factor connector commonly used with SFP/SFP+.

---

## Question 3

Which fiber uses multiple light paths?

A. SMF  
B. MMF  
C. Copper  
D. Coaxial  

### Answer: B. MMF

Explanation:

Multi-mode fiber allows multiple light rays through the core.

---

## Question 4

Which wavelength is commonly associated with MMF?

A. 850 nm  
B. 1550 nm  
C. 2000 nm  
D. 10 nm  

### Answer: A. 850 nm

Explanation:

850 nm is commonly used for short-distance multi-mode Ethernet.

---

## Question 5

Which connector is designed for high-density data center fiber connections?

A. LC  
B. SC  
C. ST  
D. MPO  

### Answer: D. MPO

Explanation:

MPO supports multiple fibers in one connector for high-density environments.
