# 1. Overview

Ethernet copper cabling uses standardized wiring schemes to ensure devices transmit and receive signals correctly. CCNA tests T568A/T568B pinouts, cable types, and Auto-MDIX because incorrect cabling can prevent Ethernet links from operating.

---

# 2. Core Concepts

# TIA/EIA Cabling Standards

TIA/EIA defines the wire color arrangement for terminating twisted-pair Ethernet cables.

Two common standards:

| Standard | Usage |
|---|---|
| T568A | Standardized wiring scheme |
| T568B | Most commonly used in many installations |

---

# RJ-45 / 8P8C Connector

| Feature | Value |
|---|---|
| Connector type | 8P8C |
| Common name | RJ-45 |
| Pins | 8 |
| Wire pairs | 4 pairs |
| Ethernet usage | 10/100/1000 Mbps |

# T568A vs T568B Comparison

| Pin | T568A | T568B |
|---|---|---|
| 1 | White/Green | White/Orange |
| 2 | Green | Orange |
| 3 | White/Orange | White/Green |
| 4 | Blue | Blue |
| 5 | White/Blue | White/Blue |
| 6 | Orange | Green |
| 7 | White/Brown | White/Brown |
| 8 | Brown | Brown |

---

# Important Exam Point

The only difference between T568A and T568B:

```
Orange and Green pairs are swapped
```

Pins:

```
1,2,3,6
```

change positions.

---

# Ethernet Signal Pairs

For 10/100 Ethernet:

| Pins | Function |
|---|---|
| 1,2 | Transmit |
| 3,6 | Receive |

---

For Gigabit Ethernet:

| Pins | Function |
|---|---|
| 1,2 | Data |
| 3,6 | Data |
| 4,5 | Data |
| 7,8 | Data |

All four pairs are used.

# Straight-Through Cable

## Definition

A straight-through cable uses the same wiring standard on both ends.

Example:

```
End A              End B

T568B  ----------  T568B
```

or

```
T568A  ----------  T568A
```

---

# Straight-Through Pin Comparison

Example:

```
T568B                T568B

Pin 1 W/O  --------  Pin 1 W/O
Pin 2 O    --------  Pin 2 O
Pin 3 W/G  --------  Pin 3 W/G
Pin 6 G    --------  Pin 6 G
```

---

# Straight-Through Usage

Traditional rule:

| Device 1 | Device 2 | Cable |
|---|---|---|
| PC | Switch | Straight-through |
| PC | Hub | Straight-through |
| Router | Switch | Straight-through |
| Server | Switch | Straight-through |

---
⁸
# Crossover Cable

## Definition

A crossover cable uses different wiring standards on each end.

Example:

```
End A              End B

T568A  ----------  T568B
```

---

# Crossover Cable Purpose

It swaps transmit and receive pairs.

Transmit:

```
Pins 1,2
```

connect to:

```
Pins 3,6
```

---

# Crossover Usage (Traditional)

| Device 1 | Device 2 | Cable |
|---|---|---|
| PC | PC | Crossover |
| Switch | Switch | Crossover |
| Router | Router | Crossover |
| Hub | Hub | Crossover |

---

# Straight-Through vs Crossover

| Feature | Straight-Through | Crossover |
|---|---|---|
| Ends | Same standard | Different standards |
| Example | T568B-T568B | T568A-T568B |
| Purpose | Connect unlike devices | Connect similar devices |
| TX/RX pairs | Same | Swapped |

---

# Device Categories

## MDI (Medium Dependent Interface)

Usually endpoint devices.

Examples:

| Device | Type |
|---|---|
| PC NIC | MDI |
| Router Ethernet port | MDI |

---

## MDIX (Medium Dependent Interface Crossover)

Usually networking devices.

Examples:

| Device | Type |
|---|---|
| Switch port | MDIX |
| Hub port | MDIX |

---

# Auto-MDIX

## Definition

Auto-MDIX automatically detects whether Ethernet transmit and receive pairs need to be swapped.

It removes the need to manually choose straight-through or crossover cables.

---

# Auto-MDIX Operation

Without Auto-MDIX:

```
PC (MDI)
   |
Straight cable
   |
Switch (MDIX)
```

Works.


Same devices:

```
PC (MDI)
   |
Straight cable
   |
PC (MDI)
```

Fails without crossover.

---

With Auto-MDIX:

```
PC
 |
Any cable type
 |
PC
```

Device automatically adjusts.

---

# Auto-MDIX Characteristics

| Feature | Description |
|---|---|
| Function | Automatically detects cable type |
| Works on | Modern Ethernet devices |
| Removes need for | Manual crossover cables |
| IEEE support | 802.3u |

# 3. Worked Examples

## Example 1: Identify Cable Type

### Scenario

A cable has:

```
End A: T568A
End B: T568B
```

What type of cable is it?

### Solution

Step 1:

Compare both ends.

```
T568A ≠ T568B
```

Step 2:

Different wiring standards mean transmit/receive pairs are crossed.

Answer:

```
Crossover Cable
```

---

## Example 2: Choose Correct Cable

### Scenario

Connect:

```
PC → Switch
```

Older Ethernet devices without Auto-MDIX.

Which cable is required?

### Solution

Step 1:

PC = MDI

Step 2:

Switch = MDIX

Step 3:

Different device types use straight-through.

Answer:

```
Straight-through cable
```

# 5. Exam Traps

- T568A and T568B are not different cable types.
- The difference is only wire pair arrangement.
- Straight-through = same standard on both ends.
- Crossover = different standards on both ends.
- Modern switches usually support Auto-MDIX.
- PC-to-switch traditionally uses straight-through.
- Switch-to-switch traditionally uses crossover.
- Routers are usually MDI devices.
- Switch ports are usually MDIX devices.
- Auto-MDIX removes the need to manually select crossover cables.
- Gigabit Ethernet uses all four wire pairs.

# 7. Practice Questions

## Question 1

A cable terminated as T568B on both ends is:

A. Crossover  
B. Straight-through  
C. Fiber  
D. Console cable  

### Answer: B. Straight-through

Explanation:

Same wiring standard on both ends creates a straight-through cable.

---

## Question 2

Which cable was traditionally used between two switches?

A. Straight-through  
B. Crossover  
C. Fiber only  
D. Console cable  

### Answer: B. Crossover

Explanation:

Similar devices traditionally required crossover cables.

---

## Question 3

What does Auto-MDIX do?

A. Increases cable speed  
B. Encrypts traffic  
C. Detects and adjusts transmit/receive pairs  
D. Changes IP addresses  

### Answer: C. Detects and adjusts transmit/receive pairs

Explanation:

Auto-MDIX automatically handles cable crossover requirements.

---

## Question 4

Which pins carry transmit data in 10/100 Ethernet?

A. 1,2  
B. 3,6  
C. 4,5  
D. 7,8  

### Answer: A. 1,2

Explanation:

Fast Ethernet uses pins 1,2 for transmit and 3,6 for receive.

---

## Question 5

A cable has T568A on one end and T568B on the other. What type is it?

A. Straight-through  
B. Crossover  
C. Rollover  
D. Fiber  

### Answer: B. Crossover

Explanation:

Different standards on each end swap transmit and receive pairs.
