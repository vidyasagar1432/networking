# 1. Overview

Copper media uses electrical signals to transmit data across Ethernet networks. CCNA tests copper cabling because cable type, category, speed, distance, and interference protection directly affect network performance and troubleshooting.

# Twisted Pair Cable

## Definition

Twisted pair cable contains pairs of copper wires twisted together to reduce electromagnetic interference (EMI) and crosstalk.

Example:

```
Pair 1:  Orange wires twisted
Pair 2:  Green wires twisted
Pair 3:  Blue wires twisted
Pair 4:  Brown wires twisted
```

---

# Why Wires Are Twisted

| Purpose | Explanation |
|---|---|
| Reduce EMI | Prevents external electrical interference |
| Reduce crosstalk | Prevents signal leakage between pairs |
| Improve signal quality | Maintains data integrity |

---

# UTP vs STP

## UTP (Unshielded Twisted Pair)

Definition:

Cable without additional shielding.

Example:

```
-----------------
| Twisted Pairs |
-----------------
```

---

## STP (Shielded Twisted Pair)

Definition:

Cable with metal shielding around pairs or entire cable.

Example:

```
-----------------
| Shield        |
| Twisted Pair  |
-----------------
```

---

# UTP vs STP Comparison

| Feature | UTP | STP |
|---|---|---|
| Shielding | None | Metal shielding |
| Cost | Lower | Higher |
| Installation | Easier | More difficult |
| Flexibility | Higher | Lower |
| EMI protection | Lower | Higher |
| Grounding required | No | Yes |
| Common usage | Office LANs | High-interference areas |

---

# Shielding Types

| Type | Meaning |
|---|---|
| U/UTP | Unshielded cable |
| F/UTP | Foil shield around all pairs |
| U/FTP | Foil shield around each pair |
| S/FTP | Braided shield + foil around pairs |

# Straight-Through vs Crossover Cable

## Straight-Through

Same wiring standard on both ends.

Example:

```
T568B -------- T568B
```

Used for:

```
PC → Switch
Router → Switch
```

---

## Crossover

Different wiring standards on each end.

Example:

```
T568A -------- T568B
```

Used historically for:

```
PC → PC
Switch → Switch
Router → Router
```

Modern devices support:

```
Auto-MDI/MDIX
```

which automatically detects cable type.

# 4. Configuration/Commands (if applicable)

Copper cabling has no IOS configuration, but these commands help troubleshoot Ethernet interfaces.

---

## Check Interface Status

```bash
show interfaces status
```

Purpose:

- Shows switch ports.
- Displays connected devices and speed.

---

## Check Interface Details

```bash
show interfaces gigabitEthernet 0/1
```

Purpose:

Displays:

- Speed
- Duplex
- Errors
- CRC errors

---

## Check Speed and Duplex

```bash
show controllers ethernet-controller
```

Purpose:

- Displays physical Ethernet information.

---

## Enable Interface

```bash
interface gigabitEthernet 0/1
no shutdown
```

Purpose:

- Activates the switch port.

# 5. Exam Traps

- Cat5e supports Gigabit Ethernet.
- Cat6 does not always support 10 Gbps at 100 meters.
- Cat6a supports 10 Gbps at 100 meters.
- Cat8 is mainly for data centers, not normal office cabling.
- STP requires proper grounding.
- UTP is the most common Ethernet cabling.
- Maximum copper Ethernet distance is usually 100 meters.
- Fiber is preferred for longer distances.
- RJ-45 is an 8P8C connector.
- Auto-MDI/MDIX removes the need for crossover cables on modern devices.

# 7. Practice Questions

## Question 1

Which cable category supports 10 Gbps Ethernet up to 100 meters?

A. Cat5e  
B. Cat6  
C. Cat6a  
D. Cat7 only  

### Answer: C. Cat6a

Explanation:

Cat6a is designed for 10GBASE-T at full 100-meter distance.

---

## Question 2

What is the main purpose of twisting copper pairs?

A. Increase voltage  
B. Reduce interference  
C. Increase cable length  
D. Replace shielding  

### Answer: B. Reduce interference

Explanation:

Twisting reduces EMI and crosstalk.

---

## Question 3

Which cable provides better protection against EMI?

A. UTP  
B. STP  
C. Cat5e only  
D. Coaxial only  

### Answer: B. STP

Explanation:

STP includes shielding to reduce interference.

---

## Question 4

What connector is commonly used with Ethernet twisted-pair cables?

A. LC  
B. SC  
C. RJ-45  
D. BNC  

### Answer: C. RJ-45

Explanation:

Ethernet copper cables commonly use RJ-45 (8P8C).

---

## Question 5

A 1000BASE-T network requires which minimum cable category?

A. Cat3  
B. Cat5e  
C. Cat6a  
D. Cat8  

### Answer: B. Cat5e

Explanation:

Gigabit Ethernet over copper requires Cat5e or better.
