# Hybrid Connectivity: AWS Direct Connect, Azure ExpressRoute, and Site-to-Site VPN

## CCNP Enterprise (ENCOR 350-401) & Cloud Networking Fundamentals

**CCNA Relevance: Basic understanding of cloud connectivity options.**  
**CCNP ENCOR Relevance: High — Hybrid cloud connectivity, VPNs, Direct Connect, ExpressRoute, routing, redundancy, and enterprise cloud design are important topics.**  
**Cloud Certifications (AWS SAA, Azure AZ-104/AZ-700): Core networking topic.**

---

# 1. Overview

Many organizations cannot move all their infrastructure to the cloud immediately. Instead, they operate in a **hybrid cloud** model, where on-premises data centers and cloud environments work together.

Hybrid connectivity enables secure communication between:

- On-premises networks
- AWS VPCs
- Azure VNets
- Branch offices
- Cloud applications

The three primary connectivity methods are:

- **Site-to-Site VPN**
- **AWS Direct Connect**
- **Azure ExpressRoute**

---

# 2. What Is Hybrid Cloud?

A hybrid cloud combines:

- On-premises infrastructure
- Public cloud resources
- Secure network connectivity

```
        On-Premises

     +-------------+

     | Data Center |

     +-------------+

           ||

           ||

       Secure Link

           ||

     +-------------+

     | AWS / Azure |

     +-------------+
```

Applications can communicate across both environments.

---

# 3. Why Hybrid Connectivity?

Organizations use hybrid networking to:

- Extend existing networks
- Migrate workloads gradually
- Improve disaster recovery
- Access cloud services securely
- Maintain compliance
- Reduce latency
- Avoid Internet exposure

# 5. Site-to-Site VPN Overview

A **Site-to-Site VPN** creates an encrypted IPsec tunnel between an on-premises network and a cloud virtual network.

```
On-Premises

↓

VPN Gateway

↓↓ Internet ↓↓

Cloud VPN Gateway

↓

AWS VPC / Azure VNet
```

---

# 6. Site-to-Site VPN Components

- Customer Gateway (on-premises router/firewall)
- VPN Gateway (cloud)
- IPsec Tunnel
- Internet

```
Office

↓

Router

↓

Internet

↓

Cloud VPN Gateway

↓

Cloud Network
```

---

# 7. IPsec Tunnel

Traffic is encrypted before leaving the organization.

```
Original Packet

↓

IPsec Encryption

↓

Internet

↓

IPsec Decryption

↓

Original Packet
```

Provides:

- Confidentiality
- Integrity
- Authentication

# 14. AWS Direct Connect Overview

**AWS Direct Connect (DX)** is a dedicated private connection between an organization's network and AWS.

Traffic bypasses the public Internet.

```
Office

↓

Dedicated Fiber

↓

AWS Direct Connect

↓

AWS Network
```

# 20. Azure ExpressRoute Overview

Traffic stays on Microsoft's backbone rather than traversing the public Internet.

# 25. VPN vs Direct Connect vs ExpressRoute

| Feature | VPN | Direct Connect | ExpressRoute |
|----------|-----|----------------|--------------|
| Transport | Internet | Dedicated Circuit | Dedicated Circuit |
| Encryption | Yes (IPsec) | Optional (MACsec/IPsec depending on design) | Optional (IPsec over ExpressRoute if required) |
| Latency | Variable | Low | Low |
| Bandwidth | Internet-dependent | High | High |
| Cost | Low | Higher | Higher |
| Reliability | Medium | High | High |

# 28. Redundancy

Best practice:

Use **multiple redundant connections**.

Example:

```
Office

 |        |

VPN1    VPN2

 |        |

AWS

```

Or:

```
Primary

↓

Direct Connect

Backup

↓

Site-to-Site VPN
```

This provides resilience if the dedicated circuit fails.

# 33. Security Considerations

- Encrypt Internet-based VPN traffic.
- Implement least-privilege firewall rules.
- Use redundant VPN tunnels.
- Monitor BGP sessions.
- Protect edge devices.
- Consider MACsec or IPsec where appropriate on dedicated links if encryption is required.

---

# 34. Best Practices

- Use **Site-to-Site VPN** for quick deployment or backup connectivity.
- Use **Direct Connect** or **ExpressRoute** for mission-critical production workloads.
- Deploy redundant circuits and VPN tunnels.
- Use BGP for dynamic routing where supported.
- Monitor latency, packet loss, and tunnel health.
- Separate production and management traffic when possible.
- Document route advertisements and failover behavior.

---

# 35. Troubleshooting

## VPN Tunnel Down

Check:

- IPsec parameters
- IKE version
- Pre-shared keys or certificates
- Firewall policies
- Internet connectivity

---

## BGP Not Establishing

Verify:

- ASN configuration
- Neighbor IP addresses
- Authentication (if configured)
- Advertised prefixes
- Reachability

---

## Direct Connect / ExpressRoute Issues

Check:

- Physical circuit status
- Provider connectivity
- Routing configuration
- Virtual interfaces / peerings
- Cloud gateway status

# CCNP Exam Traps

- **Site-to-Site VPN** uses **IPsec over the public Internet**.
- **AWS Direct Connect** and **Azure ExpressRoute** provide **private dedicated connectivity**, bypassing the public Internet.
- Dedicated circuits generally offer **lower latency**, **higher bandwidth**, and **more predictable performance** than Internet-based VPNs.
- **BGP** is commonly used for dynamic route exchange over VPNs and dedicated circuits.
- **AWS Transit Gateway** centralizes connectivity between VPCs, VPNs, and Direct Connect.
- **Azure Virtual WAN** provides centralized connectivity for VNets, VPNs, and ExpressRoute.
- A common enterprise design uses **Direct Connect/ExpressRoute as the primary path** with **Site-to-Site VPN as a backup**.
