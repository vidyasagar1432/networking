# 1. Overview

IPv6 addressing provides a 128-bit addressing system designed to replace IPv4 and solve address exhaustion. CCNA tests IPv6 address structure, address notation, compression rules, address types (unicast, multicast, anycast), and identifying valid IPv6 addresses.

---

# 2. Core Concepts

# IPv6 Address Basics

IPv6:

```
Internet Protocol version 6
```

Address size:

```
128 bits
```

Written as:

```
8 groups of 16 bits
```

Separated by:

```
Colon (:)
```

Example:

```
2001:0db8:0000:0000:0000:ff00:0042:8329
```

---

# IPv6 Address Structure

IPv6 address contains:

| Part | Purpose |
|---|---|
| Network prefix | Identifies network |
| Interface ID | Identifies host/device |

Typical format:

```
Network Prefix / Interface ID
```

Example:

```
2001:db8:1234:1::10/64
```

| Component | Size |
|---|---:|
| Network prefix | 64 bits |
| Interface ID | 64 bits |

---

# IPv6 Address Notation

Full format:

```
hhhh:hhhh:hhhh:hhhh:hhhh:hhhh:hhhh:hhhh
```

Where:

```
h = hexadecimal digit
```

Each group:

```
16 bits
```

Total:

```
8 × 16 = 128 bits
```

---

# Hexadecimal Values

IPv6 uses:

```
0-9
A-F
```

Example:

```
ABCD:1234:5678:9ABC
```

---

# IPv6 Address Example

Full address:

```
2001:0db8:0000:0001:0000:0000:0000:0001
```

Groups:

| Group | Value |
|---|---|
| 1 | 2001 |
| 2 | 0db8 |
| 3 | 0000 |
| 4 | 0001 |
| 5 | 0000 |
| 6 | 0000 |
| 7 | 0000 |
| 8 | 0001 |

---

# IPv6 Address Compression Rules

IPv6 provides two compression methods.

---

# Rule 1: Remove Leading Zeros

Leading zeros inside each group can be removed.

Example:

Full:

```
2001:0db8:0001:0000:0000:0000:0000:0001
```

Remove leading zeros:

```
2001:db8:1:0:0:0:0:1
```

---

# Rule 2: Replace Consecutive Zero Groups

A sequence of consecutive zero groups can be replaced with:

```
::
```

Example:

Before:

```
2001:db8:1:0:0:0:0:1
```

After:

```
2001:db8:1::1
```

---

# Important Compression Rules

| Rule | Description |
|---|---|
| Leading zeros can be removed | Yes |
| Single zero group replaced by :: | No |
| Multiple zero groups replaced by :: | Yes |
| :: can appear once only | Yes |

---

# Invalid Compression Example

Invalid:

```
2001::db8::1
```

Reason:

```
:: appears twice
```

---

# IPv6 Address Types

IPv6 does not use broadcast.

IPv6 communication types:

| Type | Purpose |
|---|---|
| Unicast | One-to-one |
| Multicast | One-to-many |
| Anycast | One-to-nearest |
| Broadcast | Not used |

---

# IPv6 Unicast

## Definition

Communication from one device to another specific device.

Example:

```
PC ---- Router
```

---

# IPv6 Unicast Address Types

| Type           | Prefix    | Purpose             |
| -------------- | --------- | ------------------- |
| Global Unicast | 2000::/3  | Internet-routable   |
| Link-Local     | FE80::/10 | Local communication |
| Unique Local   | FC00::/7  | Private networks    |
| Loopback       | ::1/128   | Local testing       |
| Unspecified    | ::/128    | No address          |

---

# Global Unicast Address (GUA)

Range:

```
2000::/3
```

Purpose:

Public IPv6 addressing.

Example:

```
2001:4860:4860::8888
```

(Google DNS IPv6)

---

# Link-Local Address

Range:

```
FE80::/10
```

Purpose:

Communication on the local link.

Characteristics:

| Feature | Value |
|---|---|
| Automatically created | Yes |
| Routable | No |
| Required on IPv6 interfaces | Yes |

Example:

```
FE80::1
```

---

# Unique Local Address (ULA)

Range:

```
FC00::/7
```

Purpose:

Private IPv6 networks.

Similar to IPv4:

```
RFC1918 private addresses
```

---

# Loopback Address

IPv6 equivalent of:

```
127.0.0.1
```

IPv6:

```
::1
```

Purpose:

Testing local TCP/IP stack.

---

# Unspecified Address

Address:

```
::
```

Meaning:

```
No address assigned
```

Used during:

- DHCPv6 startup
- Duplicate address detection

---

# IPv6 Multicast

## Definition

One sender communicates with multiple receivers.

Prefix:

```
FF00::/8
```

Format:

```
FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
```

---

# Common IPv6 Multicast Addresses

| Address | Purpose |
|---|---|
| FF02::1 | All IPv6 nodes |
| FF02::2 | All IPv6 routers |
| FF02::5 | OSPFv3 routers |
| FF02::6 | OSPFv3 DR routers |
| FF02::9 | RIPng routers |

---

# IPv6 Anycast

## Definition

Multiple devices share the same address.

Traffic goes to:

```
Nearest device
```

based on routing distance.

Example:

```
Client
 |
 +---- Server A
 |
 +---- Server B
```

Client reaches closest server.

---

# Unicast vs Multicast vs Anycast

| Type | Communication | Example |
|---|---|---|
| Unicast | One-to-one | PC to server |
| Multicast | One-to-many | OSPF updates |
| Anycast | One-to-nearest | DNS services |
| Broadcast | Not supported | N/A |

---

# IPv6 Special Addresses Summary

| Address | Purpose |
|---|---|
| :: | Unspecified |
| ::1 | Loopback |
| FE80::/10 | Link-local |
| FC00::/7 | Unique local |
| 2000::/3 | Global unicast |
| FF00::/8 | Multicast |

---

# IPv6 Interface Address Example

Example:

```
2001:db8:10:1::5/64
```

Meaning:

| Part | Value |
|---|---|
| Network | 2001:db8:10:1 |
| Host ID | ::5 |
| Prefix | /64 |

---

# IPv6 vs IPv4 Addressing

| Feature | IPv4 | IPv6 |
|---|---|---|
| Size | 32 bits | 128 bits |
| Format | Decimal | Hexadecimal |
| Broadcast | Supported | Not used |
| Multicast | Limited | Extensive |
| Address space | 4.3 billion | Huge |

# 5. Exam Traps

- IPv6 addresses are 128 bits.
- IPv6 uses hexadecimal notation.
- IPv6 does not use broadcast.
- FF00::/8 is multicast.
- FE80::/10 is link-local.
- 2000::/3 is global unicast.
- ::1 is IPv6 loopback.
- :: is unspecified, not loopback.
- A device can have multiple IPv6 addresses.
- Link-local addresses are automatically generated.
- The compression symbol (::) can appear only once.
- Leading zeros can always be removed.
- Anycast uses the same address on multiple devices.

# 7. Practice Questions

## Question 1

How many bits are in an IPv6 address?

A. 32  
B. 64  
C. 128  
D. 256  

### Answer: C. 128

Explanation:

IPv6 uses 128-bit addresses.

---

## Question 2

Which prefix identifies IPv6 multicast addresses?

A. FE80::/10  
B. 2000::/3  
C. FF00::/8  
D. FC00::/7  

### Answer: C. FF00::/8

Explanation:

All IPv6 multicast addresses begin with FF.

---

## Question 3

What is the compressed form of:

```
2001:0db8:0000:0000:0000:0000:0000:0001
```

A. 2001:db8::1  
B. 2001::db8::1  
C. 2001:db8:0:0:0:0:0:1  
D. 2001:db8::0::1  

### Answer: A. 2001:db8::1

Explanation:

Continuous zero groups are replaced by one ::.

---

## Question 4

Which IPv6 address type replaces IPv4 broadcast?

A. Unicast  
B. Multicast  
C. Anycast  
D. Loopback  

### Answer: B. Multicast

Explanation:

IPv6 uses multicast instead of broadcast.

---

## Question 5

Which address range is link-local?

A. 2000::/3  
B. FF00::/8  
C. FE80::/10  
D. FC00::/7  

### Answer: C. FE80::/10

Explanation:

FE80::/10 is reserved for link-local communication.
