# 1. Overview

Static routing is a manually configured method where an administrator defines the path to a destination network. CCNA tests static route configuration, default routes, next-hop selection, administrative distance, and floating static routes used for backup connectivity.

---

# 2. Core Concepts

# Static Route Definition

A static route is a route manually entered into a router's routing table.

Router does not learn it automatically.

Example:

```
Router A ---- Router B ---- LAN
```

Router A needs to know:

```
Destination network
+
Next-hop router
```

---

# Static Route Characteristics

| Feature | Description |
|---|---|
| Configuration | Manual |
| Updates | No automatic updates |
| Resource usage | Low |
| Scalability | Limited |
| Routing decisions | Administrator controlled |
| Best use | Small networks, backup paths |

---

# Static Route Syntax

Cisco IOS:

```bash
ip route destination-network subnet-mask next-hop-address
```

Example:

```bash
ip route 192.168.2.0 255.255.255.0 10.0.0.2
```

Meaning:

| Field | Value |
|---|---|
| Destination | 192.168.2.0/24 |
| Next hop | 10.0.0.2 |

---

# Static Route Types

| Type                  | Purpose                        |
| --------------------- | ------------------------------ |
| Standard static route | Route to a specific network    |
| Default static route  | Route for unknown destinations |
| Floating static route | Backup route                   |
| Summary static route  | Route to multiple networks     |
| Host static route     | Route to a single host         |

---

# Standard Static Route

Example:

Network:

```
192.168.10.0/24
```

Command:

```bash
ip route 192.168.10.0 255.255.255.0 10.1.1.2
```

Router forwards traffic for:

```
192.168.10.0/24
```

through:

```
10.1.1.2
```

---

# Next-Hop vs Exit Interface Static Routes

## Next-Hop Route

Uses router IP:

```bash
ip route 192.168.2.0 255.255.255.0 10.0.0.2
```

Router performs:

```
Route lookup
+
ARP lookup
```

---

## Exit Interface Route

Uses outgoing interface:

```bash
ip route 192.168.2.0 255.255.255.0 gigabitEthernet 0/1
```

Router sends directly out interface.

---

# Next-Hop vs Exit Interface

| Feature | Next-Hop | Exit Interface |
|---|---|---|
| Uses | Router IP | Local interface |
| Common use | Point-to-point/Ethernet | Point-to-point links |
| Requires ARP | Yes (Ethernet) | Depends |
| Troubleshooting | Easier | Less information |

---

# Fully Specified Static Route

Uses:

```
Exit interface + Next hop
```

Syntax:

```bash
ip route destination mask interface next-hop
```

Example:

```bash
ip route 192.168.2.0 255.255.255.0 g0/1 10.0.0.2
```

---

# Default Route

## Definition

A default route is used when no more specific route exists.

IPv4 default route:

```
0.0.0.0/0
```

IPv6 default route:

```
::/0
```

---

# Default Route Purpose

Commonly used for:

- Internet access
- ISP connections
- Stub networks

Example:

```
LAN
 |
Router
 |
ISP
 |
Internet
```

Router sends unknown traffic to ISP.

---

# Default Route Configuration

Command:

```bash
ip route 0.0.0.0 0.0.0.0 next-hop
```

Example:

```bash
ip route 0.0.0.0 0.0.0.0 203.0.113.1
```

---

# Default Route in Routing Table

Example:

```
S* 0.0.0.0/0 via 203.0.113.1
```

Meaning:

```
S = Static
* = Candidate default route
```

---

# Floating Static Route

## Definition

A floating static route is a backup static route with a higher administrative distance than the primary route.

Primary route:

```
Lower AD
```

Backup route:

```
Higher AD
```

---

# Floating Static Route Purpose

Provides:

- Backup WAN links
- Failover connectivity
- Redundancy

---

# Normal Static Route AD

Default:

```
AD = 1
```

Example:

Primary:

```
ip route 10.0.0.0 255.255.255.0 192.168.1.2
```

AD:

```
1
```

---

# Floating Static Route AD

Configured with higher AD:

Example:

```
AD = 10
```

Command:

```bash
ip route 10.0.0.0 255.255.255.0 192.168.2.2 10
```

---

# Floating Static Route Operation

Normal:

```
Primary Link
AD 1
ACTIVE
```

Backup:

```
Backup Link
AD 10
STANDBY
```

---

Failure:

```
Primary Link DOWN
        |
        v
Backup Route Installed
```

# Static Route Administrative Distance

| Route Type | Default AD |
|---|---:|
| Connected | 0 |
| Local | 0 |
| Static | 1 |
| Floating Static | User-defined |
| OSPF | 110 |
| RIP | 120 |

---

# Static Route Selection

Router chooses:

1. Longest prefix match
2. Lowest AD
3. Lowest metric

Example:

```
Static route AD 1
OSPF route AD 110
```

Static wins.

---

# Recursive Lookup

When a static route uses a next hop:

Example:

```bash
ip route 192.168.2.0 255.255.255.0 10.0.0.2
```

Router checks:

Step 1:

Find route to:

```
10.0.0.2
```

Step 2:

Find outgoing interface.

Step 3:

Forward packet.

# Summary Static Route

## Definition

A summary static route is a single static route that represents multiple contiguous networks with a common prefix.

## Purpose

- Reduces routing table size
- Decreases memory and CPU usage
- Simplifies route management

## How It Works

Compare the binary representation of multiple networks to find the longest common prefix.

Example networks:

```
192.168.0.0/24
192.168.1.0/24
192.168.2.0/24
192.168.3.0/24
```

Binary (third octet):

```
000000 00  → 0
000000 01  → 1
000000 10  → 2
000000 11  → 3
```

Common prefix: **22 bits**

Summary route:

```
192.168.0.0/22
```

Mask: `255.255.252.0`

## Syntax

```bash
ip route summary-network summary-mask next-hop
```

## Example

Topology:

```
LAN A: 192.168.0.0/24
LAN B: 192.168.1.0/24
LAN C: 192.168.2.0/24
LAN D: 192.168.3.0/24
        |
       R1
        |
       R2
```

R1 configuration:

```bash
ip route 192.168.0.0 255.255.252.0 10.0.0.2
```

One route replaces four individual static routes.

## Verification

```bash
show ip route static
```

Output:

```
S   192.168.0.0/22 [1/0] via 10.0.0.2
```

## Summary Route Requirements

| Requirement | Description |
|---|---|
| Contiguous networks | Networks must be sequential with no gaps |
| Bit boundary alignment | Must start on a power-of-2 boundary (0, 2, 4, 8, 16...) |
| Correct mask | Prefix must cover exactly the intended networks |
| Over-summarization risk | Including unused address space can black-hole traffic |

# Host Static Route

## Definition

A host static route is a route to a single IP address (/32).

## Purpose

- Reach a specific server or device
- Management interface access
- Override less specific routes for one host
- Troubleshooting and testing

## Syntax

```bash
ip route host-ip 255.255.255.255 next-hop
```

Or using CIDR notation:

```bash
ip route host-ip/32 next-hop
```

## Example

Scenario:

Server IP:

```
192.168.10.50
```

Command:

```bash
ip route 192.168.10.50 255.255.255.255 10.1.1.2
```

Or:

```bash
ip route 192.168.10.50/32 10.1.1.2
```

## Verification

```bash
show ip route static
```

Output:

```
S   192.168.10.50/32 [1/0] via 10.1.1.2
```

## Host Route Characteristics

| Feature | Description |
|---|---|
| Prefix length | /32 (255.255.255.255) |
| Destination | Single IP address only |
| Use case | Specific host reachability |
| Priority | Wins over less specific routes due to longest prefix match |

## Host Route Example in a Network

Topology:

```
PC ---- R1 ---- R2 ---- Server (192.168.10.50)
```

R1 needs a route to one specific server behind R2:

```bash
R1(config)# ip route 192.168.10.50 255.255.255.255 10.0.0.2
```

Traffic to `192.168.10.50` follows the host route; all other traffic to `192.168.10.0/24` follows the standard route.

# 5. Exam Traps

- Static routes have default AD of 1.
- Lower AD is preferred.
- Floating static routes use higher AD.
- Default route is 0.0.0.0/0.
- A default route is used only when no better match exists.
- Longest prefix match happens before AD.
- Static routes do not automatically update.
- A floating static route is not active until the primary route fails.
- The AD value is configured at the end of the static route command.
- Connected routes have AD 0 and beat static routes.
- Recursive lookup occurs when using a next-hop address.
- IPv6 default route is ::/0.

# 7. Practice Questions

## Question 1

What is the default administrative distance of a static route?

A. 0  
B. 1  
C. 90  
D. 110  

### Answer: B. 1

Explanation:

Static routes have AD 1 by default.

---

## Question 2

Which route is used when no specific route exists?

A. Host route  
B. Default route  
C. Connected route  
D. Local route  

### Answer: B. Default route

Explanation:

Default routes match unknown destinations.

---

## Question 3

What makes a static route "floating"?

A. Lower metric  
B. Higher bandwidth  
C. Higher administrative distance  
D. Shorter prefix  

### Answer: C. Higher administrative distance

Explanation:

Floating routes are backup routes with higher AD.
