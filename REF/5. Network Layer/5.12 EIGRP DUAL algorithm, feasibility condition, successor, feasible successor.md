# 1. Overview

Enhanced Interior Gateway Routing Protocol (EIGRP) is an advanced distance-vector routing protocol developed by Cisco. CCNA tests EIGRP concepts including DUAL algorithm operation, successor and feasible successor routes, feasibility condition, metrics, and EIGRP terminology.

---

# 2. Core Concepts

# EIGRP Definition

EIGRP:

```
Enhanced Interior Gateway Routing Protocol
```

Protocol type:

```
Advanced Distance Vector
(Hybrid routing protocol)
```

Purpose:

Automatically exchange routing information between routers.

---

# EIGRP Characteristics

| Feature | Value |
|---|---|
| Protocol type | Advanced Distance Vector |
| Algorithm | DUAL |
| Transport | RTP |
| Protocol number | 88 |
| Administrative Distance | 90 (internal) |
| External AD | 170 |
| Multicast address | 224.0.0.10 |
| IPv6 multicast | FF02::A |
| Metric | Composite metric |
| Convergence | Fast |

---

# EIGRP Terminology

| Term | Meaning |
|---|---|
| Neighbor | Router running EIGRP directly connected |
| Successor | Best route to destination |
| Feasible Successor | Backup loop-free route |
| Feasible Distance (FD) | Total metric through successor |
| Reported Distance (RD) | Neighbor's metric to destination |
| Advertised Distance (AD) | Same as RD |
| Topology Table | Stores all learned routes |
| Routing Table | Stores best routes only |

# EIGRP Metric

EIGRP uses composite metric.

Default calculation uses:

```
Bandwidth + Delay
```

Formula:

```
Metric =
256 × ((10^7 / Minimum Bandwidth) + Total Delay)
```

---

# EIGRP Metric Components

| Component | Used by Default |
|---|---|
| Bandwidth | Yes |
| Delay | Yes |
| Reliability | No |
| Load | No |
| MTU | No |

---

# K Values

EIGRP uses K values to determine metric components.

Default:

| K Value | Component | Value |
|---|---|---:|
| K1 | Bandwidth | 1 |
| K2 | Load | 0 |
| K3 | Delay | 1 |
| K4 | Reliability | 0 |
| K5 | MTU | 0 |

Default:

```
K1 = 1
K3 = 1
```

Only:

```
Bandwidth + Delay
```

are used.

# DUAL Algorithm

## Definition

DUAL:

```
Diffusing Update Algorithm
```

is the algorithm EIGRP uses to calculate loop-free paths.

Created by:

```
J.J. Garcia-Luna-Aceves
```

---

# DUAL Goals

| Goal | Purpose |
|---|---|
| Loop prevention | Avoid routing loops |
| Fast convergence | Quickly recover from failures |
| Backup paths | Maintain alternate routes |

---

# DUAL Route Selection

DUAL selects:

1. Lowest Feasible Distance
2. Meets Feasibility Condition

---

# Successor

## Definition

A successor is the best route to a destination.

Characteristics:

- Lowest metric
- Installed in routing table
- Used for forwarding traffic

Example:

```
Destination: 10.1.0.0/16

Path A metric: 10000
Path B metric: 20000
```

Selected:

```
Path A = Successor
```

---

# Feasible Distance (FD)

Definition:

Total metric from local router to destination through successor.

Example:

```
Local Router
 |
10000
 |
Successor
 |
Destination
```

FD:

```
10000
```

---

# Feasible Successor (FS)

## Definition

A feasible successor is a backup route that satisfies the feasibility condition.

Characteristics:

- Loop-free backup path
- Stored in topology table
- Not normally installed in routing table

---

# Feasible Condition (FC)

The feasibility condition determines whether a route is loop-free.

Rule:

```
Reported Distance < Feasible Distance
```

OR:

```
RD < FD
```

---

# Feasibility Condition Example

Current successor:

```
FD = 100
```

Backup route:

```
RD = 50
```

Check:

```
50 < 100
```

Condition satisfied.

Result:

```
Feasible Successor
```

---

# Non-Feasible Route Example

Current successor:

```
FD = 100
```

Backup route:

```
RD = 150
```

Check:

```
150 < 100
```

False.

Result:

```
Not a feasible successor
```

---

# Successor vs Feasible Successor

| Feature | Successor | Feasible Successor |
|---|---|---|
| Purpose | Primary route | Backup route |
| Installed in routing table | Yes | No |
| Best metric | Yes | No |
| Meets FC | Yes | Yes |
| Used immediately after failure | Yes | Yes |

---

# EIGRP Route States

| State | Meaning |
|---|---|
| Passive | Normal operation |
| Active | Searching for route |

---

# Passive State

Normal:

```
Route available
```

No queries needed.

---

# Active State

Occurs when:

- Successor fails
- No feasible successor exists

Router sends:

```
Query packets
```

---

# Stuck in Active (SIA)

Problem:

Router does not receive replies to queries.

Causes:

- Slow neighbors
- Poor design
- Network instability

---

# EIGRP Convergence Example

Before failure:

```
Successor:
R2

Feasible Successor:
R3
```

Failure:

```
R2 unavailable
```

DUAL checks:

```
Is R3 FS?
```

Yes.

Result:

```
R3 becomes Successor
```

No full recalculation needed.

# 3. Worked Examples

## Example 1: Find Successor and Feasible Successor

Router learns:

| Path | FD | RD |
|---|---:|---:|
| Path A | 100 | 80 |
| Path B | 150 | 50 |
| Path C | 200 | 180 |

---

Step 1:

Lowest FD:

```
Path A = 100
```

Successor:

```
Path A
```

---

Step 2:

Check feasibility condition:

Path B:

```
RD 50 < FD 100
```

Valid.

Path B:

```
Feasible Successor
```

---

Path C:

```
RD 180 < FD 100
```

False.

Not FS.

---

Answer:

```
Successor = Path A
Feasible Successor = Path B
```

---

## Example 2: EIGRP Failover

Before failure:

```
Destination:
192.168.1.0/24

Successor:
R2

Feasible Successor:
R3
```

---

Failure:

```
R2 link fails
```

DUAL checks:

```
R3 satisfies FC
```

Result:

```
R3 becomes successor
```

No query process required.

# 5. Exam Traps

- EIGRP is not a pure link-state protocol.
- EIGRP uses DUAL algorithm.
- Successor is the best route.
- Feasible successor is a backup route.
- Feasible successor must satisfy:
  ```
  RD < FD
  ```
- Lower FD becomes successor.
- EIGRP internal AD is 90.
- EIGRP external AD is 170.
- EIGRP uses protocol number 88.
- EIGRP multicast is 224.0.0.10.
- Hello packets discover neighbors.
- RTP provides reliable delivery.
- EIGRP metric uses bandwidth and delay by default.
- A route can exist in topology table but not routing table.

# 7. Practice Questions

## Question 1

Which algorithm does EIGRP use?

A. SPF  
B. Bellman-Ford  
C. DUAL  
D. Dijkstra  

### Answer: C. DUAL

Explanation:

EIGRP uses Diffusing Update Algorithm.

---

## Question 2

What is the feasibility condition?

A. FD < RD  
B. RD < FD  
C. Metric = 0  
D. AD < Metric  

### Answer: B. RD < FD

Explanation:

A feasible successor must have reported distance lower than feasible distance.

---

## Question 3

Which route is installed in the routing table?

A. Feasible successor  
B. Successor  
C. Query route  
D. Active route  

### Answer: B. Successor

Explanation:

The successor is the best path.

---

## Question 4

What is the default AD of internal EIGRP?

A. 90  
B. 100  
C. 110  
D. 120  

### Answer: A. 90

Explanation:

Internal EIGRP routes have AD 90.
