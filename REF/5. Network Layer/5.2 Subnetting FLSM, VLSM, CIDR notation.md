# 1. Overview

Subnetting divides a large IPv4 network into smaller logical networks by borrowing host bits for network identification. CCNA heavily tests CIDR notation, subnet masks, FLSM, VLSM calculations, usable host ranges, and network design efficiency.

---

# 2. Core Concepts

# IPv4 Subnetting Basics

Subnetting:

```
Network + Host
        |
        v
Network + Subnet + Host
```

Purpose:

| Reason | Benefit |
|---|---|
| Reduce broadcast domains | Better performance |
| Improve IP utilization | Less address waste |
| Improve security | Network segmentation |
| Simplify routing | Route summarization |

---

# IPv4 Address Structure

Example:

```
192.168.1.10/24
```

| Component | Value |
|---|---|
| Network bits | 24 |
| Host bits | 8 |
| Subnet mask | 255.255.255.0 |
| Total addresses | 256 |
| Usable hosts | 254 |

---

# CIDR Notation

## Definition

CIDR (Classless Inter-Domain Routing) represents subnet masks using slash notation.

Format:

```
IP address / prefix length
```

Example:

```
192.168.10.0/24
```

Meaning:

```
24 bits = network portion
8 bits = host portion
```

---

# Subnet Calculation Formulas

## Number of Subnets

Formula:

```
2^borrowed bits
```

Example:

Borrow 3 bits:

```
2³ = 8 subnets
```

---

## Number of Hosts

Formula:

```
2^host bits - 2
```

Example:

/27:

Host bits:

```
32 - 27 = 5
```

Hosts:

```
2⁵ - 2 = 30 usable hosts
```

---

# Block Size Calculation

Formula:

```
256 - subnet mask value
```

Example:

Mask:

```
255.255.255.192
```

Block size:

```
256 - 192 = 64
```

Networks:

```
0
64
128
192
```

# FLSM (Fixed Length Subnet Mask)

## Definition

FLSM divides a network into equal-sized subnets using the same subnet mask for every subnet.

Example:

Original:

```
192.168.1.0/24
```

Need:

```
4 equal networks
```

---

# FLSM Characteristics

| Feature | Value |
|---|---|
| Subnet sizes | Same |
| Mask | Same for all subnets |
| Simplicity | High |
| Address efficiency | Lower |
| Used in | Simple designs |

---

# FLSM Example

Network:

```
192.168.1.0/24
```

Need:

```
4 subnets
```

---

Borrow bits:

```
2^n >= 4
```

n:

```
2 bits
```

New prefix:

```
/24 + 2 = /26
```

Mask:

```
255.255.255.192
```

---

Subnets:

| Network | Host Range | Broadcast |
|---|---|---|
| 192.168.1.0/26 | .1-.62 | .63 |
| 192.168.1.64/26 | .65-.126 | .127 |
| 192.168.1.128/26 | .129-.190 | .191 |
| 192.168.1.192/26 | .193-.254 | .255 |

---

# VLSM (Variable Length Subnet Mask)

## Definition

VLSM allows different subnet sizes within the same network.

Purpose:

Efficient IP address allocation.

---

# VLSM Characteristics

| Feature | Value |
|---|---|
| Subnet sizes | Different |
| Masks | Different |
| Efficiency | High |
| Complexity | Higher |
| Used in | Enterprise networks |

---

# FLSM vs VLSM

| Feature | FLSM | VLSM |
|---|---|---|
| Subnet size | Equal | Variable |
| Mask | Same | Different |
| Address waste | More | Less |
| Complexity | Lower | Higher |
| Modern usage | Less common | Common |

---

# VLSM Design Rule

Allocate largest networks first.

Order:

```
Largest requirement
        |
        v
Smallest requirement
```

# 5. Exam Traps

- CIDR uses variable prefix lengths; classful boundaries are outdated.
- FLSM requires every subnet to use the same mask.
- VLSM allows different subnet masks.
- Always allocate largest VLSM subnet first.
- Usable hosts formula is:
  ```
  2^host bits - 2
  ```
- /31 is commonly used for point-to-point links.
- /32 represents a single host route.
- Network address cannot be assigned.
- Broadcast address cannot be assigned.
- Block size is calculated from the interesting octet.
- Do not confuse number of subnets with number of hosts.

# 7. Practice Questions

## Question 1

How many usable hosts exist in a /27 subnet?

A. 14  
B. 30  
C. 62  
D. 126  

### Answer: B. 30

Explanation:

/27 leaves 5 host bits:

```
2⁵ - 2 = 30
```

---

## Question 2

Which subnetting method allows different subnet sizes?

A. FLSM  
B. VLSM  
C. NAT  
D. CIDR  

### Answer: B. VLSM

Explanation:

VLSM uses variable subnet masks.

---

## Question 3

A /26 subnet has how many usable hosts?

A. 30  
B. 62  
C. 126  
D. 254  

### Answer: B. 62

Explanation:

/26 leaves 6 host bits:

```
2⁶ - 2 = 62
```

---

## Question 4

Which subnet mask represents /28?

A. 255.255.255.0  
B. 255.255.255.128  
C. 255.255.255.224  
D. 255.255.255.240  

### Answer: D. 255.255.255.240

Explanation:

/28 equals 28 network bits.

---

## Question 5

What is the best VLSM allocation strategy?

A. Allocate smallest networks first  
B. Allocate randomly  
C. Allocate largest networks first  
D. Use only /24 networks  

### Answer: C. Allocate largest networks first

Explanation:

Largest-first allocation prevents address waste.
