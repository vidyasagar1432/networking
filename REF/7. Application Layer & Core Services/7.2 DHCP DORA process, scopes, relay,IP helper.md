# 1. Overview

Dynamic Host Configuration Protocol (DHCP) automatically provides network configuration parameters such as IP address, subnet mask, default gateway, and DNS server information to clients. CCNA tests the DHCP DORA process, DHCP server scopes, DHCP relay operation, and Cisco IOS IP helper configuration.

---

# 2. Core Concepts

# DHCP Definition

DHCP:

```
A client-server protocol used to automatically assign
IP configuration information to network devices.
```

---

# DHCP Provides

| Parameter | Purpose |
|---|---|
| IP address | Device identity |
| Subnet mask | Network boundary |
| Default gateway | Remote network access |
| DNS server | Name resolution |
| Lease time | Address usage duration |
| Domain name | Network domain |

---

# DHCP Protocol Details

| Item | Value |
|---|---|
| OSI Layer | Application Layer (Layer 7) |
| Protocol | DHCP |
| Transport | UDP |
| Server Port | UDP 67 |
| Client Port | UDP 68 |
| IPv4 Broadcast | 255.255.255.255 |

---

# DHCP Communication

Initial DHCP communication uses broadcast because:

```
Client does not have an IP address yet.
```

Example:

```
Client:
0.0.0.0

Destination:
255.255.255.255
```

---

# DHCP DORA Process

DORA:

```
D - Discover
O - Offer
R - Request
A - Acknowledge
```

---

# DHCP DORA Flow

```
Client                         DHCP Server

DHCP Discover
   --------------------->

              DHCP Offer
   <---------------------

DHCP Request
   --------------------->

              DHCP ACK
   <---------------------
```

---

# Step 1: DHCP Discover

Client sends:

```
DHCPDISCOVER
```

Purpose:

```
Find available DHCP servers
```

Source:

```
0.0.0.0
```

Destination:

```
255.255.255.255
```

Client does not have an IP address.

---

# Step 2: DHCP Offer

Server responds:

```
DHCPOFFER
```

Contains:

| Information | Example |
|---|---|
| Offered IP | 192.168.1.100 |
| Subnet mask | 255.255.255.0 |
| Gateway | 192.168.1.1 |
| Lease time | 8 hours |
| DNS | 8.8.8.8 |

---

# Step 3: DHCP Request

Client sends:

```
DHCPREQUEST
```

Purpose:

```
Accepts one DHCP offer
```

Broadcast message:

```
All DHCP servers receive it.
```

Other servers withdraw offers.

---

# Step 4: DHCP ACK

Server sends:

```
DHCPACK
```

Contains:

```
Final IP configuration
```

Client configures:

```
IP address
Subnet mask
Gateway
DNS
```

---

# DHCP DORA Summary

| Step | Message | Direction |
|---|---|---|
| 1 | DHCPDISCOVER | Client → Server |
| 2 | DHCPOFFER | Server → Client |
| 3 | DHCPREQUEST | Client → Server |
| 4 | DHCPACK | Server → Client |

---

# DHCP Lease Process

DHCP addresses are leased.

Lease states:

```
BOUND
 |
 v
RENEW
 |
 v
REBIND
 |
 v
EXPIRE
```

---

# Lease Renewal

Client attempts renewal at:

```
T1 = 50% of lease time
```

Example:

Lease:

```
8 hours
```

Renewal:

```
4 hours
```

---

# Rebinding

If renewal fails:

```
T2 = 87.5% of lease time
```

Client broadcasts request.

---

# DHCP Scope

A DHCP scope is:

```
A pool of IP addresses available for assignment.
```

Example:

```
Network:

192.168.1.0/24


DHCP Scope:

192.168.1.100 - 192.168.1.200
```

---

# DHCP Scope Components

| Component | Example |
|---|---|
| Network range | 192.168.1.0/24 |
| Address pool | 100-200 |
| Exclusions | .1-.20 |
| Default gateway | 192.168.1.1 |
| DNS server | 8.8.8.8 |
| Lease duration | 8 hours |

---

# DHCP Exclusion

Purpose:

```
Prevent specific addresses from being assigned.
```

Example:

Reserve:

```
192.168.1.1
```

for router.

Exclude:

```
192.168.1.1-192.168.1.20
```

---

# DHCP Reservation

Purpose:

```
Always assign same IP to a device.
```

Uses:

```
MAC address mapping
```

Example:

```
Printer MAC
      |
      v
192.168.1.50
```

---

# DHCP Server Placement

## Same Network

Example:

```
Client
 |
 |
Switch
 |
 |
DHCP Server
```

Broadcast reaches server.

---

## Different Network

Example:

```
Client VLAN 10

     |
   Router

     |
DHCP Server VLAN 100
```

Problem:

Routers do not forward broadcasts.

Solution:

```
DHCP Relay
```

---

# DHCP Relay

Definition:

```
A router or Layer 3 switch forwards DHCP
messages between clients and DHCP servers.
```

---

# Why DHCP Relay Is Needed

DHCP Discover is:

```
Broadcast
```

Routers:

```
Do not forward broadcasts
```

Relay converts:

```
Broadcast → Unicast
```

---

# DHCP Relay Process

```
Client VLAN 10

DHCP Discover
       |
       v

Router Interface

ip helper-address

       |
       v

DHCP Server
```

---

# IP Helper Address

Cisco command:

```
ip helper-address <DHCP server IP>
```

Purpose:

```
Configure DHCP relay on Layer 3 interface.
```

---

# Cisco DHCP Relay Example

Network:

```
Client VLAN 10:

192.168.10.0/24


DHCP Server:

10.1.1.10
```

Router:

```
interface g0/0.10
```

Configuration:

```bash
interface g0/0.10
 ip helper-address 10.1.1.10
```

---

# DHCP Relay Supported Protocols

By default:

```
ip helper-address
```

forwards:

| Protocol | Port |
|---|---:|
| DHCP Server | UDP 67 |
| DHCP Client | UDP 68 |
| TFTP | UDP 69 |
| DNS | UDP 53 |
| Time service | UDP 37 |
| TACACS | UDP 49 |

---

# DHCP Server vs DHCP Relay

| Feature | DHCP Server | DHCP Relay |
|---|---|---|
| Assigns IP | Yes | No |
| Stores scopes | Yes | No |
| Forwards requests | No | Yes |
| Uses IP helper | No | Yes |

---

# Cisco DHCP Server Configuration

Example:

```bash
ip dhcp pool LAN_POOL
 network 192.168.1.0 255.255.255.0
 default-router 192.168.1.1
 dns-server 8.8.8.8
```

---

Explanation:

| Command | Function |
|---|---|
| ip dhcp pool | Creates DHCP scope |
| network | Defines address range |
| default-router | Provides gateway |
| dns-server | Provides DNS |

# DHCP Troubleshooting

| Problem | Possible Cause |
|---|---|
| Client gets 169.254.x.x | DHCP unavailable |
| No DHCP offer | Server unreachable |
| Wrong gateway | Scope configuration issue |
| Different VLAN clients fail | Missing relay |
| Duplicate IP | Static/DHCP conflict |

# APIPA Address

If DHCP fails:

Client assigns:

```
169.254.0.0/16
```

Called:

```
Automatic Private IP Addressing (APIPA)
```

# 5. Exam Traps

- DHCP uses UDP ports 67 and 68.
- DORA order is:
  ```
  Discover → Offer → Request → ACK
  ```
- DHCP Discover is a broadcast.
- Routers do not forward broadcasts by default.
- DHCP relay uses ip helper-address.
- DHCP relay does not assign IP addresses.
- DHCP server stores scopes.
- APIPA range is 169.254.0.0/16.
- DHCPREQUEST is sent by the client.
- DHCPACK is sent by the server.
- DHCP scope defines available addresses.
- DNS provides names; DHCP provides IP configuration.
- A missing IP helper causes DHCP failure across VLANs.

# 7. Practice Questions

## Question 1

What is the correct DHCP process order?

A. Offer → Discover → ACK → Request  
B. Discover → Offer → Request → ACK  
C. Request → Offer → ACK → Discover  
D. ACK → Request → Offer → Discover  

### Answer: B

Explanation:

DORA order is Discover, Offer, Request, ACK.

---

## Question 2

Which UDP ports are used by DHCP?

A. 20/21  
B. 22/23  
C. 53/54  
D. 67/68  

### Answer: D

Explanation:

DHCP server uses UDP 67 and client uses UDP 68.

---

## Question 3

Why is DHCP relay required?

A. To encrypt DHCP  
B. To forward broadcasts between networks  
C. To assign MAC addresses  
D. To replace DNS  

### Answer: B

Explanation:

Routers do not forward DHCP broadcasts.

---

## Question 4

Which command configures DHCP relay on Cisco IOS?

A. ip dhcp enable  
B. ip helper-address  
C. dhcp relay start  
D. service dhcp  

### Answer: B

Explanation:

ip helper-address forwards DHCP requests.

---

## Question 5

A client receives 169.254.10.20. What does this indicate?

A. DHCP success  
B. Static address  
C. DHCP failure  
D. DNS failure  

### Answer: C

Explanation:

169.254.x.x is APIPA, assigned when DHCP fails.
