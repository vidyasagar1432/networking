# 1. Overview

Broadband, cellular, and satellite technologies are WAN access methods used to connect homes, branches, remote offices, and mobile locations. Unlike dedicated WAN technologies such as leased lines, these solutions use shared infrastructure and are commonly selected based on cost, availability, and performance requirements.

---

# 2. WAN Access Technology Comparison

| Technology | Medium | Typical Use |
|---|---|---|
| Cable | Coaxial cable | Home/branch Internet |
| DSL | Telephone copper lines | Home/SMB Internet |
| Cellular | Radio frequency | Mobile/backup WAN |
| Satellite | Radio link to satellite | Remote locations |

---

# 3. Broadband Overview

## Definition

Broadband refers to high-speed Internet access technologies that provide continuous network connectivity.

Examples:

- Cable Internet
- DSL
- Fiber
- Fixed wireless

---

# Broadband Characteristics

| Feature | Description |
|---|---|
| Always connected | No dial-up required |
| Shared bandwidth | Multiple users share infrastructure |
| Lower cost | Compared with leased lines |
| Internet-based | Usually connects through ISP |

# CMTS

CMTS:

```
Cable Modem Termination System
```

Located at ISP facility.

Functions:

- Communicates with cable modems
- Manages subscriber traffic
- Connects cable network to Internet

---

# Cable Characteristics

| Feature | Description |
|---|---|
| Medium | Coaxial cable |
| Bandwidth | High |
| Download speed | Usually higher |
| Upload speed | Usually lower |
| Sharing | Shared among users |

|---|---|

# Cable Disadvantages

|---|---|

# 5. DSL (Digital Subscriber Line)

## Definition

DSL provides Internet access using existing telephone copper wiring.

---

# DSL Architecture

```
Computer

   |

   |

   |

   |

```

---

# DSL Components

## DSL Modem

Converts:

```
Digital data

to

DSL signal
```

---

## DSLAM

DSLAM:

```
Digital Subscriber Line Access Multiplexer
```

Located at ISP central office.

Functions:

- Aggregates DSL connections
- Converts DSL signals into ISP traffic

---

# DSL Types

| Type | Description |
|---|---|
| ADSL | Asymmetric DSL |
| SDSL | Symmetric DSL |
| VDSL | Very high-speed DSL |

---

# ADSL

ADSL:

```
Asymmetric Digital Subscriber Line
```

Means:

```
Download speed > Upload speed
```

Example:

```
Download:
100 Mbps

Upload:
20 Mbps
```

---

# DSL Advantages

| Advantage | Description |
|---|---|
| Uses existing phone lines | Easy deployment |
| Low cost | Affordable |
| Available in many areas | Good coverage |

---

# DSL Disadvantages

| Disadvantage | Description |
|---|---|
| Distance sensitive | Speed decreases with distance |
| Copper limitations | Lower than fiber |
| Higher latency | Compared with modern fiber |

---

# 6. Cable vs DSL

| Feature | Cable | DSL |
|---|---|---|
| Medium | Coaxial cable | Telephone copper |

# 14. CCNA Exam Traps

- Cable uses coaxial cable.
- DSL uses telephone copper lines.
- DSLAM terminates DSL connections at the provider.
- Cable uses CMTS at the provider side.
- Cellular WAN uses radio communication.
- 5G provides lower latency than previous generations.
- Satellite provides connectivity where cables are unavailable.
- GEO satellites have high latency due to distance.
- Broadband is usually shared, not dedicated.
- SD-WAN can use broadband and cellular as WAN transports.
