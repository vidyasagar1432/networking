# 1. Overview

Software-Defined Wide Area Networking (SD-WAN) is a modern WAN architecture that uses software-based controllers and centralized policies to manage connectivity across branches, data centers, and cloud environments. SD-WAN separates the control plane from the data plane, enabling automated path selection, application-aware routing, and easier WAN management.

# 13. SD-WAN vs MPLS

| Feature | MPLS | SD-WAN |
|---|---|---|
| Control | Provider controlled | Customer controlled |
| Transport | MPLS only | Multiple transports |
| Deployment | Manual | Automated |

| Visibility | Limited | Better analytics |
| Flexibility | Lower | Higher |
