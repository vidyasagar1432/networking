# 1. Overview

A Cisco IOS upgrade replaces the existing operating system image on a router or switch with a newer version. Upgrades are performed to fix bugs, add features, improve security, and support new hardware or protocols.

A successful IOS upgrade requires checking hardware compatibility, backing up configurations, transferring the new image, updating boot settings, and verifying operation after reboot.

# 2. Cisco IOS Image Basics

## IOS Image

The IOS image is the operating system file stored in device storage.

Example:

```

```

# IOS Image Contains

- Operating system
- Routing features
- Switching features
- Security features
- Management functions

# 13. Cisco IOS XE Package Modes

Cisco IOS XE supports different installation methods.

---

# Bundle Mode

IOS runs directly from `.bin` file.

Example:

```
flash:cat9k.bin
```

---

# Install Mode

Image is extracted into packages.

Example:

```
packages.conf
```

---

# Bundle vs Install

| Feature | Bundle | Install |
|---|---|---|
| Boot file | .bin | packages.conf |
| Startup speed | Slower | Faster |
| Recommended | No | Yes |
| Management | Basic | Better |

# 18. Upgrade Troubleshooting

## Problem: Device Boots Old IOS

Check:

```bash
show boot
```

Possible issue:

- Boot variable not updated

---

## Problem: Not Enough Flash Space

Check:

```bash
dir flash:
```

Remove old image:

```bash
delete flash:<old-image>
```

Then:

```bash
squeeze flash:
```

(older platforms)

---

## Problem: Upgrade Failed

Check:

- Correct image
- Hardware compatibility
- Available memory
- Configuration backup

# 19. IOS Upgrade Best Practices

| Practice | Reason |
|---|---|
| Backup configuration | Recovery |
| Test in lab first | Avoid outages |
| Check release notes | Know changes |
| Verify checksum | Prevent corruption |
| Schedule maintenance window | Reduce impact |
| Keep old image | Rollback option |
