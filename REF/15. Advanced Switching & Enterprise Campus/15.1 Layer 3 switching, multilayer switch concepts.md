# Layer 3 Switching and Multilayer Switch Concepts

## CCNP Enterprise (ENCOR 350-401) Level

**CCNA Relevance: Yes — Layer 3 switches, SVIs, inter-VLAN routing, and basic routing on switches are core CCNA topics.**  
**CCNP ENCOR Relevance: High — Hardware forwarding, CEF, SVIs, routed ports, FHRPs, and multilayer campus design are essential CCNP Enterprise concepts.**

---

# 1. Overview

A **Layer 3 (L3) switch**, also known as a **multilayer switch**, combines the functionality of a Layer 2 switch and a Layer 3 router into a single device. It can perform **high-speed packet switching** and **IP routing** using specialized hardware (ASICs), making it ideal for enterprise campus networks.

Unlike a traditional router, which generally forwards packets using software (or specialized forwarding engines), a multilayer switch performs routing at wire speed using hardware.

# 3. Layer 2 Switching

A Layer 2 switch forwards frames based on the **destination MAC address**.

```
PC1

   |

Switch

   |

PC2
```

Decision Process:

```
Ethernet Frame

↓

Destination MAC

↓

MAC Address Table

↓

Outgoing Port
```

Characteristics:

- Uses MAC addresses
- Does not route between VLANs
- Uses CAM table
- Broadcast domain per VLAN

---

# 4. Layer 3 Routing

A router forwards packets using the **destination IP address**.

```
Packet

↓

Destination IP

↓

Routing Table

↓

Next Hop

↓

Outgoing Interface
```

Characteristics:

- Uses IP addresses
- Connects different networks
- Maintains routing table

---

# 5. What Is a Layer 3 Switch?

A Layer 3 switch performs:

```
Layer 2 Switching

        +

Layer 3 Routing

```

Example:

```
               L3 Switch

      -------------------------

      |          |            |

    VLAN10     VLAN20      VLAN30

```

The switch can route traffic directly between VLANs without requiring an external router.

---

# 6. Layer 2 vs Layer 3 Switch

| Feature | Layer 2 Switch | Layer 3 Switch |
|----------|----------------|----------------|
| MAC Switching | Yes | Yes |
| IP Routing | No | Yes |
| Routing Table | No | Yes |
| Inter-VLAN Routing | No | Yes |
| Dynamic Routing | No | Yes |
| Hardware Forwarding | Yes | Yes |

# 10. ASIC (Application-Specific Integrated Circuit)

An ASIC is a specialized hardware chip designed for fast packet forwarding.

Functions:

- MAC lookup
- IP lookup
- ACL processing
- QoS
- VLAN tagging
- Packet rewriting

---

# 11. Cisco Express Forwarding (CEF)

## Definition

Cisco Express Forwarding (CEF) is the primary forwarding mechanism used by Cisco routers and multilayer switches.

Instead of performing a routing-table lookup for every packet, CEF uses prebuilt tables for extremely fast forwarding.

# 12. Forwarding Information Base (FIB)

The FIB is a hardware-optimized copy of the routing table.

Example:

| Destination | Next Hop |
|--------------|----------|
| 10.10.0.0/16 | Gi1/0/1 |
| 20.20.0.0/16 | Gi1/0/2 |

---

# 13. Adjacency Table

Stores Layer 2 rewrite information.

Contains:

- Destination MAC
- Source MAC
- VLAN
- Interface

---

```
Destination IP

↓

FIB

↓

Adjacency Table

↓

Rewrite Ethernet Header

↓

Transmit
```

# 15. Switched Virtual Interface (SVI)

## Definition

An SVI is a virtual Layer 3 interface associated with a VLAN.

Example:

```bash
interface vlan 10

 ip address 192.168.10.1 255.255.255.0

 no shutdown
```

Hosts use the SVI as their default gateway.

---

```
      |

Interface VLAN10

192.168.10.1
```

# 17. Routed Ports

A multilayer switch interface can operate as a Layer 3 routed port.

Configuration:

```bash
interface GigabitEthernet1/0/1

 no switchport

 ip address 10.1.1.1 255.255.255.252
```

Characteristics:

- No VLAN membership
- Behaves like a router interface
- Used between switches or routers

---

# 18. Routed Port vs SVI

| Feature | Routed Port | SVI |
|----------|-------------|-----|
| Belongs to VLAN | No | Yes |
| Physical Interface | Yes | No |
| Used for Inter-VLAN Routing | No | Yes |
| Used for Point-to-Point Links | Yes | No |

---

# 19. Enabling IP Routing

By default, many Cisco switches operate as Layer 2 devices.

Enable Layer 3 routing:

```bash
ip routing
```

Verify:

```bash
show running-config | include ip routing
```

---

# 20. Dynamic Routing on L3 Switches

Multilayer switches support routing protocols such as:

- OSPF
- EIGRP
- RIP
- IS-IS (platform dependent)
- BGP (high-end platforms)

Example:

```bash
router ospf 1

 network 192.168.10.0 0.0.0.255 area 0
```

# 25. Troubleshooting

## VLAN Cannot Reach Another VLAN

Check:

- `ip routing` enabled
- SVI is up/up
- VLAN exists
- Access ports assigned correctly
- Default gateway configured on hosts

---

## SVI Down

An SVI remains down if:

- VLAN does not exist
- No active ports in that VLAN
- Interface administratively down

Verify:

```bash
show interfaces vlan 10
```

---

## Routed Port Issues

Check:

```bash
show ip interface brief
```

Ensure:

- `no switchport`
- IP address configured
- Link is up

---

# 26. Best Practices

- Perform inter-VLAN routing on distribution-layer multilayer switches.
- Use SVIs for VLAN gateways.
- Use routed ports for point-to-point links.
- Enable CEF for optimal forwarding (enabled by default on most modern Cisco platforms).
- Enable dynamic routing instead of static routing in larger networks.
- Use FHRPs (HSRP/VRRP/GLBP) for gateway redundancy.

---

# CCNP Exam Traps

- A Layer 3 switch performs both switching and routing.
- Routing occurs at hardware speed using ASICs.
- CEF uses the **FIB** and **Adjacency Table**.
- An SVI is the default gateway for hosts in a VLAN.
- `ip routing` must be enabled for Layer 3 routing.
- Routed ports use `no switchport`.
- SVIs are virtual interfaces; routed ports are physical interfaces.
- Inter-VLAN routing is significantly faster on a multilayer switch than Router-on-a-Stick.
- CEF is the default forwarding mechanism on modern Cisco devices.
