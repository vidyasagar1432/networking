# 1. Overview

Modern network automation requires a structured way to configure and monitor network devices. **NETCONF** and **RESTCONF** are protocols that allow applications and controllers to programmatically manage network devices, while **YANG models** define the structure of configuration and operational data.

Model-driven telemetry uses YANG-based models to stream real-time device information to monitoring platforms instead of relying on traditional polling methods.

# 3. What is YANG?

## Definition

YANG:

```
Yet Another Next Generation
```

YANG is a **data modeling language** used to describe the structure of network configuration and operational data.

It defines:

- What data exists
- Data hierarchy
- Data types
- Relationships
- Constraints

# 8. NETCONF Operations

NETCONF uses RPC (Remote Procedure Call) messages.

Common operations:

| Operation | Purpose |
|---|---|
| <get> | Retrieve operational data |
| <get-config> | Retrieve configuration |
| <edit-config> | Modify configuration |
| <copy-config> | Copy configuration |
| <delete-config> | Delete configuration |
| <lock> | Lock datastore |
| <unlock> | Release datastore |

---

# 9. NETCONF Datastores

NETCONF organizes configuration into datastores.

| Datastore | Purpose |
|---|---|
| Running | Active configuration |
| Startup | Saved configuration |
| Candidate | Proposed changes |

# 11. RESTCONF HTTP Methods

RESTCONF uses normal HTTP methods.

| HTTP Method | Purpose |
|---|---|
| GET | Read data |
| POST | Create data |
| PUT | Replace data |
| PATCH | Modify data |
| DELETE | Remove data |

---

# Example RESTCONF Request

GET interface information:

```
GET /restconf/data/interfaces
```

Response:

```json
{
 "interface": "GigabitEthernet0/1",
 "status": "up"
}
```

# 12. NETCONF vs RESTCONF

| Feature | NETCONF | RESTCONF |
|---|---|---|
| Protocol | NETCONF | REST |
| Transport | SSH | HTTPS |
| Port | 830 | 443 |
| Data | XML | XML/JSON |
| Operations | RPC | HTTP methods |
| Model | YANG | YANG |

# CCNA Exam Traps

- NETCONF uses SSH and XML.
- RESTCONF uses HTTPS and JSON/XML.
- Both use YANG models.
- YANG is a data modeling language, not a protocol.
- NETCONF commonly uses port 830.
- RESTCONF commonly uses HTTPS port 443.
- Telemetry pushes data from devices to collectors.
- Model-driven telemetry uses structured data.
- SNMP traditionally uses polling.
- APIs enable network automation.
