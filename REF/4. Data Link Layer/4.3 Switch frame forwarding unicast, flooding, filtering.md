## CCNA 200-301 Exam Prep

**CCNP ENCOR Relevance: Yes — switch forwarding behavior, MAC learning, and Layer 2 traffic handling are core enterprise switching concepts.**

---

# 1. Overview

Ethernet switches forward frames at Layer 2 by examining destination MAC addresses and consulting the MAC address table (CAM table). CCNA tests how switches handle known unicast, unknown unicast, broadcast, multicast, flooding, and frame filtering decisions.

---

# 2. Core Concepts

# Switch Forwarding Process

When a switch receives an Ethernet frame, it performs these steps:

```
1. Receive frame
        |
        v
2. Learn source MAC address
        |
        v
3. Check destination MAC address
        |
        v
4. Forward, flood, or filter
```

---

# Switch Decision Table

| Destination MAC | Switch Action |
|---|---|
| Known unicast | Forward |
| Unknown unicast | Flood |
| Broadcast | Flood |
| Multicast | Forward/Flood depending on configuration |
| Destination on same incoming port | Filter |

---

# MAC Address Table Role

Example:

| MAC Address | Port |
|---|---|
| AA:AA:AA:AA:AA:AA | Gi0/1 |
| BB:BB:BB:BB:BB:BB | Gi0/2 |

The switch uses this table to decide where frames should go.

---

# Unicast Forwarding

## Definition

Unicast is one-to-one communication where a frame is sent from one device to one specific destination.

Example:

```
PC-A
 |
 |
Switch
 |
 |
PC-B
```

---

# Known Unicast

## Definition

A known unicast occurs when the destination MAC address exists in the switch MAC table.

Example:

MAC Table:

| MAC | Port |
|---|---|
| PC-B | Gi0/2 |

Frame:

```
Source MAC: PC-A
Destination MAC: PC-B
```

Switch action:

```
Forward only to Gi0/2
```

---

# Known Unicast Process

Step 1:

Receive frame:

```
Incoming port: Gi0/1
```

Step 2:

Learn source:

```
PC-A → Gi0/1
```

Step 3:

Search destination:

```
PC-B
```

Step 4:

Find:

```
PC-B → Gi0/2
```

Step 5:

Send frame:

```
Gi0/2 only
```

---

# Unknown Unicast

## Definition

A frame where the destination MAC address is not present in the MAC address table.

Example:

MAC Table:

| MAC | Port |
|---|---|
| PC-A | Gi0/1 |

Frame:

```
Destination MAC: PC-X
```

PC-X is unknown.

---

# Unknown Unicast Behavior

The switch floods the frame.

```
        Switch

 Gi0/1   Gi0/2   Gi0/3
   |       |       |
  PC-A    PC-B    PC-C
          ↑
       Flooded
```

Flooding occurs:

```
All ports except incoming port
```

---

# Flooding

## Definition

Flooding is when a switch sends a frame out multiple ports because it does not know the destination location.

---

# Flooding Types

| Type | Reason |
|---|---|
| Unknown unicast flooding | Destination MAC unknown |
| Broadcast flooding | Destination is broadcast |
| Multicast flooding | No multicast optimization |

---

# Broadcast Flooding

## Definition

Broadcast frames are sent to every device in the broadcast domain.

Destination MAC:

```
FF:FF:FF:FF:FF:FF
```

Example:

ARP request:

```
Who has 192.168.1.1?
```

Switch behavior:

```
Flood to all ports
```

---

# Flooding Rules

A switch floods frames:

| Condition | Flood? |
|---|---|
| Unknown destination MAC | Yes |
| Broadcast MAC | Yes |
| Known destination MAC | No |
| Same incoming port | No |

---

# Filtering

## Definition

Filtering occurs when a switch receives a frame but does not forward it because the destination is reachable through the same incoming interface.

---

# Example of Filtering

MAC Table:

| MAC | Port |
|---|---|
| PC-A | Gi0/1 |
| PC-B | Gi0/1 |

Frame:

```
PC-A → PC-B
```

Incoming:

```
Gi0/1
```

Destination also:

```
Gi0/1
```

Switch action:

```
Discard frame
```

This is called:

```
Filtering
```

---

# Forwarding vs Filtering vs Flooding

| Action | Meaning |
|---|---|
| Forwarding | Send frame to specific port |
| Flooding | Send frame to multiple ports |
| Filtering | Do not send frame |

---

# Switch Behavior Summary

| Destination Type | Action |
|---|---|
| Known unicast | Forward |
| Unknown unicast | Flood |
| Broadcast | Flood |
| Same port destination | Filter |

---

# Broadcast Domain and Flooding

Switches flood broadcasts within the same VLAN.

Example:

```
VLAN 10

PC1
 |
Switch
 |
PC2
```

Broadcast reaches:

```
All VLAN 10 ports
```

---

# VLAN Impact

Each VLAN has its own:

- Broadcast domain
- MAC address table entries

Example:

| VLAN | MAC |
|---|---|
| 10 | PC-A |
| 20 | PC-B |

---

# MAC Address Learning During Forwarding

When a frame arrives:

Example:

```
Source MAC:
00:11:22:33:44:55

Port:
Gi0/5
```

Switch updates:

```
00:11:22:33:44:55 → Gi0/5
```

---

# MAC Table Aging

Dynamic entries are removed after inactivity.

Default Cisco value:

```
300 seconds
```

---

# Layer 2 Forwarding Methods

Cisco switches use hardware-based forwarding.

| Method | Description |
|---|---|
| Store-and-forward | Receives complete frame before forwarding |
| Cut-through | Starts forwarding before full frame received |

---

# Store-and-Forward Switching

## Process

```
Receive complete frame
        |
Check FCS
        |
Forward frame
```

Advantages:

| Benefit | Explanation |
|---|---|
| Error checking | Removes corrupted frames |
| Better reliability | Validates FCS |

---

# Cut-Through Switching

## Process

```
Read destination MAC
        |
Immediately forward
```

Advantages:

- Lower latency

Disadvantages:

- May forward corrupted frames

---

# Cisco Switching Mode

Modern Cisco switches primarily use:

```
Store-and-forward
```

# 3. Worked Examples

## Example 1: Known Unicast Forwarding

### Scenario

MAC Table:

| MAC | Port |
|---|---|
| PC-A | Gi0/1 |
| PC-B | Gi0/2 |

PC-A sends a frame to PC-B.

What does the switch do?

---

### Solution

Step 1:

Frame enters:

```
Gi0/1
```

Step 2:

Switch learns:

```
PC-A → Gi0/1
```

Step 3:

Checks destination:

```
PC-B
```

Step 4:

MAC table shows:

```
PC-B → Gi0/2
```

Step 5:

Forward:

```
Gi0/2 only
```

Answer:

```
Known unicast forwarding
```

---

## Example 2: Unknown Unicast Flooding

### Scenario

A switch receives a frame for:

```
MAC:
AA:BB:CC:DD:EE:FF
```

but the MAC address is not in the table.

What happens?

---

### Solution

Step 1:

Switch checks CAM table.

Result:

```
Destination unknown
```

Step 2:

Switch floods frame.

Sent to:

```
All ports except incoming port
```

Answer:

```
Unknown unicast flooding
```

# 5. Exam Traps

- Switches learn source MAC addresses, not destination MAC addresses.
- Known unicast traffic is forwarded, not flooded.
- Unknown unicast traffic is flooded.
- Broadcast traffic is always flooded within the VLAN.
- Flooding does not include the incoming port.
- Filtering means the switch discards the frame because the destination is on the same port.
- Routers stop Layer 2 broadcasts.
- VLANs create separate broadcast domains.
- MAC address tables are per VLAN.
- A switch does not route based on IP addresses.
- Full-duplex switched Ethernet does not use CSMA/CD.

# 7. Practice Questions

## Question 1

A switch receives a frame with a destination MAC in its MAC table. What does it do?

A. Floods the frame  
B. Drops the frame  
C. Forwards to the correct port  
D. Sends to router  

### Answer: C. Forwards to the correct port

Explanation:

Known unicast frames are forwarded using the MAC table.

---

## Question 2

What happens when a switch receives a frame for an unknown MAC address?

A. Filters it  
B. Floods it  
C. Encrypts it  
D. Routes it  

### Answer: B. Floods it

Explanation:

Unknown unicast frames are flooded to all ports except the source port.

---

## Question 3

What is the destination MAC address for Ethernet broadcast?

A. 00:00:00:00:00:00  
B. FF:FF:FF:FF:FF:FF  
C. 01:00:5E:00:00:01  
D. 255.255.255.255  

### Answer: B. FF:FF:FF:FF:FF:FF

Explanation:

Ethernet broadcast uses all binary 1s.

---

## Question 4

What does a switch do if destination and source are on the same interface?

A. Floods  
B. Filters  
C. Routes  
D. Broadcasts  

### Answer: B. Filters

Explanation:

The switch does not forward the frame back out the same port.

---

## Question 5

Which command displays the switch MAC forwarding table?

A. show ip route  
B. show arp  
C. show mac address-table  
D. show vlan  

### Answer: C. show mac address-table

Explanation:

This command displays MAC-to-port mappings.
