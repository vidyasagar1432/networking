# 1. Overview

Ethernet is the most widely used LAN technology defined by IEEE 802.3 standards. CCNA tests Ethernet frame structure, MAC addressing, frame forwarding, collision domains, and how switches process Ethernet frames.

# 2. Core Concepts

# Ethernet Overview

## Definition

Ethernet is a Layer 2 (Data Link) and Layer 1 (Physical) technology used for local area networks.

# Ethernet Frame

## Definition

An Ethernet frame is the Layer 2 data unit used to transport data across a LAN.

---

# Ethernet Frame Format

```
+-----------+
| Preamble  |
+-----------+
| SFD       |
+-----------+
| Dest MAC  |
+-----------+
| Source MAC|
+-----------+
| Type      |
+-----------+
| Data      |
+-----------+
| FCS       |
+-----------+
```

---

# Ethernet Frame Fields

| Field | Size | Purpose |
|---|---:|---|
| Preamble | 7 bytes | Synchronization |
| SFD | 1 byte | Start of frame |
| Destination MAC | 6 bytes | Receiver address |
| Source MAC | 6 bytes | Sender address |
| Type/Length | 2 bytes | Protocol identification |
| Data | 46-1500 bytes | Payload |
| FCS | 4 bytes | Error detection |

---

# Ethernet Frame Size

| Frame Type | Size |
|---|---:|
| Minimum Ethernet frame | 64 bytes |
| Maximum Ethernet frame | 1518 bytes |
| Jumbo frame | >1518 bytes |

---

# Minimum Frame Size

Ethernet requires minimum frame size:

```
64 bytes
```

Purpose:

- Detect collisions in legacy Ethernet.

---

# Maximum Frame Size

Standard Ethernet MTU:

```
1500 bytes
```

```
1518 bytes
```

Includes:

- Header
- Payload
- FCS

# Ethernet Switching Process

A switch performs:

1. Learn source MAC address
2. Examine destination MAC address
3. Forward or flood frame

---

# MAC Address Learning

Example:

Incoming frame:

```
Source MAC:
AA:AA:AA:AA:AA:AA

Port:
Gi0/1
```

Switch learns:

```
AA:AA:AA:AA:AA:AA → Gi0/1
```

Stored in MAC address table.

---

# MAC Address Table

Example:

| MAC Address | Port |
|---|---|
| AA:AA:AA:AA:AA:AA | Gi0/1 |
| BB:BB:BB:BB:BB:BB | Gi0/2 |

---

# Frame Forwarding Decisions

| Destination MAC | Switch Action |
|---|---|
| Known unicast | Forward only that port |
| Unknown unicast | Flood |
| Broadcast | Flood |
| Multicast | Flood or forward depending on configuration |

# Broadcast Domain

# CSMA/CD

## Carrier Sense Multiple Access with Collision Detection

Legacy Ethernet access method.

---

# CSMA/CD Process

1. Listen before transmitting
2. Transmit data
3. Detect collision
4. Send jam signal
5. Wait random time
6. Retransmit

# 3. Worked Examples

## Example 1: Analyze Ethernet Frame

### Scenario

A frame contains:

```
Destination MAC:
FF:FF:FF:FF:FF:FF
```

What type of communication is this?

---

### Solution

Step 1:

Check destination MAC.

```
FF:FF:FF:FF:FF:FF
```

is the broadcast MAC.

Step 2:

Broadcast frames are delivered to all devices in the broadcast domain.

Answer:

```
Broadcast frame
```

---

## Example 2: Switch Learning Process

### Scenario

A switch receives:

```
Source MAC:
AA-AA-AA-AA-AA-AA

Incoming Port:
Gi0/5
```

What does the switch learn?

---

### Solution

Step 1:

Switch reads source MAC.

Step 2:

Creates MAC table entry.

Result:

```
AA-AA-AA-AA-AA-AA → Gi0/5
```

The switch now knows where to send future frames.

# 5. Exam Traps

- Ethernet frame operates at Layer 2.
- IP addresses are not inside the Ethernet addressing fields.
- MAC addresses are used for local delivery.
- Destination MAC comes before source MAC in the frame.
- Broadcast MAC address is FF:FF:FF:FF:FF:FF.
- Minimum Ethernet frame size is 64 bytes.
- Maximum standard Ethernet frame size is 1518 bytes.
- MTU is usually 1500 bytes.
- Switches learn source MAC addresses, not destination MAC addresses.
- Unknown unicast frames are flooded.
- Routers break broadcast domains.
- Full-duplex Ethernet does not use CSMA/CD.

# 7. Practice Questions

## Question 1

Which address does an Ethernet frame use?

A. IP address  
B. MAC address  
C. Port number  
D. URL  

### Answer: B. MAC address

Explanation:

Ethernet operates at Layer 2 and uses MAC addressing.

---

## Question 2

What is the minimum Ethernet frame size?

A. 32 bytes  
B. 64 bytes  
C. 128 bytes  
D. 1500 bytes  

### Answer: B. 64 bytes

Explanation:

Ethernet requires a minimum 64-byte frame.

---

## Question 3

What does a switch learn from incoming frames?

A. Destination MAC  
B. Source MAC  
C. IP address  
D. Port number  

### Answer: B. Source MAC

Explanation:

Switches build MAC tables by learning source MAC addresses.

---

## Question 4

Which EtherType identifies IPv4?

A. 0x0800  
B. 0x0806  
C. 0x86DD  
D. 0xFFFF  

### Answer: A. 0x0800

Explanation:

0x0800 identifies IPv4 packets inside Ethernet frames.

---

## Question 5

What happens when a switch receives a frame for an unknown destination MAC?

A. Drops the frame  
B. Sends to router  
C. Floods the frame  
D. Encrypts the frame  

### Answer: C. Floods the frame

Explanation:

Unknown unicast frames are flooded out all ports except the receiving port.
