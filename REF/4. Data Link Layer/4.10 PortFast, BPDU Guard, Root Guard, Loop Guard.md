**CCNP ENCOR Relevance: Yes — STP protection mechanisms are important for enterprise Layer 2 design, security, and troubleshooting.**

# 1. Overview

STP protection features improve network stability by controlling unexpected topology changes and preventing Layer 2 loops. CCNA tests PortFast, BPDU Guard, Root Guard, and Loop Guard behavior, including when ports are placed into error states or inconsistent states.

---

# 2. Core Concepts

# STP Protection Features Overview

| Feature | Purpose | Protects Against |
|---|---|---|
| PortFast | Fast forwarding for end devices | Slow STP convergence |
| BPDU Guard | Disables ports receiving BPDUs | Unauthorized switches |
| Root Guard | Prevents unwanted root bridge election | Rogue root bridge |
| Loop Guard | Prevents accidental forwarding loops | Unidirectional failures |

---

# PortFast

## Definition

PortFast immediately places an access port into the forwarding state without waiting for normal STP convergence.

---

# Normal STP Port Transition

```
Blocking
   |
Listening
   |
Learning
   |
Forwarding
```

Delay:

```
30-50 seconds
```

---

# PortFast Behavior

Without PortFast:

```
PC
 |
Switch Port

Waiting for STP
```

With PortFast:

```
PC
 |
Switch Port

Immediately Forwarding
```

---

# PortFast Usage

Correct:

```
Switch ---- PC
```

Incorrect:

```
Switch ---- Switch
```

Reason:

Switch links need STP protection.

---

# PortFast Characteristics

| Feature | Value |
|---|---|
| Used on | Access ports |
| Changes STP topology | No |
| Skips listening/learning | Yes |
| Default | Disabled |

---

# BPDU Guard

## Definition

BPDU Guard disables a PortFast-enabled port if it receives a BPDU.

Purpose:

Prevent unauthorized switches from connecting to end-device ports.

---

# BPDU Guard Example

Normal:

```
Switch
  |
 PC
```

Attack/mistake:

```
Switch
  |
Small Switch
```

Small switch sends:

```
BPDU
```

Result:

```
Port shutdown
```

---

# BPDU Guard Action

When BPDU received:

```
Port → err-disabled state
```

---

# BPDU Guard Characteristics

| Feature | Value |
|---|---|
| Used with | PortFast |
| Trigger | BPDU received |
| Result | Port disabled |
| Protection | Rogue switch |

---

# Root Guard

## Definition

Root Guard prevents a port from accepting superior BPDUs that could make another switch the root bridge.

---

# Root Guard Example

Before:

```
             Root Bridge
                 |
              Switch A
```

Unauthorized switch:

```
Switch A ---- New Switch
```

New switch sends:

```
Superior BPDU
```

Root Guard blocks it.

---

# Root Guard Behavior

When superior BPDU received:

```
Port → Root-inconsistent state
```

When superior BPDU stops:

```
Port automatically recovers
```

---

# Root Guard Characteristics

| Feature | Value |
|---|---|
| Applied to | Designated ports |
| Blocks | Superior BPDUs |
| State | Root-inconsistent |
| Auto recovery | Yes |

---

# Loop Guard

## Definition

Loop Guard prevents a blocked STP port from incorrectly moving to forwarding state when BPDUs stop arriving.

---

# Loop Guard Problem

Normal operation:

```
Switch A
 |
Blocked Port
 |
Switch B
```

Port stays blocked because it receives BPDUs.

---

Failure:

```
BPDU stops arriving
```

Without Loop Guard:

```
Blocked port
      |
      v
Forwarding
      |
      v
Loop
```

---

# Loop Guard Protection

With Loop Guard:

```
Port → Loop-inconsistent state
```

Prevents loop creation.

---

# Loop Guard Characteristics

| Feature | Value |
|---|---|
| Protects | Non-designated ports |
| Detects | Missing BPDUs |
| State | Loop-inconsistent |
| Auto recovery | Yes |

---

# Root Guard vs Loop Guard

| Feature | Root Guard | Loop Guard |
|---|---|---|
| Problem | Wrong root bridge | Lost BPDU |
| Protects against | Superior BPDUs | Unidirectional failures |
| Applied on | Designated ports | Non-designated ports |
| Result | Root-inconsistent | Loop-inconsistent |

---

# BPDU Guard vs Root Guard

| Feature | BPDU Guard | Root Guard |
|---|---|---|
| Trigger | Any BPDU received | Superior BPDU received |
| Applied on | Edge/access ports | Designated ports |
| Result | Err-disabled | Root-inconsistent |

---

Example:

                Core Switch

# STP Inconsistent States

| State | Caused By |
|---|---|
| Err-disabled | BPDU Guard |
| Root-inconsistent | Root Guard |
| Loop-inconsistent | Loop Guard |

# Cisco Commands

# Enable PortFast

Interface level:

```bash
interface gigabitEthernet 0/1
spanning-tree portfast
```

Enables PortFast on a port.

---

# Enable BPDU Guard

Interface level:

```bash
interface gigabitEthernet 0/1
spanning-tree bpduguard enable
```

Disables port if BPDU arrives.

---

# Enable BPDU Guard Globally

```bash
spanning-tree portfast bpduguard default
```

Enables BPDU Guard on all PortFast ports.

---

# Enable Root Guard

```bash
interface gigabitEthernet 0/2
spanning-tree guard root
```

Prevents superior BPDU acceptance.

---

# Enable Loop Guard

```bash
interface gigabitEthernet 0/3
spanning-tree guard loop
```

Prevents blocked ports from forwarding incorrectly.

---

# Verify STP Protection

```bash
show spanning-tree inconsistentports
```

Displays ports in inconsistent states.

---

# Check Interface Status

```bash
show interfaces status
```

Shows port status including err-disabled.

---

# Recover Err-Disabled Port

```bash
shutdown
no shutdown
```

Manually resets the interface.

---

# Enable Automatic Recovery

```bash
errdisable recovery cause bpduguard
```

Enables automatic recovery from BPDU Guard.

# 3. Worked Examples

## Example 1: BPDU Guard Scenario

### Scenario

A user connects a small switch to an access port.

Configuration:

```
PortFast enabled
BPDU Guard enabled
```

The new switch sends BPDUs.

What happens?

---

### Solution

Step 1:

Port receives BPDU.

Step 2:

BPDU Guard detects unexpected BPDU.

Step 3:

Port enters:

```
err-disabled
```

Answer:

```
The port is shut down to protect the network.
```

---

## Example 2: Root Guard Scenario

### Scenario

A distribution switch should remain the root bridge.

An access switch sends a superior BPDU.

Root Guard is enabled.

What happens?

---

### Solution

Step 1:

Switch receives superior BPDU.

Step 2:

Root Guard blocks the port.

Step 3:

Port enters:

```
root-inconsistent
```

Step 4:

When superior BPDU disappears:

```
Port recovers automatically
```

# 5. Exam Traps

- PortFast does not disable STP; it skips transition delays.
- PortFast should only be used on ports connected to end devices.
- BPDU Guard shuts down ports receiving BPDUs.
- Root Guard protects the root bridge position.
- Loop Guard protects against missing BPDUs.
- Root Guard creates root-inconsistent state.
- Loop Guard creates loop-inconsistent state.
- BPDU Guard creates err-disabled state.
- PortFast and BPDU Guard are commonly configured together.
- Root Guard is usually placed toward access/distribution boundaries.
- Loop Guard is used on redundant switch links.
- Do not use PortFast on switch-to-switch links.

# 7. Practice Questions

## Question 1

Which feature allows an access port to immediately enter forwarding state?

A. Root Guard  
B. Loop Guard  
C. PortFast  
D. BPDU Guard  

### Answer: C. PortFast

Explanation:

PortFast skips normal STP listening and learning delays.

---

## Question 2

A PortFast port receives a BPDU. What happens with BPDU Guard enabled?

A. Port becomes root port  
B. Port enters err-disabled state  
C. Port becomes forwarding  
D. VLAN shuts down  

### Answer: B. Port enters err-disabled state

Explanation:

BPDU Guard protects edge ports from switches.

---

## Question 3

Which STP protection prevents a switch from becoming root bridge?

A. Loop Guard  
B. Root Guard  
C. PortFast  
D. BPDU Filter  

### Answer: B. Root Guard

Explanation:

Root Guard blocks superior BPDUs.

---

## Question 4

Which feature protects against a blocked port moving to forwarding because BPDUs stop?

A. BPDU Guard  
B. Root Guard  
C. Loop Guard  
D. PortFast  

### Answer: C. Loop Guard

Explanation:

Loop Guard prevents loops caused by missing BPDUs.

---

## Question 5

Which command displays STP inconsistent ports?

A. show vlan brief  
B. show spanning-tree inconsistentports  
C. show interfaces trunk  
D. show mac address-table  

### Answer: B. show spanning-tree inconsistentports

Explanation:

It displays Root Guard and Loop Guard inconsistent states.
