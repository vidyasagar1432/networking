# 1. Overview

A VLAN (Virtual Local Area Network) logically separates a physical switch network into multiple Layer 2 broadcast domains. CCNA tests VLAN purpose, VLAN types, access/trunk behavior, default VLANs, voice VLANs, and native VLAN concepts.

---

# 2. Core Concepts

# What is a VLAN?

## Definition

A VLAN is a logical grouping of devices in the same broadcast domain, regardless of their physical switch location.

Without VLANs:

```
All switch ports
      |
One broadcast domain
```

With VLANs:

```
VLAN 10          VLAN 20

PCs              PCs
 |                |
+----------------+
|    Switch      |
+----------------+
```

---

# VLAN Purpose

| Purpose | Description |
|---|---|
| Segmentation | Separates users and devices |
| Security | Limits broadcast visibility |
| Broadcast control | Reduces broadcast traffic |
| Flexibility | Logical grouping independent of location |
| Management | Easier network organization |

---

# VLAN Characteristics

| Feature | Description |
|---|---|
| Operates at | Layer 2 |
| Identified by | VLAN ID |
| Creates | Broadcast domains |
| Configured on | Switches |
| Uses | 802.1Q tagging |
| Requires router/L3 switch for inter-VLAN communication | Yes |

---

# VLAN ID

A VLAN is identified by a numeric ID.

Range:

| VLAN Range | Usage |
|---|---|
| 0 | Reserved |
| 1 | Default VLAN |
| 2-1001 | Normal VLAN range |
| 1002-1005 | Legacy reserved |
| 1006-4094 | Extended VLAN range |

---

# VLAN Membership

Devices become part of a VLAN through switch ports.

Example:

```
PC-A
 |
Access Port
 |
VLAN 10
```

---

# Access Ports

## Definition

An access port belongs to a single VLAN and carries traffic for one VLAN only.

Example:

```
PC
 |
Access Port
 |
VLAN 10
```

---

# Access Port Characteristics

| Feature | Value |
|---|---|
| VLANs supported | One |
| Connected devices | End devices |
| Frame tagging | No |
| Common use | PCs, printers |

---

# Trunk Ports

## Definition

A trunk carries multiple VLANs between network devices.

Example:

```
Switch A
   |
 Trunk
   |
Switch B
```

---

# Trunk Characteristics

| Feature | Value |
|---|---|
| VLANs supported | Multiple |
| Tagging | 802.1Q |
| Used between | Switches |
| Carries | Multiple VLANs |

---

# VLAN Types

Common VLAN types:

| VLAN Type | Purpose |

## Definition

A data VLAN carries normal user-generated traffic.

Examples:

- PCs
- Laptops
- Printers
- Servers

# Data VLAN Characteristics

| Feature | Description |
|---|---|

| Example | VLAN 10 |

# Voice VLAN

## Definition

A voice VLAN is dedicated for IP phone traffic.

Purpose:

- Separate voice traffic
- Improve QoS
- Simplify phone deployment

```
 |

 |
 |
Switch Port
```

```
Data VLAN + Voice VLAN
```

# Voice VLAN Characteristics

| Improves | Voice quality |

# Native VLAN

## Definition

The native VLAN carries untagged frames on an 802.1Q trunk.

Example:

```
Switch A
   |
 Trunk
   |
Switch B
```

Untagged traffic:

```
Native VLAN
```

---

# Native VLAN Characteristics

| Feature | Description |
|---|---|
| Used on | Trunk links |
| Frame tagging | Untagged |
| Default native VLAN | VLAN 1 |
| Must match | Both trunk ends |

---

# Native VLAN Example

Switch A:

```
Native VLAN 99
```

Switch B:

```
Native VLAN 99
```

Correct.

---

Mismatch:

Switch A:

```
Native VLAN 99
```

Switch B:

```
Native VLAN 1
```

Problem:

```
Native VLAN mismatch
```

# VLAN Tagging

## IEEE 802.1Q

802.1Q adds a VLAN tag into the Ethernet frame.

---

# 802.1Q Tag Format

Inserted between:

```
Source MAC
       |
       v
802.1Q Tag
       |
       v
EtherType
```

---

# VLAN Tag Fields

| Field | Size |
|---|---:|
| TPID | 16 bits |
| Priority (802.1p) | 3 bits |
| DEI | 1 bit |
| VLAN ID | 12 bits |

---

# VLAN ID Capacity

12-bit VLAN ID:

```
2^12 = 4096 VLANs
```

Usable range:

```
1-4094
```

---

# Inter-VLAN Communication

Devices in different VLANs cannot communicate directly.

Example:

```
VLAN 10

PC-A
 |
X

VLAN 20

PC-B
```

Requires:

- Router
- Layer 3 switch

---

# VLAN Broadcast Domains

Each VLAN creates a separate broadcast domain.

Example:

```
VLAN 10
 |
Broadcast Domain 1


VLAN 20
 |
Broadcast Domain 2
```

---

# VLAN Security Benefits

| Benefit | Description |
|---|---|
| Isolation | Separates departments |
| Reduced attacks | Limits broadcast exposure |
| Control | Easier access policies |

# Cisco VLAN Commands

## Create VLAN

```bash
Switch(config)# vlan 10
```

Purpose:

Creates VLAN 10.

---

## Name VLAN

```bash
Switch(config-vlan)# name SALES
```

Purpose:

Assigns a VLAN name.

---

## Assign Access Port

```bash
Switch(config)# interface gigabitEthernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
```

Explanation:

```bash
switchport mode access
```

Sets the port as an access port.

```bash
switchport access vlan 10
```

Places port in VLAN 10.

---

## Configure Voice VLAN

```bash
Switch(config-if)# switchport voice vlan 20
```

Purpose:

Assigns voice VLAN 20.

---

## View VLANs

```bash
show vlan brief
```

Displays:

- VLAN IDs
- Names
- Assigned ports

---

## View VLAN Information

```bash
show vlan
```

Displays detailed VLAN information.

# 3. Worked Examples

## Example 1: Identify VLAN Type

### Scenario

A switch port connects to an IP phone and a PC. The phone traffic is placed in VLAN 50, while PC traffic uses VLAN 10.

Identify VLAN types.

---

### Solution

Step 1:

PC traffic:

```
VLAN 10
```

This is:

```
Data VLAN
```

Step 2:

Phone traffic:

```
VLAN 50
```

This is:

```
Voice VLAN
```

Answer:

```
VLAN 10 = Data VLAN
VLAN 50 = Voice VLAN
```

---

## Example 2: Native VLAN Mismatch

### Scenario

Two switches have a trunk connection.

Switch A:

```
Native VLAN 99
```

Switch B:

```
Native VLAN 1
```

What problem occurs?

---

### Solution

Step 1:

Compare native VLANs.

```
99 ≠ 1
```

Step 2:

802.1Q requires matching native VLANs.

Result:

```
Native VLAN mismatch
```

Fix:

Configure the same native VLAN on both sides.

# 5. Exam Traps

- VLANs create separate broadcast domains.
- VLANs operate at Layer 2.
- Devices in different VLANs require Layer 3 routing.
- Default VLAN is VLAN 1.
- Native VLAN traffic is untagged.
- Voice VLAN is used for IP phones.
- Data VLAN carries normal user traffic.
- Native VLAN must match on both trunk ends.
- VLAN 1 cannot be deleted on Cisco switches.
- Trunk ports carry multiple VLANs.
- Access ports carry one VLAN.
- 802.1Q is the standard VLAN tagging method.

# 7. Practice Questions

## Question 1

What is the primary purpose of VLANs?

A. Increase cable speed  
B. Create logical broadcast domains  
C. Replace routers  
D. Encrypt traffic  

### Answer: B. Create logical broadcast domains

Explanation:

VLANs logically separate Layer 2 broadcast domains.

---

## Question 2

Which VLAN carries untagged frames across an 802.1Q trunk?

A. Data VLAN  
B. Voice VLAN  
C. Native VLAN  
D. Default VLAN  

### Answer: C. Native VLAN

Explanation:

Native VLAN traffic is not tagged.

---

## Question 3

What is the default VLAN on Cisco switches?

A. VLAN 0  
B. VLAN 1  
C. VLAN 10  
D. VLAN 100  

### Answer: B. VLAN 1

Explanation:

Cisco switches start with VLAN 1 as the default VLAN.

---

## Question 4

Which command displays VLAN information?

A. show vlan brief  
B. show ip route  
C. show arp  
D. show mac address  

### Answer: A. show vlan brief

Explanation:

This command displays VLANs and assigned ports.

---

## Question 5

Two switches have different native VLANs on the same trunk. What occurs?

A. Faster traffic  
B. Native VLAN mismatch  
C. VLAN deletion  
D. IP conflict  

### Answer: B. Native VLAN mismatch

Explanation:

Native VLAN configuration must match on both trunk endpoints.
