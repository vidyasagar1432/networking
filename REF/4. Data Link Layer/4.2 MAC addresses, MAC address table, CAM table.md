# 1. Overview

A MAC address is a Layer 2 physical address used by Ethernet devices for communication inside a local network. CCNA tests MAC address structure, address types, switch learning behavior, and how switches use the MAC address table (CAM table) to forward frames.

---

# 2. Core Concepts

# MAC Address Definition

## What is a MAC Address?

MAC (Media Access Control) address is a unique hardware identifier assigned to a network interface card (NIC).

| Feature | Value |
|---|---|
| Layer | Layer 2 (Data Link) |
| Length | 48 bits |
| Format | Hexadecimal |
| Assigned by | NIC manufacturer |
| Stored in | Network interface hardware |
| Used by | Switches |

---

# MAC Address Format

Example:

```
00:1A:2B:3C:4D:5E
```

Other formats:

```
001A.2B3C.4D5E
```

```
00-1A-2B-3C-4D-5E
```

---

# MAC Address Structure

A MAC address contains:

```
48 bits = 6 bytes
```

Format:

```
XX:XX:XX:XX:XX:XX
```

---

# MAC Address Fields

| Field | Size | Purpose |
|---|---:|---|
| OUI (Organizationally Unique Identifier) | 24 bits | Manufacturer identification |
| Device Identifier | 24 bits | Unique device ID |

---

# OUI Example

MAC:

```
00:1A:2B:3C:4D:5E
```

First 3 bytes:

```
00:1A:2B
```

represent:

```
Manufacturer
```

Last 3 bytes:

```
3C:4D:5E
```

represent:

```
NIC/device identifier
```

---

# MAC Address Types

| Type | Destination | Example |
|---|---|---|
| Unicast | One device | 00:11:22:33:44:55 |
| Broadcast | All devices | FF:FF:FF:FF:FF:FF |
| Multicast | Group of devices | 01:00:5E:xx:xx:xx |

---

# Unicast MAC Address

## Definition

A unicast MAC identifies a single network interface.

Example:

```
PC-A
00:AA:BB:CC:DD:01
```

Frame delivery:

```
Switch → Specific Port
```

---

# Broadcast MAC Address

## Definition

Broadcast reaches all devices in the local broadcast domain.

Address:

```
FF:FF:FF:FF:FF:FF
```

Switch behavior:

```
Flood out all ports
```

except the receiving port.

---

# Multicast MAC Address

## Definition

Multicast sends traffic to a group of devices.

Example:

```
01:00:5E:xx:xx:xx
```

Common use:

- Streaming
- Routing protocols
- Video conferencing

---

# MAC Address vs IP Address

| Feature | MAC Address | IP Address |
|---|---|---|
| Layer | Layer 2 | Layer 3 |
| Purpose | Local delivery | End-to-end routing |
| Format | Hexadecimal | Decimal/hex |
| Example | 00:1A:2B:3C:4D:5E | 192.168.1.10 |
| Changes | Usually fixed | Can change |
| Device | Switch | Router |

---

# Burned-In Address (BIA)

## Definition

The original MAC address assigned by the manufacturer.

Characteristics:

| Feature | Description |
|---|---|
| Stored in NIC firmware | Yes |
| Permanent | Usually |
| Also called | Hardware address |

---

# MAC Address Table (CAM Table)

## Definition

A MAC address table is a database maintained by a switch that maps MAC addresses to physical switch ports.

Also called:

```
CAM Table
```

(Content Addressable Memory)

---

# MAC Table Example

| MAC Address | Interface | Type |
|---|---|---|
| 00:11:22:33:44:55 | Gi0/1 | Dynamic |
| AA:BB:CC:DD:EE:FF | Gi0/2 | Dynamic |

---

# Why Switches Need a MAC Table

Without a MAC table:

```
Switch receives frame
        |
        v
Flood everywhere
```

With MAC table:

```
Switch receives frame
        |
        v
Find destination port
        |
        v
Forward only there
```

---

# Switch MAC Learning Process

A switch learns from:

```
Source MAC address
```

not destination MAC.

---

# MAC Learning Example

Topology:

```
PC-A              Switch             PC-B

MAC-A             Gi0/1              Gi0/2
```

PC-A sends frame.

Frame contains:

```
Source MAC = MAC-A
```

Switch learns:

```
MAC-A → Gi0/1
```

---

# MAC Address Forwarding Process

## Step 1: Receive Frame

Switch receives Ethernet frame.

---

## Step 2: Learn Source MAC

Switch checks:

```
Source MAC
```

and updates CAM table.

---

## Step 3: Check Destination MAC

Switch searches CAM table.

---

## Step 4: Forward Frame

Actions:

| Destination | Action |
|---|---|
| Known unicast | Forward to specific port |
| Unknown unicast | Flood |
| Broadcast | Flood |
| Multicast | Forward/flood depending on configuration |

---

# Dynamic MAC Entries

Most MAC entries are learned automatically.

Example:

```
MAC-A → Gi0/1
```

---

# Aging Timer

Dynamic MAC addresses are removed after inactivity.

Default Cisco aging time:

```
300 seconds
```

(5 minutes)

---

# Static MAC Entries

Manually configured MAC addresses.

Characteristics:

| Feature | Value |
|---|---|
| Learned automatically | No |
| Removed by aging | No |
| Used for | Special cases |

---

# CAM Table Operation

CAM memory allows switches to quickly search:

```
MAC Address → Port
```

Advantages:

| Benefit | Explanation |
|---|---|
| Fast lookup | Hardware-based searching |
| Efficient forwarding | Sends only where needed |

---

# Unknown Unicast Flooding

Example:

Destination MAC not in table:

```
PC-A → Switch → Unknown PC
```

Switch floods:

```
All ports except incoming port
```

---

# Broadcast Flooding

Example:

ARP request:

```
Who has 192.168.1.1?
```

Destination MAC:

```
FF:FF:FF:FF:FF:FF
```

Switch floods to VLAN.

---

# MAC Table and VLANs

MAC tables are separated by VLAN.

Example:

| VLAN | MAC | Port |
|---|---|---|
| 10 | AA:AA | Gi0/1 |
| 20 | BB:BB | Gi0/2 |

Same MAC can exist in different VLANs.

---

# MAC Address Security

Switches can limit MAC addresses using:

```
Port Security
```

Features:

| Feature | Purpose |
|---|---|
| Static MAC | Allow specific devices |
| Maximum MAC | Limit devices per port |
| Sticky MAC | Dynamically learn and save MAC |

# MAC Table Troubleshooting

| Problem | Possible Cause |
|---|---|
| MAC not learned | Link down |
| Wrong port mapping | Device moved |
| Constant MAC changes | MAC flapping |
| Too many MACs | Loop or security issue |

---

# MAC Flapping

## Definition

A MAC address appears on multiple ports repeatedly.

Example:

```
MAC-A → Gi0/1
MAC-A → Gi0/2
MAC-A → Gi0/1
```

---

# Causes of MAC Flapping

| Cause | Example |
|---|---|
| Switching loop | STP problem |
| Incorrect cabling | Duplicate connection |
| Virtual machines | MAC movement |

# 3. Worked Examples

## Example 1: Build MAC Table

### Scenario

A switch receives:

```
Source MAC:
AA:AA:AA:AA:AA:AA

Incoming Port:
Gi0/5
```

What entry is created?

---

### Solution

Step 1:

Switch examines source MAC.

```
AA:AA:AA:AA:AA:AA
```

Step 2:

Associates it with incoming interface.

Result:

```
AA:AA:AA:AA:AA:AA → Gi0/5
```

---

## Example 2: Forwarding Decision

### Scenario

MAC table:

| MAC | Port |
|---|---|
| PC-A | Gi0/1 |
| PC-B | Gi0/2 |

PC-A sends traffic to PC-B.

What does switch do?

---

### Solution

Step 1:

Receive frame on Gi0/1.

Step 2:

Learn:

```
PC-A → Gi0/1
```

Step 3:

Search destination:

```
PC-B
```

Found:

```
Gi0/2
```

Step 4:

Forward only to:

```
Gi0/2
```

```bash

```

Purpose:

Changes dynamic MAC timeout to 600 seconds.

# 5. Exam Traps

- Switches learn source MAC addresses, not destination MAC addresses.
- MAC addresses operate at Layer 2.
- IP addresses operate at Layer 3.
- CAM table and MAC address table mean the same thing.
- Broadcast MAC is FF:FF:FF:FF:FF:FF.
- Unknown unicast frames are flooded.
- Dynamic MAC entries age out.
- Static MAC entries do not age out.
- MAC tables are maintained per VLAN.
- A switch does not use IP addresses to forward Ethernet frames.
- MAC flapping often indicates a Layer 2 loop.

# 7. Practice Questions

## Question 1

What does a switch learn from incoming Ethernet frames?

A. Destination MAC  
B. Source MAC  
C. Destination IP  
D. Source port number  

### Answer: B. Source MAC

Explanation:

Switches build CAM tables by learning source MAC addresses.

---

## Question 2

What is the broadcast MAC address?

A. 00:00:00:00:00:00  
B. FF:FF:FF:FF:FF:FF  
C. 01:00:5E:00:00:01  
D. 192.168.1.255  

### Answer: B. FF:FF:FF:FF:FF:FF

Explanation:

All Ethernet broadcast frames use FF:FF:FF:FF:FF:FF.

---

## Question 3

What is another name for a switch MAC table?

A. Routing table  
B. ARP table  
C. CAM table  
D. NAT table  

### Answer: C. CAM table

Explanation:

Switches store MAC-to-port mappings in CAM memory.

---

## Question 4

How long does a Cisco switch typically keep dynamic MAC entries?

A. 30 seconds  
B. 60 seconds  
C. 300 seconds  
D. 3600 seconds  

### Answer: C. 300 seconds

Explanation:

The default MAC aging timer is 5 minutes.

---

## Question 5

A switch receives a frame for an unknown destination MAC. What happens?

A. Drop frame  
B. Flood frame  
C. Send to router  
D. Modify MAC address  

### Answer: B. Flood frame

Explanation:

Unknown unicast frames are flooded within the VLAN.
