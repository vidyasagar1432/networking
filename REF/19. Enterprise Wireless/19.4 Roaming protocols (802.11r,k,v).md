# Roaming Protocols: IEEE 802.11r, 802.11k, and 802.11v

## CCNP Enterprise (ENCOR 350-401) Wireless Roaming

**CCNA Relevance:** Basic roaming concepts.  
**CCNP ENCOR Relevance:** High — Fast and efficient roaming is critical for enterprise wireless networks, especially for voice, video, healthcare, manufacturing, and high-density deployments.

---

# 1. Overview

Wireless clients often move throughout a building while remaining connected.

Examples:

- Walking during a VoIP call
- Video conferencing while moving
- Using a warehouse scanner
- Moving between classrooms
- Roaming through a hospital

The process of changing from one Access Point (AP) to another without losing connectivity is called **roaming**.

---

# 2. What Is Roaming?

Roaming occurs when a wireless client disconnects from one AP and connects to another AP while remaining on the same wireless network (SSID).

```
        AP1                  AP2

    ((( Coverage )))    ((( Coverage )))

            \              /

             \            /

              Laptop

                 →

             User Walking
```

The goal is to maintain application connectivity with minimal interruption.

---

# 3. Why Roaming Matters

Without efficient roaming:

- Voice calls may drop
- Video sessions may freeze
- Applications may disconnect
- TCP sessions may reset
- User experience degrades

Enterprise Wi-Fi is designed to minimize these interruptions.

---

# 4. Basic Roaming Process

```
Connected to AP1

↓

Signal Weakens

↓

Find Better AP

↓

Authenticate

↓

Associate

↓

Connected to AP2
```

This process is known as a **handoff** or **roam**.

---

# 5. Traditional Roaming Problem

Older roaming required a complete authentication process every time.

```
Scan

↓

Authenticate

↓

Associate

↓

4-Way Handshake

↓

Traffic
```

This delay could exceed **100–500 ms**, which is noticeable for voice and video.

---

# 6. Fast Roaming Standards

The IEEE introduced several standards to improve roaming.

```
802.11r

↓

Fast Transition

---------------------

802.11k

↓

Neighbor Reports

---------------------

802.11v

↓

Network Assistance
```

These standards complement each other and are often deployed together.

---

# 7. The Three Standards at a Glance

| Standard | Purpose |
|----------|---------|
| **802.11r** | Speeds up authentication during roaming |
| **802.11k** | Helps clients discover nearby APs |
| **802.11v** | Helps the network guide client roaming decisions |

---

# 8. IEEE 802.11r (Fast BSS Transition)

**802.11r** reduces the delay caused by reauthentication.

Instead of performing a complete authentication exchange with every new AP, cryptographic information is prepared in advance.

This enables much faster roaming.

---

# 9. 802.11r Concept

Traditional:

```
Roam

↓

Full Authentication

↓

Delay
```

Fast Transition:

```
Roam

↓

Fast Transition

↓

Minimal Delay
```

---

# 10. Fast BSS Transition (FT)

BSS = **Basic Service Set**

Fast BSS Transition allows a client to move between APs with significantly reduced authentication overhead.

Typical roaming delays can be reduced to **tens of milliseconds**, making voice applications much more reliable.

---

# 11. 802.11r Authentication

Instead of creating new security keys every time:

```
Original Key

↓

Derived Keys

↓

Fast Authentication

↓

Roam
```

This eliminates much of the authentication delay.

---

# 12. 802.11r Benefits

- Faster roaming
- Better VoIP quality
- Reduced packet loss
- Lower latency
- Improved user experience
- Better support for real-time applications

---

# 13. 802.11r Requirements

- Client support
- AP support
- WLC support (if applicable)
- WPA2/WPA3 Enterprise or supported Personal implementations
- Proper WLAN configuration

Not every client device supports 802.11r.

---

# 14. IEEE 802.11k (Neighbor Reports)

**802.11k** helps clients make better roaming decisions.

Instead of scanning every channel:

```
Current AP

↓

Neighbor Report

↓

Nearby AP List

↓

Client Chooses
```

---

# 15. Traditional Scanning

Without 802.11k:

```
Client

↓

Scan Channel 1

↓

Scan Channel 6

↓

Scan Channel 11

↓

Scan 5 GHz

↓

Choose AP
```

This scanning process increases roaming time.

---

# 16. 802.11k Neighbor Report

The AP provides information such as:

- Neighbor APs
- Operating channels
- BSSIDs
- Capabilities

Example:

```
AP1

↓

Neighbor List

↓

AP2

AP3

AP4
```

The client knows where to look instead of scanning blindly.

---

# 17. Benefits of 802.11k

- Faster AP discovery
- Reduced scanning time
- Improved battery life
- Better roaming efficiency
- Lower roaming latency

---

# 18. IEEE 802.11v (BSS Transition Management)

**802.11v** allows the network to assist clients with roaming decisions.

Instead of waiting for the client to decide:

```
Controller

↓

Recommendation

↓

Client

↓

Move to AP2
```

---

# 19. Client Steering

Example:

```
AP1

95% Utilized

------------------

AP2

30% Utilized

↓

Move Client
```

This balances the wireless load across APs.

---

# 20. Load Balancing

```
AP1

100 Clients

↓

Move

↓

AP2

40 Clients
```

802.11v helps distribute clients more efficiently.

---

# 21. Band Steering

Many dual-band clients initially connect to **2.4 GHz**.

```
Client

↓

2.4 GHz

↓

Controller Suggests

↓

5 GHz
```

Although band steering is often implemented using vendor-specific mechanisms, 802.11v BSS Transition Management can assist in steering capable clients toward a preferred BSS.

---

# 22. Sleep Mode Assistance

802.11v also includes features that help clients conserve battery power by improving communication about power-saving behavior.

This is particularly useful for mobile devices.

---

# 23. Roaming Workflow

Without enhancements:

```
Weak Signal

↓

Scan

↓

Authenticate

↓

Associate
```

With 802.11r/k/v:

```
Weak Signal

↓

Neighbor Report (802.11k)

↓

Network Recommendation (802.11v)

↓

Fast Authentication (802.11r)

↓

Roam
```

---

# 24. Controller Role

The WLC maintains information about:

- AP locations
- Client associations
- Neighbor relationships
- RF conditions
- Load distribution

This information supports efficient roaming decisions.

---

# 25. Voice over Wi-Fi (VoWiFi)

Voice applications require:

- Low latency
- Low jitter
- Minimal packet loss

802.11r, 802.11k, and 802.11v are commonly enabled to improve roaming performance for voice deployments.

---

# 26. Roaming Types

## Layer 2 Roaming

```
AP1

↓

AP2

↓

Same VLAN
```

The client remains in the same IP subnet.

No IP address change is required.

---

## Layer 3 Roaming

```
AP1

↓

Different VLAN

↓

AP2
```

The infrastructure must preserve connectivity while the client moves between subnets.

Modern controllers provide mechanisms to support this.

---

# 27. Deployment Requirements

For optimal roaming:

- Overlapping coverage
- Proper AP placement
- Correct transmit power
- Consistent SSID
- Compatible security settings
- Client support for roaming standards

---

# 28. Troubleshooting

## Slow Roaming

Check:

- 802.11r enabled
- Client compatibility
- Signal overlap
- RF interference
- Authentication delays

---

## Clients Do Not Roam

Verify:

- RSSI thresholds
- Client drivers
- Neighbor relationships
- Coverage design
- AP transmit power

---

## Voice Call Drops

Check:

- 802.11r configuration
- QoS (WMM)
- Roaming latency
- SNR
- Packet loss
- Controller logs

---

# 29. Best Practices

- Enable **802.11r** for supported voice and real-time devices.
- Enable **802.11k** to reduce scanning time.
- Enable **802.11v** for client steering and load balancing.
- Design for sufficient AP overlap (without excessive overlap).
- Avoid excessive transmit power.
- Use consistent WLAN security across APs.
- Validate roaming with active site surveys.

---

# CCNP Exam Traps

- **802.11r = Fast Transition (FT)** — reduces authentication delay during roaming.
- **802.11k = Neighbor Reports** — helps clients discover nearby APs more quickly.
- **802.11v = BSS Transition Management** — allows the network to recommend better APs.
- These standards **complement each other** rather than replace one another.
- **802.11r** primarily reduces authentication time.
- **802.11k** primarily reduces scanning time.
- **802.11v** primarily improves roaming decisions and load balancing.
- Clients must support these standards to benefit from them.
- Good RF design remains essential—these protocols cannot compensate for poor coverage.
